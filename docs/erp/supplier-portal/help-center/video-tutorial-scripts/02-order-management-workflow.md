**订单详情展示**：

- **特殊要求**：红色文字标注，警示图标
- **附件文档**：图纸、规格书等文件图标

**动画效果**：
- 通知图标脉冲动画（吸引注意力）

**解说脚本**：

### 【订单确认与交期管理】1:31-2:30
**画面内容**：
1. 确认订单操作演示：
   - 点击【确认】按钮
   - 弹出确认表单
   - 填写确认交期（日历控件演示）
   - 填写备注信息

2. 交期管理技巧：
   - 演示修改交期（如需要调整）
   - 展示交期冲突预警
   - 演示生产能力评估工具

**表单填写示例**：
```
确认交期：2026-05-20（原要求：2026-05-18）
备注：因原材料采购需额外2天，交期调整为5月20日
附件：无
```

**预警演示**：
- 当交期晚于原要求时，系统显示黄色警告
- 交期冲突时显示红色警示（与其他订单重叠）
- 建议交期：系统基于历史数据推荐

**解说脚本**：
> "收到订单后，务必在3个工作日内确认。点击确认按钮，填写您能承诺的交货日期。如果无法满足原交期，请实事求是地调整，并在备注中说明原因。系统会检查交期冲突并给出预警，请根据您的实际生产能力合理安排。"

### 【生产进度更新】2:31-3:30
**画面内容**：
1. 进度更新操作演示：
   - 点击【更新进度】按钮
   - 选择当前进度状态
   - 上传现场照片或文档
   - 填写进度说明

2. 进度状态类型展示：
   - 备料中（物料准备阶段）
   - 生产中（生产制造阶段）
   - 质检中（质量检验阶段）
   - 待发货（生产完成，等待发货）

**照片上传演示**：
- 选择生产现场照片（清晰、有代表性）
- 照片自动压缩和添加水印
- 多张照片的上传和排序

**客户视角展示**：
- 切换视角：演示客户看到的进度信息
- 进度时间轴可视化展示
- 照片的缩略图预览

**解说脚本**：
> "订单确认后，定期更新生产进度能让客户放心。系统提供4个标准进度状态，您还可以上传现场照片增加透明度。客户在他们的门户中能看到这些更新，这是建立信任的重要方式。建议至少每周更新一次进度，重大节点及时更新。"

**画面内容**：
1. 发货操作流程：
   - 点击【发货】按钮
   - 填写物流信息表单
   - 上传发货单照片
   - 确认发货完成

2. 物流信息表单字段：
   - 物流公司（下拉选择或手动输入）
   - 运单号（扫码或手动输入）
   - 发货时间（默认当前时间，可调整）
   - 预计到达时间（自动计算）

3. 物流跟踪演示：
   - 运单号自动关联物流公司API
   - 实时物流状态展示
   - 异常物流提醒（如延迟、异常签收）

**扫码功能演示**：
- 手机摄像头扫描发货单条形码
- 自动识别并填充运单号
- 识别物流公司logo

**解说脚本**：
> "产品准备完成后，进入发货环节。准确填写物流信息至关重要，运单号是跟踪货物的关键。您可以直接扫描发货单条形码，系统会自动识别。发货后，客户可以在他们的系统中实时查看物流状态，减少催货沟通。"

**沟通技巧提示**：
