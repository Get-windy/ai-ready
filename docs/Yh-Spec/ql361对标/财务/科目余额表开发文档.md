# 科目余额表开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/balance-report`（列表查询页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- 列表查询页（账簿/报表查询：查询区 + 分组表头汇总表格 + 合计行；无分页，一次全量呈现），按科目汇总期初/本期发生/本年累计/期末四段余额的试算平衡表。
- 单入口：菜单 财务 → 账簿 → 科目余额表；另有 `finance/trial-balance` 目录（对应关系待复核）。
- 数据实据（截图）：科目 4103 本年利润、4000 期初资本。

## 2. 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（会计月(止)*、科 目）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 会计月(起)、会计月(止)*（必填）、科目层级（默认 1）、科目（可指定单个科目过滤）
- 勾选项：显示无数据科目
- 布局（截图）：查询区两行——第一行查询方案 + 工具栏按钮，第二行查询条件 + 勾选项

### 功能按钮

按抓取 JSON buttons 实据：刷新、打印(F8)、导出、明细对账、查询

## 3. 数据表格列配置

### 默认显示列（10 个数据列，含 2 个分组表头，抓取 JSON columns 实据）

科目类型、科目编码、科目名称、层级、期初余额、本期发生额（分组表头，下辖：借方、贷方）、本年累计（分组表头，下辖：借方、贷方）、期末余额

> JSON columns 共 10 项（科目类型、科目编码、科目名称、层级、期初余额、本期发生额、本年累计、期末余额、借方、贷方），首项"科目类型"经截图核对为真实首列，非抓取拼接串；JSON 中"借方、贷方"为两组分组子列的去重抓取，按图展开后数据叶子列=科目类型/科目编码/科目名称/层级/期初余额/本期借方/本期贷方/累计借方/累计贷方/期末余额，共 10 列。

## 4. 业务规范

- 取数逻辑：数据源自会计凭证分录按科目聚合——期初余额（会计月起时点数）、本期发生额（起止月间借贷）、本年累计（年初至止月借贷）、期末余额（止月时点）。
- 试算平衡（合计行实据）：期初余额 6,788,490.9 / 本期借方 3,950,432 / 本期贷方 3,950,432 / 本年累计借方 41,826,093.29 / 本年累计贷方 41,826,093.29 / 期末余额 8,464,142.32——Σ本期借方=Σ本期贷方、Σ本年累计借方=Σ本年累计贷方（凭证借贷守恒的表级体现）。
- 科目类型值域（截图实据）：资产类、负债类、所有者权益类、损益类（成本类是否独立待复核）；损益类科目期初为 0（年度结转后），本期发生即当期损益。
- 科目层级：默认 1 级；调大层级展开至明细科目（科目名称缩进呈现）。
- 表格结构（截图）：首列为齿轮列配置入口；表头两级——"本期发生额""本年累计"为分组表头，各辖"借方/贷方"子列；科目名称含层级缩进；无分页栏。
- 与其他页面关系：数据源《会计凭证开发文档》；逐笔联查《明细账开发文档》（"明细对账"按钮核对总账与明细）；核算维度展开《辅助核算余额表开发文档》（按核算项细分同一科目余额）；报表取数《资产负债表开发文档》（资产/负债/权益科目期末与年初余额）、《利润表开发文档》（损益科目发生额）；本系统前端目录 `finance/balance-report`、`finance/trial-balance`（双目录对应关系待复核）。
