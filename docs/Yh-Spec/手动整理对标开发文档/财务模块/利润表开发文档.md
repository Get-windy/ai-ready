# 利润表开发文档

> **文档类型：** 页面对标复刻（已完成代码）

## 页面概述

利润表是**按会计期间出具的损益报表**（营业收入 → 逐级加减成本费用 → 利润）。**报表页**，单入口（无独立表单/分页）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 利润表 | `finance/profit-report` | 单表纵向 3 列，三级缩进行 |

菜单：财务 → 财务报表 → 利润表。

### 配置功能说明
- **查询参数**：会计期间（年度/期间）、科目层级（默认 2）、勾选"显示为0科目"。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 报表列结构

### 列（对标单表纵向 3 列）
| # | 列名 | 说明 |
|---|------|------|
| 1 | 项目 | 损益项目（三级缩进） |
| 2 | 本期发生额 | 单会计月当月发生 |
| 3 | 本年累计 | 年初至止月累计 |

### 三级缩进结构
- 一级：一、营业收入 / 减：主营业务成本 / 加：其他业务收入 / 减：其他业务成本（加粗，带"减：/加："前缀）。
- 二级：费用科目小计（销售费用/管理费用/财务费用，加粗无前缀）。
- 三级：费用类型/收入明细（普通字体，深层缩进）。

---

## 业务规范说明

- **报表口径**：本期发生额=单会计月当月发生；本年累计=年初至止月累计。
- **科目层级参数**：控制展开级次（层级 2 展开到子项；层级 1 仅小计行）。
- **汇总行**：营业利润/利润总额/净利润等（按国内报表惯例）。
- **数字右对齐**，无链接穿透（与资产负债表不同）。
