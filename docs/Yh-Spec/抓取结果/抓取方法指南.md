> 用途：让 sub-agent 用 Playwright MCP 抓取 ql361（22stable.ql361.com）配置弹窗，产出金标准所需字段。
> 技术细节见《对标开发技术参考文档.md》§1.5 ⑥⑦⑧。本文件给可直接复制的 JS 脚本。

## 0. 登录（若会话已过期）

## 1. 导航到页面（无独立路由，必须点菜单）
- `browser_click` 顶部域菜单（销售/采购/财务/资料…）。
- `browser_find("页面名")` 定位子菜单项 → `browser_click` 对应文本（若是双入口，点「历史」进列表页，点页面名进表单页）。
- 确认已打开：`browser_find` 该页特征列/按钮（列表页表头列名）。

## 2. 抓「列配置弹窗」→ 全部可配置列 + 默认显示列
1. 定位激活数据表内的列配置图标 **`.icon-shezhi2`**（⚠️ 多Tab/双数据表时用 `opacity/可见性` 或激活面板锚点定位；不要用全页 `.pop()`）。
2. `browser_click` 该图标（target 用 CSS 选择器，如 `.icon-shezhi2`，若有多个可先 evaluate 取可见那个的 index 或用面板内定位）。
3. 用下面 evaluate **一次性读取全部列 + 每列 checkbox 勾选状态**（x=默认显示、空格=隐藏）：

```js
() => {
  const dialogs = [...document.querySelectorAll('[class*=Dialog], .lkgrid-setting-dialog, [role=dialog]')];
  const dlg = dialogs.find(d=>d.innerText.includes('全局配置') && d.innerText.includes('显示名'));
  if(!dlg) return { err:'no column dialog', foundDialogs: dialogs.slice(0,5).map(d=>d.innerText.slice(0,60).replace(/\s+/g,' ')) };
  const rows = [...dlg.querySelectorAll('tr')];
  const raw = rows.map(r=>{
    const cb = r.querySelector('input[type=checkbox]') || r.querySelector('.dijitCheckBox, .dijitCheckBoxInput');
    let checked=false;
    if(cb){ checked = cb.checked===true || (cb.className||'').includes('Checked') || cb.getAttribute('aria-checked')==='true' || (cb.classList && (cb.classList.contains('dijitCheckBoxChecked')||cb.classList.contains('checked'))); }
    const tds = [...r.querySelectorAll('td')];
    const texts = tds.map(td=>td.innerText.trim()).filter(t=>t);
    return {texts, checked};
  }).filter(r=>r.texts.length>0);
  // 去重：应带序号两列重复(个人/全局两Tab预渲染)，保留每串 "序号\t\t列名" 首次出现
  const seen=new Set(); const cols=[];
  for(const r of raw){
    const m = r.texts[0]?.match(/^(\d+)\t\t(.+)$/);
    if(m && !seen.has(m[2])){ seen.add(m[2]); cols.push({seq:+m[1], name:m[2], def:r.checked}); }
  }
  return { count: cols.length, cols: cols.map(c=>({n:c.seq, name:c.name, def:c.def?'[x]':'[ ]'})) };
}
```

- 结果里 `def:'[x]'` = 默认显示列；`'[ ]'` = 隐藏列。`count` = 全部可配置列数（去重后）。

## 3. 抓「页面配置弹窗」→ 查询条件配置字段 + 功能按钮配置字段（含隐藏）
1. 入口 = 页面**顶部按钮栏**的「配置」齿轮（**`iconButtonConfig`-样 class / title="配置"的齿轮按钮**，不是数据表 icon-shezhi2，也不是功能按钮区文本「配置」）。
2. `browser_click` 该齿轮 → 打开 **Vue "配置" dialog**（顶部 Tab：查询条件 / 功能按钮；底部「使用鼠标拖动行可以调整顺序 + 恢复默认 + 关闭(Esc)」）。
3. 用 evaluate 读取弹窗文本，**分别抓「查询条件」和「功能按钮」两个 Tab** 的字段清单。切换 Tab 用 `browser_click`（真实点击，见 §⑦）。

```js
() => {
  const dlg = [...document.querySelectorAll('*')].find(e=>e.innerText && e.innerText.includes('查询条件') && e.innerText.includes('功能按钮') && e.innerText.includes('使用鼠标拖动'));
  if(!dlg) return { err:'no page-config dialog' };
  // 当前激活 Tab 的字段=去掉开关词后的列表
  const text = dlg.innerText;
  const words='配置 查询条件 功能按钮 使用鼠标拖动行可以调整顺序 恢复默认值 关闭';
  const body = text.split('\n').map(l=>l.trim()).filter(l=>l && !words.includes(l));
  return { body };
}
```
- 手动切换「查询条件」/「功能按钮」Tab 后各跑一次上面的 evaluate。
- 注意：页面配置弹窗字段也**含隐藏项**（未勾选的字段也在列表里），按金标准「页面配置弹窗-查询条件配置字段/功能按钮tab配置字段」列出**全部**（含隐藏）。

## 4. 关闭弹窗
```js
() => { const d=document.querySelector('.dijitDialogCloseIcon, [class*=Close]'); if(d){d.click();return 'closed';} return 'none'; }
```
（列配置/页面配置弹窗都可用；Vue 弹窗用「关闭(Esc)」。）

## 5. 多Tab / 双数据表（关键）
- 复合页每个 Tab 一个数据表 → 每个数据表一个 `.icon-shezhi2`；dojo **预渲染**，非激活 Tab 的图标 `offsetParent` 也非空。
- **必做**：先确认当前激活 Tab（`browser_find` 该 Tab 下独有的表头列名/按钮文本），在该**激活面板内**定位 `.icon-shezhi2`（可 evaluate 找出 `getBoundingClientRect` 在视口内的那个，或用面板独有文本 anchor 父级定位）。
- 一个 Tab 抓完（列配置+页面配置）后 **关闭弹窗**，再切下一个 Tab；切 Tab 用 `browser_click` 真实点击。
- 双入口（表单+列表）：表单页、列表页**各是一个数据表/一组配置**，要分别抓（列表页点菜单下「历史」，表单页点菜单项）。表单页的列配置常挂在「单据明细/核销明细」数据表上。
