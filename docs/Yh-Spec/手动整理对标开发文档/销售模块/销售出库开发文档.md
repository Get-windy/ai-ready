## 页面概述

销售出库模块包含两个核心页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 销售出库列表页 | http://localhost:5656/sales/outbound/index | 包含按单据和按明细两个子标签页 |
| 新增/编辑销售出库表单页 | http://localhost:5656/sales/outbound/form（编辑：`/sales/outbound/form/:id`） | 新增与编辑同组件，按路由 id 区分模式 |

### 本轮补齐过程中发现并修复的其它缺陷
| 缺陷 | 现象 | 修复 |
|---|---|---|
| 表格缺行选择列 | `columns` 未声明 `type:'checkbox'`，行无法勾选 → 批量打印/物流备注/F8/导出选中 等批量功能永远拿不到选中行 | 两个 Tab 均补行选择列 |
| 选择事件未接线 | 页面传了非法的 `:row-selection`，且未监听 `BillTableList` 的 `selection-change`，`selectedRowKeys` 恒为空 | 改监听 `@selection-change`，删除死代码 `rowSelection` |
| 「新增」跳 404 | `handleAdd` 跳 `/sales/outbound/create`，该路由未注册 | 改跳 `/sales/outbound/form` |
| 明细分页口径错误 | 后端按「单据」分页后展开明细，`total` 是单据数、记录却是明细行数 | 改为按明细行分页（`total` = 明细行数） |
| 明细字段键互相覆盖 | `pageDetail` 先放表头 `extNum1/extText1/remark`，又被表体同名字段覆盖 → 表头自定义字段/单据备注与明细串值 | 表头字段改前缀 `headerExt*`、单据备注改 `docRemark`；补齐 `customerTicket`/`createTime` |

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
