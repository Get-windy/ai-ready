## 1. 页面概述

- **列表页**：互联平台账号与往来单位的绑定关系维护页，查询区 + 数据表格；页面顶部有功能说明提示条。
- 截图：![互联账号](../../../../tool-results/ql361/pages/资料__往来单位__互联账号.png)

## 2. 页面配置

### 查询条件

- 往来单位（选择器）
- 互联账号（请输入互联手机号码）

### 功能按钮

- 工具栏（抓取 JSON buttons）：刷新、打印(F8)、导出、更多、查询、跳转（分页跳转）
- 无"新增"按钮（绑定关系的建立入口待复核）
- 行级操作：待复核（抓取时表格无数据，操作列内容未呈现；JSON columns 含"操作"列）

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据）

操作、往来单位、互联用户名、手机号

> JSON columns 第 2 项"往来单位 互联用户名 手机号"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 业务定位（提示条实据）：管理互联平台账号与往来单位的绑定关系——即上下游企业（客户/供应商）在互联平台上的账号与本系统往来单位档案一一绑定
- 无"新增"按钮：绑定关系可能由互联平台侧发起绑定后在本页查看/管理（推断，待复核）
- 抓取时 0 条记录：该演示账套尚未建立互联绑定
- 与其他页面关系：客户/供应商（往来单位，绑定关系一端）、客户"买家账号"列（商城买家账号与互联账号口径区分待复核）、互联业务（推断用于企业间订单协同，实据不足待复核）
