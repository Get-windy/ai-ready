## 二、功能完整性：对标成熟系统

### 2.1 VS Odoo（最大功能缺口）

| Odoo 核心模块 | 我们 | 状态 | 说明 |
|---|---|---|---|
| **CRM** (Lead→Opportunity→Quotation→Sale) | ✅ | 有但无API | 缺少客户门户、自动化工作流、邮件集成 |
| **Sales / Purchase** | ✅ | 较完整 | 缺少价格表(Pricelist)、多单位换算、订阅计费 |
| **Inventory / Stock** | ✅ | 较完整 | 缺少序列号追踪、库存调拨审批流、ABC分析 |
| **Accounting / Finance** | ⚠️ | 部分 | 有总账/凭证/报表，但**缺少固定资产、预算管理、成本核算** |
| **Manufacturing / MRP** | ❌ | **完全缺失** | BOM、工单、工艺路线、排产 |
| **Project** (任务/甘特图/工时) | ❌ | **完全缺失** | 项目管理、任务、甘特图、工时、项目成本 |
| **HR / Payroll** | ❌ | **完全缺失** | 员工、考勤、薪资、招聘 |
| **eCommerce** (商城/支付) | ❌ | **完全缺失** | 在线商城、购物车、支付集成 |
| **Marketing / Email** | ❌ | **完全缺失** | 邮件群发、营销活动、ROI分析 |
| **Helpdesk / Support** | ❌ | **完全缺失** | 工单系统、知识库、SLA |
| **Documents / DMS** | ⚠️ | FileAttachment | 缺少文档管理、版本控制、文档审批 |
| **Workflow** | ✅ | Canvas引擎 | 有工作流引擎，但缺少审批模板库 |
| **Quality / Maintenance** | ❌ | **完全缺失** | 质检、设备维护、巡检 |
| **Calendar / Meeting** | ❌ | **完全缺失** | 日历集成、会议管理 |

## 三、前端UI/组件/布局/操作性：改进项

### 3.1 现有能力成熟度

| 能力维度 | 当前 | 目标 | 差距 |
|---|---|---|---|
| **Dashboard** | 基础卡片 | 可拖拽Widget、角色定制 | ⭐⭐⭐ |
| **列表视图** | TableList（已增强） | 列头分组、内联编辑、批量内联更新 | ⭐⭐ |
| **表单体验** | FormEnhanced | 动态字段依赖、Tab内联编辑 | ⭐⭐⭐ |
| **搜索** | GlobalSearch(Ctrl+K) | 跨模型搜索、保存搜索条件 | ⭐⭐ |
| **看板视图** | 仅Opportunity有 | 所有模块可切换看板 | ⭐⭐⭐ |
| **甘特图** | ❌ 无 | 项目管理必备 | ⭐⭐⭐ |
| **日历视图** | ❌ 无 | 排程/任务/事件管理 | ⭐⭐⭐ |
| **报表设计器** | 固定报表 | 拖拽设计、钻取、多格式导出 | ⭐⭐⭐ |
| **导入向导** | ❌ 无 | Excel导入、字段映射、校验 | ⭐⭐⭐ |
| **批操作** | 基础批删/批审 | 批量编辑字段、批量打印、批量邮件 | ⭐⭐ |

### 3.2 必须改进的10项

#### 1. 仪表盘重构 —— `views/dashboard/index.vue`
- 从固定卡片 → 可拖拽Widget面板
- Widget库：KPI卡片、趋势图、待办列表、最近记录
- 布局持久化（每用户自定义）
- 角色依赖（不同角色看到不同Widget）

#### 2. 看板视图通用化
- 从CRM独有 → 所有列表可切换看板
- 新建通用 `KanbanBoard.vue` 组件
- 支持按状态/阶段/负责人/自定义字段分组
- 卡片间拖拽移动（自动更新字段值）

#### 3. 记录活动流（Chatter） —— Odoo最受欢迎特性
- 每张表单底部增加活动流
- 消息/评论（@提及）
- 自动状态变更日志
- 附件上传 & 安排活动（电话/会议/待办）
- 关注/取消关注

#### 4. 高级搜索/筛选器
- 保存筛选条件（命名、共享）
- 筛选条件组合（AND/OR）
- 快速筛选模板（本月创建/待审批/逾期）
- 搜索高亮

#### 5. 页面/表单配置
- 表单字段级权限（某些字段不可见/只读）
- 表单布局模板（不同角色看到不同布局）
- 自定义字段（运行时添加）

#### 6. 批量导入增强
- 模板下载 → 拖拽上传 → 字段映射 → 数据校验 → 预览确认 → 导入进度

#### 7. 打印/PDF增强
- 打印模板编辑器 & HTML→PDF服务端生成
- 批量打印（选择多条 → PDF合并）
- 打印模板自定义（公司Logo/格式）

#### 8. 内联编辑
- 单元格点击编辑、Tab键快速切换
- 批量编辑（选中行→批量修改字段）
- ESC取消/Enter确认

#### 9. 通知系统增强
- 通知中心（已读/未读/全部）
- 通知类型：审批待办、过期提醒、库存预警
- WebSocket实时推送
- Email/短信通知配置

#### 10. 移动端体验优化
- 触控友好（大按钮、滑动操作）
- 离线数据（IndexedDB）
- 扫码/拍照（PWA）
- PWA（离线缓存、添加主屏幕）

## 四、页面聚合与路由架构：评估

### 4.1 当前架构问题

```
严重问题:
├── 路由冗余
│   ├── /purchase/* 和 /erp/purchase/* 两个路由体系并存
│   ├── 同一业务两套页面, 用户混淆, 维护成本翻倍
│   └── 需要决定保留哪个体系并清理

├── 导航深度不一致
│   ├── purchase/tabs/Orders.vue → /purchase (tab切换)
│   └── erp/purchase/index.vue → /erp/purchase (独立页)
│   用户在不同模块间切换时体验不统一

├── 模块间关联薄弱
│   ├── 客户详情页没有"相关订单"列表
│   ├── 订单详情没有"关联出库单"链接
│   └── 缺少"业务对象详情页"的统一设计

└── 页面标题/面包屑不一致
    ├── 部分页面有page-header, 部分没有
    └── 浏览器标签标题未统一管理
```

### 4.2 现代页面聚合模式（参考Odoo/金蝶）

```
模块首页 (Workspace)
├── 数据概览 (KPI卡片 + 图表)
├── 快速操作 (新建/导入/导出)
├── 待办事项 (当前用户的审批/任务)
├── 最近记录
└── 快捷链接 (配置/报表)

├── 列表视图 (List View)
│   ├── 多视图切换 (列表/看板/日历/甘特图)
│   ├── 筛选/分组/排序
│   └── 批量操作

├── 表单视图 (Form View)
│   ├── 内联编辑子表
│   ├── 活动流 (Chatter)
│   └── 关联记录导航

├── 报表/分析 (Reports)
│   ├── 预置报表 + 图表钻取
│   └── 多格式导出

└── 配置 (Settings)
    ├── 模块参数 + 编号规则
    └── 审批流程配置
```

### 4.3 具体改造建议

| # | 改造项 | 工作量 | 价值 |
|---|---|---|---|
| 1 | **统一路由体系** — 删除 `/erp/*` 冗余路由 | 1周 | ⭐⭐⭐⭐ |
| 2 | **模块工作台首页** — 每个模块增加Workspace首页 | 2周/模块 | ⭐⭐⭐ |
| 3 | **统一详情页规范** — 标题+操作+Descriptions+Chatter | 2周 | ⭐⭐⭐ |
| 4 | **跨模块关联导航** — 客户→订单→出库单→产品 | 2周 | ⭐⭐⭐ |
| 5 | **标签页增强** — Ctrl+Click新标签、右键菜单、持久化 | 1周 | ⭐⭐⭐ |
