## 域级说明

- **单据编号规则**（截图实据）：销售订单 XSDD-、销售退货申请 XSTHSQD-、预订货单 YDHD-、零售单 LSD-、销售出库单 XSCKD-、销售退货单 XSTHD-、销售换货单 XSHHD-，后缀均为 `YYYYMMDD-序号`。
- **快捷键体系**：F8 打印、Ctrl+S 保存草稿、Ctrl+Enter 提交/记账、F3 挂单（零售单）、F1 商品快录聚焦（零售单）。
- **状态流转主线**：销售订单（提交→审核→出库→发货→完成）在订单处理中心闭环；退货走"销售退货申请（审核）→销售退货单（入库）"或直接开退货单两条路径。
- **通用待复核项**：各页打印配置弹窗、录单默认值弹窗的字段级明细（XSMK 仅有截图存档）；拜访域各子标签（拜访设置/拜访线路/任务列表/拜访记录/职员汇总任务/签到统计/签到记录/职员定位）未抓取。
