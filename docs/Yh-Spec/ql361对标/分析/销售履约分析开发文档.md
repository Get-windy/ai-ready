## 业务规范说明

### 统计口径（履约闭环）

- **发货履约率（%）**=发货金额/订单价税合计×100（数量口径为已发数量/订货数量，截图 100/0 两值为主；本周合计发货 8,188/价税 8,328≈98.3%）
- **未发金额**=订单价税合计−发货金额（合计 8,328−8,188=140 ✅，对应唯一待发货单 XSDD-20260723-009）
- **未结金额**=订单价税合计−已结金额（8,328−7,824=504 ✅；发货完成单 XSDD-20260723-002 未结 90 元）
- **订单状态**：审核中 → 待付款 → 待发货 → 发货完成 → 交易完成（与订单处理中心状态流转一致，销售域实据）
- **数据范围**：销售订单（XSDD-）按订货日期过滤；一行一单（勾选"按明细显示"切换一行一明细）

### 与其他页面关系

- 取数：销售订单 + 销售出库单（发货）+ 收款单（结算）三单关联
- 上游：《订单处理中心》（履约操作的执行端）；下游：《销售欠款分析》（未结金额→欠款口径）
