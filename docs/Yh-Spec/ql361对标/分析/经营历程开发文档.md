## 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（往来单位、仓库、经手人、部门）与截图/bodyPreview 确认的全量展开项：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据类型（下拉，默认"全部单据"）、单据编号、往来单位、仓库、经手人
- 部门
- 勾选项：显示红冲

### 功能按钮

按抓取 JSON buttons 实据：刷新、打印(F8)、导出、查询、跳转（分页跳转）

行级操作（截图实据）：红冲(作废)、复制、备注

- **红冲(作废)**：对已记账单据做红字冲销（生成红冲单，原单标记作废，金额反向）
- **复制**：以当前单据为模板快速开新单
- **备注**：维护单据备注信息

### 打印配置

有打印(F8)按钮（列表打印/导出流水台账）；打印配置弹窗字段级明细未抓取，待复核。按销售域惯例：打印配置设置后只针对当前操作员有效（待复核）

## 业务规范说明

### 统计口径与数据关系

- **数据范围**：全部业务域已过账（已记账）单据的全量流水，一行一单；默认按时间快捷段过滤（本月 = 2026-07-01 至 2026-07-23 共 4690 条）
- **金额口径**：单据金额原值列示，合计行对当前过滤范围求和（本月合计 3,329,527.9）；红冲单金额以负数/红字参与合计（"显示红冲"勾选控制红冲单是否入列，默认不显示）
- **来源订单列**：由订单下推生成的单据（如销售订单→销售出库单）记录来源订单号，实现单据链追溯
- **红冲(作废)**：冲销后原单不删除而是成对保留（原单 + 红冲单），保证流水可审计；勾选"显示红冲"可见红冲记录
- **组内分工**：业务草稿提交记账后进入本页；本页是全系统单据级"经营档案"，各统计分析页（销售业绩/经营分析/进销存等）均以此流水为底层取数源

### 与其他页面关系

- 上游：《业务草稿》（提交记账过账）、各业务域表单页直接提交/记账的单据
- 下游：红冲(作废)生成红冲单同步回写库存/往来/资金；销售业绩、经营分析、查应收/查应付等分析页取数基础
- 同组页面：待审批单据、业务草稿

## 验收标准

- 没有桩（Stub）与模拟（Mock）数据：代码中不得出现 TODO、FIXME、stub、模拟、mock、假数据、临时、演示、示例、占位、placeholder，确保使用真实数据
- 查询条件（单据类型、单据编号、往来单位、仓库、经手人、部门）真实过滤；查询方案可保存
- 10 个默认列真实渲染；金额合计行与分页正确（大数据量分页：4690 条/235 页级别）
- 行级红冲(作废)/复制/备注真实可用：红冲生成对冲单并回写下游库存/往来，复制带出原单数据开新单
- "显示红冲"勾选真实控制红冲单显隐；打印(F8)、导出真实可用
