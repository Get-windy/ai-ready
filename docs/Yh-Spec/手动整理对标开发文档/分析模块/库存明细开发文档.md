### 口径说明

- **粒度**：一行 = 单据 × 商品明细（× 批次）；`单据编号` 重复多行即同单多品（实测 `XSCKD-20260901-002` 连续 4 行）。
- **账面入库 / 账面出库双组**：入 / 出**分列**（出库单只填 `账面出库`，入库单只填 `账面入库`，实测零值填充另一组），每组四子列 = 数量 / 小单位数量 / 成本单价 / 成本金额，是**该笔流水的账面影响**，不是余额。
- **批次维度**：`批次条码` + `生产日期` + `到期日期` 三列与《查批次》同源；行级 `批次号` 链接即跳《查批次》的批次跟踪视图。
- **客户 / 收货信息列群**：`客户级别`、`所属分类`、`地址`、`联系人`、`客户备注`、`收货人姓名`、`收货人电话`、`收货人地址` 为往来单位侧快照（默认隐藏），支撑配送类单据的收货落点追溯。
- **单据链信息**：`来源订单`（上游单据）、`单据类型`、`单据明细备注`、`记账时间`、`是否赠品`——`记账时间` 默认隐藏，用于区分单据日期与过账日期口径。
- **成本口径**：`成本单价 / 成本金额` 按出库/入库时的成本价（批次成本 / 移动加权）；实测 `0.625 × 288 = 180` 勾稽成立。

## 4. 业务规范

### 统计口径（明细账粒度）

- **粒度**：一行 = 一张单据 × 一个商品明细（× 批次）；`单据编号` 重复即同单多品。
- **账面入库 / 账面出库**：入 / 出数量**分列**（出库单只填账面出库，入库单只填账面入库）；基准文档记「`数量` 为入 − 出净值口径（具体符号规则待复核）」——本次实测 `columnConfig` **无独立 `数量` 列**（`数量` 是 `账面入库` / `账面出库` 两组的同名子列），**基准该表述待复核**。
- **成本口径**：`成本单价` / `成本金额` 按出库/入库时的成本价（批次成本 / 移动加权）。
- **批次维度**：`批次条码` + `生产日期` + `到期日期` 三列与《查批次》同源。
- **显示红冲**：勾选后红冲单明细入列（与《经营历程》「显示红冲」同规则），实测默认不勾选。
- **日期类型**：单据日期（实测默认）/ 其他日期口径（**可选值待复核**）。
- **期间口径**：查询区默认 `本月`（实测 `2026-09-01 至 2026-09-15`），全部流水按此区间过滤；分页 19 行/页。

### 与其他页面关系

- 上游：全部出入库单据（销售出库 / 采购入库 / 调拨 / 盘点 / 借进借出 / 采退 / 销退等）过账流水。
- 联查终点：《进销存分析》行级「对账」→ 本页该商品期间流水；各汇总页金额钻取的明细落地页。
- 行级去向：`批次号` → 《查批次》批次跟踪；`单据编号` → 打开源单据。
- 同组页面：《查库存》（时点存量）、《查批次》（批次台账）、《进销存分析》（期间汇总）。

### 剩余缺口

1. **3 个查询条件后端未识别（静默不生效）**：`productAttribute`（商品属性）、`dateType`（日期类型）、`includeReversed`（显示红冲）按原样透传，但 `/erp/stock/flow/page` 无对应参数。实测：加 `productAttribute=NOPE&dateType=bookkeepingTime&includeReversed=true` 后 `total` 仍为 14（与不加参数一致）。**故「显示红冲」「日期类型」「商品属性」三项当前对结果无影响，且页面没有任何提示**（代码注释写的是"后端补齐即生效"）。
2. **多数列无数据源**：`/erp/stock/flow/page` 实测每行只返回 `moveTime / docType / docTypeName / docNo / productId / productCode / productName / warehouseId / warehouseName / qty / unitCost / amount / balanceAfter / operatorId / operatorName`。因此**默认可见的 17 列中有 7 列恒空**：口味、批次条码、生产日期、到期日期、单位、往来单位（VO 无 `partnerName`）、经手人（`operatorName` 在 dev 库为 null）；全部 28 个隐藏列（规格 / 型号 / 产地 / 条码 / 商品备注 / 客户级别 / 所属分类 / 地址 / 所属仓库 / 联系人 / 客户备注 / 重量 / 体积 / 小单位 / 单位编号 / 部门 / 品牌 / 收货人 3 列 / 是否赠品 / 单据明细备注 / 记账时间 / 小单位数量 2 列）同样无来源。当前真正有值的是：单据日期、单据编号、商品名称、仓库 + 账面入库 / 出库的数量 / 成本单价 / 成本金额。
3. **无合计行**：对标底部有合计（入库 / 出库数量与金额），本页未接 `summary-columns`。
4. **无分类树 / 无页内 Tab**（与对标一致，非缺口）。
5. **查询方案为占位**：`queryScheme` 未被任何请求使用。
6. **导出 / 打印列口径为「默认可见列」**：打印与导出按列定义的 `defaultHidden` 过滤，而非读取运行时列配置，用户自定义显隐不体现在打印 / 导出中（`index.vue:429-436` 注释已说明）。
