## 1. 页面概述

销售费用分析页是**销售投入产出（费销比）看板**：把销售过程中产生的六类让利/费用按业务归属主体（往来单位 / 职员）归集为 `费用总额`，再与 `销售收入` 对比得出 `费销比(%)`，用于评估客户/业务员的销售经济性。

| 页面 | 地址 | 说明 |
|------|------|------|
| 销售费用分析 | `analytics/sales-expense` | 单入口复合页（2 个视图 Tab：按往来单位 / 按职员；逐 Tab 独立列配置，结构同构） |

单入口：分析 → 采销分析 → 销售费用分析。

- 实测实据（2026-09-15）：
  - `按往来单位` 共 **161** 条记录（含大量销售收入为 0 的长尾单位）。实据样本：肃州区北关龙虾猪蹄王 销售收入 175 / 赠品 6.78 / 优惠 1.58 / 费用总额 8.36 / 费销比 4.78；嘉峪关市润泽园小区西门蜜粉儿 销售收入 0 / 优惠 1.08 / 费用总额 1.08 / 费销比 100。**合计行**：费用总额 `41,353.12`。
  - `按职员` 共 **7** 条记录。实据样本：HC001 杨生淮 销售收入 36,778.12 / 赠品 282.42 / 优惠 77.22 / 费用总额 359.64 / 费销比 0.98；HC003 刘洋洋 销售收入 0 / 优惠 0.63 / 费用总额 0.63 / 费销比 100；HC006 许军 35 / 0 / 0.07 / 0.07 / 0.2。**合计行**：费用总额 `355.67`。
- 六类费用中 `促销活动`、`商品兑付`、`金额兑付`、`其它费用` 在本次实据中**均为 0**（当前数据无此类费用）。

## 4. 业务规范

### 统计口径（六类费用 + 费销比）

- **费用总额** = 赠品 + 促销活动 + 优惠 + 商品兑付 + 金额兑付 + 其它费用。实据：杨生淮 282.42 + 0 + 77.22 + 0 + 0 + 0 = **359.64** ✅；肃州区北关龙虾猪蹄王 6.78 + 0 + 1.58 + 0 + 0 + 0 = **8.36** ✅。
- **费销比(%)** = 费用总额 / 销售收入 × 100。实据：杨生淮 359.64 / 36,778.12 ≈ 0.98 ✅；肃州区北关龙虾猪蹄王 8.36 / 175 ≈ 4.78 ✅；高晓丽 63.6 / 1,188 ≈ 5.35 ✅。
  - ⚠️ **零收入兜底口径**：`销售收入 = 0` 且 `费用总额 > 0` 时费销比显示 **100**（实据：刘洋洋 0.63/0 → 100；嘉峪关市润泽园小区西门蜜粉儿 1.08/0 → 100），**非 0、非空**；该兜底是否为「截断到 100」还是「分母置 1」**待复核**（与基准文档一致）。
  - ⚠️ **负收入**：`销售收入` 为负（退货净额）时费销比为负（基准文档记载，本次实据未出现负收入行，**待复核**）。
- **六类费用分项语义**：`赠品`（随单赠货成本）、`促销活动`（活动分摊费用）、`优惠`（整单/单品优惠让利）、`商品兑付`（以货抵付）、`金额兑付`（以款抵付）、`其它费用`（随单费用，如物流/装卸）。
- **销售收入**：与《销售分析》`销售收入`口径一致（净销售 = 销售额 − 退货额）；本次实据中按职员合计 41,353.12 与《销售业绩》实销金额合计一致（同源口径交叉验证 ✅）。
- **维度语义**：`按往来单位` 以客户/供应商为单位归集（161 条，含大量零收入长尾）；`按职员` 以经手人为单位归集（7 条，与《销售业绩》职员集合同源）。

### 与其他页面关系

- 取数：销售出库单优惠/赠品明细 + 促销活动费用分摊 + 兑付记录 + 随单费用。
- 同源页：《销售分析》（`其他费用支出` / `结算优惠` 列）、《查费用》（费用单单据级口径）、《营销活动分析》（活动侧投入产出）、《销售业绩》（销售收入口径交叉验证）。
- 下游：`总额设置` 调整后应同步影响 `费用总额` 与 `费销比(%)`（设置项弹窗待复核）。

## 5. 实现差异说明

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/sales-expense/index.vue`（共 147 行）。
- **骨架**：`a-tabs`（`index.vue:4-13`，2 Tab：`按部门分布` / `按类型分布`）+ `ARReportPage`（`index.vue:15-40`），**非金标准路线 A**。`ARReportPage` 为纯报表壳（`components/ARReportPage/ARReportPage.vue`：内联查询表单 `:11-64` + `ARStatCards` `:6-9` + `a-table` `:100-120` + 内置 CSV 导出 `:354-367`），**不含** `BillDetailTable`/`StandardPagination`/`PageConfigPanel`，**无列配置齿轮、无页面配置弹窗**。
- **Tab 口径完全不同**：本页 Tab 为「**按部门分布 / 按类型分布**」（费用会计口径），对标为「**按往来单位 / 按职员**」（销售归属口径）。
- **查询条件**：`queryFields`（`index.vue:52-54`）= 仅「申请日期」`applyDateRange`（date-range）。**无**时间快捷段（昨日/今日/…/本年）、**无**往来单位/职员/经手人/部门/仓库。
- **列定义**：`columns`（`index.vue:57-67`）为 **computed**，共 **3 列**：首列（`按部门分布` 时题名「部门」，`按类型分布` 时题名「费用类型」，`dataIndex='name'`）、`费用金额`（`amount`，`formatMoney`）、`占比`（`percent`，渲染为 `a-progress` 进度条）。**无销售收入、无六类费用、无费用总额、无费销比**。
- **统计卡片**：`ARStatCards`（经 `ARReportPage` 的 `stat-cards` prop 注入），`statCards`（`index.vue:79-99`）= 费用总额 / 费用笔数 / 平均单笔 / 涉及部门(类型)数 / 占比最高·X。**与对标的「销售收入 vs 费用总额 vs 费销比」模型不同**。
- **数据来源**：`@/api/analytics` → `expenseStatisticsApi.byDepartment`（`api/analytics.ts:737-739`，`/erp/expense/statistics/by-department`）、`byType`（`api/analytics.ts:741-743`，`/erp/expense/statistics/by-type`）；`fetcher`（`index.vue:108-113`）按当前 Tab 分发；`normalizeResponse`（`index.vue:121-132`）把 `{byDepartment|byType, totalAmount, expenseCount}` 拍平成 `{name, amount, percent}` 行并降序排序。
- **导出**：`ARReportPage` 内置「当前页 CSV 导出」（`ARReportPage.vue:354-367`，**非真实 xlsx、非全量导出**）。
- **打印**：无（`ARReportPage` 无打印能力）。
- **storage-key**：无（未使用列配置/页面配置持久化）。

### 剩余缺口

1. **🔴 Tab 口径不对（最大缺口）**：对标为「按往来单位 / 按职员」（销售归属口径，含六类费用与费销比）；本页为「按部门分布 / 按类型分布」（费用会计口径，仅金额+占比）。**两者维度语义、列结构、取数接口均不同**，需按对标重建双 Tab。
2. **🔴 列结构整体不对齐**：对标两 Tab 各 11 列（单位/职员编号名称 + 销售收入 + 赠品/促销活动/优惠/商品兑付/金额兑付/其它费用 + 费用总额 + 费销比(%)）；本页 3 列（名称/费用金额/占比）。**仅「名称」1 列语义近似**，六类费用拆分、销售收入、费销比全缺。
3. **🔴 查询条件不对齐**：对标 = 时间快捷段 8 段 + 日期范围 + 维度过滤（往来单位/职员/经手人/部门/仓库）；本页 = 仅「申请日期」。
4. **🔴 「总额设置」缺失**：对标有 `总额设置`（费用总额构成 / 费销比口径设置）；本页无。
5. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；**无列配置齿轮、无页面配置弹窗**。
6. **无打印**：对标有 `打印(F8)`；本页无打印按钮。
7. **无合计行**：对标有合计行（按往来单位 `41,353.12`；按职员 `355.67`）；本页无合计。
8. **无钻取**：对标六类费用/费用总额数值带下划线可下钻；本页占比用进度条展示，无下钻。
9. **导出为原型级**：仅 `ARReportPage` 内置当前页 CSV（`ARReportPage.vue:354-367`），非真实 xlsx、非全量。
10. **卡片口径不对**：对标核心是「销售收入 vs 费用总额 vs 费销比」；本页为「费用总额/笔数/均值/涉及数/最高占比」，**无销售收入与费销比指标**。
