# 库存预警补货开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：待规划（采购域对标新增页面）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：补货计算工作台，按仓库库存上下限预警计算缺货数量，勾选商品后一键转采购。
- **单入口**：仅列表页（顶部公式提示条 + 查询区 + 左侧商品分类树 + 数据表格 + 合计行 + 分页）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 全部仓库 / 指定仓库（单选）
- 商品、品牌、所属供应商
- 备注（截图确认）
- 只显示下限预警的商品（勾选框）

> 查询条件一行放下，无「更多条件」折叠入口。

### 功能按钮（抓取 JSON buttons 实据）

采购（红色主按钮）、刷新、打印(F8)、导出、查询、跳转（分页）

### 预警公式设置

顶部黄色提示条「缺货数量 = 库存上限 + 待发货 − 账面数量 − 待收货」内「点击设置」链接进入公式设置（弹窗内容待复核）。

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

仓库编号、仓库名称、商品名称、货号、品牌、口味、型号、预警类型、单位、缺货数量、库存上限、库存下限、备注

> 注：JSON 首项「仓库编号 仓库名称 商品名称 货号」为表头拼接串，非真实单列，已剔除。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核）。

## 4. 业务规范

- 缺货数量 = 库存上限 + 待发货 − 账面数量 − 待收货（页面提示条实据）；「预警类型」列与「只显示下限预警的商品」勾选项对应，枚举值待复核。
- 采购按钮：勾选行后按选中商品转采购流程（生成采购订单的跳转与携带字段待复核）。
- 左侧商品分类树点击过滤表格商品。
- 本页是采购准备四页中唯一带「仓库编号/仓库名称」列的页面：预警按「仓库 × 商品」粒度计算。
- 数据依赖：商品库存上下限（商品/仓库主数据）、账面库存、待发货（销售）、待收货（采购在途）。
- 下游：采购按钮 → 采购订单；同组姊妹页：缺货补货（按销售订单缺口）、智能补货（按日均销量推算）、以销定购（按销售订单逐单转采购）。
