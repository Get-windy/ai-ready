## 页面概述

费用统计用于对**费用单的申请/审批/记账金额**做多维度汇总分析（费用总额/已审批/待审批/已拒绝/单据数/平均单额），并按部门、费用类型、费用明细三个视图下钻查看，配合统计卡片、环形/柱状/趋势图与可配置列明细表。单入口报表页。

| 页面 | 地址 | 说明 |
|------|------|------|
| 费用统计 | `finance/expense-stats` | 申请日期区间查询 + 统计卡片 + 三图 + 三视图明细表（按部门/按费用类型/按明细） |

菜单：财务 → 费用管理 → 费用统计。

### 配置功能说明

- **查询参数**：申请日期区间（`a-range-picker` → `startDate`/`endDate`，实际取当天起止 `dateStart`/`dateEnd`）、单据编号、往来单位、经手人、部门、费用名称、制单人、费用类别、审批状态、单据状态、摘要、显示红冲。
- **快捷日期**：昨日/今日/本周/近一周/本月/上月/近三月（默认）/本年，与《费用单》《费用审批》同款。
- **列配置（唯一入口＝数据表表头齿轮）**：点表格左上角齿轮打开「数据表列配置」（个人配置/全局配置，含列显隐/排序/宽度/显示名），按 storageKey `expense-stats-columns-{dept|type|doc}` 分别持久化。**页面工具栏不再另设列配置按钮**（避免与数据表内置入口重复）。
- **页面配置弹窗**：工具栏齿轮图标按钮（查询条件显隐 + 功能按钮开关，storageKey `expense-stats-page-config`），三视图共用同一套查询口径。
- **图表可显隐**：工具栏「图表」按钮切换，状态记忆在 `localStorage: expense-stats-chart-visible`；按钮悬停提示采用 **下置浮层（placement=bottom）+ 0.4s 延迟**，不遮挡按钮与标签栏。

## 业务规范说明

- **数据源（P0 单一口径）**：`/api/erp/finance/expense-stats/{summary,by-department,by-type,monthly-trend}`，统一聚合《费用单》`erp_expense_doc` + `erp_expense_item`；**不另建统计表/重复费用表**，状态口径与《费用审批》共用同一 `approval_status` 状态机。
- **日期口径**：按费用单**单据日期**（`doc_date`）区间过滤（`dateStart`/`dateEnd`，当天起止包含）。原文档写「申请日期（applyDate）」，实际费用单无 `applyDate` 列，统一落在 `doc_date`。
- **统计范围**：`deleted=0` 且默认排除「已取消」（`status=2`）单据；红冲单（`red_flag=1`）默认计入（作为负向冲销），勾选/传 `showRed=false` 时排除。
- **明细级聚合口径**：全部金额取**费用项金额**合计、单据数取 `COUNT(DISTINCT 主表ID)`。因费用单存在 **P1 守恒**（本单金额 = Σ费用项金额 = Σ付款金额，实测 28/28 单据守恒），明细口径与单据口径完全一致；采用明细口径后，按「费用名称/科目」过滤时卡片与分组表会同步收敛到匹配费用项。
- **金额口径**：`totalAmount`=全部（非取消）费用单费用项金额；`approvedAmount`/`pendingAmount`/`rejectedAmount`=按审批状态分组（2/1/3）；`draftAmount`=未提交（0 或 NULL）；`paidAmount`/`unpaidAmount`=按**记账状态**（status=1 / status=0）区分的**支付口径**；`expenseCount`=去重单据数；`itemCount`=费用项条数；`averageAmount`=总额/单数。
- **分组口径**：`byType` 按**费用名称**（`erp_expense_item.expense_name`，空值→「未指定费用项」）、`byDepartment` 按**部门名称**（`h.dept_name`，空值→「未指定部门」）分组汇总，均为「名称 → 金额」映射（空值按 0）；分组明细另返回 `docCount`/`itemCount`/审批分组金额/已记账金额/单均/占比。
- **派生占比**：分组行「占比」= 分组金额 / 费用总额 × 100%，**后端计算**（2 位小数；总额为 0 时返回 0），保证前后端口径唯一。
- **上游**：费用单（`finance:expense-doc`）提交/审批/记账的数据实时进入本页统计；本页**只读**，无任何写入能力。

### 页面对齐（已建成）

- **三视图 Tab**：按部门 / 按费用类型 / 按明细，各自独立列配置与分页口径。
- **统计卡片**：`ARStatCards` 6 指标卡 + 支付口径说明条（已记账/未记账/费用笔数/往来单位/内部费用）。
- **图表**：`ARReportChart`（ECharts 封装）三图，新增 `point-click` 事件（可选监听，不改动其他报表页行为）支持图表下钻。
- **明细表**：`BillTableList`（内置 `BillDetailTable` 网格）三视图共用，**列配置＝表头齿轮内置面板**、页面配置弹窗，底部合计行 + 分页器。
- **工具栏按钮**：页面配置（齿轮图标）/ 图表显隐（柱状图标，悬停下置提示）/ 刷新 / 导出；列配置不在此处（见数据表表头齿轮）。
- **查询**：12 条件 → `buildParams()` → `fetchSummary()` + 当前视图数据；`onMounted` 首次加载（默认近三月）。
- **口径唯一**：占比/单均由后端计算；下钻复用《费用单》`page-detail`（为其补 `expenseType`/`approvalStatus`/`summary` 过滤与 `approvalStatus/approvalLevel/currentApproverName` 返回列），不重复实现明细查询。

### 顺带修复的共享组件缺陷

- **多视图表头串名**：`BillDetailTable` 在 `columns` 变化时用 `existing.displayName || title` 覆盖标题，而默认 `displayName` 恒等于上一视图的标题 → 同一列 key 在不同 Tab 间复用时表头不更新（实测「按部门」的「部门」串到「按费用类型」的「费用名称」）。改为**仅当用户自定义过显示名（`displayName !== title`）才保留**，未自定义则跟随当前视图列定义。该修复对所有使用多 Tab 列配置的页面普适。

### 待完善（非阻塞）

1. **预算对比（预算 vs 实际）**：本页暂不接入。原因（阻塞而非遗漏）：①《预算执行》（`finance/budget-exec`，菜单 80131）自身尚未金标准升级，其预算明细 `budget_item.subject_code` 当前为空、`subject_name`（如「办公费」）与费用项 `expense_name`（如「办公用品」）**口径不一致**，按名称 join 会产生误导性对比；②按「功能/模块不重复开发」原则，应待《预算执行》提供稳定的**按科目/部门**口径后由本页消费其数据，而非另建一套预算聚合。
2. **同环比**：卡片 `ARStatCards` 支持 `trend`（同比%）字段，本页未接（需确定基准期口径）。
3. **打印**：报表打印（F8）未实现，故未放置打印按钮（避免桩按钮）。
4. **多币种/汇率**：费用单为单币种，未做币种维度。
5. **明细视图列头排序**：后端 `page-detail` 为固定排序（单据日期/单号），未开放任意列排序的服务端分页排序。
