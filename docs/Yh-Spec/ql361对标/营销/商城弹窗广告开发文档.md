## 1. 页面概述

- **列表页**：商城端弹窗广告投放管理页，查询区 + 广告活动列表；新增广告/维护。
- 截图：![商城弹窗广告](../../../../tool-results/ql361/pages/营销__商城营销__商城弹窗广告.png)

## 2. 页面配置

### 查询条件

- 活动名称
- 起始时间、结束时间（默认本月：2026-07-01 ~ 2026-07-31）
- 活动状态（待开始,进行中,已结束——枚举实据）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增广告、查询、跳转（分页跳转）
- 行级操作（操作列存在，抓取时点无数据行，行级动作明细待复核）

### 打印配置

无（页面无打印按钮，截图确认）

## 3. 数据表格列配置

### 默认显示列（6 列，抓取 JSON columns 实据）

操作、活动名称、起始时间、结束时间、活动状态、创建人

> JSON columns 首项即"操作"，无拼接串，6 列全部为真实列，与截图表头一一对应。

### 全部可配置列

待复核（未抓取列配置弹窗）。

## 4. 业务规范

- 弹窗广告模型（列实据归纳）：
  - 投放按时间窗排期：一行 = 一个弹窗广告活动，起始/结束时间内对商城访客弹窗展示
  - 活动状态枚举（下拉实据）：待开始 / 进行中 / 已结束；创建人审计列
  - 广告素材与跳转（推断，待复核）：新增广告表单维护弹窗图片、跳转链接（商品/活动页/自定义）、弹出频度与人群定向——列表列未覆盖，新增表单字段待复核
- 与其他页面关系：商城营销组引流位（弹窗广告是商城首页的强触达位，跳转目标可关联拼团/秒杀/预售/优惠券等活动，推断待复核）；效果分析（分析域"营销分析 → 营销活动分析"）；本系统落地对应弹窗广告 `/api/erp/mall/admin/popup-ad`（api/marketing.ts 实据）
