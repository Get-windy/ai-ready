# 销售换货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/exchange/form`（表单）+ `sales/exchange/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**：表单页（`sales/exchange/form`）= 销售换货录单（一退一换，同单完成），编辑模式为新增模式加 id；列表页（`sales/exchange/index`）= 按单据 / 按明细两个 tab。
- 表单页结构：复合表单——表头字段区 + 上下两个商品明细表格（换入仓库表 + 换出仓库表）+ 底部收款 Tab + 源单行 + 备注区 + 单据信息行。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：客户\*、换入仓库\*、换出仓库\*、经手人\*、单据日期\*、销售类型\*（默认"正常销售"）
- 收款区：收款账户、收款金额、更多账户、此前预收、使用预收款、可用预收；其他：源单

### 全部表单字段（XSMK《销售换货开发文档》依据，35 个）

- 基本信息：编号、客户、客户编号、开户行、银行账号、税号、换入仓库、换出仓库、经手人、部门、单据日期、销售类型、联系人、联系电话、收货地址
- 收款区：收款账户、收款金额、更多账户、此前预收、使用预收款、可用预收、预收余额、应收款增加、信用额度、可用额度、此前欠款、本次欠款、欠款余额、收款期限、源单
- 单据信息：单据备注、制单人、制单时间、打印次数、本单金额

### 字段分组

顶部基本信息（客户/换入仓库/换出仓库/经手人/日期/销售类型）→ 换入仓库明细表格 → 换出仓库明细表格 → 收款 Tab → 源单 → 备注区 → 单据信息行。

### 录单默认值

经手人默认当前登录人、销售类型默认"正常销售"、单据日期默认当天（截图确认实据；配置弹窗明细待复核）。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账即同时完成换入商品入库（换入仓库）与换出商品出库（换出仓库）。
- 一退一换同单完成：换入表 = 客户退回（入库），换出表 = 新货换出（出库），两张明细表共用一单；差价经收款区结算（应收款增加），多退少补。
- 换入仓库与换出仓库必填且相互独立，退回商品与换出商品可入出不同仓。
- 明细带批次条码/生产日期/保质期/到期日期，换入换出批次双向可溯源。
- 上游：销售出库单（换货针对已售商品，可带源单）；下游：销售单据查询/销售明细查询（XSMK 换货列表列含入库数量、出库数量两个口径）；库存侧一次记账两笔库存变动（换入增加、换出扣减）。
