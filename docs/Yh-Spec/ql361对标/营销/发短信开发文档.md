# 发短信开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`marketing/sms-send`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页**：营销/通知短信的编辑与群发——短信编辑发送表单 + 右侧手机效果预览；3 个子标签（发短信 / 短信历史 / 短信模板管理）。
- 截图：![发短信](../../../../tool-results/ql361/pages/营销__营销活动__发短信.png)

## 2. 表单页配置

### 表单字段清单（截图实据）

| 字段 | 类型 | 说明 |
|------|------|------|
| 选择客户 | 弹选 + 计数 | 已选择 N 人，"选择"按钮弹出客户选择器 |
| 短信内容 | 多行文本 | 67 字/条，超出按新一条计费发送；实时字数计数（当前/67）；占位"请填写短信内容~" |
| 选择短信模板 | 按钮 | 引用"短信模板管理"维护的模板，内容填入编辑区后可二次修改 |
| 公司签名 | 文本 | 当前"皇朝商行"；发送时以【签名】前缀拼入短信 |
| 短信类型 | 单选 | 通知短信 / 营销短信（默认营销短信） |
| 是否同意短信协议 | 勾选 | 必勾，未勾选"确认发送"置灰；含"点击查看《短信协议》"链接 |

- 黄色提示条：目前剩余短信 100 条，如需购买短信，请联系客服！
- 手机预览（右区）：短信气泡实时预览"【皇朝商行】拒收请回复R"——签名以【】包裹自动加前缀，营销短信自动带"拒收请回复R"退订后缀

### 功能按钮

按抓取 JSON buttons 实据：选择短信模板、确认发送；截图补充：选择（选择客户）、子标签切换（发短信/短信历史/短信模板管理）

### 打印配置

无（表单页无打印按钮）。

## 3. 数据表格列配置

无（表单页无数据表格；"短信历史"子标签的列结构待复核）。

## 4. 业务规范

- 发送前置：选择客户（>0 人）→ 填写/模板引用短信内容 → 勾选《短信协议》→ 确认发送由置灰转可用
- 计费规则：67 字/条，超出部分按新一条短信计费（提示条实据）；剩余短信条数为账户配额（当前 100 条），用尽需联系客服购买——SaaS 增值计费项
- 合规约束（国内短信实据归纳）：公司签名以【】包裹强制前置；营销短信强制带"拒收请回复R"退订说明；通知短信与营销短信分通道（营销短信受更严的内容与时段管制）
- 模板复用："选择短信模板"引用"短信模板管理"子标签维护的模板
- 发送结果可在"短信历史"子标签回溯（发送记录/送达状态，列结构待复核）
- 与其他页面关系：客户选择器数据源（ERP 往来单位-客户，带移动电话的客户档案）、模板管理（本页"短信模板管理"子标签自维护）、效果分析（营销短信属营销活动触达手段，归入分析域"营销分析"）、本系统落地对应 `/api/sms` 与平台短信管理（dynamicRoutes.ts：admin/platform/sms、marketing/sms-send）
