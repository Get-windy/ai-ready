## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）：草稿进入"业务草稿"，提交后进入订单处理中心"待审核"阶段
- 提交后单据在订单处理中心按 待审核 → 拣货/发货 → 出库 → 发货完成 → 交易完成 流转（见订单处理中心统计卡片口径）
- 订金账户：订金是带使用条件的预收款或预付款；"使用预订货款"关联预订货单的预订金
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入
- 销售订单发货后生成销售出库单（源单回链），退货时先生成销售退货申请

### 与其他页面关系

- 列表/流程管理在《订单处理中心开发文档》（全部/待审核/拣货发货三阶段）
- 下游单据：销售出库单（发货）、销售退货申请（退货前置）
- 关联定价：销售价格跟踪记录本单产生的客户-商品价格

### 价格等级字段处理

餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点vip01、连锁|vip 这8个字段是用户对价格等级自定义的昵称，需按标准化产品价格等级处理。

### 客户来源

销售订单的客户来源通过 ERP 模块的往来单位下的客户分类处理，而非 CRM 模块的客户信息。CRM客户是公海客户，ERP客户是实体客户。
