# 批次 3：仓储 + 配送闭环任务单

> 依赖：批次 0.1（WMS 列表页）完成后本批次的作业单深化才有承载。
> Odoo 对标：`stock.picking`（作业单状态机 draft→waiting→ready→done）、批次/序列号（`stock.lot`）、`stock.orderpoint`、盘点（`stock.inventory`）。配送域 Odoo 无原生模块，参照 delivery_carrier + fleet 与国内配送 SaaS（美团配送/达达商家端）惯例。
> 预估总量：10 人日。

---

## 3.1 其他出库单/其他入库单（P0，1.5 人日）

- **页面**：`erp/stock-out/form`（双入口）/ `erp/stock-in/index`
- **对标**：管家婆其他出入库 + Odoo stock.picking（无源单的 direct picking）
- **要点**：
  1. 业务类型字典化（出库：领用/赠送/样品/盘亏/其他；入库：盘盈/获赠/退货入库/其他）——类型驱动后续凭证科目
  2. 表单对齐金标准（仓库/经手人/明细网格/金额面板/审核流）
  3. 审核后库存回写 + 成本口径（出库按移动加权成本）
- **验收**：两类单据审核后 erp_stock 增减正确、库存流水可查

## 3.2 调拨/报损/溢余/盘点/成本调整五页（P0，2 人日）

- **页面**：`erp/stock-transfer` / `erp/stock-damage` / `erp/stock-overflow` / `erp/stocktake` / `erp/stock-cost-adjust`
- **要点**：
  1. 调拨：调出仓库→调入仓库，在途状态（调出确认→调入确认两段式，Odoo inter-warehouse transfer）；审核后两仓库存联动
  2. 库存盘点：创建盘点单（按仓库/分类圈定范围）→ 录入实盘数 → 差异表 → 审核后自动生成报损单/溢余单联动（盘点差异不直接改库存，走报损溢余单，留审计痕）
  3. 报损/溢余：审核后库存+成本损失/收益凭证（业财集成）
  4. 成本调整：调整原因+新旧成本，调整后库存成本重算+差异凭证
- **验收**：盘点→差异→报损单自动生成全链 E2E；调拨在途查询可见

## 3.3 生产三页：生产模板/组装/拆分（P1，1.5 人日）

- **页面**：`wh/production-template/form` / `erp/stock-assemble` / `erp/stock-split`
- **对标**：Odoo MRP BoM 简化版（kit/phantom BoM 的组装拆卸）
- **要点**：
  1. 生产模板（BOM）：成品 + 子件清单（用量/损耗率），版本管理
  2. 组装单：选模板+组装数量→子件需求自动计算（校验子件库存充足）→审核后 子件出库+成品入库（同事务）+ 成本结转（成品成本=Σ子件成本+工费）
  3. 拆分单：反向逻辑
- **验收**：组装单审核后子件减/成品增、成本=子件合计；库存不足时禁止提交并提示缺料子件

## 3.4 库存预警三页（P1，1 人日）

- **页面**：预警查询（75 行）/库存预警配置/补货管理
- **要点**：预警规则（商品/仓库维度的安全库存上下限）→ 预警查询（当前预警清单，低于下限红标）→ 生成补货单（与批次 2.4 采购准备联动，入口统一）
- **验收**：预警规则改动后预警清单实时变化；预警行可跳补货

## 3.5 质量管理三页（P1，1 人日）

- **页面**：质检单/质量标准/缺陷记录
- **要点**：
  1. 质量标准：按商品/分类定义检验项目+合格标准
  2. 质检单：与采购入库联动（入库单明细→待质检→质检结论 合格/让步接收/拒收→拒收数量生成采购退货链路入口）
  3. 缺陷记录：质检缺陷归档+供应商质量统计（与供应商绩效联动，后续批次）
- **验收**：入库单质检流程 E2E（C2 链路已有基础，补齐质检单页面操作链）

## 3.6 WMS 作业单六页深化（P1，1.5 人日）

- **页面**：收货/上架/拣货/发货/移库/盘点作业单表单（批次 0.1 已补列表页）
- **要点**：表单页对齐金标准（明细可编辑已实现——C1；补：状态机按钮完整化、源单追溯、与 erp_stock 镜像一致性核对——C3 双轨镜像已验证，复核边界场景：取消作业单时镜像回滚）
- **验收**：作业单全状态流转+取消回滚 E2E；wms_inventory 与 erp_stock 双轨一致

## 3.7 配送域 11 页（P1，1.5 人日）

- **页面**：配送单/配送查询/物流发货/发货查询/物流退货收货/采购订货收货/线路列表/调度任务/实时跟踪/配送参数/API监控
- **后端**：dms 模块 25+ 实体已接线（A 阶段），前端页多为薄实现（均 170 行）
- **要点**：
  1. **调度任务**（核心）：订单池（待调度销售出库单）→ 手动/自动派单（按线路+骑手/车辆负载）→ 生成配送任务 → 司机端接单（driver-delivery 联动）
  2. 配送单：状态机（待调度→已派单→配送中→已签收→已收款），签收/收款回写销售单
  3. 实时跟踪：骑手轨迹地图（高德 API，读取轨迹表，轨迹点播放）
  4. 物流发货/发货查询：第三方物流单号登记+物流状态跟踪
  5. 收货业务两页：退货收货→生成销售退货入库；采购订货收货→跳采购入库联动
  6. 配送参数：计费规则/区域配置
- **验收**：销售出库单→调度派单→司机签收→销售单状态回写 全链 E2E
