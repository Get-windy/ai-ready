## 1. 页面概述

客户活跃分析页是**客户运营的流失预警台账**：以「客户分类」为分层结果列，以「未交易天数」为分层依据，配合「最近交易日期 / 最近拜访日期」两个时序锚点与「近 90 天下单金额 / 次数」两个活跃度指标，形成「谁在活跃、谁在流失、流失到哪一步」的一页视图。页面顶部另有**分层公式卡片**（红/青/紫三色，算式形态）直观展示有效客户构成。**单入口、单视图**（本页**无**页内视图 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 客户活跃分析 | `analytics/customer-active` | 单入口单视图台账（查询区 + 分层公式卡 + 8 列表格 + 合计行 + 分页） |

单入口：分析 → 采销分析 → 销售分析 → 客户活跃分析。

- **对标子分组归属**：ql361「采销分析」组下有 **3 个 `.popupmenu__list-title` 子分组**——`销售业绩`、`销售分析`、`采购分析`，**均为分组标题、非页面**（`.png` 实测右键菜单展开可见）。本页归在子分组 **`销售分析`** 下（与销售分析/销售履约分析/销售欠款分析/销售费用分析/推广分析/预订货查询同组）。本系统 `sys_menu` **无该层级**，仅保留菜单 80417 直挂 61002（文档层面记录此对应关系）。

## 4. 业务规范

### 统计口径（客户分层）

- **有效客户 = 活跃客户 + 即将流失客户**：实测 **893 = 706 + 187 ✅**（分层公式卡实据）。口径上**不含**已流失/无效客户（与基准文档一致）。
- **客户分类（分层结果列）**：按「未交易天数」分层。实测取值 `活跃客户` / `即将流失客户` 两类；**实测可见边界**：未交易天数 `0 / 1 / 5 / 6 / 7 / 9 / 13` 归「活跃客户」，`37 / 44` 归「即将流失客户」。
  > 具体阈值（如「≥30 天即即将流失」）由工具栏 `客户分类设置` 维护，实测**未打开该弹窗**，阈值与是否含「流失客户」第三档 **待复核**。
- **未交易天数 = 当前日期 − 最近交易日期**（实测三点验证，✅）：
  - 敦煌市阿堡仔店：`2026-08-02` → `44` 天 ✅（8/2→9/2=31，9/2→9/15=13）
  - 嘉峪关市祁丰乡享运源餐厅：`2026-09-10` → `5` 天 ✅
  - 肃州区瑞瑞翔餐饮店(明洞炸鸡)：`2026-09-14` → `1` 天 ✅
  - 敦煌市派大星家沙拉煎饼：`2026-08-09` → `37` 天 ✅（8/9→9/9=31，+6）
- **近 90 天下单金额 / 次数**（表头口径，即列配置弹窗「近半年下单金额 / 次数」）：滚动窗口内的销售订单口径。实测样本：`13,615 / 38`、`7,771.67 / 46`、`2,086 / 7`、`804 / 9` —— 次数与金额**并非线性对应**，说明为**去重单数 + 金额求和**两个独立指标（非客单价派生）。
- **最近拜访日期**：外勤拜访记录联动。实测**前 20 行为空**（该批次客户近期无拜访记录写入），列本身可空 → 属**流失预警动作项**（拜访为空即需触达）。
- **合计行**：`近90天下单金额` 合计 `3,108,744.15`、`近90天下单次数` 合计 `10,398`（合计行**逐列求和**，含未来默认隐藏列亦应计入——本页无隐藏列，无此歧义）。

### 取数来源与上下游关系

- **取数**：销售订单（最近交易日期、近窗口下单金额/次数、历史口径）＋ 外勤拜访记录（最近拜访日期）＋ 客户主数据（客户名称/编号/分类）＋ 分层阈值配置（客户分类设置）。
- **同源页**：《销售业绩》（其「拓客数」为新增客户入口，本页为存量客户的活跃/流失侧）、《销售欠款分析》（同一批客户的欠款侧指标）。
- **下游**：客户运营动作（拜访计划 / 促销活动触达）；本页**只读**，不产生业务单据。
- **与《交易分析》《商城客户列表》的分工**：本页口径为**ERP 往来单位（客户档案）侧**，非 CRM 公海客户、非商城注册用户。

6. **无钻取 / 无客户分类设置**：对标有「分层公式卡、客户分类设置」等特有件，本页无（后端亦无对应端点）。
