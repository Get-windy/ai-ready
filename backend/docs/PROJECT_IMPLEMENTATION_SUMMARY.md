## 技术实现亮点

### 1. 分布式数据存储策略
- **快照存储**：订单创建时确定且不可变的数据
- **关联JOIN**：可实时从主数据获取的信息
- **实时计算**：可通过其他字段推导或API获取的数据

### 2. CRM-ERP客户转换机制
- 清晰区分了CRM公海客户（潜在客户）与ERP实体客户（业务往来单位）
- 实现了从CRM线索到ERP实体客户的标准化转换流程
- 多维度匹配算法确保客户信息的准确对应

### 3. 价格与客户等级集成
- 使用customerGradeCode/cusomerGradeName替代了冗余的boolean字段
- 与现有biz_customer_grade体系集成
- 支持基于客户等级的动态价格计算

## 概念澄清
- **CRM模块**：处理公海客户（包括潜在客户和实体客户），主要负责线索管理和客户开发
- **ERP模块**：处理实际业务客户（往来单位/实体客户），主要负责与租户实际业务往来和交易
- **转化机制**：实现从CRM线索到ERP实体客户的标准化转化流程
