### 10.1 接口验收（26 项）

**A. 结构基线（①–⑥）**

1. **断言建页前基线**：`sys_menu` 中 `component LIKE '%print%'` = **0 行**（基线；建页后断言 ≥1）。
2. **断言 `61205` 建页前子菜单数 = 0**（基线；建页后断言 ≥1）。
3. **断言 `61201 系统配置` 无 `sort=3`**（基线；若选择挂在 61201 则建页后断言补上 3）。
4. **断言 `sys_permission` 中 `set:*` = 0 行**（基线；建页后断言 ≥2）。
5. **断言库中不存在打印设置配置表**（若走路线 B）或 **`sys_config` 中无 `print.*` 键**（若走路线 A）。
6. **断言打印域 9 张表建页前均为 0 行**（基线）：`erp_print_template` / `sys_print_template` / `sys_print_chain` / `sys_print_chain_item` / `sys_print_client` / `sys_print_task` / `erp_print_task` / `erp_printer` / `erp_printer_group`。

**B. 读写（⑦–⑯）**

7. `GET /api/set/print-config` → 200；**断言返回含全部 7 个配置项字段**（逐字段断言键名存在）。
8. **断言首次访问时返回默认值**（若实现为「无行则返回默认」）；**或断言自动建行**（两种设计择一，需明确）。
9. `GET` 未登录 → **401**；无 `set:print-config:view` 权限 → **403**。
10. `PUT /api/set/print-config` 单项更新（改 `batch_summary_print=true`）→ 200；**回读 DB** 断言该列 = true，**其余列不变**（**记录原值以便复原**）。
11. 全量更新 7 项 → 200；**回读**逐项断言。
12. **`tenant_id` 断言**：调用时**不传** `tenantId` → 断言写到**当前登录租户**；**伪造其它 `tenantId`** → **断言被忽略/拒绝**（防跨租户覆盖）。
13. **唯一性/幂等**：连续两次 `PUT` → 断言**只有一行配置**（不产生第二行）。
14. **非法值**：`qty_decimal=99` → 断言被拒（400）；`print_content='<不存在的选项>'` → 断言被拒或回退（**行为须先裁定并断言**）。
15. **断言写入产生操作日志**：`SELECT count(*) FROM sys_oper_log WHERE module LIKE '%打印%' AND action='UPDATE'` **+1**（若已加 `@OperationLog`）。
16. **断言配置读取无缓存不一致**：`PUT` 后立即 `GET` → 断言返回新值（**热生效**，见 §11）。

**C. 与打印链路的联动（⑰–㉒）** —— **本页验收的核心，防「假配置」**

17. **「跳过预览直接打印」联动**：置 `assistant_enabled=true` → 调用 `PrintDialog` 的打印动作（Playwright）→ **断言不再强制要求先点「预览」**（当前 `index.vue:276-279` 强校验）；置 `false` → 断言**恢复**强校验。

19. **「允许打印草稿」联动**：造一条 `status=草稿` 的单据 → `allow_draft_print=false` 时断言**打印按钮禁用或报错**；`true` 时断言**可打印**。

22. **断言前端无硬编码下载地址**：grep 前端源码中「打印助手」相关 URL → 断言**由接口下发**。

**D. 复用与不重复建设（㉓–㉖）**

## 二轮收口（2026-09-19）

> 本节记录**二轮收口的实际实现**，取代 §12 / §④ 中已被处置的结论（7 项消费、打印内容选项）。
> **验收证据**：模块级 E2E `tools/e2e-settings.cjs` → **201 项全过**，其中「5b 未闭环项收口验证」含本页专项断言（behavior 端点、3 个打印内容选项、远程打印拒绝路径）。

### ① 新增读路径：`GET /api/set/print-config/behavior`

| 项 | 实现 |
|---|---|
| 端点 | `PrintConfigController#getBehaviorConfig` → `GET /api/set/print-config/behavior`，**无权限注解**（打印组件要能读；配置要作用于**所有人**的打印，不能只对有管理权限的人生效） |
| 返回 | 仅**行为字段**（草稿/小数位/打印内容/助手/远程），不含管理页所需的 `options`/审计字段 |
| 无行时 | 与 `GET /set/print-config` 同口径：按默认值**自动建行**（一行一租户，唯一索引兜底） |
| 租户 | 由服务端会话解析，**请求不带 `tenantId`** |

### ② 前端适配层：`components/PrintDialog/printBehavior.ts`

- **带缓存**（5 分钟；含「读失败」结果，避免每个弹窗都打一次失败请求）。
- **读失败一律降级为改造前行为**（无权限/异常/超时 → `null`）→ 绝不允许「配置读不到把打印弄挂」。
- 只做**格式化与派生字段注入**，不碰打印执行链路（模板渲染 / 本地打印 / 远程打印链路提交一律复用既有能力，不重复实现）。
- 组件调用点：`PrintDialog.open()` 草稿门控、`applyPrintBehavior(props.printData, printBehavior)`（数量/单价定长格式化 + `batchEffectiveText` 派生）、`handlePrint`（助手打印跳过预览）、远程分支（`POST /v2/print/tasks/by-chain`）。

### ③ 7 个配置项逐项接线状态

| 配置项 | 状态 | 落点 |

| 允许打印草稿 | ✅ | `isDraftDocument` + `open()` 拦草稿态并提示 |

| 打印内容 | ✅ | `applyPrintBehavior` → 明细行派生 `batchEffectiveText` |
| 助手打印 | ✅ | 开启后点「打印」**直接渲染打印**，不再要求先预览 |
