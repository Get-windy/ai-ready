# 商品条码开发文档

## 页面概述

| 页面 | 地址 | 说明 |
|------|------|------|
| 商品条码 | 对标系统：https://22stable.ql361.com/desktop.html#/（桌面式多标签架构，页面以桌面标签打开，无独立路由）；本系统无独立条码页（条码在商品档案内维护），对应关系待复核 | 商品×单位维度的条码档案维护与条码打印 |

**对标系统页面性质**：主数据维护页（左侧商品分类树 + 查询区 + 数据表格；一行 = 一个商品的一个单位，条码按单位分别维护）。

## 业务规范说明

### 状态流转与特殊交互

- 数据粒度：一行 = 商品 × 单位；商品多单位（瓶/箱/袋）各自持有独立条码与换算关系（截图实据：同一商品多行，换算关系"1箱=12瓶""1箱=4袋"等）
- 上架状态：已上架/未上架，指商品在商城的上架状态，与商品页"商品上架"子标签联动
- 条码打印：选中行批量打印条码标签（扫码枪/标签机场景）
- 无"新增"按钮：条码随商品档案及单位维护产生，本页仅维护与打印（行级"修改"）

### 与其他页面关系

- 商品（档案）：条码的源数据在商品档案按单位维护，本页为条码维度视图
- 商品货位设置：同样有"条码（全部）"查询条件与"条码打印"按钮，条码打印能力两处复用
- 商城/销售录单：扫描枪录入按条码匹配商品+单位

### 架构师红线（Ponytail六步过滤网）

动手前必过六关：①此功能业务真需要？②标准库/原生API能搞定？③现有依赖能否复用？④能否一行代码干净解决？⑤能否复用已有组件？⑥通通走不通才写最小可用闭环。**Lazy, not negligent**——跨边界防注入、容灾、安全防御代码不准省。
