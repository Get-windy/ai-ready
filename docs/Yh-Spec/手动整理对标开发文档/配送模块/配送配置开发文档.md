## 1. 页面概述

- **配送配置维护页**：以键值（KV）形式维护 DMS 的运行配置（`dms_config`），供调度、时效、费用、地图、推送等策略读取。
- 与《配送参数》的关系：**同一数据源、近似功能**，是历史演进留下的两个入口。

## 2. 本系统现状（实测）

### 2.1 页面结构

`PageContainer` + `SearchBar` + `a-table` + `a-modal`（`useWmsTable` 组合）：筛选区 → 表格 → 编辑弹窗。

### 2.2 查询条件与列

- **查询条件**：配置键（input）。
- **表格列**：配置键 `configKey`、配置值 `configValue`、描述 `configDesc`、作用域 `scope`、操作（编辑）。

### 2.3 按钮与弹窗

- 工具栏：刷新；行级：编辑（`dms:config:edit`）。
- **编辑弹窗**：配置键（禁用）、配置值（textarea，必填）、描述（禁用）、作用域（禁用）。

### 2.4 接口调用

`configApi.list → GET /dms/config/list`（**不分页，返回全量**）；`configApi.update → PUT /dms/config/{key}`。

## 3. 金标准目标设计

> 配送配置应与《配送参数》**合并为唯一的参数中心**（推荐），或在保留双入口时明确分工：本页管**租户级运行配置**，参数页管**业务策略参数**。以下为参数中心的金标准设计。

### 3.1 参数元数据（类型化渲染）

| 元数据 | 说明 |
|--------|------|
| `group` | 分组：派单策略 / 时效 / 费用 / 地图 / 推送 / 签收 / 风控 / 展示 |
| `valueType` | `NUMBER` / `TEXT` / `BOOLEAN` / `ENUM` / `JSON` / `TIME_RANGE` |
| `configValue` / `defaultValue` | 当前值 / 默认值 |
| `min` / `max` / `unit` | 取值范围与单位 |
| `editable` / `effect` | 是否可改 / 生效方式（热生效 / 需重启） |
| `scope` | 作用域（租户 / 全局 / 区域） |

前端按 `valueType` 渲染控件（数字 → `a-input-number`；布尔 → `a-switch`；枚举 → `a-select`；JSON → 带校验编辑器），**不再用纯文本域**。

### 3.2 页面结构（金标准）

`CategoryListLayout`（左侧分组成员树）+ `BillTableList`（序号齿轮列配置，`storage-key` = `dms-config-columns`）+ `PageConfigPanel`。

- 列：参数名、参数键、当前值（类型控件）、默认值、取值/单位、生效方式、作用域、更新时间、操作（保存 / 恢复默认）。
- 支持行内编辑或批量编辑后统一保存；`diff` 预览后再提交。

### 3.3 后端接口（金标准）

| 接口 | 说明 |
|------|------|
| `GET /api/dms/config/page` | 分页 + 多条件（替代 `list` 全量） |
| `GET /api/dms/config/meta` | 参数元数据（驱动前端渲染） |
| `PUT /api/dms/config/{key}` | 单参数更新（**类型校验**） |
| `PUT /api/dms/config/batch` | 批量保存（事务） |
| `POST /api/dms/config/{key}/reset` | 恢复默认 |
| `GET /api/dms/config/{key}/history` | 变更历史（审计） |
| `POST /api/dms/config/export` / `import` | 参数集导出/导入 |

### 3.4 业界生产级实践要点

1. **元数据与代码同源**：参数元数据由后端注册表定义，前端只渲染，避免页面与消费方脱钩。
2. **类型校验前置**：后端按 `valueType` 校验（范围/枚举/JSON Schema），杜绝"字符串万能值"。
3. **变更审计与回滚**：`dms_config_history` 记录 key/旧值/新值/操作人/时间/IP。
4. **热生效**：变更发事件（复用 `dms_event_outbox`），消费方刷新缓存；`effect=需重启` 的项明确标注。
5. **灰度**：按租户/区域配置，先试点再全量。
6. **危险操作二次确认**：恢复默认、批量保存需 diff 预览与确认。

| 项 | 现状 | 金标准目标 | 差距 |
