> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：对应 WMS 仓库/库位维护，路由待复核
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：仓库与货位两级仓储主数据维护页，2 个子标签（1.仓库 / 2.货位），左侧仓库分类树 + 查询区 + 数据表格；当前抓取为 1.仓库 子标签。
- 截图：![仓库规划](../../../../tool-results/ql361/pages/资料__仓库管理__仓库规划.png)

## 2. 页面配置

### 查询条件

- 筛选条件（单文本框）
- 勾选项：显示停用、显示层次结构（默认勾选）
- 左侧仓库分类树（全部、酒泉、中转仓、敦煌）与列表联动过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、停用

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（6 列，抓取 JSON columns 实据，1.仓库子标签）

操作、仓库编号、仓库名称、联系人、联系电话、地址

> JSON columns 首项"操作 仓库编号 仓库名称"与第 5 项"联系人 联系电话 地址"均为抓取拼接串（表头快照），非真实单列，列数统计已剔除。2.货位子标签列结构未抓取，待复核。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 两级仓储模型（子标签实据）：1.仓库 → 2.货位；仓库下维护货位
- 仓库层级：仓库本身支持父子层级（截图实据：中转仓编号 ml00100001 挂在酒泉 ml001 下，编号含父级码段；"显示层次结构"默认勾选）
- 停用优先：行级提供"停用"而非仅删除——被业务引用的仓库走停用，与"显示停用"勾选项配套
- 与其他页面关系：商品货位设置（按"商品×仓库"维护推荐货位）、库存/出入库单据（发货仓库/拣货仓库引用；订单处理中心"集货位"引用货位）、客户（"所属仓库"列引用）、职员权限（操作员"仓库权限"按仓库授权）

## 5. 抓取补证（2026-09-11 实时实抓）

对标系统 22stable.ql361.com「资料 → 仓库管理 → 仓库规划」实测（脚本 `frontend/_probe_warehouse.js` + `frontend/_probe_wh_form.js`，产物 `tool-results/ql361/pages/资料__仓库管理__仓库规划__capture.json` / `__forms.json` / `warehouse-shots/*.png`）：

- **页内 Tab**：`1.仓库` / `2.货位`（默认进入 `2.货位`）。
- **Tab1 工具栏**：新增、刷新、打印(F8)、导出、查询、跳转；**行内**：修改 / 删除 / 停用（`a.grid-cell-link`）。
- **Tab1 列配置弹窗**（`lkgrid-setting-dialog`）：个人配置 / 全局配置；列 = 仓库编号、仓库名称、联系人、联系电话、地址（5 列，全部默认显示）；操作列与序号列**不在**列配置内；底部 上移/下移/恢复默认/保存。
- **Tab1 无页面配置齿轮**（`pageConfigTrigger=null`），与本文档第 2 章口径一致。
- **Tab2 工具栏**：新增货位、刷新、打印(F8)、批量删除、更多、查询、跳转；表格含勾选列 + 操作（修改/删除/停用）+ 所属仓库/货位编号/备注。
- **新增仓库弹窗「仓库信息」**（`dojoxDialog`，z=950）：仓库名称\*、仓库编号\*（默认带出 `ck005`，系统按编号规则生成）、所属分类（带放大镜选择）、助记码、联系人、电话(`type=tel`)、地址、邮编、备注；按钮 **保存(Enter) / 取消(Esc)**。
- **分类信息弹窗**（树节点「修改」）：分类名称\*、所属分类、层级编号\*；按钮 保存(Enter) / 关闭(Esc)。
- **新增货位弹窗「货位」**：仓库\*（放大镜搜索）、通道号\*(A)+生成数\*(1)、货架号\*(01)+生成数\*(1)、货架层数\*(一位数字，如：1)、货位列号\*(01)+生成数\*(1)、备注 + 编号规则说明（`A1 - 101`，生成数量=通道生成数×货架生成数×货架层数×货位列号生成数）；按钮 保存(Enter) / 取消(Esc)。
- 注：Tab2 的「更多」下拉为 dojo 弹出层，抓取脚本未取到菜单项；本系统按合理口径实现为「导出」。
