# 预订货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/pre-order/form`（表单）+ `sales/pre-order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**：表单页（`sales/pre-order/form`）= 客户预订货（先款后货/订金订货）录单，编辑模式为新增模式加 id；列表页（`sales/pre-order/index`）= 按单据 / 按明细两个 tab。
- 表单页结构：表头字段区 + 商品明细表格 + 底部收款 Tab（预订金）+ 备注区 + 单据信息行 + 右侧摘要面板。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：客户\*、经手人\*、单据日期\*、销售类型\*（默认"正常销售"）
- 选填：发货仓库（截图确认无必填星标）
- 收款区：预订金账户、预订金金额、更多账户

### 全部表单字段（XSMK《预订货单开发文档》依据，35 个）

- 基本信息：编号、客户、客户编号、开户行、银行账号、税号、发货仓库、经手人、部门、单据日期、销售类型、收货人、联系电话、收货地址、客户级别、自定义字段1~5、审核人、摘要
- 收款区：预订金账户、预订金金额、更多账户、信用额度、收款期限
- 备注/信息：单据备注、表尾自定义字段1~2、制单人、制单时间、打印次数
- 摘要面板：商品金额、本单金额

### 字段分组

顶部基本信息（客户/发货仓库/经手人/日期/销售类型）→ 商品明细表格 → 收款 Tab（预订金）→ 备注区 → 单据信息行 → 摘要面板。

### 录单默认值

经手人默认当前登录人、销售类型默认"正常销售"、单据日期默认当天（截图确认实据；配置弹窗明细待复核）。

### 打印设置

XSMK 已有配置弹窗（截图存档），配置项明细待复核。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）。
- 预订金：客户预订货时收取的订金，计入"预订金账户"；销售订单/销售出库单的"使用预订货款"字段即消费本单预订金余额（订金 = 带使用条件的预收款）。
- 发货仓库非必填：预订货阶段可不确定发货仓，转正式订单时再指定（推断，待复核）。
- XSMK 列表列含"已收预订金、未收预订金、本单预订金余额、预订数量、已订数量、未订数量、已发数量、未发数量"，表明预订货单有独立的订金收取与发货履约跟踪。
- 下游：销售订单（预订货转正式订货时消费预订金）、销售出库单；分析域有"预订货查询"页面（ql361 分析__采销分析__预订货查询 抓取结果）做预订货履约分析；销售订单明细全量列含"预订货单编号"，明细行可关联预订货单。
