## 1. 页面概述

- **列表查询页**（批次台账）：商品批次库存台账（批次查询/批次跟踪/近效期预警三视图，生产/到期日期 + 可用/账面双数量 + 批次成本）；食品效期管理与批次追溯核心页。菜单路径：分析 → 仓配分析 → 查批次。
- 页面结构：视图 Tab（商品批次查询/商品批次跟踪/近效期预警查询）+ 查询区（两行）+ 左侧商品分类树 + 批次表格（首列勾选框，操作列"批次跟踪"链接）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__仓配分析__查批次.png`

## 4. 业务规范

### 统计口径（批次粒度）

- **批次粒度**：商品×仓库×批次（生产日期/到期日期/批次条码）一行；批次条码为批次唯一标识（可打印标签）
- **可用数量 vs 账面数量**：可用=账面−占用（待发货锁定/拣货中）；合计行 199,178.702 vs 199,182.702 差额 4 为占用量
- **成本口径**：成本单价/成本金额按批次成本（批次进货价），与移动加权成本并存（成本核算口径与《进销存分析》联动）
- **效期色标**：过期商品橙色显示，停用商品红色显示（勾选"显示停用商品"后入列）；近效期预警查询视图按过期天数筛选
- **批次跟踪**：批次的全链路流水（入库→调拨→出库）追溯视图

### 与其他页面关系

- 取数：批次库存 + 批次流水（《库存明细》批次条码列同源）
- 同组页面：《查库存》（商品粒度汇总）、《进销存分析》（期间变动）、《库存明细》（流水粒度）
- 下游：近效期预警→促销/报损动作；批次调整→库存调整单
