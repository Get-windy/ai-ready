## 1. 页面概述

- **列表查询页**（统计分析页）：商城交易转化日/周/月报（登录→下单转化漏斗 + 客单价）；B2B 商城运营核心日报。菜单路径：分析 → 营销分析 → 交易分析。
- 页面结构：查询区（两行）+ 粒度切换（按天/按周/按月）+ 转化漏斗表格 + 合计行（比率列不合计）。
- 页面截图：`tool-results/ql361/pages/分析__营销分析__交易分析.png`

## 4. 业务规范

### 统计口径（商城转化漏斗）

- **漏斗链路**：登录客户数（当日登录商城的去重客户）→ 下单客户数（当日有下单的去重客户）→ 下单笔数/下单金额
- **客单价**=下单金额/下单客户数（1,773/9=197 ✅；注意分母为客户数非笔数）
- **下单转化率(%)**=下单客户数/登录客户数×100（9/25=36 ✅）
- **合计行**：量额列求和（87/35/38/8,328），比率列不合计（空）
- **下单金额 8,328 与《销售业绩》"实订金额"同口径**（商城下单即销售订单，跨页验证一致 ✅）

### 与其他页面关系

- 取数：商城登录日志 + 商城订单（销售订单 XSDD- 商城来源）
- 同源页：《销售业绩》（实订金额）、《商城客户列表》（客户级访问/成交）
