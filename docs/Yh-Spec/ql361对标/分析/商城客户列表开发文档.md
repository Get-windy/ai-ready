# 商城客户列表开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/mall-customer-list`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：商城注册客户名册与访问/成交行为（买家归属分类树 + 批量发短信/发优惠券触达动作）；商城私域客户运营页。菜单路径：分析 → 营销分析 → 商城客户列表。
- 页面结构：查询区（三行）+ 左侧买家归属分类树 + 客户表格（首列勾选框，客户名称为链接）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__营销分析__商城客户列表.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图/bodyPreview 实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 访问日期\*（必填，起 至 止）、注册日期（起 至 止）、客户、客户级别
- 成交数量\*（下拉区间，默认"全部"）、访问次数\*（下拉区间，默认"全部"）
- 勾选项：显示停用
- 左侧买家归属分类树（9 个分类：全部客户 / 系统用户 / 餐饮客户 / 合作商 / 个人会员 / 其他渠道 / 单位客户 / 餐饮连锁 / 在线注册客户 / 观望筹备客户）

### 功能按钮（抓取 JSON buttons 实据）

- 发短信、发优惠券（勾选客户后的批量营销触达动作）、刷新、打印(F8)、导出、查询、跳转（分页跳转）

### 打印配置

- 有打印(F8)按钮（客户名册打印）；打印配置弹窗字段级明细未抓取，待复核

## 4. 业务规范

### 统计口径（客户行为）

- **成交率(%)**=成交数量/访问次数×100（4/10=40 ✅；8/27≈29.63 ✅）
- **访问次数/成交数量**：查询期（访问日期区间）内该客户的商城访问与下单次数
- **买家账号**：商城登录账号（手机号实据）；**客户级别**：ERP 客户级别同步（连锁客户/A餐饮客户等，级别名含渠道属性）
- **所属仓库/默认经手人**：该客户默认履约仓库与归属业务员（商城下单路由依据）
- **买家归属分类**：客户渠道分类（餐饮客户/餐饮连锁/在线注册客户等 9 类），与 ERP 客户分类联动

### 与其他页面关系

- 取数：商城客户（买家账号）+ ERP 客户主数据（级别/联系人/仓库/经手人）+ 商城访问/订单行为
- 下游：发短信/发优惠券触达（营销动作回流商城）；《交易分析》（整体转化口径）、《客户活跃分析》（ERP 侧活跃口径）
