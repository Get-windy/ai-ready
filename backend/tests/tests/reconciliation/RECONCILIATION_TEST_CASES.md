# 企智连对账模块测试用例

### 1.1 测试目标
确保企智连对账模块的准确性和可靠性，覆盖所有核心场景和异常情况。

### 1.2 测试范围
- 自动对账功能测试
- 手动对账功能测试
- 对账结果确认测试
- 异常场景处理测试
- 边界条件测试

### 1.3 测试环境
- **测试环境**: http://test.qizhilian.com:8080
- **数据库**: PostgreSQL 16

```

```

```
- 交易时间: 2026-04-14 10:00
- 银行流水时间: 2026-04-15 09:00

操作步骤:
1. 进行自动对账
2. 系统检测到时间差异

预期结果:
- 系统考虑时间差在 reasonable range 内
- 仍标记为匹配（如果时间差在容忍范围内）
- 或标记为差异待处理
```
