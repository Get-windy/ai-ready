## 2. 页面配置

### 查询条件

- 筛选条件（线路编号/线路名称/配送区域）
- 显示状态（已启用）
- 线路类型（全部）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、导入、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作：待复核（抓取时表格无数据，操作列内容未呈现；JSON columns 含"操作"列）

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（7 列，抓取 JSON columns 实据）

操作、线路编号、线路名称、线路类型、物流公司、配送区域、备注

> 本页 JSON columns 无抓取拼接串（首项"操作"为真实单列）。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 线路类型：区分自配送/第三方物流等类型（"线路类型（全部）"下拉实据，枚举值待复核）
- 物流公司：线路类型为第三方物流时关联物流公司档案
- 配送区域：线路覆盖的区域范围，与客户"所属区域"联动
- 抓取时 0 条记录：该演示账套尚未维护线路（订单处理中心"按线路"视图与"配送线路"查询条件仍引用本档案）
- 与其他页面关系：客户（"所属区域"与线路"配送区域"匹配，决定落入哪条配送线路）、销售订单/出库单（表头"配送线路"引用）、订单处理中心（查询条件"配送线路"、"按线路"维度子标签引用）、物流公司（"物流公司"列引用）、司机/配送（DMS 配送任务按线路调度）
