# 线索开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`crm/lead/index`（列表）+ `crm/lead/form`（表单）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=添加）：主按钮 → 列表页 `crm/lead/index`；标签"添加"→ 新增/编辑表单页 `crm/lead/form`。
- **列表页**：线索台账（我方实现，views/crm/lead/index.vue）。
- **表单页**：CRM 线索——销售线索登记与跟进（我方实现，views/crm/lead/form.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `crm/lead/index.vue`（3 项）

- `name` 线索名称（输入）
- `source` 来源渠道（下拉：官网咨询/微信公众号/邮件咨询/电话咨询/社交媒体/其他）
- `status` 线索状态（下拉：新线索/跟进中/已转化/已关闭）

### 功能按钮

来源：我方源码 `crm/lead/index.vue`

- 工具栏：新增（Ctrl+N）、刷新（F5）、批量分配（选中行）、批量转化（选中行）、导入线索
- 行操作：查看、编辑、分配、转化为客户、添加跟进、跟进记录、删除

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段（17 个）

来源：我方源码 `crm/lead/form.vue`

- 必填：线索名称\*（leadName）、公司名称\*（companyName）
- 选填：线索编号（自动生成，disabled）、联系人、联系电话、联系邮箱、所属行业、线索来源、线索等级、预计金额、省份、城市、详细地址、需求描述、负责销售、状态、备注

### 字段分组／录单默认值／打印设置

- 字段分组：单块基本信息（BillFormPage basic-info，无底部 Tab；底部按钮：保存 Ctrl+S / 提交 Ctrl+Enter）
- 录单默认值：线索编号自动生成、状态默认"新建"(0)
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（8 列，来源：我方源码 `crm/lead/index.vue`）

线索名称、公司/联系人、联系方式、来源渠道、评分、状态、添加时间、操作

### 全部可配置列（8 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `vxeColumns` 数组（8 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`crm/lead/index`，标签按钮 list_path=`crm/lead/form`，tag_label=添加（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- CRM 线索：销售线索登记与跟进，可转化为商机（见《商机开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
