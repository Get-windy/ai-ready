## 页面概述

其他收入单用于**非主营收入登记**（往来单位收入/内部收入两类）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 其他收入表单页 | `finance/other-income/form`（主菜单入口） | 新增收入 + 收入项明细 |
| 其他收入列表页（历史） | `finance/other-income/index` | 双入口「历史」标签 |

> 注：`other-income-doc` 目录亦有页面（`/erp/finance/other-income-doc/page`），与 `other-income` 对应关系待复核，本表以菜单 `finance:other-income-doc`（80116）为准。

单号实据：`QTSRD-20260723-001`（`QTSRD-` 前缀 + `YYYYMMDD-序号`）。

- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 新增编辑其他收入表单页配置

### 页面结构（自定义 `a-form`）
收入类型单选 → 表头字段区 → 收入项明细表格 → 备注区 → 底部本单金额与操作。

### 表头字段
| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 收入类型 | 单选 | 是 | 往来单位收入 / 内部收入 |
| 往来单位 | a-select | 是 | 带新增+搜索，带出往来编号 |
| 往来编号 | a-input 只读 | 否 | 随往来单位带出 |
| 经手人 | a-select | 是 | 默认当前登录人 |
| 单据日期 | a-date-picker | 是 | 默认当天 |
| 收款账户 | a-select | 否 | |
| 收款金额 | a-input-number | 否 | 带「全/清」 |
| 更多账户 | a-input | 否 | 带「…」弹窗 |

### 收入项明细表格
操作、科目编号、科目名称、金额、备注。

### 工作流按钮
| 状态 | 按钮 | 动作 |
|------|------|------|
| 任意 | 保存草稿 Ctrl+S | `save` |
| 任意 | 记账 Ctrl+Enter | `confirm` |
