## 1. 页面概述

经营历程是**跨业务域「已过账」单据的全量流水台账**：把销售 / 采购 / 收付款 / 库存 / 费用等各域已记账的正式单据按业务日期倒序汇总，提供红冲（作废）、复制、备注等行级操作，是全系统单据级「经营档案」。**单入口、单视图**（无页内 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 经营历程 | `analytics/business-history` | 单视图列表页（跨 13 类单据全量流水 + 行级红冲/复制/备注） |

单入口：分析 → 综合单据 → 经营历程。

- 页面结构：查询方案 + 时间快捷段 + **两行查询区** + 流水台账表格（首列红色齿轮列配置入口 + 序号线 + 固定「操作」列，**无行勾选框**）+ 底部合计行 + 分页条。
- 实测实据（2026-09-15）：共 **2,934** 条记录、第 **1/147** 页、每页显示 **20** 行、底部合计 **2,087,351.86**。当前页可见行均为「收款单」（`SKD-20260915-0xx`）。
- 多 Tab 判定：实测 JSON `tabs` 为 `{}`（空对象），`.png` 顶部仅一个「经营历程」页签 → **单视图，无子 Tab**。

### 配置功能说明

- 实测工具栏（右上）：`刷新`、`打印(F8)`、`导出`（另有 `更多` 折叠项）；**本组三页中唯本页有打印**。
- 实测行级动作：每行「操作」列 = `红冲(作废)`、`复制`、`备注`（三个动作）。

## 4. 业务规范

### 统计口径与数据关系

- **数据范围**：全部业务域已过账（已记账）单据的全量流水，一行一单，默认按时间快捷段过滤（实测 2026-09 月内共 **2,934** 条）。
  - 后端实现为 13 个单据分支的 UNION 聚合（`DocQueryService.java` 的 `BRANCHES`，`DocQueryService.java:50-127`），`StatusMode.ALL` 时**不过滤状态**，按业务日期倒序分页。
- **金额口径**：单据金额原值列示，底部合计对当前过滤范围求和（实测 `2,087,351.86`）。红冲单以负数 / 红字参与合计。
- **来源订单列**：由订单下推生成的单据（如销售订单 → 销售出库单）记录来源订单号，实现单据链追溯。
- **红冲(作废)**：冲销后原单不删除而成对保留（原单 + 红冲单），保证流水可审计；勾选 `显示红冲` 可见红冲记录。红冲单同步回写库存 / 往来 / 资金。
- **复制**：以当前单据为模板快速开新单。
- **备注**：维护单据备注信息（对应列配置中的 `单据备注`）。
- **组内分工**（综合单据组三页 = 单据生命周期的三个横切状态）：
  《业务草稿》提交记账后进入本页；本页是全系统单据级「经营档案」，各统计分析页均以此为底层取数源。

### 与其他页面关系

- **上游**：《业务草稿》（提交记账过账）、各业务域表单页直接提交 / 记账的单据。
- **下游**：红冲(作废) 生成红冲单同步回写库存 / 往来 / 资金；销售业绩、经营分析、查应收 / 查应付等分析页取数基础。
- **同组页面**：待审批单据、业务草稿。

## 5. 实现差异说明

> 本节按当前源码与真机实测（2026-09-18）回写。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/business-history/index.vue`（483 行）。
- **骨架**：`ErrorBoundary > PageContainer(full-height) > CategoryListLayout`（`:tabs="[]"`、`:show-category-panel="false"`、`:show-table-footer="true"`）+ `BillDetailTable`（`:view-mode="true"`、`:min-rows="20"`）+ `StandardPagination`（`variant="classic"`、`page-size-options=[20,50,100]`）。**无行勾选框**（对标亦无 → 无批量动作）。
- **逐 Tab 列数**：单视图。全部 **17 列 / 默认 9 列**（8 个默认隐藏 = 制单人 / 记账人 / 摘要 / 单据备注 / 附件 / 制单时间 / 记账时间 / 打印次数）。列配置键 `analytics-business-history-columns`（`storage-key` = `global-config-key`）。
- **页面配置**：`PageConfigPanel`（对标实测有），键 `analytics-business-history-page-config`；查询条件 6 项 + 功能按钮 3 项（刷新 / 打印(F8) / 导出）可启停；另登记打印配置项 2 项（打印抬头显示公司名 / 打印底部显示合计行）。
- **查询项**：工具栏左侧「查询方案」下拉（占位）+ 8 段时间快捷段（默认「本月」）；查询区 6 项 = 单据类型、单据编号、往来单位、仓库、经手人、部门，另有「显示红冲」勾选（`includeReversed`）+ 查询 / 重置。
- **行级动作**：红冲(作废)（仅该类型支持 `cancel` 时出现，二次确认）、复制（仅支持 `copy` 时出现）、备注（写回单据自身「单据备注」）。红冲 / 复制分发到各业务域既有 `POST {base}/{id}/cancel`、`/copy`；备注走 `PUT {base}/{id}` 仅提交 `remark` 一个字段（依赖 MyBatis-Plus NOT_NULL 更新策略，不覆盖其余列）。
- **打印(F8) / 导出**：打印为浏览器打印窗口（`window.print`，列口径 = 当前可见列、含合计行），并绑定 F8 快捷键；导出为全量 CSV（逐页 100 条拉取后端数据 → `useExport`）。
- **合计行 / 排序**：底部合计行「金额」取自后端 `summary.amount`（红冲单以负数参与）；仅「金额」可排序（后端 `sortField/sortOrder`）。
- **取数端点**：`GET /docquery/business-history/page`（13 类单据全量 UNION，默认排除已取消）。
- **后端**：`DocQueryController` + `DocQueryService`（`StatusMode.ALL`）；本轮未改后端、未新增迁移。

### 剩余缺口

1. **「查询方案」下拉仅为占位**：`queryScheme` 未被任何请求使用（`index.vue:197`、`:18-25`）→ 对标「查询方案」能力未落地。
2. **打印配置项未参与实际输出**：`PageConfigPanel` 登记的 `showCompany`（打印抬头显示公司名）/ `showSummary`（打印底部显示合计行）只做持久化，`handlePrint()`（`index.vue:380-401`）未读取它们，打印内容恒为「标题 + 表格 + 合计行」；打印次数也未回写后端（表格「打印次数」列取自单据数据，不由本页累加）。
3. **打印 ≠ 对标打印模板**：本页打印为前端 `window.print()` 直出 HTML，非后端打印模板 / 打印任务，也不产生打印记录。
4. **对标工具栏「更多」未接**：只落了 `刷新 / 打印(F8) / 导出`；「更多」内项在对标侧本身未取到，**未确证**。
5. **每页行数档位**：对标实测每页 20 行，本页 20/50/100 三档（默认 20）。
