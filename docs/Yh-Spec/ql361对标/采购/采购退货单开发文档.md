# 采购退货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/return/form`（表单）+ `purchase/return/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：采购退货出库录单（可关联源单），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 底部收款区 + 备注区 + 单据信息行 + 右侧摘要结账面板。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `purchase/return/form`；标签「历史」→ `purchase/return/index`。

## 2. 表单页配置

### 表头字段（必填 *）

- 必填：供应商\*、出库仓库\*、经手人\*（默认当前登录人）、单据日期\*
- 选填：联系人、联系电话、联系地址

### 全部表单字段（35 个，cfg 实据 35 字段 ✅）

- 基本信息：编号、供应商、供应商编号、开户行、银行账号、税号、出库仓库、经手人、部门、单据日期、联系人、联系电话、联系地址
- 扩展：自定义字段1~5、摘要、付款期限、源单
- 收款区：收款账户、收款金额、更多账户、此前预付、退回预付款、预付余额、本次欠款、此前欠款、欠款余额
- 备注/信息：单据备注、制单人、制单时间、打印次数
- 摘要面板：本单金额（优惠金额等摘要项自动计算）

> 弹窗 Tab：页面配置 / 录单默认值 / 打印设置（勾选后自动保存，对所有操作员生效）。

### 字段分组

顶部基本信息 → 商品明细表格 → 收款区 → 备注区 → 单据信息 → 摘要结账面板。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。

## 4. 列表页配置（双入口「历史」标签）

### 按单据 Tab

- 查询条件：日期、单据编号、供应商/客户、经手人、部门、制单人、仓库、单据状态、单据备注、审核人、打印次数

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后单据生效，库存减少（出库方向）。
- 资金方向与入库单相反：退货是供应商退款给我方，故为「收款账户/收款金额」；入库单为「付款账户/付款金额」。
- 退回预付款：退货款可退回至预付款余额；本次欠款 = 本单退货金额 − 本次已收；此前欠款/欠款余额为供应商往来回显。
- 表头为「出库仓库」（退货出库），与入库单的「仓库」（入库方向）区分。
- 源单字段：可关联采购入库单/采购订单生成（带单退货，具体源单类型范围待复核）。
- 批次管理：按批次条码/效期定位退货批次出库。
- 上游：采购入库单/采购订单（源单带单，待复核）；无源单时可直接开单退货。下游：库存减少；供应商应收退款/预付款退回（财务）；采购订单列表「退货数量/退货金额」列回写（XSMK 依据）。
- 关联查询：采购单据查询/采购明细查询（本单纳入两页统一检索）。
