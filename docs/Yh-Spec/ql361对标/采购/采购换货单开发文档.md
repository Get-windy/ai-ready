# 采购换货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/exchange/form`（表单）+ `purchase/exchange/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：与供应商一退一换同单完成（换入仓库表 + 换出仓库表双明细），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 换入仓库明细表 + 换出仓库明细表 + 底部付款区 + 备注区 + 单据信息行 + 右侧摘要结账面板。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `purchase/exchange/form`；标签「历史」→ `purchase/exchange/index`。

## 2. 表单页配置

### 表头字段（必填 *）

- 必填：供应商\*、换入仓库\*、换出仓库\*、经手人\*（默认当前登录人）、单据日期\*（默认当天）
- 付款区：付款账户、付款金额、更多账户、此前预付、使用预付款、此前欠款
- 单据信息：制单人、制单时间、打印次数、打印记录、源单
- 摘要区：优惠金额（其余摘要项自动计算）

### 字段分组

顶部基本信息 → 换入仓库明细表 → 换出仓库明细表 → 付款区 → 备注区 → 单据信息 → 摘要结账面板。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

> 与采购订单/采购入库单相比，本页工具区无「导入」，为「导出」（JSON 与截图一致确认）。

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

> 换出仓库表列集合同换入表（21 列）；列顺序差异（截图确认）：货位列于条码之前。JSON 首项/末项为两表表头拼接串，非真实单列，已剔除。

### 全部可配置列（换入/换出表共用 57 列，cfg 实据 57 列 ✅）

操作、图片、商品名称、货号、条码、规格、型号、产地、品牌、区域、货位、计价单位、可用库存、可用库存换算结果、账面库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、最近采购日期、零售价、批发价、单价、金额、小单位、小单位单价、小单位数量、成本单价、成本金额、体积（m³）、重量（kg）、赠品、备注、价格等级8昵称（餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip）、单据自定义1(数字字段)~3(数字字段)、单据自定义4(文本字段)~5(文本字段)、单据自定义6(数字字段)~7(数字字段)、单据自定义8(往来单位)、单据自定义9(职员)、单据自定义10(部门)

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。换入表与换出表共用同一列配置清单（列顺序差异见默认列注）。cfg 实据（2026-08-14）抓取页签为「采购退货单」，商品列集合与换货单一致（57 列），表单页商品列无独立 cfg 实据。

## 4. 列表页配置（双入口「历史」标签）

- 查询条件（对标系统实据）：日期、单据编号、供应商、经手人、部门、仓库（入库/出库）、单据状态、结算状态、单据备注、制单人、审核人、打印次数
- 功能按钮（默认全选）：新增、刷新、批量打印、打印(F8)、导出、配置
- 按单据列（25 列，对标实据 2026-08-14）：单据日期、单据编号、单据状态、入库仓库、出库仓库、供应商、供应商编号、经手人、部门、入库数量、出库数量、本单金额、金额、折后金额、已结金额、结算状态、重量（kg）、体积（m³）、销售类型、单据备注、制单人、记账人、制单时间、记账时间、打印次数
- 按明细列（16 列）：单据日期、单据编号、入库仓库、出库仓库、供应商、供应商编号、商品名称、货号、单位、数量、单价、金额、批次条码、生产日期、到期日期、明细备注

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后单据生效，换出仓库减库存、换入仓库增库存，一单一退一换同单完成。
- 换入仓库 ≠ 换出仓库：表头双仓库必填，支持跨仓换货（换入明细入换入仓、换出明细出换出仓）。
- 付款区：换货差价以付款结算（付款账户/付款金额），可用预付款抵扣；此前预付/此前欠款为供应商往来回显。
- 源单：出现在单据信息行（截图确认），可关联源单生成（源单类型范围待复核）。
- 批次管理：换入/换出两侧均按批次条码/效期/货位采集。
- 上游：采购入库单/采购订单（源单带单，待复核）；无源单时可直接开单换货。下游：库存一增一减；供应商往来差价结算（财务）。
- 姊妹单据：销售换货单（销售域，同为双明细表结构）；关联查询：采购单据查询/采购明细查询（本单纳入统一检索）。
