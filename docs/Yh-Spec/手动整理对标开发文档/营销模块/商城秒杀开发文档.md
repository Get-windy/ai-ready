## 4. 业务规范

- **秒杀模型（列实据归纳）**：
  - 场次制：一行 = 一个秒杀场次（活动名称 + 起始/结束时间窗），场次内商品以秒杀价限时限量抢购。
  - 活动状态随时间窗流转（待开始/进行中/已结束——同域商城预售、商城弹窗广告活动状态下拉枚举实据佐证，本页下拉为「全部」，状态枚举**待复核**）。
  - `创建时间` 为审计列。
  - **与日常价的隔离（基准文档推断，待复核）**：秒杀价仅在场次时间窗内、限场次库存生效，不写入价格等级与销售价格跟踪。
- **与其他页面关系**：商城营销组同域（商城拼团凑团享价、商城预售订金预售与秒杀限时抢并列商城三大玩法）；推广联动（「我要推广」可推广秒杀活动）；本系统落地对应 `/api/erp/marketing/flash-sale`。
- **状态枚举（本系统实现实据，非对标实据）**：本系统 `FlashSale.status` = 0 草稿 / 1 已发布 / 2 已取消 / 3 已结束；对标枚举**待复核**。

## 5. 实现差异说明

> 本节按当前源码回写（源码未在本轮改动）。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/marketing/mall-flash/index.vue`（共 569 行）。
- **骨架**：`ARReportPage`（`index.vue:2-11`，`title="秒杀场次"`、`page-param-style="pageNum"`、`export-file-name="秒杀场次"`、`row-key="id"`），**非**金标准路线 A。`ARReportPage` 为纯报表壳（`components/ARReportPage/ARReportPage.vue`：内联查询表单 `:16-64` + `a-table` `:100-120` + 内置 CSV 导出 `:340-371`），**不含** `BillDetailTable`/`StandardPagination`/`PageConfigPanel`，**无列配置齿轮、无页面配置弹窗**。
- **查询条件**：`queryFields`（`index.vue:295-298`）= 标题 `title`（input）、状态 `status`（select，选项来自 `STATUS_MAP` 数值枚举）。
- **列定义**：`columns`（`index.vue:301-312`），共 **10 列**：场次标题、秒杀商品、秒杀价、原价、已售/库存、开始时间、结束时间、状态、排序、操作。**与对标 5 列仅「开始时间/结束时间/状态(活动状态)」约 3 列语义近似**，`活动名称`/`创建时间` 缺失，另多出 7 列自有列。
- **状态映射**：`STATUS_MAP`（`index.vue:277-282`）= 0 草稿 / 1 已发布 / 2 已取消 / 3 已结束；`PARTICIPANT_STATUS_MAP`（`:285-289`）= 0 已参与 / 1 已下单 / 2 已取消。
- **工具栏**：`header-extra` 插槽放「新增秒杀」按钮（`index.vue:12-22`），调 `openCreate`（`:397-401`）；`ARReportPage` 内置「刷新」「导出」（`showRefresh`/`exportFileName`）。
- **行级操作**（`index.vue:50-112`）：参与记录、编辑（status ∈ {0,1}）、发布（status === 0）、取消（status ∈ {0,1}）、删除（status ∈ {0,2}）。
- **新增/编辑弹窗**：`a-modal`（`index.vue:117-226`），字段：场次标题、秒杀商品（下拉，`optionsApi.getProducts`）、秒杀价、原价（选商品后自动带出）、场次库存、起止时间（`a-range-picker` show-time）、排序、备注；`handleSave`（`:421-460`）校验「秒杀价不能高于原价」后区分 `flashSaleApi.update` / `flashSaleApi.create`。
- **参与记录抽屉**：`a-drawer`（`index.vue:229-263`）+ 内联 `a-table`（后端分页），列 `participantColumns`（`:500-507`）= 客户、数量、金额、状态、关联订单、参与时间；加载 `loadParticipants`（`:516-533`）调 `flashSaleApi.participants(id, {pageNum,pageSize})`。
- **数据来源**：`apps/pc-admin/src/api/marketing.ts` → `flashSaleApi.page/getById/create/update/remove/publish/cancel/participants`（`marketing.ts:378-403`，端点 `/erp/marketing/flash-sale/...`）；商品下拉 `optionsApi.getProducts`（`index.vue:548-556`）。
- **后端**：`backend/erp/erp-marketing/src/main/java/cn/aiedge/erp/marketing/controller/FlashSaleController.java`。
- **storage-key**：无（未使用列配置/页面配置持久化）。

### 剩余缺口

1. **🔴 列结构整体不对齐（最大缺口）**：对标实测 5 列（活动名称/起始时间/结束时间/活动状态/创建时间）；本页 10 列（场次标题/秒杀商品/秒杀价/原价/已售/库存/开始时间/结束时间/状态/排序/操作）。**`活动名称`、`创建时间` 两列缺失**，`秒杀商品/秒杀价/原价/已售/库存/排序` 为对标列配置外的自有列。
2. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；`ARReportPage` 无列配置入口。
3. **查询条件不对齐**：对标为 `活动名称 / 起始时间 / 结束时间 / 活动状态`；本页为 `标题 / 状态`（缺时间区间条件）。
4. **状态轴不对齐**：对标活动状态为「待开始/进行中/已结束」（同域佐证，本页待复核）；本页为「草稿/已发布/已取消/已结束」四态，二者语义不可一一映射。
5. **行级操作未复核**：对标行级动作**待复核**；本页为 5 项（参与记录/编辑/发布/取消/删除），无对标依据可断言一致。
6. **错误处理为原型级**：`handleSave`/`handlePublish`/`handleCancel`/`handleDelete`/`loadParticipants` 的 catch 分支仅 `console.warn`（`index.vue:455-457`、`:468-470`、`:478-480`、`:488-490`、`:526-530`），未做用户提示。
7. **导出**：本页用 `ARReportPage` 内置「当前页 CSV 导出」（`ARReportPage.vue:340-371`，非真实 xlsx，非全量导出）。
8. **无页面配置/打印**：对标「无打印」与实测一致；但本页亦无页面配置弹窗。
