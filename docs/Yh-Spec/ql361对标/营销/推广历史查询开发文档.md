# 推广历史查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`marketing/promote-history`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **查询列表页**：推广记录与转化效果的查询回溯页——查询方案 + 时间快捷段 + 查询区 + 效果数据表格；无新增按钮、无子标签，纯查询定位。
- 截图：![推广历史查询](../../../../tool-results/ql361/pages/营销__营销推广__推广历史查询.png)

## 2. 页面配置

### 查询条件

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年（8 段）
- 分享日期\*（起 至 止，必填）
- 分享类型（全部）
- 分享人、商品、优惠券（弹选）
- 筛选条件（分享概要模糊检索）

### 功能按钮

- 工具栏（抓取 JSON buttons）：刷新、打印(F8)、导出、查询、跳转（分页跳转）

### 打印配置

页面有打印(F8)按钮；打印模板配置细节待复核

## 3. 数据表格列配置

### 默认显示列（10 列，抓取 JSON columns 实据）

分享时间、分享人、分享类型、分享概要、浏览次数、浏览人数、分享领取数、下单人数、下单笔数、下单金额

> JSON columns 首项"分享时间 分享人"为抓取拼接串（表头合并单元格的文本拼接），非真实单列，已剔除，不计入列数。效果列列头带排序箭头与 ? 注释图标（口径说明）；底部合计行对 6 个效果列汇总（抓取时点全 0）。

## 4. 业务规范

- 推广转化漏斗（列实据归纳）：
  - 一行 = 一次分享动作（分享时间 + 分享人 + 分享类型 + 分享概要）；分享类型对应《我要推广开发文档》5 类可推广对象（商品/优惠券/促销/拼团/秒杀，推断待复核）
  - 效果漏斗四段（列实据，列头带口径注释）：
    1. 触达：浏览次数 / 浏览人数（推广链接被打开的量与人）
    2. 领取：分享领取数（经分享领取的券/福利数）
    3. 转化：下单人数 / 下单笔数（经推广下单的买家数与订单数）
    4. 金额：下单金额（推广带来的成交额）
  - 合计行对 6 个效果列全量汇总（实据），支撑推广业绩按人/按对象考核
  - 分享日期必填（* 实据）——效果数据量大，强制限定时间窗
  - 与订单的衔接：订单处理中心默认列"推广人"（销售域实据）记录单笔订单的推广归属，本页为其汇总查询端
- 与其他页面关系：数据上游（《我要推广开发文档》产生的分享动作及其浏览/领取/下单回流数据）；分析域（营销分析 → 营销推广分析为图形化分析端，本页为明细台账端）；本系统落地对应推广历史查询 `/api/crm/marketing` 效果报表（api/marketing.ts 实据）
