# 费用类型开发文档

> **文档类型：** 页面对标复刻（✅ **金标准已实现**，2026-09-12）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）

> **定位：** 费用类会计科目视图（费用科目字典）—— 与《会计科目》同源，作为《费用单》费用科目、《费用统计》的统一取数来源。

## 0. 结论先行（本页是什么）

**费用类型 = 会计科目中「费用类」科目的视图**，不新建任何字典表。

- **口径**：`finance_account_subject` 中 `subject_type = 5`（损益类）且 `direction = 1`（借方）的科目。
  → 即「费用/损失类」科目：管理费用、销售费用、财务费用、税金及附加、营业外支出、所得税费用…
  → 收入类（损益类贷方，如 6001 主营业务收入）与资产/负债/权益/成本类**不在本页**。
- **红线**：严禁另建「费用类型」数据表/字典（P0，见第 9 节）；全系统单一口径 = `finance_account_subject`。

## 5. 业务规范

- **口径（红线）**：本页只读写 `finance_account_subject` 中 `subject_type=5 且 direction=1` 的科目；
  请求携带的 `subjectType/direction` 参数**被后端忽略**（防止越界）。
- **越界保护**：对非费用类科目（如 6001 收入类、1001 资产类）调用详情/修改/删除/启停，
  一律返回「费用科目不存在: {id}」，不会改动其它科目。
- **编号唯一**：`subject_code` 全局唯一（含软删除外的全部科目），重复返回「科目编号已存在: X」。
- **科目全名**：留空自动 = `上级科目全名 / 本科目名称`；上级改名后自动重算全部下级。
- **层级**：`parent_id` 建树；新增下级时上级 `isLeaf` 自动转 false，删除最后一个下级后上级恢复 `isLeaf=true`；`level = 上级 level + 1`。
- **删除保护**：有子科目不可删除；已被凭证分录（`finance_voucher_item.subject_id`）引用不可删除，提示改用停用。
- **核算项**：引用 `finance_auxiliary_type`（辅助核算类型）主数据，**不另建字典**；可清空为「不核算」。
- **单一口径**：凭证/总账/明细账/科目余额表/财务报表/费用单/费用统计统一引用同一科目表。

## 6. 接口（后端）

后端：`ExpenseTypeSubjectController`（`/api/erp/md/expense-type`，委托 `ExpenseTypeSubjectService` → `AccountSubjectService`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/tree` | 费用类科目树；`keyword` / `includeDisabled` / `hierarchical`（false=平铺）。口径由后端固定为 损益类+借方 |
| GET | `/list` | 扁平列表（平铺口径，供下拉/导出复用） |
| GET | `/aux-types` | 核算项可选项（读 `finance_auxiliary_type` 启用项，复用辅助核算类型主数据） |
| GET | `/{id}` | 单条（非费用类科目 → 404「费用科目不存在」） |
| POST | `` / `/` | 新增费用（强制 `subject_type=5`，`direction` 缺省 1） |
| PUT | `/{id}` | 更新（强制保持 `subject_type=5`） |
| DELETE | `/{id}` | 逻辑删除（沿用会计科目约束） |
| PUT | `/{id}/enable` | 启用/停用 |
| GET | `/export` | 真实 xlsx 流（POI，与列表同一口径，列=科目编号/科目名称/核算项，文件名 `费用类型_日期.xlsx`） |

前端口径：`mdExpenseTypeApi`（`api/md.ts`）。

> **不重复开发说明**：本控制器是**薄门面**，全部读写委托 `AccountSubjectService`；
> 建树逻辑抽为共享工具 `support/AccountSubjectTreeBuilder`（`AccountSubjectServiceImpl` 同步改为调用它，消除重复实现）。
> 与同构的《其他收入》`/api/erp/md/other-income`（损益类 **贷方**）互为对称：一个是费用类视图，一个是收入类视图。

## 9. 实现差异说明（本系统 vs 对标）

## 11. 最终裁决方案（2026-09-12 修订）

- **P0 费用类型单一口径（红线）**：本页费用类型为全局基础数据，费用单/审批/统计/报销统一引用，
