## 页面概述

订单处理是**商城订单统一处理工作台**：按商城订单来源（微商城/XSDD-）查询、审核、收款、发货、终止的处理中心。**单入口**，含 **2 个视图 Tab**（按单据 / 按明细）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 订单处理 | `mall/order-process` | 复合页（列表 + 2 Tab：按单据 / 按明细） |

单入口：商城 → 订单处理 → 订单处理。

- 实测实据（**2026-09-15 复核**）：按单据 Tab 共 **12** 条记录、订单金额合计 **3,292**（运费合计 0、代收金额合计 0），含 `XSDD-20260915-004` … `XSDD-20260914-001`；按明细 Tab 共 **31** 条记录。（2026-09-07 首抓为 11 条 / 合计 2,451 —— 业务数据逐日变化，属正常漂移。）
- 单号前缀：`XSDD-YYYYMMDD-序号`。
- 单据状态下拉（多选）：`审核中,待付款,待发货,发货完成,交易完成,审核驳回`。
- 订单来源：微商城；支付方式：微信支付。
- **默认 Tab**：**「按单据」**（本系统 `activeTab='doc'` 即此口径；2026-09-15 曾据一次 DOM 读数误记为「按明细」，经确认**以「按单据」为准**，该条差异已撤回）。

## 业务规范说明

- **订单主线**：商城订单（微商城，`XSDD-` 前缀）→ 本页统一处理；状态流转 待付款/待发货/已发货/发货完成/交易完成/审核驳回。
- **行级操作（按单据）**：审核、收款、终止、更多。审核=通过订单；收款=对订单发起收款；终止=强制终止订单。
- **金额口径**：订单金额（商品金额+运费+其他费用−优惠）；已结金额=已收款。
- **配送**：配送方式/物流公司/运单号/运费/运费承担方/代收金额；收货人/联系电话/收货地址/客户备注/卖家备注。
- **订单来源**：微商城；订单来源为「微商城」时展示。
- **下游**：审核后进入发货流程；收款联动收款单；记账状态（未完成/已完成）与审批流联动。

### 当前实现

#### 2. `orderStatus` 多值与数字 `status` 的兼容口径

修正前后差异：

| 项 | 修正前 | 修正后 |
|----|--------|--------|
| `orderStatus` 取值 | 单值 `switch`，非白名单值落 `default: 0`（实际退化为「草稿/待付款」查询，静默错误） | 按逗号拆分 → 逐值映射 → `Set<Integer>` → `IN (...)`；**无法识别的值显式忽略并 `log.warn`**，不再退化为 0 |
| 全部值均无法识别 | 退化为 `status = 0` | 显式 `status IN (-1)` → 返回空结果（可解释，不静默给错数据） |
| 数字状态 | 不接收（商城订单页 Tab1 提交的 `status` 被完全忽略） | 新增 `status` 参数，数字单值/多值直接 `IN`；非数字取值同样忽略并记日志 |
| 两参数同时给出 | — | 取并集（`LinkedHashSet` 去重） |

实现函数：`MallAdminServiceImpl#collectStatusSet(orderStatus, status)`、`#toErpStatusOrNull(mallStatus)`（新增，替换原 `toErpStatus` 的「兜底 0」）；原 `toErpStatus(String)` 保留为 `@Deprecated`，仅供写操作（审核/驳回/发货/终止）内部使用。

商城状态串 ↔ erp 状态映射表（`toErpStatusOrNull`）：

| 商城状态串 | erp `status` | 说明 |
|------------|--------------|------|
| `PENDING_PAYMENT` | 0 | 待付款 → 草稿（未付款） |
| `PENDING_AUDIT` | 1 | 审核中 → 待审批 |
| `PAID` | 1 | 已付款待审批 → 待审批 |
| `APPROVED` | 2 | 已审批（待发货） |
| `SHIPPED` | 3 | 已发货 → 部分出库 |
| `COMPLETED` | **5** | 交易完成（**修正前误映射为 4**；erp 规范 4=完成、5=交易完成是两个阶段） |
| `CANCELLED` / `REJECTED` | 6 | 已取消（erp 规范无「审核驳回」独立值，二者共用 6） |

#### 3. 状态口径统一（以后端 `erp_sale_order.status` 为唯一基准）

权威口径（以 `backend/erp/erp-sales/.../sale/entity/SaleOrder.java` 与 `.../b2b/dao/ErpSaleOrderMall.java` 的字段注释为准；`V8.0.0__Create_Sale_Order_Tables.sql` 里的旧注释「5-取消」已过期，未采纳）：
**0草稿 / 1待审批 / 2已审批 / 3部分出库 / 4完成 / 5交易完成 / 6已取消**。

修正前后差异（本页）：

| 项 | 修正前 | 修正后 |
|----|--------|--------|
| `STATUS_MAP` | 字符串 key（`PENDING_PAYMENT`/`PENDING_AUDIT`/`PAID`/`APPROVED`/`SHIPPED`/`COMPLETED`/`REJECTED`/`CANCELLED`），且 `PENDING_PAYMENT` 与 `PAID` 都标「待付款」 | 拆为 `STATUS_MAP`（数字 key，erp 权威 0~6，供下拉与导出）+ `MALL_STATUS_MAP`（字符串 key，商城侧细分状态，供列表/详情展示） |
| `STATUS_OPTIONS` | 6 个商城状态串（审核中/待付款/待发货/发货完成/交易完成/审核驳回） | 7 个 erp 数字状态，提交 `status=0,1,2,3,5,6,4` |
| `mallStatusOf()` 兜底 | `0:PENDING_PAYMENT 1:PENDING_AUDIT 2:APPROVED 3:SHIPPED 4:COMPLETED 5:REJECTED`（**与后端映射不一致**：1 应该是 `PAID`、5 不存在于 erp 规范） | 与后端 `erpStatusToMallStatus` **逐值一致**：`0:PENDING_PAYMENT 1:PAID 2:APPROVED 3:SHIPPED 4:COMPLETED 5:COMPLETED 6:CANCELLED` |
| 后端 `resolveMallStatus()` | 自带一套 `switch`（与 `toErpStatus` 各写一份，易漂移） | 委托 `erpStatusToMallStatus`，与 `toErpStatusOrNull` 构成互逆映射 |

**后端口径的确切对应关系**（两张字典合并后的现状，前端口径与之一致）：
`PENDING_PAYMENT→0`、`PENDING_AUDIT→1`、`PAID→1`、`APPROVED→2`、`SHIPPED→3`、`COMPLETED→5`、`CANCELLED/REJECTED→6`。
其中 `PENDING_AUDIT` 与 `PAID` 共用 1、`CANCELLED` 与 `REJECTED` 共用 6 是**既有映射定义**（本轮沿用、未改动），故展示时仍需 `extInfo.originalMallStatus` 才能区分「审核中/待审批」与「审核驳回/已取消」。

**已按后端规范移除、不再硬凑的项**：ql361 的「审核中」「待付款」在 erp 单列状态里都落在 `1`，前端下拉无法再区分，选项合并为一项「待审批（待付款/审核中）」；「审核驳回」与「强制终止」同为 `6`，合并为「已取消（审核驳回/强制终止）」。商城侧细分状态仍通过列表/详情展示（读 `extInfo.originalMallStatus`）如实呈现，未丢失。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
