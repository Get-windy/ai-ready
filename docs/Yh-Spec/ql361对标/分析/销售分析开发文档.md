- **列表查询页**（统计分析页）：销售额/毛利/利润全口径销售经营分析（8 个维度 Tab + 按天/按周/按月粒度 + 15 列量本利表格）；销售经营的量本利分析核心页。菜单路径：分析 → 采销分析 → 销售分析。

## 4. 业务规范

### 统计口径（量本利全链路）

- **销售额**：销售出库口径含税销售额；**销售额占比(%)**=该行销售额/合计销售额×100
- **销售收入**=销售额−退货额（净销售口径；本月 791,277.5−11,153.67=780,123.83 与合计行一致 ✅）
- **销售毛利**=销售收入−销售成本（780,123.83−621,115.95=159,007.88 ✅）
- **销售利润**=销售毛利−其他费用支出−结算优惠；**利润率(%)**=销售利润/销售收入×100；**费销比(%)**=其他费用支出/销售收入×100
- **其他费用支出**：随单费用（物流费/装卸费等）；**结算优惠**：收款结算环节让利
- 销售成本按出库成本（移动加权/批次成本，成本核算口径与《进销存分析》一致）

### 与其他页面关系

- 取数：销售出库单/销售退货单（经营历程流水）+ 商品成本 + 随单费用 + 收款结算优惠
- 同源页：《销售费用分析》（费用口径展开）、《经营分析》（公司级利润表口径）、《销售业绩》（漏斗口径）
- 8 维度 Tab 中"按来源"=单据产生方式（手工开单/商城下单/导入等）
