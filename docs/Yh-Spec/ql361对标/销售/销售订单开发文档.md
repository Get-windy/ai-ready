# 销售订单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/order/form`（表单）+ `sales/order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页**：销售订单录单；编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 底部收款/物流信息/会员信息 3 Tab + 备注区 + 单据信息行 + 右侧摘要结账面板。
- **列表页**：独立为「订单处理中心」（见《订单处理中心开发文档》），含全部/待审核/拣货发货三阶段。
- **双入口**：主菜单 → `sales/order/form`；标签「历史」→ `sales/order/index`。

## 2. 表单页配置

### 表头字段（必填 *）

- 必填：客户\*、发货仓库\*、经手人\*（默认当前登录人）、单据日期\*、销售类型\*（默认"正常销售"）
- 选填：收货人、联系电话、收货地址

### 全部表单字段（68 个，cfg 实据 68 字段 ✅，与 XSMK 同口径）

- 基本信息：编号、客户、客户编号、开户行、银行账号、税号、客户备注、发货仓库、经手人、部门、单据日期、销售类型、收货人、联系电话、收货地址、客户级别
- 扩展：自定义字段1~5、审核人、摘要
- 收款区：订金账户、订金金额、更多账户、使用预订货款、此前预收、预收余额、信用额度、可用额度、此前欠款、收款日、对账日
- 物流区：配送方式、配送线路、司机、物流公司、运费承担方、运费、运单号、代收货款、预计发货、联系人、联系电话、提货地址
- 会员区：会员卡号、此前积分、销售积分、退货积分、兑换积分、使用积分、当前积分
- 备注/信息：单据备注、买家备注、表尾自定义字段1~2、制单人、制单时间、打印次数、源单
- 摘要面板：销售数量、退货数量、商品金额、促销优惠、优惠金额、其他费用、本单金额

### 字段分组

顶部基本信息 → 商品明细表格 → 收款 Tab → 物流信息 Tab → 会员信息 Tab → 备注区 → 单据信息 → 摘要结账面板。

### 录单默认值

经手人默认当前登录人、销售类型默认"正常销售"、单据日期默认当天。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）：草稿进"业务草稿"，提交后进订单处理中心"待审核"。
- 提交后按 待审核 → 拣货/发货 → 出库 → 发货完成 → 交易完成 流转。
- 订金 = 带使用条件的预收款/预付款；「使用预订货款」关联预订货单的预订金抵扣。
- 发货后生成销售出库单（源单回链）；退货前置生成销售退货申请。
- 下游：销售出库单（发货）、销售退货申请（退货）；定价联动销售价格跟踪。

## 5. 实现差异说明

- 收款 Tab 我方较对标多「扩展信息 Tab」（开户行/银行账号/税号/客户备注），属非标准扩展。
- 明细「数量」与「件散数量」合并同列（目标分列），换算关系默认隐藏。
