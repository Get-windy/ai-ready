## 四、如何补全未实测页

1. 用**具备「预算/费用/对账/其他往来单位」菜单权限**的账号（或 ql361 管理员）重新登录。
2. 按《抓取方法指南.md》对目标页逐 Tab 抓列配置+页面配置。
3. 把实测结果存 `抓取结果/<页名>_抓取.json`，并按金标准四段式改写对应文档。
4. 更新本清单「二、无对标实测」→ 移到「一、有对标实测」。
