## 2. 环境健康度评估模型

### 2.1 多维评估指标体系

#### 2.1.1 资源可用性维度
- **CPU使用率**: 实时监控和历史趋势分析
- **内存使用率**: 包括物理内存和虚拟内存
- **磁盘空间**: 可用空间和I/O性能
- **网络带宽**: 网络延迟和吞吐量
- **数据库连接**: 连接池状态和响应时间

#### 2.1.2 服务状态维度
- **服务健康检查**: HTTP/HTTPS端点检查
- **进程状态**: 关键进程运行状态
- **端口监听**: 必需端口的可用性
- **依赖服务**: 外部依赖服务的连通性
- **服务响应时间**: 关键接口响应时间

#### 2.1.3 性能指标维度
- **请求成功率**: HTTP状态码分布
- **错误率**: 业务错误和系统错误
- **响应时间**: P50, P90, P95, P99
- **吞吐量**: 请求处理能力
- **并发连接数**: 活跃连接数

### 2.2 健康度评分算法

#### 2.2.1 评分权重分配
```
健康度总分 = Σ(维度权重 × 维度得分)

维度权重分配:
- 资源可用性: 30%
- 服务状态: 40%
- 性能指标: 30%
```

#### 2.2.2 阈值设置机制
- **绿色(健康)**: 得分 ≥ 85
- **黄色(警告)**: 70 ≤ 得分 < 85
- **红色(危险)**: 得分 < 70

### 2.3 实时监控和趋势分析
- **实时健康度计算**: 每5分钟计算一次
- **历史趋势分析**: 24小时/7天/30天趋势
- **异常检测**: 基于历史数据的智能异常检测
- **预测分析**: 基于机器学习的环境健康预测
