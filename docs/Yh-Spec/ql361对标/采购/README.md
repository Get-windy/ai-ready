## 域级说明

- **单据编号规则**（截图实据）：采购订单 CGDD-、采购入库单 CGRKD-、采购退货单 CGTHD-、采购换货单 CGHHD-、采购费用分摊单 CGFYD-，后缀均为 `YYYYMMDD-序号`；以销定购列表数据行为销售订单（XSDD- 前缀）。
- **快捷键体系**：F8 打印、Ctrl+S 保存草稿、Ctrl+Enter 提交（采购订单）/ 记账（采购入库单/采购退货单/采购换货单/采购费用分摊；费用分摊页无保存草稿、无打印(F8)）。
- **状态流转主线**：采购准备（预警/缺货/智能/以销定购四种补货计算）→ 采购订单（提交）→ 采购入库单（记账，库存增加、回写订单已收数量）→ 采购退货单（记账，库存减少）/ 采购换货单（记账，一增一减）；采购费用分摊（选费用单+选采购入库单，按金额自动分摊，记账计入入库商品成本）。
- **资金方向**（表单页底部区域实据）：采购订单用订金（订金账户1）；入库单付款（付款账户，可用预付款抵扣）；退货单收款（收款账户，可退回预付款）；换货单按差价付款。
- **补货公式**（页面提示条实据）：库存预警补货 缺货数量=库存上限+待发货−账面数量−待收货；缺货补货 缺货数量=待发货数量−账面库存；智能补货 计划采购数量=备货天数×日均销售量+待发货数量−待收货数量−账面库存。
- **通用待复核项**：①各表单页打印配置/录单默认值弹窗的字段级明细；②补货三页"采购"按钮与以销定购"采购成品/采购原料"生成采购单的具体规则；③采购入库单/退货单/换货单及采购查询三页、采购费用分摊两表的全量可配置列（列配置弹窗未抓取）；④采购费用分摊"分摊方式"下拉全量值域与记账后成本回写口径；⑤采购单据查询"单据类型"下拉完整值域。
