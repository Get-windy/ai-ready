# 业绩提成中心开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/commission-center`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **复合页**（统计分析 + 结算操作）：人员年度提成结算工作台（每月提成/提成构成/方案汇总提成/业绩概览/业绩明细五视图 + 批量结算）；提成核算到结算的闭环页。菜单路径：分析 → 提成分析 → 业绩提成中心。
- 页面结构：角色切换（深灰条）+ 子视图 Tab（5 个）+ 查询区（两行）+ 年度×月份提成矩阵表格（合计行 12 个月列）。
- 页面截图：`tool-results/ql361/pages/分析__提成分析__业绩提成中心.png`

### 查询条件（抓取 JSON filterLabels + 截图实据）

## 4. 业务规范

### 统计口径与数据关系（提成结算闭环）

- **年度矩阵**：人员 × 12 个月，单元格为该月提成金额（每月提成视图）
- **结算顺序约束**：**若存在某月份提成未结算，此后月份提成将不显示**（页面提示条实据）——提成必须按月顺序结算，保证核算连续性
- **五视图分工**：每月提成（年度矩阵总览）、提成构成（单月提成的方案项拆分）、方案汇总提成（按提成方案汇总）、业绩概览（业绩指标总览）、业绩明细（单据级提成明细）
- **角色维度**：按人员角色（配送员/业务员等）切换提成口径，角色由提成方案覆盖范围决定

### 与其他页面关系

- 取数：《业务员提成》（销售提成计算）、《回款统计》（回款提成）+ 配送计件（配送员）+ 提成方案
- 下游：提成结算→工资/费用发放（财务域）；批量结算回写结算状态
