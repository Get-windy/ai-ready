# 商城预售开发文档

> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页（复合页）**：商城商品预售活动管理页，2 个子标签（商品预售 / 预售订单）+ 预售商品列表；商品预售主数据维护 + 预售订单交易台账子标签，一行 = 一个活动下的一个预售商品。
- 截图：![商城预售](../../../../tool-results/ql361/pages/营销__商城营销__商城预售.png)

## 2. 页面配置

### 查询条件

- 筛选条件（活动名称）
- 商品（弹选）
- 起始时间、结束时间（默认本月：2026-07-01 ~ 2026-07-31）
- 活动状态（待开始,进行中,已结束——枚举实据）
- 创建人（弹选）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、查询、跳转（分页跳转）
- 行级操作（操作列存在，抓取时点无数据行，行级动作明细待复核）

### 打印配置

无（页面无打印按钮，截图确认）

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

操作、活动名称、商品名称、商品图片、货号、规格、型号、预售价、起始时间、结束时间、是否支付订金、活动状态、创建人

> JSON columns 首项即"操作"，无拼接串，13 列全部为真实列，与截图表头一一对应。

### 全部可配置列

待复核（未抓取列配置弹窗；"预售订单"子标签列结构待复核）。

## 4. 业务规范

- 预售模型（列实据归纳）：
  - 一行 = 活动 × 商品：活动名称与商品名称（+图片/货号/规格/型号）并列，同一预售活动可挂多个商品、同一商品可属多个活动
  - 预售价：预售商品独立定价（区别于日常售价与秒杀价/拼团价）
  - 是否支付订金（列实据）：订金开关——支持"订金 + 尾款"两段式预售（先付订金锁货，发货前收尾款），也可全额直购；订金比例与尾款期限在新增表单维护（待复核）
  - 活动状态枚举（下拉实据）：待开始 / 进行中 / 已结束
  - 交易侧："预售订单"子标签承接预售产生的订单台账（子标签实据），订金/尾款支付状态与发货节点待复核
- 与其他页面关系：商城域同组（商城拼团、商城秒杀与预售并列商城三大玩法）；与销售域"预订货单"的关系（销售域实据：预订货单 YDHD- 支持预订金）——商城预售面向线上商城买家、预订货单面向线下开单客户，两者是否归一待复核；本系统落地对应预售 `/api/erp/marketing/presale`（api/marketing.ts 实据）
