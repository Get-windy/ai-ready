| 页面 | 地址 | 说明 |

| 月结 | `finance/month-closing` | 期间选择 + 结转/关账状态 |

## 业务规范说明

- **月结流程**：期末结转（收入/费用转入本年利润）→ 检查平衡 → 关账。
- **关账后不可记账**：已关闭期间禁止新增凭证。
- **结转生成凭证**：期末结转损益生成凭证（本年利润 4103）。
