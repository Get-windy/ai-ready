# 利润表开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/profit-report`（报表页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **报表页**：按会计期间出具的损益报表（营业收入→逐级加减成本费用→利润，三级缩进行结构；期间参数 + 单报表格，无分页）。菜单路径：财务 → 财务报表 → 利润表。
- **数据实据**（单会计月 2026年7月，科目层级 2，本期发生额/本年累计）：一、营业收入 785,230.39/5,896,668.37；减：主营业务成本 625,175.35/4,767,610.95；加：其他业务收入 14,524.44/171,790.65；减：其他业务成本 13,732.67/198,093.29；销售费用 5.21/19,599.54；管理费用 94,978.06/815,804.29；财务费用 310.89/22,781.48（子项"利息…"第 24 行起视口截断，完整内容待复核）。

## 3. 数据表格列配置

### 默认显示列（抓取 JSON columns 实据，3 列）

项目、本期发生额、本年累计

> JSON columns 共 4 项，首项"项目 本期发生额 本年累计"为抓取时表头单元格拼接串，非真实单列，列数统计已剔除。与资产负债表（左右对照 6 列）不同，利润表为单表纵向 3 列。

### 行结构口径（截图实据）

- 三级缩进：一级项目（一、营业收入/减：主营业务成本/加：其他业务收入/减：其他业务成本，加粗带"减：/加："前缀）→ 费用科目小计（销售费用/管理费用/财务费用，加粗无前缀，中层级缩进）→ 明细子项（费用类型/收入明细，普通字体，深层缩进）
- 科目层级参数控制展开级次：层级 2 时费用科目展开到费用类型子项（管理费用展开 8 个子项实据）；层级 1 时仅小计行（推断，与资产负债表科目层级同规律，待复核）
- 报表口径：本期发生额=单会计月当月发生；本年累计=年初至止月累计
- 多会计月方式：按多个会计月并列出具（列结构待复核）
- 数字列右对齐，无链接样式（与资产负债表"期末余额链接穿透"不同，是否支持穿透待复核）
- 截图视口内可见 24 行（第 24 行"利息…"截断）；其后应有营业利润/利润总额/净利润等汇总行（按国内报表惯例推断，待复核补抓）

## 4. 业务规范

### 数据来源与取数逻辑

- 取数自损益类科目发生额（与科目余额表"本期发生额/本年累计"两口径对应）：本期发生额=会计月当月发生；本年累计=年初至止月累计
- 项目-科目映射实据：其他业务收入子项 进货退货差价/商品损溢收入/商品拆装收入 为业务预置明细；费用科目子项 优惠金额/包装费/配送费用/招待及应酬费用/市内交通费/门店费用/人员费用 等为费用类型档案（《费用类型开发文档》6403/6601/6602/6603 科目下的用户自定义费用项）
- 勾稽校验实据：各小计=子项合计，全部成立——其他业务收入 14,524.44=0+14,524.44+0；销售费用 5.21=−817.79+0+0+823；管理费用 94,978.06=0+20,000+0+0+16,534.13+621.81+57,822.12+0；本年累计同口径成立（171,790.65=6,211.28+165,609.84−30.47；19,599.54=5,450.01−10−30+14,189.53；815,804.29=八子项之和）
- 一级项目"一、营业收入 785,230.39"与科目余额表 6001 主营业务收入本期贷方 780,123.83 存在差 5,106.56（抓取时点/口径差异），精确映射公式（是否含 6051 其他业务收入或其他调整项）待复核
- 本期可见行合计粗算：785,230.39−625,175.35+14,524.44−13,732.67−5.21−94,978.06−310.89=65,552.65（不含截断行及后续项目）；与资产负债表未月结差额 58,891.00 的勾稽口径待复核
- 显示为0科目：勾选后本期/累计均为 0 的科目行也列示（未勾选时隐藏，截图实据多行子项为 0 仍显示，因其父级非 0——精确过滤规则待复核）
