## 4. 业务规范

- 积分规则模型（截图实据归纳）：
  - 积分流入三路：注册初始积分（开户即送）、会员生日倍积分（生日当天消费按 N 倍计）、消费积分（日常消费累计）；另有签到积分（线上签到玩法）
  - 消费积分两种算法互斥（单选）：按销售金额积分（全局统一比例，如 100 元=1 分）或按不同商品累计积分（商品级系数，"详细设置"维护）；勾选项"按折扣积分"决定按折前还是折后金额计积分（推断，具体口径待复核）
  - 积分规则=四舍五入：消费金额换算积分时的取整方式
  - 积分应用场景：线下开单 / 微商城 双通道，控制积分在哪些渠道产生与使用
  - 签到积分递增模型：首日 3 分、连续签到每日 +1、封顶 8 分；月历可视化直观呈现"连续签到越久单日得分越高、到顶持平"的递增曲线（3/4/5/6/7/8/8/8…）
  - 积分流出（积分抵现）：100 积分=1 元，单笔订单最高可抵扣金额 100%（即可全额抵扣，比例可调）；积分另一流出方向为《积分兑换开发文档》的礼品兑换
- 与其他页面关系：参数落点（《会员管理开发文档》的会员积分账户按本页规则累计与扣减；《积分兑换开发文档》消费积分余额）；销售开单联动（销售订单"会员信息"Tab：销售积分/兑换积分/使用积分/当前积分，按本页"积分应用场景-线下开单"启用；"微商城"对应 B2B 商城渠道）；"客户 | 会员管理"开关确认会员档案依托于客户（ERP 往来单位），与《会员管理开发文档》"会员是客户的扩展档案"互证
