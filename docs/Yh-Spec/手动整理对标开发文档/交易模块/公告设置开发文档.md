# 公告设置开发文档

> **文档类型：** 页面对标复刻（列表页 + 新增/编辑弹窗）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）商城模块
> **对标来源：** 顶部「商城」菜单 → 「商城设置」组 → 「公告设置」。**来源=对标系统实测抓取 2026-09-07**
> **定位：** 商城公告管理：列表查询 + 新增/编辑（标题+富文本内容）。即 XSMK 商城「商城设置 → 公告设置」。

## 页面概述

公告设置是**商城公告统一管理**页：管理展示在商城首页的公告，含查询、新增/编辑（公告标题 + 富文本公告内容）、发布/下线/删除。**单入口，列表页**（无子 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 公告设置 | `mall/notice-config` | 单视图列表页（筛选条件 + 公告数据表 + 新增公告弹窗） |

单入口：商城 → 商城设置 → 公告设置。

- 实测实据：**共 0 条记录**（当前租户无公告）、每页 20 行；顶部按钮=新增公告 + 打印(F8)；查询区=筛选条件（请输入公告名称）+ 查询；数据表列=勾选框/操作/公告名称/发布人/发布时间。

### 配置功能说明
- **列表结构**：公告设置为**单视图列表页**，无子 Tab。**无标准「页面配置」**（无查询条件/功能按钮 Tab 的配置齿轮），查询区与按钮区为固定项。
- **数据表列配置**：数据表右上角表头齿轮图标（`.icon-shezhi2`），弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**共 3 个可配置列，全部默认显示**。
- ⚠️ **当前实现说明**：本页当前为 `ARReportPage`（单表 + 顶部「新增公告」按钮，无列配置/页面配置弹窗、无打印），但已对齐金标准字段语义（标题/类型/内容/状态/排序/发布时间），见「实现差异说明 → 待完善」。

## 业务规范说明

- **公告主线**：商城公告（商家→买家端）发布后展示在商城首页；标题 + 富文本内容。
- **发布人/发布时间**：公告列表展示发布人与发布时间；新增公告默认未发布（草稿），发布后商城端立即可见。
- **状态流转**：金标准侧为「保存草稿 → 发布」二元（发布后下线），本系统已实现 0草稿/1已发布/2已下线 三态 + 发布/下线操作。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/mall/notice-config/index.vue`
- API：`apps/pc-admin/src/api/erp/mall.ts`（`mallNoticeApi`：`/erp/mall/admin/notice/page`、`POST /notice`、`PUT /notice/{id}`、`DELETE /notice/{id}`、`PUT /notice/{id}/publish`、`PUT /notice/{id}/offline`、`GET /notice/{id}`）
- 后端：`backend/erp/erp-mall/.../MallAdminNoticeController.java`（`@RequestMapping("/api/erp/mall/admin/notice")`）

### 页面对齐（已建成：`ARReportPage`）
- **列表**：当前为 `ARReportPage`，列=公告标题/类型/内容/状态/排序/发布时间/创建时间/操作。
- **查询区（3 字段）**：标题（input）、类型（select：公告/活动/系统）、状态（select：草稿/已发布/已下线）。**与金标准（仅筛选条件·公告名称）不一致**（本系统更丰富）。
- **头部按钮**：新增公告（`header-extra`）。
- **行级操作**：编辑、发布（状态≠1 时）、下线（状态=1 时）、删除（popconfirm）。
- **新增/编辑弹窗字段**：公告标题（限 100）、公告类型（1公告/2活动/3系统）、公告内容（textarea，限 500）、排序。
- **状态**：`status` 0草稿/1已发布/2已下线（`mall_notice.status`）；通知类型 `noticeType` 1公告/2活动/3系统。

### 待完善（非阻塞 · 建议对齐金标准）
1. **列配置弹窗**：`ARReportPage` → 升级 `CategoryListLayout` + `BillTableList` + `ColumnConfigPanel`；对齐金标准 3 列（公告名称/发布人/发布时间）。
2. **列对齐**：金标准仅「公告名称/发布人/发布时间」3 列（无类型/内容/状态/排序/创建时间/操作列配置项）；本系统当前 8 列。按需取舍（保留类型/状态列以便筛选）。
