> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页）：客户欠款按职员/客户/区域三维度汇总 + 超期欠款账龄五档分布（左侧部门分类树）；应收风控核心页。菜单路径：分析 → 采销分析 → 销售欠款分析。
- 页面结构：维度 Tab（按职员/按客户/按区域）+ 查询区（两行）+ 左侧部门分类树 + 汇总表格（超期欠款分布分组表头）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__销售欠款分析.png`

## 4. 业务规范

### 统计口径（欠款滚动 + 账龄）

- **欠款余额**=此前欠款+本期新增欠款−本期回款−结算优惠（杨生淮：-119,512.78+80,347.82−回款−162.99=-202,656.8，回款额隐含其中；负值=该职员名下客户净预存/超收，正值=净欠款）
- **此前欠款**：查询起始日前的累计未结；**本期新增欠款**：查询期内销售产生的未结金额；**结算优惠**：本期收款让利冲减欠款
- **超期欠款总额**：超过信用账期未结的金额；**账龄五档分布**：按超期时长归入 小于1个月/1-3个月/3-6个月/6-12个月/12个月以上（本批次全部为 0=无超期）
- **日期类型**：单据日期（默认）/其他日期口径（可选值待复核），决定欠款归属期口径

### 与其他页面关系

- 取数：销售出库单未结金额（应收）− 收款单已收 + 预收款抵扣；与《销售履约分析》"未结金额"同源
- 下游：《查应收》（单据级应收明细）、《往来余额表》（客户级应收应付净额）、《回款统计》（回款侧口径）
