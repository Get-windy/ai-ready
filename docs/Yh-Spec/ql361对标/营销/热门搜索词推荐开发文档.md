# 热门搜索词推荐开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`marketing/hot-keywords`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：商城搜索框热门推荐词的人工维护页——上限 20 个关键词，支持排序；轻量词表维护，无分页、无时间维度。
- 截图：![热门搜索词推荐](../../../../tool-results/ql361/pages/营销__商城营销__热门搜索词推荐.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入关键词模糊检索）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增关键词、查询
- 黄色提示条"最多新增20个热门关键词"
- 行级操作（操作列存在，抓取时点无数据行，行级动作明细待复核——据同类页面惯例为修改/删除）

### 打印配置

无（页面无打印按钮，截图确认）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据）

操作、关键词名称、排序、最后修改时间

> JSON columns 首项"操作 关键词名称 排序 最后修改时间"为抓取拼接串（表头合并单元格的文本拼接），非真实单列，已剔除，不计入列数。无分页栏（截图确认）——词表上限 20 条，一页呈现。

### 全部可配置列

待复核（未抓取列配置弹窗；本页列少，预计 4 列即全量）。

## 4. 业务规范

- 热词模型（实据归纳）：
  - 人工维护词表："新增关键词"按钮 + "最多新增20个热门关键词"提示条实据——热词由运营人工配置，非系统自动统计生成
  - 排序列：控制热词在商城搜索框下拉/推荐位的展示顺序
  - 最后修改时间：词表审计线索
  - 展示位置（推断，待复核）：商城（mobile-mall/B2B 商城）搜索框聚焦时展示推荐热词，点击直达搜索结果
- 与其他页面关系：商城营销组引流位（与商城弹窗广告首页弹窗互补，热词是搜索入口的引导位）；本系统落地对应热搜 `/api/search/hot`（api/marketing.ts 实据）
