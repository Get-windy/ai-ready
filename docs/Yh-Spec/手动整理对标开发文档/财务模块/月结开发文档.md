月结、批量月结、反月结。

### 数据表列配置

> 数据表内 `icon-shezhi2` → 列配置弹窗（个人/全局配置）。**全部可配置列含隐藏 + 默认显示列**。

全部配置数据列（5）：1会计年、2会计月、3开始日期、4结束日期、5状态。

对标默认显示（5）：会计年、会计月、开始日期、结束日期、状态。（全部显示，无隐藏列。）

### 期间（对标实测）
会计期间列表按账期列出：会计年 / 会计月 / 开始日期 / 结束日期 / 状态。

对标实测样例：`2026年 / 8月 / 2026-08-01 / 2026-08-31 / 未结账`（最新期间未结账）；`2026年 / 7月 / 2026-07-01 / 2026-07-31 / 已结账`；`2026年 / 6月 / … / 已结账`。

- 状态值：未结账 / 已结账。
- 行级操作：对「未结账」期间执行月结/批量月结/反月结。

## 业务规范说明

- **月结流程**：期末结转（收入/费用转入本年利润）→ 检查平衡 → 关账。
- **月结状态**：未结账 / 已结账；最新会计期间默认未结账，历史期间已结账。
- **关账后不可记账**：已关闭期间禁止新增凭证。
- **结转生成凭证**：期末结转损益生成凭证（本年利润 4103）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 期间单一口径（红线）**：月结为唯一关账入口，**严禁在已关闭期间新增/修改凭证**；关账前必须检查借贷平衡。
- **P1 结转**：期末结转损益经凭证（KJPZ-）转入本年利润 4103，不得直改科目余额。
- **P1 平衡校验**：结转/关账前校验借=贷，存在未平衡凭证阻止关账。
- **P2 验收**：无桩/无模拟；期间状态（未结账/已结账）、结转凭证、关账后禁止记账需真实数据闭环验证。
