## 4. 业务规范

### 统计口径（履约闭环）

- **发货履约率（%）** = 发货金额 / 订单价税合计 × 100（数量口径为 已发数量 / 订货数量；实测常见 100 与 0 两值）。实据：肃州区星港饮酒泉一中店 48 / 103 ≈ 46.6 ✅。
- **未发金额** = 订单价税合计 − 发货金额（实据：待发货单 `XSDD-20260915-005` 55 − 0 = 55 ✅；`XSDD-20260915-004` 380 − 0 = 380 ✅）。
- **未结金额** = 订单价税合计 − 已结金额（实据：`XSDD-20260915-005` 55 − 0 = 55 ✅；`XSDD-20260914-002` 380 − 380 = 0 ✅）。
- **订单状态**：审核中 → 待付款 → 待发货 → 发货完成 → 交易完成（与《订单处理中心》状态流转一致；彩色标签：待发货=处理中色、发货完成=橙/成功色、交易完成=绿）。
- **按单据 vs 按客户**：`按单据` 一行一销售订单（XSDD- 号段）；`按客户` 按客户聚合订单数、金额并给出合计行。
- **数据范围**：销售订单按订单日期过滤；`区域`/`部门`/`仓库`/`经手人`/`产生方式` 提供多维过滤。

### 与其他页面关系

- 取数：**销售订单 + 销售出库单（发货）+ 收款单（结算）三单关联**。
- 上游：《订单处理中心》（履约操作的执行端）、《销售出库单》（发货数量/金额来源）。
- 下游：《销售欠款分析》（未结金额 → 欠款口径）、《销售分析》（销售额/毛利口径）。
- 口径一致性：本页 `未结金额` 与《销售欠款分析》`欠款余额`同源（单 vs 汇总粒度）。
