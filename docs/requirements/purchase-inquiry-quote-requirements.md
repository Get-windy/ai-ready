## 🎯 背景与目标

### 背景
基于Odoo对比分析，现有ERP系统采购模块已具备基础的采购订单管理能力，但缺少完整的询价/报价管理流程。为实现端到端的采购流程管理，需要补齐询价/报价核心功能。

### 目标
1. 实现完整的采购询价流程管理
2. 支持多供应商同时报价
3. 提供报价比较与决策支持
4. 实现询价到采购订单的自动转化

## 👥 用户角色

| 角色 | 职责 | 主要操作 |
|------|------|----------|
| **采购申请人** | 提出采购需求 | 创建询价申请、查看进度 |
| **采购专员** | 执行采购流程 | 创建询价单、邀请供应商、比价分析 |
| **供应商** | 提供报价 | 接收询价、提交报价、查看状态 |
| **采购经理** | 审批与决策 | 审批询价单、确认中标、生成订单 |
| **财务专员** | 价格审核 | 查看报价、核对价格 |

## 🔄 业务流程

### 1. 采购询价主流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   创建询价   │ → │   发布询价   │ → │  供应商报价  │ → │   比价分析   │
│   (草稿)    │    │  (已发布)   │    │  (报价中)   │    │             │
└─────────────┘    └─────────────┘    └─────────────┘    └──────┬──────┘
                                                                  ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   完成关闭   │ ← │   生成订单   │ ← │   确认中标   │ ← │   审批决策   │
│  (已关闭)   │    │             │    │             │    │             │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 2. 询价单状态流转

```
                    ┌──────────┐
         ┌─────────→│  草稿    │←─────────┐
         │          │ (DRAFT) │          │
         │          └────┬────┘          │
         │    编辑/保存   │    提交审批    │
         │               ↓               │
         │          ┌──────────┐         │
         │    ┌────→│  待审批  │────┐    │
         │    │     │(PENDING)│    │    │
         │    │     └────┬────┘    │    │
         │  驳回          │          通过
         │               ↓
         │          ┌──────────┐
         │          │ 已发布   │←────邀请供应商
         └─────────→│(PUBLISH) │
                    └────┬────┘
                         │
                         ↓ 供应商报价
                    ┌──────────┐
                    │ 报价中   │
                    │(QUOTING) │
                    └────┬────┘
                         │
                         ↓ 截止/手动关闭
                    ┌──────────┐
              ┌────→│ 已关闭  │
              │     │(CLOSED) │
              │     └──────────┘
              │
              └──── 取消
                    ┌──────────┐
                    │ 已取消  │
                    │(CANCEL) │
                    └──────────┘
```

### 3. 报价单状态流转

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  已提交  │ → │  已审查  │ → │  已接受  │ → │ 生成订单 │
│(SUBMIT)  │    │(REVIEW)  │    │(ACCEPT)  │    │          │
└────┬─────┘    └────┬─────┘    └────┬─────┘    └──────────┘
     │               │               │
     │               │               └────→ 已拒绝 (REJECT)
     │               │
     └───────────────┴───────────────→ 已撤回 (WITHDRAW)
```

## 📊 功能需求

### F1. 询价单管理

#### F1.1 创建询价单
**功能描述**: 采购专员创建新的采购询价单

**输入字段**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 询价标题 | String | 是 | 最大200字符 |
| 询价类型 | Enum | 是 | 物资采购/服务采购/工程采购 |
| 紧急程度 | Enum | 否 | 普通/紧急/特急，默认普通 |
| 截止日期 | DateTime | 是 | 供应商报价截止时间 |
| 需求描述 | Text | 是 | 详细采购需求说明 |
| 采购部门 | Long | 是 | 关联部门ID |
| 采购专员 | Long | 是 | 负责人ID |
| 邀请供应商 | List<Long> | 否 | 预选供应商ID列表 |

**业务规则**:
- 询价单号自动生成，格式: INQ-YYYYMMDD-XXXX
- 创建时状态为"草稿"
- 截止日期必须晚于当前时间至少24小时

#### F1.2 询价单明细管理
**功能描述**: 管理询价单中的采购物资明细

**明细字段**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 物料名称 | String | 是 | 采购物料名称 |
| 规格型号 | String | 否 | 技术规格要求 |
| 计量单位 | String | 是 | 件/套/吨/米等 |
| 采购数量 | Decimal | 是 | 数量，精度4位 |
| 期望品牌 | String | 否 | 品牌偏好 |
| 质量要求 | String | 否 | 质量等级要求 |
| 交付地点 | String | 否 | 送货地址 |
| 备注说明 | Text | 否 | 特殊要求 |

#### F1.3 发布询价单
**功能描述**: 将草稿状态的询价单发布给供应商

**业务流程**:
1. 验证询价单完整性（标题、明细、截止日期）
2. 检查是否已选择至少1个供应商
3. 更新状态为"已发布"
4. 向供应商发送询价通知
5. 记录发布时间和发布人

**系统行为**:
- 自动生成询价单号
- 发送系统通知给被邀请供应商
- 可选：发送邮件/短信通知

#### F1.4 关闭/取消询价单
**功能描述**: 结束询价流程

**关闭场景**:
- 手动关闭：采购专员主动结束
- 自动关闭：到达截止日期自动关闭
- 取消：询价需求变更或错误创建

**业务规则**:
- 已有关报价的询价单不能"取消"，只能"关闭"
- 关闭后供应商不能再提交报价
- 取消后释放相关资源

### F2. 供应商报价管理

#### F2.1 接收与提交报价
**功能描述**: 供应商查看询价并提交报价

**报价单字段**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 报价单号 | String | 系统自动 | 格式: QUO-YYYYMMDD-XXXX |
| 关联询价 | Long | 是 | 询价单ID |
| 供应商 | Long | 是 | 供应商ID |
| 报价日期 | DateTime | 系统自动 | 提交时间 |
| 有效期至 | DateTime | 是 | 报价有效截止时间 |
| 付款条款 | Text | 否 | 付款方式说明 |
| 交付条款 | Text | 否 | 交货条件说明 |
| 质保条款 | Text | 否 | 质保承诺 |
| 竞争优势 | Text | 否 | 供应商自荐说明 |
| 附件 | List<File> | 否 | 资质文件/样品照片等 |

**报价明细字段**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 关联询价明细 | Long | 是 | 对应询价项 |
| 物料名称 | String | 是 | 供应商确认的物料名 |
| 规格型号 | String | 否 | 实际供应规格 |
| 计量单位 | String | 是 | 报价单位 |
| 报价数量 | Decimal | 是 | 可供应数量 |
| 单价 | Decimal | 是 | 含税单价，精度2位 |
| 税率 | Decimal | 否 | 默认13% |
| 品牌 | String | 否 | 实际供应品牌 |
| 产地 | String | 否 | 生产地 |
| 交货周期 | Integer | 否 | 天数 |
| 单项备注 | Text | 否 | 特殊说明 |

**自动计算**:
- 金额 = 数量 × 单价
- 税额 = 金额 × 税率 / 100
- 总金额 = 所有明细金额之和

#### F2.2 报价审查与评分
**功能描述**: 采购团队对供应商报价进行评估打分

**评分维度**:
| 维度 | 权重 | 分值范围 | 评分标准 |
|------|------|----------|----------|
| 价格得分 | 40% | 0-100 | 最低价得满分，按价格比例递减 |
| 质量得分 | 35% | 0-100 | 品牌、规格、资质综合评估 |
| 服务得分 | 25% | 0-100 | 交期、售后、历史表现 |
| **综合得分** | 100% | 0-100 | 加权平均 |

**评分公式**:
```
综合得分 = 价格得分 × 0.4 + 质量得分 × 0.35 + 服务得分 × 0.25
```

**审查记录**:
- 审查人、审查时间
- 各项评分
- 审查意见
- 是否推荐中标

#### F2.3 报价状态管理
**状态说明**:
| 状态 | 说明 | 可转换状态 |
|------|------|-----------|
| 已提交 | 供应商刚提交，待审查 | 已审查、已撤回 |
| 已审查 | 已完成评分评估 | 已接受、已拒绝 |
| 已接受 | 被确认为中标报价 | - |
| 已拒绝 | 未中标 | - |
| 已撤回 | 供应商主动撤回 | - |

### F3. 报价比较与决策支持

#### F3.1 比价分析功能
**功能描述**: 系统提供多维度报价比较分析

**比价视图**:
| 比较维度 | 展示内容 |
|----------|----------|
| 价格对比 | 各供应商单价、总价、税费对比 |
| 品牌对比 | 品牌档次、产地信息 |
| 交期对比 | 交货周期、交付承诺 |
| 综合评分 | 系统评分、推荐指数 |
| 历史对比 | 该供应商历史报价、履约率 |

**比价报告**:
- 最低价标识
- 性价比推荐
- 风险提示（异常低价/高价预警）

#### F3.2 决策支持功能
**功能描述**: 辅助采购经理做出采购决策

**决策辅助**:
- 自动推荐最优报价（综合评分最高）
- 价格趋势分析
- 供应商历史绩效参考
- 预算符合度检查

### F4. 采购订单生成

#### F4.1 自动转单
**功能描述**: 中标报价自动转为采购订单

**转单规则**:
- 接受报价后触发
- 复制询价单/报价单信息到采购订单
- 关联原询价单和报价单
- 生成采购订单号

**字段映射**:
| 询价/报价字段 | 采购订单字段 |
|--------------|-------------|
| 询价标题 | 订单标题 |
| 中标供应商 | 供应商 |
| 报价明细 | 订单明细 |
| 报价单价 | 订单单价 |
| 交付条款 | 交货要求 |
| 付款条款 | 付款条件 |

## ✅ 验收标准

### AC1. 询价单管理
- [ ] 可以成功创建询价单并自动生成编号
- [ ] 可以添加、编辑、删除询价明细
- [ ] 可以发布询价单给指定供应商
- [ ] 可以按状态、日期、采购员筛选查询
- [ ] 可以正常关闭或取消询价单
- [ ] 询价单状态流转符合业务规则

### AC2. 供应商报价管理
- [ ] 供应商可以查看被邀请的询价单
- [ ] 供应商可以提交完整的报价单和明细
- [ ] 报价金额、税额自动计算正确
- [ ] 可以对报价进行审查和评分
- [ ] 可以正常接受、拒绝或撤回报价
- [ ] 报价状态流转符合业务规则

### AC3. 比价分析与决策
- [ ] 可以查看同一询价单下所有报价的对比
- [ ] 比价分析包含价格、品牌、交期等维度
- [ ] 系统能自动计算综合评分
- [ ] 能自动推荐最优报价
- [ ] 可以正常确认中标报价

### AC4. 采购订单生成
- [ ] 接受报价后能自动生成采购订单
- [ ] 订单信息正确复制自询价单和报价单
- [ ] 订单与原询价单、报价单正确关联
- [ ] 生成的订单可以正常进入审批流程

### AC5. 性能与安全性
- [ ] 查询响应时间 <= 500ms
- [ ] 支持并发报价提交（100+并发）
- [ ] 数据权限控制正确（只能查看自己相关的数据）
- [ ] 操作日志完整记录
