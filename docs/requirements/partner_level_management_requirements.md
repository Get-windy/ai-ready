# 合作商等级管理需求规格说明书

## 1. 业务需求概述

### 1.1 业务目标
- 建立合作商等级管理体系，激励优质合作商
- 通过积分和等级机制提升合作商活跃度和忠诚度
- 实现差异化权益和优惠政策

### 1.2 核心业务场景
- 合作商注册和基础信息维护
- 合作商业绩统计和积分计算
- 等级评定和升级/降级
- 权益配置和优惠策略应用

## 2. 合作商等级体系设计

### 2.1 等级分类
- **普通合作商**：新注册或低活跃度合作商
- **银牌合作商**：月度交易额 ≥ 10,000元 或 年度累计 ≥ 50,000元
- **金牌合作商**：月度交易额 ≥ 50,000元 或 年度累计 ≥ 300,000元  
- **钻石合作商**：月度交易额 ≥ 200,000元 或 年度累计 ≥ 1,000,000元

### 2.2 等级评定规则
- **评定周期**：月度自动评定 + 年度综合评定
- **评定指标**：
  - 交易金额（权重60%）
  - 交易频次（权重20%）
  - 客户满意度（权重10%）
  - 合规性（权重10%）

## 3. 积分规则和算法

### 3.1 积分获取规则
- **基础交易积分**：每1元交易额 = 1积分
- **活跃度奖励**：月度登录 ≥ 15天，额外奖励100积分
- **推荐奖励**：成功推荐新合作商，奖励500积分
- **活动参与**：参与平台活动，每次奖励50-200积分

### 3.2 积分消耗规则
- **兑换商品**：积分商城商品兑换
- **服务升级**：优先客服、专属顾问等服务
- **培训课程**：免费参加高级培训课程

### 3.3 积分有效期
- 积分有效期为2年，到期自动清零
- 每年12月31日进行积分年度结算

## 4. 优惠策略和权益

### 4.1 各等级权益对比

| 权益项目 | 普通 | 银牌 | 金牌 | 钻石 |
|---------|------|------|------|------|
| 交易手续费 | 2.0% | 1.8% | 1.5% | 1.0% |
| 账期天数 | 7天 | 15天 | 30天 | 60天 |
| 专属客服 | ❌ | ✅ | ✅✅ | ✅✅✅ |
| 优先发货 | ❌ | ❌ | ✅ | ✅✅ |
| 培训课程 | 基础 | 基础+进阶 | 全部 | 全部+定制 |
| 营销支持 | ❌ | 基础物料 | 定制方案 | 全方位支持 |

### 4.2 动态优惠策略
- **季节性促销**：根据季节和节日调整优惠力度
- **业绩冲刺**：季度末业绩冲刺期间额外优惠
- **新品推广**：新产品上线期间特殊优惠政策

## 5. 数据模型设计

### 5.1 核心实体
- **PartnerLevel**：合作商等级定义
  - levelId, levelName, minScore, maxScore, description
- **PartnerPoints**：合作商积分记录
  - partnerId, points, validUntil, sourceType, transactionId
- **PartnerBenefits**：等级权益配置
  - levelId, benefitType, benefitValue, description
- **PartnerTransaction**：合作商业绩记录
  - partnerId, amount, date, status, category

### 5.2 关系模型
- 一对多：PartnerLevel → PartnerBenefits
- 一对多：Partner → PartnerPoints
- 一对多：Partner → PartnerTransaction

## 6. 接口设计

### 6.1 核心API接口
- `GET /api/partner/level/{partnerId}` - 获取合作商当前等级
- `GET /api/partner/points/{partnerId}` - 获取合作商积分详情
- `POST /api/partner/points/calculate` - 计算合作商积分变动
- `PUT /api/partner/level/evaluate` - 触发等级重新评定
- `GET /api/partner/benefits/{levelId}` - 获取指定等级权益列表

### 6.2 业务流程接口
- `POST /api/partner/transaction/record` - 记录合作商业绩
- `POST /api/partner/points/redeem` - 积分兑换申请
- `GET /api/partner/promotion/current` - 获取当前可用优惠

## 7. 业务流程

### 7.1 等级评定流程
1. 系统每日统计合作商业绩数据
2. 月末触发等级评定计算
3. 根据积分和业绩确定新等级
4. 自动更新合作商等级信息
5. 通知合作商等级变更结果

### 7.2 积分管理流程
1. 交易完成后自动计算基础积分
2. 系统定期检查活跃度并发放奖励积分
3. 合作商可查看积分明细和有效期
4. 支持积分兑换和消耗操作
5. 年度积分结算和清理

## 8. 技术实现建议

### 8.1 性能优化
- 积分计算采用异步队列处理
- 等级评定使用定时任务批量处理
- 关键查询接口增加缓存层

### 8.2 数据一致性
- 使用分布式事务保证积分变动一致性
- 建立积分变动审计日志
- 实现数据回滚机制

### 8.3 扩展性考虑
- 等级规则配置化，支持动态调整
- 权益类型可扩展，支持新增权益类型
- 积分规则引擎化，支持复杂计算逻辑
