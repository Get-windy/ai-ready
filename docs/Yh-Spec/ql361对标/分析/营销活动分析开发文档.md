> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/mkt-activity-analysis`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页）：四类促销活动（商品促销/整单促销/特价/优惠券）的参与与让利效果统计；营销活动的投入产出分析页。菜单路径：分析 → 营销分析 → 营销活动分析。
- 页面结构：活动类型 Tab（4 个）+ 查询区（两行）+ 活动效果表格（13 列）+ 底部分页。
- 页面截图：`tool-results/ql361/pages/分析__营销分析__营销活动分析.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels 为空 + 截图/bodyPreview 实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 活动名称、日期范围（起 至 止）、活动状态（下拉，默认"全部"）、活动类型（下拉，默认"全部"）、活动范围（下拉，默认"全部"）

- 查询、跳转（分页跳转）

### 打印配置

- 无（本页无打印按钮实据）

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

操作、活动名称、日期、活动状态、参与订单数、参与客户数、商品购买数量、优惠金额、惠后订单金额、赠品数量、客单价、活动类型、活动范围

> JSON columns 首项"操作"经截图核对为真实首列，非抓取拼接串，计入列数。

### 全部可配置列

- 未抓取（列配置弹窗探针待复核）

## 4. 业务规范

### 统计口径（活动效果）

- **四类活动**：商品促销（单品级）/整单促销（整单满减满赠）/特价（直接特价）/优惠券（领用核销）
- **参与口径**：参与订单数/参与客户数（去重）/商品购买数量（活动商品销量）
- **让利口径**：优惠金额（活动让利总额）、惠后订单金额（折后实收）、赠品数量（随单赠品）
- **客单价**=惠后订单金额/参与订单数
- **活动状态**：未开始/进行中/已结束/已停用（可选值待复核）；**活动范围**：全部客户/指定客户/指定区域等（可选值待复核）

### 与其他页面关系

- 取数：营销活动主数据 + 销售订单活动关联明细
- 同源页：《销售费用分析》（促销活动费用列=本页优惠金额的财务口径）、《营销推广分析》（推广侧分享/浏览口径）
