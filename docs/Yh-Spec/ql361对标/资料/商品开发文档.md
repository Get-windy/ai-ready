## 1. 页面概述

- **列表页**：商品主数据档案列表，含新增/导入/云导入；左侧商品分类树 + 查询区 + 数据表格；4 个子标签（全部商品 / 套餐 / 商品上架 / 商品授权）。

## 2. 页面配置

### 查询条件

- 筛选条件（商品名称/货号/条码/规格/型号，单框多字段模糊匹配）
- 品牌（选择器）
- 新增日期（起）、新增日期（止）
- 显示状态（默认"已启用"）
- 使用优惠券（全部）
- 是否标品（全部）
- 所属行业类别（全部）
- 勾选项：显示层次结构
- 左侧商品分类树按分类过滤
- JSON filterLabels 实据为"品牌"+ 20 个"更多"占位，对应查询配置区折叠字段，全量查询条件待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、导入、云导入、刷新、打印(F8)、导出、更多、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、停用、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（15 列，抓取 JSON columns 实据）

操作、图片、商品名称、商品货号、所属行业类别、条码、规格、型号、产地、品牌、单位、可用库存、换算关系、餐饮店、备注

> JSON columns 首项"操作 图片 商品名称 商品货号 所属行业类别"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。"餐饮店"为用户自定义价格等级昵称列（价格等级 8 昵称之一：餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip），需按标准化产品价格等级处理（与销售域一致）。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 显示状态：已启用/停用，行级"停用"操作停用商品；查询默认只显示"已启用"
- 是否标品：区分标准品与非标品
- 使用优惠券：商品级优惠券开关，与营销域优惠券联动
- 4 子标签分工（截图实据）：全部商品（档案总表）、套餐、商品上架（商城上架管理）、商品授权（待复核）
- 换算关系：商品多单位换算（如 1箱=12瓶），条码/价格按单位分别维护（见商品条码、商品价格管理页）
- 与其他页面关系：新增 → 商品档案表单页（本次未抓取，待复核）、商品条码（按商品×单位维护条码）、商品价格管理（按商品×单位维护价格档案）、图片管理（按商品维护图片）、商品辅助资料（品牌/单位/标签来源）、商品货位设置（推荐货位）、销售订单/采购订单等单据录单引用商品档案
