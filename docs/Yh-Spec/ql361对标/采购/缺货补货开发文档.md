## 业务规范说明

### 状态流转与特殊交互

- **缺货数量公式**（截图实据）：缺货数量 = 待发货数量 − 账面库存；公式以查询区下拉框呈现，可切换（备选公式待复核）
- **统计口径**：仅统计时间范围内已审核生效的销售订单；待审批、已取消、已驳回订单不参与统计（页面提示实据）
- **仅显示缺货商品**：默认勾选，去掉勾选则显示全部有订单的商品（含不缺货的）
- **采购按钮**：勾选表格行后点击"采购"，将选中商品按缺货数量转入采购流程（生成采购订单的具体跳转与携带字段待复核）
- 列口径：订单数量/价税合计为销售订单侧汇总；已发货数量、待发货数量、待收货数量、账面库存为实时库存口径

### 与其他页面关系

- 数据源：销售订单（待发货缺口）+ 实时库存 + 采购在途（待收货数量）
- 下游：采购按钮 → 采购订单（具体生成方式待复核）
- 同组姊妹页：库存预警补货（按仓库上下限预警）、智能补货（按日均销量推算）、以销定购（按销售订单逐单转采购）

### 供应商来源

供应商来源通过 ERP 模块的往来单位下的供应商分类处理。
