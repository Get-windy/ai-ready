> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/purchase-analysis`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页，图表优先）：采购订/采/退三段金额与单数统计（按时间/按商品/按供应商三维度，默认图表视图 + 七项指标卡片）；采购侧与销售分析对称的量额分析页。菜单路径：分析 → 采销分析 → 采购分析。
- 页面结构：指标卡片行（七卡两色）+ 维度 Tab + 粒度切换（按天/按周/按月）+ 折线趋势图（ECharts 工具栏：区域缩放/柱状切换/还原/下载）。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__采购分析.png`

## 4. 业务规范

### 统计口径（采购三段）

- **订→采→退三段**：采订单数/订单优惠后金额（采购订单 CGDD- 口径）→ 采购单数/采购优惠后金额（采购入库单 CGRKD- 口径）→ 退货单数/采购退货折后金额（采购退货单口径）
- **实采金额**=采购优惠后金额−采购退货折后金额（本周 71,489.00−0.00=71,489.00 ✅）
- 与《销售分析》对称：销售侧为 销售额→退货额→销售收入，采购侧为 采购优惠后金额→退货折后金额→实采金额

### 与其他页面关系

- 取数：采购订单/采购入库单/采购退货单（经营历程流水）
- 下游：《采购准备》（补货建议→采购执行闭环）、《查应付》（采购未结口径）、《进销存分析》（入库侧数量金额）
