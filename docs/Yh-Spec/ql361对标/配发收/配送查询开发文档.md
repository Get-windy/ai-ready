# 配送查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`dispatch/query`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：配送任务台账查询——按"全部配送任务"单一视图查询配送任务执行与收发货汇总；无统计卡片、无新增按钮、无阶段 Tab，纯查询定位。
- 单入口（无历史/添加标签）。
- 截图：![配送查询](../../../../tool-results/ql361/pages/配发收__配送业务__配送查询.png)

## 2. 页面配置

### 查询条件

按抓取 JSON 实据（filterLabels：配送司机、配送车辆、送货员、制单人）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、近两日、近一周、近一月、本周、上周、本月、上月（9 段，比销售域多"近两日/近一月/上周"）
- 日期范围（起 至 止）、配送状态（多选：待配送,配送中,已配送）、配送司机、配送车辆、送货员、任务编号
- 备注、配送单据编号、制单人、制单时间（起 至 止）
- 勾选项：显示红冲

### 功能按钮

按抓取 JSON buttons 实据：刷新、批量打印、打印(F8)、导出、查询、跳转（分页跳转）

### 打印配置

待复核（抓取数据未覆盖打印配置弹窗；页面有批量打印与打印(F8)按钮，打印模板配置细节待复核）。

## 3. 数据表格列配置

### 默认显示列（21 列，抓取 JSON columns 实据）

操作、指定配送日期、任务编号、配送状态、配送开始时间、配送结束时间、司机名称、配送车辆、送货员、配送单量、订金金额、退货单量、发货数量、发货金额、退货数量、退货金额、装箱数量、配送里程(km)、备注、制单人、制单时间

## 4. 业务规范

- 一行 = 一个配送任务（任务编号），按"指定配送日期"计划、按"配送开始时间/配送结束时间"记录实际执行；配送状态三值：待配送、配送中、已配送。
- 执行资源：司机名称、配送车辆、送货员（司机与送货员为两个角色，可不同人）。
- 任务聚合双向单量：**配送单量 / 订金金额**（正向发货侧）与**退货单量**（退货带回侧）；**发货数量/发货金额** 与 **退货数量/退货金额** 成对统计——同一配送任务既送新货又带回退货。
- **装箱数量**：任务维度装箱总量；**配送里程(km)**：任务行驶里程，供司机绩效/费用核算。
- 显示红冲勾选：被红冲的任务/单据默认隐藏，勾选后显示。
- 与源单关系：配送任务的上游是发货环节——销售订单经订单处理中心"拣货/发货"（物流发货入口）发货后生成销售出库单（XSCKD，见《发货查询开发文档》），配送任务按配送日期+司机/车辆组织出库单的配送；退货侧源单为销售退货单——配送带回的退货计入"退货单量/退货数量/退货金额"，收货确认走《物流退货收货开发文档》。查询条件"配送单据编号"可按任务内具体单据检索，即任务与单据为一对多。
- 上下游：上游物流发货（订单处理中心拣货/发货阶段直达）、发货查询（销售出库单台账）；同域物流退货收货（退货回流的收货确认）；本系统落地对应 DMS 配送管理模块（配送任务/司机/车辆/路线/里程），配送状态与司机端（driver-delivery）任务执行联动。
