# 商品条码开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：无独立条码页（条码在商品档案内维护），对应关系待复核
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：商品×单位维度的条码档案维护与条码打印页，左侧商品分类树 + 查询区 + 数据表格；一行 = 一个商品的一个单位，条码按单位分别维护。
- 截图：![商品条码](../../../../tool-results/ql361/pages/资料__商品管理__商品条码.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入商品名称/货号/条码）
- 条码（全部）
- 上架状态（全部）
- 显示状态（已启用）
- 新增时间（≥，日期控件，带月份/年份切换浮层）
- 采购日期（≥）
- 左侧商品分类树按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：刷新、打印(F8)、条码打印、导出、查询、跳转（分页跳转）
- 注：JSON buttons 中"七月、2025、2026、2027"为抓取时日期浮层控件的误捕获，非真实功能按钮；无"新增"（条码随商品/单位维护）
- 行级操作（截图确认）：修改

### 打印配置

无（抓取未覆盖打印配置弹窗；"条码打印"为独立功能按钮，条码标签模板配置细节待复核）

## 3. 数据表格列配置

### 默认显示列（8 列，抓取 JSON columns 实据）

操作、图片、商品名称、货号、单位、换算关系、上架状态、条码

> JSON columns 首项"操作 图片 商品名称 货号"与中段"单位 换算关系 上架状态 条码"均为抓取拼接串（表头快照），非真实单列；末尾"七月、日、一、二、三、四、五、六"为日期浮层误捕获。以上均已从列数统计剔除。

### 全部可配置列

> 2026-09-11 Playwright 实测复核（列配置弹窗实抓）：**全部 12 列** =
> 图片、商品名称、货号、单位、换算关系、上架状态、条码、规格、型号、产地、新增时间、最近采购日期。
> 默认显示 7 列（图片 ~ 条码），隐藏 5 列（规格、型号、产地、新增时间、最近采购日期）。
> 弹窗 Tab：个人配置 / 全局配置，底部 上移 / 下移 / 恢复默认 / 保存。

## 4. 业务规范

- 数据粒度：一行 = 商品 × 单位；商品多单位（瓶/箱/袋）各自持有独立条码与换算关系（截图实据：同一商品多行，换算关系"1箱=12瓶""1箱=4袋"等）
- 上架状态：已上架/未上架，指商品在商城的上架状态，与商品页"商品上架"子标签联动
- 条码打印：选中行批量打印条码标签（扫码枪/标签机场景）
- 无"新增"按钮：条码随商品档案及单位维护产生，本页仅维护与打印（行级"修改"）
- 与其他页面关系：商品（条码源数据在商品档案按单位维护，本页为条码维度视图）、商品货位设置（共享"条码（全部）"查询条件与"条码打印"按钮）、商城/销售录单（扫描枪录入按条码匹配商品+单位）

## 5. 实现差异说明（本系统 · 2026-09-11 金标准实现）

- **后端**：`ProductBarcodeController` 新增 `GET /api/erp/product/barcodes/page`（商品×单位分页）、`GET /export`（真实 xlsx）、`PUT /unit/{unitId}`（行级改条码 + 唯一性校验 + 双口径落库）；查询层 `ProductBarcodeQueryMapper`（递归分类 CTE / 关键词 / 上架与显示状态 / 新增时间≥ / 采购日期≥）。
- **数据源**：主 `erp_product_unit`（一行一单位，单位名/换算关系/条码），条码为空时回退 `erp_product_barcode` 默认记录；**未新建任何表或列**，符合"不另建重复条码表"红线。
- **前端**：`views/md/barcode/index.vue` 由桩页重写为 `CategoryListLayout`（只读分类树）+ 工具栏（刷新/打印(F8)/条码打印/导出）+ 6 项查询 + `BillDetailTable`（列配置 12 列/默认 7，存储键 `md-barcode-list-columns`）+ 分页 + 行级「修改」弹窗 + 条码打印（零依赖 Code128-B SVG 标签，可扫描）。
- **差异项**：
  1. 「条码」下拉选项未能从对标稳定抓取，本系统取 全部 / 已设置条码 / 未设置条码（后端兼容按条码类型过滤）——列为待复核。
  2. 对标行级「修改」弹窗字段未抓取到实据，本系统按业务最小集实现：商品/货号/单位/换算关系（只读）+ 条码 + 条码类型。
  3. 「最近采购日期」取已入库(8)/已完成(9)采购入库单最大单据日期。
- **验收**：接口 + 页面 E2E 见 `tools/e2e-barcode.cjs`，截图 `tool-results/md-barcode/`。
