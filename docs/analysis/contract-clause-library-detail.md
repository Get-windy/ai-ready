## 八、条款智能匹配规则

### 8.1 基于合同类型的自动匹配
```yaml
采购合同:
  - 必选: GL-001~009, PC-001~003, QC-001, BC-001~003
  - 条件匹配:
    - 金额>100万: 增加QC-002, SG-001
    - 技术产品: 增加TC-001~004
    - 长期合作: 增加PC-004, PC-005

销售合同:
  - 必选: GL-001~009, SC-001~004, QC-001, BC-001~003
  - 条件匹配:
    - 代理销售: 增加SC-005~007
    - 技术服务: 增加SV-001~006
```

### 8.2 基于金额的风险匹配
```yaml
风险分级:
  - 低风险(<50万): 基础条款包
  - 中风险(50-500万): 基础+质量控制+违约责任扩展
  - 高风险(>500万): 基础+全风险条款+担保条款
```

### 8.3 基于行业的特殊匹配
```yaml
行业特殊:
  - 制造业: 增加QC-003, PC-008
  - 医药业: 增加QC-003~004
  - 软件业: 增加IP-001~007
  - 建筑业: 增加SG-001~002
```

---

**条款库管理说明**：
1. 本条款库将集成到合同管理系统中
2. 条款支持在线编辑和版本控制
3. 系统可根据合同参数自动推荐条款组合
4. 法务人员可对条款进行审核和调整

**更新计划**：
- 每季度更新一次条款库
- 基于业务反馈和法律变化调整条款
- 增加新的行业特定条款
