## 6. 快速开始

### 6.1 准备测试数据

```bash
# 运行测试数据准备脚本
psql -U postgres -d qizhilian_test -f data/prepare_test_data.sql
```

### 6.2 运行测试

```bash
# 手动测试
1. 登录测试环境
2. 进入对账模块
3. 执行对应测试用例

# 自动化测试
python run_tests.py
```
