# 收款单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/receipt-doc/form`（表单）+ `finance/receipt`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页**：对结算单位的待收款单据批量收款核销。页面性质 = 表头收款字段区 + 待收款单据明细表格 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/receipt-doc/form`；标签「历史」→ `finance/receipt`（收款单列表页）。
- 单号实据：NO. SKD-20260723-034（SKD- 前缀 + YYYYMMDD-序号）。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：结算单位\*、经手人\*（另有单据日期\* 截图确认必填）
- 收款区：收款账户、收款金额（带"全/清"）、更多账户
- 预收抵扣区：此前预收（只读）、可用预收、使用预收款、预收款余额（只读）
- 应收区：此前应收（只读）、应收余额（只读）
- 调整区：优惠金额、多收金额

> 表头三行布局实据：第一行 结算单位\*/经手人\*/单据日期\*/此前应收（只读）/收款账户/收款金额（全/清）；第二行 更多账户（…弹窗）/此前预收（只读）/可用预收/使用预收款/应收余额（只读）/预收款余额（只读）；第三行 优惠金额/多收金额。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿可改；记账后收款生效——回写各待收款单据"已结算/待审金额/未结算"（按单收款页口径），并自动生成会计凭证（KJPZ-；明细账摘要实据"由[收款单 SKD-…]…"）
- 无结算收款单核销(0)：对历史已记账但未勾选核销单据的收款单做事后补核销，按钮带未核销计数（与按单收款页同名按钮一致）
- 查看已结算单据：明细区从"待收款"切换查看已收款核销完成的单据
- 自动分配：把收款金额按明细单据顺序/未结算金额自动分摊到"本次结算"（自动分配后仍可手调）
- 收款金额守恒：本单金额（收款金额+使用预收款+更多账户）= Σ本次结算 + 多收金额；优惠金额计入"本次优惠"核销应收但不产生资金
- 预收抵扣：选定结算单位后自动带出此前预收/可用预收；"使用预收款"从预收余额抵扣应收，抵扣后"预收款余额=此前预收−使用预收款"、"应收余额=此前应收−本次结算−本次优惠"实时联动（预收"收→抵→退"主线中的"抵"环节）
- 多收金额：收款超过应收部分转为客户预收（预收"收"环节的补充入口）
- 上游：《按单收款开发文档》行级"收款"进入本页；待收款单据=销售出库单（XSCKD-）/销售退货单（XSTHD-）等应收来源
- 预收来源：《预收款单开发文档》（YSKD-）；订金/预订货款见销售域（使用预订货款）
- 职员经手单据须先在《账款交账开发文档》交账方可被选择（按单收款页提示实据）
- 下游：记账生成会计凭证（KJPZ-）→ 总账/明细账/科目余额表/辅助核算余额表（应收账款 1122 核算项=往来单位）
- 本系统前端目录 `finance/receipt`、`finance/receipt-doc`（dynamicRoutes.ts 实据）
