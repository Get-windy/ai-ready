# 采购订货收货开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`dispatch/purchase-receive`
> 对标菜单：**配发收 → 收货业务 → 采购订货收货**（实测 menuId `40001`，billType `230101`）
> 数据来源：**Playwright 实测抓取（2026-09-12）**——双 Tab 分别抓列配置弹窗 + 页面配置弹窗 + 页面结构 + 截图。
> 通用规范见《对标开发技术参考文档》第 4、5 章，本文不重复。

## 1. 页面概述

- **列表操作页（入口直达型）**：实测点击「采购订货收货」打开的是 **「收货处理」**——采购订货的**待收货 / 部分收货跟踪工作台**，支持「批量收货」。
- **双 Tab**：`按单据`（表头默认 12 列）/ `按明细`（表头默认 16 列），两 Tab 各有独立列配置与页面配置。
- 落地时应复用采购收货处理视图组件，不重复造页面。
- 截图：`tool-results/ql361/pages/配发收__收货业务__采购订货收货.png`

## 4. 业务规范

- **本页 = 采购收货处理工作台**：跟踪采购订货的**订货数量 / 已收货数量 / 待收货数量**（按明细）与**应收数量 / 未收数量**（按单据）。
- **批量收货**：工具栏「批量收货」对多选单据执行收货；收货后生成**采购入库单**（见《采购入库单开发文档》）。
- **状态**：单据状态（如 待收货 / 部分收货 / 已收货）+ 结算状态分列跟踪。
- **往来单位口径**：往来单位 + 结算单位（含隐藏的往来编号/结算单位编号）——采购单据可采用不同结算主体。
- **数量列口径差异**：按单据默认显示「应收数量/未收数量」（隐藏「已收数量」）；按明细默认显示「订货数量/已收货数量/待收货数量」——两 Tab 的收发货数量命名不同，落地时需分别映射。
- **商品扩展列**：按明细含 货号/条码/规格/型号/产地/品牌/大中小包装/换算关系/优惠折扣/优惠后单价金额（多数隐藏）。
- **预计收货日期**：按单据默认显示，用于收货排程。
