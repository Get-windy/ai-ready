# 商品辅助资料开发文档

> **文档类型：** 页面对标复刻（本系统已完成代码，⚠️ 与对标 Tab 数有差异）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按仓储模块金标准结构编写；商品辅助资料（品牌 / 单位 / 标签）多 Tab 组合页。

## 页面概述

商品辅助资料用于维护**商品的辅助主数据**：品牌、单位、标签。为多 Tab 组合页（单入口，仅读列表 + 弹窗编辑）。

> **⚠️ 对标实测为 3 个子标签**：商品品牌、商品单位、商品标签。**无「商品分类」Tab**（与初稿/本系统的 4 Tab 不同）—— 商品分类在 ql361 中由独立菜单/主数据承载，不在本页。

| 子标签 | 说明 |
|--------|------|
| 商品品牌 | 品牌名称/助记码/备注（新增/编辑） |
| 商品单位 | 商品单位/助记码/计量单位备注/是否默认（新增/单位组管理） |
| 商品标签 | 标签名称/对应商品（数据表） |

菜单：资料 → 商品管理 → 商品辅助资料。

> 本系统菜单 `component` 指向 `views/md/product-supplement/index.vue`（`views/md/product-aux` 为历史桩目录）。

### 配置功能说明

- **3 Tab**：商品品牌、商品单位、商品标签；每 Tab 独立增删改。
- **数据表**：各 Tab 为 `BillDetailTable` 风格数据表 + 搜索区。
- ⚠️ **当前实现说明**：本系统页面为 `PageContainer` + 居中 Tab + `BillDetailTable`/`ColumnConfigTable` + `StandardPagination`，各 Tab 用 `a-modal` 编辑。

## 业务规范说明

- **品牌**：`erp_product_brand`（`productBrandApi.page` 分页）；品牌名称必填，可用于商品表单「品牌」下拉。
- **单位**：`erp_product_unit_dict`（`productUnitDictApi.page` 分页）；该单位字典为商品表单「单位组」数据源。
- **标签**：`erp_mall_tag`（`mallTagApi.list`）；「对应商品」经商品选择器关联。
- **分类**：`erp_product_category`（`productCategoryApi`，树形）；分类编码留空自动生成；赋 `parentId` 建层级。（⚠️ 本系统 4 Tab 含分类树；对标实测 3 Tab 无分类，分类为独立主数据。）
- **助记码**：品牌/单位可自动生成助记码（`useMnemonicCode`）。
- **状态**：品牌/单位默认启用（status=1）。
