> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-damage`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：库存损耗/报废出库录单，编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **单入口**：仅表单页。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：出库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（出库仓库/经手人/单据日期）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记帐后生效扣减库存。
- 数量列名为「报损数量」（区别于通用「数量」），按批次报损（批次条码/生产日期/保质期/到期日期列齐备）。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 报损金额按成本计价计入本单金额（列中无单价/金额列，金额取库存成本，待复核）。
- 与报溢单互为反向单据（一损/一溢）；盘点单的盈亏处理可生成报损单/报溢单（盘点单「盘点处理」流程推断，待复核）。
- 记帐后影响 分析→仓配分析→查库存/库存明细。
