# 借出单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`wh/borrow-out`（表单）+ `wh/borrow-out/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：将商品借给往来单位出库录单（后续需还回），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 预计还回时间 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `wh/borrow-out`；标签「历史」→ `wh/borrow-out/index`。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + _desktop.tabBar + 截图确认）

- 必填：往来单位\*、出库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 表尾：预计还回时间（日期选择）
- 摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（往来单位/出库仓库/经手人/单据日期）→ 商品明细表格 → 预计还回时间 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

### 全部表单字段

抓取数据仅覆盖默认显示字段；列配置弹窗全量字段无 XSMK 存档依据，待复核。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 4. 列表页配置（双入口「历史」标签）

- 查询条件（对标系统实据）：日期、单据编号、往来单位、仓库、经手人、部门、单据状态、还回状态（还回数量/还回金额列实据，XSMK 依据）
- 功能按钮（默认全选）：新增、刷新、打印(F8)、导出、配置
- 按单据列（18 列，对标实据 2026-08-14 + XSMK 依据）：单据日期、单据编号、单据状态、仓库、往来单位、往来单位编号、经手人、部门、借出数量、借出金额、预计还回时间、已还数量、已还金额、单据备注、制单人、审核人、打印次数
- 按明细列（14 列）：单据日期、单据编号、商品名称、货号、单位、借出数量、借出单价、借出金额、已还数量、已还金额、批次条码、生产日期、到期日期、单据备注

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后商品出库（借出库存，待还回）。
- 预计还回时间：约定归还日期，供借进借出查询跟踪逾期。
- 借出后续（借出商品查询子标签实据推断）：还回（还回入库）或借转销售（推断，待复核）。
- 往来单位必填（借出必有借入方）；借出数量不得超过可用库存；批次条码列齐备：按批次借出。
- 反向单据：借进单（从往来单位借入，预计还出时间）；台账查询：借进借出查询（借进商品查询/借出商品查询双子标签）。
