> **文档类型：** 页面对标复刻

## 页面概述

退货申请处理是**商城退货申请（售后）受理工作台**：对商城订单的退货申请进行查询、审批（通过/拒绝）、完成、收退货处理。**单入口**，含 **2 个视图 Tab**（按单据 / 按明细）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 退货申请处理 | `mall/return-process` | 复合页（列表 + 2 Tab：按单据 / 按明细） |

单入口：商城 → 订单处理 → 退货申请处理。

- 实测实据：按单据 Tab 当前账号 0 条记录（`共 0 条记录`，第 0/0 页）。
- 单号前缀：退货申请单（对标校验：qi360/ql361 商城退货申请，本系统沿用销售退货申请 `SaleReturn`）。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区（「配置」齿轮）；列配置在数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）。

- ⚠️ **当前实现说明**：本页**尚未升级金标准组件**（当前为 `ARReportPage`，单 Tab、无列/页面配置弹窗），见「实现差异说明 → 待完善」。

## 业务规范说明

- **退货主线**：商城订单发货后客户申请退货 → 本页受理（审批通过/拒绝）→ 完成。退货类型区分（售后退货）。
- **行级操作**：详情（弹窗）、通过（审批通过）、拒绝（必填原因）、完成（已完成状态可操作）。
- **金额/数量口径**：退货数量（明细退货数量合计）、退货金额（单价×数量合计）、本单金额=退货金额+费用；已结金额=已结算部分。
- **收货**：订货数量/已收数量/未收数量（收货进度跟踪）。
- **关联**：来源订单（来源单据）关联商城订单；结算状态（未结算/已结算）。
- **审批流**：状态流转 草稿→待审批→已审批→已完成→已取消；审批通过后进入完成，完成即办结。

## 实现差异说明

**实现文件**：
- 前端：`views/mall/return-process/index.vue`
- API：`api/erp.ts`（`saleReturnApi`：`/erp/sale/return/page`、`/{id}`、`/{id}/items`、`/{id}/approve`、`/{id}/reject`、`/{id}/complete`、`/export`）。⚠️ 注意：本页**复用销售退货单 API**（`/erp/sale/return/*`）而非独立商城退货 API；`api/erp/mall.ts` 亦存在 `/erp/mall/admin/return/*`（approve/reject/batch-approve/batch-reject）但当前页面未接入。

### 页面对齐（已建成：`ARReportPage`）
- **单 Tab 列表**：当前为 `ARReportPage`，**无按单据/按明细双 Tab**。
- **查询区（4 字段）**：关键字（退货单号）、客户（客户名称）、状态（全部状态）、申请日期（日期范围）。**仅有 4 个查询字段，未对齐金标准 16/17 字段**。
- **数据表列（9 列）**：退货单号、客户名称、退货仓库、退货数量、退货金额、退货原因、状态、申请时间、操作（详情/通过/拒绝/完成）。
- **详情弹窗**：退货单号/状态/客户名称/退货仓库/退货数量/退货金额/制单人/审核人/申请时间/审核时间/退货原因/备注 + 退货明细表（商品编码/商品名称/规格/单位/退货数量/单价/金额/退货原因）。
- **退货单状态映射**：0草稿/1待审批/2已审批/3已完成/4已取消。
- **行级操作**：详情、通过（`status=1` 待审批）、拒绝（必填原因，退回草稿）、完成（`status=2` 已审批）。
