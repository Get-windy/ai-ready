## 执行指南

### 1. 环境准备

```bash
# 1. 确保已安装Java 17
java -version

# 2. 确保已安装Maven
mvn -version

# 3. 配置测试环境
# 编辑 src/test/resources/application.properties
```

### 2. 执行测试

```bash
# 进入项目目录
cd I:\AI-Ready\tests\api-automation

# 编译项目
mvn clean compile

# 执行所有测试
mvn clean test

# 执行指定模块测试
mvn test -Dtest=AuthApiTest
mvn test -Dtest=PurchaseApiTest
mvn test -Dtest=CustomerApiTest
mvn test -Dtest=SystemApiTest

# 执行指定测试方法
mvn test -Dtest=AuthApiTest#testLoginWithUsername

# 跳过测试编译
mvn clean test -Dmaven.test.skip=false
```

### 3. 生成测试报告

```bash
# 生成Allure报告
mvn allure:report

# 启动Allure服务查看报告
mvn allure:serve

# 报告位置
# target/site/allure-maven-plugin/index.html
```

### 4. 参数化执行

```bash
# 指定环境
mvn test -Denv=dev
mvn test -Denv=test
mvn test -Denv=prod

# 指定基础URL
mvn test -Dbase.url=http://api.example.com

# 调试模式
mvn test -Dapi.test.debug=true
```

## 测试数据

### 数据生成策略

测试使用JavaFaker库自动生成测试数据，包括：

- 用户信息：用户名、姓名、邮箱、手机号
- 企业信息：公司名称、统一社会信用代码、地址
- 业务数据：订单号、SKU、金额、数量
- 时间数据：当前时间、未来日期

### 数据隔离

- 每个测试类使用独立的测试数据
- 测试数据包含时间戳，避免冲突
- 支持测试数据清理（待实现）

## 持续集成

### Jenkins配置

```groovy
pipeline {
    agent any
    
    stages {
        stage('Checkout') {
            steps {
                checkout scm
            }
        }
        
        stage('Build') {
            steps {
                sh 'mvn clean compile'
            }
        }
        
        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }
        
        stage('Report') {
            steps {
                allure([
                    includeProperties: false,
                    jdk: '',
                    properties: [],
                    reportBuildPolicy: 'ALWAYS',
                    results: [[path: 'target/allure-results']]
                ])
            }
        }
    }
}
```

## 附录

### 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未授权/Token无效 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 409 | 资源冲突 |
| 500 | 服务器内部错误 |

### 响应格式

```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        // 业务数据
    },
    "timestamp": 1640000000000
}
```
