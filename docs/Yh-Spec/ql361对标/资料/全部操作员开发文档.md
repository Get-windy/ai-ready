# 全部操作员开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`system/user`（用户管理）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：系统登录账号（操作员）及其数据权限维护页，左侧所属部门树 + 查询区 + 数据表格；操作员账号与 8 类数据权限的集中管理。
- 截图：![全部操作员](../../../../tool-results/ql361/pages/资料__职员权限__全部操作员.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入职员名称）
- 勾选项：显示停用
- 左侧所属部门树（全部、管理部、客服部、配送部、仓管、兼职人员）按部门过滤
- JSON filterLabels 5 个"更多"占位对应查询配置区折叠字段，全量查询条件待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增操作员、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 新增操作员旁有配额提示"您一共可添加5个操作员，已添加5个"
- 行级操作（截图确认）：修改、删除、更多；各权限列值为可点链接（点击设置对应数据权限，推断，待复核）

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

操作、用户名、职员、部门、岗位、操作员类型、仓库权限、调拨权限、部门权限、往来单位权限、商品权限、现金银行权限、客户级别权限

> 本页 JSON columns 无抓取拼接串（首项"操作"为真实单列）。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 操作员配额制：账号数受 license 限制（截图实据："您一共可添加5个操作员，已添加5个"），达上限后新增操作员应受限（待复核）
- 功能权限与数据权限分离：功能权限由岗位承载（岗位权限页）；数据权限在本页按操作员逐类设置——仓库权限、调拨权限、部门权限、往来单位权限、商品权限、现金银行权限、客户级别权限 7 类数据权限 + 操作员类型
- 权限值形态："全部仓库/所有仓库""所有权限""所有部门/未设置"等（截图实据），链接点击进入设置（推断，待复核）
- 操作员类型：普通操作员（截图实据，其他类型枚举待复核）
- 用户名与职员：操作员必须绑定职员（截图实据：用户名 干饭郎_刘洋洋 ↔ 职员 刘洋洋），职员档案在职员部门页维护
- 与其他页面关系：职员部门（职员"添加操作员"后在本页出现；部门树同源）、岗位权限（操作员"岗位"列引用岗位档案）、仓库规划（仓库/调拨权限按仓库授权）、各业务页面（数据权限过滤，如仅授权仓库的单据可见）
