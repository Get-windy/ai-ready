# 岗位权限开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`system/role`（角色）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：岗位（角色）档案与功能权限设置页，查询区 + 数据表格，单一列表视图；行级"设置权限"进入权限配置。
- 截图：![岗位权限](../../../../tool-results/ql361/pages/资料__职员权限__岗位权限.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入岗位名称）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增岗位、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、设置权限

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（3 列，抓取 JSON columns 实据）

操作、岗位名称、备注

> JSON columns 首项"操作 岗位名称 备注"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 设置权限：行级入口进入该岗位的功能权限配置（权限树/弹窗未抓取，待复核）
- 系统预置岗位保护：系统管理员、业务员备注"系统预置，不能修改和删除"（截图实据）——预置岗位禁止修改/删除
- 岗位即角色：岗位承载功能权限，操作员绑定岗位获得权限（全部操作员页"岗位"列实据）
- 自定义岗位：销售主管兼库管、销售开单等为企业自建岗位，可修改/删除
- 与其他页面关系：全部操作员（操作员"岗位"列引用本页岗位，功能权限随岗位）、职员部门（职员"职务"为自由文本，与岗位区分）、各业务页面（菜单/按钮级权限按岗位控制）
