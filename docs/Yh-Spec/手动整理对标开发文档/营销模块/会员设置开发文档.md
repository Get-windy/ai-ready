## 1. 页面概述

## 4. 业务规范

- **积分规则模型**：
  - 积分流入三路：注册初始积分（开户即送）、会员生日倍积分（生日当天消费按 N 倍计）、消费积分（日常消费累计）；另有签到积分（线上签到玩法）。
  - 消费积分两种算法**互斥（单选）**：按销售金额积分（全局统一比例，实测 100 元=1 分）或按不同商品累计积分（商品级系数，`详细设置` 维护）。
  - 勾选项「按折扣积分」决定按折前/折后金额计积分（**具体口径待复核**）。
  - 积分规则 = 四舍五入（消费金额换算积分时的取整方式）。
  - 积分应用场景：线下开单 / 微商城双通道，控制积分在哪些渠道产生与使用（勾选态待复核）。
  - 签到积分递增模型：首日 3 分、连续签到每日 +1、封顶 8 分。
- **积分流出（积分抵现）**：实测 100 积分=1 元，单笔订单最高可抵扣 100%（即可全额抵扣，比例可调）；另一流出方向为《积分兑换开发文档》的礼品兑换。
- **跨页关系**：
  - 《会员管理》：会员积分账户按本页规则累计与扣减；「客户 | 会员管理」开关证实**会员档案依托客户（ERP 往来单位）**。
  - 《积分兑换》：消费积分余额的兑换出口。
  - 销售开单：「会员信息」Tab（销售积分/兑换积分/使用积分/当前积分）按本页「积分应用场景-线下开单」启用；「微商城」对应 B2B 商城渠道。

### 剩余缺口

1. **页面性质需整体重写（P0）**：从「营销规则列表（ARReportPage + MarketingRule）」改为对标形态的**参数设置单页**（三分区卡片 + 开关 + 底部保存）。
2. **标题与菜单名不一致**：页内 `title="会员配置"`（`index.vue:4`）应对齐菜单名「会员设置」。
3. **缺全部对标设置项**：客户 | 会员管理开关、会员自动升级开关、积分奖励（注册初始积分/生日倍积分）、消费积分（二选一算法 + 按折扣积分）、积分规则下拉、积分应用场景、签到积分三项 + 月历、积分抵现（抵现比例/单笔最高抵扣）。
4. **缺「详细设置」入口**（按不同商品累计积分的商品级系数配置）。
5. **后端缺口（P0）**：**未见**会员设置参数实体与端点（应为单行配置，`GET/PUT` 一对）。现有 `/erp/marketing/rules` 是通用营销规则 CRUD，语义不等价；需新增参数表（或复用既有单行配置模式）+ 端点。
6. **无保存闭环**：无参数持久化、无校验（必填 `*` 项）、无开关联动（如关闭「积分奖励」时禁用其下输入项）。
7. **无列配置 / storage-key（对标页本就不需要）**——本项在本页**不构成缺口**；带表格的实现反而与对标不符。
8. **无 E2E 覆盖**。
