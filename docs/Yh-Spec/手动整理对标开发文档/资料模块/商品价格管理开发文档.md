# 商品价格管理开发文档

> **文档类型：** 页面对标复刻（⚠️ **本系统当前为占位桩页**，后端未接入；对标为多Tab组合页）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 商品价格管理为**多Tab组合页**（4 个子标签），用于商品的批量调价与价格等级/客户级别折扣维护。

## 页面概述

商品价格管理用于查看与维护**商品价格**（8 个价格等级 + 客户级别折扣/指定价）。对标系统为**多Tab组合页**，含 4 个子标签：**商品价格批量修改**（默认）、**客户级别折扣设置**、**级别指定价设置**、**客户指定价设置**。单入口仅读（无表单页）。

| 子标签 | 说明 |
|--------|------|
| 商品价格批量修改 | 商品筛选（分类树）+ 8 价格等级列 + 批量修改（默认激活） |
| 客户级别折扣设置 | 客户级别 → 级别默认价 维护（简单网格） |
| 级别指定价设置 | 按「客户级别」指定商品/分类价格规则（查询 + 数据表） |
| 客户指定价设置 | 按「客户」指定商品/分类价格规则（查询 + 数据表） |

菜单：资料 → 商品管理 → 商品价格管理。

> ✅ **本系统实现说明（2026-09-11 金标准完成）**：已按对标 4 子标签全栈复刻（不再收敛到《商品 → 批量改价》，改为对标页直接读/写同一份价格口径）。
> - 后端：`erp-stock` 模块 `ProductPriceController`，前缀 `/api/erp/md/product-price`（不再 404）
> - 前端：`views/md/product-price/index.vue`（`CategoryListLayout` 4 子标签 + 各子标签独立列配置）
> - 数据：价格读写 `erp_product` / `erp_product_unit`（与《商品》《批量改价》单一来源）；子标签 2/3 新建 `erp_customer_grade_discount` / `erp_customer_grade_price`（迁移 V11.158.0）；子标签 4 复用 `erp_customer_product_price`（同迁移补列）

### 四子标签实现口径

| 子标签 | 读 | 写 | 关键交互 |

| 客户级别折扣设置 | `erp_customer_grade_discount` | 同表 | 新增/修改/删除；订货价 = 基础价（批发价/零售价/等级价）×＋计算数，弹窗实时预览 |
| 级别指定价设置 | `erp_customer_grade_price` × 商品档案实时字段 | 同表 | 新增/修改/批量删除/导入（模板下载 + Excel 真实落库）；规则文本「零售价+1.5」/「指定价 3.34」 |

### 与文档口径的两处裁决

1. **不做「收敛到商品批量改价」**：对标页 4 子标签均有独立列/查询/写入口，收敛会丢功能；改为**共用同一份价格口径**（读 `erp_product_unit`，不复制价格），既满足「数据源唯一」红线又完成对标。
2. **价格等级命名**：对标 8 个等级列标题（食堂团餐/外围餐饮店/餐饮店/大团餐/重点|vip01/连锁|vip/特价客户/自助vip）取自 ql361 自定义命名；本系统同理**动态取 `erp_product_grade` 的 grade_name**，按 sort_order 渲染 grade_price_1~8 列，改等级名即改列标题。

### 后续增强（2026-09-12）

| 项 | 实现 |
|---|---|
| **价格列行内改价** | 子标签 1 表格改为可编辑模式（`view-mode=false`）：**8 个价格等级列 + 批发价 / 零售价 / 最低售价** 点击即进入输入态，回车/失焦自动调用 `PUT /batch-modify`（单行单字段 FIXED）落库并提示；其余列全部 `readonly`，避免误改主数据。保存失败自动 `fetchList()` 还原 |
| **前 5 列左冻结** | 序号 / 勾选 / 图片 / 商品名称 / 单位 默认 `fixed: 'left'`，横向滚动保持可见。为此修复 `BillDetailTable` 三处组件缺陷（见下） |

> **组件级修复（`BillDetailTable`，全站通用）**：
> 1. 冻结列 `left` 原先写死 `0` → **多列冻结会全部重叠**。改为按可见顺序累加「排在该列之前的同侧冻结列宽度」计算偏移（左右两侧对称）。
> 2. 冻结**表头** `z-index:3` 低于普通表头 `z-index:10` → 横向滚动时表头冻结被普通表头盖住（表现为「单元格冻结正常、表头冻结失效」）。改为 `z-index:12` 并补不透明底色 `#fafafa`。
> 3. 数据行 td 无底色 → 冻结列 `background:inherit` 取到透明，滚动内容从冻结列下方透出。补 `.ss-row td { background:#fff }`（空行/hover 仍按原样覆盖）。
> 4. **空值数字单元格「点开即把 0 当新值提交」**：`enterEdit` 对 number 列把编辑初值补成 `0`，而 `NULL` 的 original 是 `null` → 判定"值已变"，用户只是点开再点走就会把空值写成 0（批发价/最低售价在库里为 NULL 时中招，零售价为 0 时反而正常）。改为**空值一律以 `''` 为编辑初值**，并在 `commitEdit` 用 `isEmptyValue()` 做空值等价判定（null/undefined/'' 不视为变化）。
> 回归：`tools/e2e-billdetailtable-regression.cjs` 覆盖 销售订单历史 / 订单处理中心 / 商品条码 / 销售出库历史 **16/16 通过**。
