## 4. 接口安全测试

### 4.1 REST API安全测试
#### 4.1.1 输入验证安全测试
**API接口列表及安全测试重点：**

| API端点 | 方法 | 安全测试重点 |
|---------|------|-------------|
| /api/sale/pricing/strategies | POST | SQL注入、XSS、权限绕过 |
| /api/sale/pricing/strategies/{id} | PUT | 参数篡改、权限提升 |
| /api/sale/pricing/strategies/{id} | DELETE | 水平权限、删除保护 |
| /api/sale/pricing/strategies/{id} | GET | 数据泄露、权限绕过 |
| /api/sale/pricing/strategies | GET | 批量数据泄露、分页攻击 |
| /api/sale/pricing/strategies/{id}/activate | POST | 状态篡改、权限验证 |
| /api/sale/pricing/strategies/{id}/deactivate | POST | 状态篡改、权限验证 |
| /api/sale/pricing/strategies/{id}/copy | POST | 权限继承、数据泄露 |
| /api/sale/pricing/calculate | POST | 业务逻辑、价格计算 |
| /api/sale/pricing/simulate | POST | 业务逻辑、模拟攻击 |

- **测试用例**：
  1. 参数长度、类型、格式验证
  2. 业务逻辑验证（价格合理性）
  3. 复杂参数组合测试

## 10. 测试环境要求

### 10.1 测试环境配置
- **环境类型**：独立安全测试环境
- **数据要求**：脱敏生产数据
- **网络隔离**：与生产环境完全隔离

### 10.2 测试工具要求
- **扫描工具**：OWASP ZAP、SonarQube、Nessus
- **测试工具**：Burp Suite、Postman、JMeter
- **监控工具**：ELK Stack、Prometheus、Grafana

### 10.3 测试数据要求
- **测试账户**：不同权限级别测试账户
- **测试数据**：价格策略模板数据
- **攻击载荷**：SQL注入、XSS等测试数据
