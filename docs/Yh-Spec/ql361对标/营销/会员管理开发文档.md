## 1. 页面概述

- **列表页**：会员（积分卡）档案的查询与维护页——客户分类树 + 查询区 + 会员表格；含发短信/发优惠券批量触达，销售订单"会员信息"Tab 的数据源。

## 2. 页面配置

### 查询条件

- 查询方案（--查询方案--，支持保存方案）

- 工具栏（抓取 JSON buttons）：新增、发短信、发优惠券、会员设置、刷新、打印(F8)、更多、查询、跳转（分页跳转）

## 4. 业务规范

- 会员档案口径（实据归纳）：
  - 会员 = 客户扩展档案：《会员设置》页首行开关"客户 | 会员管理"（截图实据，当前"开"）；本页"客户名称"列 + 左侧客户分类树实据——会员档案挂在 ERP 往来单位（客户）上，会员名称/会员卡号/会员生日为会员层扩展字段，与 ERP 客户同源
  - 会员级别（实据值"A餐饮客户"）：会员分级体系，级别与客户分类关联（分级规则由《会员设置》维护）
  - 会员卡状态（实据值"停用"）：控制开单时会员识别与权益享受；状态枚举全集（启用/停用/挂失等）待复核
  - 有效时间（起~止区间，实据 2022-09-01 起）：会员有效期，过期会员开单不享受会员权益
  - 当前积分（实据 100）：会员积分账户余额；行级"积分明细"联查逐笔积分流水；与销售订单"会员信息"Tab（此前积分/销售积分/退货积分/兑换积分/使用积分/当前积分，销售域抓取实据）同源
  - 最近交易时间 / 最近交易（起止）查询：按最近交易区间筛选会员，支撑沉睡会员唤醒营销场景
- 与其他页面关系：销售订单表单页底部"会员信息"Tab（会员卡号、此前积分、销售积分、退货积分、兑换积分、使用积分、当前积分，销售域抓取实据）——录单时读取并回写本页维护的会员积分账户；销售订单明细全量可配置列含"兑换礼品、兑换积分、使用积分"，与《积分兑换》页联动；会员积分规则由《会员设置开发文档》维护，本页档案是规则的落点；发短信/发优惠券批量触达与营销域《发短信开发文档》《优惠券开发文档》同源
- 本系统现状对照（代码实据）：前端页面 `apps/pc-admin/src/views/marketing/member-manage/index.vue`（dynamicRoutes.ts 实据）；后端接口 `/api/erp/marketing/card`（LoyaltyCardController；LoyaltyCard 字段：programId、partnerId、cardCode、points、totalEarned、totalRedeemed、expirationDate、isActive），支持分页/新增/修改/积分增加/积分扣减/删除（api/marketing.ts 实据）；积分流水 `/api/erp/marketing/points/page`（pointsApi）
