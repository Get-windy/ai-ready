## 4. 业务规范

- 秒杀模型（列实据归纳）：
  - 场次制：一行 = 一个秒杀场次（活动名称 + 起始/结束时间窗），场次内商品以秒杀价限时限量抢购
  - 活动状态随时间窗流转（待开始/进行中/已结束——同域商城预售、商城弹窗广告活动状态下拉枚举实据佐证，本页下拉为"全部"，状态枚举待复核）
  - 创建时间审计列
  - 与日常价的隔离（推断，待复核）：秒杀价仅在场次时间窗内、限场次库存生效，不写入价格等级与销售价格跟踪
- 与其他页面关系：商城域同组（商城拼团凑团享价、商城预售订金预售与秒杀限时抢并列商城三大玩法）；推广联动（我要推广可推广"秒杀"活动）；本系统落地对应秒杀 `/api/erp/marketing/flash-sale`（api/marketing.ts 实据）
