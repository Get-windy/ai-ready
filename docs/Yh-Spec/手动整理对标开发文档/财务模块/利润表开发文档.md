## 页面概述

利润表是**按会计期间出具的损益报表**（营业收入 → 逐级加减成本费用 → 利润）。**报表页**（查询 + 单表纵向项目行，无分页，无独立表单），单入口。报表项目行**非固定模板**，由公司实际启用的科目按「科目层级=2」展开生成。

菜单：财务 → 财务报表 → 利润表。

### 本系统实现（2026-09-10 · 金标准）

**报表行生成算法（科目层级驱动）**
1. 取**启用**的科目类型 4（成本类）/ 5（损益类）且 `level ≤ 科目层级` 的科目，按 `parent_id` 建树；
2. 每个科目自有发生额按**正常余额方向取正数**（`direction=1` 借方取 借−贷，`direction=2` 贷方取 贷−借）；
3. 父科目 = 自有发生额 + 全部子科目发生额（ql361：`销售费用` = 其费用类型子项合计）；
4. 按科目性质分段，并插入 一/二/三/四 段汇总行：

   | 段 | 行 | 取数 |
   |---|---|---|
   | 一、营业收入 | 主营业务收入（`6001`，缺省取编码最小的收入类科目） | 该科目树合计 |
   | 　 | 减：成本类科目（type=4） | 各一级科目树，前缀「减：」 |
   | 　 | 加：其他收入类科目（type=5 且 direction=2，排除 `6301`） | 各一级科目树，前缀「加：」 |
   | 　 | 期间费用（type=5 且 direction=1，排除 `671x`/`6801`） | 各一级科目树，无前缀 |
   | 二、营业利润 | = 营业收入 + 其他收入 − 成本 − 期间费用 | |
   | 　 | 加：营业外收入（`6301*`） / 减：营业外支出（`671*`） | |
   | 三、利润总额 | = 营业利润 + 营业外收入 − 营业外支出 | |
   | 　 | 减：所得税费用（`6801*`） | |
   | 四、净利润 | = 利润总额 − 所得税费用 | |

5. 子科目按 `indentLevel` 缩进（一级 0 / 二级 1 / 三级 2…），仅一级科目带「加：/减：」前缀；
6. `显示为0科目` 未勾选时隐藏「本期与本年累计**同时为 0**」的科目行（汇总行始终保留）。

**接口**：`GET /api/erp/finance/report/v2/income-statement-report`
参数：`fiscalYear` / `fiscalPeriod`(会计月止) / `periodMode`(single|multi) / `startPeriod`(多会计月起) / `subjectLevel`(默认 2) / `showZero`(默认 false)。

**返回**：`{ 回显口径, rows[], 段汇总(本期/累计), hasData }`；
`rows[]` 字段：`rowNo / itemCode / itemName / indentLevel / summaryRow / subjectId / subjectCode / subjectLevel / currentAmount / cumulativeAmount`。

**实现文件**
- 后端：`erp-finance/.../controller/FinancialReportController.java`（`/income-statement-report`）、`service/impl/FinancialReportServiceImpl#generateIncomeStatementReport`、`dto/IncomeStatementQuery|RowDTO|ReportDTO`
- 前端：`apps/pc-admin/src/views/finance/profit-report/index.vue`、`api/finance/index.ts#reportApi.getIncomeStatementReport`

## 业务规范说明

- **报表口径**：本期发生额=单会计月当月发生；本年累计=年初至止月累计。
- **报表项目行**：由公司实际启用科目按「科目层级（默认 2）」展开生成，非固定模板；含 一/二/三/四 段汇总行（营业收入、营业利润、利润总额、净利润）与明细科目行（带 减：/加： 前缀或缩进）。
- **汇总行**：营业利润/利润总额/净利润（按国内报表惯例，带「(亏损以'-'填列)」后缀）。
- **数字右对齐**，无链接穿透（与资产负债表不同，本表无「明细对账」按钮）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 损益口径（红线）**：利润表只读取自凭证/科目余额，**严禁手工改表或绕过凭证**；本期发生=单会计月，本年累计=年初至止月。
  → ✅ 已落地：`generateIncomeStatementReport` 仅读 `finance_ledger`（凭证记账产出），`period_debit/period_credit` 按期间聚合。
- **P1 勾稽**：净利润须能与资产负债表期初/期末权益变动核对一致。
  → 🅿️ 待补：两表同期核对用例（口径已对齐：均以 `finance_ledger` 为唯一数据源）。
- **P1 汇总行**：逐级小计按国内报表惯例补全「减：/加：」前缀，一/二/三/四 段汇总行完整（科目层级驱动）。
  → ✅ 已落地：四段汇总行恒定输出（加粗），成本类「减：」、其他收入类「加：」、期间费用无前缀、子科目缩进。
- **P2 验收**：金额与科目余额/明细账对数一致；三级缩进不串级。
  → ✅ 已验证：`本年累计 = Σ(1..止月 发生额)`、`本期 = 止月当月`；段汇总勾稽
  `营业利润 = 营业收入 + 其他收入 − 成本 − 期间费用`、`净利润 = 利润总额 − 所得税` 均成立；
  子科目 `indentLevel` 按层级递增（实测二级科目缩进 1）。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
