## 4. 业务规范

- **特价模型（行数据实据归纳）**：
  - 特价 ≠ 促销规则：特价直接给商品一口特价（区别于商品促销/整单促销的规则减免/满赠），活动期内按特价成交；活动名称实据「香芋地瓜丸3件起特价」「果蜜一次拿货5件以上特价」——特价可带起购数量门槛。
  - 定向维度：促销商品（查看商品弹层）、客户范围（查看客户弹层）双定向——同品不同客可不同价；使用范围实据「线上线下」（线下开单 + 线上商城双通道生效）。
  - 活动状态实据「促销中」；时间窗外自动过期，可作废；「显示已过期/已作废活动」默认隐藏。
  - 与价格体系关系：销售明细价格等级字段含「特价客户」等级；特价与价格等级、销售价格跟踪（最近成交价）的优先级**待复核**。
  - 创建人/创建时间审计列（实据「杨生淮」/「2026-01-29 09:54:27」）。
- **与其他页面关系**：与《商品促销开发文档》《整单促销开发文档》并列三种让利手段（特价直接改价 / 商品促销行级规则 / 整单促销单级规则）；销售开单联动（命中特价的商品明细按特价取价）；本系统落地对应等级特价 `/api/erp/product-grade-price`。

## 5. 实现差异说明

> 本节按当前源码回写（源码未在本轮改动）。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/marketing/special-price/index.vue`（共 352 行）
- **骨架**：`ErrorBoundary` > `PageContainer(title="特价管理")`（`index.vue:2-3`），**非**金标准路线 A（无 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`）。
- **页面结构**：**非列表-查询式**，而是「**先选商品 → 再看该商品的等级特价**」的主从式页面：
  - 搜索区（`index.vue:5-40`）：`a-form layout="inline"`，含「特价商品」下拉 `selectedProductId`（`:8-16`，`show-search`，商品来自 `optionsApi.getProducts()`）+「新增特价」按钮（`:20-28`，未选商品时禁用）+「刷新」按钮（`:29-36`）。
  - 表格区（`index.vue:43-89`）：`a-table`，`:pagination="false"`（无分页），空态文案为「请先选择商品」/「该商品暂无等级特价」（`:51`）。
- **列定义**：`columns`（`index.vue:195-205`），共 **9 列**：客户等级、等级编码、基准价、特价、数量区间（qtyRange，`:60-62`）、有效期（period，`:63-65`）、状态（`isActive` 开关，`:66-74`）、备注、操作。
- **数据请求**：`loadPrices()`（`index.vue:216-227`）= `gradePriceApi.byProduct(selectedProductId)`——**按商品取等级特价，无分页、无活动维度**。
- **行级操作**（`index.vue:75-86`）：编辑、删除。
- **弹窗**（`index.vue:92-168`）：客户等级 `gradeName`（必填）、等级编码 `gradeCode`、基准价 `basePrice`、特价 `gradePrice`（必填）、数量区间 `minOrderQty/maxOrderQty`、有效期 `dateRange`、备注 `remark`。
- **数据来源**：`apps/pc-admin/src/api/marketing.ts` → `gradePriceApi.byProduct/create/update/remove`（`marketing.ts:495-508`，端点 `/erp/product-grade-price/by-product/{productId}`、`/erp/product-grade-price`）；商品下拉 `optionsApi.getProducts()`（`index.vue:325-332`）。
- **后端**：`erp/erp-pricing/.../pricing/controller/ProductGradePriceController.java`（`@RequestMapping("/api/erp/product-grade-price")`，`ProductGradePriceController.java:20`；含 `/by-product/{productId}`、`/batch-save`、POST/PUT/DELETE）。
- **storage-key**：无（未使用列配置/页面配置持久化）。

### 剩余缺口

1. **🔴 页面模型整体偏离（最大缺口）**：对标是**特价活动**维度（活动名称/起始时间/结束时间/促销商品/客户范围/使用范围/活动状态/创建人/创建时间）；本页是**商品 × 客户等级特价**维度（客户等级/等级编码/基准价/特价/数量区间/有效期/状态/备注）。**仅「特价金额/有效期(起止)/状态」语义近似**，无「活动名称」「客户范围」「使用范围」「创建人」等对标列。
2. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；页面为手写 `a-table` + 独立弹窗。
3. **无列表查询区、无分页**：`a-table :pagination="false"`；查询需先在下拉中选定单个商品（`index.vue:8-16`），无法按活动名称/时间/状态/客户范围跨商品检索。
4. **查询条件不对齐**：对标有活动名称/商品/客户/起止时间/使用范围/活动状态/创建人 + 勾选项；本页仅「特价商品」下拉一项。
5. **行级操作不对齐**：对标为「查看/修改/更多」；本页为「编辑/删除」，且额外提供 `isActive` 行内启停开关。
6. **按钮不对齐**：对标有「更多玩法告诉我们..」；本页无。
7. **打印**：对标无打印按钮，本页亦无（一致）。
8. **无导出**：本页**无导出入口**（未使用 `ARReportPage`，也未另接导出）。
