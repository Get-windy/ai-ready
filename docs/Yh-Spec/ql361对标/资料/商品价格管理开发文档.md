# 商品价格管理开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/product/price-batch`（价格批量维护）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页（复合页）**：商品×单位维度的价格档案维护工作台，价格档案维护列表 + 4 个子标签工作台：商品价格批量修改 / 客户级别折扣设置 / 级别指定价设置 / 客户指定价设置。
- 截图：![商品价格管理](../../../../tool-results/ql361/pages/资料__商品管理__商品价格管理.png)

## 2. 页面配置

### 查询条件

- 筛选条件（商品名称/货号/条码/规格/型号）
- 品牌（选择器）
- 单位类型（全部）
- 商品（选择器）
- 上架状态（全部）
- 最近进货日期（≥）
- 库存数量（≥）
- 勾选项：显示层次结构
- 左侧商品分类树按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：刷新、打印(F8)、批量修改、更多、查询、跳转（分页跳转）
- 注：本页无"操作"列（截图确认），价格维护通过勾选行 + "批量修改"按钮进行

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 4. 业务规范

- 数据粒度：一行 = 商品 × 单位；不同单位各自定价（截图实据：瓶/箱两行价格不同）
- 批量修改：勾选多行后按统一规则批量调价（弹窗未抓取，调整维度/公式待复核）
- 价格体系三层（按子标签实据归纳）：
  1. 商品价格批量修改：商品价格档案本体（批发价/零售价/最低售价 + 各价格等级价）
  2. 客户级别折扣设置：按客户级别设折扣
  3. 级别指定价设置：按客户级别对指定商品设价
  4. 客户指定价设置：按单个客户对指定商品设价
- 最低折扣(%)与最低售价：录单价格下限控制，与销售订单"折扣(%)/折后单价"联动校验
- 与其他页面关系：商品（价格随商品×单位维护；商品页默认列含价格等级列"餐饮店"，与本页同源）、客户（客户级别折扣/指定价作用于客户档案的客户级别）、销售订单/销售出库单（录单取价按"客户指定价 > 级别指定价 > 客户级别折扣 > 商品价格等级"优先级推断，待复核）、销售价格跟踪（销售域：记录最近成交价，与本页"最近进价"口径不同）
