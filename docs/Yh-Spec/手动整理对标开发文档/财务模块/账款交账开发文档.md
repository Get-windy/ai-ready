| 页面 | 地址 | 说明 |

| 账款交账 | `finance/account-delivery` | 复合页（列表 + 统计卡片 + 按职员/按单据双视图） |

## 页面配置

### 交账维度（本系统实测）
按日 / 按周 / 按月 / 按业务员 / 按客户。

### 查询条件（本系统实测）
交账维度、收款日期区间。

### 功能按钮（对标）
去交账、刷新、打印(F8)、导出、查询、跳转。

### 数据表列（本系统实测）
分组(groupKey)、名称(groupName)、收款笔数(receiptCount)、收款总额(totalAmount)、现金(cashAmount)、银行(bankAmount)、其他方式(otherAmount)。

> 对标列（按职员）：交账职员、部门、待交账单据、待交账金额、待交账收款金额（分组：使用预收/收款合计）、待交账优惠、待交账欠款金额。

## 业务规范说明

- **交账主线**：职员（司机代收/业务员上门收款）经手收取客户款项 → 挂"待交账" → 财务按职员或按单据核对 → 勾选后"去交账" → 款项交回入账，职员待交账清零。
- **统计卡片五档**：待交账单据、待交账金额、待交账收款金额、待交账优惠、待交账欠款金额。
- **列口径**：待交账金额=职员经手单据应收合计；待交账收款金额拆为 使用预收 + 收款合计；待交账优惠=收款给客户的优惠；待交账欠款金额=仍未收齐挂欠部分。
- **前置**：职员经手未交账单据不可在《按单收款》被选择收款。
