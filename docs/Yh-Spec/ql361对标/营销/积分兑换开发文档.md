## 4. 业务规范

- 兑换目录口径（实据归纳）：
  - 目录定位：本页维护"哪些商品可用积分兑换、各需多少积分"——兑换所需积分即商品的积分定价；商品名称/货号/单位/规格/型号/产地各列与商品主数据同源（选品入目录，非新建商品）
  - 抓取时点目录为空（共 0 条记录）：该客户账套未启用积分兑换目录，页面结构与列口径仍以实据为准
  - 兑换办理出口：销售订单明细全量可配置列含"兑换礼品、兑换积分、使用积分"（销售域抓取实据），销售订单"会员信息"Tab 含"兑换积分"字段——开单时选兑换商品、按本页"兑换所需积分"扣减会员积分账户
  - 积分两路流出：本页兑换商品流出 + 《会员设置》"积分抵现"流出（v5 截图实据：抵现 100 积分=1 元、单笔订单最高可抵扣 100%）；与会员设置的积分流入规则（注册初始/生日倍数/消费/签到）构成积分闭环
  - 积分余额约束：兑换以《会员管理》维护的会员积分账户（当前积分）为前提，余额不足应禁止兑换
- 与其他页面关系：会员管理（会员积分账户与积分明细流水的维护页，本页兑换扣减的落点）、会员设置（积分流入规则与积分抵现参数配置页）、销售开单（兑换办理在订单明细"兑换礼品/兑换积分/使用积分"完成）
- 本系统现状对照（代码实据）：前端页面 `apps/pc-admin/src/views/marketing/points-exchange/index.vue`（dynamicRoutes.ts 实据）；积分流水查询 `/api/erp/marketing/points/page`（pointsApi），积分增减 `/api/erp/marketing/card/{id}/points/add|deduct`（api/marketing.ts 实据）
