## 域级说明

### 菜单结构实据（客户活跃分析截图左侧菜单树完整捕获）

分析一级域下 6 组 31 页，组内再有子分组：综合单据（单据中心）；采销分析（销售业绩/销售分析/采购分析三个子分组）；仓配分析（仓储分析）；提成分析（提成统计）；财务分析（财务报表/资金费用/往来经营三个子分组）；营销分析（营销分析/商城分析两个子分组）。

### 六组口径分工（域级分析体系）

1. **综合单据 = 单据生命周期三横切**：待审批单据（审批中）→ 业务草稿（未过账，提交记账过账）→ 经营历程（已过账全量流水，红冲留痕）。经营历程是全系统单据级"经营档案"，为各分析页底层取数源。
2. **采销分析 = 业务漏斗与量本利**：销售业绩（拓客→拜访→订货→销售→退货→回款漏斗）、销售分析（量本利八维度：销售收入=销售额−退货额，毛利=收入−成本，利润=毛利−费用−优惠）、履约/欠款/费用三专项、客户活跃与推广两运营页、采购分析（订/采/退三段：实采=采购优惠后−退货折后）、采购准备（预警→补货→下单操作闭环）。
3. **仓配分析 = 库存四粒度**：查库存（时点存量）→ 查批次（批次×效期粒度）→ 进销存分析（期间汇总账：期末=期初+入库−出库）→ 库存明细（流水明细账，对账联查终点）。
4. **提成分析 = 业绩→提成核算链**：业务员提成（按方案实时计算）→ 回款统计（回款三口径：回款总=收款+预收+预订货收款）→ 业绩提成中心（年度×月份结算闭环，未结算月份之后不显示的顺序约束）。
5. **财务分析 = 财务账表七口径**：经营分析（损益：营业利润=收入合计−支出合计）、查资金（资金账：期末=期初+借方−贷方）、查费用（费用矩阵：费用额=各维度列之和）、发票统计（税务账：应交税额=销项−进项）、查应收/查应付（往来滚动账：余额=期初+本期发生−已结−优惠，期末=余额−预收/预付）、往来余额表（四象限净额：往来合计=(应收+预付)−(应付+预收)，仅应收应付可清账）。
6. **营销分析 = 商城运营**：营销活动分析（活动让利口径）、营销推广分析（分享→浏览→下单漏斗，按推广对象）、交易分析（登录→下单转化：客单价=金额/下单客户数，转化率=下单客户/登录）、商城客户列表（私域名册+触达动作，成交率=成交/访问）。

### 通用规范

- **时间快捷段**：多数页为 昨日/今日/本周/近一周/本月/上月/近三月/本年 八段；销售履约分析为 昨日/今日/本周/本月/上月/近90天；业务员提成含"上周"无近一周/本年；业绩提成中心为 去年/本年；发票统计为月份区间（无快捷段）
- **通用组件**：--查询方案--（保存方案）、表格左上角红色齿轮（列配置）、查询区齿轮（页面配置，部分页无）、打印(F8)/导出（营销活动分析与交易分析两页无）、合计行、分页（每页 16/18/19/20/22 行不一）
- **色标体系**：单据状态彩色标签（待发货黄/交易完成绿/发货完成橙）、过期商品橙色/停用商品红色（查批次/进销存）、黄色提示条（口径规则，如"已取消、已驳回订单不参与统计"）
- **钻取体系**：金额/数量下划线单元格可钻取明细；单据编号/客户名称链接打开源单；行级"对账/明细/批次跟踪/批次号"联查
- **本系统对应实现**（dynamicRoutes.ts 实据）：pc-admin `views/analytics/` 下 31 个页面目录与对标 31 页一一对应（路由 `analytics/<path>`），字段口径按本套文档逐页对齐
