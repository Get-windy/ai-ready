- **指标**：系统容量、性能衰减、稳定性

#### 5.1.3 压力测试
- **目的**：发现系统瓶颈和极限
- **范围**：系统瓶颈点和关键服务
- **方法**：超过设计容量的负载
- **指标**：系统崩溃点、错误处理、恢复能力

#### 5.1.4 稳定性测试
- **目的**：验证系统长期运行的稳定性
- **范围**：全系统7×24小时运行
- **方法**：持续负载，监控资源使用
- **指标**：内存泄漏、资源泄漏、性能衰减
