## 2. 页面配置

### 查询条件

- 筛选条件（请输入物流公司名称/编号/备注）
- 勾选项：显示停用
- JSON filterLabels 实据为 20 个"更多"占位，对应查询配置区折叠字段，全量查询条件待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、导入、刷新、打印(F8)、导出、更多、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（7 列，抓取 JSON columns 实据）

操作、物流公司编号、物流公司名称、联系人、联系电话、物流公司地址、备注

> 本页 JSON columns 无抓取拼接串（首项"操作"为真实单列）。

### 全部可配置列

## 4. 业务规范

- 停用机制：默认不显示停用记录，勾选"显示停用"后可见（与销售域"显示状态=已启用"默认值口径一致）
- 删除约束：物流公司被单据（销售订单物流信息、线路）引用后能否删除，待复核（生产级口径：被引用主数据不允许物理删除）
- 与其他页面关系：销售订单/销售出库单（物流信息 Tab 的"物流公司""运单号"字段引用）、线路（配送管理：线路档案含"物流公司"列，第三方物流线路引用）、物流备注（订单处理中心功能按钮：按物流公司维度备注）
