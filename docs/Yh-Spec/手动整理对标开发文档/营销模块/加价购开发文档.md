## 4. 业务规范

- **加价购模型（基准文档实据归纳）**：
  - 连带销售规则（页面定位）：买家购买主商品后，可加 N 元换购指定商品——主商品与换购品、加价金额在新增表单维护（列表列未覆盖，**待复核**）。
  - 生命周期：新增 → 时间窗内生效 → 过期自动失效或人工作废；`显示已过期/已作废活动` 默认隐藏历史活动（勾选项实据，与商品促销/整单促销/特价同构）。
  - `制单人` 审计列。
  - **换购入口（基准文档推断，待复核）**：商城商品详情/购物车结算环节提示可加价换购。
- **与其他页面关系**：商城营销组玩法之一（与拼团/秒杀/预售价格玩法、弹窗广告/热搜词引流位互补，加价购做连带提升客单价）；本系统落地对应 `/api/erp/marketing/addon-rule`。
- **本系统状态轴（实现实据，非对标实据）**：`ADDON_STATUS_MAP` = 0 停用 / 1 启用（`api/marketing.ts:780-783`），并配套 `enable`/`disable` 端点；对标状态枚举措**待复核**。

### 剩余缺口

1. **🔴 列结构整体不对齐（最大缺口）**：对标实测 5 列（活动名称/起始时间/结束时间/活动状态/制单人）；本页 10 列（规则名称/主商品/加价商品/加价金额/限购/有效期起/有效期止/状态/创建时间/操作）。**`活动名称`、`制单人` 两列缺失**，`起始时间/结束时间` 被替换为「有效期起/有效期止」；`主商品/加价商品/加价金额/限购/创建时间` 为对标列配置外的自有列。
2. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；`ARReportPage` 无列配置入口。
3. **查询条件不对齐**：对标为 `起始时间 / 结束时间 / 活动状态 / 勾选项 显示已过期·已作废活动`；本页为 `规则名称 / 状态`（**缺时间区间与「显示已过期/已作废」勾选项**）。
4. **状态轴不对齐**：对标活动状态枚举**待复核**；本页为「启用/停用」二态（启停式），语义上未区分「待开始/进行中/已结束/已作废」生命周期。
5. **弹窗表单用商品 ID 手填**：`mainProductId`/`addonProductId` 为 `a-input-number`（`index.vue:48-53`），未接商品弹选，易填错且无法校验商品存在性。
6. **行级操作未复核**：对标行级动作**待复核**；本页为 3 项（编辑/启用停用/删除），无对标依据可断言一致。
7. **导出**：本页用 `ARReportPage` 内置「当前页 CSV 导出」（`ARReportPage.vue:340-371`，非真实 xlsx，非全量导出）。
8. **无页面配置/打印**：对标「无打印」与实测一致；但本页亦无页面配置弹窗。
