## 业务规范说明

### 统计口径（期间损益）

- **三层公式**（逐行与合计均成立，截图验证 ✅）：
  - 收入合计 = 销售收入 + 其他业务收入（99,080.55+67=99,147.55）
  - 支出合计 = 销售成本 + 销售费用 + 管理费用 + 财务费用（77,281.35+217.52+17,580+50.48=95,314.85，尾差 0.03 为四舍五入）
  - 营业利润 = 收入合计 − 支出合计（99,147.55−95,314.85=3,832.7）
- **销售收入**：销售出库净额口径（与《销售分析》销售收入同源）；**其他业务收入**：其他收入单
- **三费**：销售费用/管理费用/财务费用按费用科目归集（与《查费用》同源，科目 6601/6602/6603 实据）
- **包含手工会计凭证**：勾选后手工凭证的损益类分录并入计算（保证账表一致）
- **销售成本**：出库成本核算口径（与《进销存分析》金额口径联动）

### 与其他页面关系

- 取数：业务单据自动凭证 + 手工会计凭证（勾选）→ 损益类科目期间发生额
- 同源页：《利润表》（法定报表口径）、《销售分析》（销售侧毛利口径）、《查费用》（费用明细细度）
