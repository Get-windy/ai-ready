### 口径说明

- **`商品批次查询` = 批次时点存量**：一行 = 商品 × 仓库 × 批次（`生产日期` / `到期日期` / `批次条码` 三者定位批次）；`可用数量` vs `账面数量` 双列（差额 = 占用）；`成本单价` / `成本金额` 为该批次成本；`上传附件` / `附件` 两列承载批次随附文件（检验报告等）。
- **`商品批次跟踪` = 批次全链路流水**：一行 = 单据 × 商品明细 × 批次，`单据日期 / 单据编号 / 单据类型 / 往来单位` 定位来源单据，`状态` 实测取值 `出库`（行实据），`数量` 与 `成本金额` 为**带符号值**（实测出库行 `-10` / `-102`）。
- **`近效期预警查询` = 效期驱动视图**：`有效天数`（默认可见，带说明图标）+ `近效期天数`（默认隐藏）构成预警窗口；`常用单位 / 可用库存 / 账面库存` 为存量落点，`备注` 承载人工标注。
- **`保质期` 列**：实测值形如 `3650天` / `365天`（`head` 串实据），按天存储。

## 4. 业务规范

### 批次 / 效期口径

- **批次粒度**：商品 × 仓库 × 批次（生产日期 / 到期日期 / 批次条码），`批次条码` 为批次唯一标识（基准文档：可打印标签）。
- **可用 vs 账面**：可用 = 账面 − 占用（待发货锁定 / 拣货中）。基准文档记合计行 `199,178.702` vs `199,182.702`（差额 4 = 占用量），**本次实测未复现该合计行数值，待复核**。
- **成本口径**：`成本单价` / `成本金额` 按**批次成本**（批次进货价）核算，与移动加权成本并存；实测 `成本金额 = 成本单价 × 账面数量`（`2.3957 × 19 ≈ 45.52`，行实据校验通过）。
- **效期色标**：`过期商品橙色显示，停用商品红色显示`（查询区勾选项文案逐字实据）；勾选 `显示停用` 后停用批次方入列。
- **保质期口径**：按天存储（实测 `3650天` / `365天`），`到期日期 = 生产日期 + 保质期`；`有效天数` 为剩余有效天数（带 `?` 说明，计算基准**待复核**）。
- **追溯口径**：`商品批次跟踪` 以批次条码为线索串起入库 → 调拨 → 出库全流水，负数为出库、正数为入库（实测出库行 `-10`，状态列 `出库`）。

### 与其他页面关系

- 取数：批次库存 + 批次流水（《库存明细》的 `批次条码` 列同源）。
- 同组页面：《查库存》（商品粒度汇总）、《进销存分析》（期间变动）、《库存明细》（流水粒度）。
- 下游：近效期预警 → 促销 / 报损动作；批次调整 → 库存调整单（基准文档）。

- **取数端点**：`GET /api/erp/batch-sn/batches/page`（`api/erp/batch.ts` 的 `batchApi`，直连 axios，`BASE_URL=/api/erp/batch-sn`；后端 `BatchQueryRequest` 对 `size` 有 `@Max(100)` 上限，故单次固定 100 条）；仓库下拉 `GET /erp/stock/warehouses`；分类树 `GET /erp/product-category/tree`。
- **口径 / 归一**：批次条码 = 批次唯一标识（与「批号」同源）；保质期 = 生产日期 → 到期日期；有效天数 = 到期日期 − 当天；效期色标（过期橙色 / 隔离红色）。
- **分页**：商品批次查询为服务端分页；近效期预警查询为**全量拉取（上限 2000 条）按到期日期升序 + 前端分页**。
- **后端**：本轮未改后端；未新增迁移。

### 剩余缺口

1. **「商品批次跟踪」视图无取数端点**：后端无「单据 × 批次」全链路流水端点，该 Tab 恒为空表并显示警示条「本系统后端暂无「商品批次跟踪」（单据 × 批次全链路流水）取数端点，本视图列结构已按对标落地，待后端补齐 `/erp/batch-sn/batches/trace/page` 后即可出数。」（`index.vue:130-136`、`:459-465`）。
2. **「上传附件」列不可用**：`erp_batch_number` 无批次附件字段，该列渲染为禁用态「上传附件」（`index.vue:154-156` 与 `title="后端 batch_number 无批次附件字段，待补齐后开放"`）。
3. **筛选条件 / 品牌 / 分类过滤后端未识别**：`buildParams()` 透传 `keyword`（筛选条件）、`brand`、`categoryId`，但后端 `BatchQueryRequest` 无对应字段（透传"后端补齐即生效"）；分类选中时只弹一次提示，实际结果不收敛（`index.vue:274-284`）。
4. **近效期视图为全量拉取 + 前端分页**：上限 2000 条，超出仅提示（`MAX_ROWS`），非服务端分页。
5. **查询方案为占位**：`queryScheme` 未被任何请求使用。
6. **dev 库无批次数据 → 多项参数生效性未确证**：`/api/erp/batch-sn/batches/page` 实测 `total=0`（加 `keyword=NOPE_XYZ`、`categoryId=999999` 仍为 0），无法用对照法判定 keyword / brand / categoryId 是否被后端识别，**未确证**（缺数据）。
