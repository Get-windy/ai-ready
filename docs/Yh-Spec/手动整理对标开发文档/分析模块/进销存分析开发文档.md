### 口径说明

- **`按商品` = 进销存主账（期间）**：`此前余额`（期初，含小单位数量 + 金额）+ 五类入库（采购入库 / 调拨入库 / 其他入库 / 借进入库 / 销退入库）→ `入库合计` − 五类出库（销售出库 / 调拨出库 / 其他出库 / 借出出库 / 采退出库）→ `出库合计` = `期末余额`；其中 `采购入库` 独有 `采购费用分摊` 子列（采购费用摊入成本）。
- **金额 vs 数量双口径**：每组均带 `小单位数量` + `金额` 两列；实测行 `博多新米坊酒酿果味酱罐头`：此前余额 `15 / 15 / 244.08` → 期末 `15 / 15 / 244.08`（零变动期），**期末 = 此前 + 入库合计 − 出库合计** 在数量与金额两口径同时成立。
- **`仓库调拨分析` = 仓对仓调拨台账**：一行 = 出库仓 → 入库仓；`差异金额 = 调拨金额 − 成本金额`（实测三行分别为 0.01 / 0 / 0，全表合计 0.01），差异来源为调拨计价与成本核算的尾差。
- **`商品调拨分析` = 商品维度调拨汇总**：`调拨数量` 与 `换算结果` 并存（前者为基本单位数量，后者按 `换算关系` 折算为大单位表达），`调拨金额 / 成本金额 / 差异金额` 三列与仓库视图同口径。

## 4. 业务规范

### 进销存公式

- **恒等式**：`期末余额 = 此前余额 + 入库合计 − 出库合计`（数量与金额两口径同时成立；实测零变动行校验通过）。
- **五类入库**：采购入库（`CGRKD-`）、调拨入库（仓库间调拨）、其他入库、借进入库（借货入）、销退入库（`XSTHD-` 销售退货回库）。
- **五类出库**：销售出库（`XSCKD-`）、调拨出库、其他出库、借出出库、采退出库（`CGTHD-` 采购退货出库）。
- **双单位口径**：`小单位数量`（折算到最小单位）/ `数量`（大单位）；基准文档的「数量显示」下拉用于切换呈现口径，**本页实测未见该下拉，待复核**。
- **金额口径**：按成本价核算（出库成本），`此前/期末金额` 为库存货值；`采购费用分摊` 单列强调采购费用资本化路径。
- **是否发生业务**：基准文档记可过滤期内无变动商品（全部 / 有业务 / 无业务），**本页实测未见，待复核**。
- **显示红冲**：勾选后红冲单据入列（与《库存明细》《经营历程》同规则），实测默认不勾选。

- 联查：行级 `对账` → 该商品期间明细流水（《库存明细》）；`仓库调拨分析` 行首 `商品分析` → 商品维度调拨明细。
