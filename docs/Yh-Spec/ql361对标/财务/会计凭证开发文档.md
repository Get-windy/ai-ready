- **双入口**：主菜单 → `finance/voucher/form`；标签「历史」→ `finance/voucher`（列表）。
- 单号实据 NO. KJPZ-20260723-127（KJPZ- 前缀 + YYYYMMDD-序号；当日已排至 127 号，实据佐证业务单据自动生成凭证共用此号段）；标题行含附件、键盘（快捷录入）、齿轮（配置）图标（截图实据）。

## 2. 表单页配置

### 表头字段（必填 * 标注 / 选填）

- 必填：单据日期\*（默认当天）、经手人\*（默认当前登录人）、部门\*（默认"管理部"）

### 全部表单字段（14 个，抓取 JSON filterLabels + 截图实据归纳）

- 表头：单据日期、经手人、部门
- 分录：明细摘要、科目编号、科目全名、明细科目、借方金额、贷方金额
- 备注：单据备注
- 单据信息：制单人、打印次数、打印记录、源单

### 字段分组

表头（单据日期/经手人/部门）→ 凭证分录录入表格 → 备注区（单据备注）→ 单据信息（制单人/打印次数/打印记录/源单）→ 底部操作。

### 录单默认值

经手人=当前登录人、部门=管理部、单据日期=当天（截图实据）。

### 打印设置

无（打印模板配置细节待复核；表单页有打印(F8)按钮及打印次数/打印记录字段）。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter。

## 3. 数据表格列配置

### 录入列口径（实据归纳）

- 明细摘要：本分录行摘要（区别于表尾单据备注）

- 明细科目：科目的末级/辅助明细（核算项选择，如往来单位/部门/职员）
- 借方金额、贷方金额：一行只填一方；合计行分别汇总借贷

## 5. 业务规范

- 状态流转：保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿可改；记账后凭证入账，驱动总账/明细账/科目余额表/辅助核算余额表/报表。
- 借贷平衡：记账强制 Σ借方金额=Σ贷方金额（合计行实时校验），不平不可记账（会计恒等要求）。
- 凭证两大来源（实据归纳）：
  - **业务自动生成**：收款单/付款单/提现存现转款等业务单据记账时自动生成凭证（明细账摘要实据"由[收款单 SKD-…]…""由[提现存现转款单 YHZKD-…]…"，单据类型=会计凭证，单据编号=KJPZ-）
  - **手工录入**：本页直接录入（调账、结转等场景）
- 源单回链：自动生成的凭证回链来源业务单据（单据信息行"源单"实据）。
- 红冲：明细账查询区有"显示红冲"勾选项（明细账实据），凭证可被红字冲销；红冲操作入口待复核。
- 与其他页面关系：上游为全部业务单据（收款/付款/预收/预付/转款/费用/其他收入/调整/销售/采购）记账自动生成；下游《总账开发文档》《明细账开发文档》《科目余额表开发文档》《辅助核算余额表开发文档》→《资产负债表开发文档》《利润表开发文档》；期间约束：记账日期落在已月结期间不可记账/修改（见《月结开发文档》，锁定口径待复核）；本系统前端目录 `finance/voucher`（dynamicRoutes.ts 实据）。
