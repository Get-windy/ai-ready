## 4. 业务规范

- 结款方式：现结/挂账（截图实据），挂账客户配套 动态收款期限（天）/固定账期/结算期 三个账期字段
- 代客下单：行级直接为该客户开销售订单（与商城"买家账号"对应：客户可开通商城账号自主下单，或由业务员代客下单）
- 发短信/发优惠券：选中客户批量触达（营销联动）
- 客户一票通：客户多门店/多联系方式的通票标识（实据不足，待复核）
- 显示供应商中的客户：客户与供应商可为同一主体（互为往来单位），勾选后并列显示
- 客户分类树含经营状态类分类（在线注册客户/观望筹备客户/流失客户/关店客户），支持按生命周期管理客户
- 与其他页面关系：客户级别（子标签维护级别档案；商品价格管理按客户级别设折扣/指定价；销售订单按客户级别取价）、区域管理（所属区域来源；配送线路按区域关联客户）、会员管理（会员积分/会员卡，销售订单"会员信息"Tab 引用）、销售订单（客户为录单必填主数据；代客下单直达订单表单）、互联账号（客户与互联平台账号绑定关系）
