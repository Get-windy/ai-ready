# 采购订单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/order/form`（表单）+ `purchase/order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：采购订单录单，编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 底部订金区 + 备注区 + 单据信息行 + 右侧摘要结账面板。
- **列表页**：按单据 / 按明细 2 个 Tab（对标系统侧列表页未单独抓取，XSMK 依据）。
- **双入口**：主菜单 → `purchase/order/form`；标签「历史」→ `purchase/order/index`。

## 2. 表单页配置

### 表头字段（必填 *）

- 必填：供应商\*、仓库\*、经手人\*（默认当前登录人）、单据日期\*（默认当天）
- 选填：联系人、联系电话、联系地址

### 全部表单字段（35 个，XSMK《采购模块/采购订单开发文档》依据）

- 基本信息：编号、供应商、供应商编号、开户行、银行账号、税号、仓库、经手人、部门、单据日期、联系人、联系电话、联系地址
- 扩展：自定义字段1(数字)~2(数字)、自定义字段3(文本)~5(文本)、审核人、摘要、源单
- 订金区：订金账户1、订金金额1、更多账户、此前预付、预付余额、此前欠款、预计到货、付款期限、其他费用
- 备注/信息：单据备注、制单人、制单时间、打印次数
- 摘要面板：优惠金额（其余摘要项自动计算）

### 字段分组

顶部基本信息 → 商品明细表格 → 订金区 → 备注区 → 单据信息 → 摘要结账面板。

### 录单默认值

经手人默认当前登录人、单据日期默认当天（截图确认实据）；录单默认值/打印设置 Tab 配置项明细待复核（XSMK 已有配置弹窗截图存档）。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、更多、保存草稿 Ctrl+S、提交 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）：草稿进入「业务草稿」，提交后进入审核流程（采购订单列表「单据状态」字段实据，XSMK）。
- 采购订单收货后生成采购入库单（源单回链）；列表全量列含 订货数量/已收数量/未收数量/退货数量/退货金额（XSMK 依据）。
- 订金账户1：订金是带使用条件的预收款或预付款；此前预付/此前欠款为该供应商往来余额回显。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 退货走采购退货单（出库方向），换货走采购换货单。
- 上游：采购准备四页（库存预警补货/缺货补货/智能补货/以销定购）的「采购」动作均落地为采购订单（生成细节待复核）。
- 下游单据：采购入库单（收货入库）、采购退货单（退货出库）、采购换货单（换货）、采购费用分摊（费用计入采购成本，待复核）；关联定价：采购价格跟踪记录本单产生的供应商-商品价格。
