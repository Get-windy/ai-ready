## 页面概述

其他收入单用于**非主营收入登记**（往来单位收入/内部收入两类）。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 其他收入表单页 | `finance/other-income-doc/form`（主菜单入口） | 新增收入 + 收入项明细 |
| 其他收入列表页（历史） | `finance/other-income-doc/index` | 双入口「历史」标签，列表**双 Tab**：按单据 / 按明细 |

> 注：`other-income` vs `other-income-doc` 双目录对应关系待复核（前端有 `views/finance/other-income/` 与 `views/finance/other-income-doc/`，后端接口 `/erp/finance/other-income-doc/page`），本表以菜单 `finance:other-income-doc`（80116）为准。

单号实据：`QTSRD-20260723-001`（`QTSRD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明（每个页面都有）
- **页面配置/列配置**：管理页面级字段(查询条件/功能按钮)与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区域「配置」齿轮，列配置在数据表右上角表头单元格内齿轮图标。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转；支持上移/下移/恢复默认/保存。
- 表单页配置弹窗：**页面配置 / 打印设置** 两 Tab（页面配置=字段显隐；打印设置=「始终使用最后一次打印的模板，打印时不再选择」「记账后立即打印」两个勾选项）。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级金标准组件**（列表仍为 `SearchBar`+`BillTableList`，表单为自定义 `a-form`），见「实现差异说明 → 待完善」。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 入账单一口径（红线）**：其他收入记账必须走凭证（KJPZ-）入总账/明细账，**严禁直接改收益/往来余额**；收入项明细必须有映射科目。
- **P1 收入类型**：往来单位收入须带核算项（往来单位），内部收入归部门/科目。
- **P1 分账**：往来单位收入记账计入对应客户/供应商往来；非主营收入不得与《收款单》核销混用（主营/非主营分账）。
- **P2 验收**：无桩/无模拟；列表列/配置对齐金标准（按单据 25 列/按明细 18 列/收入项明细 5 列）；凭证、往来联动、目录收敛需真实数据闭环验证。
