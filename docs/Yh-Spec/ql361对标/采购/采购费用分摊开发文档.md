# 采购费用分摊开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/cost-sharing/form`（表单）+ `purchase/cost-sharing/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：将费用单费用分摊到采购入库单商品明细，计入采购成本，编辑模式为新增模式加 id。页面性质 = 表头字段区 + 费用单选择表（费用来源）+ 采购入库单明细表（分摊对象）+ 备注区 + 单据信息行 + 底部记账；两表为「来源→对象」关系而非对等双向（与采购换货单同为双网格结构）。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `purchase/cost-sharing/form`；标签「历史」→ `purchase/cost-sharing/index`。

## 2. 表单页配置

### 表头字段（必填 *）

- 必填：经手人\*（默认当前登录人）、单据日期\*（默认当天）

### 全部表单字段（10 个，cfg 实据 10 字段 ✅）

编号、经手人、部门、单据日期、合计金额、分摊方式、单据备注、制单人、制单时间、本单金额

### 字段分组

顶部基本信息（经手人/单据日期）→ 费用单选择表（选费用单）→ 采购入库单明细表（选采购入库单 + 分摊方式 + 自动分摊）→ 备注区 → 单据信息 → 底部 本单金额 + 记账。

### 功能按钮（抓取 JSON buttons 实据）

历史、导出、选费用单、选采购入库单、自动分摊、记账 Ctrl+Enter

> 本页无打印(F8)、无保存草稿、无导入（JSON 与截图双重确认），实现时不得凭空添加。

### 打印配置

无（本页无打印(F8)按钮，与采购域其他表单页不同）。

## 3. 数据表格列配置

### 默认显示列（抓取 JSON columns + 截图补全，费用单表 8 列 / 入库单明细表 11 列）

费用单选择表：操作、费用单编号、往来单位、往来单位编码、结算单位、费用项、费用金额、备注

采购入库单明细表：操作、单据编号、供应商、供应商编码、结算单位、商品名称、计价单位、数量、优惠后单价、优惠后金额、分摊金额

> 注：JSON 两表表头拼接串已剔除；入库单明细表 JSON 仅 9 列（无「操作」「结算单位」），截图确认两列均存在（操作列带 ×，结算单位列于供应商编码与商品名称之间），按图补全为 11 列（图与 JSON 冲突以图为准）。

### 全部可配置列（费用单表 9 列，cfg 实据 9 列 ✅；入库单明细表 10 列为 JSON columns + 截图实据，无 cfg 弹窗）

费用单表（9 列）：操作、费用单编号、往来单位、往来单位编码、结算单位编号、结算单位、费用项、费用金额、备注

入库单明细表（10 列）：操作、单据编号、供应商、供应商编码、商品名称、计价单位、数量、优惠后单价、优惠后金额、分摊金额

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转；支持上移/下移/恢复默认/保存。

## 4. 列表页配置（双入口「历史」标签）

- 查询条件（对标系统实据）：日期、单据编号、供应商、经手人、部门、单据状态、结算状态、单据备注
- 功能按钮（默认全选）：新增、刷新、打印(F8)、导出、配置
- 按单据列（15 列，对标实据 2026-08-14）：单据日期、单据编号、单据状态、供应商、供应商编号、经手人、部门、费用金额合计、分摊金额合计、单据备注、制单人、记账人、制单时间、记账时间、打印次数
- 按明细列（8 列）：单据日期、单据编号、费用单编号、往来单位、费用项、费用金额、分摊金额、单据备注

## 5. 业务规范

- 记账（Ctrl+Enter）单动作生效：本页无保存草稿，选单→分摊→记账一气呵成；记账后分摊金额计入入库商品成本（回写口径待复核）。
- 双表「来源→对象」结构：上表经「选费用单」弹窗选入财务域费用单（费用来源），下表经「选采购入库单」弹窗选入入库单并展开到商品明细行（分摊对象）；两个选单弹窗的检索条件与可选项范围待复核。
- 分摊方式：下拉默认「按金额」（截图实据），其余可选方式（按数量/按重量/按体积等国内 ERP 通例）待复核。
- 自动分摊：按分摊方式将上表费用总额摊入下表各明细行「分摊金额」列；勾稽关系应为 Σ分摊金额=Σ费用金额；分摊金额列是否支持手工改派待复核。
- 本单金额：底部 ¥ 金额与费用合计联动（联动口径按 Σ费用金额推断，待复核）。
- 费用来源：财务域费用单（YBFYD- 单号，《费用单开发文档》）；费用单表「费用项」列对应费用类型档案。
- 分摊对象：采购入库单（CGRKD- 单号）；分摊记账后应回写入库明细成本单价/成本金额（采购订单全量列含「成本单价、成本金额」，XSMK 依据），回写与重算口径待复核。
- 采购订单/采购入库单表头均有「其他费用」字段（JSON filterLabels 实据）：单据级手工费用与本页分摊费用的关系（并存还是互斥）待复核。
- 财务影响：记账后是否生成会计凭证（借库存商品 贷费用科目）待复核；关联查询：采购单据查询/采购明细查询（同域查询页）。
