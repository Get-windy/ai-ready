## 1. 页面概述

- **列表查询页**：配送任务台账——按「全部配送任务」**单视图**查询配送任务的执行情况与收发货双向汇总。
- 单入口（无历史/添加标签）；无新增按钮、无统计卡片、无阶段 Tab，**纯查询定位**。
- 页面标题/视图名：`全部配送任务`。
- 截图：`tool-results/ql361/pages/配发收__配送业务__配送查询.png`

## 4. 业务规范

- **一行 = 一个配送任务**（任务编号）：按「指定配送日期」计划，按「配送开始时间 / 配送结束时间」记录实际执行。
- **配送状态三值**：待配送 / 配送中 / 已配送。
- **执行资源**：司机名称、配送车辆、送货员——**司机与送货员是两个角色**，可不同人。
- **任务聚合双向单量**：
  - 正向（发货侧）：配送单量 / 订金金额 / 发货数量 / 发货金额
  - 回流（退货侧）：退货单量 / 退货数量 / 退货金额
  - 同一配送任务既送新货又带回退货，故两组数量金额成对统计。
- **装箱数量**：任务维度装箱总量；**配送里程(km)**：任务行驶里程，供司机绩效 / 费用核算；另有隐藏的**体积(m³) / 重量(kg)**为装载体积重量口径。
- **显示红冲**：被红冲的任务/单据默认隐藏，勾选后显示。
- **上下游关系**：
  - 上游：销售订单经订单处理中心「拣货/发货」（《物流发货》）生成销售出库单 XSCKD（《发货查询》），配送任务按配送日期 + 司机/车辆组织出库单的配送。
  - 退货侧：源单为销售退货单，配送带回的退货计入「退货单量/退货数量/退货金额」，收货确认走《物流退货收货》。
  - 查询条件「配送单据编号」说明**任务与单据为一对多**。
- **链接**：物流发货（订单处理中心拣货/发货直达）、发货查询（销售出库单台账）、物流退货收货（退货回流收货确认）。

## 5. 实现差异说明（本系统现状）

| 项 | 对标实测 | 本系统现状 | 差距 |
|----|---------|-----------|------|
| 页面骨架 | 数据表+固定查询区 | `ARReportPage`（`views/dispatch/query/index.vue`） | 需换 `CategoryListLayout` + `BillTableList`（含序号列齿轮） |
| 列配置 | 24 列（默认 20） | 20 列，且列名/口径与对标不一致 | 按本表第 3 章重建列定义（`defaultHidden` 表达隐藏列） |
| 默认列不符项 | 无「客户/联系电话/订单号/配送费/代收货款/优先级/重量/体积」 | 现有列含上述 8 项对标**默认不显示**列，缺「配送单量/订金金额/退货单量/退货数量/退货金额/装箱数量/送货员」 | 列口径需按对标重排 |
| 查询条件 | 13 项 + 9 段快捷时间 | 订单号 / 状态 / 骑手ID 3 项 | 需补配送状态多选、司机、车辆、送货员、任务编号、配送单据编号、制单人、制单时间、备注、显示红冲 |
| 功能按钮 | 刷新/批量打印/打印(F8)/导出/查询/保存并查询/跳转 | 「打印/导出」由 `ARReportPage` 内置 | 补批量打印、F8、保存并查询 |
| 排序/分页 | 经典分页栏 + 跳转 | 组件自带 | 对齐经典分页栏 |
| 后端 | — | `dms/dispatch/controller/DispatchController.java` + DMS 任务表 | 字段口径需扩：配送单量/订金金额/退货单量/退货数量/退货金额/装箱数量/司机编号/送货员 |
| 页面配置弹窗 | ❌ 对标无 | — | **不要**为本页加 `PageConfigPanel`（与对标一致） |
