## 页面概述

商品是**商品主数据档案**，是销售/采购/仓储/财务/商城全链路的商品主体。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 商品列表页 | `md/product/index`（component `erp/product/index`） | 4 子 Tab + 分类树 + 查询 + 列配置 |
| 商品表单页 | `md/product/form`（点「新增」/菜单「商品→添加」） | 新增/编辑商品（3 Tab：基本信息/商品图片/商城信息） |

菜单：资料 → 商品管理 → 商品（子项「添加」进表单页）。

> 列表页 4 子 Tab：全部商品 / 套餐 / 商品上架 / 商品授权。每个子 Tab 独立一整套列配置，逐个抓取如下。

### 配置功能说明
- **列配置**：数据表右上角表头单元格内齿轮图标（`icon-shezhi2` → 个人配置/全局配置弹窗）。
- ⚠️ **页面级「配置」齿轮**：本页列表/表单**未观察到**独立「查询条件/功能按钮」配置弹窗——列表页查询条件与功能按钮为界面固定项，表单页为固定字段 + 列配置。
- ✅ **当前实现说明（2026-09-11 金标准复刻）**：列表页按**资料模块布局**（与客户/供应商同款 `PartnerListPage`：暗色子Tab条 + 工具栏 + 查询区 + 左分类树 + 数据表 + 当前路径/分页），4 个子 Tab 各自独立列配置（独立 `storage-key`），列配置入口沿用数据表表头齿轮；无页面级配置弹窗（与对标一致）。

## 新增编辑商品表单页配置（3 Tab）

### 页面结构（`BillFormPage` + `useBillForm` 协作）

#### 商品标签：标准槽位 + 用户自定义昵称（2026-09-12 修正口径）

> ⚠️ 对标账号页面上那 20 个名字（早餐面点 / 酒席宴席 / … / 超市商店）**是该账号用户在「商品辅助资料 → 商品标签」自建的昵称**，
> 不是系统固有值——不能再硬编码进代码。实测佐证：标签管理页正好 20 条（列：序号 | 操作 | 对应商品 | 标签名称），
> 与「商品上架」子标签的 20 个标签列**同源**；商城信息处只列**启用中**的标签（对标少 1 个即因该标签被停用）。

| 项 | 口径 |
|----|------|
| 标准槽位 | `erp_mall_tag.tag_code` = **TAG_1..TAG_20**（固定 20 槽位，系统内部一律用编码） |
| 默认昵称 | **「标签1…标签20」**，用户可在商品辅助资料里改成业务别名 |
| 商品侧存储 | `erp_product.mall_tags` 存**槽位编码**（如 `TAG_1,TAG_5`）→ **改昵称不影响已打标商品** |
| 两个出口 | 表单「商城信息」复选框 = 启用中的标签；列表「商品上架」标签列 = 全部槽位（列标题取昵称）。两处均由字典动态渲染 |
| 顺带修复 | 「对应商品」列聚合 SQL 别名未加双引号，PostgreSQL 折叠成小写致 `row.get("productName")` 恒为 null——该列此前一直为空 |
- **商品详情页图文编辑**：自定义标题、段落、arial、16px。
- **推荐商品**：关联商品最多添加 12 条，已添加的关联商品将在商品详情页面的【相关推荐】模块做显示。推荐商品子表列：操作、商品名称、货号、型号、规格、商品单位、产地、品牌、排序值。

## 业务规范说明

- **商品类型**：`productType` SINGLE 单品 / KIT 套餐 / SERVICE 服务（列表「套餐」Tab 过滤 KIT）。
- **状态**：`status` ENABLED / DISABLED；列表「商品上架」Tab 过滤 `mallShelfStatus` 0 下架 / 1 上架。
- **价格等级**：`Grade` GRADE_1..8（8 级：餐饮店/食堂团餐/外围餐饮店/自助vip/大团餐/重点|vip01/连锁|vip/特价客户），单位明细行带出预设进价/参考成本/最近进价/批发价/零售价/最低售价/最低折扣。
- **标品**：`isStandardProduct`，若标品则要求小单位数量换算无小数、单位换算关系也不能出现小数。
- **货号生成**：`productCodeAlias` 为空时保存自动生成 `SP` + 时间戳36进制大写。
- **保存校验**：商品名称/分类/行业类别/至少 1 单位/销售常用单位必填。
- **批量改价**：跳转 `/erp/product/price-batch`（批量改价页），`batchUpdatePrices` PUT `/batch-prices`。
- **可用库存**：`availableStock` 由库存模块镜像（销售/采购/仓储整链路由商品主数据）。
- **行业类别/标签**：`industryCategory`（行业类别，列表可筛选）；商城信息「商品标签」= `erp_mall_tag` 字典的启用槽位（标准槽位 TAG_1..TAG_20，默认名「标签1…标签20」，用户可改昵称）。
