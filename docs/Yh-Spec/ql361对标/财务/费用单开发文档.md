# 费用单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/expense-doc/form`（表单）+ `finance/expense-doc`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页**：非主营支出的费用登记（往来单位费用/内部费用两类）。页面性质 = 费用类型单选 + 表头字段区 + 费用项明细表格 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/expense-doc/form`；标签「历史」→ `finance/expense-doc`（列表）。
- 单号实据 NO. YBFYD-20260723-001（YBFYD- 前缀 + YYYYMMDD-序号，"一般费用单"拼音首字母）；标题行含附件、键盘（快捷录入）、齿轮（配置）图标（截图实据）。

## 2. 表单页配置

### 表头字段（必填 * 标注 / 选填）

- 费用类型：往来单位费用 / 内部费用（单选，默认往来单位费用；选"内部费用"时往来单位是否仍必填待复核）
- 必填：往来单位\*（带新增+搜索）、经手人\*、单据日期\*（默认当天）
- 选填/联动：往来编号（只读，随往来单位带出）、付款账户、付款金额（带"全/清"）、更多账户（带"…"弹窗）

### 全部表单字段（18 个，cfg 实据 18 字段 ✅）

- 类型：往来单位费用、内部费用（cfg 原文两条，即"费用类型"单选）
- 表头：编号、往来单位、往来编号、经手人、部门、单据日期、付款账户、付款金额、更多账户
- 表尾：审核人、摘要
- 备注/信息：单据备注、制单人、制单时间、打印次数
- 底部：本单金额

### 字段分组

费用类型单选 → 表头 → 费用项明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 底部本单金额与操作。

### 录单默认值

费用类型默认"往来单位费用"、单据日期默认当天（截图实据）。

### 打印设置

无（打印模板配置细节待复核；表单页有打印(F8)按钮及打印次数/打印记录字段）。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter。

## 3. 数据表格列配置

### 默认显示列（5 列，抓取 JSON columns 实据）

操作、费用编号、费用名称、金额、备注

> JSON columns 首项"操作 费用编号 费用名称 金额 备注"为抓取拼接串（表头整行文本），已剔除，不计入列数。

### 全部可配置列（5 列，cfg 实据 5 列 ✅）

操作、费用编号、费用名称、金额、备注

## 5. 业务规范

- 状态流转：保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）；记账后费用生效——付款账户资金减少、费用科目入账，并生成会计凭证（KJPZ-）。
- 往来单位费用 vs 内部费用：往来单位费用挂往来单位（如为客户代垫运费、供应商罚款）；内部费用不挂往来单位（公司日常开支），仅科目入账。
- 一单多费用项：明细按费用类型分行（费用编号/费用名称来自费用类型主数据），本单金额=Σ金额；付款金额与费用合计的差额处理（挂账费用/后续核销）待复核。
- 费用科目：损益类费用科目实据 6601 销售费用 / 6602 管理费用 / 6603 财务费用（科目余额表实据）。
- 与其他页面关系：费用类目主数据（资料 → 财务账户 → 费用类型；列=操作、科目编号、科目名称、核算项；按钮=新增费用…）；反向单据《其他收入开发文档》（结构对称）；采购侧费用另有"采购费用分摊"（采购域）；下游账簿：明细账/科目余额表费用科目；本系统前端目录 `finance/expense-doc`（另有 expense-apply/expense-approval/expense-pay/expense-reimburse/expense-stats 费用报销系列，对应关系待复核）。
