## 1. 页面概述

- **列表页**：商品图片批量上传与主图维护页，2 个子标签（商品图片列表 / 图片空间），当前抓取为商品图片列表子标签，按商品逐行上传图片。
- 截图：![图片管理](../../../../tool-results/ql361/pages/资料__商品管理__图片管理.png)

## 2. 页面配置

### 查询条件

- 查询方案（--查询方案--，支持保存方案）
- 筛选条件（请输入品名/货号/助记码）
- 图片（全部，按"有/无图片"过滤；本系统落地为 全部 / 已上传图片 / 未上传图片）
- 规格、型号、产地、品牌
- 商品状态（全部）
- 排序（按货号）、顺序
- 左侧商品分类树按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：查询、选择图片、跳转（分页跳转）
- 注：本页无 刷新/打印(F8)/导出 按钮（截图确认右侧无功能按钮行），"选择图片"为行内选择按钮
- 行级操作（截图确认）：选择图片、主图（单选）、删除（图片下方红色 ×）
- 分页（实测 `10-tab1.json` labels）：首页 / 上页 / 第(x/y)页 / 下页 / 尾页 / 跳转到 N 页 / 共 N 条记录 / 每页显示 N 行（抓到 "(1/165)"、"共 3282 条记录"、"每页显示 20 行"）
- 左侧分类树（实测 `30-tab1-struct.json` treeTexts）：根节点 **「全部商品」** + 各商品分类（饮品原料/低温熟食/…），根节点默认展开
- 商品图片缩略图（实测 `30-tab1-struct.json` gridImages.w）：**100×100**

### 子标签 2「图片空间」（2026-09-11 复抓实据）

- 查询条件：请输入关键字搜索、图片匹配方式（按名称 / 按商品货号）、查询
- 工具栏：上传图片（左）；自动匹配 / 删除 / 搬移（右，后两者需先勾选）
- 左侧图片目录树：我的图片
- 网格头：「我的图片」+ 橙色自动匹配规则提示 + 全选 / 只显示图片
- 网格内容：缩略图 + 图片名称；分页
- 网格缩略图（实测 `32-space-struct.json` gridImages.w）：**138×138**，每行约 6 格
- 分页（实测 `20-tab2.json` buttons）：页码 `1 2 3 … 106` + 下一页
- 图片目录面板标题栏（截图实测）：`图片目录` + `✕` + `➕` + `«`（疑似 ql361 左侧 dock 面板通用控件，本系统仅实现 `«` 折叠）
- 自动匹配规则（页面原文）：将图片的名称命名为匹配方式对应的名称，多张图片在图片名称后用 -1、-2 表示。如：匹配方式为按商品货号匹配，则匹配的图片的命名为 sp001-1、sp001-2。

### 打印配置

无（页面无打印按钮，截图确认）。

## 3. 数据表格列配置

### 默认显示列（9 列，抓取 JSON columns 实据，商品图片列表子标签）

商品名称、商品状态、货号、规格、型号、产地、品牌、上传图片、图片

> 本页 JSON columns 无抓取拼接串（首项"商品名称"为真实单列）。图片空间子标签为图片网格视图，无列配置。

### 全部可配置列

9 列全部可配置（无隐藏列、无必填列）；固定列「操作」。列配置弹窗（2026-09-11 复抓）：
- 标题「列配置」，两个标签页 **个人配置 / 全局配置**，提示「只对当前操作员有效，在全局配置中配置字段显示、排序。」
- 表格列：序号 | 上级(拖拽手柄) | 列名 | 显示名(可编辑) | 显示(复选框)
- 底部按钮：上移 / 下移 / 恢复默认 / 保存

## 4. 业务规范

- 一行一商品：图片按商品维护（不按单位分行，与商品条码/价格页粒度不同）
- 主图：多张图片中选定一张为主图（截图实据：图片下方"主图"标记），主图用于商城/单据显示
- 选择图片：行内"选择图片"从图片空间素材库选图并关联该商品，关联后即时显示在"图片"列
- 商品状态：启用/停用，与商品档案显示状态同步
- 图片（全部）查询条件按"有/无图片"过滤，便于批量补齐缺图商品
- 与其他页面关系：商品（图片列显示商品主图缩略图，同源维护）、商城（B2B/B2C 商品图片展示）、图片空间子标签（**已抓取 = 图片素材库**：上传 / 自动匹配 / 删除 / 搬移，见第 2 章）
