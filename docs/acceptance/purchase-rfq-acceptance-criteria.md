## 🎯 总体验收标准

### 1. 功能完整性
- [ ] 实现完整的采购询价/报价业务流程
- [ ] 支持多供应商同时询价和报价
- [ ] 提供比价分析和决策支持功能
- [ ] 支持从报价自动生成采购订单

### 2. 性能要求
- [ ] 询价单创建响应时间 ≤ 2秒
- [ ] 报价提交响应时间 ≤ 3秒
- [ ] 比价分析计算时间 ≤ 5秒
- [ ] 系统支持100个并发用户
- [ ] 系统支持500个供应商同时报价

### 3. 安全性要求
- [ ] 实现完整的权限控制
- [ ] 数据访问权限控制正确
- [ ] 操作日志完整记录

### 4. 可用性要求
- [ ] 系统可用性 ≥ 99.9%

## 📝 详细验收标准

### 1. 询价单管理模块

#### 1.1 创建询价单
- [ ] **功能验证**: 可以成功创建询价单
- [ ] **编号生成**: 系统自动生成唯一的询价单号（格式：INQ+年月日+4位随机数）
- [ ] **状态管理**: 创建后状态为"草稿"
- [ ] **数据验证**: 必填字段验证（标题、询价类型、截止日期、采购员）
- [ ] **时间验证**: 截止日期必须晚于当前时间至少24小时
- [ ] **明细管理**: 可以添加、编辑、删除询价明细
- [ ] **供应商邀请**: 可以选择邀请的供应商
- [ ] **权限控制**: 只有采购专员可以创建询价单

#### 1.2 编辑询价单
- [ ] **状态限制**: 只能编辑"草稿"状态的询价单
- [ ] **字段编辑**: 可以修改所有字段
- [ ] **明细编辑**: 可以修改询价明细
- [ ] **供应商编辑**: 可以修改邀请的供应商
- [ ] **保存验证**: 修改后自动保存，返回成功提示
- [ ] **权限控制**: 只有创建人或采购经理可以编辑

#### 1.3 发布询价单
- [ ] **完整性验证**: 发布前验证询价单完整性
- [ ] **供应商验证**: 至少选择了一个供应商
- [ ] **状态变更**: 发布后状态变为"已发布"
- [ ] **时间记录**: 记录发布时间和发布人
- [ ] **通知发送**: 被邀请供应商收到询价通知
- [ ] **权限控制**: 只有采购专员可以发布询价单

#### 1.4 查询询价单
- [ ] **列表查询**: 可以查询询价单列表
- [ ] **条件筛选**: 可以按状态、日期、采购员筛选
- [ ] **分页功能**: 支持分页查询
- [ ] **排序功能**: 支持按创建时间、截止时间排序
- [ ] **详情查询**: 可以查询询价单详情
- [ ] **权限控制**: 只能查看自己有权限的询价单

#### 1.5 关闭询价单
- [ ] **状态限制**: 只能关闭"已发布"或"报价中"状态的询价单
- [ ] **关闭验证**: 关闭前验证是否有报价
- [ ] **状态变更**: 关闭后状态变为"已关闭"
- [ ] **时间记录**: 记录关闭时间和操作人
- [ ] **权限控制**: 只有采购专员可以关闭询价单

#### 1.6 取消询价单
- [ ] **状态限制**: 只能取消"草稿"或"待审批"状态的询价单
- [ ] **状态变更**: 取消后状态变为"已取消"
- [ ] **时间记录**: 记录取消时间和操作人
- [ ] **权限控制**: 只有创建人或采购经理可以取消

### 2. 报价单管理模块

#### 2.1 提交报价
- [ ] **功能验证**: 供应商可以成功提交报价
- [ ] **编号生成**: 系统自动生成唯一的报价单号
- [ ] **状态管理**: 提交后状态为"已提交"
- [ ] **数据验证**: 必填字段验证（报价金额、有效期、供应商）
- [ ] **时间验证**: 报价有效期必须晚于当前时间
- [ ] **明细管理**: 可以添加、编辑、删除报价明细
- [ ] **价格计算**: 金额、税额自动计算正确
- [ ] **附件上传**: 可以上传报价附件
- [ ] **权限控制**: 只有被邀请的供应商可以提交报价

#### 2.2 查询报价单
- [ ] **列表查询**: 可以查询报价单列表
- [ ] **条件筛选**: 可以按状态、供应商、询价单筛选
- [ ] **分页功能**: 支持分页查询
- [ ] **排序功能**: 支持按报价时间、金额排序
- [ ] **详情查询**: 可以查询报价单详情
- [ ] **权限控制**: 供应商只能查看自己的报价单

#### 2.3 审查报价
- [ ] **状态限制**: 只能审查"已提交"状态的报价单
- [ ] **评分功能**: 可以对报价进行评分（价格、质量、服务）
- [ ] **审查意见**: 可以填写审查意见
- [ ] **状态变更**: 审查后状态变为"已审查"
- [ ] **时间记录**: 记录审查时间和审查人
- [ ] **权限控制**: 只有采购专员可以审查报价

#### 2.4 接受报价
- [ ] **状态限制**: 只能接受"已审查"状态的报价单
- [ ] **状态变更**: 接受后状态变为"已接受"
- [ ] **时间记录**: 记录接受时间和操作人
- [ ] **权限控制**: 只有采购经理可以接受报价

#### 2.5 拒绝报价
- [ ] **状态限制**: 只能拒绝"已审查"状态的报价单
- [ ] **拒绝原因**: 必须填写拒绝原因
- [ ] **状态变更**: 拒绝后状态变为"已拒绝"
- [ ] **时间记录**: 记录拒绝时间和操作人
- [ ] **权限控制**: 只有采购经理可以拒绝报价

#### 2.6 撤回报价
- [ ] **状态限制**: 只能撤回"已提交"状态的报价单
- [ ] **状态变更**: 撤回后状态变为"已撤回"
- [ ] **时间记录**: 记录撤回时间和操作人
- [ ] **权限控制**: 只有供应商可以撤回报价
