# 预警查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/alert-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：按仓库/商品/预警类型查询触发库存上下限预警的商品清单。
- **单入口**：仅列表页（查询区 + 左侧商品分类树 + 数据表格 + 分页）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 全部仓库 / 指定仓库（单选）
- 商品、品牌
- 预警类型（全部）下拉（枚举值待复核）
- 查询按钮

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、导出、查询、跳转（分页跳转）

### 打印配置

无（抓取未覆盖打印配置弹窗，待复核）。

## 3. 数据表格列配置

### 默认显示列（9 列，抓取 JSON columns 实据）

商品名称、货号、口味、型号、单位、预警仓库、库存上限、库存下限、说明

> 注：JSON columns 首项「商品名称 货号」为抓取拼接串（表头多单元格文本相连），非真实单列，已剔除。

### 全部可配置列

待复核（无 XSMK 列配置存档，需在对标系统打开列配置弹窗补抓）。

## 4. 业务规范

- 本页为只读查询：列出在预警设置中配置了上下限、且当前库存触发预警（高于上限或低于下限）的商品。
- 预警类型（全部）下拉：推断含 库存不足（低于下限）/ 库存积压（高于上限） 等类型（枚举待复核）。
- 库存上下限的比较口径在预警设置页配置（「库存上下限比较值：账面库存-待发货」，见《预警设置开发文档》）。
- 工作台登录时弹出「预警提醒」（含近效期预警）与本页同属预警体系（`tool-results/ql361/menu-仓储.png` 实据：预警提醒弹窗含近效期预警子标签，筛选项 仓库/商品/品牌/商品状态(近效期商品)/批次条码，列 图片/商品名称/货号/仓库/批号/生产日期/到期日期/有效天数）。
- 数据来源：预警设置（库存上下限阈值在此维护）；采购域联动：采购→采购准备→库存预警补货（按预警缺货生成补货建议）。
