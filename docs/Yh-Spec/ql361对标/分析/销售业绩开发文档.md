## 1. 页面概述

- **列表查询页**（统计分析页）：拓客→拜访→订货→销售→退货→回款全漏斗业绩统计（按时间/按职员两维度 + 九项指标卡片 + 多级表头表格）；销售漏斗全链路业绩看板。菜单路径：分析 → 采销分析 → 销售业绩。

## 4. 业务规范

### 统计口径

- **漏斗链路**：拓客数（新增客户）→ 拜访统计（拜访客户数、拜访完成率=实际拜访/计划拜访）→ 订货统计（订货客户数、实订金额=销售订单金额）→ 销售统计（实销金额=销售出库金额、其他费用）→ 退货统计（退货金额、退货率=退货金额/实销金额×100）→ 回款数据（回款总额）
- **实订 vs 实销**：实订金额取自销售订单（XSDD-），实销金额取自销售出库单（XSCKD-）；本周实订 8,328 元 vs 实销 93,973.99 元，差异为期初在手订单本期发货
- **退货率**：本周退货金额 3,924.59 / 实销金额 93,973.99 ≈ 4.18%（卡片显示 4.01%，分母口径含其他调整项，精确口径待复核）
- **指标卡片（九卡三色）**：订货客户数、实订金额、实销金额、回款总额（红）；退货金额、退货率（橙）；拓客数、拜访客户数、拜访完成率（青）
- **按职员 Tab**：同一套 11 指标按经手人分组（职员业绩排名）

### 与其他页面关系

- 取数：销售订单/销售出库单/销售退货单/收款单（经营历程流水）、客户主数据（拓客）、外勤拜访记录（拜访统计）
- 下游：《业绩提成中心》《业务员提成》（业绩→提成取数基础）、《经营分析》（利润口径扩展）
