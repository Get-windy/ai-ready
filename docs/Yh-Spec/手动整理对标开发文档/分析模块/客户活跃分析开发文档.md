## 1. 页面概述

客户活跃分析页是**客户运营的流失预警台账**：以「客户分类」为分层结果列，以「未交易天数」为分层依据，配合「最近交易日期 / 最近拜访日期」两个时序锚点与「近 90 天下单金额 / 次数」两个活跃度指标，形成「谁在活跃、谁在流失、流失到哪一步」的一页视图。页面顶部另有**分层公式卡片**（红/青/紫三色，算式形态）直观展示有效客户构成。**单入口、单视图**（本页**无**页内视图 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 客户活跃分析 | `analytics/customer-active` | 单入口单视图台账（查询区 + 分层公式卡 + 8 列表格 + 合计行 + 分页） |

单入口：分析 → 采销分析 → 销售分析 → 客户活跃分析。

## 4. 业务规范

### 统计口径（客户分层）

- **有效客户 = 活跃客户 + 即将流失客户**：实测 **893 = 706 + 187 ✅**（分层公式卡实据）。口径上**不含**已流失/无效客户（与基准文档一致）。
- **客户分类（分层结果列）**：按「未交易天数」分层。实测取值 `活跃客户` / `即将流失客户` 两类；**实测可见边界**：未交易天数 `0 / 1 / 5 / 6 / 7 / 9 / 13` 归「活跃客户」，`37 / 44` 归「即将流失客户」。
  > 具体阈值（如「≥30 天即即将流失」）由工具栏 `客户分类设置` 维护，实测**未打开该弹窗**，阈值与是否含「流失客户」第三档 **待复核**。
- **未交易天数 = 当前日期 − 最近交易日期**（实测三点验证，✅）：
  - 敦煌市阿堡仔店：`2026-08-02` → `44` 天 ✅（8/2→9/2=31，9/2→9/15=13）
  - 嘉峪关市祁丰乡享运源餐厅：`2026-09-10` → `5` 天 ✅
  - 肃州区瑞瑞翔餐饮店(明洞炸鸡)：`2026-09-14` → `1` 天 ✅
  - 敦煌市派大星家沙拉煎饼：`2026-08-09` → `37` 天 ✅（8/9→9/9=31，+6）
- **近 90 天下单金额 / 次数**（表头口径，即列配置弹窗「近半年下单金额 / 次数」）：滚动窗口内的销售订单口径。实测样本：`13,615 / 38`、`7,771.67 / 46`、`2,086 / 7`、`804 / 9` —— 次数与金额**并非线性对应**，说明为**去重单数 + 金额求和**两个独立指标（非客单价派生）。
- **最近拜访日期**：外勤拜访记录联动。实测**前 20 行为空**（该批次客户近期无拜访记录写入），列本身可空 → 属**流失预警动作项**（拜访为空即需触达）。
- **合计行**：`近90天下单金额` 合计 `3,108,744.15`、`近90天下单次数` 合计 `10,398`（合计行**逐列求和**，含未来默认隐藏列亦应计入——本页无隐藏列，无此歧义）。

### 取数来源与上下游关系

- **取数**：销售订单（最近交易日期、近窗口下单金额/次数、历史口径）＋ 外勤拜访记录（最近拜访日期）＋ 客户主数据（客户名称/编号/分类）＋ 分层阈值配置（客户分类设置）。
- **同源页**：《销售业绩》（其「拓客数」为新增客户入口，本页为存量客户的活跃/流失侧）、《销售欠款分析》（同一批客户的欠款侧指标）。
- **下游**：客户运营动作（拜访计划 / 促销活动触达）；本页**只读**，不产生业务单据。
- **与《交易分析》《商城客户列表》的分工**：本页口径为**ERP 往来单位（客户档案）侧**，非 CRM 公海客户、非商城注册用户。

## 5. 实现差异说明

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/customer-active/index.vue`（共 **69** 行）。
- **骨架**：`ARReportPage`（`index.vue:2-23`，`title="客户活跃分析"`、`export-file-name="客户活跃分析"`、`row-key="customerId"`），**非**金标准路线 A。`ARReportPage` 为纯报表壳（`components/ARReportPage/ARReportPage.vue`：查询表单 `:12-65` + 工具栏 `:74-99` + `a-table` `:100-120` + 内置 CSV 导出 `:340-371`），**不含** `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`，**无列配置齿轮、无页面配置弹窗、无打印**。
- **查询条件**：`queryFields`（`index.vue:38-41`）**仅 2 项** —— `关键字`（input，占位「客户名称」）、`统计天数`（input，占位「默认 30 天」）。**无**客户选择器、**无**客户类型下拉。
- **列定义**：`columns`（`index.vue:44-53`）共 **8 列** —— 客户、近N天单数、近N天金额、最近下单时间、历史单数、历史总额、跟进次数、活跃度。
  - **与对标 8 列的对照**：语义近似 4 列（`客户`≈客户名称、`最近下单时间`≈最近交易日期、`近N天单数`≈近窗口下单次数、`近N天金额`≈近窗口下单金额）；**缺失 4 列**（客户分类、客户编号、最近拜访日期、未交易天数）；**多出 4 列**（历史单数、历史总额、跟进次数，以及与「近N天」同源但列名动态化的近N天单数/金额拆分计为 2 列）。
  - **分层列口径不同**：本系统 `activityLevel` 取值为 `活跃 / 一般 / 沉默` 三档（`ACTIVITY_COLOR` `index.vue:32-36`），与对标 `活跃客户 / 即将流失客户` **命名与档数均不一致**。
- **数值格式化**：`formatNumber`（`index.vue:55-58`）用于 近N天单数/历史单数/跟进次数；`formatMoney`（`index.vue:60-63`）用于 近N天金额/历史总额；`活跃度` 走 `a-tag` 三色标签（`index.vue:11-15`，活跃=green / 一般=orange / 沉默=default）。
- **数据来源**：`saleAnalyticsApi.customerActivePage({ days: 30, ...params })`（`index.vue:66-68`）→ `/erp/sale/analysis/customer-active/page`（`api/analytics.ts:449-458`）。后端 `SaleAnalysisController.customerActivePage`（`erp/erp-sales/.../controller/SaleAnalysisController.java:30-40`），入参 `page/size/days/activeDays/silentDays/keyword`，其中 `activeDays` 默认 30、`silentDays` 默认 90。
- **后端 DTO**：`CustomerActiveAnalysisDTO`（每客户一行：近N天订单数/金额、最近下单时间、历史订单总数/总额、跟进次数、活跃度分层）。
- **storage-key**：无（未使用列配置/页面配置持久化）。
- **容错**：`ARReportPage.fetchData` 失败时 `message.error('查询失败，请检查网络后重试')` + `console.warn`（`ARReportPage.vue:300-307`），**有用户可见提示**。
