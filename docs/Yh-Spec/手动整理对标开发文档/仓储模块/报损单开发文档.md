# 报损单开发文档

## 页面概述

报损单用于库存损耗/报废出库录单（按批次报损）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 报损单列表页 | http://localhost:5656/erp/stock-damage/index | 双入口「历史」标签 |
| 新增/编辑报损单表单页 | http://localhost:5656/erp/stock-damage/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5009（原"报损管理"，本次改名"报损单"） |
| menu_code | `erp:stock-damage` |
| 主菜单路径 | `erp/stock-damage/form`（点击进新增表单） |
| 标签「历史」路径 | `erp/stock-damage/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-damage/form`（表单）、`erp/stock-damage/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记帐后生效扣减库存。
- 数量列名为「报损数量」（区别于通用「数量」），按批次报损（批次条码/生产日期/保质期/到期日期列齐备）。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 报损金额按成本计价计入本单金额（列中无单价/金额列，金额取库存成本，待复核）。
- 与报溢单互为反向单据（一损/一溢）；盘点单的盈亏处理可生成报损单/报溢单（盘点单「盘点处理」流程推断，待复核）。
- 记帐后影响 分析→仓配分析→查库存/库存明细。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
