# 在线支付对账单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/online-payment-reconcile`（列表查询页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：在线支付渠道流水与业务订单的逐笔对账查询（查询区 + 数据表格 + 对账标记；只读流水 + 轻标记维护）。菜单路径：财务 → 收款 → 在线支付对账单。
- **页面实据**：底部"合计"行（订单金额合计 7489）；分页 第(1/2)页 / 共 33 条记录 / 每页显示 20 行；行数据——支付状态=支付成功、支付类型=收款、支付方式=微信、流水号 LM 开头长串（LM2000049892026072315131…）、提交日期精确到时分秒。

## 2. 页面配置

### 查询条件

- 查询方案（--查询方案--，支持保存方案）

- 流水号/来源订单（组合模糊输入）、日期范围（起 至 止）、源单客户

## 4. 业务规范

### 状态流转与特殊交互

- 流水来源：客户在线支付（商城/订单）成功后在支付渠道产生流水，本页按时间拉取展示；来源订单回链销售订单（XSDD-）
- 对账标记：财务将流水与银行/支付账户实际到账核对后，点击对账标记由"否"置"是"；对账标记（全部/是/否）可作为查询条件
- 支付类型：收款（截图实据；退款等反向类型值域待复核）
- 与待确认款项衔接：在线支付款项到账确认在《待确认款项开发文档》完成，本页侧重渠道流水与订单的笔笔核对

### 与其他页面关系

- 来源订单：销售订单（XSDD-，销售域）在线支付产生
- 到账确认：《待确认款项开发文档》（来源订单列同源）
- 渠道范围：截图实据支付方式=微信；支付宝/聚合支付等渠道覆盖待复核（零售单收款方式含支付宝/微信，XSMK 实据）
- 本系统前端目录 `finance/online-payment-reconcile`（dynamicRoutes.ts 实据）
