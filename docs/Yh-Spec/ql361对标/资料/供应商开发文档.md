# 供应商开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/partner`（往来单位-供应商分类）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：供应商主数据档案列表，左侧供应商分类树 + 查询区 + 数据表格；无子标签，单一列表视图。
- **双入口**：主菜单 → 供应商表单页；标签「历史」→ 供应商列表页（截图：![供应商列表页](../../../../tool-results/ql361/pages/资料__往来单位__供应商__list.png)，列表页查询条件与表格列配置待抓取弹窗数据后补全）。
- 截图：![供应商](../../../../tool-results/ql361/pages/资料__往来单位__供应商.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入供应商编号/名称/助记码）
- 显示状态（已启用）
- 勾选项：显示层次结构、显示客户中的供应商
- 左侧供应商分类树（全部供应商、合作商、生产厂家、家庭成员倒账、供应商押金、公司员工）按分类过滤
- JSON filterLabels 实据为 20 个"更多"占位，对应查询配置区折叠字段，全量查询条件待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、导入、刷新、打印(F8)、导出、更多、查询、跳转（分页跳转）
- 行级操作（截图确认）：订货、修改、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

操作、供应商编号、供应商名称、联系人、联系电话、新增时间、附件、备注、经营系列、经营面积、税号、开户行、银行账号

> JSON columns 首项"操作 供应商编号 供应商名称"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 订货：行级直接为该供应商开采购订单（与客户页"代客下单"对称）
- 显示客户中的供应商：供应商与客户可为同一主体（互为往来单位），勾选后并列显示
- 显示层次结构：供应商支持层级（分类树与列表联动）
- 供应商分类树含"家庭成员倒账/供应商押金/公司员工"等内往类分类：支持非采购目的的内部往来单位管理
- 经营系列/经营面积：供应商经营画像字段，用于供应商评估（供应商门户绩效联动）
- 与其他页面关系：采购订单/采购入库单（供应商为必填主数据；行级"订货"直达采购录单）、供应商门户（erp-supplier-portal：询价报价/绩效/积分以供应商档案为主体）、客户（往来单位互转）、互联账号（供应商与互联平台账号绑定关系）
