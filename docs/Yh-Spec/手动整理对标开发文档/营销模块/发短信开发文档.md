## 4. 业务规范

- **发送前置（实据归纳）**：选择客户（>0 人）→ 填写或引用模板得到短信内容 → 勾选《短信协议》→「确认发送」由置灰转可用。
- **计费规则**：67 字/条，超出部分按新一条短信计费；账户剩余短信条数为配额（实测 100 条），用尽需联系客服购买——SaaS 增值计费项。
- **签名与合规**：公司签名以【】包裹强制前置；营销短信强制带「拒收请回复R」退订后缀；通知短信与营销短信分通道（营销短信受更严内容与时段管制）。
- **模板复用**：「选择短信模板」引用「短信模板管理」维护的模板；发送结果可在「短信历史」回溯（列结构待复核）。
- **与其他页面关系**：客户选择器数据源为 ERP 往来单位-客户（带移动电话的客户档案）；发送效果归入分析域「营销分析」；本系统落地对应 `/api/sms`。

### 剩余缺口

1. **🔴 页面性质整体偏离（最大缺口）**：对标是**短信编辑群发页**（选择客户 → 短信内容/模板 → 签名 → 短信类型 → 协议 → 手机预览 → 确认发送 + 短信历史/模板管理子标签）；本系统落地的是**短信通道配置页**（服务商 AK/Secret/签名/启停 + 保存配置/测试连通性）。两者**不是同一功能**，本页**未实现对标任何核心交互**。
2. **未达金标准路线 A**（如实标注）：本页未使用 `CategoryListLayout`/`BillDetailTable`/`PageConfigPanel` 任一金标准骨架组件。
3. **群发能力缺失**：无「选择客户」「短信内容」「短信模板」「短信类型」「短信协议」「确认发送」「手机预览」入口；`index.vue:7-8` 自述「群发任务与发送明细将在后端提供端点后接入」。
4. **短信历史 / 短信模板管理子标签**：基准文档记为 3 个子标签，2026-09-15 实测 `tabs={}` 未取到，**子标签是否存在、列结构如何均待复核**；本系统**无**这两个子标签实现。
5. **计费配额**：对标实测「剩余短信 100 条」为账户配额；本系统无配额展示/扣减实现。
6. **AccessSecret 明文展示**：`index.vue:33-38` 用 `a-input-password` 承接密钥，但配置持久化位置与加密方式**待复核**（不臆断）。
