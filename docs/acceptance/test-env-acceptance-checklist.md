```bash

```

### 2. 常用检查命令
```bash
# 服务健康检查
curl -f http://localhost:8080/health

# 数据库连接检查
mysql -h localhost -u test_user -p

# 监控状态检查
curl http://localhost:9090/api/v1/targets

# 日志查询检查
curl -XGET 'localhost:9200/_cat/indices?v'
```

### 3. 检查工具推荐
- **API测试**: Postman, curl

- **安全扫描**: OWASP ZAP, nmap
- **监控检查**: Prometheus UI, Grafana
- **日志分析**: Kibana, ELK Stack
