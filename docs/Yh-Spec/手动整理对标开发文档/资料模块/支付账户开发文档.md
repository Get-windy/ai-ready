## 页面概述

支付账户用于展示**财务资金账户**（银行账户/现金/内部/外部）的账户信息与余额，统计账户状态。**当前为只读列表 + 启/停用**，无新增/编辑表单（新增账户走财务资金账户管理）。单入口。

| 页面 | 地址 | 说明 |
|------|------|------|
| 支付账户 | `md/payment-account` | 账户统计卡片 + 账户列表（只读）+ 启/停用 |

菜单（本系统）：资料 → 支付管理 → 支付账户。

### 配置功能说明

- **统计卡片**：账户总数 / 启用数 / 余额合计（前端本地汇总）。
- ❗ **只读提示**：页顶 `a-alert` 明示「仅支持列表/统计/状态/余额，新增/编辑/删除待接入」。
- ⚠️ **当前实现说明**：本页为 `a-alert` + `ARReportPage`（带 stat-cards），**无表单**，后端无新增/编辑/删除端点。

## 业务规范说明

- **账户类型**：1 银行 / 2 现金 / 3 内部 / 4 外部；**账户等级**：1 基本 / 2 一般 / 3 专用。
- **数据源**：`finance_account` 表；列表调**不分页** `GET /list`。
- **余额**：`balance` 默认 0，`currency` 默认 CNY；`PUT /balance/{accountId}`（body BigDecimal）可维护余额。
- **状态切换**：行内启用/停用走 `PUT /status/{id}`（body 为裸状态数字）。
- **只读边界**：当前账户新增/编辑/删除通过《银行账户》或财务资金账户管理维护，本页只读展示资金账户 + 启停用。
- **统计卡片**：前端从 `list` 结果本地汇总（账户总数/启用数/余额合计）；后端 `/statistics` 已存在但前端未使用。
