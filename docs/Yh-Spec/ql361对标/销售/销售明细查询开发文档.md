# 销售明细查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/detail-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：销售单据商品明细级查询（一行 = 一个单据的一条商品明细），按商品维度追溯销售。
- 页面结构：查询区 + 工具按钮区 + 左侧商品分类树 + 数据表格 + 合计行 + 底部分页；按单据 / 按明细两个 tab。

## 2. 页面配置

### 查询条件

- 按单据 tab（查询区当前展开，抓取 JSON filterLabels + 截图实据）：查询方案（--查询方案--，可保存复用）、时间快捷段（昨日/今日/本周/近一周/本月/上月/近三月/本年）、单据日期（起至止）、日期类型（默认"单据日期"）、单据编号、商品、品牌、所属行业类别（下拉）、是否赠品（下拉，全部）、促销商品（下拉，全部）、客户、经手人、仅统计车辆库（勾选框）、更多条件（折叠展开，展开项全量待复核）
- 按单据 tab（查询条件管理弹窗，抓取实据）：日期、单据编号、供应商/客户、经手人、部门、制单人、仓库、单据状态、单据备注、审核人
- 按明细 tab（查询条件管理弹窗，抓取实据，13 项）：日期、单据编号、商品、供应商/客户、经手人、部门、制单人、审核人、仓库、单价状态、单据备注、明细备注、是否赠品
- 搜索区域规则：默认显示 2 排（必须包含查询及后续 3 个勾选选项），超出自动折叠，点击"更多条件"展开。

### 功能按钮

- 抓取 JSON buttons 实据：刷新、打印(F8)、导出、查询、更多条件、跳转（分页）
- 行级操作（截图确认）：批次号、明细备注

### 打印配置

无（页面有打印(F8)按钮，打印模板配置细节待复核）。

## 4. 业务规范

- 一行一明细：同一单据含 N 个商品即占 N 行（截图实据：XSCKD-20260723-034 连续出现 4 行），与"销售单据查询"的一行一单形成维度互补。
- 销售数量 vs 数量/单位：默认显示列同时存在"销售数量"与"数量、单位"，对应 XSMK 全量列的"销售数量数量/销售数量单位"与"销售常用单位数量/销售常用单位"双计量口径。
- 是否赠品/促销商品查询条件支持赠品与促销品的专项追溯；商品分类树按商品分类过滤明细行（树节点为业务方真实分类：饮品原料/低温熟食/调理冻品等）；行级"批次号"查看该明细行的批次轨迹（推断，具体弹层内容待复核）。
- 数据源同销售单据查询（销售出库单/退货单/零售单/换货单的明细行）；单据编号链接跳转原单据。
- 全量列含 8 个价格等级昵称列与成本/毛利/毛利率列，是销售毛利分析的明细级数据源。
