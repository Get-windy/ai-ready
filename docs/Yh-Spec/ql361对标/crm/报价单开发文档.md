# 报价单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`crm/quotation/form`（表单）+ `crm/quotation/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=历史）：主按钮 → 新增/编辑表单页 `crm/quotation/form`；标签"历史"→ 列表页 `crm/quotation/index`。
- **表单页**：CRM 报价——对客户的商品报价，可转销售订单（我方实现，views/crm/quotation/form.vue）。
- **列表页**：报价单台账（我方实现，views/crm/quotation/index.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `crm/quotation/index.vue`（4 项）

- `quotationNo` 报价单号（输入）
- `quotationName` 报价名称（输入）
- `customerName` 客户名称（输入）
- `status` 状态（下拉：草稿/已发送/已接受/已拒绝/已过期）

### 功能按钮

来源：我方源码 `crm/quotation/index.vue`

- 工具栏：新增（Ctrl+N）、刷新（F5）、批量发送（选中行）
- 行操作：查看、编辑、发送、打印、复制报价、删除

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段

来源：我方源码 `crm/quotation/form.vue`

- 必填（formRules）：报价名称\*、客户名称\*（customerId）、报价日期\*
- 选填：报价单号（自动生成，disabled）、联系人、联系电话、有效期(天)、币种、关联商机、报价条款、备注

### 字段分组／录单默认值／打印设置

- 字段分组：基本信息 → 报价明细 → 费用汇总 → 附加信息 → 审批流程
- 明细表格列（8 列）：产品、规格、数量、单位、单价、折扣%、小计、操作
- 费用汇总（4 项）：产品金额、折扣金额、报价总额、产品数量
- 录单默认值：报价单号自动生成（QT 前缀）、有效期默认 30 天、币种默认 CNY（人民币）
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（9 列，来源：我方源码 `crm/quotation/index.vue`）

报价单号、报价名称、客户名称、报价日期、有效期、报价总额、状态、创建时间、操作

### 全部可配置列（9 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `vxeColumns` 数组（9 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`crm/quotation/form`，标签按钮 list_path=`crm/quotation/index`，tag_label=历史（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- CRM 报价：对客户的商品报价，可转销售订单。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
