## 1. 页面概述

- **表单页**：非主营收入的登记（往来单位收入/内部收入两类），与费用单对称。页面性质 = 收入类型单选 + 表头字段区 + 收入项明细表格 + 备注区 + 底部金额与操作。
- **双入口**：主菜单 → `finance/other-income/form`；标签「历史」→ `finance/other-income`（列表）。
- 单号实据 NO. QTSRD-20260723-001（QTSRD- 前缀 + YYYYMMDD-序号，"其他收入单"拼音首字母）；标题行含附件、键盘（快捷录入）、齿轮（配置）图标（截图实据）。

## 2. 表单页配置

### 表头字段（必填 * 标注 / 选填）

- 收入类型：往来单位收入 / 内部收入（单选，默认往来单位收入；选"内部收入"时往来单位是否仍必填待复核）
- 必填：往来单位\*（带新增+搜索）、经手人\*（默认当前登录人）、单据日期\*（默认当天）
- 选填/联动：往来编号（只读，随往来单位带出）、收款账户、收款金额（带"全/清"）、更多账户（带"…"弹窗）

### 全部表单字段（14 个，抓取 JSON filterLabels + 截图实据归纳）

- 类型：收入类型
- 表头：往来单位、往来编号、经手人、单据日期、收款账户、收款金额、更多账户
- 明细：收入编号、收入名称、金额、备注
- 备注/底部：单据备注、本单金额
- 单据信息行（制单人/打印次数/打印记录）截图底部未显示，待复核

### 字段分组

收入类型单选 → 表头 → 收入项明细表格 → 备注区（单据备注）→ 底部本单金额与操作。

### 录单默认值

收入类型默认"往来单位收入"、经手人默认当前登录人、单据日期默认当天（截图实据）。

### 打印设置

无（打印模板配置细节待复核；表单页有打印(F8)按钮）。

### 功能按钮（抓取 JSON buttons 实据）

## 5. 业务规范

- 状态流转：保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）；记账后收入生效——收款账户资金增加、收入科目入账，并生成会计凭证（KJPZ-）。
- 往来单位收入 vs 内部收入：往来单位收入挂往来单位（如收客户违约金、供应商返利）；内部收入不挂往来单位，仅科目入账。
- 一单多收入项：明细按收入类目分行，本单金额=Σ金额。
- 收入科目：损益类收入科目实据 6051 其他业务收入 / 6301 营业外收入 / 6902 利息收入（科目余额表实据）。
- 与其他页面关系：收入类目主数据（资料 → 财务账户 → 其他收入；抓取记录含 error，类目主数据结构待复核）；对称单据《费用单开发文档》（字段结构镜像：收/付方向相反）；下游账簿：明细账/科目余额表收入科目；本系统前端目录 `finance/other-income`、`finance/other-income-doc`（双目录对应关系待复核）。
