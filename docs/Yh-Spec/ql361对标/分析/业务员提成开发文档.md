# 业务员提成开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/staff-commission`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（计算型台账）：按提成方案计算业务员销售提成（点击查询实时计算，可按已结算口径过滤）；业务员提成核算页。菜单路径：分析 → 提成分析 → 业务员提成。
- 页面性质：查询触发提成实时计算（不查询不出数），结果区空态提示"还没有内容哦，点击查询才能计算提成统计数据！"。
- 页面结构：查询区（三行）+ 提成方案配置入口 + 结果区（空态插画）。
- 页面截图：`tool-results/ql361/pages/分析__提成分析__业务员提成.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图/bodyPreview 实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、**上周**、本月、上月、近三月（注意：本页快捷段集合独有"上周"，无"近一周/本年"）
- 日期范围（起 至 止）、经手人、部门、商品、单据类型（下拉，默认"全部单据"）、销售类型（下拉，默认"全部"）
- 勾选项：按已结算提成（带 ? 帮助提示）

### 功能按钮（抓取 JSON buttons 实据）

- 提成方案（配置提成计算规则：按销售额/毛利/数量阶梯等，方案字段待复核）、刷新、打印(F8)、导出、查询（触发提成计算——计算型页面，不查询不出数）

### 打印配置

- 有打印(F8)按钮（提成表打印）；打印配置弹窗字段级明细未抓取，待复核

## 3. 数据表格列配置

### 默认显示列（抓取 JSON columns=[]，以截图描述代替并注明）

- **抓取 JSON columns=[]**：本页为计算型页面——不点击"查询"不计算不渲染表格（页面提示"点击查询才能计算提成统计数据"实据），抓取时处于空态，无列实据。
- **截图实据（页面结构）**：查询区（经手人/部门/商品/单据类型/销售类型 + 按已结算提成勾选）+ 提成方案配置入口 + 空态结果区。
- **结果表格列结构**：待复核补抓（执行业务语义推测含 职员、单据数、销售金额/毛利、提成比例、提成金额 等，待复核）。

### 全部可配置列

- 未抓取（列配置弹窗探针待复核）

## 4. 业务规范

### 统计口径与数据关系

- **计算口径**：按"提成方案"配置的规则，对查询期内业务单据（销售订单/销售出库单等，单据类型可过滤）实时计算提成；**按已结算提成**勾选后仅统计已结算部分
- **计算触发**：查询时实时计算（非预存快照），保证口径与方案变更同步
- **销售类型**：正常销售/退货/换货等类型过滤（可选值待复核）

### 与其他页面关系

- 取数：销售单据（经手人归属）+ 提成方案规则
- 同组页面：《回款统计》（回款侧考核）、《业绩提成中心》（年度提成结算闭环）
- 下游：提成结算后进入《业绩提成中心》月度矩阵
