# 盘点单开发文档

## 页面概述

盘点单用于库存盘点录单（页面标题「库存盘点单」），快速录入行 + 盈亏状态筛选 + 刷新库存，保存/盘点处理两段操作。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 盘点单列表页 | http://localhost:5656/erp/stocktake/index | 双入口「历史」标签 |
| 新增/编辑盘点单表单页 | http://localhost:5656/erp/stocktake/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5003（原"库存盘点"，本次改名"盘点单"） |
| menu_code | `erp:stocktake` |
| 主菜单路径 | `erp/stocktake/form`（点击进新增表单） |
| 标签「历史」路径 | `erp/stocktake/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stocktake/form`（表单）、`erp/stocktake/index`（列表） |

## 业务规范说明

- 保存（Ctrl+S，注意非「保存草稿」）→ 盘点处理（Ctrl+Enter）：保存后盘点单可继续盘点，盘点处理后按盈亏生成后续单据（推断生成报损单/报溢单，待复核）。
- 库存数量=账面库存，盘点数量=实盘数，盈亏数量=盘点数量−库存数量 自动计算；盈亏金额汇总于右下角。
- 快速盘点：右上角独立按钮，推断为批量导入/扫码连续盘点模式（弹窗内容待复核）。
- 商品快速录入行：扫码或输入条码/名称/编码 + 数量直接追加盘点行。
- 快速定位/盈亏状态/刷新库存为表格辅助工具，不参与单据字段。
- 盘点处理产出报损单（盘亏）/报溢单（盘盈）（推断，待复核）；处理后影响 分析→仓配分析→查库存/库存明细。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 实现差异说明

**实现文件**：
- 前端：`frontend/apps/pc-admin/src/views/erp/stocktake/form.vue`（表单页）、`frontend/apps/pc-admin/src/views/erp/stocktake/index.vue`（列表页）、`frontend/apps/pc-admin/src/api/erp.ts`（`stockTakeApi`）
- 后端：`backend/erp/erp-stock/.../stock/entity/StockTake.java`（主表）、`StockTakeItem.java`（明细）、`dto/StockTakeQuery.java`、`dto/StockTakeItemVO.java`、`dto/StockTakeUncheckedVO.java`、`mapper/StockTakeMapper.java`、`mapper/StockTakeItemMapper.java`、`service/StockTakeService.java`、`service/impl/StockTakeServiceImpl.java`、`controller/StockTakeController.java`
- 迁移：`backend/core/api/core-api/src/main/resources/db/migration/V11.56.0__Create_Stock_Take_Tables.sql`

### 页面对齐（已建成）
- **列表页** `erp/stocktake/index.vue`：`CategoryListLayout` 双Tab（盘点单历史 / 未盘商品查询），含列配置弹窗、页面配置弹窗（查询条件显隐 + 功能按钮）、快捷日期、搜索区、统计合计行。
- **表单页** `erp/stocktake/form.vue`：表头13字段（编号/盘点仓库/经手人/部门/单据日期/摘要/单据备注/制单人/制单时间/打印次数/盈亏金额）、商品快速录入行（条码/名称/编码 + 数量）、表头工具行（扫描枪录入开关/快速定位/盈亏状态筛选/刷新库存）、明细表格默认14列·可配34列、底部「保存 Ctrl+S / 盘点处理 Ctrl+Enter」、配置弹窗（页面配置/录单默认值/打印设置）。
- 后端模块 `erp/erp-stock` 新增 `StockTake`（主表）/`StockTakeItem`（明细）+ `StockTakeController` 全链路。

### 已完成（对标实据）
1. **盘点处理流程**：`POST /api/erp/stock/take/{id}/process` 已实现——按盈亏数量（盘点数量−库存数量）自动生成报损单（盘亏）/报溢单（盘盈），并通过 `stockService.checkStock` 按实盘数回写库存，结果写入 `process_result`。
2. **列配置弹窗**：列表页 `ColumnConfigPanel`（列显隐/排序/宽度/冻结）+ 表单页 `a-modal` 配置弹窗（页面配置/录单默认值/打印设置）均已实现，页面配置经 `userPageConfigApi` 持久化。
3. **快速盘点/盈亏状态筛选**：工具行「扫描枪录入」「快速定位」「盈亏状态（全部/盘盈/盘亏/无差异）」「刷新库存」均已实现交互；头部「快速盘点」进入扫码连续录入。
4. **未盘商品查询**：`GET /api/erp/stock/take/unchecked-products` 按仓库列出库存商品（排除已入盘点明细），支持「全部盘点/批量盘点」一键生成盘点单并跳转。
5. **单据号**：`KCPDD-` 前缀经 `BizNumberGeneratorService` 递增生成（`biz_number_sequence` 已初始化），`GET /api/erp/stock/take/next-no` 提供实时单号。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
