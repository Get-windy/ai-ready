# 用户管理模块API测试用例

## 概述
本文档包含用户管理模块的完整API测试用例，用于验证Sprint 27+1测试环境的用户管理功能。

## 测试环境配置
- **环境名称**: Sprint 27+1测试环境
- **基础URL**: http://test-ai-ready.example.com
- **测试数据库**: PostgreSQL 14.0
- **测试工具**: Postman/curl/JMeter
- **测试数据**: 使用测试数据工厂生成

## 测试用例分类

### 1. 认证管理测试用例

#### TC-AUTH-001: 用户登录成功
**测试目标**: 验证用户使用正确的用户名和密码可以成功登录
**前置条件**: 用户账号已存在（admin/admin123）
**测试步骤**:
1. 发送POST请求到 `/api/auth/login`
2. 请求体: `{"username":"admin","password":"admin123"}`
3. 验证响应状态码为200
4. 验证响应中包含token字段
5. 验证响应中包含用户信息

**预期结果**:
- 状态码: 200
- 响应体包含有效的JWT token
- 用户信息完整正确
