# 特价开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`marketing/special-price`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：商品特价活动维护页，查询区 + 特价列表，行级查看/修改；新增特价/修改维护。
- 截图：![特价](../../../../tool-results/ql361/pages/营销__营销活动__特价.png)

## 2. 页面配置

### 查询条件

- 筛选条件（活动名称）
- 商品、客户（弹选）
- 起始时间、结束时间
- 使用范围（全部）、活动状态（全部）、创建人（弹选）
- 勾选项：显示已过期/已作废活动（默认不勾选）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增特价、更多玩法告诉我们..、查询、跳转（分页跳转）
- 行级操作（截图确认）：查看、修改、更多（操作列）

### 打印配置

无（页面无打印按钮，截图确认；列表页打印能力待复核）

## 3. 数据表格列配置

操作、活动名称、起始时间、结束时间、促销商品、客户范围、使用范围、活动状态、创建人、创建时间

## 4. 业务规范

- 特价模型（行数据实据归纳）：
  - 特价 ≠ 促销规则：特价直接给商品一口特价（区别于商品促销/整单促销的规则减免/满赠），活动期内按特价成交；活动名称实据"香芋地瓜丸3件起特价""果蜜一次拿货5件以上特价"——特价可带起购数量门槛
  - 定向维度：促销商品（查看商品弹层）、客户范围（查看客户弹层）双定向——同品不同客可不同价；使用范围实据"线上线下"（线下开单 + 线上商城双通道生效）
  - 活动状态实据"促销中"；时间窗外自动过期，可作废；"显示已过期/已作废活动"默认隐藏
  - 与价格体系关系（销售域实据）：销售明细价格等级字段含"特价客户"等级（价格等级 8 昵称之一：餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip）；特价与价格等级、销售价格跟踪（最近成交价）的优先级待复核
  - 创建人/创建时间审计列（实据"杨生淮"）
- 与其他页面关系：与《商品促销开发文档》《整单促销开发文档》并列三种让利手段（特价直接改价 / 商品促销行级规则 / 整单促销单级规则）；销售开单联动（命中特价的商品明细按特价取价，与销售明细价格等级字段协同）；本系统落地对应等级特价 `/api/erp/product-grade-price`（api/marketing.ts 实据）
