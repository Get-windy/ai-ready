## 全系统最重要的 10 个缺失字段（跨页汇总，按业务重要性排序）

1. **使用预收款 / 使用预订货款 / 使用预付款（预付预收抵扣链）** —— 预收"收→抵→退"闭环的"抵"环节。收款单（含可用预收/预收余额）、销售出库单、采购入库单（使用预付款/此前预付/此前欠款）全线缺失或半成品（销售订单表单 disabled 未联动）。没有它，客户预存款无法在销货时抵扣，供应商预付款无法在入库时冲减，商贸核心资金链路断裂。
2. **收款账户 / 付款账户 / 更多账户（多账户拆分收付款）** —— 资金入账账户档案 + 一单多账户拆分，资金对账基础。收款单完全缺失，采购入库单付款区整组缺失，采购订单"更多账户"有 UI 未落库，销售出库单为只读占位。
3. **信用额度 / 可用额度** —— 录单时赊销风控闸门：额度−已占用决定本单能否放行。销售出库单数据模型/payload/页面配置三层已备好但 form.vue 未渲染（半成品，补 6 行渲染定义即可修复）。
4. **明细科目（辅助核算项）** —— 会计凭证分录的辅助核算维度（客户/供应商/部门/项目挂接），辅助核算余额表的根基；我方凭证分录 6 列中唯一整列缺失。
5. **源单（凭证↔业务单据穿透回链）** —— 业务单据自动生成凭证后无法穿透回查来源单据，审计与对账断链；会计凭证头缺失。
6. **待记账在途数量组（已发待记账 / 已收待记账 / 未发数量）** —— 查库存的在途口径：已发货未记账、已收货未记账、已下单未发货各占一列，是"账面库存 vs 可用库存"之外的第三层库存视图，查库存页整组缺失。
7. **进销存分项流量列（采购入库/销售出库/调拨入/调拨出/借进借出/退货各数量列）** —— 进销存分析账表的核心结构：期末=期初+五类入库−五类出库的分项展开。我方只有合计列（8/22），账表无法解释"量从哪来、到哪去"。
8. **账期三件套 + 收款日/对账日（动态收款期限/固定账期/结算期）** —— 挂账客户账期基准，驱动应收账龄分析与催收。客户档案列表+表单均无；销售出库单收款日/对账日同样属半成品未渲染。
9. **优惠金额 / 本次优惠（结账口径字段）** —— 目标结账恒等式"商品金额 − 优惠金额 = 本单金额"，核销应收时不产生资金的折让。收款单、采购入库单缺失，导致摘要/结账口径与目标不一致。
10. **行级操作列（收款/取消/修改/对账/修改/删除）** —— 工作台闭环动作：订单处理中心"只能看不能办"（无收款/取消/修改），价格跟踪无行级维护（修改/删除），查库存/进销存分析无行级联查（分布/明细/对账）。后端 API 多处已就绪（如订单处理中心分组/履约接口 `api/erp.ts:1417-1431`、价格跟踪接口字段 `erp.ts:1477-1503`），前端接入成本低。

**次一级高频缺失**（未入前十但跨页复现）：换算关系/件散数量（查库存、采购入库、商品列表）、经手人*/部门*（会计凭证头必填项）、打印次数/打印记录（审计留痕，多页缺失）、多收金额/待审金额（收款单）、往来单位编号（价格跟踪精确匹配键）。

- 重点缺失/未闭环项（按业务重要性排序）:
  - **扫描枪录入开关**: 目标商品名称列头内嵌扫码枪录入开关，仓库/门店扫码录单的核心提效交互，我方无。

  - **明细默认显示口径**: 目标默认 16 列，我方默认显示约 48 列（仅图片与价格等级隐藏），录单界面过宽，需把非默认列补 `defaultHidden`。
  - **打印记录**: 目标有打印记录查看，我方仅有无处理函数的静态链接按钮（form.vue:59）。

  - **使用预收款（含可用预收/预收款余额）**: 预收抵扣应收的"抵"环节，缺失则预收款无法在本单冲减应收，预收主线断裂。
  - **优惠金额/本次优惠**: 核销应收但不产生资金的折让让渡，影响应收余额与毛利口径。

  - **待审金额**: 已收款未审核的中间态金额，缺失则收款在途资金无法体现。
  - **此前应收/应收余额**: 收款前后余额实时联动校验，是收款金额守恒（收款+预收=Σ本次结算+多收）的核算锚点。
  - **打印次数/打印记录**: 单据打印追踪，防重复打印与审计留痕。
