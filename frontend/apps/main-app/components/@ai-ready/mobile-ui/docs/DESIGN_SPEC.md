# AI-Ready Mobile UI 设计规范

## 设计原则

### 1. 简洁清晰
- 减少视觉噪音，突出核心内容
- 使用足够的留白，让界面呼吸
- 保持一致的信息层级

### 2. 一致性
- 统一的色彩系统
- 一致的间距规范
- 统一的圆角和阴影
- 一致的交互反馈

### 3. 移动端优先
- 触摸目标不小于44px
- 支持手势操作
- 适配不同屏幕尺寸
- 考虑单手操作

## 组件规范

### 按钮 (ARButton)

#### 尺寸
| 尺寸 | 高度 | 内边距 | 字体 |
|------|------|--------|------|
| Mini | 24px | 0 12px | 10px |
| Small | 32px | 0 16px | 12px |
| Normal | 44px | 0 20px | 14px |
| Large | 50px | 0 24px | 16px |

#### 变体
- **Solid**: 实心填充，主要操作
- **Outline**: 描边样式，次要操作
- **Ghost**: 透明背景，弱操作
- **Text**: 纯文本，链接样式

### 输入框 (ARInput)

#### 尺寸
| 尺寸 | 高度 | 内边距 | 字体 |
|------|------|--------|------|
| Small | 36px | 0 12px | 12px |
| Normal | 44px | 0 16px | 14px |
| Large | 52px | 0 20px | 16px |

#### 状态
- 默认: 灰色边框
- 聚焦: 主色边框 + 外发光
- 错误: 红色边框
- 禁用: 灰色背景

### 列表 (ARList)

#### 列表项
- 高度: 48-56px
- 内边距: 16px
- 分割线: 1px solid #ebedf0
- 点击态: 背景变灰

### 卡片 (ARCard)

#### 尺寸
- 内边距: 16px
- 圆角: 12px
- 阴影: SM级别
- 封面高度: 180px

## 交互规范

### 点击态
- 透明度变化: 0.8
- 缩放效果: 0.98
- 过渡时间: 0.2s

### 加载态
- 旋转动画: 1s linear infinite
- 加载图标大小: 20px
- 加载文字: 14px

### 过渡动画
| 动画 | 时长 | 缓动函数 |
|------|------|----------|
| Fast | 0.2s | ease |
| Normal | 0.3s | ease |
| Slow | 0.5s | ease |

| 断点 | 宽度 | 说明 |
|------|------|------|
| XS | 320px | 小屏手机 |

## 无障碍设计

### 触摸目标
- 最小触摸目标: 44x44px
- 推荐触摸目标: 48x48px

### 对比度
- 文字与背景对比度 >= 4.5:1
- 大文字对比度 >= 3:1

### 焦点状态
- 清晰的焦点指示器
- 支持键盘导航
- 屏幕阅读器友好
