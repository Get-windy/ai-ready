# 采购单据查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/doc-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：全类型采购单据综合查询（采购入库单/采购退货单/采购换货单等），按单据维度汇总，一行一单。
- **单入口**：仅列表页（查询区 + 工具按钮区 + 数据表格 + 合计行 + 分页；无左侧树、无 Tab 子标签，与销售单据查询同构）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号、供应商、经手人、仓库
- 结算状态（下拉，全部）、来源订单、单据类型（下拉，全部单据）

> 注：销售单据查询查询区有「日期类型（单据日期）」下拉，本页截图未见该控件，按图实据记录；可配置查询条件全量（查询条件管理弹窗）未抓取，待复核。

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、导出、查询、跳转（分页）

行级操作（截图确认）：复制、整单备注

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（23 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、单据类型、入库仓库、出库仓库、供应商名称、供应商编号、联系人、联系电话、联系地址、供应商备注、来源订单、经手人、结算状态、采购数量、金额、优惠后金额、价税合计、本单金额、其他费用、单据备注、打印次数

> 注：JSON columns 共 23 项全为真实列；与销售单据查询（28 列）相比，本页无「客户级别/收货人/买家备注/销售收入/运费承担方/运费/成本金额/毛利」等销售侧列，新增「价税合计」列。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核；配置弹窗结构参照销售域 XSMK：个人配置 Tab + 全局配置 Tab）。

## 4. 业务规范

- 单据类型下拉（全部单据）为采购域记账类单据统一检索入口：截图实据当前数据全部为采购入库单（CGRKD-）；采购退货单（CGTHD-）、采购换货单（CGHHD-）按域内对称性推断同纳入，单据类型完整值域待复核；采购订单（CGDD-）走独立列表页（按单据/按明细 Tab），是否纳入本页待复核。
- 入库仓库/出库仓库双列并存：入库单只填入库仓、退货单只填出库仓、换货单两者皆有（与销售单据查询同规律）。
- 金额口径五列并存：金额、优惠后金额、价税合计、本单金额、其他费用；价税合计=优惠后金额+税额（推断，本系统为含税口径，精确公式待复核）；本单金额与其他费用的勾稽关系待复核。
- 行级「复制」：以本单为模板快速新增同类单据；「整单备注」：对整单补录备注。
- 数据源：采购入库单/采购退货单/采购换货单（域内记账类单据）；单据编号链接跳转原单据详情/表单页。
- 姊妹页：采购明细查询（本页单据维度 vs 明细维度）；销售域对应页：销售单据查询（同构，查询区多「日期类型/商品行属性/仅统计车辆库」等销售侧条件）。
