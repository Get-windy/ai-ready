# 待审批单据开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/pending-approval`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：全业务域待审批单据的统一汇总台账与批量审批入口（审核通过/驳回）。菜单路径：分析 → 综合单据 → 待审批单据。
- 页面性质：综合单据组三页分别对应单据生命周期"审批中/草稿/已过账"三个横切状态，本页为审批中态。
- 页面结构：查询区（三行）+ 单据台账表格（首列红色齿轮列配置入口 + 行勾选框，操作列）+ 底部合计行。
- 页面截图：`tool-results/ql361/pages/分析__综合单据__待审批单据.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图/bodyPreview 实据的全量展开项）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号、单据类型（下拉，默认"全部单据"）、往来单位、经手人、部门
- 单据备注、账期（带 ≥ 比较符下拉）、仓库、所属区域

### 功能按钮（抓取 JSON buttons 实据）

- 刷新、审核通过、驳回（勾选行后的批量审批动作）、更多（折叠其余批量动作，具体内容待复核）、查询、跳转（分页跳转）

### 打印配置

- 无（本页无打印按钮实据；审批台账不提供打印，"更多"内是否含导出待复核）

## 3. 数据表格列配置

### 默认显示列（13 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、单据类型、往来单位、所属区域、仓库、金额、经手人、部门、摘要、单据备注、附件

## 4. 业务规范

### 统计口径与数据关系

- **数据范围**：全部业务域处于"审批中"状态的单据（单据类型下拉"全部单据"实据，可按类型过滤）。一行一单，金额列为单据金额
- **账期条件**：带 ≥ 比较符，按单据账期天数过滤（如"账期≥N 天"的超期审批单筛查）
- **审批动作**：审核通过 → 单据回到来源业务域继续流转（销售订单→订单处理中心"拣货/发货"阶段，销售域实据）；驳回 → 退回制单人修改后重新提交
- **组内分工**（综合单据组三页 = 单据生命周期三横切状态）：待审批单据（审批中）→ 业务草稿（未提交/未过账）→ 经营历程（已过账全量流水）

### 与其他页面关系

- 上游：各业务域单据的"提交"动作（销售订单表单页 Ctrl+Enter 提交后进入审核中，销售域实据；采购/仓储/财务各域单据类推）
- 下游：审批通过回写源单据状态；驳回回写并通知制单人
- 同组页面：业务草稿、经营历程
