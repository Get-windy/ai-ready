## 业务规范说明

### 统计口径（期初+入−出=结存）

- **恒等式**：期末余额 = 此前余额 + 入库合计 − 出库合计（数量/金额两口径同时成立）
- **五类入库**：采购入库（CGRKD-）、调拨入库（仓库间调拨）、其他入库、借进入库（借货入）、销退入库（XSTHD- 销售退货回库）
- **五类出库**：销售出库（XSCKD-）、调拨出库、其他出库、借出出库、采退出库（CGTHD- 采购退货出库）
- **双单位**：数量（大单位）/小单位数量（换算后最小单位）；"数量显示"下拉切换呈现口径
- **金额口径**：按成本价（出库成本核算），此前/期末金额为库存货值
- **是否发生业务**：过滤期内无变动商品（全部/有业务/无业务）

### 与其他页面关系

- 取数：全部出入库单据流水（《库存明细》逐笔）按商品×期间聚合
- 联查：行级"对账"→ 该商品期间明细流水（《库存明细》）
- 同组页面：《查库存》（时点存量）、《查批次》（批次粒度）；下游：《采购分析》（采购入库侧）、《销售分析》（销售出库侧）
