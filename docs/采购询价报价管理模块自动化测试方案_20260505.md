# 采购询价报价管理模块自动化测试方案

## 🎯 方案概述

本方案为ERP核心功能中的采购询价报价管理模块设计完整的自动化测试体系，确保询价发布→报价接收→比价分析→供应商选择的采购流程质量，支持采购决策的准确性和效率。

## 📊 测试金字塔设计

### 1. 分层测试策略

| 测试层级 | 测试类型 | 覆盖率目标 | 执行频率 | 主要工具 |
|---------|---------|-----------|---------|---------|
| **单元测试** | 业务逻辑、服务接口 | ≥85% | 每次代码提交 | JUnit 5, Mockito, Testcontainers |
| **集成测试** | API接口、业务流程 | ≥90% | 每日构建 | RestAssured, Testcontainers |
| **系统测试** | 端到端采购流程 | ≥95% | 每周构建 | Selenium, Playwright |
| **性能测试** | 并发询价、报价处理 | 100% | 每月/重大版本 | JMeter, Gatling |
| **数据一致性测试** | 采购数据流验证 | 100% | 每次集成 | 数据库断言工具 |

### 2. 测试环境策略

- **开发环境**: 本地Docker环境，模拟供应商报价流程
- **测试环境**: 独立采购测试环境，包含模拟供应商系统
- **预生产环境**: 准生产配置，用于压力测试和性能验证
- **生产影子环境**: 生产数据脱敏后的测试环境

## 🔍 测试范围设计

### 核心业务流程测试场景

1. **询价发布流程**
   - 询价单创建和发布
   - 供应商邀请和通知
   - 询价截止时间管理
   - 询价文档附件管理

2. **报价接收流程**
   - 供应商报价提交
   - 报价文件上传和验证
   - 报价有效期管理
   - 报价撤回和修改

3. **比价分析流程**
   - 多维度报价比较
   - 供应商评分和排名
   - 历史报价趋势分析
   - 异常报价识别

4. **供应商选择流程**
   - 自动供应商推荐
   - 人工审批流程
   - 供应商谈判记录
   - 最终采购决策

5. **合同生成流程**
   - 采购合同自动生成
   - 条款和条件验证
   - 合同审批流程
   - 合同归档和跟踪

### 异常场景和边界条件

1. **询价异常场景**
   - 询价发布失败
   - 供应商邀请超时
   - 询价文档格式错误
   - 重复询价检测

2. **报价异常场景**
   - 报价金额异常（过高/过低）
   - 报价有效期冲突
   - 供应商资质过期
   - 并发报价冲突

3. **比价异常场景**
   - 数据不一致异常
   - 供应商评分计算异常
   - 历史数据缺失处理
   - 多货币汇率转换异常

## 🔗 集成测试设计

### API接口集成测试

1. **REST API功能测试**
   - `POST /api/rfqs` - 创建询价单
   - `GET /api/rfqs/{id}` - 查询询价详情
   - `POST /api/rfqs/{id}/invite` - 邀请供应商
   - `POST /api/quotes` - 提交报价
   - `GET /api/rfqs/{id}/quotes` - 获取报价列表
   - `POST /api/rfqs/{id}/analyze` - 执行比价分析
   - `POST /api/rfqs/{id}/select` - 选择供应商

2. **API性能测试**
   - 并发询价发布性能
   - 大批量报价处理性能
   - 复杂比价计算性能
   - 供应商通知延迟测试

### 业务流程集成测试

1. **完整采购流程测试**
   ```
   询价创建 → 供应商邀请 → 报价接收 → 比价分析 → 供应商选择 → 合同生成
   ```

2. **多供应商并发测试**
   ```
   多个供应商同时报价 → 报价冲突处理 → 最终报价确认
   ```

3. **数据一致性测试**
   ```
   询价数据 → 报价数据 → 比价结果 → 采购决策 → 合同数据
   ```
