## 实现内容

### 1. 通用组件开发

#### CategoryListLayout 组件
**位置**: `src/components/CategoryListLayout/`

这是一个通用的分类列表布局组件，可复用于所有带分类树的列表页面（商品、客户、供应商等）。

**特性**:
- 左侧分类树面板（支持多级分类、搜索、新增、编辑）
- 顶部Tab标签栏
- 自定义工具栏（左右两侧）
- 多条件搜索栏
- 表格内容区域
- 标准底部分页

**Props**:
- `showCategoryPanel`: 是否显示分类面板
- `categoryTitle`: 分类面板标题
- `categoryTreeData`: 分类树数据
- `categoryLoading`: 加载状态
- `tabs`: Tab标签列表
- `paginationCurrent/PageSize/Total`: 分页参数
- `currentPath`: 当前路径文本

**Events**:
- `category-select`: 选择分类
- `tab-change`: 切换Tab
- `search`: 执行搜索
- `page-change`: 分页变化

**Slots**:
- `toolbar-left/right`: 工具栏内容
- `search-fields`: 自定义搜索字段
- `table`: 表格内容

## 使用说明

### 运行项目
```bash
# 前端
cd frontend
pnpm install
pnpm --filter ai-ready-admin dev

# 后端
cd backend
mvn spring-boot:run -pl core/api/core-api
```

### 访问页面
- 商品列表: `/erp/product`
- 新增商品: `/erp/product/create`
- 编辑商品: `/erp/product/:id`

## 注意事项

1. **样式定制**: 组件使用scoped styles，可通过全局样式覆盖
2. **TypeScript**: 部分类型错误是Vite模块解析问题，不影响运行
3. **权限控制**: 按钮操作使用`v-permission`指令控制权限
4. **响应式**: 表格高度自动计算，适配不同屏幕尺寸
