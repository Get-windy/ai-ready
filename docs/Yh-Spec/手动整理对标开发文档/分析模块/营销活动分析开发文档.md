## 4. 业务规范

### 统计口径（活动效果）

- **四类活动**：商品促销（单品级）/整单促销（整单满减满赠）/特价（直接特价）/优惠券（领用核销）。
- **参与与让利**：以「活动名称 + 日期」为行粒度，逐日汇总参与订单/客户、商品销量、优惠金额与惠后金额。
- **赠品口径**：仅商品促销/整单促销带赠品数量列；特价与优惠券无。

### 与营销模块的上下游关系（**取数关系，必须写清**）

- **上游 = 《营销模块》的促销/推广配置页**：`商品促销`/`整单促销`/`特价`/`优惠券` 的活动主数据（活动名称、日期区间、活动范围、活动类型/券类型）**由营销模块配置产生**；本页不产生任何配置，只读消费。
- **下游归因**：本页按销售订单与活动的关联明细做归因，输出「参与订单数/参与客户数/优惠金额/惠后订单金额」——即**营销模块配置活动的效果回收**。活动配了但无人参与时，本页对应行不出现（0 条记录即此意）。
- **同源页**：《销售费用分析》（促销活动费用列 = 本页优惠金额的财务口径）、《营销推广分析》（推广侧分享/浏览漏斗口径，见本模块另一篇）。

### 本系统对应关系

- 本系统营销域页面见《营销模块》各篇（商品促销/整单促销/特价/优惠券）；本页当前取数**并非**这些营销单据，而是 CRM 营销活动表（见第 5 节），**上下游尚未打通**。

4. **无打印 / 无导出**（与对标一致，非缺口）。
5. **无合计行**：对标是否有合计未确证；本页无。
6. **dev 库无活动数据 → 部分枚举展示未确证**：巡检时该页真实数据行 0（`/crm/marketing/page` 无记录），状态 / 类型文案的展示效果**未确证**（缺数据）。
