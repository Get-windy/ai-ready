## 测试范围

### 1. 认证与授权测试 (25个用例)
- 登录安全：暴力破解防护、密码策略、加密存储
- 会话管理：Token过期、刷新、多设备登录
- 权限控制：垂直/水平越权、RBAC

### 2. 数据安全测试 (12个用例)
- 敏感数据加密：传输加密、存储加密
- SQL注入防护：参数化查询、报错隐藏
- XSS防护：HTML转义、CSP策略
- CSRF防护：Token、SameSite

### 3. API安全测试 (16个用例)
- 接口鉴权：Token验证、权限检查
- 参数校验：长度限制、类型校验
- 速率限制：接口限流、登录限流
- 信息泄露：错误隐藏、路径遍历

### 4. 业务安全测试 (12个用例)
- 支付安全：金额篡改、重复支付
- 订单安全：状态篡改、删除防护
- 价格安全：价格篡改、折扣滥用

## 安全基线要求

| 类别 | 要求 | 状态 |
|------|------|------|
| 认证安全 | 密码策略、登录锁定、TLS加密 | ✓ |
| 授权安全 | RBAC、防越权、动态刷新 | ✓ |
| 数据安全 | 加密存储、SQL注入、XSS防护 | ✓ |
| API安全 | 鉴权、参数校验、限流 | ✓ |
