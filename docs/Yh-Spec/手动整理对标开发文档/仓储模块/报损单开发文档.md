# 报损单开发文档

## 页面概述

报损单用于库存损耗/报废出库录单（按批次报损）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 报损单列表页 | http://localhost:5656/erp/stock-damage/index | 双入口「历史」标签 |
| 新增/编辑报损单表单页 | http://localhost:5656/erp/stock-damage/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5009（原"报损管理"，本次改名"报损单"） |
| menu_code | `erp:stock-damage` |
| 主菜单路径 | `erp/stock-damage/form`（点击进新增表单） |
| 标签「历史」路径 | `erp/stock-damage/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-damage/form`（表单）、`erp/stock-damage/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记帐后生效扣减库存。
- 数量列名为「报损数量」（区别于通用「数量」），按批次报损（批次条码/生产日期/保质期/到期日期列齐备）。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 报损金额按成本计价计入本单金额（列中无单价/金额列，金额取库存成本，待复核）。
- 与报溢单互为反向单据（一损/一溢）；盘点单的盈亏处理可生成报损单/报溢单（盘点单「盘点处理」流程推断，待复核）。
- 记帐后影响 分析→仓配分析→查库存/库存明细。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 实现差异说明

**实现文件**：`frontend/apps/pc-admin/src/views/erp/stock-damage/form.vue`（表单页）、`.../index.vue`（列表页）
**后端**：`stock-damage` 相关模块（`StockDamageController` / 相关实体）

### 页面对齐（已实现）
- **表头字段**：已对齐对标口径（编号/出库仓库/经手人/单据日期/部门/摘要/单据备注/制单人/制单时间/打印次数/本单金额），保留我方独有字段"报损原因"。
- **后端补列**：主表补 经手人/部门/重量/体积/摘要/附件/记账人/制单人/打印次数/取消原因（V11.54.0）；明细表补 条码/货位/保质期/到期日期/换算关系/件散/大中小包装（V11.42.0）+ 型号/产地/品牌/区域/批次条码/换算结果/小单位/重量体积/自定义1-5/图片（V11.54.0）。
- **双入口**：菜单 5009 已配 主菜单→`erp/stock-damage/form`、历史→`erp/stock-damage/index`；`display_mode=1`。
- **保存闭环**：`next-no`（BSD- 前缀）/`getById`/`create`/`update`/`complete`（记帐）/`cancel`（作废）全链路已实现。
- **列配置弹窗**：列表页 列配置/页面配置 弹窗；表单页 配置弹窗（页面配置/录单默认值/打印设置）三 Tab 已实现。
- **状态流**：按文档"保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）"两步流：0=草稿 → 1=已记账（扣减库存）/ 2=已作废。单号前缀 `BSD-`。

### 待完善 / 待复核
1. **报损金额计价**：报损单价取库存成本（`unitCost`，选择商品后回填），金额=数量×单位成本；精确成本口径待复核。
2. **扫描枪录入开关**：商品名称列商品选择可用，扫描枪直录开关未单独实现（随列配置默认显示）。
3. **列表"新建"内嵌弹窗**：当前按双入口方式跳转 `form` 页新增，未做列表页内嵌弹窗。
4. **记帐实际扣减库存**：记帐回写主表记账人/时间，按批次扣减库存的库存事务待与分析-仓配（查库存）联动复核。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
