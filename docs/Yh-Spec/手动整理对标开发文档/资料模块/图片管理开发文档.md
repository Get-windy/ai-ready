# 图片管理开发文档

> **文档类型：** 页面对标复刻（⚠️ **当前为占位桩页**，后端未接入，需从零对标复刻）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按仓储模块金标准结构编写；商品图片管理（商品图片列表 + 图片空间库），多 Tab 组合页。

## 页面概述

图片管理用于**商品图片**的检索/上传/匹配维护。对标系统为**多Tab组合页**，含 2 个子标签：**商品图片列表**（默认）、**图片空间**。**不属于主图/详情图/缩略图分类表**，而是「按商品维度维护图片」+「图片库自动匹配」形态。

| 子标签 | 说明 |
|--------|------|
| 商品图片列表 | 商品分类树 + 商品筛选 + 商品图片数据表（按行上传图片） |
| 图片空间 | 图片库上传/自动匹配/删除/搬移（非标准数据表） |

菜单：资料 → 商品管理 → 图片管理。

> ⚠️ **本系统当前实现说明**：本页为 `ErrorBoundary` + `PageContainer`（图片管理）+ 搜索区 + `apiUrl='/md/image/page'` 传给 `BillTableList` 的只读桩页，后端无 `/md/image` Controller（404）。后端无 `ImageController`、数据库无 image 类表 → **需从零对标复刻**。

### 子标签 2：图片空间

**结构**：图片库/上传管理视图（非标准数据表，无列配置弹窗）。

**查询条件（界面固定）**：请输入关键字搜索（searchbox）、图片匹配方式（select，默认「按名称」）、查询按钮。

**功能按钮**：上传图片、自动匹配、删除、搬移、全选（checkbox）、只显示图片（checkbox）、选择文件...

**图片目录树**：我的图片。

**自动匹配规则说明（页面提示）**：将图片的名称命名为匹配方式对应的名称，多张图片在图片名称后用 `-1`、`-2` 表示。如：匹配方式为按商品货号匹配，则匹配的图片命名为 `sp001-1`、`sp001-2`。

- **⭐ 占位缺口**：`/md/image/page` 后端未实现；后端无 `ImageController`、数据库无 image 类表 → **需从零对标复刻**（商品图片表 + `page`/`upload`/`delete`/`autoMatch` Controller）。
