# 采购明细查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/detail-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：采购单据商品明细级查询（一行 = 一个单据的一条商品明细），按商品维度追溯采购。
- **单入口**：仅列表页（查询区 + 工具按钮区 + 数据表格 + 合计行 + 分页；**无左侧商品分类树**——与销售明细查询不同，截图确认表格自查询区下方通栏铺开）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号、商品（弹窗搜索）、是否赠品（下拉，全部）、供应商、经手人、仓库
- 单据类型（下拉，全部单据）、明细备注

> 注：销售明细查询另有「品牌/所属行业类别/促销商品/仅统计车辆库/更多条件」，本页截图未见；可配置查询条件全量待复核。

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、导出、查询、跳转（分页）

行级操作（截图确认）：批次号、明细备注

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（25 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、入库仓库、出库仓库、供应商名称、供应商编号、联系人、联系电话、联系地址、供应商备注、来源订单、经手人、结算状态、商品名称、单位、数量、批次条码、生产日期、到期日期、单价、金额、优惠后金额、明细备注、打印次数

> 注：JSON columns 共 25 项全为真实列；与采购单据查询（23 列）相比：无「单据类型」列与单据级金额列（价税合计/本单金额/其他费用/采购数量），新增明细级列（商品名称/单位/数量/批次条码/生产日期/到期日期/单价/明细备注）。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核；配置弹窗结构参照销售域 XSMK：个人配置 Tab + 全局配置 Tab）。

## 4. 业务规范

- 一行一明细：同一单据含 N 个商品即占 N 行（截图实据：CGRKD-20260721-010 连续 7 行、CGRKD-20260721-007 连续 5 行），与「采购单据查询」的一行一单形成维度互补。
- 批次追溯三列：批次条码、生产日期、到期日期为采购入库批次采集字段（与采购入库单表单页批次采集实据一致），支撑批次效期管理。
- 是否赠品查询条件：支持赠品专项追溯（对应采购入库单明细「赠品」列实据）。
- 行级「批次号」：查看该明细行的批次轨迹（推断，具体弹层内容待复核）。
- 数量/单价/金额/优惠后金额四列联动口径与采购入库单明细一致（数量×单价=金额，优惠后金额为折让后口径）。
- 数据源：采购入库单/采购退货单/采购换货单的商品明细行（与采购单据查询同源，维度不同）；单据编号链接跳转原单据。
- 销售域对应页：销售明细查询（同构，销售版带左侧商品分类树与更多销售侧条件）。
