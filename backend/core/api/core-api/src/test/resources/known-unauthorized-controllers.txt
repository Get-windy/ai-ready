# =============================================================================
# 鉴权覆盖率门禁 · 基线清单（棘轮）
#
# 语义：名单内的控制器当前**没有任何访问控制注解**（方法级或类级），
#       即「登录后即可访问」。它不是"这些接口应该无鉴权"的认可，
#       而是"还没补上"的现状快照。
#
# 判据（与 tools/audit-authz-coverage.py 一致，二者必须同步）：
#   有鉴权 = 类级或方法级出现以下任一注解
#       @SaCheckPermission / @SaCheckLogin / @SaCheckRole / @SaIgnore
#       @RequirePermission / @RequireRole / @RequiresPermission / @RequireFilePermission
#   注：@RequirePermission 等自定义注解由 core-api 的 PermissionAspect 通过 AOP 真实执行，
#       漏算会大幅高估缺口。@DataPermission / @DataPermissionCheck / @BusinessPermissionCheck
#       做的是数据范围过滤、不决定接口可达性，**不计入**。
#
# 维护规则（违反会被 AuthzAnnotationCoverageTest 拦下）：
#   1. 棘轮只允许缩小：给某个控制器补了注解，就必须删掉这里对应的行；
#      已加注解却仍留在名单里 → 测试失败（防止清单腐烂成"永远豁免"）。
#   2. 新增一行必须同时改 CLEANUP_SCOPE_20260919.md，写明为什么这个控制器是
#      确定公开的（如登录/验证码/回调/健康检查），否则不许加。
#   3. 基线过期（名单里的类已不存在）→ 测试失败。
#
# 核查方式：
#   python tools/audit-authz-coverage.py            # 看统计与完整清单
#   python tools/audit-authz-coverage.py --baseline # 重新生成本文件内容
#
# 首版生成：2026-09-19，242 个控制器 / 2162 个端点（全站 396 个控制器 / 3563 个端点）
# =============================================================================
