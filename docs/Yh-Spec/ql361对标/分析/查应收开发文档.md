## 1. 页面概述

- **账表页**（应收账）：客户应收滚动台账（期初+本期应收−已结−优惠=应收余额，行级收款/对账，三视图）；应收账款管理核心页。菜单路径：分析 → 财务分析 → 查应收。
- 页面结构：视图 Tab（查应收/职员应收/部门应收）+ 查询区（两行）+ 左侧往来单位分类树 + 滚动账表格（操作列"收款/对账"链接）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__财务分析__查应收.png`

## 4. 业务规范

### 统计口径（应收滚动）

- **应收余额 = 期初应收 + 本期应收款 − 本期已结 − 优惠**（合计行验证：538,635.72+458,346.15−387,226.64−427.19=609,328.04 ✅）
- **期末余额 = 应收余额 − 预收余额**（预收冲抵后的净应收；预收余额列示该单位预收款结余）
- **期初负值**：期初应收为负（如 -4.9、-170）= 该单位此前多收/预收净额
- **本期应收款**：期内销售出库/退货净增应收；**本期已结**：期内收款+预收抵扣；**优惠**：收款让利冲减
- **包含已审核未记账收款单/预收款单**：勾选后未记账单据也计入已结（权责发生 vs 收付实现口径切换）
- **结款方式**：挂账（赊销）/现结（款到发货）

### 与其他页面关系

- 取数：销售出库单（应收发生）+ 收款单/预收款单（已结）+ 优惠
- 行级"收款"→ 收款单表单页（财务域）；"对账"→ 该单位应收明细
- 同源页：《销售欠款分析》（职员/区域侧口径，欠款余额与本页应收余额同口径）、《往来余额表》（应收应付净额口径）、《查应付》（供应商侧）
