## 1. 页面概述

采购分析页是**采购域的量额分析工作台**：默认进入 `按时间` 图表视图（7 张指标卡 + 按天/按周/按月折线趋势），可切 `按商品`（每商品一行：采订/采购/退货三段的数量与金额，含浮动单位、小单位换算、赠品数量）与 `按供应商`（每供应商一行：同构三段口径）。**单入口、三视图 Tab**，逐 Tab 独立列配置。

| 页面 | 地址 | 说明 |
|------|------|------|
| 采购分析 | `analytics/purchase-analysis` | 单入口复合页（3 个视图 Tab：按时间 / 按商品 / 按供应商；逐 Tab 独立列配置；按时间默认图表视图） |

单入口：分析 → 采销分析 → 采购分析 → 采购分析。

- **对标子分组归属（重点）**：ql361「采销分析」组下有 **3 个 `.popupmenu__list-title` 子分组**——`销售业绩`、`销售分析`、**`采购分析`**，**均为分组标题、非页面**（`.png` 实测右键菜单展开可见）。本页与《采购准备》**同归子分组「采购分析」**之下。本系统 `sys_menu` **有对应层级**：菜单 **80420「采购分析」（menuType 0 分组）**，其下挂 **80421 采购分析** 与 **80422 采购/准备**（`V6.22.0__Fill_Mega_Menu_All_Columns.sql:188-190`）——**这是本组 10 页中唯一与 ql361 子分组结构一致的一处**。

### 口径说明

- **三段口径在三个 Tab 上同构**：`采订单数/采订数量/订单优惠后金额`（采购订单口径）→ `采购单数/采购数量/采购优惠后金额`（采购入库口径）→ `退货单数/退货数量/采购退货折后金额`（采购退货口径）→ 末段派生 `实采金额`、`退货率(%)`。三 Tab 的差异仅在**行维度**（日期 / 商品 / 供应商）与**档案列密度**。
- **小单位体系**：`按商品` 与 `按供应商` 均含 `采订小单位数量 / 采购小单位数量 / 退货小单位数量`（三段各一，**全部默认隐藏**），`按商品` 另加 `实采小单位数量` —— 即「数量」以**大单位**呈现、「小单位数量」为换算后的辅助口径（与《预订货查询》的换算语境同源）。
- **多级表头归位（重要）**：`按时间` Tab 的 `采订统计 / 采购统计 / 退货统计` 是**分组表头**，**不是数据列**；列配置若按 ql361 通例展开，其叶子应为 `采订单数/采订数量/订单优惠后金额`、`采购单数/采购数量/采购优惠后金额`、`退货单数/退货数量/采购退货折后金额`（**此为按表头结构的推断，非实测列配置，待复核**）。`按商品`/`按供应商` 两 Tab 表头**无分组**（叶子列平铺）。
- **合计行**：`按商品`/`按供应商` 两 Tab 均有（实测 `按供应商` 合计 `14,462.90`）；是否含隐藏列参与求和**因数据量小无法判定，待复核**。
- **浮动单位（`按商品` 独有）**：`浮动单位` + `采订浮动数量` + `采购浮动数量` 三列（全默认隐藏），指按「浮动单位」口径统计的数量——**浮动单位的确切定义与换算规则未抓取，待复核**。

### 统计口径（采购三段）

- **订 → 采 → 退三段**（基准文档口径，本次实测数值与之一致）：
  - `采订单数 / 采订数量 / 订单优惠后金额` —— **采购订单**（CGDD-）口径；
  - `采购单数 / 采购数量 / 采购优惠后金额` —— **采购入库单**（CGRKD-）口径；
  - `退货单数 / 退货数量 / 采购退货折后金额` —— **采购退货单**口径。
- **实采金额 = 采购优惠后金额 − 采购退货折后金额**（✅ 实测验证）：`14,462.90 − 0.00 = 14,462.90`（`按时间` Tab 指标卡实据）。基准文档首抓（2026-07-23）曾记 `71,489.00 − 0.00 = 71,489.00`（不同统计窗口），**公式不变、数值随窗口变化**。
- **退货率(%)**：派生指标，未在实测中取得非零样品，**分母口径（按金额还是按数量）待复核**。
- **赠品数量**：三段口径之外的独立列（默认可见），指采购赠品数量，**是否计入"采购数量"待复核**。
- **与《销售分析》对称**：销售侧为「销售额 → 退货额 → 销售收入」；采购侧为「采购优惠后金额 → 采购退货折后金额 → 实采金额」。两页互为镜像，**便于购销毛利对照**。
- **跨 Tab 合计一致性（实测 ✅）**：`按供应商` 两行金额 `14,144.90 + 318.00 = 14,462.90`，与 `按时间` Tab 的 `采购优惠后金额` 合计 `14,462.90` **完全相等**（同一窗口 2026-09-14~09-15），即**供应商维度汇总 = 时间维度汇总**，维度间口径自洽。

### 取数来源与上下游关系

- **取数**：采购订单（采订段）+ 采购入库单（采购段）+ 采购退货单（退货段），均取**单据明细**后按维度汇总（商品维度按 `product`、供应商维度按 `supplier`）；另有商品档案（规格/品牌/条码/产地/浮动单位）与供应商档案（编号/分类）做快照。
- **下游**：
  - **《采购准备》**（同子分组）：本页的「采订单数」是《采购准备》补货建议的**结果侧**（补货 → 下单 → 本页统计到采订），二者构成「**建议 → 执行 → 复盘**」闭环；
  - **《查应付》**：采购未结口径（本页为发生额口径，不等价）；
  - **《进销存分析》**：入库侧的数量/金额（本页为金额与单数口径，不重复）。
- **与《销售分析》的分工**：两页口径对称但方向相反，**不可相加**（采购金额 ≠ 销售成本，前者是采购价口径、后者是成本核算口径）。

1. **「按时间」Tab 的对标列规格不可得**：对标列配置弹窗抓取失败（`err: no dialog`），本实现的 12 列取自页面快照表头，**未经列配置弹窗证据校验**。

   - 按商品：`浮动单位 / 采订浮动数量 / 采购浮动数量`（无浮动单位主数据，也无浮动数量列）
