# 生产模板开发文档

## 页面概述

生产模板是成品物料清单（BOM）主数据维护页，定义成品与其原料构成及用量，为组装单/拆分单取数。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 生产模板列表页 | http://localhost:5656/erp/stock-bom/index | 双入口「列表」标签 |
| 新增/编辑生产模板表单页 | http://localhost:5656/wh/production-template/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5014 |
| menu_code | `erp:stock-bom` |
| 主菜单路径 | `wh/production-template/form`（点击进新增表单） |
| 标签「列表」路径 | `erp/stock-bom/index`（进列表） |
| tag_label | 列表 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-bom/form`（表单）、`erp/stock-bom/index`（列表） |

## 新增生产模板表单页配置

### 模板头字段（对标实据）

必填：模板名称\*、成品名称\*、成品单位\*、成品数量\*；选填：口味、型号

全部模板头字段（6 个，cfg 实据）：模板名称、成品名称、成品单位、成品数量、口味、型号

**字段分组**：模板头（模板名称/成品名称/成品单位/成品数量）→ 原料构成明细表格 → 保存。

### 功能按钮（对标实据）

打印(F8)、导出、保存 Ctrl+Enter（无保存草稿）

### 明细表格列配置（默认 9 列 · 全部 22 列对标实据）

**默认显示 9 列**：操作、商品名称（带「扫描枪录入」开关）、货号、条码、计价单位、数量、成本均价、成本金额、备注

**全部可配置 22 列**（cfg 实据）：操作、图片、商品名称、货号、条码、规格、型号、产地、品牌、计价单位、数量、成本均价、成本金额、小单位、小单位数量、小单位单价、备注、单据自定义1~3(数字字段)、单据自定义4~5(文本字段)

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。

## 业务规范说明

- 保存（Ctrl+Enter）即生效，无草稿/记账两段流程（区别于业务单据）；无单据编号、无单据信息行。
- 成品数量\*：一个模板单位产出量；明细「数量」为单模板用量的原料耗用量。
- 成本均价/成本金额：原料成本参考，合计行汇总原料总成本。
- 模板是组装单/拆分单的取数来源（开组装单时选模板自动带出原料明细，待复核）。
- 下游使用方：组装单（按模板投料生产）、拆分单（按模板拆解还原）；模板维护的成品/原料均来自 资料→商品管理→商品。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
