# 关键词库开发文档

> **文档类型：** 页面对标复刻（列表页 + 新增/编辑弹窗）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）商城模块
> **对标来源：** 顶部「商城」菜单 → 「商城设置」组 → 「关键词库」。**来源=对标系统实测抓取 2026-09-07**
> **定位：** 商城搜索关键词库管理：管理商城搜索热词/推荐词（关键词 + 备注 + 修改/删除）。即 XSMK 商城「商城设置 → 关键词库」。

## 页面概述

关键词库是**商城搜索关键词统一管理**页：维护商城搜索框可用的关键词，含查询、新增/编辑（关键词 + 备注）、删除。**单入口，列表页**（无子 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 关键词库 | `mall/keyword-bank` | 单视图列表页（筛选条件 + 关键词数据表 + 新增关键字弹窗） |

单入口：商城 → 商城设置 → 关键词库。

- 实测实据：**共 3 条记录**（西快 / 早餐 / 饺子，各含修改/删除操作）、每页 20 行；顶部按钮=新增关键字 + 打印(F8)；查询区=筛选条件（请输入关键词）+ 查询；数据表列=勾选框/操作/关键词名称/备注。

### 配置功能说明
- **列表结构**：关键词库为**单视图列表页**，无子 Tab。**无标准「页面配置」**（无查询条件/功能按钮 Tab 的配置齿轮），查询区与按钮区为固定项。
- **数据表列配置**：数据表右上角表头齿轮图标（`.icon-shezhi2`），弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**共 2 个可配置列，全部默认显示**。
- ⚠️ **当前实现说明**：本页当前为 `ARReportPage`（单表 + 顶部「新增关键词」按钮，无列配置/页面配置弹窗、无打印），但已对齐金标准字段语义（关键词 + 类型/排序/状态），见「实现差异说明 → 待完善」。

## 业务规范说明

- **关键词主线**：商城搜索关键词库（商家→买家端搜索框）；关键词为搜索热词/推荐词，供商城搜索联想与推荐。
- **关键词/备注**：列表展示关键词名称与备注；新增/编辑关键词必填关键词（≤30 字符），可填备注（≤30 字）。
- **状态**：金标准侧关键词无独立状态列（无启停），仅 关键词名称/备注 两列；本系统已实现 关键词类型（热门/置顶/屏蔽）+ 状态（启用/禁用）更细化。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/mall/keyword-bank/index.vue`
- API：`apps/pc-admin/src/api/erp/mall.ts`（`mallKeywordApi`：`/erp/mall/admin/keyword/page`、`POST /keyword`、`PUT /keyword/{id}`、`DELETE /keyword/{id}`、`PUT /keyword/{id}/status`）
- 后端：`backend/erp/erp-mall/.../MallAdminKeywordController.java`（`@RequestMapping("/api/erp/mall/admin/keyword")`）

### 页面对齐（已建成：`ARReportPage`）
- **列表**：当前为 `ARReportPage`，列=关键词/类型/排序/状态/创建时间/操作。
- **查询区（3 字段）**：关键词（input，模糊）、类型（select：热门/置顶/屏蔽）、状态（select：启用/禁用）。**与金标准（仅筛选条件·关键词）不一致**（本系统更丰富）。
- **头部按钮**：新增关键词（`header-extra`）。
- **行级操作**：编辑、状态开关（启用/禁用 a-switch，`toggleStatus`）、删除（popconfirm）。
- **新增/编辑弹窗字段**：关键词（限 50，placeholder「如：矿泉水、办公用品」）、类型（1热门/2置顶/3屏蔽）、排序。
- **状态**：`status` 1启用/0禁用（`mall_keyword.status`）；关键词类型 `keywordType` 1热门/2置顶/3屏蔽。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
