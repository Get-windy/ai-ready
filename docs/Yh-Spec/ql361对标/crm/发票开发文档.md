# 发票开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`crm/invoice/form`（表单）+ `crm/invoice/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=历史）：主按钮 → 新增/编辑表单页 `crm/invoice/form`；标签"历史"→ 列表页 `crm/invoice/index`。
- **表单页**：CRM 发票——开票登记，关联销售/收款（我方实现，views/crm/invoice/form.vue）。
- **列表页**：发票台账（我方实现，views/crm/invoice/index.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `crm/invoice/index.vue`（5 项）

- `invoiceNo` 发票号码（输入）
- `customerName` 客户名称（输入）
- `invoiceType` 发票类型（下拉：增值税专用发票/增值税普通发票/电子发票）
- `status` 状态（下拉：草稿/已开具/已发送/已收到/已作废）
- `dateRange` 日期范围（dateRange）

### 功能按钮

来源：我方源码 `crm/invoice/index.vue`

- 工具栏：刷新（行操作另含开票/发送/打印/作废）
- 行操作：查看、编辑、开票、发送、打印、作废（popconfirm 确认）

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段

来源：我方源码 `crm/invoice/form.vue`

- 必填（formRules）：发票号码\*、发票类型\*、开票日期\*、客户名称\*（customerId）
- 选填：发票抬头、纳税人识别号、关联订单（多选）、开票人、发票方向（销售/采购）、备注

### 字段分组／录单默认值／打印设置

- 字段分组：基本信息 → 发票明细 → 金额汇总 → 备注 → 审批流程
- 明细表格列（9 列）：商品名称、规格型号、单位、数量、单价、金额、税率、税额、操作
- 金额汇总（4 项）：发票金额(不含税)、税额、价税合计、明细数量
- 录单默认值：发票方向默认"销售发票"(sales)、明细税率默认 13%
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（9 列，来源：我方源码 `crm/invoice/index.vue`）

发票号码、发票类型、客户名称、开票日期、发票金额、税额、价税合计、状态、操作

### 全部可配置列（9 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `vxeColumns` 数组（9 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`crm/invoice/form`，标签按钮 list_path=`crm/invoice/index`，tag_label=历史（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- CRM 发票：开票登记，关联销售/收款。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
