## 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（会计月(止)）与截图确认：

- 查询方案（--查询方案--，支持保存方案）

无（抓取数据未覆盖打印配置弹窗；有打印(F8)按钮，打印模板配置细节待复核）

## 表格列配置

### 默认显示列（抓取 JSON columns 实据，8 列）

科目编码、科目名称、期间、摘要、借方、贷方、方向、余额

> JSON columns 首项"科目编码"经截图核对为真实首列，非抓取拼接串，计入列数。

### 行结构口径（截图实据）

- 摘要列取值：期初余额、本期合计（勾选"显示本年累计"时另有本年累计行；勾选"显示当前总计"时表尾加总计行）
- 方向列：借 / 贷 / 平（期初无余额的损益类科目方向为"平"）
- 余额列：随方向取值（借方向余额为正资产口径；贷方向为负债/权益口径）

## 业务规范说明

### 数据来源与取数逻辑

- 数据源自会计凭证（KJPZ-）记账后的分录汇总：按科目 × 会计月聚合借/贷发生额，期初余额=上期期末余额
- 科目层级：默认 1 级科目；调大层级展开至末级明细科目（层级深度随会计科目主数据）
- 科目体系实据（截图）：1001 现金库存、1002 银行存款、1122 应收账款、1123 预付账款、1405 库存商品、1601 固定资产、2202 应付账款、2203 预收账款、2204 预订货款、4000 期初资本、6001 主营业务收入、6051 其他业务收入

### 与其他页面关系

- 上游：《会计凭证开发文档》（手工录入 + 业务单据自动生成两条凭证来源）
- 联查：《明细账开发文档》（按科目逐笔）；核对：《科目余额表开发文档》（同一数据源的不同汇总维度）、"明细对账"按钮
- 报表：汇总结果供《资产负债表开发文档》《利润表开发文档》取数
- 期间约束：《月结开发文档》（已结账期间数据锁定）
- 本系统前端目录 `finance/general-ledger`（dynamicRoutes.ts 实据）
