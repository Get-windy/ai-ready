# 查费用开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/check-expense`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **账表页**（费用账）：费用科目×部门/职员/明细/往来单位四视图费用归集（科目层次结构 + 红冲并入）；期间费用归集与分摊分析页。菜单路径：分析 → 财务分析 → 查费用。
- 页面结构：视图 Tab（按部门/按职员/按明细/按往来单位）+ 查询区（两行）+ 矩阵表格（费用名称带文件夹图标，部门列矩阵）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__财务分析__查费用.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、日期类型（下拉，默认"单据日期"）、科目、部门（多选）

- 图形（表格/图表视图切换，图表形态待复核）、刷新、打印(F8)、导出、查询、跳转（分页跳转）

- 有打印(F8)按钮（费用报表打印）；打印配置弹窗字段级明细未抓取，待复核

## 3. 数据表格列配置

### 默认显示列（8 列，抓取 JSON columns 实据，按部门视图）

费用名称、费用编号、费用金额、管理部、客服部、配送部、仓管、兼职人员

> JSON columns 共 10 项，第 1 项"费用名称 费用编号 费用金额"与第 5 项"管理部 客服部 配送部 仓管 兼职人员"为抓取拼接串剔除；剔除后真实数据列 8 个（费用 3 列 + 部门 5 列，部门列随部门主数据动态生成），与截图表头逐一对应。按职员/按明细/按往来单位视图的矩阵列随维度变化（待复核）。

## 4. 业务规范

### 统计口径（费用归集矩阵）

- **费用金额 = 各维度列之和**（销售费用 5.21 = -217.26+175.4+47.07 ✅）；部门列负值为该部门费用红冲/退回净额
- **科目体系**：6601 销售费用、6602 管理费用、6603 财务费用、6711 营业外支出（与《经营分析》三费同源）
- **层次结构**：勾选"显示层次结构"后费用科目按层级呈现（父科目带子科目展开，文件夹图标）
- **包含红冲**：勾选后红冲费用单并入（负数冲减）
- **四视图**：按部门（部门矩阵）/按职员（职员矩阵）/按明细（单据级费用明细）/按往来单位（费用对象矩阵）

### 与其他页面关系

- 取数：费用单/其他支出单 + 随单费用（经手部门归属）
- 下游：《经营分析》（三费汇总口径）；同源：财务域《费用单》
