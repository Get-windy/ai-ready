## 附录

### A. 测试环境要求
- Java 11+
- Maven 3.6+
- 内存：4GB+
- 磁盘空间：10GB+

### B. 运行命令
```bash
# 运行所有测试
mvn clean test

# 运行特定标签测试
mvn test -Dgroups=import
mvn test -Dgroups=export
mvn test -Dgroups=json

# 运行测试套件
mvn test -Dtest=DataImportExportTestSuite
```

### C. 文件位置
- 测试代码：`I:\AI-Ready\tests\data_import_export\`
- 测试用例文档：`I:\AI-Ready\tests\data_import_export\DATA_IMPORT_EXPORT_TEST_CASES.md`
