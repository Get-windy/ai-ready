## 🎯 背景与目标

### 背景
采购订单管理是ERP系统的核心功能之一，连接采购申请、供应商管理、库存管理和财务管理等多个模块。基于现有代码分析，采购订单模块已实现基础的CRUD操作和状态流转，但缺少完整的订单执行跟踪、变更管理和结算流程。

### 目标
1. 完善采购订单全生命周期管理（创建→审批→执行→结算）
2. 实现订单执行跟踪和状态监控
3. 建立订单变更管理机制
4. 打通订单结算和对账流程
5. 与询价/报价模块无缝集成

| 角色 | 职责 | 主要操作 |
|------|------|----------|
| **采购申请人** | 提出采购需求 | 查看订单进度、确认收货 |

| **财务专员** | 结算付款 | 对账、发票管理、付款申请 |

## 🔄 业务流程

### 1. 订单创建流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  需求来源   │    │  创建订单   │    │  录入明细   │    │  提交审批   │
│ (询价/申请) │ → │  (草稿)    │ → │             │ → │  (待审批)   │
└─────────────┘    └─────────────┘    └─────────────┘    └──────┬──────┘
                                                                 │
                    ┌─────────────┐    ┌─────────────┐          │
                    │   编辑修改   │ ← │  审批驳回   │ ←─────────┘
                    │             │    │  (退回草稿) │
                    └─────────────┘    └─────────────┘
```

**订单创建触发条件**:
1. 询价报价中标后自动转单
2. 紧急采购手工创建
3. 长期协议合同生成订单
4. 补货建议自动生成

### 2. 订单审批流程

```
                    ┌──────────┐
         ┌─────────→│  草稿    │←─────────┐
         │          │ (DRAFT) │          │
         │          └────┬────┘          │
         │    编辑保存    │    提交审批    │
         │               ↓               │
         │          ┌──────────┐         │
         │    ┌────→│  待审批  │────┐    │
         │    │     │(PENDING)│    │    │
         │    │     └────┬────┘    │    │
         │  驳回          │          通过
         │               ↓
         │          ┌──────────┐
         │          │ 已审批   │←────供应商确认
         └─────────→│(APPROVED)│
                    └────┬────┘
                         │
                         ↓ 开始发货
                    ┌──────────┐
                    │ 执行中   │
                    │(EXECUTING)│
                    └────┬────┘
```

**审批规则**:
- 金额 < 10,000：部门经理审批
- 10,000 ≤ 金额 < 100,000：采购经理审批
- 金额 ≥ 100,000：总监审批 + 财务会签

### 3. 订单执行跟踪流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  已审批  │ → │ 供应商确认│ → │  已发货  │ → │  运输中  │
│          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └────┬─────┘
                                                     │
┌──────────┐    ┌──────────┐    ┌──────────┐        │
│  已完成  │ ← │ 部分入库  │ ← │  已到货  │ ←──────┘
│          │    │          │    │ 待验收   │
└──────────┘    └────┬─────┘    └──────────┘
                     │
                     └────────→ 全部入库 ─────→ 已完成
```

**执行状态说明**:
| 状态 | 说明 | 触发条件 |
|------|------|----------|
| 已审批 | 内部审批通过 | 审批人通过 |
| 待确认 | 等待供应商确认 | 审批通过后自动 |
| 已确认 | 供应商已确认 | 供应商操作 |
| 已发货 | 供应商已发货 | 供应商操作 |
| 运输中 | 货物在途 | 物流跟踪更新 |
| 已到货 | 货物到达仓库 | 仓库确认 |
| 部分入库 | 部分货物已入库 | 仓库入库操作 |
| 已完成 | 全部入库完成 | 入库数量=订单数量 |

### 4. 订单变更流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  变更申请   │    │  变更审批   │    │  供应商确认 │    │  执行变更   │
│  (申请人)   │ → │  (审批人)   │ → │  (供应商)   │ → │             │
└─────────────┘    └──────┬──────┘    └─────────────┘    └─────────────┘
                          │
                    ┌─────┴─────┐
                    ↓           ↓
              ┌─────────┐  ┌─────────┐
              │  通过   │  │  驳回   │
              │         │  │         │
              └────┬────┘  └────┬────┘
                   │            │
                   ↓            ↓
              继续流程      变更拒绝
```

**可变更内容**:
- 数量变更（增加/减少）
- 交期变更（提前/延后）
- 价格变更（需重新审批）
- 收货地址变更
- 联系人变更

### 5. 订单结算流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   对账      │    │  发票录入   │    │  付款申请   │    │  付款确认   │
│ (订单完成)  │ → │             │ → │             │ → │             │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
       │                  │                  │                  │
       ↓                  ↓                  ↓                  ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 对账单生成  │    │ 发票校验    │    │ 审批流程    │    │ 财务记账    │
│ 差异核对    │    │ 税额计算    │    │ 付款排程    │    │ 订单关闭    │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 📊 功能需求

### F1. 订单创建管理

#### F1.1 订单创建触发
**功能描述**: 支持多种方式触发采购订单创建

**触发方式**:
| 方式 | 场景 | 自动/手工 |
|------|------|----------|
| 询价转单 | 询价报价中标后 | 自动 |
| 手工创建 | 紧急采购、补货 | 手工 |
| 合同转单 | 长期协议生成订单 | 自动/手工 |
| MRP建议 | 系统根据库存自动生成 | 自动 |

**从询价转单规则**:
- 自动带入中标供应商信息
- 自动带入报价明细和价格
- 关联原询价单和报价单
- 生成新的订单编号

#### F1.2 订单信息录入
**功能描述**: 录入采购订单主信息

**字段清单**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 订单类型 | Enum | 是 | 普通采购/紧急采购/合同采购 |
| 供应商 | Long | 是 | 关联供应商ID |
| 供应商名称 | String | 自动 | 显示名称 |
| 订单日期 | Date | 是 | 默认当天 |
| 预计到货日期 | Date | 是 | 计划到货时间 |
| 采购部门 | Long | 是 | 负责部门 |
| 采购员 | Long | 是 | 负责人 |
| 收货仓库 | Long | 是 | 目标仓库 |
| 收货地址 | String | 否 | 详细地址 |
| 联系人 | String | 否 | 收货联系人 |
| 联系电话 | String | 否 | 联系电话 |
| 付款条款 | Text | 否 | 付款方式/账期 |
| 交货条款 | Text | 否 | 运输方式/费用承担 |
| 备注 | Text | 否 | 特殊要求 |

**业务规则**:
- 订单号自动生成，格式: PO-YYYYMMDD-XXXX
- 预计到货日期必须晚于订单日期
- 供应商必须处于"合格"状态

#### F1.3 订单明细录入
**功能描述**: 录入采购物资明细

**明细字段**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 行号 | Integer | 自动 | 自动递增 |
| 物料编码 | String | 是 | 系统物料编码 |
| 物料名称 | String | 自动 | 显示名称 |
| 规格型号 | String | 自动/手工 | 技术规格 |
| 单位 | String | 是 | 计量单位 |
| 数量 | Decimal | 是 | 采购数量，精度4位 |
| 单价 | Decimal | 是 | 不含税单价，精度4位 |
| 税率 | Decimal | 是 | 默认13%，可修改 |
| 含税单价 | Decimal | 自动 | 计算得出 |
| 行金额 | Decimal | 自动 | 数量×含税单价 |
| 税额 | Decimal | 自动 | 计算得出 |
| 预计到货日期 | Date | 否 | 可逐行指定 |
| 备注 | String | 否 | 行备注 |

**自动计算逻辑**:
```
含税单价 = 单价 × (1 + 税率/100)
行金额 = 数量 × 含税单价
税额 = 数量 × 单价 × 税率/100
订单总金额 = Σ(行金额)
订单总税额 = Σ(税额)
```

#### F1.4 订单模板
**功能描述**: 支持常用订单模板快速创建

**模板类型**:
- 标准采购模板
- 紧急采购模板
- 固定资产采购模板
- 办公用品采购模板

**模板内容**:
- 预设物料清单
- 默认供应商
- 默认审批流程
- 默认付款条款

### F2. 订单审批管理

#### F2.1 审批流程配置
**功能描述**: 根据订单金额和类型自动确定审批流程

**审批规则配置**:
| 条件 | 审批流程 |
|------|----------|
| 金额 < 10,000 | 部门经理 → 结束 |
| 10,000 ≤ 金额 < 50,000 | 部门经理 → 采购经理 → 结束 |
| 50,000 ≤ 金额 < 100,000 | 部门经理 → 采购经理 → 财务经理 → 结束 |
| 金额 ≥ 100,000 | 部门经理 → 采购经理 → 财务经理 → 总监 → 结束 |
| 紧急采购 | 采购经理 → 结束（简化流程） |

#### F2.2 审批操作
**功能描述**: 审批人对订单进行审批操作

**审批操作**:
| 操作 | 说明 | 后续状态 |
|------|------|----------|
| 通过 | 同意订单 | 进入下一审批人或已审批 |
| 驳回 | 不同意，退回修改 | 退回草稿状态 |
| 转交 | 转给其他人审批 | 待审批（变更审批人） |
| 加签 | 增加审批人 | 待审批（增加节点） |

**审批记录**:
- 审批人、审批时间
- 审批结果、审批意见
- 审批时长统计

#### F2.3 审批提醒
**功能描述**: 审批任务提醒和催办

**提醒方式**:
- 系统消息通知
- 邮件通知
- 企业微信/钉钉通知

**催办规则**:
- 超过24小时未审批：自动提醒
- 超过48小时未审批：发送给上级
- 紧急订单：缩短提醒间隔

### F3. 订单执行跟踪

#### F3.1 供应商确认
**功能描述**: 供应商查看并确认订单

**确认流程**:
1. 供应商收到订单通知
2. 查看订单详情
3. 确认能否履约（确认/拒绝）
4. 填写预计发货时间
5. 确认后订单状态更新为"已确认"

**供应商拒绝场景**:
- 库存不足
- 价格变动
- 交期无法满足
- 其他原因（需填写说明）

#### F3.2 发货跟踪
**功能描述**: 跟踪供应商发货和物流状态

**发货信息**:
| 字段 | 说明 |
|------|------|
| 发货日期 | 实际发货时间 |
| 物流单号 | 快递/物流单号 |
| 物流公司 | 承运商名称 |
| 发货数量 | 本次发货数量 |
| 预计到达 | 预计到达时间 |
| 发货备注 | 特殊说明 |

**物流跟踪**:
- 集成第三方物流查询接口
- 自动更新物流状态
- 到达预警通知

#### F3.3 收货验收
**功能描述**: 仓库收货并验收

**收货流程**:
1. 货物到达仓库
2. 扫描物流单号关联订单
3. 清点数量、检查质量
4. 录入实际收货数量
5. 记录质检结果（合格/不合格）
6. 完成入库操作

**收货异常处理**:
| 异常类型 | 处理方式 |
|----------|----------|
| 数量短缺 | 记录短缺数量，通知采购 |
| 质量问题 | 拒收/退货，记录原因 |
| 错发漏发 | 拍照记录，联系供应商 |
| 包装破损 | 开箱检验，记录破损情况 |

**部分入库支持**:
- 支持分批到货、分批入库
- 记录每次入库数量
- 自动计算剩余未到货数量
- 入库完成自动更新订单状态

#### F3.4 执行状态看板
**功能描述**: 可视化展示订单执行状态

**看板视图**:
- 待处理订单（待审批/待确认）
- 执行中订单（已确认/已发货/运输中）
- 待收货订单（已到货/待验收）
- 异常订单（延期/质量问题/数量差异）
- 已完成订单

**统计指标**:
- 订单总数、金额汇总
- 各状态订单数量分布
- 平均审批时长
- 平均到货周期
- 准时交付率
- 质量合格率

### F4. 订单变更管理

#### F4.1 变更申请
**功能描述**: 支持对执行中的订单发起变更申请

**可变更字段**:
| 字段 | 变更条件 | 审批要求 |
|------|----------|----------|
| 数量 | 未全部入库 | 部门经理审批 |
| 交期 | 未发货 | 采购经理审批 |
| 价格 | 任何阶段 | 重新走审批流程 |
| 收货地址 | 未发货 | 采购专员确认 |
| 联系人 | 任何阶段 | 无需审批 |

**变更类型**:
- 数量增加：追加采购
- 数量减少：部分取消
- 交期提前：紧急需求
- 交期延后：供应商协商
- 价格调整：市场波动/协商结果

#### F4.2 变更审批
**功能描述**: 变更申请需要经过审批

**审批流程**:
1. 采购专员提交变更申请
2. 系统判断变更类型和影响
3. 根据规则路由到相应审批人
4. 审批人查看变更详情和影响
5. 审批通过/驳回
6. 通知相关方（供应商、仓库等）

**变更影响评估**:
- 对库存的影响
- 对生产计划的影响
- 对财务预算的影响
- 对供应商的影响

#### F4.3 变更记录追溯
**功能描述**: 完整记录订单变更历史

**变更记录内容**:
- 变更单号
- 变更类型
- 变更前/后值
- 变更原因
- 申请人、申请时间
- 审批人、审批时间
- 审批意见
- 供应商确认记录

**变更查询**:
- 按订单查询变更历史
- 按时间范围查询
- 按变更类型查询
- 变更统计报表

### F5. 订单结算管理

#### F5.1 对账管理
**功能描述**: 订单执行完成后进行对账

**对账流程**:
1. 订单全部入库后自动触发对账
2. 系统生成对账单
3. 核对订单金额与实际入库金额
4. 核对数量、价格、折扣
5. 确认对账结果
6. 生成应付账款

**对账单内容**:
| 项目 | 说明 |
|------|------|
| 对账单号 | 自动生成 |
| 订单信息 | 订单号、日期、金额 |
| 入库明细 | 入库单号、数量、金额 |
| 差异说明 | 如有差异需说明 |
| 应付金额 | 最终确认金额 |

**差异处理**:
- 数量差异：按实际入库数量结算
- 价格差异：按实际成交价结算
- 质量扣款：记录扣款原因和金额

#### F5.2 发票管理
**功能描述**: 管理供应商开具的发票

**发票录入**:
- 发票类型（增值税专用发票/普通发票）
- 发票代码、发票号码
- 开票日期
- 金额、税额、价税合计
- 发票附件上传

**发票校验**:
- 发票真伪验证（对接税务系统）
- 金额与对账单核对
- 税率与订单核对
- 供应商信息核对

**发票状态**:
- 待收票
- 已收票
- 已验证
- 已认证
- 已作废

#### F5.3 付款申请
**功能描述**: 基于对账结果申请付款

**付款申请流程**:
1. 对账完成且发票已收
2. 采购专员提交付款申请
3. 财务审核（金额、发票、账期）
4. 按付款条款排程
5. 审批通过进入付款队列
6. 财务执行付款
7. 更新订单付款状态

**付款条款**:
| 条款 | 说明 |
|------|------|
| 货到付款 | 入库后立即付款 |
| 月结30天 | 入库后30天付款 |
| 月结60天 | 入库后60天付款 |
| 月结90天 | 入库后90天付款 |
| 预付X% | 订单确认后预付 |

**付款状态**:
- 未付款
- 部分付款
- 已付款
- 已超额付款

#### F5.4 结算状态跟踪
**功能描述**: 跟踪订单结算全流程

**结算状态**:
```
待对账 → 对账中 → 已对账 → 待开票 → 待付款 → 已付款 → 已结算
```

**结算报表**:
- 应付账款汇总表
- 付款计划表
- 供应商账龄分析
- 订单结算明细表
