# 预付款单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/pre-payment`（表单）+ `finance/pre-payment`（列表）；另有 advance-payment 目录，对应关系待复核
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页**：先付供应商货款、后抵应付的预付款登记，与预收款单对称。页面性质 = 表头结算单位字段区 + 付款账户明细表格 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/pre-payment`（表单）；标签「历史」→ `finance/pre-payment`（列表，预付登记历史）。
- 单号实据：NO. YFKD-20260723-001（YFKD- 前缀 + YYYYMMDD-序号）。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：结算单位\*、经手人\*（另有单据日期\* 截图确认必填）
- 只读联动：此前预付（选定结算单位后自动带出当前预付余额）

> 表头一行布局实据：结算单位\*/经手人\*/单据日期\*/此前预付（只读）。

### 字段分组

表头（结算单位/经手人/单据日期/此前预付）→ 付款账户明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录/源单）→ 底部本单金额与操作

### 录单默认值 / 打印设置

- 经手人默认当前登录人、单据日期默认当天。
- 打印(F8)按钮及打印次数/打印记录字段存在；打印配置弹窗抓取未覆盖，打印模板配置细节待复核。

### 功能按钮（按抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 明细区查询条件

无（表单页无查询区）。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后预付款生效，结算单位"预付余额"增加（此前预付字段为记账前余额快照）
- 一单多账户：明细可填多行不同付款账户，本单金额=Σ付款金额
- 预付"付→抵→退"主线之"付"：本页为预付余额的标准入口；付款单"使用预付款"为"抵"；采购退货退款退回预付为"退"（与预收"收→抵→退"对称）
- 记账后生成会计凭证（KJPZ-）；总账科目实据 1123 预付账款
- 下游抵扣：《付款单开发文档》使用预付款区（此前预付/使用预付款/预付款余额）
- 账户主数据：付款账户来自资料 → 财务账户 → 银行账户
- 对比预收款单：无"本单赠送金额"字段（实据，供应商侧无赠送场景）
- 本系统前端目录 `finance/pre-payment`、`finance/advance-payment`（双目录对应关系待复核）
