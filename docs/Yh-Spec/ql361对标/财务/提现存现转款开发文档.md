## 1. 页面概述

- **表单页**：资金在本企业账户间移动（银行提现、现金存行、账户互转），不涉及往来单位。页面性质 = 表头转出账户字段区 + 转入账户明细表格 + 手续费 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/cash-transfer/form`；标签「历史」→ `finance/cash-transfer`（列表）。
- 单号实据 NO. YHZKD-20260723-001（YHZKD- 前缀 + YYYYMMDD-序号）；标题行含附件、键盘（快捷录入）、齿轮（配置）图标（截图实据）。

## 2. 表单页配置

### 表头字段（必填 * 标注 / 选填）

- 必填：转出账户\*（带新增+搜索）、经手人\*（默认当前登录人）、单据日期\*（默认当天）
- 表尾：手续费（带"…"选择弹窗，手续费承担账户/科目待复核）、单据备注

### 全部表单字段（13 个，抓取 JSON filterLabels + 截图实据归纳）

- 表头：转出账户、经手人、单据日期
- 明细：转入账户编号、转入账户名称、转入金额、备注
- 表尾：手续费、单据备注
- 单据信息：制单人、打印次数、打印记录
- 底部：本单金额

### 字段分组

表头（转出账户/经手人/单据日期）→ 转入账户明细表格 → 表尾（手续费/单据备注）→ 单据信息（制单人/打印次数/打印记录）→ 底部本单金额与操作。

### 录单默认值

经手人默认当前登录人、单据日期默认当天（截图实据）。

## 5. 业务规范

- 状态流转：保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后转出账户余额减少、各转入账户余额增加，资金总额守恒，并自动生成会计凭证（KJPZ-；明细账摘要实据"由[提现存现转款单 YHZKD-…]…"）。
- 一对多转入：一张单可拆分到多个转入账户（如提现部分存保险柜、部分存店面备用金），本单金额=Σ转入金额。
- 手续费：跨行/提现手续费单独登记，随单计入费用（手续费科目归属待复核）。
- 与其他页面关系：账户主数据：转出/转入账户均来自资料 → 财务账户 → 银行账户（含现金类账户；总账科目实据 1001 现金库存下设 现金/店面备用金/敦煌店面备用金 明细）；与账款交账衔接：职员交账收到的现金/转账先入账户，再经本页存行或上调；下游账簿：总账/明细账（明细账摘要回链本单单号）；本系统前端目录 `finance/cash-transfer`（dynamicRoutes.ts 实据）。
