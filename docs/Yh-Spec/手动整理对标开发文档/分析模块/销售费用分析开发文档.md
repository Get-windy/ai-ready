## 1. 页面概述

销售费用分析页是**销售投入产出（费销比）看板**：把销售过程中产生的六类让利/费用按业务归属主体（往来单位 / 职员）归集为 `费用总额`，再与 `销售收入` 对比得出 `费销比(%)`，用于评估客户/业务员的销售经济性。

| 页面 | 地址 | 说明 |
|------|------|------|
| 销售费用分析 | `analytics/sales-expense` | 单入口复合页（2 个视图 Tab：按往来单位 / 按职员；逐 Tab 独立列配置，结构同构） |

单入口：分析 → 采销分析 → 销售费用分析。

- 实测实据（2026-09-15）：
  - `按往来单位` 共 **161** 条记录（含大量销售收入为 0 的长尾单位）。实据样本：肃州区北关龙虾猪蹄王 销售收入 175 / 赠品 6.78 / 优惠 1.58 / 费用总额 8.36 / 费销比 4.78；嘉峪关市润泽园小区西门蜜粉儿 销售收入 0 / 优惠 1.08 / 费用总额 1.08 / 费销比 100。**合计行**：费用总额 `41,353.12`。
  - `按职员` 共 **7** 条记录。实据样本：HC001 杨生淮 销售收入 36,778.12 / 赠品 282.42 / 优惠 77.22 / 费用总额 359.64 / 费销比 0.98；HC003 刘洋洋 销售收入 0 / 优惠 0.63 / 费用总额 0.63 / 费销比 100；HC006 许军 35 / 0 / 0.07 / 0.07 / 0.2。**合计行**：费用总额 `355.67`。
- 六类费用中 `促销活动`、`商品兑付`、`金额兑付`、`其它费用` 在本次实据中**均为 0**（当前数据无此类费用）。

## 4. 业务规范

### 统计口径（六类费用 + 费销比）

- **费用总额** = 赠品 + 促销活动 + 优惠 + 商品兑付 + 金额兑付 + 其它费用。实据：杨生淮 282.42 + 0 + 77.22 + 0 + 0 + 0 = **359.64** ✅；肃州区北关龙虾猪蹄王 6.78 + 0 + 1.58 + 0 + 0 + 0 = **8.36** ✅。
- **费销比(%)** = 费用总额 / 销售收入 × 100。实据：杨生淮 359.64 / 36,778.12 ≈ 0.98 ✅；肃州区北关龙虾猪蹄王 8.36 / 175 ≈ 4.78 ✅；高晓丽 63.6 / 1,188 ≈ 5.35 ✅。
  - ⚠️ **零收入兜底口径**：`销售收入 = 0` 且 `费用总额 > 0` 时费销比显示 **100**（实据：刘洋洋 0.63/0 → 100；嘉峪关市润泽园小区西门蜜粉儿 1.08/0 → 100），**非 0、非空**；该兜底是否为「截断到 100」还是「分母置 1」**待复核**（与基准文档一致）。
  - ⚠️ **负收入**：`销售收入` 为负（退货净额）时费销比为负（基准文档记载，本次实据未出现负收入行，**待复核**）。
- **六类费用分项语义**：`赠品`（随单赠货成本）、`促销活动`（活动分摊费用）、`优惠`（整单/单品优惠让利）、`商品兑付`（以货抵付）、`金额兑付`（以款抵付）、`其它费用`（随单费用，如物流/装卸）。
- **销售收入**：与《销售分析》`销售收入`口径一致（净销售 = 销售额 − 退货额）；本次实据中按职员合计 41,353.12 与《销售业绩》实销金额合计一致（同源口径交叉验证 ✅）。
- **维度语义**：`按往来单位` 以客户/供应商为单位归集（161 条，含大量零收入长尾）；`按职员` 以经手人为单位归集（7 条，与《销售业绩》职员集合同源）。

### 与其他页面关系

- 取数：销售出库单优惠/赠品明细 + 促销活动费用分摊 + 兑付记录 + 随单费用。
- 同源页：《销售分析》（`其他费用支出` / `结算优惠` 列）、《查费用》（费用单单据级口径）、《营销活动分析》（活动侧投入产出）、《销售业绩》（销售收入口径交叉验证）。
- 下游：`总额设置` 调整后应同步影响 `费用总额` 与 `费销比(%)`（设置项弹窗待复核）。

## 5. 实现差异说明

> 本节按当前源码与真机实测（2026-09-18）回写。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/sales-expense/index.vue`（413 行）。
- **骨架**：`ErrorBoundary > PageContainer(full-height) > CategoryListLayout`（`:tabs="TABS"`、`:show-category-panel="false"`、`:show-table-footer="true"`、`@tab-change`）+ `BillDetailTable`（`:view-mode="true"`、`:min-rows="20"`）+ `StandardPagination`（`variant="classic"`）。
- **逐 Tab 列数**：**双视图 Tab**（按往来单位 / 按职员），两 Tab 各 **11 列 / 默认 11 列**（无默认隐藏列）；逐 Tab 独立列配置键 `analytics-sales-expense-columns-<byPartner|byStaff>`（`storage-key` = `global-config-key`）。
- **页面配置**：**无 `PageConfigPanel`**（对标实测无该弹窗）→ 查询区为固定项。
- **查询项**：工具栏左侧 8 段时间快捷段（默认「本月」）+ 日期范围；查询区随 Tab 切换的 3 个维度过滤项（Tab1：往来单位 / 经手人 / 部门；Tab2：职员 / 往来单位 / 部门）+ 查询 / 重置；逐 Tab 独立查询态（切 Tab 不串用）。
- **打印(F8) / 导出**：打印为 `window.print()` 直出当前 Tab 的当前页表格（列口径 = 去除序号列的所有列），绑定 F8；导出为聚合结果全量 CSV（`useExport`，`fetchAll` 直接返回内存中的聚合结果）。
- **合计行 / 分页**：**无合计行**（后端费用单口径无 summary 字段）；聚合在客户端完成，分页亦为前端分页（每页 20/50/100）。
- **取数端点与口径**：`GET /erp/finance/expense-doc/page`（`expenseDocApi.getPage`，单次 500 条、上限 5000 条）→ 按当前 Tab 维度（往来单位 = `partnerCode/partnerName`；职员 = `handlerName`）聚合出「单位/职员编号 + 名称 + 费用总额」，其余对标列如实留空（不编造 0）。
- **后端**：本轮未改后端（**无按往来单位 / 职员归集销售费用的端点**，见缺口 1）；未新增迁移。

### 剩余缺口

1. **取数口径与对标不等价（最大缺口）**：对标 11 列 = 销售收入 + 六类让利（赠品 / 促销活动 / 优惠 / 商品兑付 / 金额兑付 / 其它费用）+ 费用总额 + 费销比(%)；本页只能取到「费用总额」= `erp_expense_doc.total_amount` 聚合，即**费用单单据口径**，与文档 §4 定义的「销售让利六类之和」不同。已核实：`api/analytics.ts` 的 `expenseStatisticsApi` 仅有 `by-department` / `by-type` 两个端点，后端无「按往来单位 / 职员归集销售费用」的 `@GetMapping`（证据：`analytics.ts:829-836`、本页取数实现 `index.vue:213-236`）。
2. **8 个对标列无数据源、恒显示 `-`**：销售收入、赠品、促销活动、优惠、商品兑付、金额兑付、其它费用、费销比(%)（`aggregate()` 显式置 `null`，`index.vue:251-264`，不返回 0 / 不造占位假值）。
3. **「总额设置」未落地**：对标工具栏有 `总额设置`（费用总额构成 / 费销比口径设置），本页无该入口（入口本身的弹窗字段在对标侧未抓取到，**未确证**）。
4. **无钻取**：对标六类费用 / 费用总额数值带下划线可下钻，本页无行级动作（列定义中无 `action`）。
5. **聚合上限**：单次查询最多统计 5000 条费用单（超出弹提示），超出部分不计入聚合（`index.vue:210-211`、`:273-275`）。
6. **分页为前端分页**：数据已全量拉取并在内存聚合，分页 / 排序均在前端，非后端分页。
