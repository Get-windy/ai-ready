## 页面概述

仓库规划用于维护**仓库主数据**（仓库编号/名称/联系人/联系电话/地址，含仓库分类树）。为「资料 → 仓库管理 → 仓库规划」页。单入口，页面内含 **「1.仓库」「2.货位」两个 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 仓库规划 | `md/warehouse-plan` | 仓库列表（1.仓库）+ 货位列表（2.货位）+ 新增仓库弹窗 |

> 对标实测：仓库规划=「1.仓库」（仓库主数据+仓库分类树）与「2.货位」（货位列表，列：所属仓库/货位编号/备注）两个 Tab；不含库区层级。货位的「推荐货位」维护另见《商品货位设置》。

### 配置功能说明

- **列配置弹窗**：两个 Tab 各自的数据表均可开列配置弹窗（个人配置/全局配置 Tab，表头 列名/显示名/显示，底部 上移/下移/恢复默认/保存）。
- ⚠️ **无页面配置弹窗**：本页无「配置」齿轮（`iconButtonConfig`）——查询条件与功能按钮为**固定项**，不可配置（见下表）。
- **导出**：列表支持导出（`export-file-name=仓库规划`）。

## 业务规范说明

- **仓库主数据**：仓库是库内作业（收货/上架/拣货/发货/盘点/移库）的最小业务实体，`wms_warehouse` 通过 `warehouseId` 关联 `erp_warehouse.id`。
- **仓库类型**：1 普通仓/2 冷库/3 危险品仓/4 保税仓（决定库存流程与温湿度/危化约束）。
- **WMS开关**：`isWmsEnabled` 0 停用/1 启用，控制仓库是否纳入 WMS 库内作业流程。
- **容量**：`totalCapacity` 总容量/`usedCapacity` 已用容量（单位 m³），已用容量由库存占用写入。
- **编号**：仓库编码人工维护、无自动前缀。
- **upstream**：仓库在《商品货位设置》中设「推荐货位」；其他单据（收货/发货/调拨等）选择仓库时经 `warehouseApi.listAll` 拉取。

## 实现差异说明

**实现文件**：
- 前端：`views/md/warehouse-plan/index.vue`
- API：`api/wms/warehouse.ts`（`warehouseApi`：`save` POST `/wms/warehouse/save`、`update` POST `/wms/warehouse/update`、`getById` GET `/{id}`、`page` GET `/wms/warehouse/page`、`remove` DELETE `/{id}`、`listAll` GET `/list-all`）
- 后端：`wms` 模块 `controller/WarehouseController.java`（`@RequestMapping("/api/wms/warehouse")`；POST /save、POST /update、GET /{id}、GET /page、DELETE /{id}、GET /list-all）
- 表：`wms_warehouse`（`warehouseId` 关联 `erp_warehouse.id`）

### 页面对齐（已建成）
- **列表页**：`ARReportPage`（查询区 + `BillTableList` 表格 + 导出），page 参数映射后端 `current`。
