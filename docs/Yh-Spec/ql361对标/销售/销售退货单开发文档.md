# 销售退货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/return/form`（表单）+ `sales/return/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**：表单页（`sales/return/form`）= 销售退货入库录单（退货商品回仓），编辑模式为新增模式加 id；列表页（`sales/return/index`）= 按单据 / 按明细两个 tab。
- 表单页结构：表头字段区 + 商品明细表格 + 底部付款/物流信息/会员信息 3 Tab + 备注区 + 单据信息行。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：客户\*、入库仓库\*、经手人\*、单据日期\*、销售类型\*（默认"正常销售"）

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账即确认退货入库，增加库存并冲减应收（或退款）。
- 资金方向为"付款"（企业退钱给客户）；"退回预收款"指把退货金额退回客户预收余额而非现金付出；"应收款减少"冲减客户应收账款。
- 与销售退货申请的关系：申请是前置审批单（需审核），本单是正式退货入库单；两条路径并存——申请审核通过转退货单，或直接开退货单（具体约束待复核）。
- 明细带批次条码/生产日期/保质期/到期日期，退货商品批次回仓可溯源。
- 上游：销售出库单（退货针对已出库商品，可带源单）、销售退货申请（审批转单）；下游：销售单据查询/销售明细查询（单据类型=销售退货单，退货金额参与统计）；拜访检视"退货金额"指标来源于本类单据。
