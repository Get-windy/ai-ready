## 📋 检查清单概览

本检查清单用于确保测试环境满足质量标准，覆盖基础设施、应用服务、数据完整性和安全合规四个维度。

---

## 一、环境部署检查项

### 1.1 基础设施层

| 检查项 | 验收标准 | 检查方法 | 负责人 | 状态 |
|--------|---------|---------|--------|------|
| 服务器资源 | CPU ≥ 4核, 内存 ≥ 16GB, 磁盘 ≥ 100GB | 系统监控工具验证 | 运维 | ☐ |
| 网络配置 | 内网连通性正常，外网访问按需开放 | ping/telnet/nc测试 | 运维 | ☐ |
| 存储系统 | 分布式存储挂载正常，读写性能达标 | IO性能测试工具 | 运维 | ☐ |
| 容器环境 | Docker/K8s集群运行正常，版本符合要求 | kubectl get nodes | 运维 | ☐ |
| 负载均衡 | 负载均衡器配置正确，健康检查通过 | LB管理控制台检查 | 运维 | ☐ |

**验收标准**:
- [ ] 所有基础设施组件运行正常
- [ ] 资源配额满足最小要求
- [ ] 网络策略配置正确

| 检查项 | 验收标准 | 检查方法 | 负责人 | 状态 |

## 四、质量检查流程

### 4.1 检查执行流程

```
┌─────────────┐
│ 1. 准备阶段  │ → 检查清单确认、工具准备、环境访问权限
└──────┬──────┘
       ↓
┌─────────────┐
│ 2. 执行阶段  │ → 按检查项逐一执行，记录检查结果
└──────┬──────┘
       ↓
┌─────────────┐
│ 3. 问题记录  │ → 发现问题记录到问题清单，分类严重程度
└──────┬──────┘
       ↓
┌─────────────┐
│ 4. 结果汇总  │ → 生成检查报告，统计通过率
└──────┬──────┘
       ↓
┌─────────────┐
│ 5. 问题跟踪  │ → 问题分配负责人，跟踪解决进度
└──────┬──────┘
       ↓
┌─────────────┐
│ 6. 复查确认  │ → 问题修复后重新检查，确保环境就绪
└─────────────┘
```

### 4.2 检查频率

| 检查类型 | 执行频率 | 执行时机 | 执行人 |
|---------|---------|---------|--------|
| 完整检查 | 每月/重大变更前 | 环境部署、版本发布前 | QA Lead |
| 日常检查 | 每日 | 每日晨检 | 运维团队 |
| 服务检查 | 实时监控 | 持续监控 | 自动化监控 |
| 安全检查 | 每周 | 定期安全巡检 | 安全团队 |

### 4.3 问题分类与处理

| 严重级别 | 定义 | 处理时限 | 升级条件 |
|---------|------|---------|---------|
| 🔴 Critical | 核心服务不可用，阻塞测试 | 立即处理，< 1小时 | 自动升级至项目经理 |
| 🟠 High | 主要功能异常，影响测试进度 | < 4小时 | 2小时未解决升级 |
| 🟡 Medium | 次要功能异常，有临时解决方案 | < 24小时 | 12小时未解决升级 |
| 🟢 Low | 不影响测试，优化项 | 下一迭代处理 | 按需升级 |

## 六、附录

### 6.1 检查工具清单

- **网络检查**: ping, telnet, nc, curl, wget
- **服务检查**: kubectl, docker, systemctl, supervisorctl
- **数据库检查**: mysql, redis-cli, mongo, curl (ES)
- **日志查看**: kubectl logs, docker logs, tail/f
- **性能测试**: ab, wrk, jmeter
- **监控查看**: Grafana Dashboard, Prometheus UI

### 6.2 快速检查脚本

```bash
#!/bin/bash
# 测试环境快速检查脚本

echo "=== 测试环境质量检查 ==="
echo "检查时间: $(date)"

# 1. 检查服务状态
echo -e "\n[1] 检查服务状态..."
kubectl get pods -n test-env

# 2. 检查数据库连接
echo -e "\n[2] 检查数据库连接..."
mysql -h mysql-host -u test -p'password' -e "SELECT 1"

# 3. 检查Redis连接
echo -e "\n[3] 检查Redis连接..."
redis-cli -h redis-host ping

# 4. 检查API健康状态
echo -e "\n[4] 检查API健康状态..."
curl -s http://api-gateway/health | jq .

# 5. 检查磁盘空间
echo -e "\n[5] 检查磁盘空间..."
df -h | grep -E "Filesystem|/dev/sd"

echo -e "\n=== 检查完成 ==="
```
