## 2.1 采购订单表单生产级化（P0，2.5 人日）

- **页面**：`purchase/order/form` → `views/erp/purchase/form.vue`（双入口，历史 `purchase/order/index` → `views/erp/purchase/index.vue`）
- **权威依据**：`docs/Yh-Spec/采购模块/采购订单开发文档.md`——**逐节核对实现，文档为准**
- **对标**：销售订单表单（views/erp/sale/form.vue，1171 行金标准）+ Odoo purchase.order

**改造内容**（先读现状代码与销售表单，逐项差距补齐）：
1. 头部档案区：供应商选择器（带出联系人/电话/应付余额）、收货仓库、经手人、单据日期、采购类型、交货日期
2. 商品明细网格：对齐销售单（商品选择器带出采购价/最近进价、件散数量、多包装单位、税率、含税/未税金额）；销售单有批次/生产日期而采购订单为预期到货场景——按开发文档定夺批次字段显隐
3. 底部：付款区（订金账户/订金金额，对称销售收款区）、物流信息、单据备注、制单人/制单时间/源单
4. 金额面板：采购数量/商品金额/优惠/其他费用/本单金额
5. 操作链：草稿→提交（触发审批引擎，已接入）→审核→入库联动（生成采购入库单入口）→红冲；打印(F8)；导入
6. 配置弹窗：页面配置/录单默认值/打印设置（对齐销售单已实现的配置组件，复用）

## 2.2 采购入库单（P0，1.5 人日）

- **页面**：`purchase/inbound/form`（双入口，历史 purchase/inbound/index）
- **后端**：PurchaseInboundServiceImpl 已回写库存（C2 修复），19 流程列已补（V11.12.0）
- **对标**：Odoo stock.picking（receipt）+ 管家婆采购入库单
- **要点**：
  1. 源单联动：选采购订单自动带明细（可改到货数量），支持部分入库（多次入库累加，订单行已入库数量回写）
  2. 明细网格：批次号/生产日期/保质期（入库时必须，与库存批次联动）、货位
  3. 质检环节：与质量管理（批次 3.5）状态联动——待质检→质检合格→正式入库（先读现状 quality-check 端点，C2 已验证此链路）
  4. 操作链：草稿→提交→收货→质检→入库确认（库存+应付+凭证触发点）→红冲（库存回冲，已实现）
- **验收**：部分入库场景 E2E（订单 100，两次入库 60+40，订单状态=全部入库）；批次信息写入库存

## 2.3 采购费用分摊（P0，1.5 人日）

- **页面**：`purchase/cost-sharing/form`（现 401 行降级态）
- **对标**：Odoo Landed Cost（`stock.landed.cost`）：费用（运费/装卸/保险）按 金额/数量/重量/体积 分摊到入库单明细行，计入存货成本
- **改造**：
  1. 选择费用单/手工录入费用项
  2. 选择待分摊采购入库单（可多选）
  3. 分摊方式选择（按金额/数量/重量），预览分摊结果（每行分摊额）
  4. 确认分摊→回写入库单行成本→库存成本重算（移动加权平均口径，先读 StockService 成本口径现状）
- **后端**：四问排查费用分摊端点现状（进度文档 B2 标注"占位表单"），大概率需补 Service 逻辑
- **验收**：分摊后库存成本=（原值+分摊额），成本调整流水可查

## 2.4 采购准备四页（P1，1.5 人日）

- **页面**：库存预警补货（137 行）/缺货补货（138 行）/智能补货/以销定购
- **对标**：Odoo `stock.orderpoint`（补货规则→自动生成 RFQ）
- **要点**：
  1. 四页口径统一定义（预警补货=低于安全库存；缺货=当前缺货订单所需；智能=按销售趋势预测；以销定购=按销售订单需求）——先读四页现状 fetcher，梳理各自 SQL 口径并在页面副标题注明
  2. **一键生成采购订单**：勾选建议行→按供应商分组→生成采购订单草稿（核心闭环，四页统一实现）
  3. 建议量可编辑、供应商可改选
- **验收**：从预警页勾选 3 行生成采购订单，供应商分组正确、数量一致
