# 其他收入开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`md/other-income`（dynamicRoutes.ts 实据；财务域另有 finance/other-income 为其他收入单据页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：其他收入类型（营业外收入等收入类损益科目）主数据维护页，查询区 + 数据表格，单一列表视图，与费用类型对称。
- 截图：![其他收入](../../../../tool-results/ql361/pages/资料__财务账户__其他收入.png)

## 2. 页面配置

### 查询条件

- 筛选条件（单文本框）
- 勾选项：显示停用
- 注：本页无"显示层次结构"勾选项（与费用类型不同，截图确认）
- JSON filterLabels 4 个"更多"占位对应查询配置区折叠字段，待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增收入、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据）

操作、科目编号、科目名称、核算项

> JSON columns 共 5 项，首项"操作 科目编号 科目名称 核算项"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。与费用类型（同 4 列）完全一致。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 其他收入类型即收入类损益科目：档案直接使用标准会计科目编码（截图实据 6101 公允价值变动损益、6111 投资收益、6301 营业外收入、6902 利息收入），收入单据按收入类型归集计入对应科目
- 与费用类型对称：费用类型承载支出类损益科目（6403/6601/6602/6603/6701/6711/6801/6901），本页承载收入类损益科目（6101/6111/6301/6902），两页列结构完全一致
- 核算项：收入的辅助核算维度（本页该列数据为空，配置待复核）
- 停用优先：与"显示停用"勾选项配套
- 层级：无"显示层次结构"勾选项（费用类型有），本页应为扁平科目列表（截图实据行首均为文档图标、无文件夹节点，待复核确认不支持子类型）
- 与其他页面关系：会计科目（收入类型科目来源于损益类）、其他收入单（财务域 QTSRD- 单号，按收入类型归集并生成凭证，档案→单据关系）、银行账户（收入收款资金账户去向）、利润表（收入类科目发生额汇入相应项目，待复核）
