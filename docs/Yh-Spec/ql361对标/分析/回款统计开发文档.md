> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页）：回款按职员/部门归集（收款+预收款+预订货收款三口径加总回款总金额，行级明细钻取）；销售回款考核与提成取数页。菜单路径：分析 → 提成分析 → 回款统计。
- 页面结构：维度 Tab（按职员/按部门）+ 查询区（两行）+ 回款归集表格（操作列"明细"链接、金额下划线可钻取）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__提成分析__回款统计.png`

## 4. 业务规范

### 统计口径（三口径回款）

- **回款总金额 = 收款金额 + 预收款金额 + 预订货收款金额**（逐行成立：141,062.72+20,959.23+0=162,021.95 ✅；合计 157,878.59+23,459.71+0=181,338.3 ✅）
- **收款金额**：收款单（SKD-）实收；**预收款金额**：预收款单（YSKD-）新增预收（可为负=预收抵扣/退回，实据 HC017 王昶元 -172.12）；**预订货收款金额**：预订货单（YDHD-）预订金
- **单量**：回款关联单据张数
- **日期类型**：单据日期（默认）/其他日期口径（可选值待复核）

### 与其他页面关系

- 取数：收款单/预收款单/预订货单（经营历程流水，经手人归属）
- 上游：《销售业绩》（回款总额=本页回款总金额同口径：销售业绩本周 180,142.52 vs 本页 181,338.3，统计时点/口径微差待复核）
- 下游：《业务员提成》（回款提成取数）、《业绩提成中心》（月度结算）
