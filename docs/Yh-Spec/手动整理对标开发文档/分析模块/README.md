## 3. 域级说明

- **取数主线**：分析域的取数全部来自业务单据与账务——
  - 综合单据 ← 全业务域单据（`DocQueryController/DocQueryService`）
  - 采销分析 ← 销售订单/出库/退货、收款/收款核销、采购订单/入库/退货、外勤拜访、商城分享
  - 仓配分析 ← `erp_stock` 实时库存 + 出入库流水 + 批次
  - 提成分析 ← 业绩（单据）× 提成方案
  - 财务分析 ← 会计凭证科目余额（账簿口径）
  - 营销分析 ← 营销模块的活动配置 + 商城订单/客户
- **口径要点**：
  - 待审批/草稿/经营历程 = 单据**过账状态**的三个视图（审批中 / 未过账草稿 / 已过账流水，经营历程支持红冲）。
  - 库存查询三口径：**可用 / 账面 / 在途**；库存分布为**透视视图**（列随仓库动态生成）。
  - 进销存分析 = 期初 + 五类入库 − 五类出库 = 期末（多级表头）。
  - 应收/应付 = **滚动账**（期初 + 本期发生 − 已结 − 优惠 = 期末），行级可收款/付款/对账。
  - 回款 = 收款 + 预收 + 预订货收款三口径（实测恒等式逐行成立）。
  - 提成 = **方案驱动 + 算后才出数**（`业务员提成` 打开为待计算空态）。
- **上下游**：
  - 营销模块（配置活动）→ 分析 → 营销分析（看效果）；
  - 采购模块（智能补货/缺货补货 70051-70054）↔ 分析 → 采购准备（策略 + 一键生成采购单）；
  - 销售模块 → 采销分析；仓储模块 → 仓配分析；财务模块（凭证/账簿）→ 财务分析。

## 5. 写作与开发原则

- **不重复通用规范**：统一指向《对标开发技术参考文档》。
