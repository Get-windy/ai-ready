## 1. 页面概述

- **账表页**（税务台账）：按月销项/进项发票台账与抵扣后应交税额（正数/负数发票分列，税务口径）；增值税进销项与应交税额统计页。菜单路径：分析 → 财务分析 → 发票统计。
- 页面结构：查询区（一行，按月份区间查询）+ 多级表头表格（年度 | 月份 | 抵扣后应交税额 | 销项开票组 | 取得进项专票组）+ 底部分页。
- 页面截图：`tool-results/ql361/pages/分析__财务分析__发票统计.png`

## 3. 数据表格列配置

### 默认显示列（3 个固定列 + 2 个分组表头 + 组内 10 项，归位后 17 个叶子列，抓取 JSON columns 实据）

- 固定列：年度、月份、抵扣后应交税额
- **销项开票**：正数发票张数、正数开票金额、负数发票张数、负数开票金额、销项开票金额、销项价税合计、销项税额
- **取得进项专票**：正数发票张数、正数开票金额、负数发票张数、负数开票金额、进项开票金额、进项价税合计、进项税额

> JSON columns 共 16 项，首项"年度 月份 抵扣后应交税额"为抓取拼接串剔除；余 15 项中"销项开票/取得进项专票"为**分组表头**，进项组 4 个与销项组同名列（正数发票张数/正数开票金额/负数发票张数/负数开票金额）JSON 未重复列出，按截图归位后叶子数据列 17 个（3 固定 + 销项 7 + 进项 7）。

## 4. 业务规范

### 统计口径（增值税进销项）

- **销项开票**：销售发票（蓝字=正数，红冲=负数）；销项开票金额=正数−负数净额；销项价税合计=金额+税额；销项税额按税率拆分
- **取得进项专票**：供应商专用发票（认证抵扣口径）；同样正/负数分列
- **抵扣后应交税额**=销项税额−进项税额（留抵为负）
- **按月查询**：税务申报月度口径（与纳税期一致）

### 与其他页面关系

- 取数：销售发票（销项）+ 采购进项发票（进项）；发票模块单据
- 同源页：财务域发票管理（开票动作端）；《经营分析》（税前利润口径）
