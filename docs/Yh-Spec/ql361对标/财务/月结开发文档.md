# 月结开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/month-closing`（功能页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **功能页**：会计期间结账/反结账操作（无查询区、无表单录入；期间状态表格 + 月结/批量月结/反月结三个操作按钮）。菜单路径：财务 → 账务处理 → 月结。
- **数据实据**：期间表格按会计期间倒序列出（2026年7月 → 2024年12月），分页 第(1/3)页 / 共 46 条记录 / 每页显示 20 行；会计月期间=自然月（开始日期=月首、结束日期=月末，含 2 月 28 日）；仅最新期间（2026年7月）为"未结账"，历史期间全部"已结账"。

## 2. 页面配置

### 查询条件

无（功能页无查询区；JSON filterLabels 为空实据）

### 功能按钮

按抓取 JSON buttons 实据：月结、批量月结、反月结、跳转（分页跳转）

按钮语义（实据归纳）：
- 月结：对选中的单个未结账期间执行结账
- 批量月结：对多个连续未结账期间一次性顺序结账
- 反月结：对已结账期间执行反结账（解锁，通常需从最新已结期间逐月往回）

## 3. 数据表格列配置

会计年、会计月、开始日期、结束日期、状态

### 状态值域（截图实据）

未结账、已结账

## 4. 业务规范

### 状态流转与特殊交互

- 期间主线：每个自然月为一个会计期间；当前期间"未结账"可正常记账 → 月结后"已结账"锁定 → 需要调整时反月结解锁
- 结账约束（通行规则 + 实据归纳，具体校验项待复核）：
  - 顺序结账：只能从最早未结账期间起顺序结账（批量月结即连续多期间顺序执行）
  - 结账后该期间内的单据/凭证不可新增、修改、删除（锁定）；报表按已结账期间出具
  - 反月结通常要求从最新已结账期间逐月往回，且需权限控制
- 与损益结转的关联（待复核）：资产负债表实据显示当月（2026-07 未结账）资产合计 3,485,946.89 ≠ 负债和所有者权益总计 3,427,055.89，而年初两侧相等（3,155,208.61）；推测月结时执行损益类科目结转至本年利润/未分配利润，未月结期间差额=本期损益未结转部分，口径待复核

### 与其他页面关系

- 约束对象：《会计凭证开发文档》（已结账期间不可记账/改凭证）及全部业务单据的记账日期
- 下游报表：《总账开发文档》《科目余额表开发文档》《资产负债表开发文档》《利润表开发文档》按会计月取数
- 本系统前端目录 `finance/month-closing`（dynamicRoutes.ts 实据）
