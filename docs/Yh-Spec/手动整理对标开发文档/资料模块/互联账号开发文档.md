## 数据模型（本系统）

### `erp_linked_account`（迁移 `V11.153.0__Create_Linked_Account_Module.sql`）

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | BIGINT PK | 雪花 ID（`ASSIGN_ID`，与资料模块其它档案一致） |
| `tenant_id` | BIGINT NOT NULL DEFAULT 0 | 多租户隔离（拦截器自动注入） |
| `party_id` | BIGINT | 往来单位 ID（`biz_party.id`） |
| `party_code` / `party_name` | VARCHAR | 往来单位编号 / 名称（**绑定快照**，列表直接渲染，避免逐行回查） |
| `platform` | VARCHAR(32) NOT NULL DEFAULT 'OTHER' | 互联平台标识（全局唯一字典） |
| `link_type` | VARCHAR(32) NOT NULL DEFAULT 'MEMBER' | 关联类型标识（全局唯一字典） |
| `linked_user_name` | VARCHAR(128) | 互联用户名 |
| `phone` | VARCHAR(32) | 手机号 |
| `status` | SMALLINT NOT NULL DEFAULT 1 | 1 已绑定 / 0 已解绑 |
| `remark` | VARCHAR(500) | 备注 |
| `deleted` + 审计四件套 | — | 逻辑删除 + `create_by/create_time/update_by/update_time` |

**唯一约束**：`uk_ela_platform_account (tenant_id, platform, linked_user_name) WHERE deleted = 0 AND linked_user_name IS NOT NULL`
→ 同一租户下「同平台 + 同互联用户名」不可重复绑定（实测：重复绑定返回 400/空数据）。

**红线口径（P0）**：本表为互联账号**唯一**主数据来源，营销 / 会员 / 商城互联统一引用，
严禁另建重复互联账号表；平台与关联类型字典由 `/dict` 单点提供。

## 后端接口（`LinkedAccountController`，`/api/erp/md/linked-account`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/page` | 分页（`partyId` / `keyword` / `platform` / `linkType` / `status` / `pageNum` / `pageSize`） |
| GET | `/list` | 不分页列表（`partyId` / `keyword` / `platform` / `status`，供营销/会员/商城引用同一口径） |
| GET | `/dict` | 字典：`platforms`（微信/支付宝/抖音/商城/其它）+ `linkTypes`（会员/客户/其它） |
| GET | `/{id}` | 详情 |
| POST | `/` | 绑定（新增）；`partyName/partyCode` 缺省时自动从 `biz_party` 回填 |
| PUT | `/{id}` | 修改 |
| PUT | `/{id}/status?status=0\|1` | 解绑 / 重新绑定（状态切换） |
| PUT | `/batch-status` | 批量解绑 / 批量绑定 |
| DELETE | `/{id}` | 删除（逻辑删除） |
| DELETE | `/batch` | 批量删除 |
| GET | `/export` | 真实 Excel（POI，与分页同一过滤口径，列为 往来单位/互联用户名/手机号） |

**查询口径**：`keyword` 同时匹配 `phone` 与 `linked_user_name`（对标占位「请输入互联手机号码」）；
列表默认 `status=1`（只显示「已绑定」），解绑后的记录（`status=0`）从列表消失，供下游按状态引用（`/list?status=0` 可单独取）。

**校验口径**：往来单位必须真实存在；互联用户名 / 手机号必填；字段长度对齐 DB 列宽（128 / 32 / 500）。

## 前端实现

| 文件 | 说明 |
|------|------|
| `views/md/linked-account/index.vue` | 列表页（资料模块布局 = `CategoryListLayout` 关分类树 + `BillTableList`） |
| `api/erp/linkedAccount.ts` | 互联账号 API |

**关键实现点**
- 列配置走 `BillTableList` 表头齿轮（`storage-key="md-linked-account-columns"`，个人 / 全局配置），**不另建配置入口**。
- 空表占位行（`record.__ghost`）不渲染行内「解绑 / 删除」，与对标空表一致。
- 查询区「往来单位」为**字段框 + 放大镜**（复刻对标的 `dijitSearchBox` 形态），选中后回填名称并可一键清除。
- 打印走 F8 快捷键 + `window.print()`（与同模块其它资料页一致）。
- 「往来单位选择」弹窗的 编号 / 名称 列带排序（对标表头 ↕）；选中分类节点（显示层次结构下的分类行）会提示「分类节点不能作为往来单位绑定」。
- 翻页 / 单条解绑 / 单条删除后清空勾选，避免「批量解绑、批量删除」作用到已不在当前页或已删除的行。
- 导出文件名用本机日期（`toISOString()` 是 UTC，东八区晚间会差一天）。

**入参校验与错误可读性（2026-09-12 补强，9 项断言）**：

| 场景 | 返回文案 |
|------|---------|
| 同平台同互联用户名重复绑定 | 该互联平台下互联用户名「X」已绑定到「客户甲」 |
| 往来单位不存在/已删除 | 往来单位不存在或已被删除，请重新选择 |
| 缺互联用户名 / 手机号 | 请输入互联用户名 / 请输入手机号 |
| 超长字段（>128） | 互联用户名不能超过 128 个字符 |
| 修改不存在的记录 | 互联账号不存在或已删除 |
| 自身更新（同平台同用户名） | 不误判为冲突 |
| 并发下唯一索引兜底 | 捕获 `DataIntegrityViolationException` → 转「已被绑定」可读文案 |

> 实现要点：唯一约束**前置校验**给出可读原因，不再依赖 DB 唯一索引抛出的通用 400「请求数据不完整或存在冲突」。
> 前端错误提示统一取 `error.response.data.message || error.message`（响应拦截器对 `code !== 200` 以 `new Error(msg)` 拒绝，
> 只取 `response.data.message` 会丢失后端文案）。

- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
