# 合同开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`crm/contract/index`（列表）+ `crm/contract/form`（表单）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=添加）：主按钮 → 列表页 `crm/contract/index`；标签"添加"→ 新增/编辑表单页 `crm/contract/form`。
- **列表页**：合同台账（我方实现，views/crm/contract/index.vue）。
- **表单页**：CRM 合同——商机成交后签订合同（我方实现，views/crm/contract/form.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `crm/contract/index.vue`（5 项）

- `contractNo` 合同编号（输入）
- `contractName` 合同名称（输入）
- `customerName` 客户名称（输入）
- `contractType` 合同类型（下拉：销售合同/采购合同/服务合同/租赁合同）
- `status` 状态（下拉：草稿/待审批/已审批/待签署/已签署/生效中/已完成/已终止）

### 功能按钮

来源：我方源码 `crm/contract/index.vue`

- 工具栏：新增（Ctrl+N）、刷新（F5）、批量审批（选中行）
- 行操作：查看、编辑、审批、续签申请、终止合同、删除

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段（21 个）

来源：我方源码 `crm/contract/form.vue`

- 必填：合同编号\*（contractNo）、合同名称\*（contractName）、客户名称\*（customerName）、合同金额\*（contractAmount）、开始日期\*（startDate）、结束日期\*（endDate）
- 选填：关联商机、联系人、合同类型、签订日期、已收金额、待收金额（disabled 自动）、币种、结算方式、付款条款、交付条款、质保条款、服务条款、负责人、状态、备注

### 字段分组／录单默认值／打印设置

- 字段分组：单块基本信息（BillFormPage basic-info，无底部 Tab；底部按钮：保存 Ctrl+S / 提交 Ctrl+Enter）
- 录单默认值：币种默认"人民币"(CNY)（select 首项）；其余字段无显式默认值
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（10 列，来源：我方源码 `crm/contract/index.vue`）

合同编号、合同名称、客户名称、合同类型、合同金额、开始日期、结束日期、状态、创建时间、操作

### 全部可配置列（10 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `vxeColumns` 数组（10 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`crm/contract/index`，标签按钮 list_path=`crm/contract/form`，tag_label=添加（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- CRM 合同：商机成交后签订合同（商机见《商机开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
