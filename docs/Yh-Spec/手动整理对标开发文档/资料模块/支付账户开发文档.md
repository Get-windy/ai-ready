## 页面概述

支付账户用于维护/查看**财务资金账户**（银行账户/现金/内部/外部）的账户信息与余额，统计账户状态，并支持账户增删改、启停与余额调整。单入口。

| 页面 | 地址 | 说明 |
|------|------|------|
| 支付账户 | `md/payment-account` | 统计卡片（后端）+ 账户列表 + 新增/修改/删除/余额调整/启停 + 导出真实 xlsx |

菜单（本系统）：资料 → 支付管理 → 支付账户。

### 配置功能说明

- **统计卡片**：账户总数 / 启用账户 / 停用账户 / 余额合计 —— **走后端 `GET /statistics`**（与列表同口径过滤），不再前端本地汇总。
- **列配置弹窗**：数据表表头齿轮（个人配置 / 全局配置，`storage-key = md-payment-account-columns`）。
- **页面配置弹窗**：查询条件（5 项，可勾选/拖拽排序）+ 功能按钮（新增账户/页面配置/刷新/打印(F8)/导出，可开关）；隐藏「打印配置」Tab。
- **工具栏**：新增账户 ｜ 页面配置 · 刷新 · 打印(F8) · 导出。
- **查询区**：筛选条件 / 账户类型 / 账户等级 / 状态（默认「全部」，即同时返回停用数据）/ 币种（默认隐藏）+ 查询 + 重置。
- **行内操作**：修改 / 余额调整 / 启用·停用 / 删除。
- **真实闭环**：新增默认 `next-code` 建议账户编号并可登记期初余额；导出为后端真实 xlsx；打印(F8) 渲染真实数据打印页。

## 业务规范说明

- **账户类型**：1 银行 / 2 现金 / 3 内部 / 4 外部；**账户等级**：1 基本 / 2 一般 / 3 专用；**状态**：1 启用 / 0 停用。
- **数据源（红线·单一口径）**：`finance_account` 表，**严禁另建重复资金账户表**；与《银行账户》（`md/bank-account`）同源，增删改/启停/编号建议**共用同一后端 Service**（`BankAccountService`），本页只做「支付账户」视图的接口编排。
- **分页查询**：`GET /page`（`pageNum/pageSize/keyword/accountType/accountLevel/status/currency/showDisabled/showTree`）；不传 `status` 且不传 `showDisabled` 时**仅返回启用账户**（与《银行账户》口径一致）；「状态=全部」由前端显式传 `showDisabled=1`。
- **余额**：`balance` 默认 0，`currency` 默认 CNY；`PUT /balance/{accountId}`（body BigDecimal）为**增量口径**——正数增加、负数减少（UI 标题「余额调整」，实时预览调整后余额）。
- **状态切换**：行内启用/停用走 `PUT /status/{id}`（body 为裸状态数字 0/1）。
- **统计卡片**：走后端 `GET /statistics`（支持与列表同口径过滤），返回 `total/enabled/disabled/totalBalance`。
- **删除保护**：系统预置账户（`is_system=1` 或科目 1001/1002）、存在下级账户、余额不为 0 的账户**禁止删除**（后端校验并返回明确文案）。
- **编号建议**：`GET /next-code`；顶级从 1001 起取空闲四位号，子账户 = 父编号 + 两位序号。
- **兼容口径**：`GET /list`（不分页）被全平台账户下拉复用（提存现 / 费用单 / 收付款 / `options.ts`），签名与行为保持不变。
