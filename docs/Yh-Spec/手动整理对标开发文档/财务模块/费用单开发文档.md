# 费用单开发文档

> **文档类型：** 页面对标复刻（已完成代码）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按金标准结构编写；非主营支出（费用）登记（与其他收入单对称）。**双入口 + 列表页双 Tab（按单据/按明细）+ 表单页费用项明细表**。字段数据来源：对标系统实测抓取（Playwright MCP，2026-09-07）。

## 页面概述

费用单用于**非主营支出的费用登记**（往来单位费用/内部费用两类）。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 费用单表单页 | `finance/expense-doc/form`（主菜单入口） | 新增费用 + 费用项明细 |
| 费用单列表页（历史） | `finance/expense-doc/index` | 双入口「历史」标签，列表**双 Tab**：按单据 / 按明细 |

单号实据：`YBFYD-20260723-001`（`YBFYD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明（每个页面都有）
- **页面配置/列配置**：管理页面级字段(查询条件/功能按钮)与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区域「配置」齿轮，列配置在数据表右上角表头单元格内齿轮图标。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转；支持上移/下移/恢复默认/保存。
- 表单页配置弹窗：**页面配置 / 打印设置** 两 Tab（页面配置=字段显隐；打印设置=「始终使用最后一次打印的模板，打印时不再选择」「记账后立即打印」两个勾选项）。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级金标准组件**（列表仍为 `SearchBar`+`BillTableList`，表单为自定义 `a-form`），见「实现差异说明 → 待完善」。

## 新增编辑费用单表单页配置

### 页面结构（自定义 `a-form`，`useBillForm` 协作）

费用类型单选（往来单位费用/内部费用）→ 表头字段区 → 费用项明细表格（操作/费用编号/费用名称/金额/备注）→ 备注区（单据备注/制单人/制单时间/打印次数）→ 底部本单金额与操作（保存草稿/记账）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 入账单一口径（红线）**：费用记账必须走凭证（KJPZ-）入总账/明细账，**严禁直接改费用/往来余额**；费用项明细必须有映射科目。
- **P1 费用类型**：往来单位费用须带核算项（往来单位），内部费用归部门/科目。
- **P1 预算联动**：费用/支出记账回写《预算执行》，纳入预算控制。
- **P2 验收**：无桩/无模拟；列表列/配置对齐金标准（按单据 27 列/按明细 19 列/费用项明细 5 列）；凭证、往来联动、预算回写需真实数据闭环验证。

## 开发原则（通用）

- **页面组件优先复用**：优先使用已有页面组件，确无对应才开发通用组件。
- **功能/模块不重复开发**：已开发过的功能/单据/通用能力全系统只实现一次，其它模块直接复用。
- **阶段结束前回写开发文档**：每阶段结束前更新文档「已完成」与「待完善」，反映当前代码实际实现。
