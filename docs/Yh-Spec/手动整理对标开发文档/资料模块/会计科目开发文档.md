## 业务规范说明

- **真实科目枚举**：`subjectType` 1 资产 / 2 负债 / 3 权益 / 4 成本 / 5 损益；`direction` 1 借 / 2 贷；`level` 1-4；`isEnabled` 布尔。
- **真实 API**：`AccountSubjectController` `GET /list`、`GET /tree`、`GET /{id}`、`GET /type/{subjectType}`、`POST`、`PUT /{id}`、`DELETE /{id}`、`PUT /{id}/enable`、`DELETE /batch`、`GET /export`（**无 `/page` 分页**，树形 `/tree`）。
- **⭐ 占位缺口**：本桩页建平铺分页 + 上级科目，与真实树形结构（`/tree`、**无 parentCode 顶层列**）不一致，需对齐为树形渲染。
- **前端口径**：真实前端 `accountSubjectApi`（`api/finance/index.ts`：getTree `/erp/finance/subject/tree`、getList、getByType、create、update、delete、toggleEnabled）。
- **科目用途**：会计凭证记账后入总账/明细账/科目余额表，按科目（含核算项）汇总。
- **对标口径**：ql361 会计科目为**科目树**（科目分类：全部/资产类/负债类/所有者权益类/损益类；数据树顶 1资产类/2负债类/4所有者权益类/6损益类），列 科目编号/科目名称/核算项，编辑打开「会计科目」完整编辑器（含借/贷余额方向）。
