# 商品价格管理开发文档

> **文档类型：** 页面对标复刻（⚠️ **本系统当前为占位桩页**，后端未接入；对标为多Tab组合页）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 商品价格管理为**多Tab组合页**（4 个子标签），用于商品的批量调价与价格等级/客户级别折扣维护。

## 页面概述

商品价格管理用于查看与维护**商品价格**（8 个价格等级 + 客户级别折扣/指定价）。对标系统为**多Tab组合页**，含 4 个子标签：**商品价格批量修改**（默认）、**客户级别折扣设置**、**级别指定价设置**、**客户指定价设置**。单入口仅读（无表单页）。

| 子标签 | 说明 |
|--------|------|
| 商品价格批量修改 | 商品筛选（分类树）+ 8 价格等级列 + 批量修改（默认激活） |
| 客户级别折扣设置 | 客户级别 → 级别默认价 维护（简单网格） |
| 级别指定价设置 | 按「客户级别」指定商品/分类价格规则（查询 + 数据表） |
| 客户指定价设置 | 按「客户」指定商品/分类价格规则（查询 + 数据表） |

菜单：资料 → 商品管理 → 商品价格管理。

> ⚠️ **本系统当前实现说明**：本页前端直连 `/md/product-price/page`，后端无对应 Controller（404），为占位桩页（6 列：产品编码/产品名称/零售价/批发价/成本价/生效日期）。对标结构的 4 子标签有待对齐（或按裁决收敛）。

## 业务规范说明

- **价格口径**：商品多价（零售/批发/成本 + 8 个价格等级：食堂团餐/外围餐饮店/餐饮店/大团餐/重点vip01/连锁vip/特价客户/自助vip）溯源 `erp_product` / `erp_product_grade`。
- **⭐ 占位缺口**：本系统 `/md/product-price/page` 后端未实现；对标为 4 子标签（批量修改 + 客户级别折扣 + 级别指定价 + 客户指定价）。真实价格维护已由《商品》（`form.vue` 单位明细等级价）与《批量改价》（`price-batch.vue`）承载，本页为冗余占位。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 价格单一口径（红线）**：本页商品价格为全局基础数据，销售/采购统一引用，**严禁另建重复价格表**；价格维护收敛《商品 → 批量改价》（`/erp/product/price-batch`）。
- **P1 关联一致性**：价格变更后实时反映到销售/采购单选价与业务单，保证前后端口径一致（零售/批发/成本/等级价 + 生效期）。
- **P2 验收**：无桩/无模拟；收敛或补 `/api/erp/md/product-price/page` 聚合 `erp_product_grade`，与商品/批量改价数据一致。
