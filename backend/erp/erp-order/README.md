# ERP Order 模块

## 模块职责

**erp-order** 是系统的**订单中心模块**，负责统一管理采购订单和销售订单的查询、统计和报表功能。

### 核心定位

本模块不是独立的业务模块，而是作为**订单统一入口**，提供：

1. **订单统一查询** - 聚合采购订单和销售订单的查询接口
2. **订单统计分析** - 提供订单相关的统计报表
3. **订单数据导出** - 支持订单数据的导出功能

### 与其他模块的关系

| 模块 | 关系 | 说明 |
|------|------|------|
| **purchase** | 数据来源 | 采购订单数据来源于purchase模块 |
| **sales/pricing** | 数据来源 | 销售订单数据来源于sales模块 |
| **erp-order** | 聚合展示 | 本模块聚合展示两类订单数据 |

### API 接口

| 接口 | 说明 |
|------|------|
| `/api/erp/purchase-orders/page` | 分页查询采购订单 |
| `/api/erp/purchase-orders/{id}` | 获取采购订单详情 |
| `/api/erp/purchase-orders/statistics` | 获取采购统计信息 |
| `/api/erp/purchase-orders/report` | 生成采购报表 |
| `/api/erp/purchase-orders/export` | 导出采购数据 |

### 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 订单中心 | `/order-center` | 统一订单查询和统计 |

### 设计原则

1. **数据聚合** - 本模块不创建订单，只聚合展示其他模块的订单数据
2. **统一入口** - 为用户提供统一的订单查询入口，避免在多个模块间切换
3. **统计分析** - 提供跨采购和销售的统计分析功能
