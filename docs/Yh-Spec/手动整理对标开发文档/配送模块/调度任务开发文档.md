# 调度任务开发文档

> **对标状态：⚠️ 无对标**——ql361 无「配送」一级菜单，无此页面；本页为本系统实现的**配送调度工作台**，按本系统 + 业界标准（即时配送 TMS）建模。
> 本系统菜单：**配送 → 调度管理 → 调度任务**（菜单ID `80730`，menu_code `dms:dispatch-task`）
> 路由：`dms/dispatch-task` ｜ 组件：`views/dms/dispatch-task/index.vue` ｜ 接口：`/api/dms/task/*`、`/api/dms/dispatch/*`
> 关联文档：《配送单开发文档》（任务的单据形态）、《配送查询开发文档》（台账）、《实时跟踪开发文档》。
> 通用规范见《对标开发技术参考文档》第 4、5 章。

## 1. 页面概述

- **调度工作台（列表操作页）**：对配送任务（`DmsTask`）执行**指派 / 改派 / 取消 / 异常标记 / 查看轨迹**，并支持一键**自动调度**待分配任务。
- 页面标题「调度任务」，数据源与《配送查询》《配送单》同源（`DmsTask`），但视角为**调度视角**（骑手维度）。

## 2. 页面结构（现状实测）

### 2.1 查询条件

| 查询条件 | 控件 | 说明 |
|---------|------|------|
| 订单号 | 输入框 | 关联订单号 |
| 状态 | 下拉 | 9 态（见 §4） |
| 骑手ID | 输入框 | ⚠️ 手输 ID，应改为骑手选择器 |

### 2.2 工具栏

- **自动调度**（页面右上，`header-extra`）：二次确认「对所有待分配任务执行自动调度？」→ 调调度服务。
- 导出（组件内置）。

### 2.3 数据表格列（11 列）

任务编号、订单号、类型、客户、骑手ID、数量、货品金额、优先级、状态、创建时间、操作。

- **类型**：1 销售配送 / 2 调拨 / 3 退货（标签色）。
- **优先级**：1 普通 / 2 紧急 / 3 加急（标签色）。
- **骑手ID** ⚠️ 显示 ID 而非姓名，应改骑手姓名。

### 2.4 行级操作

| 操作 | 显示条件 | 说明 |
|------|---------|------|
| 指派 | `status = 0`（待分配） | 打开「指派骑手」弹窗 |
| 改派 | `status ∈ {1,2}`（已分配/已接单） | 打开「改派骑手」弹窗（显示当前骑手） |
| 取消 | `status ∈ {0,1}` | 二次确认 → 取消任务 |
| 轨迹 | 有 `riderId` 且 `status ∈ {2,3,4}` | 跳转实时跟踪（`goTracking`） |
| 异常 | `status ∈ {2,3,4,5}` | 二次确认 → 标记异常 |

### 2.5 指派/改派弹窗

- 标题随模式切换：`指派骑手` / `改派骑手`。
- 头部信息：任务单号 + 订单号（改派时附当前骑手ID）。
- **候选骑手列表**（单选 radio，列：骑手ID、姓名、电话、评分、累计单量、车牌），未选骑手时「确定」禁用。

## 3. 业务规范

- **调度方式**（后端 `DispatchTypeEnum`）：1 自动 / 2 手动 / 3 抢单 / 4 竞价——手工指派属「手动」，工具栏「自动调度」属「自动」。
- **指派规则**：候选骑手应结合**在线状态、当前负载、评分、车辆**排序（现状为直接列表，排序/筛选规则待补）。
- **与订单池的关系**：待分配任务同时可从「订单池」（`DmsOrderPool` + `DmsBid`）以抢单/竞价方式消化；本页为**管理员指派视角**。
- **与司机端联动**：指派后任务进入骑手端（`frontend/apps/driver-delivery`），骑手接单 → 取货 → 配送 → 签收，状态回写。
- **异常处理**：标记异常后需人工介入（重新指派/取消），异常任务进入统计。

## 4. 状态与枚举（与后端一致）

| status | 含义 | 可执行操作 |
|:---:|------|-----------|
| 0 | 待分配 | 指派 / 取消 |
| 1 | 已分配 | 改派 / 取消 |
| 2 | 已接单 | 改派 / 轨迹 / 异常 |
| 3 | 取货中 | 轨迹 / 异常 |
| 4 | 配送中 | 轨迹 / 异常 |
| 5 | 已签收 | 异常 |
| 6 | 已完成 | — |
| 7 | 已取消 | — |
| 8 | 异常 | — |

> 对外台账（《配送查询》）需映射为「待配送 / 配送中 / 已配送」三值。

## 5. 实现差异说明（本系统现状）

| 项 | 现状 | 差距 |
|----|------|------|
| 页面骨架 | `ARReportPage` | 换 `CategoryListLayout` + `BillTableList` + 双配置弹窗 |
| 列 | 11 列，骑手显示 ID | 骑手姓名/电话、收货地址、预计送达、配送费、代收货款等 |
| 查询 | 3 项（含手输 ID） | 补客户、骑手选择器、配送日期、线路、优先级、状态多选 |
| 功能按钮 | 自动调度 + 导出 | 补批量指派、批量取消、刷新、打印(F8)、导出真实 xlsx |
| 指派弹窗 | 候选列表 + 单选 | 补筛选（在线/负载/车辆）、地图可视、一个骑手负载上限校验 |
| 自动调度 | 一键全量 | 补策略配置（按区域/负载/评分）、调度结果反馈 |
| 分页 | 组件内置 | 对齐经典分页栏 |
| 轨迹跳转 | `goTracking` | 与《实时跟踪》联动的参数与回跳需校验 |
