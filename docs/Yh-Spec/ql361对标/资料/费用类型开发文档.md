> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/expense/*`（费用模块，独立类型页对应关系待复核）

## 1. 页面概述

- **列表页**：费用类型（损益类费用科目）主数据维护页，查询区 + 数据表格，单一列表视图，支持层级。
- 截图：![费用类型](../../../../tool-results/ql361/pages/资料__财务账户__费用类型.png)

## 2. 页面配置

### 查询条件

- 筛选条件（单文本框）
- 勾选项：显示停用、显示层次结构（默认勾选）
- JSON filterLabels 8 个"更多"占位对应查询配置区折叠字段，待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增费用、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据）

操作、科目编号、科目名称、核算项

> JSON columns 首项"操作 科目编号 科目名称 核算项"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 费用类型即损益类科目：档案直接使用标准会计科目编码（6403 税金及附加、6601 销售费用、6602 管理费用、6603 财务费用、6701 资产减值损失、6711 营业外支出、6801 所得税费用、6901 以前年度损益调整），费用单据按费用类型归集计入对应科目
- 核算项：费用的辅助核算维度（本页该列数据为空，配置待复核）
- 层级结构：行首文件夹图标 + "显示层次结构"默认勾选，费用类型支持在科目下挂子类型（推断，待复核）
- 停用优先：与"显示停用"勾选项配套
- 与其他页面关系：会计科目（来源损益类科目）、费用单/其他支出（按费用类型归集生成凭证）、银行账户（资金账户来源）、销售订单/出库单"其他费用"（单据级费用项对应关系待复核）
