## 安全风险分析

### 1.1 风险分类

| 风险类别 | 风险描述 | 风险等级 | 影响范围 |
|----------|----------|----------|----------|
| **注入攻击** | SQL注入、命令注入、LDAP注入 | 🔴 高危 | 数据库、服务器 |
| **XSS攻击** | 存储型、反射型、DOM型XSS | 🔴 高危 | 用户浏览器 |
| **认证缺陷** | 暴力破解、会话劫持、弱密码 | 🔴 高危 | 用户账户 |
| **授权缺陷** | 垂直越权、水平越权 | 🔴 高危 | 数据访问 |
| **敏感信息泄露** | 错误信息、日志泄露 | 🟡 中危 | 系统信息 |
| **CSRF攻击** | 跨站请求伪造 | 🟡 中危 | 用户操作 |
| **安全配置错误** | 默认配置、不安全的HTTP头 | 🟡 中危 | 系统安全 |
| **业务逻辑漏洞** | 价格篡改、数量篡改 | 🔴 高危 | 业务数据 |

### 1.2 风险矩阵

```
风险影响程度 vs 发生概率:

                    发生概率
            低        中        高
         ┌─────────┬─────────┬─────────┐
    高   │  中危   │  高危   │  高危   │  注入攻击
影       │ XSS(反射)│ 认证缺陷 │ 越权访问 │
响       ├─────────┼─────────┼─────────┤
程   中  │  低危   │  中危   │  高危   │  敏感信息泄露
度       │ CSRF    │ 配置错误 │ 业务逻辑 │
         ├─────────┼─────────┼─────────┤
    低   │  低危   │  低危   │  中危   │  信息泄露
         │         │         │ 日志泄露 │
         └─────────┴─────────┴─────────┘
```

## 身份认证测试用例

### 2.1 登录安全测试

#### TC-SEC-AUTH-001: 暴力破解防护测试

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-SEC-AUTH-001 |
| **测试项** | 暴力破解防护 |
| **优先级** | P0 |
| **测试类型** | 安全测试 |

**测试目的**: 验证系统能够有效防护暴力破解攻击

**前置条件**:
- 测试用户testuser已注册
- 系统已配置防暴力破解机制

**测试步骤**:
1. 使用错误密码连续登录5次
2. 第6次使用正确密码尝试登录
3. 观察系统响应
4. 检查账户锁定状态

**预期结果**:
- 第5次失败后，账号被临时锁定
- 第6次登录返回"账号已被锁定"提示
- 锁定时间符合配置（如30分钟）
- 安全日志记录锁定事件

**测试数据**:
```
用户名: testuser
错误密码: WrongPassword{1-5}
正确密码: CorrectPass123
```

| **优先级** | P0 |
| **测试类型** | 安全测试 |

**测试目的**: 验证密码不以明文形式存储

**测试步骤**:
1. 创建测试用户，设置密码为"Test@123456"
2. 直接查询数据库用户表
3. 检查password字段值
4. 尝试解密/破解

**预期结果**:
- 数据库中密码字段为哈希值（如BCrypt）
- 哈希值长度符合算法特征（如BCrypt为60字符）
- 相同密码的哈希值不同（含盐）
- 无法从哈希值反推出原始密码

| **用例ID** | TC-SEC-SESS-001 |
| **测试项** | Token过期处理 |
| **优先级** | P0 |
| **测试类型** | 安全测试 |

**测试步骤**:
1. 用户登录获取Token
2. 等待Token过期（或修改系统时间）
3. 使用过期Token访问受保护接口

**预期结果**:
- 返回401 Unauthorized
- 错误码：TOKEN_EXPIRED
- 提示信息："Token已过期，请重新登录"
- 不返回任何业务数据

| **测试类型** | 安全测试 |

**测试步骤**:
1. 用户登录获取Token
2. 使用Token访问接口（成功）

### 3.1 垂直越权防护测试

#### TC-SEC-AUTHZ-001: 普通用户访问管理员接口

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-SEC-AUTHZ-001 |
| **测试项** | 垂直越权-普通用户访问管理员接口 |
| **优先级** | P0 |
| **测试类型** | 安全测试 |

**测试目的**: 验证低权限用户无法访问高权限接口

**测试步骤**:
1. 使用普通用户账号登录，获取Token
2. 尝试访问管理员专属接口：
   - GET /api/v1/admin/users
   - POST /api/v1/admin/system/config
   - DELETE /api/v1/admin/users/{id}
3. 观察响应

**预期结果**:
- 返回403 Forbidden
- 错误码：ACCESS_DENIED
- 不返回任何管理数据
- 记录安全审计日志

|------|------|

1. 用户A拥有"订单管理"权限
