# 采购询价/报价管理系统需求分析与产品设计文档

## 1. 项目背景与目标

### 1.1 背景
采购询价与报价管理是ERP系统中的核心功能模块，支持企业进行供应商寻源、价格谈判、采购决策等关键业务流程。本模块旨在解决传统采购流程中询价效率低、报价难以比较、审批流程复杂等痛点。

### 1.2 目标
- **效率提升**：询价流程从2-3天缩短至实时处理
- **成本优化**：通过比价分析降低采购成本5-15%
- **决策科学化**：建立客观的供应商评价与选择机制
- **流程标准化**：统一采购流程，降低合规风险

## 2. 功能架构设计

### 2.1 核心功能模块

#### 2.1.1 询价管理模块
- **询价单创建**：支持产品需求、数量、技术规格录入
- **供应商选择**：智能供应商推荐，基于历史合作数据
- **询价单发布**：多通道发布（系统通知、邮件、API接口）
- **询价状态跟踪**：实时跟踪供应商响应情况
- **询价单管理**：编辑、关闭、取消、复制询价单

#### 2.1.2 报价管理模块
- **报价接收**：供应商在线报价提交与接收
- **报价审核**：自动/人工审核报价完整性
- **报价评审**：多维度评分体系（价格、质量、服务）
- **报价决策**：自动推荐最佳报价或人工选择
- **报价反馈**：向供应商反馈报价结果

#### 2.1.3 比价分析模块
- **多维度比较**：价格、质量、交期、服务综合比较
- **智能推荐**：基于评分模型的供应商推荐
- **图表展示**：可视化报价比较图表
- **成本分析**：总成本分析（含运输、关税等）

#### 2.1.4 审批工作流模块
- **多级审批**：基于采购金额的自动化审批流
- **并行审批**：支持多部门并行审批
- **移动审批**：手机端审批支持
- **审批历史**：完整的审批记录与追踪

### 2.2 技术特性
- **实时性**：报价接收与状态更新实时推送
- **集成性**：与供应商管理、库存管理、财务系统集成
- **扩展性**：支持插件化扩展新评分维度
- **安全性**：数据加密传输，权限分级控制

## 3. 核心业务流程

### 3.1 询价发布流程
```
1. 创建询价单 → 2. 选择供应商 → 3. 设置询价规则 → 
4. 发布询价 → 5. 供应商接收通知 → 6. 报价提交 →
7. 报价自动接收 → 8. 报价状态更新
```

### 3.2 报价评审流程
```
1. 报价自动校验 → 2. 完整性审查 → 3. 技术评审 → 
4. 商务评审 → 5. 综合评分 → 6. 报价排序 → 
7. 推荐中标 → 8. 审批流程 → 9. 中标通知
```

### 3.3 供应商管理流程
```
1. 供应商档案管理 → 2. 绩效评分 → 3. 分级管理 → 
4. 寻源推荐 → 5. 合作记录 → 6. 黑名单管理
```

## 4. 数据模型设计

### 4.1 核心实体
- **询价单** (PurchaseInquiry)：询价主体信息
- **询价项** (PurchaseInquiryItem)：具体产品需求
- **供应商报价** (PurchaseSupplierQuote)：报价主体
- **报价项** (PurchaseQuoteItem)：具体报价明细
- **报价评审** (QuoteReview)：评审意见与评分

### 4.2 关键字段
```
询价单：
- 询价编号、标题、状态、发布日期、截止日期
- 采购员、采购部门、预算金额
- 技术要求、交付期限、付款条件

供应商报价：
- 报价编号、供应商、报价状态
- 总金额、币种、有效期限
- 评分（价格、质量、服务）
- 评审状态、中标状态
```

## 5. 评分指标体系

### 5.1 价格维度（权重40%）
- 报价金额（30%）
- 折扣幅度（30%）
- 付款条件（20%）
- 价格稳定性（20%）

### 5.2 质量维度（权重40%）
- 产品质量等级（30%）
- 历史合格率（30%）
- 认证资质（20%）
- 售后服务（20%）

### 5.3 服务维度（权重20%）
- 响应速度（25%）
- 技术支持（25%）
- 交货准时率（25%）
- 问题解决率（25%）

## 6. 用户角色与权限

### 6.1 采购员
- 创建/编辑询价单
- 选择供应商
- 发布询价
- 接收报价
- 发起评审

### 6.2 评审专家
- 评审报价技术方案
- 给出评分与意见
- 参与专家会议

### 6.3 审批领导
- 审核询价结果
- 审批采购决策
- 查看统计报表

### 6.4 供应商
- 接收询价通知
- 提交报价
- 查看报价状态
- 接收中标通知

## 7. 界面原型设计

### 7.1 主要页面
1. **询价单列表页**：状态筛选、快速创建、批量操作
2. **询价单详情页**：基本信息、询价项、供应商列表
3. **报价比较页**：矩阵式比较、图表展示、智能推荐
4. **评审工作台**：报价详情、评审表单、评分统计
5. **统计分析页**：供应商表现、采购趋势、成本节约

### 7.2 交互特性
- 拖拽式供应商选择
- 可视化评分图表
- 实时状态更新
- 批量操作支持

## 8. 集成需求

### 8.1 内部系统集成
- **供应商管理**：获取供应商信息与绩效数据
- **产品管理**：获取产品规格与技术参数
- **库存管理**：获取库存水平与需求预测
- **财务管理**：预算控制与付款信息同步

### 8.2 外部系统集成
- **邮件系统**：自动发送询价通知与结果通知
- **短信平台**：重要提醒短信通知
- **API网关**：供应商系统集成接口
- **电子签名**：在线合同签署

## 9. 性能与技术要求

### 9.1 性能指标
- 页面加载时间：≤2秒
- 报价接收延迟：≤100ms
- 查询响应时间：≤1秒
- 并发支持：≥1000用户同时在线

### 9.2 技术架构
- 前端：Vue 3 + TypeScript + Element Plus
- 后端：Spring Boot 3 + Java 17
- 数据库：PostgreSQL + Redis缓存
- 消息队列：RabbitMQ/Kafka
- 搜索：Elasticsearch

## 11. 预期效益

### 11.1 效率提升
- 询价周期缩短：从平均5天缩短至1天
- 人工工作量减少：减少50%以上的手动操作
- 决策速度提升：评审决策时间减少70%

### 11.2 成本节约
- 采购成本降低：通过比价降低3-10%
- 管理成本减少：减少30%的采购管理成本
- 库存成本优化：减少15%的库存持有成本

### 11.3 质量改进
- 供应商质量提升：不良品率降低20%
- 合规性提升：100%满足采购政策要求
- 数据准确性：报价数据准确率99%以上

### 11.4 风险管理
- 供应链风险降低：多供应商备选，降低单一依赖
- 合规风险控制：完整审计跟踪，防止违规操作
- 财务风险控制：预算控制，防止超预算采购

## 13. 风险与应对

### 13.1 技术风险
- **数据迁移风险**：制定详细的数据迁移计划，分阶段实施
- **系统集成风险**：采用标准化API接口，建立集成测试环境
- **性能风险**：进行压力测试，设计可扩展架构

### 13.2 业务风险
- **用户接受度风险**：加强培训，收集用户反馈，持续改进
- **供应商参与风险**：提供便捷的供应商门户，降低使用门槛
- **流程变更风险**：渐进式流程优化，充分沟通与培训

### 13.3 管理风险
- **项目延期风险**：采用敏捷开发，分阶段交付，设立里程碑
- **预算超支风险**：严格控制范围变更，定期成本审查
- **资源不足风险**：合理资源规划，建立后备资源计划
