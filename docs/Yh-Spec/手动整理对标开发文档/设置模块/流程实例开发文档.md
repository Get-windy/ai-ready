## 1. 页面概述

流程实例页是设置模块审批组的**运行监控台**：分页列出本租户的流程实例（实例ID / 流程名称 / 状态 / 当前节点 / 开始时间 / 结束时间 / 耗时），支持查看只读详情、查看后端**现场拼接的 SVG 流程图**，并对**运行中**实例执行人工干预（终止 / 挂起 / 恢复）。本页**不发起审批、不处理任务**（那是 803/804 的职责）。

### 5.1 状态值域（**前端 4 值 vs 后端 7 值**，P1）

### 5.2 状态流转（后端真源）

```
                       ┌─ terminate(干预) ─▶ terminated(6)
approving(0) ─ approve ─▶ approved(1)        suspend(干预) ─▶ suspended(5)
      │                                       suspended ─ resume(干预) ─▶ approving(0)
      ├─ reject ─▶ rejected(2)
      ├─ withdraw ─▶ withdrawn(3)
      └─ cancel ─▶ cancelled(4)
```

**硬编码迁移表**（`engine/StateTransitionManager.java:25-38`，逐字）：
```
draft      → {pending, cancelled}
pending    → {approving, cancelled}
approving  → {approved, rejected, cancelled, withdrawn, suspended, terminated}
approved   → {completed, cancelled}
rejected   → {resubmit, cancelled}
withdrawn  → {resubmit, cancelled}
suspended  → {approving, terminated, cancelled}
terminated → {}（空）
completed  → {}（空）
cancelled  → {}（空）
```
> **语义提醒**：迁移表是**独立的一套词表**（`draft`/`pending`/`resubmit`/`completed`），与 `WorkflowConverter` 的 7 值枚举**并不完全对应**（如 `completed` 在枚举里没有）。转换发生在 `transitionTo`（`WorkflowServiceImpl.java:1082-1096`）：当前 `status` → `instanceStatusToString` 后交给迁移表判定，通过再写回 `instanceStatusToInt(targetStatus)`。

**本页干预动作的实际语义（`interveneInstance :759-796`）**：

| 下拉项 | `action` | 目标状态 | 额外副作用 | 行 |
|-------|---------|---------|-----------|----|
| `终止流程` | `terminate` | `terminated`(6) | ① `closePendingTasks(instanceId, "流程已终止")`（关闭待处理任务）；② `publishApprovalCompleted(entity, "terminated", ...)`（发布终态事件，单据侧映射为 `onRejected`，注释称"单据回退草稿可重新提交"）；③ `insertRecordTask(..., ACTION_INTERVENE, "流程干预: terminate")` | `:774-792` |
