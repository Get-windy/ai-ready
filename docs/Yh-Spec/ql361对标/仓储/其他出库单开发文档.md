# 其他出库单开发文档

## 页面概述

| 页面 | 地址 | 说明 |
|------|------|------|
| 新增/编辑其他出库单表单页 | 对标系统：https://22stable.ql361.com/desktop.html#/（桌面式多标签架构，页面以桌面标签打开，无独立路由）；本系统路由：http://localhost:5656/erp/stock-out | 表单页：非购销业务的库存出库录单（样品领用、内部耗用等），编辑模式为新增模式加 id |

**对标系统页面性质**：表单页（表头字段区 + 商品明细表格 + 备注区 + 单据信息行 + 底部本单金额与操作按钮）。

### 配置功能说明

- **页面配置**（表头右侧齿轮图标）：管理表单字段的显示、隐藏和排序
- **列配置**（明细表格左上角表头单元格内齿轮图标）：管理明细列的显示、隐藏、排序等

## 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

必填：出库仓库*、经手人*（另有单据日期* 截图确认必填）
选填：往来单位
摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（往来单位/出库仓库/经手人/单据日期）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额

### 全部表单字段

抓取数据仅覆盖默认显示字段；列配置弹窗全量字段无 XSMK 存档依据，待复核。

### 数据表格列配置

#### 默认显示列（抓取 JSON columns 实据，20 列）

操作、商品名称（带"扫描枪录入"开关）、货号、条码、货位、计价单位、可用库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、单价、金额、备注

> 注：JSON columns 首项"操作 商品名称扫描枪录入 关 货号"为抓取拼接串（表头多单元格文本相连），非真实单列，列数统计已剔除；剔除后共 20 列。

## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿进入"业务草稿"（分析-综合单据），记账后单据生效扣减库存
- 与销售出库单不同：无收/付款区、无摘要结账面板，仅"本单金额"汇总；往来单位非必填（内部出库可无往来对象）
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入
- 批次管理列齐备（批次条码/生产日期/保质期/到期日期），出库需指定批次

### 与其他页面关系

- 与其他入库单互为反向单据（一出/一入，页面结构完全一致，仅"出库仓库*/入库仓库*"差异）
- 草稿在 分析→综合单据→业务草稿 中检索（销售域已确认该入口，仓储单据同体系，待复核）
- 记账后影响 分析→仓配分析→查库存/库存明细

### 架构师红线（Ponytail六步过滤网）
