## 业务规范说明

- **关键词主线**：商城搜索关键词库（商家→买家端搜索框）；关键词为搜索热词/推荐词，供商城搜索联想与推荐。
- **关键词/备注**：列表展示关键词名称与备注；新增/编辑关键词必填关键词（≤30 字符），可填备注（≤30 字）。
- **状态**：金标准侧关键词无独立状态列（无启停），仅 关键词名称/备注 两列；本系统已实现 关键词类型（热门/置顶/屏蔽）+ 状态（启用/禁用）更细化。

## 实现差异说明

> 本节按当前源码回写（本轮金标准升级后）。

### 当前实现
- **实现文件**：`frontend/apps/pc-admin/src/views/mall/keyword-bank/index.vue`
- **骨架**：`ErrorBoundary > PageContainer(full-height) > CategoryListLayout(:tabs="[]"、:show-category-panel="false"、:show-table-footer="true") > BillDetailTable + StandardPagination(variant="classic")`；列配置齿轮挂在 `BillDetailTable` 表头 rowNo 列；工具栏经 `#toolbar-left` / `#toolbar-right`，查询区经 `#search-fields`，数据表经 `#table`，分页经 `#table-footer`。**本页无独立 `PageConfigPanel` 组件**。
- **Tab**：无 Tab（`:tabs="[]"` + 隐藏分类面板；对标为单入口单视图列表页）
- **列**：共 6 列可配置（默认显示 5：关键词名称、备注、类型、排序、状态；默认隐藏 1：创建时间）；固定列：序号（`rowNo`，承载列配置齿轮）、操作（宽 130，`fixed: 'left'`）。**无多选勾选列**（源码未定义 checkbox 列）。
- **查询条件**：3 项（关键词 `a-input`，placeholder「请输入关键词」；类型 `a-select`，全部类型=1热门/2置顶/3屏蔽；状态 `a-select`，全部状态=1启用/0禁用）+「查询」按钮
- **功能按钮**：新增关键词（工具栏左，橙色 `.btn-add`）；刷新、打印(F8)（工具栏右）。**本页无「导出」按钮**（源码未定义 `handleExport`）
- **行级操作**：修改、删除；「状态」列内嵌 `a-switch`（启用/禁用，`handleToggle` → `PUT /{id}/status`）；点击「关键词名称」单元格链接亦进入编辑弹窗
- **打印(F8) / 导出**：`handlePrint()` 打开新窗口渲染打印模板（列：# / 关键词名称 / 备注 / 类型 / 排序 / 状态，页眉含筛选条件、打印时间、记录数）；`window.addEventListener('keydown', handleF8Key)` → F8（无修饰键）触发打印。**无导出能力**。
- **storage-key**：列配置 `mall-keyword-bank-table-columns`（`global-config-key` 同值）；页面配置：无（本页无 PageConfigPanel，故无页面配置 storage-key）
- **数据来源**：`apps/pc-admin/src/api/erp/mall.ts` → `mallKeywordApi`
  - `GET /erp/mall/admin/keyword/page`（pageNum、pageSize、keyword、keywordType、status）
  - `POST /erp/mall/admin/keyword`（新增，后端默认置启用）
  - `PUT /erp/mall/admin/keyword/{id}`
  - `DELETE /erp/mall/admin/keyword/{id}`
  - `PUT /erp/mall/admin/keyword/{id}/status?status=`（`status` 走 query 参数，1启用/0禁用）
- **新增/编辑弹窗字段**：关键词（必填，限 30、show-count，placeholder「请输入关键词，不超过30字符」）、备注（限 30、show-count，placeholder「请输入备注，限30字」）、类型（必填，1热门/2置顶/3屏蔽）、排序（`a-input-number`，min 0）
- **字段语义**：`status` 1启用/0禁用；`keywordType` 1热门/2置顶/3屏蔽；`remark` 备注（对标 ql361「备注」列）

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
