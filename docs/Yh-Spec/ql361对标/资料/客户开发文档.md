## 1. 页面概述

- **列表页**：客户主数据档案列表，含新增/导入/发短信/发优惠券/批量修改；左侧客户分类树 + 查询区 + 数据表格；5 个子标签（全部客户 / 会员管理 / 全部联系人 / 客户级别 / 区域管理）。

## 2. 页面配置

### 查询条件

- 筛选条件（请输入客户编号/名称）
- 联系地址
- 新增日期（起）、新增日期（止）
- 最近交易（起）、最近交易（止）

- 所属区域（选择器）

- 左侧客户分类树按分类过滤
- JSON filterLabels 20 个"更多"占位对应查询配置区折叠字段，全量查询条件待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增、导入、发短信、发优惠券、刷新、打印(F8)、导出、批量修改、更多、查询、跳转（分页跳转）
- 行级操作（截图确认）：代客下单、修改、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（27 列，抓取 JSON columns 实据，全部客户子标签）

操作、客户编号、客户名称、结款方式、客户级别、所属仓库、所属区域、默认经手人、推广人、联系人、助记码、联系电话、联系地址、买家账号、客户一票通、动态收款期限（天）、固定账期、结算期、开户银行、银行账号、税号、客户来源、营业执照有效期、最近交易时间、新增时间、附件、备注

> JSON columns 首项"操作 客户编号 客户名称 结款方式"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

列配置弹窗实测（2026-09-11 复抓）：全部客户 26 个数据列**全部默认勾选显示**（无隐藏列），弹窗结构 = 个人配置 / 全局配置 两个 Tab + 表格（上级 / 列名 / 显示名 / 显示）+ 上移 / 下移 / 恢复默认 / 保存。

### 其余 4 个子标签列（2026-09-11 复抓实据）

| 子标签 | 默认显示列 | 全量列 |
|--------|-----------|--------|
| 会员管理 | 会员名称、会员卡号、客户名称、会员级别、会员卡状态、有效时间、会员生日、当前积分、最近交易时间、备注（10） | + 客户编号、联系电话、累计消费额、发卡时间、初始积分、默认经手人（16） |
| 全部联系人 | 姓名、性别、对应客户、职务、手机、联系地址、配送方式、物流公司（8） | + 客户编号、客户所属区域、客户经手人、网点（12） |
| 客户级别 | 客户级别、级别默认价（2） | 同左 |

行级操作：会员管理=修改/积分明细/更多；全部联系人 / 客户级别 / 区域管理=修改/删除。

> 页面配置齿轮仅 全部客户、会员管理 两个子标签提供；全部联系人 / 客户级别 / 区域管理 为固定查询与按钮（列配置齿轮仍走表头）。

## 4. 业务规范

- 结款方式：现结/挂账（截图实据），挂账客户配套 动态收款期限（天）/固定账期/结算期 三个账期字段
- 代客下单：行级直接为该客户开销售订单（与商城"买家账号"对应：客户可开通商城账号自主下单，或由业务员代客下单）
- 发短信/发优惠券：选中客户批量触达（营销联动）
- 客户一票通：客户多门店/多联系方式的通票标识（实据不足，待复核）
- 显示供应商中的客户：客户与供应商可为同一主体（互为往来单位），勾选后并列显示
- 客户分类树含经营状态类分类（在线注册客户/观望筹备客户/流失客户/关店客户），支持按生命周期管理客户
- 与其他页面关系：客户级别（子标签维护级别档案；商品价格管理按客户级别设折扣/指定价；销售订单按客户级别取价）、区域管理（所属区域来源；配送线路按区域关联客户）、会员管理（会员积分/会员卡，销售订单"会员信息"Tab 引用）、销售订单（客户为录单必填主数据；代客下单直达订单表单）、互联账号（客户与互联平台账号绑定关系）
