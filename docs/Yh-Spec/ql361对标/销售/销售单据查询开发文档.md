# 销售单据查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/doc-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：全类型销售单据综合查询（销售出库单/退货单/零售单/换货单等），按单据维度汇总，一行一单，页面聚焦单据查询。
- 页面结构：查询区 + 工具按钮区 + 数据表格 + 合计行 + 底部分页（无左侧树）；按单据 / 按明细两个 tab。

## 2. 页面配置

### 查询条件

- 按单据 tab（查询区当前展开，抓取 JSON filterLabels + 截图实据，13 项）：查询方案（--查询方案--，可保存复用）、时间快捷段（昨日/今日/本周/近一周/本月/上月/近三月/本年）、日期范围（起至止）、日期类型（默认"单据日期"）、单据编号、客户、经手人、仓库、结算状态（下拉，全部）、来源订单、单据类型（下拉，全部单据）、商品行属性（下拉，全部）、仅统计车辆库（勾选框）
- 按单据 tab（查询条件管理弹窗，抓取实据）：日期、单据编号、供应商/客户、经手人、部门、制单人、仓库、单据状态、单据备注、审核人
- 按明细 tab（查询条件管理弹窗，抓取实据，13 项）：日期、单据编号、商品、供应商/客户、经手人、部门、制单人、审核人、仓库、单价状态、单据备注、明细备注、是否赠品
- XSMK 全量（查询条件管理弹窗，33 项）：日期、日期类型、单据编号、客户、收货人、联系电话、收货地址、经手人、部门、制单人、记账人、仓库、结算状态、来源订单、来源订单日期、产生方式、单据类型、销售类型、商品行属性、单据备注、买家备注、自定义字段1(数字)、自定义字段2(数字)、自定义字段3(文本)、自定义字段4(文本)、自定义字段5(文本)、物流公司、运单号、区域、本单金额、来源、显示红冲、仅统计车辆库
- 搜索区域规则：默认显示 2 排（必须包含查询及后续 3 个勾选选项），超出自动折叠（本页无"更多条件"按钮，当前条件两排内放下）。

### 功能按钮

- 抓取 JSON buttons 实据：刷新、打印(F8)、导出、查询、跳转（分页）
- 行级操作（截图确认）：复制、整单备注

### 打印配置

无（页面有打印(F8)按钮，打印模板配置细节待复核）。

## 4. 业务规范

- 单据类型下拉（全部单据）覆盖销售域全部单据类型：销售出库单（截图实据主类型）、销售退货单、零售单、销售换货单等，本页是销售单据的统一检索入口。
- 入库仓库/出库仓库双列并存：出库单只填出库仓，退货单只填入库仓，换货单两者皆有。
- 金额口径区分：金额、销售收入、本单金额、成本金额、毛利 五个金额列并存，毛利 = 销售收入 − 成本金额（推断，精确口径待复核）。
- 红冲：查询条件含"显示红冲"，被红冲的单据默认隐藏（待复核）；"仅统计车辆库"勾选后仅统计车上库存（移动车销场景）的单据。
- 数据源：销售出库单/销售退货单/零售单/销售换货单（销售订单与销售退货申请、预订货单属订货业务，是否纳入"全部单据"待复核）。
- 行级"复制"以本单为模板快速新增同类单据；"整单备注"对整单补录备注；单据编号链接跳转原单据详情/表单页。
- 销售明细查询为本页的明细维度姊妹页（按单据 vs 按明细）。
