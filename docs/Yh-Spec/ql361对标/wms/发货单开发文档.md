# 发货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`wms/ship/form`（表单）+ `wh/shipping-order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=历史）：主按钮 → 新增/编辑表单页 `wms/ship/form`；标签"历史"→ 列表页 `wh/shipping-order/index`。
- **表单页**：WMS 发货执行——拣货后复核发货出库（我方实现，views/wh/shipping-order/form/index.vue）。
- **列表页**：发货单台账（我方实现，views/wh/shipping-order/index.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `wh/shipping-order/index.vue`（3 项）

- `keyword` 单号/来源单号（输入）
- `status` 状态（下拉：WMS_STATUS_MAP 全部状态）
- `carrierName` 承运商（输入）

### 功能按钮

来源：我方源码 `wh/shipping-order/index.vue`

- 工具栏：新增发货单（跳转 `wms/ship/form`）
- 行操作：查看、编辑（仅状态=待处理）、删除（仅状态=待处理，popconfirm 确认）

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段

来源：我方源码 `wh/shipping-order/form/index.vue`

- 必填：发货仓库\*（a-form-item required）、单号\*（保存时校验非空）
- 选填：来源单号、客户、承运商、运单号、备注

### 字段分组／录单默认值／打印设置

- 字段分组：单据头 → 发货明细 → 最近发货单
- 明细表格列（编辑态 9 列）：行号、商品、规格、单位、应发数量、货位、批次号、序列号、操作
- 明细表格列（只读态 12 列）：行号、商品编码、商品名称、规格、单位、应发数量、已扫数量、已确认、货位、批次号、序列号、状态
- 最近发货单列表列（9 列）：单号、来源单号、仓库、客户、承运商、进度(扫/总)、状态、创建时间、操作
- 录单默认值：单号自动生成（SH 前缀 `genTaskNo('SH')`）
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（12 列，来源：我方源码 `wh/shipping-order/index.vue`）

单号、仓库、客户、来源单号、总数量、已扫描、承运商、运单号、状态、备注、创建时间、操作

### 全部可配置列（12 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `columns` 数组（12 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`wms/ship/form`，标签按钮 list_path=`wh/shipping-order/index`，tag_label=历史（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- WMS 发货执行：拣货后复核发货出库；上游为拣货环节（见《拣货单开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
