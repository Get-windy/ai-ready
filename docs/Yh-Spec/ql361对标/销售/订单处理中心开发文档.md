## 业务规范说明

### 状态流转（统计卡片与单据状态标签实据）

销售订单全生命周期：提交（待审核）→ 审核 → 待出库 → 待发货 → 已出库 → 发货完成 → 交易完成。统计卡片六档（订单总数/待出库/待发货/已出库/发货完成/交易完成）与之一一对应；单据状态下拉多选含"审核中,待付款,待发货"等值。

### 特殊交互

- 统计卡片可点击：点击卡片即按对应状态过滤表格（截图卡片带箭头，推断可点，待复核）
- 按明细显示：勾选后表格从"一行一单"切换为"一行一明细"
- 不显示有关联审核中退货申请单的单据：存在审核中退货申请的原单可被过滤，避免重复处理
- 收款/取消/修改行级操作：待审核阶段可修改/取消，收款直接对订单收款
- 商品汇总：把选中订单按商品汇总数量（配货用）；批量打印：批量打印选中订单
- 补单类型/订单履约：已发货不足的订单可补单，订单履约视图跟踪原单与补单

### 与其他页面关系

- 新增按钮 → 销售订单表单页（/sales/order/form）
- 拣货/发货阶段生成销售出库单；退货关联销售退货申请（查询勾选项实据）
- 本页即 XSMK《销售订单开发文档》的"销售订单列表页"

### 客户来源

客户来源通过 ERP 模块的往来单位下的客户分类处理，而非 CRM 模块的客户信息。CRM客户是公海客户，ERP客户是实体客户。
