## 页面概述

明细账是**按凭证逐笔的科目明细账簿**（凭证→分录→借贷金额逐笔列示）。**报表查询页**（左侧科目分类树 + 查询 + 逐笔明细表格），单入口，无子 Tab。

| 页面 | 地址 | 说明 |
|------|------|------|
| 明细账 | `finance/detail-ledger` | 科目分类树 + 查询 + 明细分录表格 |

单入口：财务 → 账簿 → 明细账。

### 配置功能说明
- **页面配置**：页面顶部**「配置」齿轮**（`title="配置"`）→ "配置" 弹窗，**仅「查询条件」一个 Tab**（无「功能按钮」Tab），配置查询区字段的排序/显示（含隐藏项全量）。**12 字段全部默认显示，无隐藏项**。
- **列配置**：数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）→ 列配置弹窗（个人配置 / 全局配置），配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**15 列全部默认显示，无隐藏列**。
- ✅ **当前实现说明**（2026-09-10 金标准升级完成）：本页已升级 `CategoryListLayout`（左侧科目分类树）+ `BillTableList`（表头 rowNo 列内置列配置齿轮）+ `PageConfigPanel(fieldsOnly)`（仅「查询条件」Tab，12 字段）；数据由 `/api/erp/finance/ledger/detail-page` 提供（期初余额 + 逐笔发生额/期末余额 + 合计）。

## 业务规范说明

- **账簿口径**：按凭证/分录逐笔列示，反映科目明细流水。
- **余额**：逐笔累计余额（期初+借−贷）。
- **来源**：会计凭证（KJPZ-）分录入明细账；摘要实据"由[收款单 SKD-…]"（业务单据自动生成凭证）。
- **核算项**：科目挂核算项（往来单位/部门/职员）时核算项列示（核算单位/核算部门/核算职员/部门列）。
- **科目树**：左侧科目分类树按科目口径过滤；选中科目后明细账按该科目逐笔列示。
- **下钻来源**：总账科目行「明细对账」可跳转本页对应科目。

## 实现差异说明

**实现文件**：
- 前端：`views/finance/detail-ledger/index.vue`
- API：`api/finance/index.ts`（`ledgerApi.getDetailPage` / `ledgerApi.getSubjectTree`）
- 后端：`erp-finance` `LedgerController`（`/detail-page`、`/subject-tree`）+ `LedgerDetailMapper` + `LedgerDetailQuery/RowDTO/PageDTO/SubjectTreeNodeDTO`
- 迁移：`V11.95.0__Enhance_Detail_Ledger_GoldStandard.sql`（`finance_voucher_item` 补 `reconcile_flag` / `aux_unit` / `aux_dept` / `aux_staff`）

### 页面对齐（已建成）
- **报表查询页**：左侧科目分类树（全部 / 资产类 / 负债类 / 权益类 / 成本类 / 损益类 + 组内科目层级）+ 查询（日期起止/日期类型/科目/核算单位/核算部门/核算职员/经手人/部门/对账标记/摘要/单据备注/显示红冲）+ 明细分录表格（15 列全部默认显示）。
- **金标准组件**：`CategoryListLayout`（分类树 + 工具栏 + 查询区 + 表格）+ `BillTableList`（表头 rowNo 列内置列配置齿轮，个人配置 / 全局配置）+ `PageConfigPanel fieldsOnly`（仅「查询条件」Tab，12 字段全量、可排序、可显隐）。
- **账簿口径**：数据源为 `finance_voucher_item ⨝ finance_voucher`，仅取已记账凭证（`posted`；勾选「显示红冲」时含 `reversed`），严禁绕过凭证直改明细。首行「期初余额」+ 逐笔分录（逐笔累计期末余额）+ 「合计」行（借/贷/期末）。
- **余额勾稽**：期初 = 起始日之前同口径净额；期末 = 期初 + Σ借 − Σ贷；方向按余额符号标注「借 / 贷」。
- **科目穿透**：左侧树选中科目（含下级科目）或「XX类」按科目类型过滤；查询区「科目」与左侧树双向联动；凭证号可点击跳转凭证表单（`/finance/voucher/form?id=`）；支持总账「明细对账」经路由参数（`subjectId` + `dateStart/dateEnd`）下钻。
- **核算项/部门列**：核算单位/核算部门/核算职员取自 `finance_voucher_item.aux_*`；经手人/部门取自凭证头 `handler_name` / `dept_name`；对账标记取自 `reconcile_flag` 并支持查询过滤。
- **日期口径**：日期类型（单据日期 = `voucher_date` / 记账日期 = `post_at`）与日期范围联动，日期类型、时间快捷段（昨日/今日/本周/近一周/本月/上月/近三月/本年）均作用于所选日期口径；期初余额与逐笔取数同口径。
- **工具栏**：配置齿轮（页面配置）+ 刷新 + 打印(F8) + 导出（CSV 全量导出）。

### 待完善（非阻塞）
1. **凭证号前缀**：历史凭证号存在 `202609-0001` 形式（非 `KJPZ-` 前缀），由凭证模块号段生成，本页按实际值展示。
2. **对账标记写入方**：`finance_voucher_item.reconcile_flag` 目前仅在凭证保存时由 `VoucherItemDTO` 透传，**尚无业务服务回写**（对账模块写的是 `capital_flow.reconcile_flag` / `finance_payable.reconcile_flag`），故该列现恒为「否」。明细账为只读报表，**不得在账页直接改标记**（违反 P0 红线），应由对账流程回写凭证分录——属跨模块待接。
3. **核算项回填**：`aux_unit`/`aux_dept`/`aux_staff` 已由业财记账入口按行透传（`AccountingRequestItem`），历史数据为空时该列留空，可在录单端补齐。
4. **旧接口**：`/api/erp/finance/ledger/detail`（旧版明细账列表）已被本页 `/detail-page` 取代，前端 `ledgerApi.getDetail` 无调用方，属遗留接口待清理。
5. **打印(F8)**：当前为 `window.print()` 占位，未接打印模板（与凭证页、在线支付对账页一致）。
6. **查询方案**：下拉仅有 `--查询方案--` 占位，无方案保存/加载（与借进借出查询等报表页一致）。
7. **导出范围**：导出固定为 15 列全字段，不随个人列配置变化（账簿导出取全字段，属有意设计）。
8. **列配置弹窗交互差异（平台级，非本页）**：对标系统为「上级 / 列名 / 显示名 / 显示 + 上移下移 + 恢复默认 + 保存」，本平台 `BillDetailTable` 内置弹窗为「序号 / 列名 / 显示名 / 宽度 + 拖拽排序 + 恢复默认」，改动即时生效并自动持久化（无独立「保存」按钮）。此为全平台共享组件行为，改则影响所有金标准列表页，故保持现状。

## 开发原则（通用）

- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
