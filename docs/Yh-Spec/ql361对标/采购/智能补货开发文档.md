# 智能补货开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：待规划（采购域对标新增页面）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：补货计算工作台，按历史销售日均销量 × 备货天数推算计划采购数量，勾选商品后一键转采购。
- **单入口**：仅列表页（顶部公式提示条 + 查询区 + 左侧商品分类树 + 数据表格 + 合计行 + 分页）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 销售日期*（起 至 止，必填）：日均销量统计区间
- 备货天数*（必填，默认 0）：计划采购数量乘数因子
- 商品、仓库、供应商
- 计划采购数量（带 ≥ 比较符下拉，按计算结果过滤）

> 查询条件两行放下，无「更多条件」折叠入口。

### 功能按钮（抓取 JSON buttons 实据）

采购（红色主按钮）、刷新、打印(F8)、导出、查询、跳转（分页）

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（21 列，抓取 JSON columns 实据）

图片、商品名称、货号、单位、条码、型号、产地、备注、销售数量、销售金额、采购金额、日均销量、备货天数、规格、待收货数量、待发货数量、采购数量、账面库存、账面库存换算结果、计划采购数量、可用库存

> 注：JSON 首项「图片 商品名称 货号」为表头拼接串，非真实单列，已剔除。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核）。

## 4. 业务规范

- 计划采购数量 = 备货天数 × 日均销售量 + 待发货数量 − 待收货数量 − 账面库存（页面提示条实据）。
- 日均销量：按「销售日期」区间内销售数量折算（区间天数口径待复核）；备货天数为查询区必填输入，同时作为表格列回显。
- 计划采购数量过滤：查询区带 ≥ 比较符，可按计算结果阈值筛选（如只显示需要补货的商品）。
- 采购数量列：应为可编辑的建议采购量（是否可手工改后带入采购单，待复核）。
- 采购按钮：勾选行后按采购数量转采购流程（生成采购订单的跳转与携带字段待复核）。
- 数据源：销售出库/销售订单（销量统计）+ 实时库存 + 采购在途（待收货数量）；下游：采购订单。
- 同组姊妹页：库存预警补货（按仓库上下限预警）、缺货补货（按订单缺口）、以销定购（按销售订单逐单转采购）。
