# 缺货补货开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：待规划（采购域对标新增页面）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：补货计算工作台，按时间范围内销售订单的待发货缺口计算缺货数量，勾选商品后一键转采购。
- **单入口**：仅列表页（查询方案 + 时间快捷段 + 查询区 + 左侧商品分类树 + 数据表格 + 合计行 + 分页）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）
- 商品、仓库、客户、供应商、经手人
- 单据状态（下拉，全部）、订单来源（下拉，全部）
- 缺货数量公式下拉（当前值「缺货数量=待发货数量-账面库存」，是否还有备选公式待复核）
- 仅显示缺货商品（勾选框，默认选中）

> 统计口径（截图黄色提示实据）：待审批、已取消、已驳回订单不参与统计。

### 功能按钮（抓取 JSON buttons 实据）

采购（红色主按钮）、刷新、打印(F8)、导出、查询、跳转（分页）

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（12 列，抓取 JSON columns 实据）

图片、商品名称、商品货号、单位、订单数量、价税合计、已发货数量、待发货数量、待收货数量、账面库存、缺货数量、备注

> 注：JSON 首项「图片 商品名称 商品货号」为表头拼接串，非真实单列，已剔除。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核）。

## 4. 业务规范

- 缺货数量 = 待发货数量 − 账面库存（截图实据）；公式以查询区下拉框呈现，可切换（备选公式待复核）。
- 统计口径：仅统计时间范围内已审核生效的销售订单；待审批、已取消、已驳回订单不参与统计（页面提示实据）。
- 仅显示缺货商品：默认勾选，去掉勾选则显示全部有订单的商品（含不缺货的）。
- 采购按钮：勾选行后按缺货数量转采购流程（生成采购订单的跳转与携带字段待复核）。
- 列口径：订单数量/价税合计为销售订单侧汇总；已发货/待发货/待收货数量、账面库存为实时库存口径。
- 数据源：销售订单（待发货缺口）+ 实时库存 + 采购在途（待收货数量）；下游：采购订单。
- 同组姊妹页：库存预警补货（按仓库上下限预警）、智能补货（按日均销量推算）、以销定购（按销售订单逐单转采购）。
