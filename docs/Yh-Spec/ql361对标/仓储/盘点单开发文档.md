### 表头字段（抓取 JSON filterLabels + 截图确认）

顶部基本信息（盘点仓库/经手人/单据日期）→ 商品快速录入行 → 盘点明细表格（含工具行）→ 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 盈亏金额

## 业务规范说明

### 状态流转与特殊交互

- 保存（Ctrl+S，注意非"保存草稿"）→ 盘点处理（Ctrl+Enter）：保存后盘点单可继续盘点，盘点处理后按盈亏生成后续单据（推断生成报损单/报溢单，待复核）
- 库存数量=账面库存，盘点数量=实盘数，盈亏数量=盘点数量−库存数量 自动计算；盈亏金额汇总于右下角
- 快速盘点：右上角独立按钮，推断为批量导入/扫码连续盘点模式（弹窗内容待复核）
- 商品快速录入行：扫码或输入条码/名称/编码 + 数量直接追加盘点行
- 快速定位/盈亏状态/刷新库存为表格辅助工具，不参与单据字段

### 与其他页面关系

- 盘点处理产出报损单（盘亏）/报溢单（盘盈）（推断，待复核）
- 处理后影响 分析→仓配分析→查库存/库存明细

### 架构师红线（Ponytail六步过滤网）
