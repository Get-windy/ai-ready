## 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

必填：入库仓库*、经手人*（另有单据日期* 截图确认必填）
摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（入库仓库/经手人/单据日期）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额

### 全部表单字段

抓取数据仅覆盖默认显示字段；列配置弹窗全量字段无 XSMK 存档依据，待复核。

### 数据表格列配置

#### 默认显示列（抓取 JSON columns 实据，18 列）

操作、商品名称（带"扫描枪录入"开关）、货号、条码、货位、单位、批次条码、生产日期、保质期、到期日期、报溢数量、换算关系、件散数量、大包装、中包装、小包装、报溢单价、备注

> 注：JSON columns 首项"操作 商品名称扫描枪录入 关 货号"为抓取拼接串（表头多单元格文本相连），非真实单列，列数统计已剔除；剔除后共 18 列。列名"单位"为 JSON 原文（其他单据多作"计价单位"）。

#### 全部可配置列

待复核（无 XSMK 列配置存档，需在对标系统打开列配置弹窗补抓）。

## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入"业务草稿"（分析-综合单据），记帐后生效增加库存
- 数量列名为"报溢数量"，并带"报溢单价"（溢余入库需核定入账成本单价）
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入
- 批次列齐备（批次条码/生产日期/保质期/到期日期），溢余入库可登记批次与效期

### 与其他页面关系

- 与报损单互为反向单据（一溢/一损）；盘点单的盘盈处理可生成报溢单（盘点单"盘点处理"流程推断，待复核）
- 记帐后影响 分析→仓配分析→查库存/库存明细
