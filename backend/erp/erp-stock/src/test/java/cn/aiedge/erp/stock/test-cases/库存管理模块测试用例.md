# 库存管理模块测试用例

## 模块概述

库存管理模块是AI-Ready ERP系统的核心模块之一，负责管理商品的库存信息，包括库存查询、入库、出库、盘点、冻结/解冻等核心功能。

**模块路径**: `backend/erp/erp-stock`
**测试范围**: 功能测试、边界测试、异常测试、性能测试
**测试级别**: 单元测试 + 集成测试

---

## 一、功能测试用例

### TC001: 查询库存详情 - 正常情况

**测试目的**: 验证通过产品ID和仓库ID能正确查询库存详情

**前置条件**: 
- 数据库中存在产品ID=1001，仓库ID=2001的库存记录
- 库存数量=100，可用数量=80，冻结数量=20

**测试步骤**:
1. 调用 `GET /api/stock/{productId}/{warehouseId}` 
2. 传入参数：productId=1001, warehouseId=2001

**预期结果**:
- HTTP状态码: 200 OK
- 返回的库存对象不为null
- 返回的库存中 productId = 1001
- 返回的库存中 warehouseId = 2001
- 返回的库存中 quantity = 100
- 返回的库存中 availableQuantity = 80
- 返回的库存中 frozenQuantity = 20

**优先级**: P0
**测试类型**: 功能测试
