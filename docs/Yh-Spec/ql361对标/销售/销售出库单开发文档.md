# 销售出库单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/outbound/form`（表单）+ `sales/outbound/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**：表单页（`sales/outbound/form`）= 销售发货出库录单（直接销售出货或销售订单转出库），编辑模式为新增模式加 id；列表页（`sales/outbound/index`）= 按单据 / 按明细两个 tab。注：XSMK 文档路由曾作 `/sales/outbound/from`（form 拼写沿用既有文档）。
- 表单页结构：表头字段区 + 商品明细表格 + 底部收款/物流信息/会员信息 3 Tab + 备注区 + 单据信息行 + 右侧摘要结账面板。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账即确认出库，扣减库存并记应收/收款。
- 两种产生方式：直接开出库单，或由销售订单发货生成（明细全量列含"订单编号"，收款区含"订单已收订金"与"源单"）。
- 线路/点位：配送线路与配送点位字段，与配送路线域打通，出库即排线。
- 参考成本单价/参考成本金额/参考毛利：录单时实时可见毛利，属成本管控字段。
- 使用预订货款/使用预收款/订单已收订金：三类预收资金抵扣并存，欠款 = 本单金额 − 各项收款。
- 上游：销售订单（订单处理中心"拣货/发货"阶段生成出库单）；下游：销售退货单（退货）、销售单据查询/销售明细查询（统计口径主数据源，查询页默认展示即为销售出库单）；关联：销售价格跟踪（出库成交刷新客户-商品最近销售价）。
