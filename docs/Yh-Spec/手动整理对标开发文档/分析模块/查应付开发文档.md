## 1. 页面概述

查应付页是**应付域的核心滚动台账**：以「结算单位」为行，逐行给出 `期初应付 → 本期应付款 → 本期已结 → 优惠 → 应付余额` 的滚动链，并以 `预付余额` 冲抵得出 `期末余额`；左侧配合往来单位分类树，行内提供「付款 / 对账」动作。**单入口、单视图**（本页**无**页内视图 Tab，与《查应收》的三 Tab 结构不同）。

|------|------|------|

单入口：分析 → 财务分析 → 查应付。

## 4. 业务规范

### 统计口径（应付滚动）

- **核心恒等式 1**：`应付余额 = 期初应付 + 本期应付款 − 本期已结 − 优惠`（逐行验证 ✅）。
- **核心恒等式 2**：`期末余额 = 应付余额 − 预付余额`（逐行 + 合计行均验证 ✅）——`预付余额` 为正向冲减项，故期末呈负值表示「我方多付/预付净额」。
- **预付款滚动**：`预付余额 = 期初预付 + 本期预付`（`期初预付/本期预付` 默认隐藏，本轮 `head` 未给出其值，**该等式待复核**）。
- **本期应付款**：期内采购入库/退货净增应付；**本期已结**：期内付款 + 预付抵扣；**优惠**：付款让利冲减。
- **包含已审核未记账付款单/预付款单**：勾选后未记账单据也计入已结（**权责发生 vs 收付实现**口径切换）。
- **结算单位范围**：供应商 + 个人往来（实据 `老婆-高晓丽`/`老妈-王会兰`）——**不限于供应商主数据**。
- **信用与账期列**：`信用额度 / 可用额度 / 动态付款期限 / 固定账期 / 结算期` 为供应商主数据投影（不可加总），用于对账时判断超期/超额。

### 取数来源与上下游关系

- **取数**：采购入库单（应付发生） + 付款单/预付款单（已结） + 优惠；
- **行级动作**：`付款` → 付款单表单页（财务域）；`对账` → 该单位应付明细；
- **同源页**：《查应收》（客户侧镜像）、《往来余额表》（应收应付净额口径）、《采购分析》（采购侧金额）。
