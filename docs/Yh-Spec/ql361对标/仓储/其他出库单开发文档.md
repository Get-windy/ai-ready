# 其他出库单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-out`（表单）+ `erp/stock-out/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：非购销业务的库存出库录单（样品领用、内部耗用等），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `erp/stock-out`；标签「历史」→ `erp/stock-out/index`。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：出库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 选填：往来单位
- 摘要区：本单金额（自动计算）

### 全部表单字段（13 个，cfg 实据 13 字段 ✅）

编号、往来单位、往来编号、出库仓库、经手人、部门、单据日期、摘要、单据备注、制单人、制单时间、打印次数、本单金额：

### 字段分组

顶部基本信息（往来单位/出库仓库/经手人/单据日期）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（20 列，抓取 JSON columns 实据）

操作、商品名称（带「扫描枪录入」开关）、货号、条码、货位、计价单位、可用库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、单价、金额、备注

> 注：JSON columns 首项为表头拼接串（表头多单元格文本相连），非真实单列，已剔除。

### 全部可配置列（45 列，cfg 实据 45 列 ✅）

操作、图片、商品名称、货号、条码、规格、型号、产地、区域、货位、计价单位、可用库存、可用库存换算结果、账面库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、零售价、批发价、单价、金额、小单位、小单位单价、小单位数量、备注、价格等级8昵称（餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip）、单据自定义1(数字字段)~3(数字字段)、单据自定义4(文本字段)~5(文本字段)

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。

## 4. 列表页配置（双入口「历史」标签）

- 查询条件（对标系统实据）：日期、单据编号、往来单位、出库仓库、经手人、部门、单据状态、制单人、单据备注、打印次数
- 功能按钮（默认全选）：新增、刷新、批量打印、打印(F8)、导出、配置
- 按单据列（14 列，对标实据 2026-08-14）：单据日期、单据编号、单据状态、仓库、往来单位、往来单位编号、经手人、部门、数量、金额、单据备注、制单人、审核人、打印次数
- 按明细列（13 列）：单据日期、单据编号、商品名称、货号、单位、数量、单价、金额、批次条码、生产日期、到期日期、单据备注

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记账后单据生效扣减库存。
- 与销售出库单不同：无收/付款区、无摘要结账面板，仅「本单金额」汇总；往来单位非必填（内部出库可无往来对象）。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 批次管理列齐备（批次条码/生产日期/保质期/到期日期），出库需指定批次。
- 与其他入库单互为反向单据（一出/一入，页面结构完全一致，仅「出库仓库*/入库仓库*」差异）。
- 草稿在 分析→综合单据→业务草稿 中检索（销售域已确认该入口，仓储单据同体系，待复核）；记账后影响 分析→仓配分析→查库存/库存明细。
