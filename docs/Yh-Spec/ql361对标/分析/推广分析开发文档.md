## 1. 页面概述

- **列表查询页**（统计分析页）：职员商城分享推广效果漏斗（分享→浏览→下单→新客注册，按职员归集）；B2B 商城职员推广效果考核页。菜单路径：分析 → 采销分析 → 推广分析。
- 页面结构：查询区 + 汇总表格（合计行）+ 底部分页。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__推广分析.png`

## 4. 业务规范

### 统计口径（推广漏斗）

- **漏斗链路**：分享次数（职员转发商城商品/店铺链接）→ 浏览次数（客户打开链接）→ 下单笔数/下单金额（客户经链接下单转化）→ 新客注册（链接带来的新注册客户数）
- **归因口径**：订单与客户按分享链接来源归因到职员；分享类型区分（商品分享/店铺分享/活动分享等，下拉可选值待复核）
- **数据范围**：B2B 商城渠道的推广行为；本月实据仅 1 名职员开通推广（HC001）

### 与其他页面关系

- 取数：商城分享埋点 + 商城订单 + 商城客户注册；与《营销推广分析》（活动侧推广）互补
- 下游：职员推广提成/考核（《业务员提成》取数候选）
