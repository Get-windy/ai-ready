# 其他入库单开发文档

## 页面概述

其他入库单用于非采购业务的库存入库录单（赠品入库、盘盈外的其他入库等），与采购入库/销售退换货解耦。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 其他入库单列表页 | http://localhost:5656/erp/stock-in/index | 双入口「历史」标签 |
| 新增/编辑其他入库单表单页 | http://localhost:5656/erp/stock-in/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 注意页面配置按钮在页面顶部按钮区域，列配置一般都在页面内嵌的数据表（表单页的明细表、列表页的数据列表）

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5002 |
| menu_code | `erp:stock-in` |
| 主菜单路径 | `erp/stock-in/form`（点击进新增表单，`autoCreate`） |
| 标签「历史」路径 | `erp/stock-in/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-in/form`（表单）、`erp/stock-in/index`（列表） |

> 本次仓储菜单变更已将 5002 由单入口转为双入口，与其他出库单(5001)对称。

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记账后单据生效**增加**库存。
- 与采购入库单不同：无付/收款区、无摘要结账面板，仅「本单金额」汇总；往来单位非必填。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 批次管理列齐备（批次条码/生产日期/保质期/到期日期），入库可登记批次与效期。
- 与其他出库单互为反向单据（一入/一出，页面结构完全一致，仅「入库仓库\*/出库仓库\*」差异）。
- 草稿在 分析→综合单据→业务草稿 检索；记账后影响 分析→仓配分析→查库存/库存明细。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
