# 拜访检视开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/visit/review`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页（统计分析型）**：按职员汇总拜访量、任务完成率、订货/销售金额，外勤拜访三步流程（1.拜访规划 → 2.拜访执行 → 3.拜访检视）的第三步。
- 页面结构：查询区 + 工具按钮区 + 带分组表头的统计表格 + 左侧部门树 + 合计行 + 底部分页；子标签「拜访统计（本页）/ 拜访记录 / 职员汇总任务 / 签到统计 / 签到记录」。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels 实据，5 项）

- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止，与快捷段联动）
- 职员（弹窗选择）
- 部门（弹窗选择）
- 客户（弹窗选择）

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、导出、查询、跳转（分页）

### 打印配置

无（页面有打印(F8)按钮，打印模板配置细节待复核）。

## 3. 数据表格列配置

### 默认显示列（抓取 JSON columns 实据，19 列，含 1 个分组表头）

职员名称、所属部门、拜访客户总数、拜访总数、计划内拜访（分组表头：任务数量、完成数量、未完成数量、取消数量、完成率%）、计划外拜访次数、补录拜访次数、订货金额、退订金额、实订金额、销售金额、退货金额、新增客户、异常拜访次数

> 「完成率%」归属「计划内拜访」分组表头之下（截图确认）；「拜访总数」「完成率%」列头带指标口径提示图标，多列支持排序。

### 全部可配置列

无 XSMK 全量列依据（XSMK 目录无外勤拜访域文档），列配置弹窗全量字段待复核；其余 4 个子标签（拜访记录 / 职员汇总任务 / 签到统计 / 签到记录）的列结构抓取未覆盖，待复核。

## 4. 业务规范

- 指标口径（从列结构归纳，精确口径待复核）：
  - 拜访客户总数（去重客户数）vs 拜访总数（拜访人次），两个口径并存。
  - 计划内拜访由拜访规划生成任务（任务数量），执行后产生完成/未完成/取消，完成率% = 完成数量 ÷ 任务数量（推断）。
  - 计划外拜访次数 / 补录拜访次数支持计划外拜访与事后补录两类非计划拜访。
  - 实订金额 = 订货金额 − 退订金额（推断），来源于拜访中产生的销售订单与销售退货申请；销售金额 / 退货金额来源于实际销售出库/退货单据，与"订货"口径区分（订货≠出货）。
  - 异常拜访次数判定规则（定位偏离、超时停留等）待复核。
- 外勤三步流程：1.拜访规划（任务来源）→ 2.拜访执行（轨迹/签到来源）→ 3.拜访检视（本页，统计收口）。
- 订货金额/销售金额分别关联订货业务（销售订单/销售退货申请）与销售业务（销售出库单/销售退货单）单据数据；「新增客户」列关联客户档案（ERP 往来单位）。
