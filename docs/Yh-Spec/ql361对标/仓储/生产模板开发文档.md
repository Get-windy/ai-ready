# 生产模板开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-bom`（表单）+ `erp/stock-bom/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **主数据维护页**：成品物料清单（BOM）模板创建，定义成品与其原料构成及用量。页面性质 = 模板头字段区 + 原料构成明细表格 + 底部保存按钮；无单据编号行、无单据信息行，区别于业务单据表单页。
- **列表页**：双入口「历史」标签（查询条件与表格列待抓取弹窗数据后补全）。
- **双入口**：主菜单 → `erp/stock-bom`；标签「历史」→ `erp/stock-bom/index`。

## 2. 表单页配置

### 模板头字段（抓取 JSON filterLabels + cfg 页面配置实据）

必填：模板名称\*、成品名称\*、成品单位\*、成品数量\*；选填：口味、型号（cfg 页面配置实据）

全部模板头字段（6 个，cfg 实据 6 字段 ✅）：模板名称、成品名称、成品单位、成品数量、口味、型号

### 字段分组

模板头（模板名称/成品名称/成品单位/成品数量）→ 原料构成明细表格 → 保存。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、导出、保存 Ctrl+Enter（无保存草稿）

### 打印配置

无（抓取未覆盖打印配置弹窗，待复核）。

## 3. 数据表格列配置

### 默认显示列（9 列，抓取 JSON columns 实据）

操作、商品名称（带「扫描枪录入」开关）、货号、条码、计价单位、数量、成本均价、成本金额、备注

> 注：JSON columns 含两个抓取拼接串（首项「操作 商品名称扫描枪录入 关 货号」与「条码 计价单位 数量 成本均价 成本金额 备注」），均非真实单列，已剔除。

### 全部可配置列（22 列，cfg 实据 22 列 ✅）

操作、图片、商品名称、货号、条码、规格、型号、产地、品牌、单据自定义1(数字字段)~3(数字字段)、单据自定义4(文本字段)~5(文本字段)、计价单位、数量、成本均价、成本金额、小单位、小单位数量、小单位单价、备注

## 5. 业务规范

- 保存（Ctrl+Enter）即生效，无草稿/记账两段流程（区别于业务单据）。
- 成品数量\*：一个模板单位产出量；明细「数量」为单模板用量的原料耗用量。
- 成本均价/成本金额：原料成本参考，合计行汇总原料总成本。
- 模板是组装单/拆卸单的取数来源（推断：开组装单时选模板自动带出原料明细，待复核）。
- 下游使用方：组装单（按模板投料生产）、拆卸单（按模板拆解还原）；模板维护的成品/原料均来自 资料→商品管理→商品。
