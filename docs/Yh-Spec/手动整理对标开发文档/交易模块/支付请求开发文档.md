> **文档类型：** 页面对标复刻

> **对标来源：** 本系统交易模块「支付结算」组 → 支付请求（Menu 90301。**来源=对标实测抓取 2026-09-07**）
> **定位：** 按金标准结构编写；在线支付**支付单/支付请求**列表页（**单视图列表**，无独立表单，含详情抽屉 + 线下确认收款弹窗 + 4 张统计卡片）。即支付中台「支付请求」。

## 页面概述

支付请求是**在线支付单统一查询/处理**页：按业务类型、渠道、状态查询系统发起的支付请求（支付单），查看支付渠道、金额、状态、渠道订单号、创建/完成时间，并对线下渠道（现金/银行转账）的支付单做「确认收款」。（**无创建入口**——支付请求由业务流程调用 `/api/payment/request` 自动发起，本页只读查询 + 确认收款。）**单入口，无子 Tab，无独立表单**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 支付请求 | `payment/request` | 单视图列表页（统计卡片 + 3 查询字段 + 数据表） |

单入口：交易模块 → 支付管理 → 支付请求。

- 实测实据：数据表列 8、查询字段 3、列/页面配置弹窗 **无**。
- 状态机（`PAYMENT_STATUS_MAP`）：0 待支付 / 1 支付中 / 2 已支付 / 3 已取消 / 4 支付失败。
- 支付渠道（`PAYMENT_CHANNEL_MAP`）：ALIPAY 支付宝 / WECHAT 微信支付 / UNIONPAY 银联支付 / BANK 银行转账 / CASH 现金/线下。

## 页面结构（含配置）

支付请求 = 单视图列表页（无子 Tab，无列/页面配置弹窗）。查询区与按钮区为**固定项**。

### 统计卡片（固定 4 项）
待支付（status 0/1）、成功（status 2）、失败（status 3/4）、总金额（累计金额）。

### 查询条件字段（固定 3）
- 业务单号（文本框）
- 渠道（下拉：全部渠道/支付宝/微信支付/银联支付/银行转账/现金+线下）
- 状态（下拉：全部状态/待支付/支付中/已支付/已取消/支付失败）
- 查询、重置（按钮）

### 功能按钮 / 行级操作
- 头部按钮：刷新（F5）。
- 行级操作：**详情**（抽屉）、**确认收款**（仅 `status===1` 且渠道为 `CASH`/`BANK` 时显示；弹窗填收款单号 → `/request/{id}/confirm`）。

### 数据表列（固定 8 列）
业务类型、业务单号、支付金额（¥ 绿色）、支付渠道（Tag）、渠道订单号、状态（Tag）、创建时间、操作（详情/确认收款）。

## 业务规范说明

- **支付主线**：业务单据（bizType + bizId + bizNo）→ 本页生成支付单（taker：`/api/payment/request`）→ 渠道下单（orderNo/tradeNo）→ 回调 `POST /api/payment/callback/{channel}` 落支付记录并更新状态 → 本页可查。
- **金额口径**：支付金额 = 本次支付单金额；不同渠道含最小/最大限额（`/api/payment/channels?amount=`）。
- **渠道**：支付宝/微信/银联/银行转账/现金；现金、银行转账走**线下确认收款**（`/request/{id}/confirm`，需填渠道订单号）。
- **状态流转**：待支付 → 支付中 → 已支付（回调成功）；可取消（`/request/{id}/cancel`）；支付失败（status 4）。
- **下游**：支付成功回调后关联业务单据回款（`bizNo`）。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/payment/request/list.vue`
- API：`apps/pc-admin/src/api/payment/index.ts`（`paymentApi`）
- 后端：`backend/core/payment/core-payment/.../PaymentController.java`（`@RequestMapping("/api/payment")`：`POST /request`、`GET /request/page`、`GET /request/{id}`、`POST /request/{id}/cancel`、`POST /request/{id}/confirm`、`POST /callback/{channel}`、`GET /record/page`、`GET /channels`）
- 表：`payment_request`（V8.10.0__Payment_Center_Tables.sql）

### 页面对齐（当前：`BillTableList`）
- **单视图列表**：当前无子 Tab、无独立表单，符合「单入口列表」定位。
- **查询区（3 字段）**：业务单号、渠道、状态（已对齐本系统业务需要，但无「页面配置弹窗」）。
- **数据表列（8 列）**：业务类型、业务单号、支付金额、支付渠道、渠道订单号、状态、创建时间、操作。
- **统计卡片（4 项）**：待支付/成功/失败/总金额（仅基于当前页数据实时统计，非全局汇总）。
- **行级操作**：详情（抽屉）、确认收款（线下渠道，弹窗填单号）。
- **无创建入口**：支付请求由业务回调自动化生成；本页不提供手写新增。
