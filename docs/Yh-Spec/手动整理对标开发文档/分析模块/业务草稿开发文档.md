## 1. 页面概述

业务草稿是**跨业务域「草稿」状态单据的统一台账**：集中存放各业务域已保存但尚未过账的单据，供操作员批量提交记账（过账）或删除。**单入口、单视图**（无页内 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 业务草稿 | `analytics/draft` | 单视图列表页（跨 13 类单据聚合草稿箱 + 批量过账/删除） |

单入口：分析 → 综合单据 → 业务草稿。

- 页面结构：查询方案 + 时间快捷段 + **三行查询区** + 草稿台账表格（首列红色齿轮列配置入口 + 序号线 + 行勾选框 + 固定「操作」列）+ 底部合计行 + 分页条。
- 实测实据（2026-09-15）：共 **5** 条记录、**1/1** 页、每页显示 **20** 行、底部合计 **1,145**。全部为「销售出库单」（`XSCKD-20260915-0xx`），行级动作为「删除 / 复制」。
- 多 Tab 判定：实测 JSON `tabs` 为 `{}`（空对象），`.png` 顶部仅一个「业务草稿」页签 → **单视图，无子 Tab**。

## 4. 业务规范

### 统计口径与数据关系

- **数据范围**：全部业务域已保存但**未过账**的草稿单据（各业务域表单页 `Ctrl+S` 保存草稿），一行一单，`金额` = 单据金额原值；底部合计对当前过滤范围求和。
  - 后端实现为 13 个单据分支的 UNION 聚合（`DocQueryService.java` 的 `BRANCHES`，`DocQueryService.java:50-127`），`StatusMode.DRAFT` 时逐类取草稿态，例如销售订单 `status = 0`（`草稿`）、销售出库单 / 销售退货单 / 采购订单 / 采购入库单 / 采购退货单 / 收款单 / 付款单 / 调拨单 / 报损单 / 报溢单 `status = 0`、费用申请单 `status = 'DRAFT'`。
- **来源订单列**：草稿由订单下推生成时记录来源订单号（本批次实测该列均为空，即 5 单均为手工开单）。
- **提交记账（过账）**：草稿过账后成为正式单据，从本页消失并进入《经营历程》；勾选 `过账时自动修改单据日期为当前登录日期` 时，过账日替换原单据日期（跨期补录场景）。
- **组内分工**（综合单据组三页 = 单据生命周期的三个横切状态）：
  业务草稿（未过账）→ 提交记账 → 经营历程（已过账流水）；需审批的单据类型过账后先进入《待审批单据》。
- 单据类型实测：本批 5 条全部为销售出库单（`XSCKD-`）；基准文档另记收款单（`SKD-`）、采购入库单（`CGRKD-`）亦会出现。

### 与其他页面关系

- **上游**：各业务域表单页「保存草稿」（销售订单 / 销售出库单 / 采购入库单 / 收款单等）。
- **下游**：提交记账 → 经营历程（需审批者先入待审批单据）；单据编号链接 → 打开对应单据表单页（草稿态可继续编辑）。
- **同组页面**：待审批单据、经营历程。

## 5. 实现差异说明

> 本节按当前源码回写（本轮未改动源码）。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/draft/index.vue`（共 103 行）。
- **骨架**：`ARReportPage` 只读报表壳（`index.vue:2-23`，`title="业务草稿"`、`export-file-name="业务草稿"`、`row-key = docTypeCode-docNo`）。`ARReportPage` 为纯报表壳（`components/ARReportPage/ARReportPage.vue`：内联查询表单 `:16-64` + `a-table` `:100-120` + 内置分页 `:234-240` + 内置 CSV 导出 `:340-371`），**不含** `BillDetailTable` / `StandardPagination` / `PageConfigPanel`，**无列配置齿轮、无页面配置弹窗**。
- **查询条件**：`queryFields`（`index.vue:48-53`）= `单据类型`（select，13 项，`DOC_TYPE_OPTIONS` 见 `:32-46`）、`单号`（input）、`往来单位`（input）、`业务日期`（date-range）。**共 4 项**。
- **列定义**：`columns`（`index.vue:56-64`），共 **7 列**：单据类型、单号、业务日期、往来单位、金额、状态、操作人。
- **状态着色**：`statusColor()`（`index.vue:67-74`）；金额格式化 `formatMoney()`（`:76-79`）。
- **数据请求**：`fetcher`（`index.vue:82-84`）→ `docQueryApi.draftDocsPage`。
- **统计卡片**：`statCards`（`index.vue:89-97`）在 `onLoaded`（`:99-101`）后基于**当前页记录**计算「草稿总数」+「本页金额合计」—— **本系统新增，对标无此区域**（且「本页金额合计」只统计当前分页，非全量合计）。
- **行选择**：**禁用**（`ARReportPage` 的 `enableRowSelection` 默认 `false`，`ARReportPage.vue:199`；本页亦未传该 prop）→ 无勾选框、无批量提交记账 / 删除。
- **数据来源**：`apps/pc-admin/src/api/analytics.ts` → `docQueryApi.draftDocsPage`（`analytics.ts:94-96`，`GET /docquery/draft-docs/page`）。
- **后端**：`backend/core/api/core-api/src/main/java/cn/aiedge/docquery/controller/DocQueryController.java:80-91`（`@RequestMapping("/api/docquery")`，`draftDocs`）；服务层 `docquery/service/DocQueryService.java:144`（`page(..., StatusMode.DRAFT, ...)`）。
- **storage-key**：无（未使用列配置 / 页面配置持久化）。

### 剩余缺口

1. **🔴 未达金标准（骨架层）**：本页为 `ARReportPage` 只读壳，未使用 `CategoryListLayout` / `BillDetailTable` / `StandardPagination` / `PageConfigPanel`；无列配置齿轮、无页面配置弹窗。（按本页对标规格，达标线 = 查询区齐全 + 列配置可用 + 分页 + 行级操作，本页仅命中「分页」一项。）

3. **🔴 行级操作缺失**：对标行级「删除 / 复制」无实现；`columns` 中无「操作」列。
4. **🔴 批量动作缺失**：对标 `提交记账` / `删除` 无实现（且 `enableRowSelection=false`，连勾选都没有）。
5. **🔴 查询条件不对齐**：对标 11 项 + 1 勾选（查询方案 / 时间快捷段 / 日期范围 / 单据编号 / 单据类型 / 往来单位 / 仓库 / 经手人 / 部门 / 制单人 / 单据备注 / `过账时自动修改单据日期为当前登录日期`），本页仅 **4 项**；缺 `仓库`、`经手人`、`部门`、`制单人`、`单据备注`、查询方案、时间快捷段、过账改日期勾选项。

8. **打印：非缺口**：对标本身无「打印(F8)」，本页无打印即对齐。
9. **本系统多出的统计卡片区**：`statCards`（`index.vue:89-97`）为**本系统新增**，对标页无卡片区 —— 属超出对标范围的自加能力，不计入缺口，但亦不构成「对齐」。
10. **无 E2E 脚本**：`tools/` 下**无** `e2e-analytics*.cjs` —— 本页**未跑过** E2E，如实标注。
