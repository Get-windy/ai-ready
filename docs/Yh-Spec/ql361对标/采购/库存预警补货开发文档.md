## 业务规范说明

### 状态流转与特殊交互

- **缺货数量公式**（页面提示条实据）：缺货数量 = 库存上限 + 待发货 − 账面数量 − 待收货；公式旁的"点击设置"可进入设置（设置内容待复核）
- **预警类型**列：与"只显示下限预警的商品"勾选项对应，商品库存触及库存下限（或上限）即进入本表；预警类型枚举值待复核
- **采购按钮**：勾选表格行后点击"采购"，将选中商品转入采购流程（生成采购订单的具体跳转与携带字段待复核）
- 商品分类树：点击分类节点过滤表格商品
- 本页是采购准备四页中唯一带"仓库编号/仓库名称"列的页面：预警按"仓库 × 商品"粒度计算

### 与其他页面关系

- 下游：采购按钮 → 采购订单（具体生成方式待复核）
- 数据依赖：商品库存上下限（商品/仓库主数据）、账面库存、待发货（销售）、待收货（采购在途）
- 同组姊妹页：缺货补货（按销售订单缺口）、智能补货（按日均销量推算）、以销定购（按销售订单逐单转采购）

### 供应商来源

供应商来源通过 ERP 模块的往来单位下的供应商分类处理。
