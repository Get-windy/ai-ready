## 业务规范说明

### 统计口径（期初+借贷=结存）

- **恒等式**：期末余额 = 期初金额 + 借方 − 贷方（逐行成立：现金库存 6,293.33+31,879−17,525=20,647.33 ✅；合计 -588,024.12+1,342,908.75−1,110,782.1=-355,897.47 ✅）
- **科目层级**：一级科目（1001 现金库存/1002 银行存款）+ 二级账户科目（1001xx/1002xx），一级行为下级合计（现金库存 6,293.33=186+5,161.33+946 ✅）
- **贷方余额账户**：信用卡/花呗/快E贷等信贷类账户期初为负（农行信用卡 -8,665.64、农行快E贷 -100,000）
- **日期类型**：单据日期（默认）/其他日期口径（可选值待复核）

### 与其他页面关系

- 取数：收款单/付款单/预收/预付/提现存现转款等资金单据（经营历程流水）按账户归集
- 联查：行级"对账"→ 账户资金流水（本页资金流水视图/《明细账》1001-1002 科目）
- 同源页：《经营分析》（收支损益口径）、财务域《总账》（同一科目体系）
