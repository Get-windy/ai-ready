## 11. 附录

### 11.1 检查脚本示例

```bash
# 检查容器状态
docker ps --filter "name=monitoring" --format "{{.Names}} {{.Status}}"

# 检查服务健康
curl -s http://localhost:9090/-/healthy | grep -q "ok" && echo "Prometheus OK" || echo "Prometheus ERROR"

# 检查监控目标数量
curl -s http://localhost:9090/api/v1/targets | jq '.data.targets | length'
```
