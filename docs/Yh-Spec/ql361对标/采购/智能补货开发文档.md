## 业务规范说明

### 状态流转与特殊交互

- **计划采购数量公式**（页面提示条实据）：计划采购数量 = 备货天数 × 日均销售量 + 待发货数量 − 待收货数量 − 账面库存
- **日均销量**：按"销售日期"区间内的销售数量折算（区间天数口径待复核）
- **备货天数**：查询区必填输入，同时作为表格列回显（计算时逐行代入）
- **计划采购数量过滤**：查询区带 ≥ 比较符，可按计算结果阈值筛选（如只显示需要补货的商品）
- **采购数量列**：应为可编辑的建议采购量（是否可手工改后带入采购单，待复核）
- **采购按钮**：勾选表格行后点击"采购"，将选中商品按采购数量转入采购流程（生成采购订单的具体跳转与携带字段待复核）

### 与其他页面关系

- 数据源：销售出库/销售订单（销量统计）+ 实时库存 + 采购在途（待收货数量）
- 下游：采购按钮 → 采购订单（具体生成方式待复核）
- 同组姊妹页：库存预警补货（按仓库上下限预警）、缺货补货（按订单缺口）、以销定购（按销售订单逐单转采购）

### 供应商来源

供应商来源通过 ERP 模块的往来单位下的供应商分类处理。
