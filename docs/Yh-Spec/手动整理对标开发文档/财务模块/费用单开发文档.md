## 页面概述

费用单用于**非主营支出的费用登记**（往来单位费用/内部费用两类）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 费用单表单页 | `finance/expense-doc/form`（主菜单入口） | 新增费用 + 费用项明细 |
| 费用单列表页（历史） | `finance/expense-doc/index` | 双入口「历史」标签 |

单号实据：`YBFYD-20260723-001`（`YBFYD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

### 双入口配置（本系统）
| 项 | 值 |
|----|----|
| 菜单 ID | 80115 |
| menu_code | `finance:expense-doc` |
| 主菜单路径 | `finance/expense-doc/form` |
| 标签「历史」路径 | `finance/expense-doc/index` |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `views/finance/expense-doc/form.vue`、`views/finance/expense-doc/index.vue` |

## 费用单列表页配置

### 数据表列（本系统实测 · 费用申请口径）

## 新增编辑费用单表单页配置

### 页面结构（自定义 `a-form`）
费用类型单选 → 表头字段区 → 费用项明细表格 → 备注区 → 单据信息 → 底部本单金额与操作。

### 表头字段
| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 费用类型 | 单选 | 是 | 往来单位费用 / 内部费用（默认往来单位费用） |
| 编号 | a-input | 是 | `YBFYD-` 前端生成 |
| 往来单位 | a-select | 是 | 带新增+搜索，带出往来编号 |
| 往来编号 | a-input 只读 | 否 | |
| 经手人 | a-select | 是 | 默认当前登录人 |
| 部门 | a-select | 否 | |
| 单据日期 | a-date-picker | 是 | 默认当天 |
| 付款账户 | a-select | 否 | |
| 付款金额 | a-input-number | 否 | 带「全/清」 |
| 更多账户 | a-input | 否 | 带「…」弹窗 |

### 费用项明细表格
操作、科目编号、科目名称、金额、备注。

### 工作流按钮
| 状态 | 按钮 | 动作 |
|------|------|------|
| 任意 | 保存草稿 Ctrl+S | `save` |
| 任意 | 记账 Ctrl+Enter | `confirm` |
