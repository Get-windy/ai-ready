# 上架单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`wms/putaway/form`（表单）+ `wh/putaway-order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=历史）：主按钮 → 新增/编辑表单页 `wms/putaway/form`；标签"历史"→ 列表页 `wh/putaway-order/index`。
- **表单页**：WMS 上架执行——收货后商品上架到货位（我方实现，views/wh/putaway-order/form/index.vue）。
- **列表页**：上架单台账（我方实现，views/wh/putaway-order/index.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `wh/putaway-order/index.vue`（3 项）

- `keyword` 单号（输入）
- `sourceType` 来源类型（输入）
- `status` 状态（下拉：WMS_STATUS_MAP 全部状态）

### 功能按钮

来源：我方源码 `wh/putaway-order/index.vue`

- 工具栏：新增上架单（跳转 `wms/putaway/form`）
- 行操作：查看、编辑（仅状态=待处理）、删除（仅状态=待处理，popconfirm 确认）

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段

来源：我方源码 `wh/putaway-order/form/index.vue`

- 必填：上架仓库\*（a-form-item required）、单号\*（保存时校验非空）
- 选填：来源类型、来源单据ID、备注

### 字段分组／录单默认值／打印设置

- 字段分组：单据头 → 上架明细 → 最近上架单
- 明细表格列（编辑态 9 列）：行号、商品、规格、单位、上架数量、来源货位、目标货位、批次号、操作
- 明细表格列（只读态 10 列）：行号、商品编码、商品名称、规格、单位、数量、来源货位、目标货位、批次号、状态
- 最近上架单列表列（8 列）：单号、来源类型、仓库、进度(上架/总)、状态、操作人、创建时间、操作
- 录单默认值：单号自动生成（PA 前缀 `genTaskNo('PA')`）、来源类型默认"收货上架"(0)
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（10 列，来源：我方源码 `wh/putaway-order/index.vue`）

单号、仓库、来源类型、总数量、已上架、执行人、状态、备注、创建时间、操作

### 全部可配置列（10 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `columns` 数组（10 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`wms/putaway/form`，标签按钮 list_path=`wh/putaway-order/index`，tag_label=历史（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- WMS 上架执行：收货后商品上架到货位；上游为收货环节（见《收货单开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
