# 单位显示开发文档

> **文档类型：** 页面对标复刻
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）商城模块
> **对标来源：** 顶部「商城」菜单 → 「基础业务」组 → 「单位显示」。**来源=对标实测抓取 2026-09-07**
> **定位：** 按金标准结构编写；商城商品「单位显示」设置（**单视图列表页**：左侧商品分类树 + 右侧商品列表，带「单位显示」勾选列）。即 XSMK 商城「单位显示」。

## 页面概述

单位显示是**商城在售商品单位显示设置**页：与「商品上架」同源商品列表，重在控制**该商品是否在商城显示**及显示时的单位（`单位显示`列 √/×）。**单入口，无独立表单，无子 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 单位显示 | `mall/unit-display` | 单视图列表页（分类树 + 商品列表 + 单位显示勾选列） |

单入口：商城 → 基础业务 → 单位显示。

- 实测实据：共 4543 条记录、每页 20 条；与「商品上架」共用同一商品分类树。
- 商品行含「单位显示」√/× 开关；本页与「商品上架」同源（商品列表），差异在**聚焦「单位显示」字段 + 批量显示/隐藏**。

### 配置功能说明
- **列表结构**：单位显示页为**商品类列表页**（分类树 + 商品数据表），**无**标准「页面配置」（查询条件/功能按钮 Tab 的配置齿轮）。
- **数据表列配置**：数据表右上角表头齿轮图标（`.icon-shezhi2`），弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**共 12 个可配置列**。
- ⚠️ **当前实现说明**：本页**尚未升级金标准组件**（当前为 `ARReportPage`，且内容为**商品单位字典**而非「商城商品单位显示设置」，见「实现差异说明 → 语义偏差」与「待完善」）。

## 业务规范说明

- **单位显示主线**：商城在售商品 → 本页控制「单位显示」开关（√=在商城显示该商品及其单位，×=隐藏）。
- **显示单位**：与商品基础资料的「单位」列关联（如 箱/盒/袋/包）；`单位显示类型` 区分显示粒度。
- **批量操作**：批量显示 / 批量隐藏对选中行生效。
- **同源性**：与「商品上架」共享同一商城商品列表；本页不做价格/上架开关配置，仅聚焦「单位显示」。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/mall/unit-display/index.vue`
- API：`apps/pc-admin/src/api/erp/product.ts`（`productUnitDictApi`：`/erp/product-unit-dict/page`、`/list`、`POST /`、`PUT /{id}`、`DELETE /{id}`）
- 后端：属 **product 模块**（`erp/product-unit-dict`），非 mall 模块。

### ⚠️ 语义偏差（重点）
- **对标（ql361）**：单位显示 = **商城商品单位显示设置**（商品列表 + `单位显示` 勾选列 + 批量显示/隐藏；与「商品上架」同源）。
- **本系统当前**：`ARReportPage` 呈现的是**商品单位字典 CRUD**（单位名称/助记码/单位类型/换算率/排序/状态/备注），数据表为 `erp_product_unit_dict`。**页面语义与对标不一致**，需重做为主题「商城商品单位显示设置」或拆分出独立的商城单位显示页。

### 页面对齐（已建成：`ARReportPage`，当前为单位字典）
- **单表列表**：当前为 `ARReportPage`，**无分类树、无单位显示勾选列、无批量显示/隐藏**。
- **查询区（1 字段）**：关键字（单位名称/助记码）。未对齐金标准固定查询项。
- **数据表列（8 列）**：单位名称、助记码、单位类型、换算率、排序、状态、备注、操作。
- **头部按钮**：新增单位（`header-extra`）。
- **行级操作**：编辑、启用/停用、删除。
- **状态**：`1` 启用 / `0` 停用。

### 待完善（非阻塞 · 建议对齐金标准）
