## 🔄 核心业务流程

### 流程1: 采购询价完整流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  开始       │     │  创建询价单  │     │  编辑询价单  │     │  提交审批   │
│  (Start)   │ ──→ │  (Create)  │ ──→ │  (Edit)    │ ──→ │ (Submit)   │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                   │
                                                                   ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  生成订单   │ ←── │  确认中标   │ ←── │  比价分析   │ ←── │  审批通过   │
│ (GenOrder) │     │  (Award)   │     │ (Compare)  │     │ (Approve)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                                                                   │
                              ┌─────────────────────────────────────┘
                              │ 审批驳回
                              ▼
                        ┌─────────────┐
                        │  修改询价   │
                        │  (Revise)  │
                        └─────────────┘
```

**流程说明**:
1. **创建询价单**: 采购专员填写基本信息和明细
2. **编辑询价单**: 在草稿状态下可多次修改
3. **提交审批**: 提交给采购经理审批
4. **审批通过**: 发布给供应商
5. **比价分析**: 收到报价后进行多维度比较
6. **确认中标**: 选择最优供应商
7. **生成订单**: 自动生成采购订单

---

### 流程2: 供应商报价流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  接收询价   │     │  查看详情   │     │  准备报价   │     │  提交报价   │
│ (Receive)  │ ──→ │  (View)    │ ──→ │ (Prepare)  │ ──→ │ (Submit)   │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                   │
                              ┌─────────────────────────────────────┘
                              │ 报价截止/撤回
                              ▼
                        ┌─────────────┐     ┌─────────────┐
                        │  等待结果   │ ──→ │  查看结果   │
                        │  (Wait)    │     │  (Result)  │
                        └─────────────┘     └─────────────┘
```

**流程说明**:
1. **接收询价**: 系统通知供应商有新的询价
2. **查看详情**: 了解采购需求和规格
3. **准备报价**: 填写价格、条款等信息
4. **提交报价**: 正式提交报价单
5. **等待结果**: 等待采购方评审
6. **查看结果**: 查看中标/落选结果

---

### 流程3: 报价评审流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  查看报价   │     │  初步筛选   │     │  详细评分   │     │  比价分析   │
│  (View)    │ ──→ │ (Screen)   │ ──→ │ (Score)    │ ──→ │ (Compare)  │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                   │
                                                                   ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  拒绝报价   │ ←── │  接受报价   │ ←── │  决策审批   │ ←── │  生成报告   │
│  (Reject)  │     │  (Accept)  │     │ (Decide)   │     │ (Report)   │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

**流程说明**:
1. **查看报价**: 查看所有收到的报价
2. **初步筛选**: 排除明显不符合要求的报价
3. **详细评分**: 对候选报价进行多维度评分
4. **比价分析**: 生成比价报告
5. **生成报告**: 输出决策参考报告
6. **决策审批**: 采购经理审批决策
7. **接受/拒绝**: 确认中标或拒绝其他报价

### 询价单状态机

```
                    ┌─────────────────────────────────────────────┐
                    │                                             │
                    ▼                                             │
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│          │    │          │    │          │    │          │   │

│ (DRAFT)  │    │(PENDING)│    │(PUBLISH)│    │(QUOTING)│   │
│          │    │          │    │          │    │          │   │
└────┬─────┘    └────┬─────┘    └────┬─────┘    └────┬─────┘   │
     │               │               │               │          │
     │ 编辑保存      │ 审批驳回      │ 关闭          │ 关闭      │
     │               │               │               │          │
     ▼               ▼               ▼               ▼          │
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│          │    │          │    │          │    │          │   │
│  草稿    │    │  草稿    │    │ 已关闭  │    │ 已关闭  │   │
│ (DRAFT)  │    │ (DRAFT)  │    │(CLOSED)  │    │(CLOSED)  │   │
│          │    │          │    │          │    │          │   │
└──────────┘    └──────────┘    └────┬─────┘    └────┬─────┘   │
                                     │               │          │
                                     │               │          │
                                     └───────────────┴──────────┘
                                                     │
                                                     ▼
                                               ┌──────────┐
                                               │          │
                                               │ 生成订单 │
                                               │(ORDER)   │
                                               │          │
                                               └──────────┘

取消流程:
┌──────────┐    ┌──────────┐
│          │    │          │
│  草稿    │───→│ 已取消  │
│ (DRAFT)  │    │(CANCEL)  │
│          │    │          │
└──────────┘    └──────────┘
```

**状态转换规则**:

| 当前状态 | 操作 | 目标状态 | 条件 |
|----------|------|----------|------|
| 草稿 | 提交审批 | 待审批 | 信息完整 |
| 待审批 | 审批通过 | 已发布 | 审批人通过 |
| 待审批 | 审批驳回 | 草稿 | 审批人驳回 |
| 已发布 | 供应商报价 | 报价中 | 收到第一个报价 |
| 已发布 | 关闭 | 已关闭 | 手动关闭或截止 |
| 报价中 | 关闭 | 已关闭 | 手动关闭或截止 |
| 已关闭 | 确认中标 | 生成订单 | 选择中标报价 |
| 草稿 | 取消 | 已取消 | 无关联报价 |

```
└────┬─────┘    └────┬─────┘    └────┬─────┘    └──────────┘
     │               │               │
     │ 撤回          │ 拒绝          │
     │               │               │
     ▼               ▼               │
┌──────────┐    ┌──────────┐        │
│          │    │          │        │
│ 已撤回  │    │ 已拒绝  │        │
│(WITHDRAW)│    │(REJECT)  │        │
│          │    │          │        │
└──────────┘    └──────────┘        │
     │                                │
     │ 重新提交                       │
     │                                │
     └────────────────────────────────┘
```

**状态转换规则**:

| 当前状态 | 操作 | 目标状态 | 条件 |
|----------|------|----------|------|
| 已提交 | 审查评分 | 已审查 | 采购员完成评分 |
| 已提交 | 撤回 | 已撤回 | 供应商主动撤回 |
| 已审查 | 接受 | 已接受 | 确认为中标 |
| 已审查 | 拒绝 | 已拒绝 | 未中标 |
| 已撤回 | 重新提交 | 已提交 | 在截止前 |

## 📝 业务规则清单

### B1. 询价单规则

| 规则ID | 规则描述 | 触发条件 | 执行动作 |
|--------|----------|----------|----------|
| B1.1 | 询价单号唯一性 | 创建时 | 检查数据库，重复则重新生成 |
| B1.2 | 截止日期校验 | 保存时 | 必须晚于当前时间24小时以上 |
| B1.3 | 明细数量校验 | 发布时 | 至少包含1条明细 |
| B1.4 | 供应商数量校验 | 发布时 | 至少邀请1家供应商 |
| B1.5 | 状态流转校验 | 状态变更时 | 只允许按状态机定义流转 |
| B1.6 | 自动关闭 | 定时任务 | 到达截止日期自动关闭 |
| B1.7 | 已报价不能取消 | 取消时 | 已有关报价则只能关闭不能取消 |

### B2. 报价单规则

| 规则ID | 规则描述 | 触发条件 | 执行动作 |
|--------|----------|----------|----------|
| B2.1 | 报价单号唯一性 | 提交时 | 检查数据库，重复则重新生成 |
| B2.2 | 截止前报价 | 提交时 | 必须在询价截止日期前 |
| B2.3 | 金额自动计算 | 保存时 | 自动计算金额、税额、总额 |
| B2.4 | 单项金额校验 | 提交时 | 每项金额 = 数量 × 单价 |
| B2.5 | 有效期校验 | 提交时 | 有效期必须晚于当前时间 |
| B2.6 | 评分计算 | 审查时 | 自动计算综合得分 |
| B2.7 | 中标互斥 | 接受时 | 同一询价单只能有一个中标 |

### B3. 权限规则

| 规则ID | 规则描述 | 角色 | 操作 |
|--------|----------|------|------|

| B3.2 | 询价单编辑 | 采购专员 | 仅草稿状态可编辑 |
| B3.3 | 询价单审批 | 采购经理 | 审批待审批的询价单 |
| B3.4 | 报价查看 | 供应商 | 查看自己提交的报价 |
| B3.5 | 报价提交 | 供应商 | 仅被邀请的供应商可报价 |
| B3.6 | 评分审查 | 采购专员 | 审查收到的报价 |
