## 业务规范说明

### 状态流转与特殊交互

- 数据粒度：一行 = 商品 × 单位；不同单位各自定价（截图实据：瓶/箱两行价格不同）
- 批量修改：勾选多行后按统一规则批量调价（弹窗未抓取，调整维度/公式待复核）
- 价格体系三层（按子标签实据归纳）：
  1. 商品价格批量修改：商品价格档案本体（批发价/零售价/最低售价 + 各价格等级价）
  2. 客户级别折扣设置：按客户级别设折扣
  3. 级别指定价设置：按客户级别对指定商品设价
  4. 客户指定价设置：按单个客户对指定商品设价
- 最低折扣(%)与最低售价：录单价格下限控制，与销售订单"折扣(%)/折后单价"联动校验

### 与其他页面关系

- 商品（档案）：价格随商品×单位维护；商品页默认列含价格等级列"餐饮店"，与本页同源
- 客户（客户级别）：客户级别折扣/指定价作用于客户档案的客户级别
- 销售订单/销售出库单：录单取价按"客户指定价 > 级别指定价 > 客户级别折扣 > 商品价格等级"优先级推断（推断，待复核）
- 销售价格跟踪（销售域）：记录最近成交价，与本页"最近进价"口径不同（一为售价跟踪、一为进价）
