## 一、审批流程总体架构

### 1.1 审批流程分类体系

| 流程类型 | 适用合同 | 审批层级 | 平均审批周期 | 风险等级 |
|----------|----------|----------|--------------|----------|
| **简易流程** | 金额<10万元，标准化合同 | 二级审批 | 1-3天 | 低 |
| **标准流程** | 金额10-50万元，常规合同 | 三级审批 | 3-5天 | 中 |
| **复杂流程** | 金额50-200万元，重要合同 | 四级审批 | 5-7天 | 高 |
| **战略流程** | 金额>200万元，战略合同 | 五级审批 | 7-14天 | 极高 |

### 1.2 审批节点角色定义

| 角色代码 | 角色名称 | 审批权限 | 审批重点 |
|----------|----------|----------|----------|
| CREATOR | 合同创建人 | 创建、提交 | 合同基本信息准确性 |
| BM | 业务经理 | 业务审批 | 业务条款合理性、商业价值 |
| LM | 法务经理 | 法务审批 | 法律合规性、风险控制 |
| FM | 财务经理 | 财务审批 | 财务条款、付款条件 |
| DM | 部门总监 | 部门审批 | 战略一致性、资源匹配 |
| CFO | 财务总监 | 财务终审 | 财务风险、预算控制 |
| CEO | 首席执行官 | 最终审批 | 战略重要性、公司利益 |

## 二、详细审批流程图

### 2.1 简易审批流程（二级审批）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   合同创建   │────▶│  业务经理    │────▶│  合同生效   │
│  (CREATOR)  │     │    (BM)     │     │             │
└─────────────┘     └─────────────┘     └─────────────┘
        │                   │
        ▼                   ▼
    [合同起草]           [业务审核]
        │                   │
    [基本信息]           [商业条款]
        │                   │
    [条款选择]           [风险评估]
```

**适用条件**：
- 合同金额：<10万元人民币
- 合同类型：标准化采购/销售合同
- 风险等级：低风险
- 审批时限：3个工作日内完成

**审批规则**：
1. 业务经理重点关注商业条款合理性
2. 如涉及特殊条款，可转标准流程
3. 审批通过后自动生效，无需其他审批

### 2.2 标准审批流程（三级审批）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   合同创建   │────▶│  业务经理    │────▶│  法务经理    │────▶│  合同生效   │
│  (CREATOR)  │     │    (BM)     │     │    (LM)     │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
        │                   │                   │
        ▼                   ▼                   ▼
    [合同起草]           [业务审核]           [法务审核]
        │                   │                   │
    [基本信息]           [商业条款]           [法律风险]
        │                   │                   │
    [条款配置]           [供应商评估]         [条款合规]
```

**适用条件**：
- 合同金额：10-50万元人民币
- 合同类型：常规采购/销售/服务合同
- 风险等级：中风险
- 审批时限：5个工作日内完成

**审批规则**：
1. 业务经理审核商业合理性
2. 法务经理审核法律合规性
3. 如有财务条款，增加财务经理审批
4. 所有审批通过后生效

### 2.3 复杂审批流程（四级审批）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   合同创建   │────▶│  业务经理    │────▶│  法务经理    │────▶│  财务经理    │────▶│  部门总监   │
│  (CREATOR)  │     │    (BM)     │     │    (LM)     │     │    (FM)     │     │    (DM)    │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
        │                   │                   │                   │                   │
        ▼                   ▼                   ▼                   ▼                   ▼
    [合同起草]           [业务审核]           [法务审核]           [财务审核]           [战略审核]
        │                   │                   │                   │                   │
    [完整条款]           [商业评估]           [风险控制]           [预算审核]           [资源匹配]
        │                   │                   │                   │                   │
    [附件准备]           [供应商分析]         [条款优化]           [付款条件]           [战略一致性]
```

**适用条件**：
- 合同金额：50-200万元人民币
- 合同类型：重要采购/战略合作/技术服务合同
- 风险等级：高风险
- 审批时限：7个工作日内完成

**审批规则**：
1. 业务、法务、财务三部门联合审核
2. 部门总监进行战略层面审批
3. 如涉及技术条款，增加技术负责人审批
4. 重大合同需附风险评估报告

### 2.4 战略审批流程（五级审批）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   合同创建   │────▶│  业务总监    │────▶│  法务总监    │────▶│  财务总监    │────▶│    CEO     │────▶│  董事会    │
│  (CREATOR)  │     │    (DM)     │     │    (LM)     │     │    (CFO)    │     │             │     │ (可选)     │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
        │                   │                   │                   │                   │                   │
        ▼                   ▼                   ▼                   ▼                   ▼                   ▼
    [合同起草]           [战略审核]           [法务终审]           [财务终审]           [CEO审批]           [董事会备案]
        │                   │                   │                   │                   │                   │
    [完整方案]           [战略价值]           [终极风险]           [财务影响]           [公司利益]           [股东利益]
        │                   │                   │                   │                   │                   │
    [可行性研究]         [竞争分析]           [法律架构]           [投资回报]           [战略决策]           [最终批准]
```

**适用条件**：
- 合同金额：>200万元人民币
- 合同类型：战略投资、并购、重大技术引进
- 风险等级：极高风险
- 审批时限：14个工作日内完成

**审批规则**：
1. 需要附完整的商业计划书和风险评估报告
2. 法务总监和财务总监必须参与
3. CEO进行最终决策
4. 超过500万元需董事会备案或批准

## 三、智能审批路由规则

### 3.1 基于金额的自动路由

```yaml
路由规则:
  - 金额 < 10万: 简易流程 (CREATOR → BM)
  - 10万 ≤ 金额 < 50万: 标准流程 (CREATOR → BM → LM)
  - 50万 ≤ 金额 < 200万: 复杂流程 (CREATOR → BM → LM → FM → DM)
  - 金额 ≥ 200万: 战略流程 (CREATOR → DM → LM → CFO → CEO)
```

### 3.2 基于合同类型的特殊路由

| 合同类型 | 额外审批节点 | 审批重点 |
|----------|--------------|----------|
| **技术开发合同** | 技术总监(TD) | 技术可行性、知识产权 |
| **涉外合同** | 国际法务(IL) | 国际法律适用、汇率风险 |
| **政府合同** | 政府事务(GA) | 政策合规、政府关系 |
| **关联交易** | 审计部(AD) | 关联交易合规、价格公允 |

### 3.3 基于风险评分的路由调整

**风险评分模型**：
```
风险总分 = 金额风险(30%) + 合同类型风险(25%) + 合作方风险(25%) + 条款风险(20%)
```

| 风险总分 | 流程调整 |
|----------|----------|
| < 30分 | 降级一级审批（如复杂→标准） |
| 30-70分 | 按标准流程执行 |
| > 70分 | 升级一级审批（如标准→复杂） |

## 四、并行审批机制

### 4.1 条件并行审批

**适用场景**：
1. **技术+业务并行**：当合同包含明确技术规格时
   ```
   CREATOR
      ├─▶ BM (业务审核)
      └─▶ TD (技术审核)  [并行]
          └─▶ LM (法务审核)
   ```

2. **法务+财务并行**：当合同条款标准化程度高时
   ```
   CREATOR
      ├─▶ LM (法务审核)
      └─▶ FM (财务审核)  [并行]
          └─▶ DM (总监审批)
   ```

### 4.2 紧急审批通道

**适用条件**：
1. 紧急采购（设备故障、生产急需）
2. 战略客户紧急需求
3. 市场机会窗口期短

**审批时限压缩**：
- 简易流程：1个工作日内完成
- 标准流程：2个工作日内完成  
- 复杂流程：3个工作日内完成
- 战略流程：5个工作日内完成

## 五、审批提醒与催办机制

### 5.1 智能提醒规则

| 时间节点 | 提醒对象 | 提醒方式 | 提醒内容 |
|----------|----------|----------|----------|
| 提交后1小时 | 第一审批人 | 企业微信 | 新合同待审批 |
| 每日9:00 | 所有待审批人 | 邮件汇总 | 今日待审批清单 |
| 超时前24小时 | 当前审批人 | 短信+微信 | 审批即将超时 |
| 超时后每4小时 | 当前审批人+上级 | 电话+邮件 | 紧急催办通知 |

### 5.2 审批超时处理

| 超时时间 | 处理措施 | 责任人 |
|----------|----------|--------|
| 超时24小时 | 系统自动提醒 | 系统 |
| 超时48小时 | 转交备审人 | 系统/上级 |
| 超时72小时 | 升级至上级审批 | 系统自动 |
| 超时96小时 | 标记为异常流程 | 管理员 |

### 5.3 移动审批支持

**支持平台**：
1. **企业微信**：审批消息、快速审批、评论
2. **微信小程序**：全功能审批、附件查看
3. **手机APP**：离线审批、电子签名
4. **邮件审批**：回复特定格式邮件完成审批

### 6.2 审批数据监控

**关键监控指标**：
1. **平均审批时间**：各流程类型的实际审批时长
2. **审批超时率**：超时审批的比例
3. **审批退回率**：被退回修改的比例
4. **并行审批效率**：并行vs串行的时间对比

**改进措施**：
- 每月分析审批效率报告
- 识别瓶颈环节并优化
- 调整审批路由规则
- 优化提醒催办机制
