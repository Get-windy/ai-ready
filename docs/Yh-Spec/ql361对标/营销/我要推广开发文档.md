# 我要推广开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`marketing/promote-create`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页（复合页）**：推广动作发起端——6 个子标签（商品/优惠券/促销/拼团/秒杀/我的推广）+ 左侧商品分类树 + 商品列表，行级"分享"生成推广；商品子标签为默认视图。
- 截图：![我要推广](../../../../tool-results/ql361/pages/营销__营销推广__我要推广.png)

## 2. 页面配置

### 查询条件

- 商品（弹选）、品牌（弹选）、商品标签（全部）
- 筛选条件（商品名称/货号/条码/规格/型号 模糊检索）
- 左侧商品分类树（全部商品 → 饮品原料/低温熟食/调理冻品/米面制品/烘焙西点/预制品/常温食品/生鲜冻品/包装耗材/吧台用品/餐具器皿/餐饮设备/其他，14 个分类节点实据）按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：分享、推广设置、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：分享（操作列）；行勾选框（配合顶部"分享"按钮批量分享，待复核）
- 页面提示实据："仅支持分享已上架商品"——未上架商品不可分享

### 打印配置

页面有打印(F8)按钮；打印模板配置细节待复核

## 3. 数据表格列配置

### 默认显示列（16 列，抓取 JSON columns 实据）

操作、图片、商品货号、商品名称、品牌、规格、型号、产地、单位、库存、最近销售时间、新增时间、最近分享时间、分享次数、浏览人数、浏览次数

> JSON columns 首项"操作 图片 商品货号 商品名称"为抓取拼接串（表头合并单元格的文本拼接），非真实单列，已剔除，不计入列数。截图可见前 12 列（操作~新增时间），后 4 列（最近分享时间/分享次数/浏览人数/浏览次数）横向滚动，为推广效果回统计数据列。底部合计行为库存合计（抓取时点实据 199476.734）。

### 全部可配置列

待复核（未抓取列配置弹窗；优惠券/促销/拼团/秒杀/我的推广各子标签列结构与商品子标签不同，待复核）。

## 4. 业务规范

- 推广模型（实据归纳）：
  - 5 类可推广对象（子标签实据）：商品、优惠券、促销、拼团、秒杀——覆盖商城货与券、线下促销、商城玩法，与营销域各页一一对应（优惠券→优惠券页、促销→商品/整单促销、拼团→商城拼团、秒杀→商城秒杀）
  - 分享即推广：行级"分享"（及顶部"分享"批量入口）对选中对象生成推广链接/海报（具体形态待复核），分享给下游客户产生浏览与转化
  - 上架约束：仅支持分享已上架商品（提示条实据）
  - 效果回统计（列实据）：最近分享时间、分享次数、浏览人数、浏览次数——商品维度的推广热度直接呈现在列表，辅助选品推广
  - 我的推广子标签：当前操作员个人的推广记录（子标签实据，列结构待复核）
  - 推广设置（按钮实据）：推广参数配置入口（佣金/海报模板等待复核）
  - 商品列表即商城商品池：共 2534 条记录、商品分类树 14 节点（实据），与商城在售商品同源；库存列实时（合计 199476.734）
- 与其他页面关系：效果回溯（《推广历史查询开发文档》按分享时间/分享人/分享类型回溯推广明细与转化漏斗）；订单级溯源（订单处理中心默认列含"推广人"，销售域抓取实据——买家经推广链接下单后订单记录推广人，实现推广业绩归属）；分析域（营销分析 → 营销推广分析）；本系统落地对应推广活动 `/api/crm/marketing`（api/marketing.ts 实据）
