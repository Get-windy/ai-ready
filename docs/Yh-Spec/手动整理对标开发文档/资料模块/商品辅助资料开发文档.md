# 商品辅助资料开发文档

> **文档类型：** 页面对标复刻（金标准达成）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按资料模块金标准结构编写；商品辅助资料（品牌 / 单位 / 标签）多 Tab 组合页。
> **最后更新：** 2026-09-11（对标实测重抓 + 金标准改造完成）

## 页面概述

商品辅助资料用于维护**商品的辅助主数据**：品牌、单位、标签。为多 Tab 组合页（单入口，仅读列表 + 弹窗编辑）。

> **对标实测为 3 个子标签**：商品品牌、商品单位、商品标签。**无「商品分类」Tab**（与初稿/本系统改造前的 4 Tab 不同）—— 商品分类在 ql361 中由「商品」页的分类树承载，不在本页。

| 子标签 | 说明 |
|--------|------|
| 商品品牌 | 品牌名称/助记码/备注（新增/编辑） |
| 商品单位 | 商品单位/助记码/计量单位备注/是否默认（新增/单位组管理） |
| 商品标签 | 标签名称/对应商品（行内 修改/停用） |

菜单：资料 → 商品管理 → 商品辅助资料。

### 配置功能说明

- **3 Tab**：商品品牌、商品单位、商品标签；每 Tab 独立增删改。
- **数据表**：`BillDetailTable`（表头齿轮 = 列配置，个人配置 / 全局配置）。
- **无「页面配置弹窗」**：对标系统本页工具栏/查询区为界面固定项，无页面配置弹窗（实测无齿轮外的配置入口）。

**行级操作（源码 `columnMap.lkoperation.subConfig` 权威）**：**修改 / 停用·启用 / 删除**三项
（`content: "!#{flag}?'停用':'启用'"`，受 `columnPermission.modify` 控制）。
实测截图只看到「修改 / 更多」，是因为操作列宽 90px 且 `isEnableExpandOperate: true` —— **链接超宽时被网格折叠为「更多」**，并非菜单项本身叫「更多」。

**空行**：`paddingRowCount: 20` + `paddingEmptyRow: true` → 数据不足时补足 20 行。
**分页**：经典形态（首页 / 上页 / 第(x/y)页 / 下页 / 尾页 / 跳转到 N 页 / 共 N 条记录 / 每页显示 N 行）。

**实测数据（5 条）**

| 单位 | 单位关系 |
|------|---------|
| 袋,提,箱 | 1:12:48 |
| 袋,箱 | 1:32 |
| 个,件 | 1:12 |
| 个,提 | 1:12 |
| 盒,箱 | 1:48 |

> **结论（决定实现形态）**：单位组 = **商品多单位换算模板**，不是「命名单位集合」——
> 「单位」列是组内单位名逗号串（源码字段 `detailnames`），「单位关系」列是相对小单位的换算关系冒号串（源码字段 `detailunitrates`，首个恒为 1）。
> 对标列表**无组名列、无备注列**，新增表单**无名称输入项**。

## 业务规范说明

- **品牌**：`erp_product_brand`（`productBrandApi.page` 分页）；品牌名称必填，可用于商品表单「品牌」下拉。
- **单位**：`erp_product_unit_dict`（`productUnitDictApi.page` 分页）；该单位字典为**单位组内单位选择器**的数据源；`is_default` 标记默认单位。
- **标签**：`erp_mall_tag`；`status` 1启用/0停用；「对应商品」由 `erp_product.mall_tags`（逗号分隔标签串）反向聚合商品名。
- **单位组**：`erp_product_unit_group`（主表，只承载状态）+ `erp_product_unit_group_item`（明细：`unit_type` 小/中/大单位 + `unit_id` + `unit_name` + `conversion_rate` 换算关系）。
  单位组 = **商品多单位换算模板**（小单位=基准，换算关系 1；中/大单位换算关系必须 > 1）；组内单位通过 `unit_id` 引用单位字典，**不是单位字典副本**。
  列表「单位」= 单位名逗号串；「单位关系」= 换算关系冒号串（`conversion_rate` 去尾零后以 `:` 连接）。
- **单位组 → 商品**：商品表单「选择单位组」按组内 `unitType` 重设商品多单位明细「类型/单位名称/单位关系/换算关系」，实现下游闭环。
- **分类**：`erp_product_category`（树形），由「商品」页（`views/erp/product/index.vue`）承载，本页不含分类 Tab。
- **助记码**：品牌/单位支持按名称自动生成助记码（`useMnemonicCode`）；用户手工改动后不再被覆盖。
- **状态**：品牌/单位默认启用（status=1）；标签新建默认启用；单位组新建默认启用（status=1），支持「显示状态」过滤（已启用/已停用）。

## 最终裁决方案（2026-09-11 · 严格按此执行）

- **P0 辅助资料单一口径（红线）**：本页品牌/单位/标签为全局基础资料，商品主数据/销售/采购/仓储/财务统一引用，**严禁另建重复字典**。单位组成员通过 `unit_id` 引用单位字典，不复制单位数据。
- **P1 关联一致性**：品牌/单位/标签变更后实时反映到商品表单下拉与业务单，前后端口径一致。
- **P2 验收**：无桩/无模拟；各 Tab 增删改、单位组管理、导出闭环真实生效。

### 页面对齐（已建成）

- **3 Tab（对标）**：品牌/单位/标签，各自独立查询/增删改；**移除「商品分类」Tab**。
- **版式对齐（复用资料模块骨架）**：整页复用 `components/CategoryListLayout`（`:show-category-panel="false"`，本页无分类树），
  与客户 / 供应商 / 商品等资料模块页面**同一骨架**：深色居中 Tab 条 → 工具栏（左新增按钮组 / 右 刷新·打印(F8)·导出）→ 查询行（筛选条件 + 查询）→ 数据表（表头齿轮列配置）→ 分页。
  （初版为页面内自造 `aux-tab-bar/aux-toolbar` 版式，已在本次对齐中移除。）
- **列配置**：每个 Tab 独立 `storage-key`（`md-product-supplement-{brand|unit|tag}-columns`，单位组弹窗独立 `md-product-supplement-unit-group-columns`），个人配置 + 全局配置。
- **查询行样式自备**：骨架 `CategoryListLayout` 的 scoped 样式**不作用于**页面注入 `#search-fields` 插槽的内容，
  页面内需自行定义 `.search-row / .search-item / .search-label / .btn-search`（与客户 / 供应商页同一做法），否则查询行会纵向塌陷。
- **分页**：`StandardPagination` 传 `variant="classic"`（资料模块经典形态，对齐对标分页栏：首页/上页/第(x/y)页/下页/尾页/跳转/共N条/每页显示N行）。
- **弹窗校验对齐**：品牌名称\*/单位名称\*/标签名称\* 必填；助记码自动生成；备注限 30 字；保存(Enter)/取消(Esc)。
- **单位组管理**：按 2026-09-11 界面实测 + 2026-09-12 源码取证实现（弹窗 + 列配置 2 列 + 固定 3 行编辑表单 + 行内停用·启用 + 导出真实 xlsx + 20 行空行），
  见「页面配置」Tab 2-1 / Tab 2-2；`erp/product/form.vue` 的「单位组选择」已切换为按单位组带出多单位明细（Tab 2-3）。
- **打印**：F8 键 + 工具栏按钮触发浏览器打印（与资料模块同一口径）。
- **导出**：后端真实 xlsx 流（POI），与分页查询共用 keyword/status 过滤口径。

### 实现差异（与对标的显式取舍）

1. **标签 Tab 工具栏**：对标实测标签 Tab 工具栏/查询区为**空**（无任何按钮）。本系统**保留**与品牌/单位一致的工具栏（新增标签 / 刷新 / 打印(F8) / 导出）与查询行，以保证三 Tab「增删改」闭环可验收；对标空态疑为权限或空数据未渲染。**已记录为已知差异。**
