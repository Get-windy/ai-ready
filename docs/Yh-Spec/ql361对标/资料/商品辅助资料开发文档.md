- **列表页**：商品品牌/商品单位/商品标签三类辅助主数据维护页，3 个子标签（商品品牌 / 商品单位 / 商品标签），当前抓取为商品品牌子标签。

## 2. 页面配置

- 筛选条件（单文本框，占位提示未抓取到，匹配字段待复核）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据，商品品牌子标签）

操作、品牌名称、助记码、备注

> JSON columns 首项"操作 品牌名称 助记码 备注"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。商品单位/商品标签子标签列结构未抓取，待复核。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 助记码：品牌拼音首字母缩写（截图实据 SHBZ/YM/BDJY 等），用于录单快速检索
- 删除约束：品牌被商品引用后能否删除待复核（生产级口径：被引用主数据不允许物理删除）
- 商品单位：维护商品计价单位（瓶/箱/袋等），被商品档案"单位"、单据明细"计价单位"引用；多单位换算关系在商品档案按商品维护
- 商品标签：用于商品分组/营销筛选（实据不足，待复核）
- 与其他页面关系：商品（品牌/单位/标签被引用）、商品价格管理/图片管理（查询条件"品牌"来源）、销售订单等单据（品牌/单位随商品带出入库）
