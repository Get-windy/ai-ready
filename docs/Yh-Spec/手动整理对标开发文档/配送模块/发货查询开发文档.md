- **列表查询页**：**销售出库单（`XSCKD-`）台账**——发货环节已记账的出库单查询，回链来源销售订单（`XSDD-`），并含结算状态/已结金额对账口径。
- 单入口、单视图（无 Tab）、无新增按钮。

### 金额口径说明

- **本单金额** = 商品金额 − 促销优惠 − 优惠劵 − 直接优惠 + 运费 + 其他费用（隐藏列提供各构成项）。
- **已结金额 / 结算状态 / 产生方式 / 打印次数** 默认显示，用于发货单的收款对账。
- 产生方式：单据生成来源（如订单下推 / 手工新增）。

## 4. 业务规范

- **单据类型**：销售出库单 `XSCKD-`，编号后缀 `YYYYMMDD-序号`（与销售域编号规则一致）；来源订单号为 `XSDD-`。
- **回链**：来源订单列回链销售订单；与《物流发货》（订单处理中心 2.拣货/发货）是**上下游**：物流发货完成拣货/发货 → 生成并记账出库单 → 本页台账查询。
- **记账口径**：默认显示「打印次数」，隐藏列含记账人/记账时间/审核人，说明出库单走「制单 → 审核 → 记账」链路（记账后进入财务）。
- **结算口径**：结算状态 + 已结金额对应收款核销（见财务《收款单》《按单收款》）。
- **显示红冲**：勾选后显示被红冲的出库单。
- **物流口径**：物流公司、运单号、配送方式、配送状态、配送线路（后两者为查询固定项）。

### 实现要点（跨模块）

- **固定项「配送状态 / 配送线路」不在出库单上**：它们是配送任务（`dms_task`）的执行属性，因此新增
  `GET /api/dms/task/outbound-filter`（按 `source_bill_no` 反查出库单号 + 三值状态口径），页面再把结果作为
  `outboundNos` 传给 `/erp/sale/outbound/page` 精确过滤 —— **跨域只走接口，销售模块不 JOIN DMS 表结构**。
- 销售侧为**增量**改动：`SaleOutboundQueryDTO.outboundNos` + 条件装配一行（`null` 时行为完全不变，不影响《销售出库单》页）。
- 状态三值口径与《配送查询》一致：待配送 = 0/1/2，配送中 = 3/4，已配送 = 5/6（执行态 9 态只在对内执行侧展示）。
- 反查上限 5000 条，超出即 `truncated=true`，页面提示收窄条件（避免「假空列表」）。

### 6.3 待复核 / 遗留（非阻塞）

1. **打印模板**：`PrintDialog` 以 `page-code=ship-query` 取模板；当前 devdb 无打印模板记录，弹窗可打开但模板列表为空 ——
   需在《打印模板》侧补一条发货查询模板（与其它页面同一待办）。
2. **查询项默认显隐**：ql361 抓取未记录 25 项的默认勾选，本页默认显隐按**同一单据**《销售出库单》页口径对齐（日期/单据编号/客户/经手人/部门/仓库/结算状态/产生方式/来源订单/单据备注/显示红冲 = 可见）。

4. **「客户一票通」「附件」两列为对标保留列、本系统无表头数据源**：出库单实体（`SaleOutbound`）无 `customerTicket`，

   补数据源需给 `erp_sale_outbound` 加列并贯通创建链路，属销售出库单模块改造，**不在本页范围内**。
