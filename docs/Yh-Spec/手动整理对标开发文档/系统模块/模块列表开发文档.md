- **无 `deleted` 列** → 逻辑删除**不适用**（与 `sys_module` 不同）；
- **无 `UNIQUE(module_id, version)`** → 库里出现 **两组完全重复的 6 行**（`id=1..6` 与 `7..12` 逐列相同）；
- `release_time` 允许 NULL（`draft` 行实测为 NULL）→ 列表 `ORDER BY release_time DESC` 在 PostgreSQL 下是 **NULLS FIRST** → **草稿排最前**（与《模块版本开发文档》§10.1-⑧ 同一结论）；
- **实体映射**：`cn.aiedge.module.model.SysModuleVersion`，`@TableName("sys_module_version")`（`:14`）。
