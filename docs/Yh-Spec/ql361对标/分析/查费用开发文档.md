## 业务规范说明

### 统计口径（费用归集矩阵）

- **费用金额 = 各维度列之和**（销售费用 5.21 = -217.26+175.4+47.07 ✅）；部门列负值为该部门费用红冲/退回净额
- **科目体系**：6601 销售费用、6602 管理费用、6603 财务费用、6711 营业外支出（与《经营分析》三费同源）
- **层次结构**：勾选"显示层次结构"后费用科目按层级呈现（父科目带子科目展开，文件夹图标）
- **包含红冲**：勾选后红冲费用单并入（负数冲减）
- **四视图**：按部门（部门矩阵）/按职员（职员矩阵）/按明细（单据级费用明细）/按往来单位（费用对象矩阵）

### 与其他页面关系

- 取数：费用单/其他支出单 + 随单费用（经手部门归属）
- 下游：《经营分析》（三费汇总口径）；同源：财务域《费用单》
