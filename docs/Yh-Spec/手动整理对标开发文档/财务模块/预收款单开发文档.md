## 页面概述

预收款单用于**先收客户货款、后抵应收**的预收款登记。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 预收款单表单页 | `finance/advance-receipt/form`（主菜单入口） | 新增预收 + 收款账户明细 |
| 预收款单列表页（历史） | `finance/advance-receipt/index`（list_path `finance/advance-receipt`） | 双入口「历史」标签 |

> 注：`finance/pre-receipt` 与 `finance/advance-receipt` 双目录，菜单沿用 `advance-receipt`（`/erp/pre-receipt/page` 接口），`pre-receipt` 目录对应关系待复核。

- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区域（列表页为 Vue「查询条件/功能按钮」配置弹窗；表单页为 dojox「页面配置/打印设置」弹窗），列配置在数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）。

## 业务规范说明

- **预收"收→抵→退"主线之"收"**：本页为预收余额标准入口；《收款单》「使用预收款」为"抵"；销售退货单「退回预收款」为"退"。
- **记账生效**：记账后结算单位"预收余额"增加（此前预收为记账前余额快照）。
- **一单多账户**：明细可填多行不同收款账户（现金/银行/微信等），本单金额=Σ收款金额。
- **本单赠送金额**：充值赠送计入预收余额但不计资金账户。
- **账户主数据**：收款账户来自资料 → 财务账户 → 银行账户。
- **待确认通道**：线上/代收渠道预收先入《待确认款项》"预收款待确认"，确认后入账。
- **记账生成凭证**：会计凭证（KJPZ-），总账科目 2203 预收账款。

- **P0 预收"收→抵→退"（红线）**：预收款单为预收余额唯一标准入口（"收"），**严禁绕过预收款单改预收/应收余额**；《收款单》「使用预收款」为"抵"，销售退货退预收为"退"。

- **P1 待确认通道**：线上/代收渠道预收先入《待确认款项》预收待确认，确认后入账。
- **P2 验收**：无桩/无模拟；记账生效、凭证、一单多账户、待确认通道需真实数据闭环验证。
