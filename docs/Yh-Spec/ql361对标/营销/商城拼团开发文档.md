## 4. 业务规范

- 拼团模型（列实据归纳）：
  - 活动维度：一行 = 一个拼团活动（活动ID 系统编号 + 活动名称），按起始/结束时间窗生效；活动状态随时间流转（待开始/进行中/已结束——同域商城预售、商城弹窗广告活动状态下拉枚举实据佐证，本页状态枚举待复核）
  - 成团要素：成团类型列（人数团/折扣团等取值待复核）；开团个数（已发起的团数）与成功团个数（达到成团条件的团数）成对统计——成功团个数/开团个数即成团率
  - 交易侧："拼团订单"子标签承接拼团产生的订单台账（子标签实据），成团/未成团订单的后续处理（发货/退款）规则待复核
  - 开团链路（推断，待复核）：商城买家以拼团价发起开团 → 邀请凑团 → 成团时限内人数达标则成团生效，未达标自动退款
- 与其他页面关系：商城域同组（商城秒杀限时抢、商城预售订金预售与拼团凑团享价并列商城三大玩法）；推广联动（我要推广可推广"拼团"活动）；本系统落地对应拼团 `/api/erp/marketing/group-buy`（api/marketing.ts 实据）
