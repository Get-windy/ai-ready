# 全部操作员开发文档

## 页面概述

| 页面 | 地址 | 说明 |
|------|------|------|
| 全部操作员 | 对标系统：https://22stable.ql361.com/desktop.html#/（桌面式多标签架构，页面以桌面标签打开，无独立路由）；本系统路由：http://localhost:5656/system/user（用户管理） | 系统登录账号（操作员）及其数据权限维护 |

## 业务规范说明

### 状态流转与特殊交互

- 操作员配额制：账号数受 license 限制（截图实据："您一共可添加5个操作员，已添加5个"），达上限后新增操作员应受限（待复核）
- 功能权限与数据权限分离：功能权限由岗位承载（岗位权限页）；数据权限在本页按操作员逐类设置——仓库权限、调拨权限、部门权限、往来单位权限、商品权限、现金银行权限、客户级别权限 7 类数据权限 + 操作员类型
- 权限值形态："全部仓库/所有仓库""所有权限""所有部门/未设置"等（截图实据），链接点击进入设置（推断，待复核）
- 操作员类型：普通操作员（截图实据，其他类型枚举待复核）
- 用户名与职员：操作员必须绑定职员（截图实据：用户名 干饭郎_刘洋洋 ↔ 职员 刘洋洋），职员档案在职员部门页维护

### 与其他页面关系

- 职员部门：职员"添加操作员"后在本页出现；部门树同源
- 岗位权限：操作员"岗位"列引用岗位档案，功能权限随岗位
- 仓库规划：仓库权限/调拨权限按仓库授权
- 各业务页面：数据权限过滤（如仅授权仓库的单据可见）
