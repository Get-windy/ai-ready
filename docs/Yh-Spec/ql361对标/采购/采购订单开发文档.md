## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）：草稿进入"业务草稿"，提交后进入审核流程（采购订单列表"单据状态"字段实据，XSMK）
- 采购订单收货后生成采购入库单（源单回链）；列表全量列含 订货数量/已收数量/未收数量/退货数量/退货金额（XSMK 依据）
- 订金账户1：订金是带使用条件的预收款或预付款；此前预付/此前欠款为该供应商往来余额回显
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入
- 退货走采购退货单（出库方向），换货走采购换货单

### 与其他页面关系

- 上游：采购准备四页（库存预警补货/缺货补货/智能补货/以销定购）的"采购"动作均落地为采购订单（生成细节待复核）
- 下游单据：采购入库单（收货入库）、采购退货单（退货出库）、采购换货单（换货）、采购费用分摊（费用计入采购成本，待复核）
- 关联定价：采购价格跟踪记录本单产生的供应商-商品价格（采购查询组页面，待复核）

### 价格等级字段处理

餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip 这8个字段是用户对价格等级自定义的昵称，需按标准化产品价格等级处理。这些字段属销售侧价格体系，出现在采购订单全量可配置列中疑为对标系统列配置复用所致，实现时应剥离（XSMK 已记录同问题）。

### 供应商来源

供应商来源通过 ERP 模块的往来单位下的供应商分类处理。
