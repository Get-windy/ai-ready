# 总账开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/general-ledger`（列表查询页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- 列表查询页（账簿查询：查询区 + 汇总表格；每科目按期初/本期合计分行呈现），按科目+会计月汇总借贷发生额与余额的总分类账查询。
- 单入口：菜单 财务 → 账簿 → 总账。
- 数据实据（截图）：1001 现金库存（期初 6,293.33 → 期末 20,647.33，本期借 31,879 / 贷 17,525）、1002 银行存款（-594,317.45 → -378,725.29）、1122 应收账款（628,597.22 → 605,564.48）、1123 预付账款、1405 库存商品、1601 固定资产、2202 应付账款（贷方向）、2203 预收账款（贷）、2204 预订货款（贷 2,000）、4000 期初资本（贷 1,084,412.7）、6001 主营业务收入（期初方向"平"，本期贷 780,123.83）、6051 其他业务收入；方向列取值：借/贷/平。

## 2. 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（会计月(止)）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 会计月(起)、会计月(止)、科目层级（默认 1，控制科目展开级次）
- 勾选项：无发生额不显示本期合计、显示本年累计、显示当前总计
- 布局（截图）：查询区两行——第一行查询方案 + 工具栏按钮，第二行查询条件 + 勾选项

### 功能按钮

按抓取 JSON buttons 实据：刷新、打印(F8)、导出、明细对账、查询

- "明细对账"：总账与明细账核对（与科目余额表页同名单按钮一致，核对口径待复核）。

## 3. 数据表格列配置

### 默认显示列（8 列，抓取 JSON columns 实据）

科目编码、科目名称、期间、摘要、借方、贷方、方向、余额

> JSON columns 首项"科目编码"经截图核对为真实首列，非抓取拼接串，计入列数。

### 全部可配置列

待复核（未抓取列配置弹窗）

### 行结构口径（截图实据）

- 摘要列取值：期初余额、本期合计（勾选"显示本年累计"时另有本年累计行；勾选"显示当前总计"时表尾加总计行）
- 方向列：借 / 贷 / 平（期初无余额的损益类科目方向为"平"）
- 余额列：随方向取值（借方向余额为正资产口径；贷方向为负债/权益口径）

## 4. 业务规范

- 取数逻辑：数据源自会计凭证（KJPZ-）记账后的分录汇总，按科目 × 会计月聚合借/贷发生额，期初余额=上期期末余额。
- 科目层级：默认 1 级科目；调大层级展开至末级明细科目（层级深度随会计科目主数据）。
- 表格结构（截图）：每科目占两行（期初余额行 + 本期合计行，期间列均为 2026-07，科目编码/名称仅首行显示）；无分页栏（一次全量呈现）。
- 与其他页面关系：上游《会计凭证开发文档》（手工录入 + 业务单据自动生成两条凭证来源）；联查《明细账开发文档》（按科目逐笔）；核对《科目余额表开发文档》（同一数据源的不同汇总维度）、"明细对账"按钮；报表：汇总结果供《资产负债表开发文档》《利润表开发文档》取数；期间约束《月结开发文档》（已结账期间数据锁定）；本系统前端目录 `finance/general-ledger`（dynamicRoutes.ts 实据）。
