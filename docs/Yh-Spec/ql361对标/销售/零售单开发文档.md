# 零售单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/retail/form`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **表单页（收银复合页）**：门店零售开单收银，支持简易模式与 POS 收银模式，编辑模式为新增模式加 id。
- 页面结构：表头字段区 + 商品明细表格 + 左下优惠区 + 右下收款面板 + 挂单/记账操作 + 单据信息行。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：客户\*（默认"皇朝门店散客零售"，带会员卡标识）、出库仓库\*（默认"配送中心"）、经手人\*、单据日期\*、销售类型\*（默认"正常销售"）
- 选填：会员卡号（输入卡号/电话号码识别）、商品（条码/名称/编码 F1 快速录入框）

### 全部表单字段（XSMK《零售单开发文档》依据，36 个）

- 基本信息：编号、客户、客户编号、开户行、银行账号、税号、会员卡号、出库仓库、经手人、部门、单据日期、销售类型
- 扩展/快录：自定义字段1~5、商品
- 优惠区：直接优惠、优惠券、促销优惠、此前积分
- 收款区：组合收款、应收金额、可用预收、预收余额、找零金额、收款方式1、收款金额、收款方式、收款码、收银员
- 单据信息：单据备注、制单人、制单时间、打印次数

### 字段分组

顶部基本信息（客户/会员卡号/出库仓库/经手人/日期/销售类型/商品快录）→ 商品明细表格 → 优惠区（直接优惠/优惠券/促销优惠/此前积分）→ 收款面板（多支付方式 + 组合收款）→ 备注区 → 单据信息行。

### 录单默认值

客户默认"门店散客零售"、出库仓库默认"配送中心"、经手人默认当前登录人、销售类型默认"正常销售"、单据日期默认当天（截图确认实据；配置弹窗明细待复核）。

## 4. 业务规范

- 挂单（F3）：把未完成的单暂存挂起，可稍后取单继续；记账（Ctrl+Enter）：完成收银并记应收/收款。
- 组合收款：一单可同时用现金/银行卡/预收款/转账等多种支付方式合并收款，找零金额自动计算。
- 会员卡号输入卡号或电话号码即识别会员，联动积分（此前积分/产生积分/使用积分/兑换积分）与会员价。
- 商品快速录入框支持条码/名称/编码三种匹配（F1 聚焦），配合明细表"扫描枪录入"开关，适配门店扫码收银。
- 简易模式（开）为简化表单，POS 收银模式为全屏收银界面（XSMK 已实现三种模式）。
- 零售单记账后进入销售单据查询（单据类型=零售单），参与销售明细查询与毛利统计；预收款收款方式关联客户预收余额（与 ERP 财务模块应收/预收打通）。
- XSMK《零售单开发文档》另有零售单列表页（按单据/按明细两个子标签），ql361 侧零售单历史通过销售单据查询检索（推断，待复核）。
