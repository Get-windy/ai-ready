# 借进单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`wh/borrow-in`（表单）+ `wh/borrow-in/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：向往来单位借入商品入库录单（后续需还出或借转采购），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 预计还出时间 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `wh/borrow-in`；标签「历史」→ `wh/borrow-in/index`。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + _desktop.tabBar + 截图确认）

- 必填：往来单位\*、入库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 表尾：预计还出时间（日期选择）
- 摘要区：本单金额（自动计算）

### 全部表单字段（14 个，cfg 实据 14 字段 ✅）

编号、往来单位、往来编号、入库仓库、经手人、部门、单据日期、摘要、预计还出时间、单据备注、制单人、制单时间、打印次数、本单金额：

### 字段分组

顶部基本信息（往来单位/入库仓库/经手人/单据日期）→ 商品明细表格 → 预计还出时间 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（19 列，抓取 JSON columns 实据）

操作、商品名称（带「扫描枪录入」开关）、货号、条码、货位、计价单位、可用库存、生产日期、保质期、到期日期、借进数量、换算关系、件散数量、大包装、中包装、小包装、借进单价、借进金额、备注

> 注：JSON columns 首项为表头拼接串（表头多单元格文本相连），非真实单列，已剔除。与借出单差异：无「批次条码」列（借进为新入库批次，批次在入库时生成；借出需选已有批次）。

### 全部可配置列（44 列，cfg 实据 44 列 ✅）

图片、商品名称、货号、条码、规格、型号、产地、区域、货位、计价单位、可用库存、可用库存换算结果、账面库存、生产日期、保质期、到期日期、借进数量、换算关系、件散数量、大包装、中包装、小包装、零售价、批发价、最低售价、借进单价、借进金额、小单位、小单位单价、小单位数量、备注、价格等级8昵称（餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip）、单据自定义1(数字字段)~3(数字字段)、单据自定义4(文本字段)~5(文本字段)

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。

## 4. 列表页配置（双入口「历史」标签）

- 查询条件（对标系统实据）：日期、单据编号、往来单位、仓库、经手人、部门、单据状态、还出状态（还出数量/还出金额/借转采购数量/借转采购金额列实据，XSMK 依据）
- 功能按钮（默认全选）：新增、刷新、打印(F8)、导出、配置
- 按单据列（19 列，对标实据 2026-08-14 + XSMK 依据）：单据日期、单据编号、单据状态、仓库、往来单位、往来单位编号、经手人、部门、借进数量、借进金额、预计还出时间、已还数量、已还金额、借转采购数量、借转采购金额、单据备注、制单人、审核人、打印次数
- 按明细列（14 列）：单据日期、单据编号、商品名称、货号、单位、借进数量、借进单价、借进金额、已还数量、已还金额、批次条码、生产日期、到期日期、单据备注

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后借进商品入库存（借进库存，与自有库存区分）。
- 预计还出时间：承诺归还日期，供借进借出查询跟踪逾期（查询页有还出数量/借转采购数量列实据）。
- 借进后续两条出路（借进借出查询列实据）：还出（还出数量/还出金额）或借转采购（借转采购数量/借转采购金额，转为正式采购入库）。
- 往来单位必填（借进必有出借方，区别于其他入库单往来单位非必填）。
- 反向单据：借出单（借出给往来单位，预计还回时间）；台账查询：借进借出查询（借进商品查询/借出商品查询双子标签）；借转采购后关联采购业务（采购入库体系，待复核）。
