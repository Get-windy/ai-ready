# 业务草稿开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/draft`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：全业务域未过账草稿单据的统一汇总台账，支持批量提交记账/删除（草稿箱）。菜单路径：分析 → 综合单据 → 业务草稿。
- 页面性质：综合单据组三页分别对应单据生命周期"审批中/草稿/已过账"三个横切状态，本页为草稿态。
- 页面结构：查询区（三行）+ 草稿台账表格（首列红色齿轮列配置入口 + 行勾选框，操作列行级"删除/复制"，单据编号链接）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__综合单据__业务草稿.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图/bodyPreview 实据的全量展开项）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号、单据类型（下拉，默认"全部单据"）、往来单位、仓库、经手人
- 部门、制单人、单据备注
- 勾选项：过账时自动修改单据日期为当前登录日期

### 功能按钮（抓取 JSON buttons 实据）

- 刷新、提交记账（勾选草稿后批量过账：草稿 → 正式单据，进入经营历程）、删除（勾选后批量删除草稿）、更多（折叠其余批量动作，具体内容待复核）、查询、跳转（分页跳转）
- 行级操作（截图实据）：删除、复制

### 打印配置

- 无（本页无打印按钮实据；草稿不过账不打印）

## 4. 业务规范

### 统计口径与数据关系

- **数据范围**：全部业务域已保存但未过账的草稿单据（Ctrl+S 保存草稿，销售域表单页快捷键实据）。一行一单，金额列为单据金额，合计行对金额求和
- **来源订单列**：草稿由订单下推生成时记录来源订单号（本批次实据该列均为空，均为手工开单）
- **提交记账（过账）**：草稿过账后成为正式单据，从本页消失并进入《经营历程》；勾选"过账时自动修改单据日期为当前登录日期"则过账日替换原单据日期（跨期补录场景）
- **组内分工**：业务草稿（未过账）→ 提交记账 → 经营历程（已过账流水）；需审批的单据类型过账后先进入《待审批单据》
- 单据类型实据：销售出库单（XSCKD-，11 条）、收款单（SKD-）、采购入库单（CGRKD-）

### 与其他页面关系

- 上游：各业务域表单页"保存草稿 Ctrl+S"（销售订单/销售出库单/采购入库单/收款单等）
- 下游：提交记账 → 经营历程；单据编号链接 → 打开对应单据表单页（草稿态可继续编辑）
- 同组页面：待审批单据、经营历程
