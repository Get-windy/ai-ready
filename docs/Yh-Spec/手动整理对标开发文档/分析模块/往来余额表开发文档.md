## 1. 页面概述

往来余额表页是**往来域的净额总账**：以「结算单位」为行，把应收、预收、应付、预付**四个账簿**各按「期初 / 本期发生 / 期末」三列平铺（共 15 个叶子列），末组 `往来合计` 给出**债权债务对冲后的净额**；当同一单位既是客户又是供应商时，可执行**清账**（应收与应付互抵），并可从「清账历史」追溯。**单入口、单视图**（本页**无**页内视图 Tab）。

### 口径说明（多级表头归位）

- **3 个固定列**（seq 1–3，不属任何分组）：`操作`（行内 `清账` / `对账`）、`结算单位编号`、`结算单位`。

  - `应收金额`：`期初应收余额`、`本期应收`、`期末应收余额`（seq 4–6）
  - `预收金额`：`期初预收金额`、`本期预收`、`期末预收金额`（seq 7–9）
  - `应付金额`：`期初应付金额`、`本期应付`、`期末应付金额`（seq 10–12）
  - `预付金额`：`期初预付金额`、`本期预付`、`期末预付金额`（seq 13–15）
  - `往来合计`：`期初余额`、`本期发生`、`期末余额`（seq 16–18）

## 4. 业务规范

### 统计口径（四象限 + 净额）

- **四象限滚动**：`期末 = 期初 + 本期发生`，应收/预收/应付/预付**各自独立滚动**（实测逐行成立 ✅）。
- **往来合计（净额）**：`往来合计 = 应收金额 + 预付金额 − 预收金额 − 应付金额`（实测逐行成立 ✅）；符号方向为**正 = 对方欠我、负 = 我欠对方**（基准文档记「具体符号方向待复核」——本轮实测行 2 为 `175 − 128 = 47` 正数，与「对方欠我」一致，**该方向得证**）。
- **与《查应收》《查应付》的关系**：本页 `应收金额` 组 = 《查应收》口径、`应付金额` 组 = 《查应付》口径的**并集呈现**（同一单位四象限全量视图）；差别是本页把四账簿平铺并直接给出对冲净额，而《查应收/查应付》分别做单侧滚动。
- **清账**：同一单位既是客户又是供应商时，应收与应付可**对冲清账**（查询区勾选 `仅显示既是客户又是供应商` 即为此场景筛查）；清账历史可追溯。**黄色提示条明确「只支持对应收、应付账款清账」——即预收/预付不参与对冲**。
- **预收/预付不参与清账**（提示条实据）：四象限虽并列呈现，但清账动作只作用于 `应收金额` 与 `应付金额` 两组。

### 取数来源与上下游关系

- **取数**：《查应收》 + 《查应付》全量（应收/预收/应付/预付四账簿）；
- **下游**：清账动作回写应收应付余额；对账单输出（打印/导出）；
- **同源页**：《查应收》（客户侧单侧滚动）、《查应付》（供应商侧单侧滚动）、《销售欠款分析》（职员/区域侧欠款口径）。

  - 数据源：应收 `finance_receivable.remaining_amount` / 预收 `erp_pre_receipt.remaining_amount` / 应付 `finance_payable.remaining_amount` / 预付 `erp_pre_payment.remaining_amount`。

  - **`对账`**：弹窗列出该单位四象限的往来流水（应收 / 预收 / 应付 / 预付，真实数据）。
