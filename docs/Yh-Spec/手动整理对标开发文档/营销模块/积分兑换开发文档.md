## 4. 业务规范

- **目录定位**：本页维护「哪些商品可用积分兑换、各需多少积分」。兑换所需积分即商品的积分定价；商品各列与商品主数据同源。
- **抓取时点目录为空**（共 0 条）：该账套未启用积分兑换目录，不代表页面无此能力。
- **兑换办理出口**：销售订单明细含「兑换礼品、兑换积分、使用积分」字段，销售订单「会员信息」Tab 含「兑换积分」——开单时选兑换商品、按本页「兑换所需积分」扣减会员积分账户。
- **积分两路流出**：本页礼品兑换 + 《会员设置》「积分抵现」（实测 100 积分=1 元，单笔订单最高可抵扣 100%）；与《会员设置》的积分流入规则（注册初始/生日倍数/消费/签到）构成积分闭环。
- **余额约束**：兑换以《会员管理》维护的会员积分账户（当前积分）为前提，余额不足应禁止兑换（业务推断，**规则实现待复核**）。
- **价格列口径**：预设进价=成本参考、参考成本/最近进价=成本类参考、批发价/零售价/最低售价=售价体系——均默认隐藏，仅供选品时参考，不直接改 ERP 库存与价格。

## 5. 实现差异说明

### 当前实现（按源码回写，带 `文件:行号`）

> 文件：`frontend/apps/pc-admin/src/views/marketing/points-exchange/index.vue`（284 行）。

- **骨架：薄壳报表模式 + 页面口径错位** —— 页顶常驻 `a-alert type="warning"`，文案明示「积分兑换流水（兑换记录/审核）后端端点待补全」（`index.vue:3-9`）；主体为 `ARReportPage`（`index.vue:10`），props：`title="积分兑换"`（:12）、`:query-fields="queryFields"`（:13）、`:columns="columns"`（:14）、`:fetcher="fetcher"`（:15）、`page-param-style="pageNum"`（:16）、`export-file-name="积分方案"`（:17）、`row-key="id"`（:18）。**未使用**金标准路线 A 组件（`CategoryListLayout` / `BillDetailTable` / `StandardPagination` / `PageConfigPanel`）。
- **页面性质错位（P0）**：对标页是**兑换商品目录**，本页实际维护的是 **`LoyaltyProgram` 积分方案**（忠诚程序规则），字段与「商品/兑换所需积分」无关。`fetcher` 固定 `programType: 'LOYALTY'`（`index.vue:184-186`）；弹窗标题为「新增/编辑积分方案」（`index.vue:71`）。
- **查询项：仅 1 项** —— `queryFields`（`index.vue:157-159`）：`{ key: 'keyword', type: 'input', label: '关键字', placeholder: '方案名称' }`；对标为「货号/商品名称」复合检索。
- **列定义：9 列** —— `const columns: any[]`（`index.vue:162-172`）：方案名称 `name`、触发方式 `triggerType`、有效期 `period`、适用范围 `applyScope`、最大兑换次数 `maxUsage`、已兑换次数 `usageCount`、排序 `sortOrder`、状态 `isActive`、操作 `action`（fixed:right）。对标 13 列（商品名称/货号/单位/兑换所需积分/规格/型号/产地 + 6 个价格列）**无一对应**。
- **字典**：`TRIGGER_MAP = { AUTO:'自动触发', CODE:'需输入码' }`、`SCOPE_MAP = { ON_ORDER:'整单', ON_PRODUCT:'指定产品', ON_CATEGORY:'指定分类' }`（`index.vue:150-151`，与后端 `LoyaltyProgram` 注释一致）——属积分方案域自造字典，对标页无此概念。
- **按钮数组：页面无按钮数组** —— 仅 `#header-extra` 插槽 1 个按钮「新增积分方案」（`index.vue:20-30`，`openCreate`）；其余由 `ARReportPage` 内置 = **查询 / 重置 / 刷新 / 导出**（`ARReportPage.vue:55-97`）。**无**「新增兑换商品」、**无**打印(F8)。
- **行级操作**：`编辑`、`删除`（`index.vue:53-64`，`openEdit` / `handleDelete`）——对标行级动作形态**待复核**，本页动作为积分方案域自造。
- **弹窗**：新增/编辑积分方案弹窗（`index.vue:69-136`）：方案名称/触发方式/有效期/适用范围/最大兑换次数/排序/方案说明。
- **api**：`import { loyaltyProgramApi, type LoyaltyProgram } from '@/api/marketing'`（`index.vue:147`）；端点 `GET /erp/marketing/program/page`、`POST /erp/marketing/program`、`PUT /erp/marketing/program/{id}`、`DELETE /erp/marketing/program/{id}`（`api/marketing.ts:160-182`）。页面**未接线** `pointsApi`（`/erp/marketing/points/page`，`api/marketing.ts:796-800`）。
- **storage-key**：**无**（`ARReportPage` 组件无列配置弹窗与 `localStorage` 持久化；页面亦未自建 storage-key）。
- **导出**：`ARReportPage` 内置当前页 CSV 导出，文件名「积分方案」（`index.vue:17`）——与页面标题「积分兑换」口径不符。

### 剩余缺口

1. **页面口径错位（P0）**：需从「积分方案（LoyaltyProgram）」改为「可兑换商品目录」（商品 × 兑换所需积分）。
2. **金标准路线 A 未开工**：需 `CategoryListLayout` + `BillDetailTable`（列配置齿轮）+ `StandardPagination` + `PageConfigPanel`。
3. **列定义需整体重建**：对标 13 列（默认 7 列）——商品名称、货号、单位、兑换所需积分、规格、型号、产地 + 6 个价格列（默认隐藏）。
4. **查询项需重接**：「货号/商品名称」复合检索（对标 1 项），当前为「方案名称」关键字。
5. **补动作**：新增兑换商品（选品 + 兑换所需积分）、打印(F8)、导出文件名改「积分兑换」。
6. **无列配置弹窗 / 无 storage-key**。
7. **后端缺口**：页面自述「积分兑换流水（兑换记录/审核）后端端点待补全」；商品 × 积分定价的持久化实体与端点**未见**（现有 `/erp/marketing/program` 为方案规则，非商品目录）。
8. **行级动作形态待复核**（对标 0 条记录，无法取证）——落地前需再抓一次有数据的账套。
9. **兑换扣减闭环未实现**：与《会员管理》积分账户、《会员设置》抵现规则的扣减/校验链路**无代码实据**。
