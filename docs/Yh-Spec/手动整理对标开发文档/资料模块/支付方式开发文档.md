> **文档类型：** 页面对标复刻（已完成代码）

## 页面概述

支付方式用于维护**收款/付款的可选支付方式字典**（现金/银行/微信/支付宝/支票/其他）。单入口（列表 + 新增/编辑弹窗）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 支付方式 | `md/payment-method` | 支付方式列表 + 新增/编辑弹窗 |

菜单（本系统）：资料 → 支付管理 → 支付方式。

### 配置功能说明

- **导出**：列表基于 `ARReportPage`，支持导出。
- ⚠️ **当前实现说明**：本页为 `ARReportPage` + `a-modal` 弹窗（无独立表单页），已接入列配置能力。

### 入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 80550 |
| menu_code | `md:payment-method` |
| path | `md/payment-method` |

## 业务规范说明

- **支付方式字典**：作为收款单/付款单/预收/预付等单据「支付方式」字段的数据源（`GET /list` 仅返回 status=1）。
- **类型枚举**：`methodType` 现金 CASH/银行 BANK/微信 WECHAT/支付宝 ALIPAY/支票 CHECK/其他 OTHER。
- **费率**：`feeRate` 存小数（0.006=0.6%），前端表单用百分比（feeRatePercent）输入。
- **默认值**：新增默认 status=1、feeRate=0、sort=0。
- **排序**：列表 orderBy sort ASC + createTime DESC。

## 实现差异说明

**实现文件**：
- 前端：`views/md/payment-method/index.vue`
- API：`api/payment/md.ts`（`paymentMethodApi` → `/erp/md/payment-method`）
- 后端：`erp-finance` `controller/MdPaymentMethodController.java`（`@RequestMapping("/api/erp/md/payment-method")`；GET /page、GET /{id}、GET /list、POST、PUT /{id}、DELETE /{id}、PUT /{id}/status）
- 表：`md_payment_method`（迁移 V11.29.0 新增）

### 页面对齐（已建成）
- **列表页**：`ARReportPage`（查询区 + 表格），`/page` 分页，orderBy sort ASC + createTime DESC。
- **弹窗表单**：`a-modal` 新增/编辑，POST/PUT 真实生效。
- **状态切换**：行内启用/停用走 `PUT /{id}/status`（请求体为裸 Integer）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 支付方式单一口径（红线）**：本页支付方式为全局基础数据，收款/付款/预收/预付单统一引用，**严禁另建重复支付方式字典**。

- **P2 验收**：无桩/无模拟；增删改、启停、导出闭环真实生效；与收付款单数据一致。
- **⭐ 对标空缺裁决**：ql361 无「支付方式主数据」对照页，本页金标准按本页（作者系统）自定 + 业界标准，不强行挂靠对立标。
