## 1. 模块概述

### 1.1 模块信息

- **模块名称**: ERP Finance (财务管理模块)
- **包路径**: cn.aiedge.erp.finance
- **技术栈**: Spring Boot 3.x + JPA/Hibernate + Redis
- **接口前缀**: `/api/erp/finance`

### 1.2 核心功能

1. **账户管理**: 财务账户管理、账户余额查询
2. **交易管理**: 财务交易记录、交易类型管理、交易审核流程
3. **报表管理**: 财务报表生成、统计分析
4. **税务管理**: 税务申报、税务计算、税务报表
5. **数据模型**: 交易、账户、报表、税务申报

### 1.3 数据模型

| 实体 | 表名 | 主要字段 |
|------|------|----------|
| FinanceTransaction | finance_transaction | transaction_no, transaction_type, amount, transaction_time, status |
| FinanceAccount | finance_account | account_code, account_name, account_type, balance |
| FinanceReport | finance_report | report_name, report_type, generate_time |
| FinanceTaxDeclaration | finance_tax_declaration | tax_type, period, amount, status |

### 1.4 API接口

| 接口模块 | 路径 | 主要功能 |
|---------|------|----------|
| 交易管理 | `/api/erp/finance/transaction` | 创建、查询、统计、审核、撤销交易 |
| 账户管理 | `/api/erp/finance/account` | 账户CRUD、余额查询 |
| 报表管理 | `/api/erp/finance/report` | 报表生成、查询 |
| 税务管理 | `/api/erp/finance/tax` | 申报、查询、计算 |
