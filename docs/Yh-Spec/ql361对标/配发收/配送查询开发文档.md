## 业务规范说明

### 配送任务模型（列实据归纳）

- 一行 = 一个配送任务（任务编号），按"指定配送日期"计划、按"配送开始时间/配送结束时间"记录实际执行；配送状态三值：待配送、配送中、已配送
- 执行资源：司机名称、配送车辆、送货员（司机与送货员为两个角色，可不同人）
- 任务聚合双向单量：**配送单量 / 订金金额**（正向发货侧）与**退货单量**（退货带回侧）；**发货数量/发货金额** 与 **退货数量/退货金额** 成对统计——同一配送任务既送新货又带回退货
- **装箱数量**：任务维度装箱总量；**配送里程(km)**：任务行驶里程，供司机绩效/费用核算
- 显示红冲勾选：被红冲的任务/单据默认隐藏，勾选后显示

### 与源单的关系（实据归纳）

- 配送任务的上游是发货环节：销售订单经订单处理中心"拣货/发货"（物流发货入口）发货后生成销售出库单（XSCKD，见《发货查询开发文档》），配送任务按配送日期+司机/车辆组织出库单的配送
- 退货侧源单为销售退货单：配送带回的退货计入"退货单量/退货数量/退货金额"，收货确认走《物流退货收货开发文档》（销售退货申请-历史视图）
- 查询条件"配送单据编号"可按任务内具体单据检索，即任务与单据为一对多

### 与其他页面关系

- 上游：物流发货（订单处理中心拣货/发货阶段直达）、发货查询（销售出库单台账）
- 同域：物流退货收货（退货回流的收货确认）
- 本系统落地：对应 DMS 配送管理模块（配送任务/司机/车辆/路线/里程），配送状态与司机端（driver-delivery）任务执行联动
