# 按单收款开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/receipt-by-doc`（复合页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **复合页**：列表查询页 + 4 个阶段 Tab（待收款/超期待收款/全部单据/发票查询）+ 行级收款操作；应收款的统一核销工作台（按欠款单据逐单收款的处理中心）。
- **单入口**：财务 → 收款 → 按单收款。
- 本页特有证据：黄色提示实据"不可选择的单据在【账款交账】中处理"。

## 2. 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（往来单位、结算单位、经手人、欠条领取）与截图确认（待收款子标签当前展开项）：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、日期类型（默认"单据日期"）、单据编号、来源订单、往来单位、结算单位（后两者带新增+搜索）
- 单据类型（全部）、结款方式（全部）、经手人、欠条领取
- 勾选项：仅显示已选中、显示无结算收款单的业务单据
- 更多条件（点击展开）

### 功能按钮

按抓取 JSON buttons 实据：无结算收款单核销、欠条领取、刷新、更多、查询、更多条件、√（对账标记）、否（对账标记）、跳转（分页跳转）

行级操作（截图确认）：收款（操作列）。

页面提示实据："不可选择的单据在【账款交账】中处理"——职员经手未交账的单据须先在账款交账完成交账，方可在本页选择收款。

### 打印配置

无（抓取数据未覆盖打印配置弹窗；按钮区未见打印(F8)，打印入口在"更多"内的可能性待复核）

### 默认显示列（21 列，抓取 JSON columns 实据）

对账 (√ / 否)、操作、单据日期、单据类型、单据编号（列头带"扫码定位"开关，当前"开"）、欠条领取、结款方式、结算单位、司机名称、收款日期、对账日期、制单人、仓库、销售收入、本单金额、已结算、待审金额、未结算、最后对账标记时间、最后对账标记人、附件

## 4. 业务规范

### 状态流转与特殊交互

- 阶段主线：销售业务单据（销售出库单/销售退货单）记账产生应收 → 本页"待收款"；超过收款日未结 → "超期待收款"；全部单据为全集视图；发票查询查看开票情况
- 行级"收款"：对该单据发起收款，进入收款单流程（与《收款单开发文档》联动）；收款后"已结算"增加、"未结算"减少，待审金额为收款单已提交未记账的金额
- 对账（√/否）：点击在 √/否 间切换，标记该单据已与对方对账；同时记录"最后对账标记时间/最后对账标记人"
- 欠条领取：挂账客户欠款以欠条形式借出/归还的登记（buttons 与查询条件同名实据），欠条领取列记录状态
- 无结算收款单核销：对"收款单已记账但未勾选核销单据"的历史收款单进行事后补核销（按钮实据，收款单页同名单按钮带计数"(0)"）
- 显示无结算收款单的业务单据：勾选后把存在未核销收款单的业务单据一并列出，配合核销
- 单据编号列"扫码定位"开关：开启后可用扫码枪扫单据条码直接定位行
- 金额口径：本单金额 = 已结算 + 待审金额 + 未结算（按单付款页同构口径佐证：本单金额=已结金额+待审金额+未结金额）
- 行数据实据（截图）：单据类型=销售出库单/销售退货单；结款方式=挂账/现结；制单人=方丽萍/高晓丽

### 与其他页面关系

- 收款对象：销售出库单（XSCKD-）、销售退货单（XSTHD-）——销售域单据记账后流入本页
- 收款动作 → 《收款单开发文档》（SKD- 单据）；预收抵扣见《预收款单开发文档》（YSKD-）
- 职员经手单据先经《账款交账开发文档》交账后方可选择收款（页面提示实据）
- 记账后生成会计凭证（KJPZ-），明细账摘要实据"由[收款单 SKD-…]…"（《明细账开发文档》）
- 本系统前端目录 `finance/receipt-by-doc`（dynamicRoutes.ts 实据）
