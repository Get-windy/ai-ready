# 客户活跃分析开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/customer-active`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页）：客户分层活跃度监控（有效客户=活跃+即将流失，近90天下单口径 + 未交易天数预警）；客户运营与流失预警页。菜单路径：分析 → 采销分析 → 客户活跃分析。
- 页面结构：查询区（一行）+ 分层公式卡片（红/青/紫三色，算式形态）+ 客户活跃度台账表格 + 合计行。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__客户活跃分析.png`

## 4. 业务规范

### 统计口径（客户分层）

- **有效客户**=活跃客户+即将流失客户（936=711+225 ✅；不含已流失/无效客户）
- **客户分类**：按"未交易天数"分层——活跃客户（近期有交易）/即将流失客户（未交易天数超阈值，截图实据 68 天）/流失客户（阈值口径由"客户分类设置"维护，具体天数待复核）
- **未交易天数**=当前日期−最近交易日期
- **近90天下单金额/次数**：滚动 90 天窗口的销售订单口径
- **最近拜访日期**：外勤拜访记录联动（拜访为空说明该客户近期无拜访，流失预警动作项）

### 与其他页面关系

- 取数：销售订单（交易）、外勤拜访记录（拜访）、客户主数据
- 下游：客户运营动作（拜访计划/促销活动触达）；《销售业绩》"拓客数"对应新增客户入口
