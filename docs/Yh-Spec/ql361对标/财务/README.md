## 域级说明

- **菜单结构实据**（menus-full.json + 各 JSON top/group/item 字段双重印证）：财务域 6 组 20 页——收款（按单收款/收款单/预收款单/提现存现转款/待确认款项/在线支付对账单）、付款（按单付款/付款单/预付款单）、收入支出（费用单/其他收入/应收应付调整/账款交账）、账务处理（会计凭证/月结）、账簿（总账/明细账/科目余额表/辅助核算余额表）、财务报表（资产负债表/利润表）。
- **单据编号规则**（截图实据）：收款单 SKD-、预收款单 YSKD-、提现存现转款 YHZKD-、付款单 FKD-、预付款单 YFKD-、费用单 YBFYD-、其他收入 QTSRD-、应收应付调整 YSKZJ-、会计凭证 KJPZ-，后缀均为 `YYYYMMDD-序号`。核销对象单据：销售出库单 XSCKD-、销售退货单 XSTHD-（收款侧）；采购入库单 CGRKD-（付款侧）；在线支付来源订单 XSDD-（销售订单）。
- **快捷键体系**（全域实据）：F8 打印、Ctrl+S 保存草稿、Ctrl+Enter 记账（财务域单据页统一为"记账"而非销售域的"提交"）。
- **表单页统一范式**（8 个单据页实据）：标题行（NO. 单号/附件/居中标题 + 键盘/齿轮/打印(F8)/历史/导出）→ 表头字段区 → 明细可编辑网格（操作列 +/×，合计行）→ 单据备注 → 单据信息行（制单人/制单时间/打印次数/打印记录/源单）→ 本单金额 ¥ + 保存草稿/记账。
- **资金主线**（19 页实据归纳）：
  1. **应收产生与核销**：销售单据（XSCKD-/XSTHD-）记账产生应收 → 按单收款工作台（待收款/超期）行级收款 → 收款单（SKD-）核销：收款账户金额+使用预收款+更多账户 = Σ本次结算+多收金额，记账后回写已结算/待审/未结算并自动生成会计凭证（KJPZ-）。多收金额转预收。
  2. **预收"收→抵→退"**：预收款单（YSKD-）收款形成预收余额（此前预收/可用预收）→ 收款单与销售单据收款区"使用预收款"抵扣应收（预收款余额实时扣减）→ 退货时"退回预收款"（销售域实据）。预付侧完全对称：预付款单（YFKD-）"付" → 付款单"使用预付款"抵应付 → 采购退货退回。
  3. **应付产生与核销**：采购入库单（CGRKD-）记账产生应付 → 按单付款行级付款 → 付款单（FKD-）核销（口径镜像：本单金额=已结+待审+未结）。
  4. **补核销通道**：收/付款单均可"记账时未勾选核销单据"，事后经"无结算收款单核销/无结算付款单核销(37)"补核销（按钮带计数实据）；收款单/付款单页均有"查看已结算单据/自动分配"。
  5. **职员代收链路**：司机/业务员经手收款 → 账款交账（按职员/按单据，去交账）；未交账单据在按单收款中不可选（"不可选择的单据在【账款交账】中处理"提示实据）→ 交账后资金入账，可再经提现存现转款（YHZKD-）在账户间移动（提现/存现/互转+手续费）。
  6. **在途与对账**：在线支付流水（LM-）在在线支付对账单逐笔对账（对账标记）；到账款项经待确认款项（收款/预收款两子标签，批量确认）确认后正式入账。
  7. **非资金往来调整**：应收应付调整（YSKZJ-）四向调整往来余额，无账户字段、不动资金；费用单/其他收入单走资金账户（付/收款账户+更多账户），挂往来单位或纯内部。
  8. **凭证→账簿→报表→月结闭环**：业务单据记账自动生成会计凭证（明细账摘要实据"由[收款单 SKD-…]…"），亦可手工录入（借贷平衡）→ 总账（科目×月）/明细账（逐笔）/科目余额表（四段试算平衡）/辅助核算余额表（科目×核算项）→ 资产负债表/利润表 → 月结锁定期间（反月结解锁），未月结期间资产负债表两侧差额=本期损益未结转（实据差 58,891.00，口径待复核）。
