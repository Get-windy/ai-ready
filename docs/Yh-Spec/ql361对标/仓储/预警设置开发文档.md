# 预警设置开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-alert-config`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **主数据维护页**：商品×仓库库存上下限阈值的查询与维护（页面标题「库存预警固定值设置」），支持批量设置。
- **单入口**：仅维护页（查询区 + 左侧商品分类树 + 设置表格（查询后渲染））。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 全部仓库 / 指定仓库（单选）
- 商品、品牌
- 查询按钮

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、批量设置、更多、查询

### 比较口径配置

顶部提示条「库存上下限比较值：账面库存-待发货　点击设置」，点击可设置比较口径（可选口径枚举待复核）。

### 打印配置

无（抓取未覆盖打印配置弹窗，待复核）。

## 3. 数据表格列配置

### 默认显示列

待复核：抓取时页面为空态（未执行查询），JSON columns 为空；预期与预警查询同体系（商品名称/货号/预警仓库/库存上限/库存下限等，需查询后补抓确认）。

### 全部可配置列

待复核。

## 4. 业务规范

- 页面流程：先查询（仓库/商品/品牌/分类树过滤出商品清单）→ 表格行内维护库存上限/库存下限 → 保存（保存按钮形态待复核，或以「批量设置」统一赋值）。
- 批量设置：对选中商品批量赋相同上下限（弹窗内容待复核）。
- 设置结果即预警查询的过滤阈值。
- 下游消费方：预警查询（按本页阈值判定预警）；采购→采购准备→库存预警补货（按缺货补货）。
- 商品与分类来自 资料→商品管理。
