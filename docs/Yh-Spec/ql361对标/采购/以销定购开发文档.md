# 以销定购开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：待规划（采购域对标新增页面）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：销售订单转采购工作台，按订单逐单转采购（行级「采购成品 / 采购原料」操作）。
- **单入口**：仅列表页（查询方案 + 时间快捷段 + 查询区 + 数据表格 + 合计行 + 分页；数据行为销售订单）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号
- 销售类型、客户、经手人、仓库
- 单据状态（下拉，全部）、记账状态（下拉，全部）
- 显示已取消（勾选框）、仅显示已选中（勾选框）

### 功能按钮（抓取 JSON buttons 实据）

刷新、打印(F8)、导出、更多、查询、跳转（分页）

行级操作（截图确认）：采购成品、采购原料

> 与补货三页（库存预警/缺货/智能）不同，本页无顶部「采购」主按钮，转采购动作为行级操作。

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（26 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、单据子类型、录入方式、单据状态、是否使用优惠券、仓库、客户编号、客户、记账状态、强制终止、是否采购、发货、重量（kg）、体积（m³）、订单金额、预计发货、经手人、部门、卖家备注、买家备注、附件、商品数量、已发数量、未发数量

> 注：JSON 首项「操作 单据日期 单据编号」为表头拼接串，非真实单列，已剔除。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核）。

## 4. 业务规范

- 数据本质：本页表格数据行为销售订单（单据编号 XSDD- 前缀、单据子类型「正常销售」、录入方式「微商城」均为截图实据），是「按销售订单生成采购」的工作台。
- 是否采购列：标记该销售订单是否已转采购（截图实据值「否」）；转采购后应回写（回写口径待复核）。
- 采购成品 / 采购原料（行级操作）：按订单商品分别生成成品采购或原料采购（生成单据类型与携带字段待复核）。
- 记账状态（全部/未完成等）：销售订单的发货记账状态，与「单据状态」（待发货等）并存；强制终止列标记订单是否被强制终止。
- 显示已取消：默认不显示已取消订单，勾选后纳入。
- 数据源：销售订单（与订单处理中心同源，本页聚焦「转采购」视角）；下游：行级采购成品/采购原料 → 采购订单。
- 同组姊妹页：库存预警补货、缺货补货、智能补货（三页按商品维度计算，本页按订单维度逐单处理）。
