## 页面概述

利润表是**按会计期间出具的损益报表**（营业收入 → 逐级加减成本费用 → 利润）。**报表页**（查询 + 单表纵向项目行，无分页，无独立表单），单入口。报表项目行**非固定模板**，由公司实际启用的科目按「科目层级=2」展开生成。

菜单：财务 → 财务报表 → 利润表。

### 配置功能说明
- **列配置**：数据表表头内齿轮图标（`.icon-shezhi2`，表头左起「𞸎/谢」列）→ 列配置弹窗（个人配置 / 全局配置），配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**3 列全部默认显示，无隐藏列**。
- **页面配置**：无。本页工具栏仅 刷新/打印(F8)/导出/查询，无「配置」齿轮，故**无页面配置弹窗**（仅列配置弹窗）。
- ⚠️ **当前实现说明**：本页金标准列配置弹窗已实测；本系统实现见「实现差异说明 → 待完善」。

## 页面配置（对标系统实测抓取）

### 查询条件（对标默认勾选显示 · 实据）

查询方案（下拉，`--查询方案--`）、单会计月 / 多会计月（期间口径切换）、会计月(止)（会计期间月份选择，默认当前会计月 2026年8月；日期字段 id=`search_AccountingMon`）、科目层级（下拉，值 2）、显示为0科目（复选）。共 5 项。

### 功能按钮（顶部工具栏）

刷新、打印(F8)、导出、查询。（无「配置」齿轮，仅列配置弹窗。）

### 数据表列配置（全部配置数据列 3 列，全部默认显示）

> 数据表内 `.icon-shezhi2` → 列配置弹窗（个人/全局配置）。**全部默认显示 [x]，无隐藏列**。

| # | 列名 | 默认 |
|---|------|------|
| 1 | 项目 | [x] |
| 2 | 本期发生额 | [x] |
| 3 | 本年累计 | [x] |

- 对标默认显示数：3 / 全部 3。
- 隐藏列：无。
- **单表纵向 3 列**：序号列（不可配置）+ 项目 / 本期发生额 / 本年累计 3 数据列。
- **报表项目行（科目层级=2 驱动）**：一级汇总加粗行（一、营业收入 / 二、营业利润(亏损以'-'填列) / 三、利润总额(亏损总额以'-'填列) / 四、净利润(净亏损以'-'填列)），明细科目行（带「减：/加：」前缀或缩进，如 减：主营业务成本、加：其他业务收入、管理费用、财务费用、利息、手续费 等）。实测共 33 项项目行。
- **口径**：本期发生额=所选会计月当月发生；本年累计=年初至该月累计。

## 业务规范说明

- **报表口径**：本期发生额=单会计月当月发生；本年累计=年初至止月累计。
- **报表项目行**：由公司实际启用科目按「科目层级（默认 2）」展开生成，非固定模板；含 一/二/三/四 段汇总行（营业收入、营业利润、利润总额、净利润）与明细科目行（带 减：/加： 前缀或缩进）。
- **汇总行**：营业利润/利润总额/净利润（按国内报表惯例，带「(亏损以'-'填列)」后缀）。
- **数字右对齐**，无链接穿透（与资产负债表不同，本表无「明细对账」按钮）。

## 实现差异说明

**实现文件**：
- 前端：`views/finance/profit-report/index.vue`（组件标题「利润表」）
- API：`api/finance/index.ts` → `reportApi.getIncomeStatement`（`/erp/finance/report/v2/income-statement`）

### 页面对齐（已建成）
- **报表页**：PageContainer + 查询区（会计年度/开始月份/结束月份）+ 统计卡片 + 图表 + 纵向表格（项目编码/项目名称/本期金额/本年累计金额 4 列，合计行加粗）。

### 与对标差异（本系统 vs 对标实测）
| 维度 | 对标实测 | 本系统当前 | 差异 |
|------|---------|-----------|------|
| 查询条件 | 查询方案/单-多会计月切换/会计月(止)/科目层级/显示为0科目（5 项） | 会计年度/开始月份/结束月份（3 项） | 本系统用「年度+起止月份」替代「会计月(止)+科目层级+显示为0科目」 |
| 数据列 | 项目 / 本期发生额 / 本年累计（3 列） | 项目编码 / 项目名称 / 本期金额 / 本年累计金额（4 列） | 本系统含「项目编码」列，名称用「本期金额/本年累计金额」 |
| 报表项目行 | 科目层级=2 驱动（一/二/三/四 段汇总行 + 明细科目行，加：/减： 前缀/缩进），实测 33 项 | 固定 TOTAL_ROWS 合计行（营业收入合计/营业成本合计/营业毛利/期间费用合计/净利润 5 行）+ 数据行 | **本系统合计行为固定编码（TOTAL_REVENUE 等）**，非科目层级驱动 |
| 列配置弹窗 | 有（3 列） | 无（本系统 a-table 静态列） | 需补齐列配置弹窗 |
| 页面配置弹窗 | 无 | 无 | 一致 |

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 损益口径（红线）**：利润表只读取自凭证/科目余额，**严禁手工改表或绕过凭证**；本期发生=单会计月，本年累计=年初至止月。
- **P1 勾稽**：净利润须能与资产负债表期初/期末权益变动核对一致。
- **P1 汇总行**：逐级小计按国内报表惯例补全「减：/加：」前缀，一/二/三/四 段汇总行完整（科目层级驱动）。
- **P2 验收**：金额与科目余额/明细账对数一致；三级缩进不串级。
