# 购物车开发文档

> **文档类型：** 页面对标复刻
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）商城模块
> **对标来源：** **ql361 未见到独立购物车页**。已核对 ql361 顶部「商城」菜单 → 订单处理（订单处理/退货申请处理）/ 基础业务（商品上架/单位显示/买家申请管理/买家账号/商品组合）/ 商城设置（基础设置/店铺设置/运费设置/商城装修/公告设置/关键词库）均无「购物车」；浏览器按「购物车/前台/购物」关键字检索均无匹配。**本页按本系统实现 + 业界标准编写，不臆造对标字段。**
> **定位：** 商城购物车（顾客端加购待结算集合）的后台查看/清理页。

## 页面概述

购物车是**商城购物车的后台查看/清理页**：展示商城前台顾客加入购物车的商品（名称/编码/规格/数量/单价/小计），并提供删除。**单入口只读列表，无独立表单、无子 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 购物车 | `trade/cart` | 只读列表页（购物车商品） |

单入口：交易模块 → 商城订单组 → 购物车。

- **对标情况**：ql361 未见到独立购物车管理页（无实测字段可对标）；本页为商城顾客端购物车的后台监控/清理页，购物车数据由商城前台加购产生。
- 本系统实测：购物车商品总数（= 各条目数量之和）、每行为一条购物车商品（商品名称/编码/规格/数量/单价/小计），行级删除。

### 配置功能说明
- **列表结构**：购物车页为**只读商品类列表页**，**无**「页面配置」（查询条件/功能按钮 Tab 的配置齿轮）、**无**「列配置」弹窗。查询区/按钮区为固定项。
- ⚠️ **当前实现说明**：本页为 `PageContainer` + `BillTableList` 固定列列表（columns 硬编码 7 列），无列/页面配置弹窗，见「实现差异说明 → 待完善」。

## 业务规范说明

- **数据来源**：购物车为商城顾客端（mobile-mall）加购产生的待结算商品集合；本页为后台只读查看/清理。
- **删除**：行级「删除」→ popconfirm 确认 → `DELETE /api/v1/mall/cart/{id}`。
- **商品总数**：`购物车商品总数 = Σ 各条目数量`（`tableData.reduce(quantity)`）。
- **金额口径**：小计 = 单价 × 数量（`totalPrice`）；本页仅展示，不做结算。
- **下游**：购物车商品结算后生成商城订单/零售单（见 `商城订单`/`POS收银` 文档），购物车条目随之减少/清除。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/trade/cart/list.vue`
- API：`GET /api/v1/mall/cart`、`DELETE /api/v1/mall/cart/{id}`

### 页面对齐（已建成：`BillTableList` 固定列）
- **单表只读列表**：`PageContainer` + `BillTableList`，`pagination=false`、`show-toolbar=false`、`show-search=false`、`show-add=false`、`show-export=false`、`show-batch-delete=false`、`selectable=false`。
- **头部**：状态徽标、购物车商品总数、手动刷新按钮。
- **数据表列（7 列）**：商品名称、商品编码、规格、数量、单价、小计、操作（删除 popconfirm）。
- **行级操作**：删除（`DELETE /api/v1/mall/cart/{id}`）。
- **无列/页面配置弹窗、无分页、无搜索、无新增导出**。

3. **页面配置弹窗**：补查询条件/功能按钮 Tab（当前无）。
4. **批量操作**：批量删除/清空。
5. **数据源**：明确购物车数据归属（会员维度/设备维度），关联 mobile-mall 后端接口与表。
