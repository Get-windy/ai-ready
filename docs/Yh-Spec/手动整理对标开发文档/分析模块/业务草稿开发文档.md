## 1. 页面概述

业务草稿是**跨业务域「草稿」状态单据的统一台账**：集中存放各业务域已保存但尚未过账的单据，供操作员批量提交记账（过账）或删除。**单入口、单视图**（无页内 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 业务草稿 | `analytics/draft` | 单视图列表页（跨 13 类单据聚合草稿箱 + 批量过账/删除） |

单入口：分析 → 综合单据 → 业务草稿。

- 页面结构：查询方案 + 时间快捷段 + **三行查询区** + 草稿台账表格（首列红色齿轮列配置入口 + 序号线 + 行勾选框 + 固定「操作」列）+ 底部合计行 + 分页条。
- 实测实据（2026-09-15）：共 **5** 条记录、**1/1** 页、每页显示 **20** 行、底部合计 **1,145**。全部为「销售出库单」（`XSCKD-20260915-0xx`），行级动作为「删除 / 复制」。
- 多 Tab 判定：实测 JSON `tabs` 为 `{}`（空对象），`.png` 顶部仅一个「业务草稿」页签 → **单视图，无子 Tab**。

### 配置功能说明

- 实测工具栏（右上）：`刷新`、`提交记账`、`删除`、`更多`（工具栏最左侧另有一个齿轮图标，列配置入口）；**无「打印(F8)」**。

## 4. 业务规范

### 统计口径与数据关系

- **数据范围**：全部业务域已保存但**未过账**的草稿单据（各业务域表单页 `Ctrl+S` 保存草稿），一行一单，`金额` = 单据金额原值；底部合计对当前过滤范围求和。
  - 后端实现为 13 个单据分支的 UNION 聚合（`DocQueryService.java` 的 `BRANCHES`，`DocQueryService.java:50-127`），`StatusMode.DRAFT` 时逐类取草稿态，例如销售订单 `status = 0`（`草稿`）、销售出库单 / 销售退货单 / 采购订单 / 采购入库单 / 采购退货单 / 收款单 / 付款单 / 调拨单 / 报损单 / 报溢单 `status = 0`、费用申请单 `status = 'DRAFT'`。
- **来源订单列**：草稿由订单下推生成时记录来源订单号（本批次实测该列均为空，即 5 单均为手工开单）。
- **提交记账（过账）**：草稿过账后成为正式单据，从本页消失并进入《经营历程》；勾选 `过账时自动修改单据日期为当前登录日期` 时，过账日替换原单据日期（跨期补录场景）。
- **组内分工**（综合单据组三页 = 单据生命周期的三个横切状态）：
  业务草稿（未过账）→ 提交记账 → 经营历程（已过账流水）；需审批的单据类型过账后先进入《待审批单据》。
- 单据类型实测：本批 5 条全部为销售出库单（`XSCKD-`）；基准文档另记收款单（`SKD-`）、采购入库单（`CGRKD-`）亦会出现。

### 与其他页面关系

- **上游**：各业务域表单页「保存草稿」（销售订单 / 销售出库单 / 采购入库单 / 收款单等）。
- **下游**：提交记账 → 经营历程（需审批者先入待审批单据）；单据编号链接 → 打开对应单据表单页（草稿态可继续编辑）。
- **同组页面**：待审批单据、经营历程。

## 5. 实现差异说明

> 本节按当前源码与真机实测（2026-09-18）回写。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/analytics/draft/index.vue`（449 行）。
- **骨架**：`ErrorBoundary > PageContainer(full-height) > CategoryListLayout`（`:tabs="[]"`、`:show-category-panel="false"`、`:show-table-footer="true"`）+ `BillDetailTable`（`:view-mode="true"`、`:min-rows="20"`）+ `StandardPagination`（`variant="classic"`、`page-size-options=[20,50,100]`）。
- **逐 Tab 列数**：单视图。全部 **13 列 / 默认 12 列**（`columns` 共 16 项 = 业务列 13 + `rowNo/checkbox/action`；业务列中仅「制单人」`defaultHidden`）。列配置键 `analytics-draft-columns`（`storage-key` = `global-config-key`）。
- **页面配置**：`PageConfigPanel`（对标实测有「页面配置」弹窗），页面配置持久化键 `analytics-draft-page-config`（与列配置键不同值）；查询条件默认 9 项、功能按钮 3 项（刷新 / 提交记账 / 删除）均可在弹窗内启停，`hide-print-config`（对标无打印）。
- **查询项**：工具栏左侧「查询方案」下拉（占位）+ 8 段时间快捷段（默认「本月」）；查询区 9 项 = 单据编号、单据类型、往来单位、仓库、经手人、部门、制单人、单据备注、来源订单 + 查询 / 重置。
- **行级 / 批量动作**：行级「删除」「复制」（`hasPurchased` 无关；复制仅在 `docTypeCode` 支持 `copy` 时出现）；批量「提交记账」「删除」（均需勾选，二次确认）。动作按 `docTypeCode` 分发到各业务域既有 `POST {base}/{id}/submit`、`DELETE {base}/{id}`、`POST {base}/{id}/copy`，不直改状态列。
- **打印 / 导出**：均无（对标本身无）。
- **合计行 / 排序**：底部合计行「金额」取自后端 `summary.amount`（按过滤范围 SUM）；仅「金额」可排序（后端 `sortField/sortOrder`），回落「单据日期倒序」。
- **取数端点**：`GET /docquery/draft-docs/page`（13 类单据 UNION，`StatusMode.DRAFT`）。
- **后端**：`DocQueryController` + `DocQueryService`（DRAFT 态）；未新增迁移。

### 剩余缺口

1. **「查询方案」下拉仅为占位**：`queryScheme` 未被任何请求使用（`index.vue:206`、`:18-25`）→ 对标「查询方案」能力未落地。
2. **对标勾选项「过账时自动修改单据日期为当前登录日期」未落地**：本页提交记账仅调各业务域 `submit`，无该入参（`index.vue:337-357`），后端亦无对应参数。
3. **对标工具栏「更多」未接**：只落了 `刷新 / 提交记账 / 删除`；「更多」内项在对标侧本身未取到，**未确证**。
4. **每页行数档位与对标不同**：对标实测每页 20 行（本次与对标一致）；档位为 20/50/100（对标未见多档实据）。
