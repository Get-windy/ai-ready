## 业务规范说明

### 状态流转与特殊交互

- 业务定位（提示条实据）：管理互联平台账号与往来单位的绑定关系——即上下游企业（客户/供应商）在互联平台上的账号与本系统往来单位档案一一绑定
- 无"新增"按钮：绑定关系可能由互联平台侧发起绑定后在本页查看/管理（推断，待复核）
- 抓取时 0 条记录：该演示账套尚未建立互联绑定

### 与其他页面关系

- 客户/供应商（往来单位）：绑定关系的一端为往来单位档案
- 客户"买家账号"列：商城买家账号与互联账号均为外部账号体系，口径区分待复核
- 互联业务：推断用于企业间订单协同（客户互联账号下单直达本系统销售订单），实据不足待复核

### 架构师红线（Ponytail六步过滤网）
