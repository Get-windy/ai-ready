## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后转出账户余额减少、各转入账户余额增加，资金总额守恒
- 一对多转入：一张单可拆分到多个转入账户（如提现部分存保险柜、部分存店面备用金），本单金额=Σ转入金额
- 手续费：跨行/提现手续费单独登记，随单计入费用（手续费科目归属待复核）
- 记账后自动生成会计凭证（KJPZ-；明细账摘要实据"由[提现存现转款单 YHZKD-…]…"）

### 与其他页面关系

- 账户主数据：转出/转入账户均来自资料 → 财务账户 → 银行账户（含现金类账户；总账科目实据 1001 现金库存下设 现金/店面备用金/敦煌店面备用金 明细）
- 与账款交账衔接：职员交账收到的现金/转账先入账户，再经本页存行或上调
- 下游账簿：总账/明细账（明细账摘要回链本单单号）
- 本系统前端目录 `finance/cash-transfer`（dynamicRoutes.ts 实据）
