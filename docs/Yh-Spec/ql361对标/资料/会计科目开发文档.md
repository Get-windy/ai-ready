## 1. 页面概述

- **列表页**：会计科目表（Chart of Accounts）主数据维护页，左侧科目分类树 + 查询区 + 数据表格，科目树形层级。
- 截图：![会计科目](../../../../tool-results/ql361/pages/资料__财务账户__会计科目.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入科目名称/编号）
- 勾选项：显示停用、显示层次结构（默认勾选）
- 左侧科目分类树（全部、资产类、负债类、所有者权益类、损益类）按类别过滤
- JSON filterLabels 4 个"更多"占位对应查询配置区折叠字段，待复核

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增会计科目、刷新、打印(F8)、导出、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、更多

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（4 列，抓取 JSON columns 实据）

操作、科目编号、科目名称、核算项

> JSON columns 首项"操作 科目编号 科目名称 核算项"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 科目四大类：资产类（1）、负债类（2）、所有者权益类（4）、损益类（6）——截图实据为顶层大类行，编号即大类码；成本类未见（商贸企业口径，待复核）
- 树形层级：左侧科目分类树 + 行首文件夹图标 + "显示层次结构"默认勾选，科目按大类 → 一级科目 → 明细科目逐级展开（如损益类下 6601 销售费用，见费用类型页）
- 核算项：科目的辅助核算维度（本页该列数据为空，配置待复核）
- 停用优先：与"显示停用"勾选项配套；被凭证引用的科目不允许物理删除（生产级口径）
- 与其他页面关系：银行账户（资金账户 1001/1002 即本科目表资产类下科目）、费用类型（6403/6601 等即损益类下科目）、其他收入（6101/6111/6301/6902 即损益类下科目）、财务凭证（单据按科目生成凭证）
