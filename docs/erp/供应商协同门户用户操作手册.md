## 一、快速入门指南

### 1.1 系统概述
供应商协同门户是AI-Ready ERP系统的重要组成部分，为供应商提供：
- 在线接收和响应采购询价
- 提交产品报价和资质文件
- 查看订单状态和发货要求
- 管理发货和验收信息
- 在线对账和开票

### 1.2 系统访问
#### 1.2.1 访问地址
- **正式环境**: `https://supplier.ai-ready.com`
- **测试环境**: `https://test-supplier.ai-ready.com`
- **备用地址**: `https://portal.ai-ready.com/supplier`

#### 1.2.2 浏览器要求
- **推荐浏览器**: Chrome 100+, Edge 100+, Firefox 100+
- **屏幕分辨率**: 1280×720 及以上
- **网络要求**: 稳定的网络连接

### 1.3 首次使用准备
1. **账户注册**: 联系采购经理获取注册邀请邮件
2. **账户激活**: 点击邮件中的激活链接，设置初始密码
3. **信息完善**: 登录后完善企业信息和联系人信息
4. **资质上传**: 上传营业执照、资质证书等文件

## 二、系统登录与导航

### 2.1 登录操作
#### 2.1.1 登录页面
访问系统首页，输入以下信息：
- **用户名**: 企业邮箱或供应商编码
- **密码**: 注册时设置的密码
- **验证码**: 图片验证码（区分大小写）

#### 2.1.2 密码找回
忘记密码时操作流程：
1. 点击登录页"忘记密码"链接
2. 输入注册邮箱地址
3. 查收重置密码邮件
4. 点击邮件中的重置链接
5. 设置新密码（8-20位，含字母和数字）

### 2.2 系统导航
#### 2.2.1 主菜单结构
```
首页 → 系统概览和数据看板
询价管理 → 查看和响应采购询价
报价中心 → 提交和管理报价
订单管理 → 查看和跟踪订单
发货管理 → 录入发货信息和物流
验收管理 → 查看验收结果和反馈
对账开票 → 对账确认和发票提交
系统设置 → 账户信息和通知设置
```

#### 2.2.2 快捷操作
- **F1键**: 帮助文档
- **Esc键**: 返回上级
- **Ctrl+F**: 页面搜索
- **Ctrl+S**: 保存草稿
- **Ctrl+Enter**: 提交表单

## 三、核心功能操作指南

### 3.1 询价管理
#### 3.1.1 查看询价单
1. 进入"询价管理"菜单
2. 查看待响应询价列表
3. 点击询价单号查看详情
4. 查看询价产品规格、数量、交期要求

#### 3.1.2 响应询价
1. 在询价详情页点击"报价"按钮
2. 填写报价信息：
   - 单价（含税/不含税）
   - 最小起订量
   - 交货周期
   - 特殊要求说明
3. 上传资质文件（可选）
4. 提交报价或保存草稿

### 3.2 报价管理
#### 3.2.1 报价提交
1. 进入"报价中心" → "新建报价"
2. 选择对应的询价单
3. 填写详细报价信息
4. 上传技术文档和资质证明
5. 提交报价等待审核

#### 3.2.2 报价状态跟踪
- **草稿**: 保存但未提交
- **已提交**: 等待采购方审核
- **已确认**: 采购方确认报价
- **已驳回**: 采购方驳回，可查看原因
- **已过期**: 询价有效期已过

### 3.3 订单管理
#### 3.3.1 订单查看
1. 进入"订单管理"菜单
2. 查看已确认订单列表
3. 点击订单号查看详情：
   - 订单基本信息
   - 产品明细和数量
   - 交货地址和要求
   - 付款条款

#### 3.3.2 订单确认
1. 收到订单确认通知
2. 进入订单详情页面
3. 确认订单信息和条款
4. 点击"确认接单"按钮
5. 打印或导出订单PDF文件

### 3.4 发货管理
#### 3.4.1 发货录入
1. 进入"发货管理" → "新建发货单"
2. 选择对应订单
3. 填写发货信息：
   - 发货日期
   - 物流公司和单号
   - 发货产品和数量
   - 包装信息和重量
4. 上传发货凭证照片
5. 提交发货信息

#### 3.4.2 物流跟踪
1. 发货单列表查看物流状态
2. 点击物流单号查询详情
3. 系统自动同步物流轨迹
4. 异常物流系统自动提醒

### 3.5 验收管理
#### 3.5.1 验收结果查看
1. 进入"验收管理"菜单
2. 查看发货单的验收状态：
   - **待验收**: 货物已送达，待收货方验收
   - **验收中**: 正在检验货物
   - **验收通过**: 货物合格，等待付款
   - **验收异常**: 货物存在问题，需处理
   - **已完成**: 验收流程结束

#### 3.5.2 验收异常处理
1. 查看验收异常原因
2. 与采购方沟通确认问题
3. 制定解决方案：
   - 补发/更换货物
   - 协商降价处理
   - 其他协商方案
4. 在系统中提交处理方案

### 3.6 对账开票
#### 3.6.1 对账确认
1. 进入"对账开票" → "待对账"
2. 查看月度对账单明细
3. 核对订单、发货、验收数据
4. 确认无误后点击"确认对账"
5. 如有异议点击"发起异议"

#### 3.6.2 发票提交
1. 对账确认后进入"发票提交"
2. 填写发票信息：
   - 发票类型（增值税专用/普通发票）
   - 开票金额和税率
   - 发票代码和号码
3. 上传发票扫描件
4. 填写邮寄地址和联系人
5. 提交发票信息等待审核

## 四、高级功能操作

### 4.1 批量操作
#### 4.1.1 批量报价
1. 询价列表勾选多个询价单
2. 点击"批量报价"按钮
3. 填写统一报价信息
4. 系统自动为每个询价单生成报价
5. 可单独调整每个询价报价

#### 4.1.2 批量发货
1. 选择多个待发货订单
2. 点击"批量发货"按钮
3. 填写统一物流信息
4. 上传多个发货凭证
5. 系统生成多个发货单

### 4.2 数据分析
#### 4.2.1 业务统计
进入"数据看板"查看：
- 月度询价数量统计
- 报价成功率分析
- 订单金额趋势图
- 发货及时率统计
- 验收合格率分析

#### 4.2.2 报表导出
1. 选择需要的数据报表
2. 设置时间范围和筛选条件
3. 选择导出格式：
   - Excel格式（支持详细数据）
   - PDF格式（支持打印）
   - CSV格式（支持导入其他系统）
4. 下载或邮件发送报表

### 4.3 协同协作
#### 4.3.1 消息通知
- **系统通知**: 订单确认、发货提醒等
- **采购方消息**: 询价澄清、验收反馈等
- **公告通知**: 系统维护、政策变更等
- **实时聊天**: 与采购专员在线沟通

#### 4.3.2 文件共享
支持上传和共享：
- 产品技术文档
- 检测报告和证书
- 发货凭证和物流单据
- 发票扫描件
- 合同附件

## 五、系统设置与维护

### 5.1 账户管理
#### 5.1.1 个人信息
1. 进入"系统设置" → "个人信息"
2. 修改基本信息：
   - 联系人姓名和职位
   - 手机号码和邮箱
   - 办公地址和传真
3. 保存更改

#### 5.1.2 密码安全
1. 定期修改登录密码
2. 建议密码规则：
   - 长度8-20位
   - 包含大小写字母和数字
   - 避免使用简单密码
3. 开启二次验证（推荐）

### 5.2 通知设置
#### 5.2.1 通知方式
- **站内消息**: 系统内部消息
- **邮件通知**: 重要事项邮件提醒
- **短信通知**: 紧急事务短信提醒
- **微信通知**: 绑定微信接收通知

#### 5.2.2 通知类型
设置接收以下通知：
- ✅ 新询价通知
- ✅ 报价确认通知
- ✅ 订单生成通知
- ✅ 发货提醒通知
- ✅ 验收结果通知
- ✅ 对账提醒通知

### 5.3 数据备份
#### 5.3.1 手动备份
1. 进入"系统设置" → "数据备份"
2. 选择备份数据类型
3. 设置备份时间范围
4. 选择备份格式（JSON/Excel）
5. 下载备份文件

#### 5.3.2 自动备份
开启自动备份功能：
1. 设置备份周期（每日/每周/每月）
2. 设置备份保留期限
3. 配置备份邮箱接收备份文件
4. 查看备份历史记录

## 六、常见问题解答

### 6.1 登录相关问题
**Q1: 忘记密码怎么办？**
A: 点击登录页"忘记密码"链接，输入注册邮箱重置密码。

**Q2: 账户被锁定怎么办？**
A: 连续输错密码5次账户会被锁定30分钟，或联系管理员解锁。

**Q3: 收不到激活邮件？**
A: 检查垃圾邮件箱，或联系采购经理重新发送激活邮件。

### 6.2 业务操作问题
**Q4: 如何修改已提交的报价？**
A: 报价在"已提交"状态下可联系采购专员撤回修改；如已确认则无法修改。

**Q5: 发货信息填写错误怎么办？**
A: 在收货方验收前可联系采购专员修改发货信息。

**Q6: 发票信息错误如何处理？**
A: 发票提交后如发现错误，立即联系财务人员作废重开。

### 6.3 系统使用问题
**Q7: 页面显示异常怎么办？**
A: 清理浏览器缓存，或尝试使用Chrome浏览器访问。

**Q8: 系统响应慢如何处理？**
A: 检查网络连接，或避开高峰期使用系统。

**Q9: 如何导出历史数据？**
A: 在"数据备份"功能中可按时间范围导出数据。

## 七、附录

### 7.1 术语解释
- **询价单 (RFQ)**: 采购方发出的需求询问文档
- **报价单 (Quotation)**: 供应商提交的价格和条款回复
- **采购订单 (PO)**: 采购方确认采购的正式文件
- **发货单 (Delivery Note)**: 供应商发货时填写的单据
- **验收单 (Acceptance Note)**: 收货方确认收货的凭证
- **对账单 (Statement)**: 双方确认应付账款的清单

### 7.2 操作流程图
```
供应商注册 → 账户激活 → 信息完善 → 资质上传
    ↓
查看询价 → 提交报价 → 报价确认
    ↓
接收订单 → 确认接单 → 生产准备
    ↓
发货录入 → 物流跟踪 → 验收确认
    ↓
对账确认 → 发票提交 → 收款完成
```
