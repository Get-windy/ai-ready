## 页面配置

### 查询条件

按抓取 JSON 实据（filterLabels：商品、供应商、经手人、仓库）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年

## 业务规范说明

### 状态流转与特殊交互

- 一行一明细：同一单据含 N 个商品即占 N 行（截图实据见上），与"采购单据查询"的一行一单形成维度互补
- 批次追溯三列：批次条码、生产日期、到期日期为采购入库批次采集字段（与采购入库单表单页批次采集实据一致），支撑批次效期管理
- 是否赠品查询条件：支持赠品专项追溯（采购入库单明细"赠品"列实据）
- 行级"批次号"：查看该明细行的批次轨迹（推断，具体弹层内容待复核）
- 数量/单价/金额/优惠后金额四列联动口径与采购入库单明细一致（数量×单价=金额，优惠后金额为折让后口径）

### 与其他页面关系

- 数据源：采购入库单/采购退货单/采购换货单的商品明细行（与采购单据查询同源，维度不同）
- 单据编号链接跳转原单据
- 销售域对应页：销售明细查询（同构，销售版带左侧商品分类树与更多销售侧条件）

### 供应商来源

供应商来源通过 ERP 模块的往来单位下的供应商分类处理。

### 架构师红线（Ponytail六步过滤网）

对标 Odoo、SAP、金蝶、用友、管家婆等生产级系统的业务逻辑和交互逻辑，溯源字段真实所属实体，实现真正的生产级数据闭环。
