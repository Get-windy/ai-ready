# 采购价格跟踪开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/price-track`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **列表查询页**：供应商-商品维度的最近采购价跟踪（最近采购价/最近采购日期），支持手工新增与修改，属「查询 + 轻维护」复合页（与销售价格跟踪同构）。
- **单入口**：仅列表页（查询区 + 工具按钮区 + 左侧商品分类树 + 数据表格 + 分页）。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年（本页无「查询方案」下拉）
- 日期范围（起 至 止）、往来单位（带新增/搜索）、商品（带新增/搜索）
- 单位类型（下拉，默认「全部」）
- 仅显示已选中（勾选框）

### 功能按钮（抓取 JSON buttons 实据）

新增（橙色）、刷新、打印(F8)、更多、查询、跳转（分页）

行级操作（截图确认）：修改、删除；行首带勾选框（配合批量操作，批量项在「更多」内，具体内容待复核）

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（9 列，抓取 JSON columns 实据）

操作、商品名称、货号、商品单位、往来单位编号、往来单位名称、最近采购价、最近采购日期、最后修改时间

> 注：JSON columns 共 10 项，首项「操作 商品名称 货号」为表头拼接串，非真实单列，已剔除；与销售价格跟踪（11 列）相比，本页无「条码」「最近销售折扣(%)」两列（采购侧截图实据无折扣列，是否可配置待复核）。

### 全部可配置列

无全量依据（列配置弹窗未抓取，待复核；配置弹窗结构参照销售域 XSMK：个人配置 Tab + 全局配置 Tab）。

## 4. 业务规范

- 一行 = 一个「商品 × 往来单位」组合的最近采购价记录（截图实据：不同供应商同商品分行、价格各异；同一供应商多商品分行）。
- 数据来源两类：采购单据成交自动写入（最近采购价/最近采购日期）+ 手工新增/修改（最后修改时间列存在即为此佐证）；自动与手工的优先级规则待复核。
- 录单联动：采购订单/入库单录单选择供应商+商品时按此表带出最近采购价（采购订单明细全量列含「最近采购日期」字段，XSMK 依据，与此页数据同源）。
- 单位类型：同一商品多计量单位（件/箱）时分别跟踪价格（截图实据同商品按「件/箱」分行）。
- 时间快捷段与日期范围：按「最近采购日期/最后修改时间」过滤记录（作用字段待复核）。
- 数据写入方：采购订单、采购入库单等成交类单据；数据消费方：各采购单据录单页的「最近采购价」参考与价格带出逻辑；商品分类树与「资料」域商品分类一致；销售域对应页：销售价格跟踪（同构）。
