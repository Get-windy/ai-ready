## 5. 高可用性配置

### 5.1 负载均衡配置

#### 5.1.1 HAProxy配置
```haproxy
frontend http_front
    bind *:80
    bind *:443 ssl crt /etc/ssl/test.ai-ready.local.pem
    redirect scheme https if !{ ssl_fc }
    
    acl is_api path_beg /api/
    acl is_static path_beg /static/
    
    use_backend api_servers if is_api
    use_backend static_servers if is_static
    default_backend web_servers

backend api_servers
    balance roundrobin
    option httpchk GET /health
    server api1 10.0.1.11:8080 check
    server api2 10.0.1.12:8080 check

backend web_servers
    balance roundrobin
    option httpchk GET /health
    server web1 10.0.2.21:80 check
    server web2 10.0.2.22:80 check
```

### 6.2 网络告警规则

#### 6.2.1 紧急告警 (P0)
```yaml
groups:
  - name: network_critical
    rules:
      - alert: NetworkOutage
        expr: up{job="node"} == 0
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "网络中断: {{ $labels.instance }}"
          description: "节点 {{ $labels.instance }} 网络中断超过5分钟"
      
      - alert: HighPacketLoss
        expr: rate(node_network_receive_drop_total[5m]) > 0.05
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "高丢包率: {{ $labels.instance }}"
          description: "节点 {{ $labels.instance }} 丢包率超过5%"
```

#### 6.2.2 重要告警 (P1)
```yaml
groups:
  - name: network_important
    rules:
      - alert: HighBandwidthUsage
        expr: rate(node_network_receive_bytes_total[5m]) / 1024 / 1024 > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "高带宽使用: {{ $labels.instance }}"
          description: "节点 {{ $labels.instance }} 带宽使用超过80Mbps"
      
      - alert: HighLatency
        expr: histogram_quantile(0.95, rate(node_network_transmit_latency_seconds_bucket[5m])) > 0.1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "高网络延迟: {{ $labels.instance }}"
          description: "节点 {{ $labels.instance }} 网络延迟P95超过100ms"
```
