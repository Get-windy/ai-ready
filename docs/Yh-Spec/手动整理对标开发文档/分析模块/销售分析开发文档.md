## 1. 页面概述

销售分析页是**量本利分析中枢**：同一套「销售数量 → 销售额 → 退货 → 实销 → 销售收入 → 销售成本 → 销售毛利 → 费用/优惠 → 销售利润 → 利润率」指标，可切换 **8 个分析维度**（时间、商品、品牌、客户、区域、仓库、职员、来源）逐一切换粒度；按时间维度另可按天/按周/按月聚合。行内金额带下划线可钻取到单据/明细。

| 页面 | 地址 | 说明 |
|------|------|------|
| 销售分析 | `analytics/sales-analysis` | 单入口复合页（**8 个视图 Tab**：按时间/按商品/按品牌/按客户/按区域/按仓库/按职员/按来源；逐 Tab 独立列配置） |

单入口：分析 → 采销分析 → 销售分析。

## 4. 业务规范

### 统计口径（量本利全链路）

- **销售数量 → 销售额**：`销售额` 为销售出库口径含税销售额；`销售额占比(%)` = 该行销售额 / 合计销售额 × 100。
- **退货 → 净销售（销售收入）**：`销售收入` = 销售额 − 退货额（净销售口径）。实据：按品牌 无品牌 264,825.46 − 8,193.5 = **256,631.96** ✅；按来源 线下 428,427.66 − 10,194.52 = **418,233.14** ✅。
  - ⚠️ **负收入实据**：`按仓库` 配送中心 销售额 100 − 退货额 5,000 = **−4900**（销售收入可为负，列显示负数），复刻时不得以「≥0」约束。
- **毛利**：`销售毛利` = `销售收入` − `销售成本`。实据：按品牌 无品牌 256,631.96 − 215,388.57 = **41,243.39** ✅；`毛利率(%)` = 销售毛利 / 销售收入 × 100（41,243.39 / 256,631.96 ≈ 16.07 ✅）。
- **利润**：`销售利润` = 销售毛利 − 其他费用支出 − 结算优惠（基准文档口径，本次实据未出现非零费用/优惠行，**待复核**）；`利润率(%)` = 销售利润 / 销售收入 × 100；`费销比(%)` = 其他费用支出 / 销售收入 × 100；`利润占比(%)` = 该行销售利润 / 合计销售利润 × 100（实据 `按职员` 杨生淮 利润率 18.83、利润占比 231.64，占比 >100 说明其余职员贡献为负）。
- **退货率 vs 金额退货率 / 数量退货率**：`按时间`/`按品牌`/`按客户`/`按区域`/`按仓库`/`按职员`/`按来源` 提供 `退货率(%)`（金额口径，退货额 / 销售额）；**仅 `按商品`** 提供双口径 `金额退货率(%)` 与 `数量退货率(%)`。
- **实销块**（`实销金额`/`实销数量`/`实销重量`/`实销小中大单位数量`）：与「销售块」并列的**净额口径**（对外口径 vs 毛出库口径），默认全部隐藏，需在列配置中按需打开。
- **订货块**（`订货数量`/`订货金额`/`退订数量`/`退订金额`/`直接出库数量`/`直接出库金额`/`预估销售数量`/`预估销售金额`/`订货浮动数量`/`销售浮动数量`）：来自销售订单（XSDD-）侧的**在途/预估口径**，与出库侧形成「订货 vs 销售」对照；`订货浮动数量`/`销售浮动数量` 为订货与销售的差异量。
- **销售成本口径**：按出库成本（移动加权/批次成本，成本核算口径与《进销存分析》一致）。
- **其他费用支出 / 结算优惠**：`其他费用支出` = 随单费用（物流费/装卸费等）；`结算优惠` = 收款结算环节让利。
- **来源口径**：`按来源` 的 `来源` = 单据产生方式（实测取值 `线下` / `线上`；基准文档另记「手工开单/商城下单/导入等」**待复核**）。
- **小中大多单位**：`销售小中大单位数量\小/中/大` 按商品多单位体系把数量拆到小/中/大单位（与《销售明细查询》多单位口径一致）。
- **粒度**：`按时间` Tab 支持 `按天`/`按周`/`按月` 聚合（实测查询区实据）。

### 与其他页面关系

- 取数：销售出库单 / 销售退货单（经营历程流水）+ 商品成本 + 随单费用 + 收款结算优惠 + 商品/客户/仓库/区域/职员/品牌主数据。
- 同源页：《销售费用分析》（费用口径展开，六类费用）、《经营分析》（公司级利润表口径）、《销售业绩》（漏斗口径，按职员/按时间）、《销售明细查询》（明细级 96 列）、《销售价格跟踪》。
- 下游：《销售欠款分析》（`销售未结金额`/`欠款占比(%)`/`预收余额` 与欠款口径衔接）。
