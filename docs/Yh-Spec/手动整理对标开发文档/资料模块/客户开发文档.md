## 页面概述

客户是**客户主数据档案**（含分类树 + 查询 + 5 子标签）。双入口（列表 + 表单）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 客户列表页 | `md/customer/index`（list_path `md/customer/form` 双入口） | 客户档案列表 + 分类树 + 5 子标签 |
| 客户表单页 | `md/customer/form` | 新增/编辑客户 |

> 客户/供应商/其他往来单位统一走 `erp/partner`（往来单位-客户分类），`md/customer` 为客户端口。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 客户列表页配置

### 子标签（本系统实测 5 个）
全部客户 / 会员管理 / 全部联系人 / 客户级别 / 区域管理。

### 查询条件（本系统实测）
客户编号/名称（partnerCode/partnerName）、默认经手人等。

### 数据表列（本系统实测，`partnerApi`）
客户编号(partnerCode)、客户名称(partnerName，nameCell 链接)、结款方式、客户级别、所属仓库、所属区域、默认经手人、推广人、联系人、助记码、联系电话、联系地址、买家账号、动态收款期限、固定账期、结算期、开户银行、银行账号、税号、客户来源、最近交易时间、新增时间、操作。

> 对标 27 列（含一票通/营业执照有效期/附件/备注）。

## 新增编辑客户表单页配置

### 页面结构（自定义 `a-form`，`useBillForm` 协作）
客户基本信息（编号/名称/级别/结款方式）→ 联系信息（联系人/电话/地址/助记码）→ 账户信息（开户银行/账号/税号）→ 账期设置（固定账期/结算期/动态收款期限）→ 附件/备注。

### 关键字段
| 字段 | 说明 |
|------|------|
| 客户编号 | partnerCode（前端生成/可改） |
| 客户名称 | partnerName |
| 客户级别 | 标准化价格等级（餐饮店/食堂团餐/自助vip/大团餐/特价客户/外围餐饮店/重点vip01/连锁\|vip） |
| 客户分类 | 客户分类树 |
| 结款方式 | 挂账/现结 |
| 默认经手人 | 关联职员 |

## 业务规范说明

- **客户来源**：ERP 往来单位-客户（**非 CRM 公海客户**；CRM=潜在，ERP=实体交易）。
- **价格等级**：客户级别为标准化 8 价格等级（复用 `priceLevelConfig`，不重复开发）。
- **绑定售价**：客户单价按价格等级带出（销售订单/零售单按客户级别取价）。
- **预收接入**：客户预收余额（预收款单/收款单联动）。
