# 预订货查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/pre-order-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**（统计分析页）：预订货单按商品/客户两维度的订发履约汇总（含赠品三数量口径，已取消/已驳回不参与统计）。菜单路径：分析 → 采销分析 → 预订货查询。
- 页面结构：维度 Tab（商品预订货分析 / 客户预订货分析）+ 查询区 + 左侧商品分类树 + 汇总表格。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__预订货查询.png`

### 查询条件（抓取 JSON filterLabels + 截图实据）

## 4. 业务规范

### 统计口径（预订货订发履约）

- **数据范围**：预订货单（YDHD-）明细按商品汇总；**已取消、已驳回订单不参与统计**（页面提示条实据）
- **数量口径**：预订货数量（原始预订量）、已订数量（已转为正式订单量）、已发数量（已发货量）——三量递进反映预订→转单→发货履约
- **赠品三口径**：赠品数量（预订赠品）、赠品订货数量（转单赠品）、赠品发货数量（实发赠品）
- **金额/价税合计**：预订货金额（不含税/含税两口径）
- **显示层次结构**：勾选后按商品分类树分层呈现（分类小计 + 商品明细）

### 与其他页面关系

- 取数：预订货单（YDHD-，销售域）+ 预订金（预订货款科目 2204，财务域实据）
- 下游：预订货转销售订单/销售出库单发货；预发货不足联动《采购准备》"以销定购"
