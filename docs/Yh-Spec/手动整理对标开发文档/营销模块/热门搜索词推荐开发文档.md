## 4. 业务规范

- **热词模型（列实据归纳）**：
  - 人工维护词表：`新增关键词` 按钮 + `最多新增20个热门关键词` 提示条实据——热词由运营人工配置，**非系统自动统计生成**。
  - `排序` 列：控制热词在商城搜索框下拉/推荐位的展示顺序。
  - `最后修改时间`：词表审计线索。
  - **展示位置（基准文档推断，待复核）**：商城（mobile-mall/B2B 商城）搜索框聚焦时展示推荐热词，点击直达搜索结果。
- **上限约束**：`最多新增 20 个热门关键词`（提示条实据）；超出上限的拦截行为（前端禁用按钮 / 后端报错）**待复核**。
- **与其他页面关系**：商城营销组引流位（与商城弹窗广告首页弹窗互补，热词是搜索入口的引导位）；本系统落地对应 `/api/search/hot`。

## 5. 实现差异说明

> 本节按当前源码回写（源码未在本轮改动）。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/marketing/hot-keywords/index.vue`（共 121 行）。
- **骨架**：`ErrorBoundary` + `PageContainer`（`index.vue:2-3`）+ **手写 `a-table`**（`:32-51`），**非** `ARReportPage`、**非**金标准路线 A。无 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`，**无列配置齿轮、无页面配置弹窗、无新增/编辑弹窗**。
- **顶部提示**：`a-alert`（`index.vue:4-10`，`type="warning"`）文案「热搜词管理（置顶/屏蔽/权重调整）后端端点待补全」，描述「当前页对接搜索服务（/api/search/hot）真实端点，**只读展示系统统计出的热门搜索词**；人工干预配置将在后端提供端点后接入」——**自述为只读桩页**。
- **查询条件**：无查询表单；仅工具栏「展示数量」下拉（`limit`，选项 10/20/50，`index.vue:15-20`）+「刷新」按钮（`:21-29`）。**与对标「请输入关键词 + 查询」不对齐**。
- **列定义**：`columns`（`index.vue:81-84`），共 **2 列**：排名、热搜关键词。**与对标 3 列（关键词名称/排序/最后修改时间）无一列同名**。
- **数据来源**：`searchHotApi.hot(limit)`（`api/marketing.ts:656-662`，裸请求 `GET /api/search/hot?limit=N`），返回 `{ hotSearches: string[]; count: number }`；`loadData`（`index.vue:86-97`）把字符串数组按序号映射为 `{ rank: index + 1, keyword }`。
- **分页**：`:pagination="false"`（`index.vue:38`），无分页组件。
- **行级操作**：无（无操作列）。
- **后端**：无对应模块控制器（`/api/search/hot` 为外部/服务层裸端点）；本页**无 CRUD 端点**（页面 `a-alert` 亦自述「后端端点待补全」）。
- **storage-key**：无（未使用列配置/页面配置持久化）。

### 剩余缺口

1. **🔴 实现方向相反（最大缺口）**：对标是**人工维护型**词表（`新增关键词` 按钮 + 20 条上限 + 排序 + 最后修改时间）；本页是**只读展示型**（读 `/api/search/hot` 系统统计结果），**无新增/编辑/删除能力**。页面 `a-alert` 自述为「后端端点待补全」的临时态。
2. **🔴 列结构不对齐**：对标 3 列（关键词名称/排序/最后修改时间）；本页 2 列（排名/热搜关键词）。**无一列同名**，`排序`（可维护字段）与 `最后修改时间` 完全缺失。
3. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；手写 `a-table` 无列配置入口。
4. **查询条件不对齐**：对标为 `筛选条件 + 请输入关键词 + 查询`；本页为「展示数量」下拉 + 刷新（**无关键词模糊检索**）。
5. **20 个上限未落地**：对标提示条「最多新增20个热门关键词」为硬约束；本页无新增入口，故无上限校验。
6. **`PageContainer` 宽度受限**：`.table-area { max-width: 720px }`（`index.vue:103-109`），为窄表布局，与对标列表页版式不一致。
7. **错误处理为原型级**：`loadData` catch 分支仅 `console.warn`（`index.vue:91-94`）并清空数据，未做用户提示。
8. **数据口径为「系统统计」非「人工推荐」**：本页展示的 `hotSearches` 来自搜索服务统计，与对标「运营人工配置的推荐词」语义不同（**待复核**：`/api/search/hot` 是否含人工干预字段）。
