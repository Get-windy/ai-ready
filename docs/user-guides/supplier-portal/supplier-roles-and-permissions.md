# 供应商门户用户角色与权限说明

## 概述
本文档详细说明供应商门户系统中的用户角色、权限分配及各角色的核心职责，帮助供应商用户理解自身权限范围，确保系统使用的合规性和高效性。

## 用户角色分类

### 1. 供应商管理员 (Supplier Administrator)

#### 1.1 角色定义
- **角色标识**: `SUPPLIER_ADMIN`
- **核心职责**: 负责供应商企业的整体账户管理和用户权限分配
- **典型用户**: 供应商企业IT负责人、企业管理员、主要负责人

#### 1.2 主要权限
- ✅ **账户管理**
  - 创建、编辑、禁用子账户
  - 分配角色权限给子账户
  - 重置用户密码
  - 审核用户权限申请

- ✅ **企业信息管理**
  - 维护企业基本信息（名称、地址、联系方式等）
  - 更新营业执照等资质文件
  - 管理银行账户信息
  - 维护税务信息

- ✅ **安全设置**
  - 配置企业安全策略
  - 设置双因素认证
  - 管理API访问密钥
  - 查看操作审计日志

- ✅ **通知配置**
  - 配置企业级通知规则
  - 设置重要业务提醒
  - 管理邮件/短信通知模板

#### 1.3 典型操作场景
1. 新员工入职：创建采购员账户并分配权限
2. 员工离职：禁用相关账户
3. 权限调整：根据业务需求调整用户权限
4. 资质更新：上传最新的企业资质文件

### 2. 采购员 (Purchaser)

#### 2.1 角色定义
- **角色标识**: `PURCHASER`
- **核心职责**: 负责日常采购业务操作，包括询价、报价、订单处理
- **典型用户**: 供应商业务员、销售代表、客户经理

#### 2.2 主要权限
- ✅ **询价管理**
  - 查看发布的询价信息
  - 提交报价方案
  - 管理历史报价记录
  - 跟踪报价状态

- ✅ **订单管理**
  - 查看采购订单
  - 确认订单接受/拒绝
  - 提交订单变更申请
  - 跟踪订单执行状态

- ✅ **交付管理**
  - 提交发货通知
  - 更新物流跟踪信息
  - 处理交付异常
  - 确认收货

- ✅ **沟通协作**
  - 与采购方在线沟通
  - 参与协商会议
  - 处理业务咨询
  - 接收系统通知

#### 2.3 典型操作场景
1. 报价响应：收到询价后及时提交报价
2. 订单处理：确认订单并安排生产/发货
3. 交付跟踪：更新发货状态和物流信息
4. 异常处理：处理交付延迟、质量问题等异常

### 3. 财务人员 (Finance Staff)

#### 3.1 角色定义
- **角色标识**: `FINANCE_STAFF`
- **核心职责**: 负责财务结算、对账、发票管理等财务相关操作
- **典型用户**: 供应商财务专员、会计、出纳

#### 3.2 主要权限
- ✅ **结算管理**
  - 查看结算账单
  - 确认结算金额
  - 提交付款申请
  - 跟踪付款状态

- ✅ **发票管理**
  - 提交电子发票
  - 管理发票状态
  - 处理发票冲红
  - 下载发票副本

- ✅ **对账管理**
  - 查看对账单
  - 核对业务数据
  - 提交对账确认
  - 处理对账差异

- ✅ **报表查询**
  - 查看财务报表
  - 导出结算数据
  - 分析交易趋势
  - 下载凭证文件

#### 3.3 典型操作场景
1. 账单确认：核对业务数据后确认结算账单
2. 发票开立：根据订单完成情况开具发票
3. 付款处理：完成付款操作并提交凭证
4. 对账核对：定期与采购方进行财务对账

### 数据访问权限
1. **企业级数据**: 所有角色可见，但编辑权限不同
2. **部门级数据**: 按业务部门划分访问范围
3. **个人数据**: 仅本人可见和操作
4. **敏感数据**: 需额外审批才能访问

## 角色配置指南

### 1. 用户创建流程
```
供应商管理员登录 → 用户管理 → 创建用户 → 选择角色 → 配置权限 → 发送激活邮件
```

### 2. 权限调整流程
```
用户申请权限调整 → 管理员审批 → 系统记录 → 权限生效 → 通知用户
```

### 3. 角色转换规则
1. **权限叠加**: 用户可拥有多个角色，权限取并集
2. **最小权限原则**: 按需分配，避免权限过大
3. **定期审计**: 每季度审查用户权限与实际需求匹配度

## 安全注意事项

### 1. 账户安全
- 定期修改密码（建议90天）
- 启用双因素认证
- 避免多人共用账户
- 及时注销离职人员账户

### 2. 操作规范
- 操作前确认权限范围
- 重要操作需二次确认
- 异常操作系统自动记录
- 定期审查操作日志

### 3. 数据保护
- 敏感数据加密存储
- 下载数据需审批
- 禁止外传商业机密
- 遵守数据保护法规

## 常见问题

### Q1: 一个用户可以拥有多个角色吗？
**A**: 是的，系统支持用户同时拥有多个角色，权限将自动叠加。

### Q2: 如何申请额外权限？
**A**: 通过系统内的"权限申请"功能提交申请，需说明业务需求和申请期限。

### Q3: 权限调整需要多长时间生效？
**A**: 管理员批准后立即生效，系统会发送通知邮件。

### Q4: 忘记密码怎么办？
**A**: 可通过登录页的"忘记密码"功能重置，或联系供应商管理员协助重置。

### Q5: 如何查看自己的权限范围？
**A**: 登录后点击右上角用户头像 → "我的权限"，即可查看详细权限列表。

## 附录

### 术语表
- **完整权限**: 包含查看、创建、编辑、删除、导出等所有操作权限
- **查看权限**: 仅可查看数据，不能进行修改操作
- **管理权限**: 包含查看和部分管理功能，但不一定包含删除权限
