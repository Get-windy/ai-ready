# 调拨单开发文档

## 页面概述

调拨单用于仓库间库存调拨录单（出库仓库 → 入库仓库），支持同价/异价调拨。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 调拨单列表页 | http://localhost:5656/erp/stock-transfer/index | 双入口「历史」标签 |
| 新增/编辑调拨单表单页 | http://localhost:5656/erp/stock-transfer/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5011（原"调拨管理"，本次改名"调拨单"） |
| menu_code | `erp:stock-transfer` |
| 主菜单路径 | `erp/stock-transfer/form`（点击进新增表单） |
| 标签「历史」路径 | `erp/stock-transfer/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-transfer/form`（表单）、`erp/stock-transfer/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记帐后生效：出库仓库减库存、入库仓库加库存。
- 调拨方式默认「同价调拨」：调拨单价=成本单价，调拨差额为 0；异价调拨时产生调拨差额（成本单价/成本金额/调拨单价/调拨金额/调拨差额五列佐证；异价差额去向（损益科目）待复核）。
- 与其他出入库单明细差异：有「规格」列、无「货位」列；无单价/金额而代之以成本与调拨价系列列。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 双仓库联动：一出库仓库一入库仓库，记账后两仓库存同步变动，可在 分析→仓配分析→查库存/库存明细 检索。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
