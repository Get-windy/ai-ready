## 页面概述

供应商是**供应商主数据档案**（含分类树 + 查询 + 工具栏），用于采购订单/采购入库/应付等的供应商主体。双入口（列表 + 表单）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 供应商列表页 | `md/supplier/index`（list_path 双入口） | 供应商档案列表 + 供应商分类树 |
| 供应商表单页 | `md/supplier/form/:id` | 新增/编辑供应商 |

> 供应商/客户/物流/其他往来单位统一走 `erp/partner`（往来单位），`biz_party.partyType`=2（supplier），`md/supplier` 为供应端口。

### 配置功能说明

- **列配置**：数据表右上角 `.icon-shezhi2`（列配置弹窗：个人配置 / 全局配置，可视化列「上级 / 列名 / 显示名 / 显示」）。
- **工具栏**：新增 / 导入 / 刷新 / 打印(F8) / 导出 / 查询 / 跳转。
- **无页面配置弹窗**：供应商列表页查询条件/功能按钮为**固定项**（无顶部「配置」齿轮）。
- ⚠️ **当前实现说明**：本页为共享 `PartnerListPage.vue`（左类型导航 + 分类树 + `BillTableList`），**自定义搜索因共享组件未监听 `partner-search` 事件而不生效**，见「实现差异说明 → 待完善」。

## 业务规范说明

- **供应商来源**：ERP 往来单位-供应商（`biz_party.partyType`=2），**非 CRM 公海客户**。
- **主体关系**：客户=1 supplier=2 logistics=3 other=4 统一 `biz_party`；供应商特有经营系列/经营面积/税号/开户行/银行账号。
- **编号前缀**：GYS（中文）/ SUP（英文），经 `next-seq` 异步生成。
- **订货下推**：列表行「订货」跳转 `/erp/purchase/form?supplierId&supplierName`，带入采购订单供应商。
- **状态**：ENABLED=1 / DISABLED=0；采购/应付仅选定启用供应商。
- **应付接入**：供应商应付余额（付款单/预付款单联动）；期初应付/预付用于初始化。
- **账期**：动态付款期限(天)/固定账期/结算期入应付账期判断。

## 实现差异说明

**实现文件**：
- 前端：`views/md/supplier/index.vue`（薄封装）、`views/md/supplier/form.vue`，共享 `views/md/components/PartnerListPage.vue`、`partnerTypeSidebar`
- API：`api/erp/partner.ts`（`partnerApi` page `GET /erp/md/customer/page`、getById、create POST、update PUT `/{id}`、updateStatus PUT `/{id}/status`、delete DELETE `/{id}`、nextSeq GET `/next-seq`）、`partnerCategoryApi`（`/erp/partner/categories*`）、`partnerGradeApi`（`/erp/partner/grades`）、`partnerContactApi`（`/erp/partner/contacts`）
- 后端：`erp` 模块 `party/controller/MdCustomerController.java`（`@RequestMapping("/api/erp/md/customer")`；GET /page、GET /{id}、GET /search、GET /list、POST、PUT /{id}、PUT /{id}/status、DELETE /{id}、GET /next-seq、POST /{id}/follow、POST /import）
- 表：`biz_party`（主）、`biz_party_category`、`biz_party_contact`（旧 `erp_partner` 已弃用）

### 页面对齐（已建成）
- **列表页**：共享 `PartnerListPage`（左类型导航 + 分类树 + `BillTableList`），工具栏完整。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 供应商单一口径（红线）**：本页供应商为全局基础数据，采购订单/入库/应付/付款统一引用，**严禁另建重复供应商表**。
- **P1 关联一致性**：供应商状态/账期/期初/结算方式变更后正确反映到采购与应付，保证前后端口径一致。
- **P1 账期/期初**：动态付款期限/固定账期/结算期/期初应付金额入应付判断与期初初始化。
- **P2 验收**：无桩/无模拟；供应商增删改、启停、订货下推、导出闭环真实生效；与采购/应付数据一致。
