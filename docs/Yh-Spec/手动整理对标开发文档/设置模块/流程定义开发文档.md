### 5.4 保存链路与提交内容（`handleSave :705-756`）

```

  → WorkflowServiceImpl.saveWorkflowDefinition           WorkflowServiceImpl.java:103
```

### 5.5 启停的真实语义与「意外递增版本」（P0）

后端 **没有**独立的启停调用被前端使用。前端用**保存通道**代偿：

```
designer/index.vue:636   GET  /definitions/{definitionId}   （取全量 detail）
designer/index.vue:640   POST /definitions  { ...detail, enabled }   ← 用的是「新建」端点
  → WorkflowServiceImpl.saveWorkflowDefinition:103
      definitionId 非空 → :128 转 updateWorkflowDefinition          （Service 注释自认：「POST 带 definitionId 即为更新」）
  → updateWorkflowDefinition:128 内 version +1
```

**后果**：**用户每点一次启停开关，该流程定义的 `version` 就 +1，且 `process_config` / `workflow_node` 被整份重写**（`mirrorNodes` 先 `delete` 再 `insert`，`:1006-1013`）。DB 实测 `9101 order_approval` 已是 `version = 2`、`2079743652222652418 test_flow` 已是 `version = 2` —— 与「被启停过」吻合。
> 前端**自认**这一点：`message.success('保存成功（已生成新版本）')`（`:749`）。
> 后端**已有** `POST /definitions/{id}/disable`（`WorkflowController.java:119`）与 `/publish`（`:106`），前端**未接线**；`:630` 的注释「后端无独立启停接口」**与后端事实相反**（陈旧注释）。

### 5.6 状态值域（启停）

- 前端只以布尔 `enabled` 表达，后端写入的 `status` 实为 **3 个值、且两条写入路径不一致**：

| 写入路径 | `enabled = true` | `enabled = false` | 行 |
|---|:---:|:---:|---|
| **新建**（`saveWorkflowDefinition` 的 insert 分支） | `status = 1` | **`status = 0`** | `WorkflowServiceImpl.java:118` |
| **更新**（`updateWorkflowDefinition`，即「POST 带 definitionId」） | `status = 1` | **`status = 2`** | `WorkflowServiceImpl.java:151` |
| `POST /definitions/{id}/publish` | `status = 1`（**不动 version**） | — | `:161-169` |
| `POST /definitions/{id}/disable` | — | **`status = 2`**（**不动 version**） | `:172-180` |

- **读取映射只有一条**：`toModel` → `enabled = (status != null && status == 1)`（`WorkflowConverter.java:205`）→ `0` 与 `2` 都显示为「停用」，**界面看不出两者的区别**。
- 前端文案：`启用` / `停用`（`designer/index.vue:112`）；tooltip「点击停用」/「点击启用」（`:81`）。
- `DEFINITION_STATUS_MAP`（`index.ts:193-197`）定义 `0=草稿 / 1=已发布 / 2=已停用` —— **本页未引用该常量**；但后端**确实会写入 2**（更新路径与 `/disable`），**也会写入 0**（新建且停用）→ **同一常量表的三个值在库里都可达**（P2：状态语义未收敛）。
- ⚠️ **连带结论（对 §5.5 的修法有利）**：`publish` / `disable` 两个端点**只改 `status`、不 +version**（`:161-180`），因此把启停从「保存通道」改到这两个端点是**语义正确且无副作用**的修法。
