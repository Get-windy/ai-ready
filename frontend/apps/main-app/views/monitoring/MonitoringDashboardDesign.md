# 测试环境监控仪表盘UI设计文档

## 1. 设计概述

### 1.1 设计目标
为Sprint 27+1测试环境提供一套完整的监控仪表盘UI界面，实时展示系统健康状态、性能指标和告警信息。

### 1.2 技术栈
- Vue 3 + TypeScript
- Element Plus UI组件库
- ECharts 数据可视化
- CSS Grid / Flexbox 布局

### 1.3 设计原则
- **清晰易用**: 信息层级分明，一目了然
- **实时反馈**: 数据实时更新，状态即时可见
- **响应式**: 适配桌面、平板、手机多端
- **美观专业**: 现代化设计风格，符合企业级应用标准

## 3. 组件设计规范

### 3.1 KPI卡片组件 (KpiCard)

**功能**: 展示关键性能指标

**数据结构**:
```typescript
interface KpiCardData {
  title: string;           // 指标名称
  value: number | string;  // 当前值
  unit: string;           // 单位
  trend: 'up' | 'down' | 'stable';  // 趋势
  trendValue: string;     // 变化百分比
  status: 'success' | 'warning' | 'danger' | 'info';  // 状态
  icon: string;           // Element Plus图标名
  sparklineData?: number[];  // 迷你趋势图数据
}
```

**视觉设计**:
- 卡片圆角: 12px
- 阴影: 0 2px 12px rgba(0,0,0,0.08)
- 状态颜色:
  - success: #67C23A (绿色)
  - warning: #E6A23C (橙色)
  - danger: #F56C6C (红色)
  - info: #909399 (灰色)
- 图标区域: 48px圆形背景

**交互**:
- 悬停: 轻微上浮 + 阴影加深
- 点击: 下钻到详细视图

### 3.2 服务状态卡片 (ServiceStatusCard)

**功能**: 展示各组件运行状态

**数据结构**:
```typescript
interface ServiceStatus {
  name: string;           // 服务名称
  type: 'api' | 'database' | 'cache' | 'queue' | 'other';
  status: 'running' | 'stopped' | 'error' | 'warning';
  uptime: string;         // 运行时间
  lastCheck: string;      // 最后检查时间
  latency?: number;       // 响应延迟(ms)
  connections?: number;   // 连接数
}
```

**状态标识**:
- running: 绿色圆点 + 脉冲动画
- stopped: 灰色圆点
- error: 红色圆点 + 闪烁动画
- warning: 橙色圆点

**布局**:
- 网格布局，每行2-4个服务
- 每个服务卡片包含: 图标、名称、状态、关键指标

### 3.3 性能趋势图表 (PerformanceChart)

**功能**: 展示性能指标的历史趋势

**图表类型**:
1. **折线图**: 响应时间趋势
2. **面积图**: 吞吐量趋势
3. **柱状图**: 错误率分布
4. **热力图**: 请求时间分布

**配置**:
- 时间范围选择器: 最近1小时/6小时/24小时/7天
- 自动刷新: 30秒间隔
- 数据点提示: 悬停显示详细数值

### 3.4 告警通知组件 (AlertNotification)

**功能**: 实时展示系统告警

**告警级别**:
- **P0 - 紧急**: 系统不可用，红色
- **P1 - 严重**: 核心功能受影响，橙色
- **P2 - 警告**: 性能下降，黄色
- **P3 - 提示**: 信息通知，蓝色

**组件结构**:
```typescript
interface AlertItem {
  id: string;
  level: 'P0' | 'P1' | 'P2' | 'P3';
  title: string;
  message: string;
  source: string;         // 告警来源
  timestamp: string;
  acknowledged: boolean; // 是否已确认
}
```

**交互**:
- 新告警: 右侧滑入 + 声音提示
- 告警确认: 点击确认后移除高亮
- 历史告警: 可展开查看已处理告警

### 4.2 服务监控页面 (ServiceMonitoring)

**功能**: 详细展示各服务的运行状态和指标

**内容**:
- API服务列表: 响应时间、QPS、错误率
- 数据库监控: 连接数、查询时间、慢查询
- 缓存监控: 命中率、内存使用、键数量
- 消息队列: 队列深度、消费速率、堆积消息

### 4.3 性能指标页面 (PerformanceMetrics)

**功能**: 深度分析性能数据

**图表**:
- 响应时间分布图
- 吞吐量趋势图
- 错误率热力图
- 资源使用率(CPU/内存)

### 4.4 告警中心页面 (AlertCenter)

**功能**: 告警管理和历史查询

**功能**:
- 实时告警流
- 告警规则配置
- 告警历史查询
- 告警统计报表

### 5.1 色彩系统

- Success: #67C23A
- Warning: #E6A23C
- Danger: #F56C6C
- Info: #909399

**背景色**:

- 卡片背景: #FFFFFF (浅色) / #16213E (深色)
- 边框: #DCDFE6 (浅色) / #2D3748 (深色)

### 5.2 字体规范

- 页面标题: 24px, font-weight: 600
- 卡片标题: 16px, font-weight: 500
- 正文: 14px, font-weight: 400
- 辅助文字: 12px, font-weight: 400

### 5.3 间距系统

- 页面边距: 24px
- 卡片间距: 16px
- 卡片内边距: 20px
- 元素间距: 8px / 12px / 16px

## 6. 交互设计

### 6.1 数据刷新机制
- 自动刷新: 30秒间隔
- 手动刷新: 右上角刷新按钮
- 实时推送: WebSocket连接告警数据

### 6.2 下钻交互
- KPI卡片点击 → 详细趋势图
- 服务卡片点击 → 服务详情页
- 告警项点击 → 告警详情 + 处理操作

### 6.3 主题切换
- 支持浅色/深色主题
- 切换动画: 300ms过渡
- 主题偏好本地存储
