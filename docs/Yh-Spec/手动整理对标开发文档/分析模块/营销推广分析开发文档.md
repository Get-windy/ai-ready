- `分享领取数`（仅按优惠券）= 通过分享链接领到券的张数/人数口径（**待复核**）。
- `加购次数`（仅推广客户列表）= 该客户加购行为次数（**待复核**）。
- 合计行仅对数值列求和；实测 6 个 Tab 均 0 条，合计值全为 0。
- `成团类型` / `状态` / `促销方式` / `促销类型` / `客户级别` 的**取值枚举待复核**（0 条记录，无样本可取）。

## 4. 业务规范

### 统计口径（推广漏斗）

- **五维度**：按商品（商品推广效果）/按优惠券（券分享核销）/按促销活动（活动分享）/按拼团（拼团裂变）/按秒杀（秒杀引流）；**推广客户列表**为被分享触达的客户名册。
- **行粒度**：漏斗类 Tab 以「推广对象 + 起止有效期」为行；推广客户列表以「客户」为行。

### 与营销模块的上下游关系（**取数关系，必须写清**）

- **上游 = 《营销模块》的推广/促销配置页**：
  - `按优惠券` 的券主数据 ← 《营销模块》优惠券页（券名/类型/有效期/状态）；
  - `按促销活动` 的促销活动主数据 ← 《营销模块》商品促销/整单促销/特价页（促销方式/促销类型/促销模式/促销规则/起止时间）；
  - `按拼团` ← 《营销模块》商城拼团页；`按秒杀` ← 《营销模块》商城秒杀页；
  - `按商品` 的商品主数据 ← 资料模块商品档案。
  本页**不产生任何配置**，只读消费营销模块的配置对象。
- **下游 = 推广效果回收**：本页把「分享次数/浏览次数/浏览人数」等埋点与「下单人数/笔数/金额」的订单归因合并呈现，形成「营销配置 → 推广触达 → 转化」的闭环回读。活动/券配了但未被分享时，对应行不出现（0 条记录即此意）。
- **与《推广分析》分工**：《推广分析》按「职员」归集（**谁推广**），本页按「推广对象」归集（**推广了什么**）——两页互补，不可互相替代。

### 本系统对应关系

- 本系统营销域页面见《营销模块》各篇；本页当前取数**并非**这些推广对象，而是 CRM 营销活动表（见第 5 节），**上下游尚未打通**。

1. **🔴 多视图 Tab 完全缺失（最大缺口）**：对标 6 个 Tab（含 1 个客户名册视图），本系统单视图。
2. **🔴 列结构不对齐**：对标推广漏斗列（分享/浏览/下单三类）vs 本页 CRM 触达列（目标/触达/响应/转化），仅「活动名称/状态」语义近似。
3. **🔴 无列配置 / 页面配置入口**：无表头齿轮、无个人/全局配置持久化。
4. **🔴 无导出/打印**：对标有 `导出` 与 `打印(F8)`，本页 `a-table` 裸用无工具栏。
5. **🔴 无合计行**：对标 6 个 Tab 均带合计行，本页无。
6. **🔴 查询条件不对齐**：缺时间快捷段与日期范围。
7. **🟡 取数来源与营销模块未打通**：当前读 CRM 营销活动表，而非《营销模块》的优惠券/促销/拼团/秒杀单据。
8. **🟡 汇总为本地全量聚合（pageSize:500）**：超过 500 条会截断失真；每次进入页面额外发一次 500 条大分页请求。
