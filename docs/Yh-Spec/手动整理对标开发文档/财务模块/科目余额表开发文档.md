# 科目余额表开发文档

> **文档类型：** 页面对标复刻（已完成代码）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按金标准结构编写；按科目汇总的试算平衡表。

## 页面概述

科目余额表是**按科目汇总期初/本期发生/本年累计/期末四段余额的试算平衡表**。**复合页**（查询 + 分组表头汇总表格 + 合计行，无分页），单入口。

| 页面 | 地址 | 说明 |
|------|------|------|
| 科目余额表 | `finance/auxiliary`（另 `finance/trial-balance` 待复核） | 查询 + 科目汇总试算表 |

菜单：财务 → 账簿 → 科目余额表。

### 配置功能说明
- **查询参数**：会计月(起)、会计月(止)、科目层级（默认 1）、科目（指定单科目过滤）、勾选"显示无数据科目"。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

### 入口配置（本系统）
| 项 | 值 |
|----|----|
| 菜单 ID | 70223 |
| menu_code | `finance:aux-balance` |
| path | `finance/aux-balance` |

## 页面配置

### 查询条件（对标）
会计月(起)、会计月(止)、科目层级（默认 1）、科目；勾选：显示无数据科目。

### 功能按钮（对标）
刷新、打印(F8)、导出、明细对账、查询。

### 数据表列（对标 10 列）
科目类型、科目编码、科目名称、层级、期初余额、本期发生额（本期借方/本期贷方）、本年累计（累计借方/累计贷方）、期末余额。

---

## 业务规范说明

- **取数逻辑**：数据源自会计凭证分录按科目聚合——期初余额（会计月起时点）、本期发生额（起止月间借贷）、本年累计（年初至止月）、期末余额（止月时点）。
- **试算平衡**：Σ本期借方=Σ本期贷方、Σ本年累计借方=Σ本年累计贷方（凭证借贷守恒表级体现）。
- **明细对账**：科目 → 明细账穿透。
