# 明细账开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/detail-ledger`（列表查询页）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- 列表查询页（账簿查询：左树右表复合布局；科目* 为必选查询条件），按科目逐笔查询分录流水（左侧科目分类树 + 查询区 + 明细表格）。
- 单入口：菜单 财务 → 账簿 → 明细账。
- 数据实据（截图）：单据类型=会计凭证；摘要="由[收款单 SKD-20260701-041]…"、"由[提现存现转款单 YHZKD-202…]…"（业务单据自动生成凭证的回溯摘要）；记账日期精确到时分秒。

## 2. 页面配置

### 查询条件

按抓取 JSON filterLabels 实据（科目*、核算单位、核算部门、核算职员、经手人、部门）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、日期类型（单据日期）、科目*（必填，可点选左侧科目树带入）
- 核算单位、核算部门、核算职员（辅助核算三维度）、经手人、部门
- 对账标记（全部）、摘要、单据备注
- 勾选项：显示红冲
- 布局（截图）：查询区三行——第一行查询方案 + 时间快捷段（当前选中"本月"）+ 工具栏按钮，第二行日期范围（2026-07-01 至 2026-07-23）/日期类型（默认"单据日期"）/科目*（当前值"现金"）/核算三维度，第三行经手人/部门/对账标记/摘要/单据备注 + 勾选项（显示红冲，橙红色高亮）

### 功能按钮

按抓取 JSON buttons 实据：刷新、打印(F8)、导出、查询、跳转（分页跳转）

## 3. 数据表格列配置

### 默认显示列（15 列，抓取 JSON columns 实据）

对账标记、记账日期、单据日期、单据编号、单据类型、摘要、核算单位、核算部门、核算职员、借方发生额、贷方发生额、期末余额、经手人、部门、单据备注

> JSON columns 首项"对账标记 记账日期 单据日期 单据编号"为抓取拼接串（前四列表头拼接），已剔除，不计入列数。

### 全部可配置列

待复核（未抓取列配置弹窗）

### 特殊行与标记（截图实据）

- 此前余额行：表格首行（黄色高亮），显示查询起始日前的科目余额
- 显示红冲：勾选后红冲分录纳入查询（红冲=红字冲销凭证分录），橙红色高亮
- 对账标记列：可点击标记（银行对账场景逐笔勾对），列值如"否"（链接样式）

## 4. 业务规范

- 取数逻辑：数据源自会计凭证分录，按科目逐笔列出借/贷发生额，期末余额随每笔滚动。
- 凭证自动生成链（摘要实据）：业务单据（收款单 SKD-/提现存现转款单 YHZKD- 等）记账 → 生成会计凭证（KJPZ-）→ 摘要回写"由[单据类型 单号]…"→ 本页按科目呈现。
- 核算单位/核算部门/核算职员：辅助核算三维度过滤（对应会计科目主数据"核算项"设置）。
- 科目* 必填：明细账必须指定科目（点选左树或输入），防止全量流水无边界查询。
- 左侧科目分类树（截图，可折叠，约 320px 宽）：全部 → 资产类 → 现金库存（当前选中"现金"）→ 店面备用金、敦煌店面备用金、银行存款、其他货币资金、应收票据、应收账款、预付账款、应收股利、应收利息、其他应收款、坏账准备、受托代销商品、借出商品款、材料采购、在途物资、原材料、材料成本差异、库存商品、发出商品 …
- 底部分页（截图）：第(1/6)页 / 共 105 条记录 / 每页显示 20 行。
- 与其他页面关系：上游《会计凭证开发文档》（分录来源）；汇总视图《总账开发文档》（同科目按期汇总）、《科目余额表开发文档》《辅助核算余额表开发文档》；联查：单据编号链接穿透至会计凭证，凭证"源单"再穿透至业务单据；本系统前端目录 `finance/detail-ledger`（dynamicRoutes.ts 实据）。
