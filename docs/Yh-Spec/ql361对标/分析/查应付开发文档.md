> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/check-payable`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **账表页**（应付账）：供应商应付滚动台账（期初+本期应付−已结−优惠=应付余额，行级付款/对账）；应付账款管理核心页，与《查应收》镜像。菜单路径：分析 → 财务分析 → 查应付。
- 页面结构：查询区（两行）+ 左侧往来单位分类树 + 滚动账表格（操作列"付款/对账"链接）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__财务分析__查应付.png`

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels + 截图实据）

- 查询方案（--查询方案--，支持保存方案）

- 左侧往来单位分类树（全部往来单位/全部客户/全部供应商/物流公司）

## 4. 业务规范

### 统计口径（应付滚动）

- **应付余额 = 期初应付 + 本期应付款 − 本期已结 − 优惠**（合计行验证：662,427.22+275,883−241,923−1,780=694,607.22 ✅）
- **期末余额 = 应付余额 − 预付余额**（预付冲抵后的净应付；预付余额列示该单位预付款结余）
- **本期应付款**：期内采购入库/退货净增应付；**本期已结**：期内付款+预付抵扣；**优惠**：付款让利冲减
- **包含已审核未记账付款单/预付款单**：勾选后未记账单据也计入已结
- 往来对象不限于供应商：个人借款/往来（实据"老婆-高晓丽""皇朝水吧台-杨生淮借款"）也在应付口径核算

### 与其他页面关系

- 取数：采购入库单（应付发生）+ 付款单/预付款单（已结）+ 优惠
- 行级"付款"→ 付款单表单页（财务域）；"对账"→ 该单位应付明细
- 同源页：《查应收》（客户侧镜像）、《往来余额表》（应收应付净额口径）、《采购分析》（采购侧金额）
