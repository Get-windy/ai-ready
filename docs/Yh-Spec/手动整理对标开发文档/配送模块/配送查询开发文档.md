## 4. 业务规范

- **一行 = 一个配送任务**（任务编号）：按「指定配送日期」计划，按「配送开始时间 / 配送结束时间」记录实际执行。
- **配送状态三值**：待配送 / 配送中 / 已配送。
- **执行资源**：司机名称、配送车辆、送货员——**司机与送货员是两个角色**，可不同人。
- **任务聚合双向单量**：
  - 正向（发货侧）：配送单量 / 订金金额 / 发货数量 / 发货金额
  - 回流（退货侧）：退货单量 / 退货数量 / 退货金额
  - 同一配送任务既送新货又带回退货，故两组数量金额成对统计。
- **装箱数量**：任务维度装箱总量；**配送里程(km)**：任务行驶里程，供司机绩效 / 费用核算；另有隐藏的**体积(m³) / 重量(kg)**为装载体积重量口径。
- **显示红冲**：被红冲的任务/单据默认隐藏，勾选后显示。
- **上下游关系**：
  - 上游：销售订单经订单处理中心「拣货/发货」（《物流发货》）生成销售出库单 XSCKD（《发货查询》），配送任务按配送日期 + 司机/车辆组织出库单的配送。
  - 退货侧：源单为销售退货单，配送带回的退货计入「退货单量/退货数量/退货金额」，收货确认走《物流退货收货》。
  - 查询条件「配送单据编号」说明**任务与单据为一对多**。
- **链接**：物流发货（订单处理中心拣货/发货直达）、发货查询（销售出库单台账）、物流退货收货（退货回流收货确认）。

### 5.2 列定义（24 列，默认显示 20）

- 默认 20 列 + 固定「操作」列（宽 220，对标 `PredeliveryTaskList.lkoperation`）。
- 默认隐藏 4 列用 `defaultHidden: true`：司机编号(`riderId`)、体积（m³）(`totalVolume`)、重量（kg）(`totalWeight`)、打印次数(`printCount`)。
- 列口径：发货数量/发货金额 = `totalQuantity`/`goodsAmount`（任务级汇总）；配送单量/订金金额/退货三列/装箱数量 = 任务内单据聚合；配送里程 = `estimatedDistance`。

### 5.3 查询条件（13 项 + 9 段快捷时间，固定项）

| 条件 | 落库参数 |
|------|---------|
| 时间快捷段（9 段） | 作用于「指定配送日期」，默认「近一周」 |
| 日期范围（配送起/止） | `deliveryDateStart` / `deliveryDateEnd` |
| 配送状态（多选三值） | `statusList`（三值展开为执行态集合） |
| 配送司机 / 配送车辆 / 送货员 | `riderId` / `vehicleId` / `deliverymanId`（选择器，候选来自 `/filter-options`） |
| 任务编号 / 备注 / 配送单据编号 | `taskNo` / `remark` / `sourceBillNo`（模糊） |
| 制单人 | `creatorName`（选择器，候选来自历史任务去重） |
| 制单时间（起止） | `createTimeStart` / `createTimeEnd` |
| 显示红冲 | `showRed`（勾选后含已取消任务） |

### 5.4 功能按钮

- **刷新 / 导出**：导出为真实 `.xlsx`（前端 `xlsx` 生成，列与页面一致，按当前条件全量拉取，上限 5000 条）。
- **批量打印**（对标 `onPrintAll`）：未勾选提示「请选中至少一条数据！」；勾选后弹「**打印模板选择**」弹窗（打印内容复选：配送单 / 运单明细 / 运单汇总 / 出库单据 + 「仅打印未打印过的单据」），确认后按队列逐单渲染模板打印。
- **打印(F8)**：打印勾选的第一条（F8 为全局快捷键）。
- **查询 / ●保存并查询**：对标实测「保存并查询」**默认隐藏**（`showQuerySchemeButton`），仅当选了「查询方案」才显现；点击 = 以当前条件**覆盖当前方案**并立即查询，**不弹命名框**（命名的「+」为新增方案入口）。
- 打印完成后调用 `POST /api/dms/task/{id}/print` 真实累加「打印次数」。

### 5.5 操作列（对标源码 `PredeliveryTaskList.js`：field `lkoperation`，width 220，type link）

| 操作 | 对标显隐条件 | 本系统落地 |
|------|-------------|-----------|
| 打印 | `print_count==0 \|\| print_bd==0` | `printCount` 为空/0 时显示「打印」 |
| 补打 | `print_count>0 && print_bd==1`（与打印互斥） | `printCount>0` 时显示「补打」 |
| 单据明细 | 始终显示 | 右侧抽屉展示任务内商品明细（`GET /api/dms/task/{id}` 的 `items`） |
| 取消 | `columnVisible=#{post}`，`cancancel!=1` 时置灰 | 状态 ∈ {待分配, 已分配} 时显示，二次确认后 `POST /api/dms/task/{id}/cancel`（终态后置灰隐藏） |

### 5.6 状态口径（对外三值）

| 对外 | 执行态 `TaskStatusEnum` |
|------|------------------------|
| 待配送 | 0 待分配 / 1 已分配 / 2 已接单 |
| 配送中 | 3 取货中 / 4 配送中 |
| 已配送 | 5 已签收 / 6 已完成 |
| （兜底展示） | 7 已取消 / 8 异常 |

> 执行态 9 态只在执行侧（司机端 / 调度）展示；本页筛选只提供三值。
