## 页面概述

资产负债表是**按会计期间出具的财务状况报表**（资产 = 负债 + 所有者权益，左右对照）。**报表页**（查询 + 左右对照固定项目行，无分页），单入口。报表项目行为**固定**（自定义简易资产负债表，非标准会计科目分类表）。

菜单：财务 → 财务报表 → 资产负债表。

- **列配置**：数据表表头内齿轮图标（`.icon-shezhi2`，表头左起「𞸎/谢」列）→ 列配置弹窗（个人配置 / 全局配置），配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**6 列全部默认显示，无隐藏列**。

## 业务规范说明

- **报表口径**：资产（asset）/ 负债（liability）/ 权益（equity）分类；期末余额=期末时点数（所选期止月），年初余额=年初数。
- **平衡**：资产合计 = 负债合计 + 权益合计（负债和所有者权益总计）。
- **报表项目行**：**固定项目行**（自定义简易资产负债表，映射到公司实际启用账户），左右对照；资产侧与负债及权益侧项目行左右对齐。
- **期末余额链接穿透**：可点击穿透到明细账（对标；本系统待补）。

## 实现差异说明

**实现文件**：
- 前端：`views/finance/balance-report/index.vue`（组件标题「资产负债表」）
- API：`api/finance/index.ts` → `reportApi.getBalanceSheet`（`/erp/finance/report/v2/balance-sheet`）

### 页面对齐（2026-09-10 金标准升级完成）
- **前端** `views/finance/balance-report/index.vue`：`CategoryListLayout`（无分类树/无 Tab/无表尾）+ `BillTableList` 左右对照表；查询区 5 项；工具栏「刷新 / 打印(F8) / 导出」；表头 `rowNo` 列内置列配置齿轮（`storage-key="finance-balance-report-columns"`）；无页面配置弹窗。
- **后端** `FinancialReportController#balanceSheetReport` → `GET /api/erp/finance/report/v2/balance-sheet-report`，`FinancialReportService#generateBalanceSheetReport(BalanceSheetQuery)`；返回 `BalanceSheetReportDTO`（行 `BalanceSheetRowDTO` + 合计 + 平衡标志）。
- **数据源**：只读科目余额 `finance_ledger`（由凭证记账生成），不绕过凭证直改（P0 红线）。
- **固定项目行**：资产侧 现金库存(1001)/银行存款(1002)/应收账款(1122)/预付账款(1123)/库存商品(140x)/固定资产(160x 净额)/资产合计；负债及权益侧 应付账款(2202)/预收账款(2203)/预订货款(其余负债)/负债合计/未分配利润(41x + 全部损益类)/期初资本(其余权益)/所有者权益合计/负债和所有者权益总计。左右按行号对齐，右侧 8 行为最长侧。
- **口径**：期末余额 = 年初余额 + 各期发生额累计（第 1 期期初 + Σ 本期借-贷）；年初余额 = 本年度第 1 期期初数。**不依赖跨期结转链**——补录凭证到历史期间后后续期间未重算时，累计口径仍能保证「资产 = 负债 + 所有者权益」成立。
- **未分配利润含本年损益**：未结转损益时，损益类科目（4 成本 / 5 损益）余额计入未分配利润，保证资产负债表天然平衡。
- **科目层级**：父科目余额 = 自有余额 + 全部子科目余额（rollup），层级 1~4 切换不重复计、不遗漏。
- **穿透**：明细行「资产期末余额 / 期末余额」为链接，点击跳转 `/finance/detail-ledger?subjectId=&dateStart=&dateEnd=`（本年度 1/1 ~ 期止月月末），合计行不可穿透。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 平衡公式（红线）**：资产负债表只读取自科目余额，**严禁绕过凭证直改**；资产合计=负债合计+权益合计必须成立。
- **P1 勾稽**：期末/年初余额与科目余额表/利润表净利润核对一致。
- **P1 分类口径**：资产/负债/权益分类清晰，期初/期末两列口径准确。
- **P2 验收**：无桩/无模拟；平衡公式、勾稽、穿透需真实数据闭环验证。

### 验收记录（2026-09-10）
- **接口**：`GET /erp/finance/report/v2/balance-sheet-report`，9 个场景（单/多会计月、会计月 1/7/9、科目层级 1/2/4、显示/隐藏 0 科目、无数据年度）全部 `code=200` 且 `资产合计 = 负债合计 + 所有者权益合计`（差额 0.00、`balanced=true`）。
- **前端端到端**（headless Chromium，真实登录 + 真实数据）：表头 6 列与对标一致；8 行左右对照；平衡条「资产合计 3,945.00 = 负债合计 -1,245.00 + 所有者权益合计 5,190.00 平衡」；工具栏 3 按钮且无「配置」齿轮；查询区 5 项；列配置弹窗含「个人配置/全局配置」两 Tab 与 6 列、恢复默认；控制台 0 error。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
