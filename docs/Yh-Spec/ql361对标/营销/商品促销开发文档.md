## 1. 页面概述

- **列表页**：按商品/明细行生效的促销活动维护页，查询区 + 活动列表，行级查看/修改；新增商品促销/修改维护，无阶段 Tab、无统计卡片。
- 截图：![商品促销](../../../../tool-results/ql361/pages/营销__营销活动__商品促销.png)

## 2. 页面配置

### 查询条件

- 商品、客户（弹选）
- 促销类型（全部）、组合促销（全部）、促销模式（全部）
- 起始时间、结束时间
- 使用范围（全部）、活动状态（全部）、制单人（弹选）
- 勾选项：显示已过期/已作废活动（默认不勾选）

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增商品促销、更多玩法告诉我们..、查询、跳转（分页跳转）
- 行级操作（截图确认）：查看、修改、更多（操作列）

### 打印配置

无（页面无打印按钮，截图确认；列表页打印能力待复核）

## 3. 数据表格列配置

### 默认显示列（14 列，抓取 JSON columns 实据）

操作、活动名称、起始时间、结束时间、促销方式、促销商品、组合促销、促销类型、促销模式、促销规则、促销客户、使用范围、活动状态、制单人

> JSON columns 首项即"操作"，无拼接串，14 列全部为真实列；截图可见前 10 列，其后（促销客户/使用范围/活动状态/制单人）横向滚动。

## 4. 业务规范

- 促销规则模型（行数据实据归纳）：
  - 作用层级：促销方式=商品促销——按商品/明细行生效（区别于《整单促销开发文档》按整单门槛生效）；销售订单明细列"优惠折扣(%)/惠后单价/优惠后金额"（销售域实据）为其落点
  - 规则要素：促销类型（实据"按商品数量"）× 促销模式（实据"满赠"）→ 促销规则自然语言化："订单单个促销商品数量满 5.000000，赠送【亿海裙带丝】1.000000【件】"——买 N 赠 M，赠品可为同款商品
  - 组合促销（实据"否"）：标记本活动是否可与其他促销活动叠加；为否时互斥优先级待复核
  - 定向维度：促销商品（哪些商品参与）、促销客户（哪些客户可享受）、使用范围（线上/线下渠道）三维定向
  - 生命周期：新增 → 起始~结束时间窗内生效（活动状态）→ 过期自动失效或人工作废；"显示已过期/已作废活动"默认隐藏历史活动
  - "更多玩法告诉我们.."：厂商收集促销玩法需求的反馈入口（按钮实据），佐证促销类型/模式为可扩展枚举
- 与其他页面关系：与《整单促销开发文档》互补（商品促销按行、整单促销按单，两者查询区与列结构同构，14 列一致，JSON 实据）；与《特价开发文档》区别（特价直接改价，商品促销按规则减免/赠送）；销售开单联动（销售订单摘要"促销优惠"来源之一即本页活动）；商城侧（我要推广可推广"促销"活动）；本系统落地对应 `/api/sale/promotion`（促销活动，api/marketing.ts 实据）
