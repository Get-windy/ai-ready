## 1. 页面概述

优惠券页是**优惠券制券 + 领用核销的一体管理页**：`优惠券设置` Tab 维护券模板（面值/总数/领取与使用情况/指定客户/有效期/双通道），`领用明细` Tab 查询逐客户逐券的领取与核销流水。**单入口、双视图 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 优惠券 | `marketing/coupon` | 单入口复合页（2 个视图 Tab：优惠券设置 / 领用明细；逐 Tab 独立列配置） |

单入口：营销 → 营销活动 → 优惠券。

- 实测实据（2026-09-15）：`优惠券设置` 共 **1** 条记录（在线下单减5元，面值 5.00元，总数 1000 / 已领取未使用 48 / 已使用 82 / 未领取 870，全部客户、正常、商城允许、线下禁止）；`领用明细` 共 **0** 条记录。

### 口径说明

- `优惠券设置` = **制券视图**：`面值/总数` 定义券，`已领取（未使用）/已使用/未领取` 三列构成**数量守恒**（总数 = 三者之和，实测 1000 = 48 + 82 + 870），`商城使用/线下使用` 双通道，`指定客户` 限定发放对象。
- `领用明细` = **逐客户逐券的领用/核销流水**：`客户/联系人/联系电话` 定位领用人，`领用状态/状态/领取时间/使用时间/来源单据` 记录生命周期。
- 「操作」列**不进列配置弹窗**（固定动作列）——基准文档记「默认 16 列」即由此多出的 1 列；弹窗口径为 15 列。

## 4. 业务规范

- **数量守恒口径（基准文档，待复核）**：总数 = 已领取（未使用）+ 已使用 + 未领取——本券记录型视图（13 列）不含总数/存量拆分列，该口径属制券视图。
- **发放双模式（基准文档，待复核）**：开放领取=是 → 客户商城自助领取；=否 → 后台定向发放。
- **双使用通道（基准文档，待复核）**：商城使用 / 线下使用 两列标记线上/线下可用。
- **生命周期（实测列可支撑）**：领取时间 → 使用时间 →（有效期至）失效；领用状态与状态双列描述当前态；「来源单据」标注券来自哪张单据（来源单据实据）。
- **字段实据**：`类型`（券类型，取值枚举措待复核）、`使用规则`（如「无限制」/满 N 可用，待复核）、`面值`（金额）。
- **与其他页面关系**：销售开单联动（订单结账面板「优惠金额(−)」来源之一）；商城侧与「我要推广」可推广优惠券；效果归入分析域「营销分析」；本系统落地对应 `/api/erp/marketing/coupon`。

### 计算口径（逐条）

| 环节 | 口径 | 业界依据 |
|------|------|---------|
| 命中判定 | 活动状态 `published` + 时间覆盖 + 使用范围（线下/商城）匹配 + 促销客户（空＝全部，雪花 id 按字符串比对） | — |
| 优先级 | `priority` 降序，**同优先级按 id 升序兜底** | SAP 明确要求避免同优先级（否则随机选择） |
| 叠加/互斥 | `stack_policy=STACK` 继续算；`EXCLUSIVE` 命中即停（更低优先级不再参与） | SAP 独占/非独占规则组 |
| 条目消耗 | 同一商品行只被**一个行级**活动（商品促销/特价）消耗，高优先级先占 | SAP Order Entry Consumption |
| 折扣计算 | 打折＝匹配行金额×(1−折扣率)；满减＝达门槛减固定额；特价＝Σ(行成交价−特价单价)×数量；满赠＝0（只登记赠品） | Odoo Reward 类型 |
| 封顶 | `max_discount_amount` 限制单条活动在本单的优惠上限 | SAP Caps |
| 分摊 | 行级优惠摊到命中行；整单级优惠按**各行金额占比**摊到每一行（末行吃舍入残差，保证合计=优惠额） | SAP / Commerce Layer 分摊法 |
| 券校验 | 状态 UNUSED + 未过期 + 属本客户 + 通道开关 + 门槛（`use_rule`） | — |
| 次数 | 试算**不累加**；只有落单才 `quota_used + 1` | — |
