# 采购准备开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`analytics/purchase-prep`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **复合页**（统计分析 + 业务操作）：四种补货策略（库存预警/缺货/智能/以销定购）的采购建议工作台，勾选后一键生成采购单；补货建议→采购下单的操作闭环页。菜单路径：分析 → 采销分析 → 采购准备。
- 页面结构：策略 Tab（4 个）+ 缺货公式条（黄色）+ 查询区（一行）+ 左侧商品分类树 + 建议表格（首列勾选框）+ 合计行。
- 页面截图：`tool-results/ql361/pages/分析__采销分析__采购准备.png`

## 4. 业务规范

### 统计口径（四种补货策略）

- **缺货数量公式**（页面公式条实据）：缺货数量 = 库存上限 + 待发货 − 账面数量 − 待收货（"点击设置"可调整公式构成项）
- **库存预警补货**：账面数量触及库存下限的商品，补到库存上限；预警类型（下限预警/上限预警）区分
- **缺货补货**：当前已缺货（待发货>账面数量）的商品
- **智能补货**：按历史销量/周转智能计算建议采购量（算法口径待复核）
- **以销定购**：按未发货销售订单（含预订货）反推采购需求
- **上下游联动**：勾选商品 →"采购"生成采购订单/采购入库单草稿，完成"预警→补货→下单"闭环

### 与其他页面关系

- 取数：库存（账面数量/库存上下限）+ 待发货（销售订单未发）+ 待收货（采购订单未收）+ 商品主数据（品牌/口味/型号/所属供应商）
- 下游：采购订单（CGDD-）/采购入库单（CGRKD-）；《查库存》（账面数量口径）、《销售履约分析》（待发货口径）
