## 三、AI-Ready 遗漏的功能点（按优先级排列）

### 🔴 高优先级（核心业务缺失）

#### 1. 商品规格属性（SKU 体系）
管家婆支持 `prop1`（颜色）、`prop2`（尺码）两级规格属性，每个属性有独立 ID 和名称。商品按规格拆分 SKU，库存按 SKU 维度管理。

**AI-Ready 现状**：产品模块没有规格属性体系，SKU 管理缺失。虽然 ERP 系统有 `erp/product` 和商品条码管理，但缺少完整的规格→SKU 维度的库存管理。

**建议**：建立 规格属性 → SKU → 库存 三级体系，规格属性支持自定义名称（颜色/尺码/版本等），每个 SKU 可独立管理库存、价格、条码。

#### 2. 单位换算体系（副单位）
管家婆每个明细行有 `unit`（主单位）、`unitrate`（换算率）、`subqty`（副单位数量）。

**AI-Ready 现状**：产品模块有 `ProductUnitsPanel.vue` 多单位管理组件，但下单时如何选择单位、如何做单位换算，尚未在前端业务页面中完整体现。

**建议**：在采购/销售订单的明细行中支持单位切换，显示主单位和副单位数量，后台做单位换算。

#### 3. 折扣价体系
管家婆明细行有 `assdpprice`（折前单价）和 `asstpprice`（折后单价）两个字段，支持折扣率计算。

**AI-Ready 现状**：定价引擎模块（`erp/pricing`）已有基础框架，但前端业务单据（采购/销售订单）中缺少折前单价、折扣率、折后单价的三段式展示。

**建议**：采购/销售订单明细行增加：单价（标准价）→ 折扣率(%) → 折后价 三段式输入。

#### 4. 税率字段
管家婆每个明细行有 `tax`（税率%）字段。

**AI-Ready 现状**：前端页面的采购/销售订单中看不到税率字段。

**建议**：所有业务单据明细行增加税率字段，与财务模块的科目/凭证对接。

### 🟡 中优先级（可用但不够完善）

#### 5. 单据中心（统一单据查询）
管家婆有独立的"单据中心"API（`beefun.bill.summary.list`），可以按单据类型、时间范围统一查询所有业务单据。

**AI-Ready 现状**：每个模块各自有列表页，但缺少一个统一的"所有单据"查询入口。

**建议**：新增一个"单据中心"模块，聚合所有业务单据类型，支持跨模块搜索单据号、查看单据状态。

#### 6. 草稿箱机制
管家婆支持"单据草稿"概念（销售出库单草稿、退货单草稿、费用单草稿、收款单草稿），用户可以先保存草稿后续提交。

**AI-Ready 现状**：当前只有"新建/编辑"表单直接提交，没有显式的草稿保存机制。

**建议**：在 FormLayout 中增加"保存为草稿"按钮，表单数据持久化到本地或后端，支持草稿列表管理。

#### 7. 仓库仓位
管家婆明细行支持 `position`（仓位）字段，精确到货架位置。

**AI-Ready 现状**：WMS 模块有库位管理（`wms/location`），但仓库-库位-货位的三级结构尚未在业务单据中体现。

**建议**：在采购入库/销售出库等业务单据中增加仓位选择，对接 WMS 的库位数据。

#### 8. 其他出入库 / 内部领用
管家婆支持"其他出库单(139)"、"其他入库单(126)"、"内部领用单(152)"、"领用退回单(153)"等辅助单据类型。

**AI-Ready 现状**：只有标准的采购/销售/调拨/盘点单据。

**建议**：增加其他出入库、内部领用等辅助库存变动单据。

### 🟢 低优先级（锦上添花）

#### 9. 项目管理
管家婆有独立的"项目列表查询"API，支持按项目维度核算。

**AI-Ready 现状**：完全无项目管理功能。

**建议**：后续如有项目制核算需求，可考虑增加简单项目管理模块，支持按项目归集收入和费用。

#### 10. 账套期初数据
管家婆支持账套基本信息和历史数据导入，这是企业初始化的刚需功能。

**AI-Ready 现状**：有租户管理但无期初数据导入功能。

**建议**：增加系统初始化向导，支持导入期初库存、期初应收应付、会计科目期初余额。

#### 11. 销售换货
管家婆支持销售换货单(142)，AI-Ready 只有采购换货。

**建议**：增加销售换货功能。

## 四、AI-Ready 的优势（做得更好的地方）

| 领域 | AI-Ready 优势 | 管家婆对比 |
|------|-------------|-----------|
| **WMS 仓储执行** | 完整的 WMS 模块（仓库/库位/收货/上架/拣货/波次/发货/盘点/移库/质检/事件） | 只有基础的云 WMS 出入库 |
| **DMS 配送管理** | 完整的配送管理体系（渠道/骑手/车辆/路线/调度/订单池/追踪/核验/配置） | 只有物流公司列表 |
| **费用管理** | 完整的费用申请→报销→审批→付款→统计闭环 | 只有基础费用单 |
| **资产管理** | 完整的资产全生命周期（资产/分类/采购/折旧/调拨/处置/盘点/报表） | 无 |
| **预算管理** | 完整的预算体系（模板/年度/调整/报表） | 无 |
| **CRM** | 完整的客户关系管理（线索/商机/客户/合同/发票/供应商） | 只有往来单位管理 |
| **报表分析** | 销售分析/销售报表/财务报表 | 只有基础资产负债表和经营情况表 |
| **权限体系** | 完善的 RBAC + 数据权限 + 按钮级权限 | 基础权限控制 |
| **多租户** | 完整的租户管理/租户审批/模块编码控制 | 单租户（账套模式） |
| **国际化** | 支持中文/英文/日文/韩文 | 只有中文 |
| **前端技术栈** | Vue 3 + TypeScript + VxeTable 企业表格 | 未知 |

## 五、总结与建议

### 必须补齐的核心功能（高优）

1. **SKU 规格属性体系** — 建立 规格属性 → SKU → 按SKU库存 的三级模型
2. **单位换算** — 在业务单据中真正落地单位选择和换算
3. **折扣价 + 税率** — 明细行增加 原价/折扣率/折后价/税率

### 建议新增的功能（中优）

4. **单据中心** — 统一所有业务单据的查询入口
5. **草稿箱机制** — 支持保存草稿、暂存、后续提交
6. **其他出入库/内部领用** — 补齐库存辅助单据
7. **仓库仓位** — 业务单据对接库位选择

### 可以后续考虑（低优）

8. 项目管理
9. 账套期初数据导入
10. 销售换货
