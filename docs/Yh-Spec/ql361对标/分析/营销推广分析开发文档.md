## 1. 页面概述

- **列表查询页**（统计分析页）：商城分享推广按商品/优惠券/活动/拼团/秒杀五维度效果（分享→浏览→下单漏斗）；商城营销推广的渠道效果页。菜单路径：分析 → 营销分析 → 营销推广分析。
- 页面结构：子视图 Tab（6 个）+ 查询区 + 汇总表格（合计行）。
- 页面截图：`tool-results/ql361/pages/分析__营销分析__营销推广分析.png`

## 4. 业务规范

### 统计口径（推广漏斗）

- **漏斗链路**：分享次数（分享行为数）→ 浏览次数（PV）/浏览人数（UV 去重）→ 下单数量/下单金额（转化）
- **五维度**：按商品（商品推广效果）/按优惠券（券分享核销）/按促销活动（活动分享）/按拼团（拼团裂变）/按秒杀（秒杀引流）；推广客户列表为被分享触达的客户名册
- **与《推广分析》分工**：推广分析按"职员"归集（谁推广），本页按"推广对象"归集（推广了什么）

### 与其他页面关系

- 取数：商城分享埋点 + 商城订单归因
- 同源页：《推广分析》（职员侧）、《交易分析》（商城整体转化）
