# 借进单开发文档

## 页面概述

借进单用于向往来单位借入商品入库录单（后续需还出或借转采购）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 借进单列表页 | http://localhost:5656/wh/borrow-in/index | 双入口「历史」标签，按单据/按明细 2 个 Tab |
| 新增/编辑借进单表单页 | http://localhost:5656/wms/borrow-in/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 80010 |
| menu_code | `wh:borrow-in` |
| 主菜单路径 | `wms/borrow-in/form`（点击进新增表单） |
| 标签「历史」路径 | `wh/borrow-in/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `views/wh/borrow-in/form/index.vue`（表单）、`wh/borrow-in/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后借进商品入库存（借进库存，与自有库存区分）。
- 预计还出时间：承诺归还日期，供借进借出查询跟踪逾期。
- 借进后续两条出路：还出（还出数量/还出金额）或借转采购（借转采购数量/借转采购金额，转为正式采购入库）。
- 往来单位必填（借进必有出借方，区别于其他入库单往来单位非必填）。
- 反向单据：借出单（借出给往来单位，预计还回时间）；台账查询：借进借出查询；借转采购后关联采购业务（采购入库体系，待复核）。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
