| 页面 | 地址 | 说明 |

| 费用统计 | `finance/expense-stats` | 申请日期区间查询 + 统计卡片 + 图表 + 部门明细表 |

菜单：财务 → 费用管理 → 费用统计。

### 配置功能说明

- **查询参数**：申请日期范围（`a-range-picker` → `startDate`/`endDate`）。

## 业务规范说明

- **数据源**：`/erp/expense/statistics/summary`，一次性返回统计汇总及 `byType`/`byDepartment` 两个分组映射，前端本地派生图表与占比。
- **日期口径**：按费用单**申请日期**（applyDate）区间过滤（`startDate`/`endDate`，当天起止包含）。
- **金额口径**：`totalAmount`=全部费用单金额；`approvedAmount`/`pendingAmount`/`rejectedAmount`=按状态分组的在审/通过/拒绝金额；`expenseCount`=单据数；`averageAmount`=总额/单数。
- **分组口径**：`byType` 按费用类型、`byDepartment` 按申请部门分组汇总，均为「名称 → 金额」映射（空值按 0 处理）。
- **派生占比**：部门明细表「占比」= 部门金额 / 总额 × 100%（总额为 0 时显示 0.0%）。
- **上游**：费用单（`finance:expense-doc`）提交/审批的数据实时进入本页统计。

## 实现差异说明

**实现文件**：
- 前端：`views/finance/expense-stats/index.vue`
- API：`api/finance/index.ts`（`expenseStatsApi.getSummary` / `getByDepartment` / `getByType` → `/erp/expense/statistics/{summary,by-department,by-type}`）
- 后端：`erp-finance` `expense/controller/ExpenseController.java`（`@RequestMapping("/api/erp/expense")`，`@GetMapping("/statistics/summary"`/`/statistics/by-department`/`/statistics/by-type`)）
- 表：`expense_application`（费用单，分组聚合源）

### 页面对齐（已建成）
- **统计卡片**：`ARStatCards`，6 指标卡在 `summary` 非空时渲染。
- **图表**：`ARReportChart`（ECharts 封装），`byType` 饼图、`byDepartment` 柱状图。
- **明细表**：`a-table`（部门/金额/占比），`pagination=false`。
- **查询**：日期区间 → `loadData` → `getSummary(buildParams())`，`onMounted` 首次加载。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 统计单一口径（红线）**：费用统计复用《费用单》（`expense_application`）作为唯一数据源，**严禁另建重复统计表/重复费用数据表**，状态与金额口径与《费用审批》严格一致。
- **P1 状态/分组一致**：`approvedAmount/pendingAmount/rejectedAmount` 与审批状态机（在审/通过/拒绝）逐一对齐；`byType/byDepartment` 分组口径唯一（名称→金额，空值按 0），保证前后端口径一致。
- **P2 验收**：无桩/无模拟；申请日期区间、统计卡片、分组图、部门明细占比闭环真实生效；与费用单/审批数据一致。
