# 职员部门开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`system/department`（部门）+ `system/user`（用户）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：职员档案与部门档案维护页，2 个子标签（职员信息 / 部门信息），左侧所属部门树 + 查询区 + 数据表格；当前抓取为职员信息子标签。
- 截图：![职员部门](../../../../tool-results/ql361/pages/资料__职员权限__职员部门.png)

## 2. 页面配置

### 查询条件

- 筛选条件（请输入职员编号/姓名）
- 勾选项：显示停用
- 左侧所属部门树（全部、管理部、客服部、配送部、仓管、兼职人员）按部门过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：新增职员、刷新、打印(F8)、导出、导入、查询、跳转（分页跳转）
- 行级操作（截图确认）：修改、删除、停用；操作员账号列内"添加操作员"（未开通时）

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（10 列，抓取 JSON columns 实据，职员信息子标签）

操作、职员编号、职员姓名、性别、部门、直属上级、职务、联系电话、是操作员、操作员账号

> 本页 JSON columns 无抓取拼接串（首项"操作"为真实单列）。部门信息子标签列结构未抓取，待复核。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 职员与操作员分离：职员档案是人事维度，操作员是系统登录账号；职员可"添加操作员"开通账号（截图实据：是操作员 √ / 操作员账号链接），与"全部操作员"页联动
- 直属上级：职员间汇报关系（截图实据：配送员直属上级为高晓丽，高晓丽直属上级为杨生淮），用于审批流/业绩归属
- 职务：自由文本职务（老板/总经理/销售经理/配送员等），与"岗位权限"的岗位（权限维度）是两个概念
- 停用优先：行级提供"停用"，与"显示停用"勾选项配套
- 部门信息子标签：维护部门档案（左侧部门树的数据源），未抓取待复核
- 与其他页面关系：岗位权限（操作员绑定岗位获得功能权限）、全部操作员（账号列表与数据权限）、销售订单等单据（"经手人"引用职员档案；"默认经手人"在客户档案引用）、司机配送端（配送员与 DMS 骑手/司机账号关联）
