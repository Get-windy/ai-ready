# 配送单开发文档

> **对标状态：⚠️ ql361 无此页面**——2026-09-12 实测确认：对标系统「配发收 → 配送业务」下**只有「配送查询」**，菜单面板仅 `配送业务(配送查询) / 发货业务(物流发货、发货查询) / 收货业务(物流退货收货、采购订货收货)`，**不存在「配送单」**。故本页为**本系统新增单据**，按本系统自主建模，**不得臆造 ql361 字段**。
> 本系统路由：`dispatch/dispatch-order`（双入口：主菜单 → 表单页 `/form`；标签「历史」→ 列表页 `/index`）
> 关联文档：《配送查询开发文档》（本单据的台账查询）、《配送模块（DMS）开发文档》（资源与调度）、《销售出库开发文档》（上游来源）。
> 通用规范见《对标开发技术参考文档》第 4、5 章。

## 1. 页面概述

- **双入口单据页**：主菜单点击进入**表单页**（新建配送单），标签「历史」进入**列表页**（配送单列表）。
- 业务定位：**一次配送动作的载体**——由出库/送货需求生成，承载「来源单据 → 配送任务 → 司机/车辆执行 → 签收」的全过程。
- 数据落地：本系统 `DmsTask`（`/api/dms/task`，表 `dms_task`），状态机 0–8。
- 与《配送查询》的关系：配送查询是本单据的**台账视图**（含收发货双向统计与里程），**同一数据源**，查询侧需将 DMS 执行态映射为对标三值口径（见 §5）。

## 2. 列表页

### 2.1 页面配置（查询条件）

> 按本系统金标准：查询条件进「页面配置 → 查询条件」Tab。

- 配送日期（起 至 止）+ 时间快捷段（昨日/今日/近两日/近一周/近一月/本周/上周/本月/上月）
- 任务编号、来源单据编号、订单号、客户、收货人/联系电话
- 配送状态（多选：待配送/配送中/已配送）
- 配送司机、配送车辆、送货员、配送线路、配送区域
- 制单人、制单时间（起 至 止）、备注
- 勾选项：显示红冲

### 2.2 功能按钮

页面配置 → 功能按钮 Tab：刷新、新增、批量打印、打印(F8)、导出、删除、审核/反审核（如启用）。工具栏右侧：页面配置 / 新增 / 刷新 / 打印(F8) / 导出（**不含列配置**）。

### 2.3 数据表格列配置

列配置入口 = 数据表表头序号列的齿轮（`BillDetailTable` 内置个人/全局配置），`storage-key` = `dispatch-order-columns`。

**建议列（对齐《配送查询》口径 + DMS 自身字段；★ = 默认显示）**

| 列 | 来源 | 列 | 来源 |
|----|------|----|------|
| ★ 指定配送日期 | `deadlineTime`/计划日 | ★ 配送单量 | 聚合 |
| ★ 任务编号 | `taskNo` | ★ 订金金额 | 聚合 |
| ★ 配送状态 | `status`（映射三值） | ★ 退货单量 | 聚合 |
| ★ 配送开始时间 | `pickupTime` | ★ 发货数量 | `totalQuantity` |
| ★ 配送结束时间 | `deliveryTime` | ★ 发货金额 | `goodsAmount` |
| 司机编号 | `riderId` | 退货数量 | 聚合 |
| ★ 司机名称 | `riderName` | 退货金额 | 聚合 |
| ★ 配送车辆 | `vehicleName` | ★ 装箱数量 | 聚合 |
| ★ 送货员 | 送货员 | ★ 配送里程(km) | `estimatedDistance` |
| 体积（m³） | `totalVolume` | 重量（kg） | `totalWeight` |
| ★ 备注 | `remark` | 打印次数 | 打印 |
| ★ 制单人 | `createBy` | ★ 制单时间 | `createTime` |

> 默认隐藏：司机编号、体积（m³）、重量（kg）、打印次数（与对标《配送查询》的隐藏列一致）。

## 3. 表单页配置

### 3.1 表头字段（建议分组）

| 分组 | 字段 | 必填 | 说明 |
|------|------|:---:|------|
| 基本信息 | 任务编号 | 是 | 号段生成（见 §4.1） |
| | 指定配送日期 | 是 | 计划配送日 |
| | 订单类型 | 是 | 销售配送 / 调拨 / 退货 |
| | 优先级 | 否 | 普通 / 紧急 / 加急 |
| 来源单据 | 关联订单号 | 是 | 销售订单/调拨单/退货单 |
| | 来源仓库 / 发货地址 | 否 | `sourceWarehouseId` / `sourceAddress` |
| 收货信息 | 客户名称 | 是 | 往来单位（选择器） |
| | 联系电话 / 收货地址 | 否 | |
| | 要求送达时间 | 否 | `deadlineTime` |
| 配送资源 | 配送线路 / 配送区域 | 否 | 引用《线路》主数据 |
| | 配送司机 / 配送车辆 / 送货员 | 否 | 调度后回填 |
| 费用 | 货品金额 / 配送费 / 代收货款 | 否 | 金额由后端复核 |

### 3.2 明细（商品行）

`BillDetailTable` 明细列（建议）：商品名称、货号、条码、单位、数量、单价、金额、重量（kg）、体积（m³）、明细备注。
合计：商品行数 / 总数量 / 货品金额。

> ⚠️ **现状缺口**：当前表单**无商品明细**（仅头字段），而配送单需承载商品行；落地时必须补明细表（见 §5 待完善）。

### 3.3 底部与摘要

- 底部资金区：货品金额 / 配送费 / 代收货款 / 应收合计（金额后端复核）。
- 制单人 / 制单时间。
- 配置弹窗 3 Tab：**页面配置 / 录单默认值 / 打印设置**（按本系统金标准）。

## 4. 业务规范

### 4.1 单据编号

- **现状**：前端 `PS + YYYYMMDDHHmmss`（时间戳），**不符合号段规范**。
- **建议**：按本系统统一号段（`sys_number_rule` + `/{module}/next-no`）生成，格式 `PSD-YYYYMMDD-序号`（与销售 `XSDD-`/出库 `XSCKD-` 风格一致，对标配送任务编号规则**待复核**）。

### 4.2 状态机（DMS 执行态 → 查询三值口径）

| DMS `status` | 含义 | 配送查询三值映射 |
|:---:|------|:---:|
| 0 | 待分配 | 待配送 |
| 1 | 已分配 | 待配送 |
| 2 | 已接单 | 待配送 |
| 3 | 取货中 | 配送中 |
| 4 | 配送中 | 配送中 |
| 5 | 已签收 | 已配送 |
| 6 | 已完成 | 已配送 |
| 7 | 已取消 | （不显示/灰显） |
| 8 | 异常 | （异常标记） |

> 状态流转由后端校验 `fromStatus → toStatus` 合法性（`PUT /dms/task/{id}/status`）。

### 4.3 与上下游

- **上游**：销售出库单（`XSCKD-`）/ 调拨单 / 退货单 → 生成配送任务（关联订单号）。
- **下游**：司机端（`frontend/apps/driver-delivery`）执行 → 签收（`dms_sign`）→ 回写配送状态；配送查询台账统计收发货双向单量与里程。
- **调度**：调度任务/智能调度/订单池（见《配送模块（DMS）开发文档》）为配送单指派司机与车辆。
