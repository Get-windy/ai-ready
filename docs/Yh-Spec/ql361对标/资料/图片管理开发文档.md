# 图片管理开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：商品图片在商品档案内维护，独立页面对应关系待复核
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：商品图片批量上传与主图维护页，2 个子标签（商品图片列表 / 图片空间），当前抓取为商品图片列表子标签，按商品逐行上传图片。
- 截图：![图片管理](../../../../tool-results/ql361/pages/资料__商品管理__图片管理.png)

## 2. 页面配置

### 查询条件

- 查询方案（--查询方案--，支持保存方案）
- 筛选条件（请输入品名/货号/助记码）
- 图片（全部，按"是否有图片"过滤的推断，待复核）
- 规格、型号、产地、品牌
- 商品状态（全部）
- 排序（按货号）、顺序
- 左侧商品分类树按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：查询、选择图片、跳转（分页跳转）
- 注：本页无 刷新/打印(F8)/导出 按钮（截图确认右侧无功能按钮行），"选择图片"为行内上传按钮
- 行级操作（截图确认）：选择图片（上传）、主图（单选）、删除（图片下方红色 ×）

### 打印配置

无（页面无打印按钮，截图确认）。

## 3. 数据表格列配置

### 默认显示列（9 列，抓取 JSON columns 实据，商品图片列表子标签）

商品名称、商品状态、货号、规格、型号、产地、品牌、上传图片、图片

> 本页 JSON columns 无抓取拼接串（首项"商品名称"为真实单列）。图片空间子标签结构未抓取，待复核。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 一行一商品：图片按商品维护（不按单位分行，与商品条码/价格页粒度不同）
- 主图：多张图片中选定一张为主图（截图实据：图片下方"主图"单选钮），主图用于商城/单据显示
- 上传图片：行内"选择图片"按钮直接上传，上传后即时显示在"图片"列
- 商品状态：启用/停用，与商品档案显示状态同步
- 图片（全部）查询条件推断为按"有/无图片"过滤，便于批量补齐缺图商品（推断，待复核）
- 与其他页面关系：商品（图片列显示商品主图缩略图，同源维护）、商城（B2B/B2C 商品图片展示）、图片空间子标签（推断为已上传图片素材库，未抓取待复核）
