# 商城装修开发文档

> **文档类型：** 页面对标复刻（配置/表单型页面 · 商城视觉装修）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）商城模块
> **对标来源：** 顶部「商城」菜单 → 「商城设置」组 → 「商城装修」。**来源=对标系统实测抓取 2026-09-07**
> **定位：** 商场首页/页面装修的可视化配置（主题风格/装修模板/分类页/商品详情）。即 XSMK 商城「商城设置 → 商城装修」。

## 页面概述

商城装修是**商城买家端视觉装修配置中心**：通过主题色、装修模板、分类页展示、商品详情富文本四个方面配置微商城首页与相关页面的外观与布局。**单入口，配置/表单型页面**（无数据表列表，无列配置/页面配置弹窗，4 个内部 Tab）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 商城装修 | `mall/shop-decoration` | 配置/表单页（4 个 Top Tab：风格选择 / 装修模板 / 分类页装修 / 商品详情） |

单入口：商城 → 商城设置 → 商城装修。

- 实测实据：页面顶部 4 个 Tab：**风格选择 / 装修模板 / 分类页装修 / 商品详情**。每个 Tab 为独立装修配置区，底部「保存」按钮。无标准查询区/功能按钮区。

### 配置功能说明
- **列配置/页面配置弹窗**：**无**。配置/表单型页面，无数据表列配置 `.icon-shezhi2`，无顶部「配置」齿轮（无查询条件/功能按钮 Tab），按其真实设置项清单改写。
- ⚠️ **当前实现说明**：本页当前为「页面模板选择 + 轮播图管理」两个卡片（真实接口），**尚未对齐金标准 4 Tab 装修结构**，见「实现差异说明 → 待完善」。

## 页面结构（配置/表单型）

商城装修 = **4 个 Top Tab**，每个 Tab 一组装修配置项，底部统一「保存」按钮。**无列配置/页面配置弹窗**。

### Tab 一：风格选择（默认激活）
通过颜色的选择切换商城主题和主要操作按钮的颜色。
| 字段 | 控件 | 默认值/说明 |
|------|------|------|
| 主题色 | 主题色卡片选择（9 种） | 绯红 / 宝蓝 / 亮橙 / 桃粉 / 天蓝 / 翠绿 / 香槟 / 炫紫 / 深绿 |

### Tab 二：装修模板
装修模板 = 子 Tab「我的模板」+「模板库」（提示：静态提示文案，非数据表）。

**子 Tab · 我的模板**
- 提示文案：1、您可点击"新增模板"然后进行编辑保存，保存后所有模板将显示在此页面；2、操作【发布模板】即可应用当前模板到微商城。
- 按钮：刷新、新增模板。
- 正在使用模板：皇朝餐饮货仓首页01。
- 模板列表（7 个）：食品快消品、生鲜农贸、食品快消品、食品快消品、母婴用品、办公用品、化妆用品。
- 操作：点击「新增模板」进入排版布局/拖拽装修编辑器进行编辑→保存→发布。

**子 Tab · 模板库**
- 提示文案：1、操作步骤：选择心仪的模板>点击【引用】>跳转至排版布局页面进行编辑>点击【保存】即可完成，也可操作【发布】，发布后商城会立即应用该模板；2、模板不具备唯一性，您可以选择任意一个行业的模板进行布局；3、点击【发布】后，您需要对当前模板进行商品关联，以便用户访问才能看到商品数据。
- 行业模板（14 个）：办公用品、服装鞋帽、化妆用品、机械机电、家电数码、母婴用品、汽修汽配、生鲜农贸、食品快消品、手机通讯、通用行业、五金建材、医药制品、珠宝钟表。
- 操作：每个模板右侧「引用」按钮（引用后跳转排版布局页编辑≥保存/发布）。

### Tab 三：分类页装修
分类页展示配置。
| 字段 | 控件 | 默认值/说明 |
|------|------|------|
| 分类展示方式 | 单选 | 按目录分类（默认勾选）/ 按品牌分类 |
| 商品默认排序 | 下拉选择 | 综合排序（下拉选项） |
| 分类页分类样式 | 单选 | 纯文本模式（默认勾选）/ 图文模式 |
| 显示分类下商品数量 | 复选框 | 勾选（默认开启） |

- 提示：纯文本模式将不会展示分类图片。

### Tab 四：商品详情
商品详情页富文本装修（富文本编辑器）。
| 字段 | 控件 | 默认值/说明 |
|------|------|------|
| 商品详情 | 富文本编辑器（工具栏：加粗/斜体/下划线/字符边框/删除线/格式刷/字体颜色/背景色/有序列表/无序列表/清空文档/自定义标题/段落格式/字体(arial)/字号(16px)/首行缩进/居左对齐/居中对齐/居右对齐/两端对齐/默认/左浮动/右浮动/居中/单图上传/图片排序/多图上传/撤销/重做/超链接/分隔线/查询替换） | — |
| 设置应用商品 | 入口 | 关联商品详情页展示的商品 |
| 保存 | 按钮 | 底部「保存」 |

### 保存与作用
- 各 Tab 底部「保存」按钮统一保存当前 Tab 装修配置；「发布模板」后商城立即应用该模板，需对该模板进行商品关联。

## 业务规范说明

- **商城主线**：商城装修驱动买家端微商城外观——主题色（风格选择）、首页布局（装修模板）、分类页展示方式、商品详情富文本。
- **风格选择**：9 种主题色控制商城主题色与主要操作按钮颜色，直接影响买家下单按钮与导航色调。
- **装修模板**：行业模板（14 类）可引用后进入排版布局编辑器；「我的模板」保存自建/引用的模板；「发布模板」将当前模板应用到微商城，发布后需对模板进行商品关联（否则用户访问看不到商品数据）。
- **分类页装修**：分类展示方式（按目录/按品牌）+ 分类样式（纯文本/图文）+ 分类下商品数量；纯文本模式不展示分类图片。
- **商品详情**：富文本编辑器装修商品详情页（可配富文本、图片、超链接等）。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/mall/shop-decoration/index.vue`
- API：`apps/pc-admin/src/api/erp/mall.ts`（`shopBannerApi`、`shopTemplateApi`、`shopConfigApi`）
- 后端：`MallAdminController.java`（`@RequestMapping("/api/erp/mall/admin")`，模板 `/template/list`、轮播 `/banner`、配置 `/config`）

### 页面对齐（已建成：`PageContainer` + 两个卡片）
- **页面模板（真实接口）**：`shopTemplateApi.list()` → `/erp/mall/admin/template/list`，模板卡片列表（缩略图/名称/描述），点击选中 +「应用所选模板」→ `shopConfigApi.update({ templateId })`。
- **轮播图管理（真实接口 CRUD）**：表列=图片/标题/跳转类型/跳转目标/排序/状态/操作；行级操作=编辑/停用启用/删除；新增/编辑弹窗字段=标题/图片URL/跳转类型(product商品详情/category商品分类/none无跳转)/跳转目标/外部链接/排序/状态。`shopBannerApi` `/erp/mall/admin/banner` + `/{id}`。
- **装修配置占位**：页面顶部 `a-alert` 提示「可视化拖拽装修后端待补全」，说明拖拽式页面设计师需后端提供装修配置存储端点（如 `/api/erp/mall/admin/decoration`）后开放。
- **⚠️ 未对齐金标准 4 Tab**：当前无「风格选择」「分类页装修」「商品详情富文本」；装修模板为单卡片选择 + 轮播图管理，非金标准「我的模板/模板库」双子 Tab。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
