## 模板使用说明

### 1. 填写指南
- 带 `[ ]` 的为系统自动生成内容
- 带 `________` 的为必填项
- 带 `□` 的为选择项，请勾选适用项

### 2. 条款选择建议
- **付款条款**：建议采用"预付款30% + 到货款60% + 质保金10%"的比例
- **交货期限**：根据采购紧急程度确定，常规为15-30个工作日
- **质量保证期**：原材料一般为6-12个月

### 3. 风险提示
- 第5条违约责任中的违约金比例建议为0.5%-1%/天
- 第8条争议解决建议选择甲方所在地法院管辖
- 第7条保密期限建议不少于3年

### 4. 附件清单
以下附件作为本合同不可分割的一部分：
1. 附件一：技术规格书
2. 附件二：质量验收标准
3. 附件三：价格明细表
4. 附件四：其他补充协议
