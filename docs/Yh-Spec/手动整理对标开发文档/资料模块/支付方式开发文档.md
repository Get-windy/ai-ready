## 页面概述

支付方式用于维护**收款/付款的可选支付方式字典**（现金/银行/微信/支付宝/支票/其他）。单入口（列表 + 新增/编辑弹窗）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 支付方式 | `md/payment-method` | 支付方式列表 + 新增/编辑弹窗 |

菜单（本系统）：资料 → 支付管理 → 支付方式。

### 配置功能说明

- **列表骨架**：`CategoryListLayout`（无左侧分类树、无 Tab）+ `BillTableList` + 经典分页栏，与《物流公司》《银行账户》同构。
- **列配置**：数据表表头 `rowNo` 列右上角齿轮 → 「个人配置 / 全局配置」双 Tab（storage-key `md-payment-method-columns` / global-key `md-payment-method-columns-global`）。
- **页面配置**：**无**（对标 ql361 无此页，本页按资料模块自定，查询区固定 3 项，不设页面配置弹窗）。
- **导出**：工具栏「导出」→ 后端 `GET /export` 返回**真实 xlsx**。

## 业务规范说明

- **支付方式字典**：作为收款单/付款单/预收/预付等单据「支付方式」字段的数据源（`GET /list` 仅返回 status=1）。
- **类型枚举**：`methodType` 现金 CASH/银行 BANK/微信 WECHAT/支付宝 ALIPAY/支票 CHECK/其他 OTHER。
- **费率**：`feeRate` 存小数（0.006=0.6%），前端表单用百分比（feeRatePercent）输入。
- **默认值**：新增默认 status=1、feeRate=0、sort=0。
- **排序**：列表 orderBy sort ASC + createTime DESC。
- **编码唯一**：`method_code` 租户内唯一（统一大写存储），新增/修改均校验（修改时排除自身）。
- **默认唯一（系统级）**：`is_default=1` 全租户至多一条；置默认时自动清除其它记录的默认标记；停用时同时清除默认标记。
- **引用保护**：删除前校验 `md_payment_channel.method_id`、`erp_receipt.payment_method`、`erp_payment.payment_method`，被引用则拒绝删除并提示引用来源与条数，建议改为「停用」。
- **PUT 语义**：修改为整体覆盖，`accountId`/`remark` 清空（传 null/空串）会真正落库（用 `LambdaUpdateWrapper` 显式 set，规避 `updateById` 忽略 null 字段）。

**实现文件**：
- 前端：`views/md/payment-method/index.vue`
- API：`api/payment/md.ts`（`paymentMethodApi` → `/erp/md/payment-method`）

- 表：`md_payment_method`（迁移 V11.29.0 新增；`remark` 列由 V11.33.0 补）

### 页面对齐（已建成 · 金标准）
- **列表页**：`CategoryListLayout`（无分类树）+ `BillTableList` + 经典分页栏；查询区固定「筛选条件 / 类型 / 状态」；工具栏「新增 ｜ 刷新 / 打印(F8) / 导出 / 更多(批量启停)」；行内「修改 / 删除 / 更多(启停)」。
- **列配置**：表头 `rowNo` 齿轮（个人配置 / 全局配置），storage-key `md-payment-method-columns`。
- **弹窗表单**：`a-modal` 新增/编辑（编码编辑禁用、默认入账账户接财务账户、费率按百分比输入、备注），POST/PUT 真实生效。
- **状态切换**：行内与批量均走真实接口（`PUT /{id}/status` / `PUT /batch-status`，请求体 `{ "status": 0|1 }`）。

### 后端接口（`/api/erp/md/payment-method`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/page` | 多条件分页（keyword / methodType / status），返回 `PaymentMethodVO`（含 `accountName`） |
| GET | `/{id}` | 详情 |
| GET | `/list` | 启用项下拉（收付款单统一引用口径） |
| POST | `/` | 新增（编码唯一 + 字段校验 + 默认唯一） |
| PUT | `/{id}` | 修改（整体覆盖语义） |
| PUT | `/{id}/status` | 启停（不污染其它字段） |
| PUT | `/batch-status` | 批量启停 |
| DELETE | `/{id}` | 删除（引用保护） |
| GET | `/export` | 导出真实 xlsx（10 列，含字典翻译与费率百分比） |

> ⚠️ 本 Controller **不加** Spring Security `@PreAuthorize`（sa-token 登录不填充 SecurityContext，会恒抛 AccessDeniedException → 500），与 `FinanceAccountController` 口径一致。
