## 页面概述

收款单用于对结算单位的待收款单据（销售出库单/销售退货单等应收来源）批量收款核销。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 收款单表单页 | `finance/receipt-doc/form`（主菜单入口） | 新增收款 + 待收款单据核销 |
| 收款单列表页（历史） | `finance/receipt-doc/index`（list_path `finance/receipt`） | 双入口「历史」标签 |

单号实据：`SKD-20260723-034`（`SKD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明（每个页面都有）
- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序。
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级为金标准组件**（列表仍为 `PageContainer`+`SearchBar`+`BillTableList`，表单为自定义 `a-form`），见「实现差异说明 → 待完善」。

## 业务规范说明

- **收款核销**：收款金额分摊到各待收款单据「本次结算」，记账后回写各单据「已结算/待审金额/未结算」。
- **预收抵扣（货币主线"收→抵→退"）**：选定客户带出此前预收/可用预收；「使用预收款」从预收余额抵扣应收，抵扣后「预收余额=此前预收−使用预收款」实时联动。
- **多收金额**：收款超过应收部分转为客户预收（"收"环节补充入口）。
- **收款金额守恒**：本单金额（收款金额+使用预收款+更多账户）= Σ本次结算 + 多收金额。
- **自动分配**：按明细顺序/未结算金额自动分摊，分配后仍可手调。
- **记账生成凭证**：记账后自动生成会计凭证（`KJPZ-`），进入总账/明细账/科目余额表；应收对应科目 1122（核算项=往来单位）。
- **上游**：按单收款页行级「收款」进入本页；待收款单据=销售出库单（XSCKD-）/销售退货单（XSTHD-）等应收来源；预收来源=预收款单（YSKD-）。
- **交账前置**：职员经手单据须先在《账款交账》交账方可被选择。
- **单号前缀** `SKD-`（前端 `generateNo`/`genTaskNo` 生成，后端 save 原样落库）。
