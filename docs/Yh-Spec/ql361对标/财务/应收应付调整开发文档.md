## 1. 页面概述

- **表单页**：不动资金账户的往来余额调整（应收增加/应收减少/应付增加/应付减少四向）。页面性质 = 调整方向单选 + 表头字段区 + 科目明细表格 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/ar-ap-adjust/form`；标签「历史」→ `finance/ar-ap-adjust`（列表）。
- 单号实据 NO. YSKZJ-20260723-001（YSKZJ- 前缀 + YYYYMMDD-序号，"应收/应付增减"类拼音首字母）；标题行含附件、键盘（快捷录入）、齿轮（配置）图标（截图实据）。

## 2. 表单页配置

### 表头字段（必填 * 标注 / 选填）

- 调整方向：应收增加 / 应收减少 / 应付增加 / 应付减少（单选，默认应收增加）
- 必填：单据日期\*（默认当天）、结算单位\*（带新增+搜索）、经手人\*（默认当前登录人）

### 全部表单字段（12 个，抓取 JSON filterLabels + 截图实据归纳）

- 方向：调整方向
- 表头：单据日期、结算单位、经手人
- 明细：科目编号、科目名称、金额
- 备注/信息：单据备注、制单人、打印次数、打印记录
- 底部：本单金额

### 字段分组

调整方向单选 → 表头（单据日期/结算单位/经手人）→ 科目明细表格 → 备注区（单据备注）→ 单据信息（制单人/打印次数/打印记录）→ 底部本单金额与操作。

### 录单默认值

调整方向默认"应收增加"、经手人默认当前登录人、单据日期默认当天（截图实据）。

### 打印设置

无（打印模板配置细节待复核；表单页有打印(F8)按钮及打印次数/打印记录字段）。

### 功能按钮（抓取 JSON buttons 实据）

## 5. 业务规范

- 状态流转：保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后调整生效——结算单位应收/应付余额按方向增减，并生成会计凭证（KJPZ-）。
- 四向语义（实据归纳）：
  - 应收增加：客户欠款调增（如漏记费用转应收、期初补录）
  - 应收减少：客户欠款调减（如坏账豁免、差错冲减，不动资金）
  - 应付增加：欠供应商款调增
  - 应付减少：欠供应商款调减
- 与收/付款单的本质区别：本单无账户字段（截图与 JSON 均无收/付款账户），不产生资金流水，仅调整往来余额与对应科目。
- 明细"科目编号/科目名称"：调整的对转科目（差额去向，如营业外收入/营业外支出等），金额可多行拆分。
- 与其他页面关系：余额结果体现于《按单收款开发文档》/《按单付款开发文档》未结算金额、查应收/查应付（分析域）；科目主数据：资料 → 财务账户 → 会计科目（抓取成功：列=操作、科目编号、科目名称、核算项）；期初场景：配合期初余额录入使用（总账 4000 期初资本科目实据佐证系统存在期初体系）；本系统前端目录 `finance/ar-ap-adjust`（dynamicRoutes.ts 实据）。
