# 拆卸单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-split`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：成品拆解为原料的生产逆向录单（成品出库 + 原料入库同单完成），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 成品详情(出库)表 + 原料详情(入库)表 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **单入口**：仅表单页。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：成品仓库\*、原料仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（成品仓库/原料仓库/经手人/单据日期）→ 成品详情(出库)表 → 原料详情(入库)表 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导出、保存草稿 Ctrl+S、记帐 Ctrl+Enter（截图按钮文案为「记帐」）

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（成品表与原料表结构一致，各 15 列，抓取 JSON columns 实据）

操作、商品名称（带「扫描枪录入」开关）、货号、货位、条码、计价单位、批次条码、生产日期、保质期、到期日期、数量、件散数量、成本单价、成本金额、备注

> 注：JSON columns 首项为表头拼接串（表头多单元格文本相连），非真实单列，已剔除；两表列结构一致（JSON 去重后实为两表合并结果）。

### 全部可配置列

待复核（无 XSMK 列配置存档，需在对标系统打开列配置弹窗补抓）。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：记帐后成品按「成品详情(出库)」扣减成品仓库库存，原料按「原料详情(入库)」增加原料仓库库存。
- 与组装单结构差异：无「生产单位」字段、无「加工费用/计算成本」行（截图与 JSON 实据）。
- 可由生产模板带出原料构成（模板引用交互待复核）。
- 反向单据：组装单（原料组装为成品）；上游：生产模板（BOM 原料构成来源）；记帐后影响 分析→仓配分析→查库存/库存明细。
