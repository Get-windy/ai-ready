## 页面概述

总账是**按科目汇总的账务账簿**（期初余额 + 本期发生 + 期末余额）。**报表查询页**（查询 + 汇总表格），单入口，无子 Tab。

| 页面 | 地址 | 说明 |
|------|------|------|
| 总账 | `finance/general-ledger` | 查询 + 科目汇总表格 |

单入口：财务 → 账簿 → 总账。

### 配置功能说明
- **列配置**：数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）→ 列配置弹窗（个人配置 / 全局配置），配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**8 列全部默认显示，无隐藏列**。
- **页面配置**：本页**无「配置」齿轮**（顶部工具栏仅 刷新 / 打印(F8) / 导出 / 明细对账），故**无 查询条件/功能按钮 页面配置弹窗**。查询条件为固定布局。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 业务规范说明

- **账簿口径**：期初余额 + 本期借/贷发生 = 期末余额。
- **科目行**：按科目（含核算项）汇总，反映到期末余额。
- **来源**：会计凭证（KJPZ-）记账后入总账。
- **下钻**：选中科目行 →「明细对账」进入《明细账》该科目逐笔明细。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 账簿单一口径（红线）**：总账为**只读汇总账簿**，数据唯一来源于《会计凭证》记账（KJPZ-），**严禁直接写总账/明细账**（禁止手工调账绕过凭证）。
- **P1 科目体系**：总账科目与《会计科目》（finance_account_subject）字典一致，按科目（含核算项）汇总期初+发生=期末。
- **P1 穿透**：科目行 →「明细对账」下钻《明细账》，保证凭证级可追溯。
- **P2 验收**：总账不可增删改，仅查询/导出；与明细账、科目余额表、试算平衡数据一致。
