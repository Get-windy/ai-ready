## 域级说明

- **单据编号规则**（截图实据）：其他出库单 QTCKD-、其他入库单 QTRKD-、调拨单 DBD-、报损单 BSD-、报溢单 BYD-、盘点单 KCPDD-、成本调价单 CBTJD-、组装单 ZZD-、拆卸单 CXD-、借进单 JJD-、借出单 JCD-，后缀均为 `YYYYMMDD-序号`；生产模板/预警查询/预警设置/借进借出查询为非单据页，无单号。
- **快捷键体系**：F8 打印、Ctrl+S 保存草稿（盘点单为"保存"）、Ctrl+Enter 记账/记帐（盘点单为"盘点处理"、生产模板为"保存"）；表单页均带键盘快捷录入口。
- **状态流转主线**：仓储单据统一两段式——保存草稿（入"业务草稿"）→ 记账生效（即时增减库存，可查库存/库存明细检索流水）；盘点单为 保存→盘点处理（按盈亏联动报损/报溢，推断待复核）；借进单记账后走 还出 或 借转采购 两条出路（借进借出查询列实据）；预警设置→预警查询→（采购域）库存预警补货 构成缺货补货链路。
- **页面范式**：11 个业务单据表单页结构高度一致（NO.行+表头一行+明细网格+单据备注+单据信息行+底部金额与操作），差异集中在表头仓库字段（出/入/调/盘点/调价仓库）、明细数量列命名（数量/报损数量/报溢数量/盘点数量/借进数量/借出数量）与金额列组；组装单/拆卸单为双明细表复合页。
- **通用待复核项**：各页列配置弹窗全量列（无 XSMK 存档）、打印配置弹窗、调拨差异价调拨的差额去向、盘点处理产出单据形态、预警类型枚举与比较口径可选项、预警设置表格列（抓取时空态）、借出商品查询子标签列结构、行级操作明细。
