# 其他入库单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-in`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：非采购业务的库存入库录单（赠品入库、盘盈外的其他入库等），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **单入口**：仅表单页。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：入库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 选填：往来单位
- 摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（往来单位/入库仓库/经手人/单据日期）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

### 全部表单字段

抓取数据仅覆盖默认显示字段；列配置弹窗全量字段无 XSMK 存档依据，待复核。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、导出、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 3. 数据表格列配置

### 默认显示列（20 列，抓取 JSON columns 实据）

操作、商品名称（带「扫描枪录入」开关）、货号、条码、货位、计价单位、可用库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、单价、金额、备注

> 注：JSON columns 首项为表头拼接串（表头多单元格文本相连），非真实单列，已剔除。

### 全部可配置列（45 列，cfg 实据 45 列 ✅；cfg 抓取页签为「其他出库单」，两单共用同一商品列集合）

操作、图片、商品名称、货号、条码、规格、型号、产地、区域、货位、计价单位、可用库存、可用库存换算结果、账面库存、批次条码、生产日期、保质期、到期日期、数量、换算关系、件散数量、大包装、中包装、小包装、零售价、批发价、单价、金额、小单位、小单位单价、小单位数量、备注、价格等级8昵称（餐饮店、食堂团餐、自助vip、大团餐、特价客户、外围餐饮店、重点|vip01、连锁|vip）、单据自定义1(数字字段)~3(数字字段)、单据自定义4(文本字段)~5(文本字段)

> 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记账后单据生效增加库存。
- 与采购入库单不同：无付/收款区、无摘要结账面板，仅「本单金额」汇总；往来单位非必填。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 批次管理列齐备（批次条码/生产日期/保质期/到期日期），入库可登记批次与效期。
- 与其他出库单互为反向单据（一入/一出，页面结构完全一致，仅「入库仓库*/出库仓库*」差异）。
- 草稿在 分析→综合单据→业务草稿 中检索（销售域已确认该入口，仓储单据同体系，待复核）；记账后影响 分析→仓配分析→查库存/库存明细。
