# 商品货位设置开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：对应 WMS 库位绑定，路由待复核
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表页**：按"商品×仓库"维护推荐货位的主数据维护页，左侧商品分类树 + 查询区 + 数据表格；仓库为必选查询条件，按仓库逐仓设置商品货位。
- 截图：![商品货位设置](../../../../tool-results/ql361/pages/资料__仓库管理__商品货位设置.png)

## 2. 页面配置

### 查询条件

- 筛选条件（商品名称/货号）
- 品牌（选择器）
- 仓库\*（必选，前端必填校验"该值是必需的。"）
- 货位（选择器）
- 条码（全部）
- 上架状态（全部）
- 显示状态（已启用）
- 勾选项：仅显示未设置货位的商品、仅显示有库存的商品
- 左侧商品分类树按分类过滤

### 功能按钮

- 工具栏（抓取 JSON buttons）：刷新、打印(F8)、条码打印、导出、更多、查询、跳转（分页跳转）
- 行级操作：待复核（抓取时表格无数据；JSON columns 含"操作"与"上架"列，"上架"疑为行内勾选设置，待复核）

### 打印配置

无（抓取未覆盖打印配置弹窗；页面有打印(F8)与条码打印按钮，模板细节待复核）

## 3. 数据表格列配置

### 默认显示列（12 列，抓取 JSON columns 实据）

操作、图片、商品名称、货号、上架、单位、规格、型号、仓库、推荐货位、备注、修改时间

> JSON columns 首项"操作 图片 商品名称 货号"为抓取拼接串（表头快照），非真实单列，列数统计已剔除。

### 全部可配置列

待复核（抓取未覆盖列配置弹窗）。

## 4. 业务规范

- 仓库必选：查询必须选定仓库（前端必填校验截图实据），按"一个仓库下的全部商品"逐仓设置货位
- 推荐货位：为商品设置拣货推荐货位，供拣货/上架指引（订单处理中心"集货位"、WMS 拣货联动）
- 仅显示未设置货位的商品：用于新商品货位补齐作业；仅显示有库存的商品：用于在库商品货位整理
- 上架列：疑为商品在该仓库货位的上架勾选（实据不足，待复核）
- 条码打印：选中行打印商品条码标签（与商品条码页能力一致）
- 与其他页面关系：仓库规划（仓库/货位主数据来源）、商品（来源与分类树同源）、商品条码（共享"条码（全部）"与"条码打印"）、WMS 拣货/上架（推荐货位指导）
