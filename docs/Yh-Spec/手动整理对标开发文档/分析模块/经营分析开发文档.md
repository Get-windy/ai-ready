### 实测数值与三层公式交叉验证（2026-09-15）

| 日期 | 销售收入 | 其他业务收入 | 收入合计 | 销售成本 | 其他业务成本 | 销售费用 | 管理费用 | 财务费用 | 支出合计 | 营业利润 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2026-09-15 | 19,455 | 219.3 | 19,674.3 | 15,646.88 | 228.36 | 26.54 | 24 | 6.91 | 15,932.69 | 3,741.61 |
| 2026-09-14 | 22,038.12 | 313.8 | 22,351.92 | 17,987.28 | 5,728.66 | 60.93 | 0 | 23.22 | 23,800.09 | -1,448.17 |
| **合计** | 41,493.12 | 533.1 | 42,026.22 | 33,634.16 | 5,957.02 | 87.47 | 24 | 30.13 | 39,732.78 | 2,293.44 |

- **收入合计 = 销售收入 + 其他业务收入**：19,455 + 219.3 = **19,674.3** ✅；22,038.12 + 313.8 = **22,351.92** ✅；合计 41,493.12 + 533.1 = **42,026.22** ✅
- **支出合计 = 销售成本 + 其他业务成本 + 销售费用 + 管理费用 + 财务费用**：15,646.88 + 228.36 + 26.54 + 24 + 6.91 = **15,932.69** ✅；17,987.28 + 5,728.66 + 60.93 + 0 + 23.22 = **23,800.09** ✅
- **营业利润 = 收入合计 − 支出合计**：19,674.3 − 15,932.69 = **3,741.61** ✅；22,351.92 − 23,800.09 = **-1,448.17** ✅（负利润，实测红字）；合计 42,026.22 − 39,732.78 = **2,293.44** ✅
- **合计行 = 逐行求和**：销售收入 19,455 + 22,038.12 = 41,493.12 ✅；其他业务成本 228.36 + 5,728.66 = 5,957.02 ✅；财务费用 6.91 + 23.22 = 30.13 ✅（合计行**逐列求和，含隐藏列**）。

## 4. 业务规范

### 统计口径（期间损益）

- **三层公式**（逐行与合计行均成立，见上表 ✅）：`收入合计 = 销售收入 + 其他业务收入 (+ 其他收入 + 投资收益 + 营业外收入)`；`支出合计 = 销售成本 + 其他业务成本 + 营业外支出 + 销售费用 + 管理费用 + 财务费用 + 其他费用`；`营业利润 = 收入合计 − 支出合计`。
  > 注：默认视图下 收入组合计仅含「销售收入 + 其他业务收入」（其余 3 列隐藏且本期无值），故实测等式成立；勾选全部收入列后应为 6 项之和，**待复核**。
- **科目体系实据**（与《查费用》同源）：`6601 销售费用`、`6602 管理费用`、`6603 财务费用`、`6711 营业外支出`；成本类为销售成本（出库成本核算口径）。
- **销售收入**：销售出库净额口径（与《销售分析》销售收入同源）；**其他业务收入**：其他收入单 / 非主营收入登记。
- **包含手工会计凭证**：勾选后手工凭证的损益类分录并入计算（保证「账表一致」；这也是本页与《利润表》法定口径的主要差异开关）。
- **粒度切换**：`按天` 一行一日；`按周`/`按月` 为区间聚合——**对标区间聚合实据未抓取，待复核**。
- **负利润呈现**：营业利润为负时红字（实测 2026-09-14 = -1,448.17 红字）——属样式口径，非账务口径。

### 取数来源与上下游关系

- **取数**：业务单据自动凭证 + 手工会计凭证（勾选时）→ 损益类科目期间发生额，按日期维度摊平。
- **同源页**：
  - 《利润表》（财务域，法定报表口径，按科目层级呈现）；
  - 《销售分析》（销售侧毛利口径，销售收入同源）；
  - 《查费用》（费用明细细度，三费按科目归集）。
- **下游/交叉验证**：本页「支出合计」中的三费应与《查费用》按费用科目汇总口径一致（本次未做跨页对账，**待复核**）。
- **与《查资金》的分工**：本页为**损益**口径（收入/成本/费用），《查资金》为**资金**口径（账户余额与收付流水），二者不等价——折旧、应收应付等非现金项只在损益侧体现。

- **分页**：会计月粒度，前端分页（20/50/100）。
- **后端**：本轮未改后端；未新增迁移。

### 剩余缺口（按本页自身规格＝账表页逐项判定）

1. **无「按天 / 按周」损益聚合端点**：现有端点最小粒度为会计月 → 粒度按钮中「按天 / 按周」置灰（`index.vue:127-133`）。
2. **查询项 3 项置灰（后端无入参）**：部门、经手人、「包含手工会计凭证」在端点 `/erp/finance/report/v2/income-statement-report` 无对应参数（控件 disabled + title 说明），不做静默失效的假查询。
3. **部分对标列无数据源、恒空白**：其他收入、投资收益、其他业务成本、其他费用、优惠等在损益端点无对应字段（`buildRow()` 未赋值），列位按对标保留但为空。
4. **合计行为前端求和**：后端无 summary 字段，合计由前端对已取到的会计月行累加（口径 = 当前日期范围覆盖的会计月）。
5. **查询方式为「逐会计月多次调用」**：跨越多个会计月时按顺序（`Promise.all` 并发）逐月请求，最多 36 个月；月份越多请求数越多，非单次区间聚合端点。
6. **查询方案为占位**：`queryScheme` 未被任何请求使用。

## 开发原则（通用）

> - **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
> - **【金标准】模块级 E2E 脚本统一放 `tools/`**：命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖。
> - **【金标准】启动进程随手关**：收工关闭自己启动的实例与临时产物，不得清理他人产物（见 `AI_DEVELOPER_RULES.md` 7.3）。
