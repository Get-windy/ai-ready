# 销售退货申请开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/return-apply/form`（表单）+ `sales/return-apply/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**：表单页（`sales/return-apply/form`）= 客户退货前置申请录单，编辑模式为新增模式加 id；列表页（`sales/return-apply/index`）= 按单据 / 按明细两个 tab。
- 表单页结构：表头字段区 + 商品明细表格 + 底部付款/物流信息/会员信息 3 Tab + 备注区 + 单据信息行。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：客户\*、入库仓库\*、经手人\*、单据日期\*、销售类型\*（默认"正常销售"）
- 选填：联系人、联系电话、联系地址、预计收货（日期）、审核人

### 全部表单字段（50 个，XSMK 依据；cfg 未抓到页面配置弹窗，表单字段以 XSMK 为准）

- 基本信息：编号、客户、客户编号、客户级别、开户行、银行账号、税号、入库仓库、经手人、部门、单据日期、销售类型、联系人、联系电话、联系地址、预计收货、自定义字段1~5、审核人、摘要
- 欠款区：信用额度、可用额度、本次欠款、此前欠款、欠款余额、收款期限、源单
- 物流区：配送单、配送方式、配送线路、物流公司、运费、运单号
- 会员区：会员卡号、此前积分、产生积分、兑换积分、使用积分、剩余积分
- 备注/信息：单据备注、买家备注、表尾自定义字段1~2、制单人、制单时间、打印次数、本单金额

### 字段分组

顶部基本信息（客户/入库仓库/经手人/日期/销售类型/联系人信息/预计收货/审核人）→ 商品明细表格 → 付款 Tab → 物流信息 Tab → 会员信息 Tab → 备注区 → 单据信息行。

### 录单默认值

经手人默认当前登录人、销售类型默认"正常销售"、单据日期默认当天（截图确认实据；配置弹窗明细待复核）。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 提交（Ctrl+Enter）→ 审核（表头有"审核人"字段，退货申请需审核后才可退货入库）。
- 订单处理中心查询区含"不显示有关联审核中退货申请单的单据"勾选项，证明退货申请与销售订单存在关联审批链，审核中的退货申请会挂起原单。
- 退款方向为"付款"（企业付给客户），与销售出库单的"收款"方向相反；"预计收货"为退货商品的预计回仓日期。
- 上游：销售订单 / 销售出库单（退货针对已售商品，源单回链）；下游：销售退货单（申请审核通过后转正式退货单入库）；订单处理中心按单据查询时可关联显示审核中的退货申请。
