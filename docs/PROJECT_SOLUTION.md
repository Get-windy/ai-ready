# 智企连·AI-Ready 项目方案  
**基于 SmartAdmin 框架，借鉴 Odoo 设计思想，打造完全自主、适合中国用户的 AI-Ready 企业管理系统**

---

## 1. 项目背景与目标

### 1.1 背景
- **市场需求**：中小企业对一体化 ERP+CRM 系统需求旺盛，但传统 SaaS 产品存在数据安全、定制成本高、按年付费等问题；同时，AI 技术的成熟使得"用自然语言指挥业务"成为可能，企业需要能被 AI Agent 调用的业务系统。
- **技术趋势**：国内头部 ERP 厂商（用友、金蝶等）正在加速 AI 融合，而开源社区缺乏一款符合中国用户习惯、技术栈主流、自主可控的 AI-Ready ERP。
- **前期讨论**：经过多轮技术选型与合规分析，团队决定从基于 Odoo 二次开发转向**完全自主开发**，以规避开源协议风险、掌握全部知识产权、适配国内技术生态。

### 1.2 目标
打造一款 **开源与商业相结合** 的企业智能管理系统，具备以下核心特性：
- **AI-Ready**：预留标准化的 Agent 调用接口，任何 AI Agent（如 OpenClaw、Dify、LangChain、自研 Agent）均可调用系统能力。
- **模块化**：借鉴 Odoo 的设计哲学，业务模块可插拔、可独立扩展、可组合部署。
- **中国化**：内置中国会计准则、电子发票接口、银行直连、移动端多端适配（小程序、APP、H5）。
- **自主可控**：100% 自研代码，采用 **Apache 2.0** 开源协议，无任何法律风险，企业可安心商用。
- **生产级**：基于成熟的 SmartAdmin 框架，满足安全合规、高性能、高可用要求。

## 3. 技术选型

### 3.1 基础框架：SmartAdmin

**选择理由**：
- **安全合规**：国内首个满足《网络安全-三级等保》要求、内置数据脱敏、接口加解密、登录防爆破等功能。
- **双版本支持**：Java8+SpringBoot2 或 Java17+SpringBoot3，满足不同部署环境。
- **成熟代码规范**：开源六年，千余企业验证的代码规范，降低协作成本。
- **内置代码生成器**：一键生成前后端 CRUD 代码，大幅提升开发效率。
- **移动端原生支持**：基于 UniApp 的移动端模板，可直接扩展多端应用。

**技术栈明细**：
| 层次 | 技术 | 说明 |
|------|------|------|
| 后端 | Java 17 / Spring Boot 3.2.5 | 长期支持版本（已从2.7.18升级） |
| 安全框架 | Sa-Token | 轻量级权限认证，支持 OAuth2.0 |
| ORM | Mybatis-Plus | 增强 CRUD，提供丰富条件构造器 |
| 数据库 | PostgreSQL（默认）/ MySQL（可选） | 主库 PostgreSQL，可选 MySQL 支持 |
| 缓存 | Redis 7.x | 会话、数据缓存 |
| 消息队列 | RabbitMQ | 异步任务、打印队列 |
| 前端 | Vue 3 + Vite 5 + Ant Design Vue | 现代化组件库 |
| 移动端 | UniApp + Vue 3 | 一套代码编译为 H5、微信小程序、APP |
| API 文档 | Knife4j | 自动生成 OpenAPI 规范 |
| 容器化 | Docker + Kubernetes | 便于交付部署 |

### 3.2 版本升级记录

#### 2026-05-01: Spring Boot 2.7.18 → 3.2.5

**升级内容**:
1. **pom.xml 更新**: 将 `spring-boot-dependencies` 版本从 `2.7.18` 升级到 `3.2.5`
2. **命名空间迁移**: 将所有 `javax.*` 导入改为 `jakarta.*`：
   - `javax.validation` → `jakarta.validation`
   - `javax.servlet` → `jakarta.servlet`
   - `javax.persistence` → `jakarta.persistence`
   - `javax.annotation` → `jakarta.annotation`
   - `javax.mail` → `jakarta.mail`
3. **JavaMail 依赖更新**: 将 `com.sun.mail:javax.mail` 替换为 `com.sun.mail:jakarta.mail:2.0.1`
4. **API 变更适配**: 
   - `ServerHttpRequest.getMethodValue()` 改为 `ServerHttpRequest.getMethod().name()`
5. **模块兼容性修复**: 更新了 `core-base`、`core-common`、`core-api`、`core-web-admin` 等核心模块

**升级原因**:
- Spring Boot 2.7.x 官方 LTS 支持已于 2025 年 5 月结束
- Spring Boot 3.x 支持 Jakarta EE 9+ 标准
- 获得更好的性能、安全更新和新功能支持

### 3.3 借鉴 Odoo 的设计模式

| Odoo 特性 | 借鉴实现方式 | 落地模块 | 当前状态 |
|-----------|--------------|----------|---------|
| **模块化架构** | Maven 多模块项目，每个业务模块独立打包，通过 SPI 或 Spring 自动装配进行集成。 | `erp-*`、`crm-*` 等模块 | ✅ 已实现 |
| **模型继承** | 使用 Java 类继承 + 组合模式；通过 `@TableField` 扩展自定义字段。 | 基类 `BaseEntity`，业务实体继承 | ✅ 已实现 |
| **视图继承/定制** | 前端组件插槽（slot）+ 混入（mixin），后端提供 JSON 配置化表单。 | Vue 组件库 + 低代码表单设计器 | ⚠️ 需加强 |
| **ORM 高级特性** | Mybatis-Plus 提供 `QueryWrapper`，自定义 `@TableField(exist=false)` 实现计算字段。 | 所有 Service 层 | ✅ 已实现 |
| **动态字段** | 通过 JSON 列或扩展表存储动态字段，前端动态渲染。 | `custom_field` 表 + 动态表单组件 | ❌ 待实现 |
| **工作流引擎** | 自研 WorkflowEngine（基于状态机），提供流程定义、实例管理和任务处理。 | `core-base` 模块 | ✅ 已实现 |
| **报表引擎** | 集成 JasperReports 或自研基于 HTML+PDF 的打印模板。 | `erp-printing` 模块 | ✅ 已实现 |

### 5.3 Agent 调用层（核心差异化）

- **能力注册中心**：启动时扫描 `@AgentCapability` 注解，将能力注册到数据库表 `agent_capability`。
- **统一调用协议**：使用 JSON-RPC 2.0，支持 HTTP 同步和 WebSocket 异步。
- **安全与审计**：每个 Agent 调用需要携带 API Key，记录调用日志（包括 Agent 标识、操作人、参数、结果）。
- **预定义能力**（覆盖 ERP 与 CRM）：
  - `sale.order.create`：创建销售订单
  - `sale.order.query`：查询订单
  - `stock.picking.print`：打印拣货单
  - `crm.lead.create`：创建线索
  - `crm.opportunity.update`：更新商机阶段
  - `report.sales.today`：今日销售报表
  - `party.customer.create`：创建客户
  - `party.supplier.query`：查询供应商
  - `finance.invoice.create`：创建发票
  - `stock.inventory.query`：查询库存
  - `purchase.order.create`：创建采购订单
  - `system.ping`：系统状态检查

**接口规范**（JSON-RPC）：
```json
{
  "jsonrpc": "2.0",
  "method": "capability.invoke",
  "params": {
    "capability_id": "sale.order.create",
    "context": {
      "session_id": "conv_12345",
      "user_id": 10086,
      "agent_id": "openclaw_001"
    },
    "arguments": {
      "customer_id": 123,
      "products": [{"id": 456, "qty": 2}]
    }
  },
  "id": 1
}
```

## 10. 风险管理

| 风险 | 影响 | 应对措施 |
