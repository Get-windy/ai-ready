# AI-Ready 代码生成器模块

## 概述
AI-Ready 代码生成器模块是一个用于自动生成前后端代码的工具。它支持从数据库表结构生成实体类、Mapper、Service、Controller以及前端页面等。

## 功能特性
- 代码模板管理：支持模板定义与存储、模板变量支持、模板版本管理
- 代码生成功能：支持实体类、Mapper/Service/Controller、前端页面、API文档生成
- 数据源管理：支持数据库连接配置、表结构解析、字段类型映射
- 生成配置：支持生成规则配置、代码风格配置、批量生成

## 技术架构
- 使用 MyBatis-Plus Generator 作为底层生成引擎
- 提供 RESTful API 接口
- 支持多种数据库
- 可扩展的模板系统

## 使用指南
1. 配置数据源
2. 定义代码模板
3. 设置生成配置
4. 执行代码生成
