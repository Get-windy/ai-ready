## 业务规范说明

### 统计口径（明细账粒度）

- **粒度**：一行 = 一张单据 × 一个商品明细（× 批次）；单据编号重复多行即同单多品
- **账面入库 / 账面出库**：入/出数量分列（出库单只填账面出库，入库单只填账面入库）；**数量**为入−出净值口径（具体符号规则待复核）
- **成本口径**：成本单价/成本金额按出库/入库时的成本价（批次成本/移动加权）
- **批次维度**：批次条码 + 生产日期 + 到期日期三列与《查批次》同源
- **显示红冲**：勾选后红冲单明细入列（与《经营历程》"显示红冲"同规则）
- **日期类型**：单据日期（默认）/其他日期口径（可选值待复核）

### 与其他页面关系

- 上游：全部出入库单据（销售出库/采购入库/调拨/盘点/借进借出/采退/销退等）过账流水
- 联查终点：《进销存分析》"对账"、各汇总页金额钻取的明细落地页
- 同组页面：《查库存》（时点存量）、《查批次》（批次台账）、《进销存分析》（期间汇总）
