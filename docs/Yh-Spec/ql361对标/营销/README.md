## 域级说明

- **菜单结构**（menus-full.json 实据）：营销 → 会员中心（会员管理、积分兑换、会员设置）、营销活动（发短信、优惠券、商品促销、整单促销、特价、套餐）、商城营销（商城拼团、商城秒杀、商城预售、商城弹窗广告、加价购、热门搜索词推荐）、营销推广（我要推广、推广历史查询）。分析域另有"营销分析"组：营销活动分析、营销推广分析、交易分析、商城客户列表（不在本域 17 页范围）。
- **域级营销主线**（实据归纳）：
  - **会员/积分线**（会员中心）：会员设置定规则（注册初始/生日倍数/消费/签到四路积分流入 + 抵现/兑换两路流出，线下开单与微商城双场景）→ 会员管理落档案（会员=客户扩展档案，"客户|会员管理"开关实据）→ 积分兑换做流出；销售订单"会员信息"Tab（会员卡号/此前积分/销售积分/退货积分/兑换积分/使用积分/当前积分，销售域实据）是积分与开单的交点。
  - **促销线**（营销活动）：发短信做触达（67 字/条、签名/退订合规）；优惠券（制券→发放→领取→核销，数量守恒，商城/线下双通道）与商品促销（行级满赠）/整单促销（单级门槛）/特价（一口价）/套餐（组合定价）五种让利手段，落点为订单明细"优惠折扣/惠后单价"与摘要"促销优惠、优惠金额(−)"（销售域实据）。
  - **商城玩法线**（商城营销）：拼团（凑团享价）/秒杀（限时抢）/预售（订金+尾款）三大交易玩法 + 弹窗广告/热门搜索词两个引流位 + 加价购连带；活动状态统一为 待开始/进行中/已结束（预售、弹窗广告下拉枚举实据）。
  - **推广线**（营销推广）：我要推广把商品/券/促销/拼团/秒杀 5 类对象行级分享出去（仅已上架），推广历史查询按 浏览→领取→下单 漏斗回溯；订单处理中心默认列"推广人"（销售域实据）完成订单级业绩归属。
  - 四线关系：会员/积分是"留客"资产，促销是"成交"让利，商城玩法是"线上场"交易形态，推广是"拉新"裂变；效果数据汇入分析域"营销分析"。
- **活动类页面通用交互**（多页实据归纳）：列表页默认本月时间窗（2026-07-01~07-31 实据）；"显示已过期/已作废活动"勾选项默认不勾选（优惠券/商品促销/整单促销/特价/加价购 5 页实据）；"更多玩法告诉我们.."反馈入口（商品促销/整单促销/特价 3 页实据）；行级操作 查看/修改/更多 或 修改/停用/复制/删除 形态。

- **编号规则**（行实据）：套餐编号 tc + 序号（tc0001）；商品货号 bdgj + 序号（我要推广实据 bdgj001~034）。
