## 页面概述

单位显示是**商城在售商品单位显示设置**页：与「商品上架」同源商品列表，重在控制**该商品是否在商城显示**及显示时的单位（`单位显示`列 √/×）。**单入口，无独立表单，无子 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 单位显示 | `mall/unit-display` | 单视图列表页（分类树 + 商品列表 + 单位显示勾选列） |

单入口：商城 → 基础业务 → 单位显示。

- 实测实据（**2026-09-15 复核**）：共 **4542** 条记录、每页 20 条；与「商品上架」共用同一商品分类树（13 个一级分类，逐字一致）。（首抓记 4543 条，业务数据逐日变化。）
- 商品行含「单位显示」√/× 开关；本页与「商品上架」同源（商品列表），差异在**聚焦「单位显示」字段 + 批量显示/隐藏（+ 刷新）**。

### 配置功能说明
- **列表结构**：单位显示页为**商品类列表页**（分类树 + 商品数据表），**无**标准「页面配置」（查询条件/功能按钮 Tab 的配置齿轮）。

## 业务规范说明

- **单位显示主线**：商城在售商品 → 本页控制「单位显示」开关（√=在商城显示该商品及其单位，×=隐藏）。
- **显示单位**：与商品基础资料的「单位」列关联（如 箱/盒/袋/包）；`单位显示类型` 区分显示粒度（对标实测 4 项：`全部`(-1)/`只显示常用单位`(0)/`只显示小单位`(1)/`只显示中/大单位`(2)，本系统取值口径见「实现差异说明 → 后端改动（本轮）」）。
- **批量操作**：批量显示 / 批量隐藏对选中行生效。
- **同源性**：与「商品上架」共享同一商城商品列表；本页不做价格/上架开关配置，仅聚焦「单位显示」。

## 实现差异说明

> 本节按当前源码回写（本轮：单位级 `unit_display_type` + 预设进价 + 两个查询条件闭环后）。

### 当前实现
- **实现文件**：`frontend/apps/pc-admin/src/views/mall/unit-display/index.vue`
- **骨架**：`ErrorBoundary` > `PageContainer(full-height)` > `CategoryListLayout(category-title="商品分类"、:tabs="[]"、:category-editable="false" 只读分类树)` > `BillDetailTable` + `StandardPagination(variant="classic")`；**无** `PageConfigPanel`（对标无页面配置弹窗）
- **Tab**：无 Tab（`CategoryListLayout :tabs="[]"`）
- **分类树**：`商品分类`（`全部商品` 根节点 + `/erp/product-category/tree` 真实分类），只读（`category-editable=false`），点选分类即带 `categoryId` 重新查询
- **列**：共 12 列可配置（默认显示 10：单位显示、图片、商品名称、商品货号、零售价、批发价、条码、规格、型号、单位；默认隐藏 2：品牌、预设进价）；固定列：序号（rowNo，承载列配置齿轮）、多选（checkbox）。`columns` 数组共 14 项（含 rowNo、checkbox 两条 `LOCKED_COLUMNS`）
- **查询条件**：6 项（筛选条件=商品名称/货号/条码/规格/型号 关键字、品牌、商品标签、单位显示、单位显示类型、显示状态）+「查询」按钮，全部为真实请求参数：
  - 筛选条件 → `keyword`；品牌 → `brand`（选项 `GET /erp/product/brands`）
  - 商品标签 → `productTag`（选项 `GET /erp/product/mall-tags`，即 `erp_product.mall_tags` 已打标槽位编码去重，如 `TAG_1`，与「商品上架」页同源；昵称由「商品辅助资料 → 商品标签」维护，本页按编码展示）
  - 单位显示 → `unitDisplay`（商品级整品开关 `erp_product.unit_display`：1 显示 / 0 隐藏，V11.361.3）
    > ✅ **下拉已按对标实测校准**（2026-09-14）：文案与取值 = `全部`(-1) / `是`(1) / `否`(2)，默认「全部」。
    > **值映射**：对标布尔「是/否」↔ `erp_product.unit_display` 1/0 —— `是`(1) → `unitDisplay=1`（同值直接对表）、**`否`(2) → `unitDisplay=0`（映射，非 2）**。
    > 前端常量 `UNIT_DISPLAY_TO_API`（`views/mall/unit-display/index.vue`）。⚠️ `0` 是 falsy，映射后**不能**再用 `if (searchForm.unitDisplay)` 判空，否则「否」会静默变成不过滤。
    > **「全部」(-1) 处理**：**不传参**（后端空即不过滤），不硬传 `-1` —— 后端 `unitDisplay` 是 `Integer` 精确匹配 `erp_product.unit_display`（0/1 值域），传 `-1` 会得到零结果。
    > **后端未改**（值域与语义均一致，无需改）。
  - 单位显示类型 → `unitDisplayType`（**单位粒度**类型，单位级 `erp_product_unit.unit_display_type`：`-1`=全部 / `0`=只显示常用单位 / `1`=只显示小单位 / `2`=只显示中/大单位；建列 V11.361.8，取值口径 V11.363.0 按对标实测改正）
  - 显示状态 → `status`（`ENABLED`/`DISABLED`）
    > ✅ **下拉文案与取值已按对标实测校准**（2026-09-14）：`全部`(-1) / `已启用`(2) / `已停用`(1)，默认「已启用」（对标实测默认态）。
    > **值映射**：前端保留实测整数作为下拉值，请求前经 `STATUS_TO_API` 映射为后端字符串 —— `已启用`(2) → `ENABLED`、`已停用`(1) → `DISABLED`；「全部」(-1) → **不传参**（清空 = 不过滤）。
    > **口径差异（如实记录，未对齐）**：本系统沿用后端 `erp_product.status` 的**字符串**值域 —— `V1.1.9` 建表即 `VARCHAR(20) DEFAULT 'ENABLED'`，值为 `ENABLED`/`DISABLED`。对标 ql361 实测为**整数** `全部`(-1) / `已启用`(2) / `已停用`(1)。本轮**保留后端字符串语义不动**（该列被其它商品档案页共用，不得硬改成整数），仅在前端做值映射与文案对齐。**该差异属已知未对齐项**（「对标整数 ↔ 我方字符串」，未做后端语义改造）。
  - 注：对标查询区「商品」项在本页由「筛选条件」单框承载（`keyword` 已覆盖商品名称/货号/条码/规格/型号），非缺口。
- **功能按钮**：左侧 批量显示、批量隐藏（未勾选时禁用）；右侧 刷新、打印(F8)、导出
- **行级操作**：「单位显示」勾选开关（逐行 √/×，调用 `productApi.batchUnitDisplayFlag([id], 1|0)` → `PUT /erp/product/batch-unit-display`，body `{ids, unitDisplay}`，只写**商品级** `erp_product.unit_display` = 「该商品是否在商城显示」，**不写**单位粒度列）；勾选态由 `isUnitDisplayed()` 判定 = `record.unitDisplay !== 0`（列默认 1=显示）；无编辑 / 无删除
  - 区分口径：对标「单位显示」= 布尔（`全部`(-1)/`是`(1)/`否`(2)）↔ 本页 √/× 与批量显示/隐藏；对标「单位显示类型」= 单位粒度（`-1/0/1/2`）↔ 查询区「单位显示类型」+ `batchUnitDisplay`（本页无逐个单位的类型编辑 UI）。两者**不是**同一个概念，故不走同一列。
- **打印(F8) / 导出**：`handlePrint()` 按 10 列（单位显示/商品名称/商品货号/零售价/批发价/条码/规格/型号/单位）`window.open` 内联 HTML 打印，`handleF8Key()` 绑定 F8；导出为前端 CSV（`\uFEFF` BOM，11 列含 品牌、预设进价，文件名 `单位显示_YYYYMMDD.csv`）；两处「单位显示」列均改由 `isUnitDisplayed()` 派生，「预设进价」导出取后端返回的真实 `presetPurchasePrice`
- **storage-key**：列配置 `mall-unit-display-table-columns`（global-config-key 同值）；页面配置：无（本页未挂 `PageConfigPanel`）
- **同源关系**：与「商品上架」（`views/mall/product-shelf/index.vue`）**同源** —— 同一商品主数据与同一分类树接口 `/erp/product-category/tree`；差异在于本页直连 `erp_product`（`/erp/product/page`），聚焦「单位显示」布尔开关（商品级 `erp_product.unit_display`）+「单位显示类型」查询条件（单位级 `erp_product_unit.unit_display_type`，`-1/0/1/2`）+ 分类树只读 + 无页面配置；「商品上架」走 `v_mall_product` **视图**（`/erp/mall/admin/product/page`），聚焦商城上下架开关（视图列 `status` = `ON_SHELF` / `INACTIVE`，由 `erp_product.mall_shelf_status` 1/0 派生）
