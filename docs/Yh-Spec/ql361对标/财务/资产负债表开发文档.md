## 表格列配置

### 默认显示列（抓取 JSON columns 实据 + 截图补全，6 列）

资产、年初余额、资产期末余额、负债及权益、年初余额、期末余额

> JSON columns 共 5 项（资产、年初余额、资产期末余额、负债及权益、期末余额），首项"资产"为真实首列；JSON 漏抓负债及权益侧的"年初余额"列，按图补全为 6 列（图与 JSON 冲突以图为准）。

### 行结构口径（截图实据）

- 资产侧按流动性列示一级科目项目；负债及权益侧列示负债项目 + 负债合计 + 权益项目 + 所有者权益合计 + 负债和所有者权益总计
- 期末余额列数字为链接：点击穿透至该科目余额明细（穿透目标待复核，预计为科目余额表/明细账）
- 多会计月方式：按多个会计月并列出具（列结构待复核）

## 业务规范说明

### 数据来源与取数逻辑

- 取数自科目余额表口径：年初余额=当年 1 月期初；期末余额=会计月(止)月末余额；科目层级控制项目展开级次
- 恒等校验：资产合计=负债和所有者权益总计（已月结期间成立）；未月结期间因损益未结转出现差额（实据见上，差 58,891.00=本期损益未结转影响的口径待复核）
- 科目映射实据：资产侧=1001 现金库存/1002 银行存款/1122 应收账款/1123 预付账款/1405 库存商品/1601 固定资产；负债侧=2202 应付账款/2203 预收账款/2204 预订货款；权益侧=未分配利润（4103 本年利润结转）/4000 期初资本

### 与其他页面关系

- 数据源：《科目余额表开发文档》（同一聚合口径）；《月结开发文档》（结账后出具口径稳定）
- 姊妹报表：《利润表开发文档》（损益侧）
- 本系统前端目录 `finance/balance-sheet`（dynamicRoutes.ts 实据）
