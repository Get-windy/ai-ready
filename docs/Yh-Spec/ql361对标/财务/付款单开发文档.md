> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`finance/payment-doc/form`（表单）+ `finance/payment`（列表）

## 1. 页面概述

- **表单页**：对结算单位的待付款单据批量付款核销，与收款单对称。页面性质 = 表头付款字段区 + 待付款单据明细表格 + 备注区 + 单据信息 + 底部金额与操作。
- **双入口**：主菜单 → `finance/payment-doc/form`；标签「历史」→ `finance/payment`（付款单列表页）。
- 单号实据：NO. FKD-20260723-001（FKD- 前缀 + YYYYMMDD-序号）。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：结算单位\*、经手人\*（另有单据日期\* 截图确认必填）
- 付款区：付款账户、付款金额（带"全/清"）、更多账户
- 预付抵扣区：此前预付（只读）、使用预付款、预付款余额（只读）
- 应付区：此前应付（只读）、应付余额（只读）
- 调整区：优惠金额、多付金额

> 表头三行布局实据：第一行 结算单位\*/经手人\*/单据日期\*/此前应付（只读）/付款账户/付款金额（全/清）；第二行 更多账户（…弹窗）/此前预付（只读）/使用预付款/应付余额（只读）/预付款余额（只读）/优惠金额；第三行 多付金额。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后付款生效——回写各待付款单据"已结金额/待审金额/未结金额"（按单付款页口径），并生成会计凭证（KJPZ-）
- 查看已结算单据：明细区从"待付款"切换查看已付款核销完成的单据
- 自动分配：把付款金额按明细单据顺序/未结算金额自动分摊到"本次结算"
- 付款金额守恒：本单金额（付款金额+使用预付款+更多账户）= Σ本次结算 + 多付金额；优惠金额核销应付但不产生资金
- 预付抵扣：选定结算单位后带出此前预付；"使用预付款"抵扣应付，预付款余额=此前预付−使用预付款、应付余额=此前应付−本次结算−本次优惠 实时联动
- 多付金额：付款超过应付部分转为供应商预付（预付"付→抵→退"主线中的"付"补充入口）
- 无结算收款单核销(0)按钮：文案疑为"无结算付款单核销"之误（按单付款页按钮实据为"无结算付款单核销(37)"），待复核
- 上游：《按单付款开发文档》行级"付款"进入本页；待付款单据=采购入库单（CGRKD-）等应付来源
- 预付来源：《预付款单开发文档》（YFKD-）
- 下游：记账生成会计凭证（KJPZ-）→ 总账/明细账/科目余额表/辅助核算余额表（应付账款 2202 核算项=往来单位）
- 本系统前端目录 `finance/payment`、`finance/payment-doc`（dynamicRoutes.ts 实据）
