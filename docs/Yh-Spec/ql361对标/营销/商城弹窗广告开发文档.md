## 业务规范说明

### 弹窗广告模型（列实据归纳）

- **投放按时间窗排期**：一行 = 一个弹窗广告活动，起始/结束时间内对商城访客弹窗展示
- **活动状态枚举**（下拉实据）：待开始 / 进行中 / 已结束；创建人审计列
- 广告素材与跳转（推断，待复核）：新增广告表单维护弹窗图片、跳转链接（商品/活动页/自定义）、弹出频度与人群定向——列表列未覆盖，新增表单字段待复核
