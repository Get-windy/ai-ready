# 无对标页面 · 业界系统截图可用性核查（2026-09-15）

> **背景**：交易模块有 8 个页面在 ql361 无对应页面。按「无对标页面查业界成熟系统（Odoo／SAP／管家婆／金蝶／用友），**有截图才补齐，没有就不做**」的要求，本文件记录**逐页核查结论**（能否取得**真实界面截图**），作为补齐与否的依据。

## 三、由本次对标产出的「可借鉴点」（已写入两篇页文档）

| 页面 | 借鉴点 | 落点 |
|---|---|---|
| 支付请求 | ① **支付方式/类型是主数据配置**（Journal + Payment Method 下拉），非自由文本 → 建议补 `bizType` 字典改下拉（对应本页缺口 2）<br>② **差额处理语义**（保留未结／标记全额结清 + 差异记账科目 + Write-Off 标签）→ 本页「确认收款」目前只有收款单号，无差额语义，建议补 | `支付请求开发文档.md` §业界对标 |
| 购物车 | 结算摘要**优惠单列 + 净额**（Discount 负数 / Subtotal）→ 本页「小计」列无优惠语义，若支持优惠宜补「优惠金额／应收金额」两列 | `购物车开发文档.md` §业界对标 |

**明确不借鉴**（已写入文档）：Odoo 卡字段（卡号/CVC/ZIP，PCI 合规不应后台留存）、前台交互（优惠码/心愿单/Buy Now）、税与运费实时计算（本系统在《运费设置》）。

## 四、复现方法

```bash
curl -sL "https://www.odoo.com/documentation/17.0/applications/websites/ecommerce/cart.html" -o cart.html
grep -oE '<img[^>]+_images/[^"]+' cart.html      # 提取真实界面图 URL
# SAP（JS 渲染）需用浏览器打开后检查 document.querySelectorAll('img') 的尺寸
```
