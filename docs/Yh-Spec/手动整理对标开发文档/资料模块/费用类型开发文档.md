## 业务规范说明

- **真实枚举（`ExpenseType` 16 类）**：TRAVEL 差旅(TRA) / OFFICE_SUPPLIES 办公(OFF) / MEETING 会议(MET) / ENTERTAINMENT 招待(ENT) / TRANSPORTATION 交通(TRN) / COMMUNICATION 通讯(COM) / TRAINING 培训(TRG) / CONSULTING 咨询(CON) / ADVERTISING 广告(ADV) / R&D 研发(RND) / EQUIPMENT 设备(EQP) / MAINTENANCE 维护(MNT) / RENTAL 租赁(RNT) / INSURANCE 保险(INS) / TAX 税费(TAX) / OTHER 其他(OTH)。
- **枚举属性**：`requiresApproval`（除 TAX 外均 true）、`requiresInvoice`（除 TAX 外 true）、`requiresBudgetControl`（除 TAX/OTHER 外 true）。
- **真实 API**：`ExpenseTypeController` `/api/erp/expense/type`（`list`/`/{code}`/`descriptions`/`codes`，**无分页**），前端《费用单》经此获取类型下拉。
- **⭐ 占位缺口**：本桩页建模带 parentName/subjectCode 的平铺分页，与真实枚举（无数据表、无层级、无分页）字段不一致，**建议改为枚举渲染**。
- **对标口径**：ql361 费用类型以**会计科目（费用类科目）为载体**（科目编号/科目名称/核算项），与《费用单》类型下拉相关联。
