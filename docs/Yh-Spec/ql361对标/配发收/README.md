## 域级说明

- **菜单结构**（实据）：配发收一级域 → 配送业务（配送查询）/ 发货业务（物流发货、发货查询）/ 收货业务（物流退货收货、采购订货收货）。三组对应"配送 → 发货 → 收货"的物流闭环。
- **入口直达现象**（实据）：本域 5 个菜单中 3 个为"直达型"入口——物流发货打开"订单处理中心"并选中 2.拣货/发货；物流退货收货打开"销售退货申请-历史"；采购订货收货打开"收货处理"。仅配送查询、发货查询为独立标签页。本系统落地时直达入口应复用目标视图组件，不重复造页面。
- **单据编号规则**（截图实据）：发货查询中出库单号 XSCKD-、来源订单号 XSDD-，后缀均为 `YYYYMMDD-序号`（与销售域编号规则一致）；配送任务编号、收货单据编号规则待复核。
- **快捷键体系**：打印(F8) 在配送查询/物流退货收货/采购订货收货三页实据存在；Ctrl+S/Ctrl+Enter 为表单页快捷键（销售域实据），本域列表页不涉及。
- **状态流转主线**（实据归纳）：销售订单（XSDD）→ 订单处理中心审核 → 拣货/发货（物流发货入口）→ 生成销售出库单（XSCKD，已记账）→ 配送任务（配送查询：待配送/配送中/已配送）；退货线：销售退货申请（审核）→ 物流退货收货（已收/未收跟踪）→ 销售退货单入库；采购线：采购订单 → 采购订货收货（待收货/部分收货，批量收货）→ 采购入库单。
- **通用待复核项**：本域 5 页打印配置弹窗、列配置弹窗全量列（XSMK 无记录）；物流发货/物流退货收货/采购订货收货三页的行级操作（抓取时点无数据行）；按明细子标签列结构；收货确认与采购入库单/销售退货单的生成先后关系。
