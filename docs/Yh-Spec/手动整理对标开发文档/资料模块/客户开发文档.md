## 页面概述

客户是**客户主数据档案**（含分类树 + 查询 + 5 子标签）。双入口（列表 + 表单）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 客户列表页 | `md/customer/index`（list_path `md/customer/form` 双入口） | 客户档案列表 + 客户分类树 + 5 子标签 |
| 客户表单页 | `md/customer/form` | 新增/编辑客户 |

> 客户/供应商/物流/其他往来单位统一走 `erp/partner`（往来单位-客户分类），`md/customer` 为客户端口。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列。**列配置弹窗**在数据表右上角 `.icon-shezhi2`；**页面配置弹窗**在页面顶部按钮栏「配置」齿轮（仅 全部客户/会员管理 两个子标签提供，其余子标签为固定查询/按钮，无配置齿轮）。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，可视化列「上级 / 列名 / 显示名 / 显示」；底部「上移 / 下移 / 恢复默认 / 保存」。
- 页面配置弹窗（Vue）结构：顶部「查询条件 / 功能按钮」Tab + 底部「使用鼠标拖动行可以调整顺序 / 恢复默认值 / 关闭(Esc)」（字段列表含隐藏项）。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 业务规范说明

- **客户来源**：ERP 往来单位-客户（**非 CRM 公海客户**；CRM=潜在，ERP=实体交易）。
- **价格等级**：客户级别为标准化 8 价格等级（复用 `priceLevelConfig`，不重复开发）。
- **绑定售价**：客户单价按价格等级带出（销售订单/零售单按客户级别取价）。
- **预收接入**：客户预收余额（预收款单/收款单联动）。
- **会员联动**：会员管理/会员信息（会员卡号/会员名称/初始积分）联动营销会员模块。
- **账期**：动态收款期限（天）/固定账期/结算期用于应收账期判断。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 客商主数据单一口径（红线）**：客户主数据统一走 `erp/partner`（`biz_party.partyType`=customer），**严禁另建客户表**；CRM 公海为潜在客户、ERP 往来单位为实际交易，二者区分不混用。
- **P1 取价/预收**：客户单价按价格等级（`priceLevelConfig`）带出；预收余额经《预收款单/收款单》联动，不改客户表。
- **P1 账期/会员**：账期字段（动态收款期限/固定账期/结算期）入应收判断；会员信息（卡号/积分/等级）联动营销会员。
- **P2 验收**：客户档案增删改经 `partnerApi`；编号/名称唯一；与销售/采购/零售/收付款数据闭环验证。
