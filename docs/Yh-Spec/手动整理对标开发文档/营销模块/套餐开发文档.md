## 4. 业务规范

- **套餐模型（行数据实据归纳）**：
  - 套餐 = 多商品组合的销售单元：商品明细列实据为多行「商品*数量」组合；套餐金额 176 为整组定价。
  - 套餐编号规则（行实据）：`tc + 序号`（`tc0001`）——`tc` 为「套餐」拼音首字母，与销售域单据编号风格一致。
  - 套餐条码：套餐可独立赋码，配合「条码打印」打印套餐条码标签，开单扫码按套餐整组录入。
  - 捆绑销售（实据 √）：勾选后套餐内商品必须整套购买、不可拆零；未勾选时是否可拆卖**待复核**。
  - 生命周期：新增 →（可复制快速建档）→ 停用（下架停售，对应显示状态查询条件）→ 删除；复制动作用于同构套餐快速复制。
  - 双条件检索：既可按套餐自身（名称/编号/助记码/条码）查，也可按内含商品（名称/货号/条码/规格/型号）反查——套餐与商品为多对多关系。
  - 与仓储「组装单/拆卸单」的区别：套餐是销售侧组合定价，组装/拆卸是仓储侧实物加工改变库存形态；两者业务归口不同，不可混用。
- **与其他页面关系**：销售开单联动（套餐作为可售单元进入商品选择，套餐条码扫码录入；销售明细按套餐行或拆行计价**待复核**）；库存扣减（套餐发货扣减各明细商品库存，推断，扣减时点与批次规则**待复核**）；本系统落地对应套餐 `/api/erp/product-kit`。

### 剩余缺口

1. **🔴 列结构部分偏离（最大缺口）**：对标 7 列（图片/套餐名称/套餐编号/套餐金额/套餐条码/捆绑销售/商品明细）；本页 9 列（套餐编码/套餐名称/套餐商品/类型/套餐价/套餐成本/毛利率/状态/操作）。**仅「套餐名称」「套餐编号(套餐编码)」「套餐金额(套餐价)」3 列语义对应**；**缺**「图片」「套餐条码」「捆绑销售」「商品明细」（商品明细在抽屉中而非列表列）；**多出**「套餐商品/类型/套餐成本/毛利率/状态」。
2. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；`ARReportPage` 无列配置入口。
3. **查询条件不对齐**：对标为「套餐四合一模糊检索 + 按内含商品反查 + 显示状态」；本页为「关键字 + 类型 + 状态」，**无法按内含商品反查**。
4. **按钮不对齐**：对标工具栏有「刷新/打印(F8)/条码打印/更多」、行级为「修改/停用/复制/删除」；本页工具栏仅「新增套餐」（+ `ARReportPage` 内置刷新/导出），行级为「组件/编辑/停用|启用」。**无条码打印、无复制、无删除入口**（后端 `ProductKitController` 已有 `/{id}/copy` 与 `DELETE /{id}`，页面未挂）。
5. **套餐条码 / 捆绑销售缺失**：本页弹窗与列均无「套餐条码」「捆绑销售」字段（对标核心列）；`allowSplit`（允许拆分）为反向语义，**是否等价于捆绑销售待复核**。
6. **图片缺失**：对标「图片」列未实现。
7. **打印**：对标有打印(F8)+条码打印；本页无打印按钮。
8. **导出**：本页用 `ARReportPage` 内置「当前页 CSV 导出」（`ARReportPage.vue:340-371`，非全量），且导出列不含对标 4 列。
9. **组件明细抽屉**：本页把「商品明细」放在抽屉（7 列），对标是列表内「商品明细」文本列；表现形式不同（信息可得，但列配置不覆盖）。
