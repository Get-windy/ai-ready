## 4. 业务规范

- **促销规则模型（同构实据归纳）**：
  - 作用层级：按整单门槛生效——整单金额/数量满 N 触发减/赠/折；落点为销售订单摘要结账面板「促销优惠、优惠金额(−)」。
  - 与商品促销的分工（列结构同构实据）：商品促销按「订单单个促销商品」触发（行级）；整单促销按整单汇总门槛触发；两页查询区与 13 列完全一致，说明共用同一套促销活动模型，仅促销方式不同。
  - 定向维度：促销商品、促销客户、使用范围三维定向（列实据）。
  - 组合促销：是否可与其他活动叠加的标记（列实据），行级取值待复核。
  - 生命周期：新增 → 时间窗内生效 → 过期/作废；「显示已过期/已作废活动」默认隐藏（基准文档勾选项实据）。
- **与其他页面关系**：与《商品促销开发文档》互补（单级 vs 行级；叠加规则由「组合促销」列控制）；销售开单联动（整单优惠在销售订单摘要面板体现）；商城侧「我要推广」可推广促销活动；本系统落地对应 `/api/sale/promotion`。

## 5. 实现差异说明

> 本节按当前源码回写（源码未在本轮改动）。

### 当前实现

- **实现文件**：`frontend/apps/pc-admin/src/views/marketing/order-promo/index.vue`（共 339 行）
- **骨架**：`ARReportPage`（`index.vue:2-11`，`title="整单促销"`、`page-param-style="pageNum"`、`export-file-name="整单促销"`），**非**金标准路线 A（`ARReportPage` 无列配置齿轮/页面配置弹窗）。
- **查询条件**：`queryFields`（`index.vue:180-189`）= 名称 `name`（input）、状态 `status`（select，选项来自 `STATUS_MAP`）——**仅 2 项**。
- **列定义**：`columns`（`index.vue:192-201`），共 **8 列**：促销名称、满减门槛（minAmount）、立减金额（reductionAmount）、促销时间（period，`:27-29`）、每客户限次、叠加（stackable 标签，`:30-34`）、状态、操作。
- **状态映射**：`STATUS_MAP`（`index.vue:171-176`）= draft 草稿 / published 已发布 / expired 已过期 / cancelled 已取消。
- **数据请求**：`fetcher`（`index.vue:213-215`）= `promotionApi.page({ ...params, type: 'full_reduction' })`——**固定 `type='full_reduction'`**（整单满减）。
- **工具栏**：`header-extra` 放「新增满减」按钮（`index.vue:12-22`）。
- **行级操作**（`index.vue:40-66`）：编辑；`status==='draft'` 时「发布」；`status==='published'` 时「取消」；`status in (draft,cancelled)` 时「删除」。
- **弹窗**（`index.vue:71-158`）：促销名称、促销时间、满减门槛（minAmount）、立减金额（reductionAmount）、最大使用次数、每客户限次、可叠加、促销描述。
- **数据来源**：`apps/pc-admin/src/api/marketing.ts` → `promotionApi.page/create/update/remove/publish/cancel`（`marketing.ts:254-279`，端点 `/sale/promotion/...`）。
- **后端**：`erp/erp-sales/.../sale/controller/PromotionController.java`（`@RequestMapping("/api/sale/promotion")`，`PromotionController.java:20`）。
- **storage-key**：无（未使用列配置/页面配置持久化）。

### 剩余缺口

1. **🔴 列结构整体不对齐（最大缺口）**：对标 13 列（活动名称/起始时间/结束时间/促销方式/促销商品/组合促销/促销类型/促销模式/促销规则/使用范围/促销客户/活动状态/制单人）；本页 8 列（促销名称/满减门槛/立减金额/促销时间/每客户限次/叠加/状态/操作）。**仅「促销名称(活动名称)」「促销时间(起止)」「叠加(组合促销)」「状态(活动状态)」语义近似**。
2. **未达金标准路线 A**（如实标注）：未使用 `CategoryListLayout`/`BillDetailTable`/`StandardPagination`/`PageConfigPanel`；`ARReportPage` 无列配置入口。
3. **查询条件不对齐**：对标为商品/客户/促销类型/组合促销/促销模式/起止时间/使用范围/活动状态/制单人 + 勾选项；本页仅 `名称 + 状态` 2 项。
4. **规则模型缺失**：无「促销类型 / 促销模式 / 促销规则 / 促销商品 / 促销客户 / 使用范围」字段。本页以「满减门槛+立减金额」表达单级满减，**只覆盖对标促销模式枚举中的一种**（枚举全集待复核）。
5. **按钮不对齐**：对标有「更多玩法告诉我们..」；本页无。行级对标为「查看/修改/更多」，本页为「编辑/发布/取消/删除」。
6. **打印**：对标无打印按钮，本页亦无（一致）。
7. **导出**：本页用 `ARReportPage` 内置「当前页 CSV 导出」（`ARReportPage.vue:340-371`，非全量）。
