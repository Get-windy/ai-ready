## 页面概述

其他往来单位用于维护**非客户/非供应商/非物流的往来单位**（维修服务商、培训公司、财务公司、法律服务、保险公司、IT 服务商、咨询公司、仓储合作方、质检机构、其他），按「单位类别」区分。双入口（列表 + 表单）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 其他往来单位列表页 | `md/partner/index`（list_path 双入口） | 往来单位档案列表 |
| 其他往来单位表单页 | `md/partner/form` | 新增/编辑往来单位 |

> 其他往来单位走 `biz_party.partyType`=4（other），`md/partner` 为其他往来端口。

### 配置功能说明

- **页面配置/列配置**：管理页面级字段与数据表列。
- **工具栏**：新增 / 导入 / 列设置 / 刷新 / 打印(F8) / 导出 / 更多-批量删除。
- ⚠️ **当前实现说明**：本页为共享 `PartnerListPage`，自定义搜索键名 `category` 与后端 `categoryId` 不匹配（搜索不生效），见「实现差异说明 → 待完善」。

> 🔒 **对标实测（2026-09-07）**：当前账号（杨生淮 / 肃州区皇朝酒店用品商行）的 **资料 → 往来单位** 子菜单仅包含 **客户 / 供应商 / 物流公司 / 互联账号** 四项，桌面整棵菜单树中也未检索到「其他往来单位」菜单项（全 DOM 文本精确/模糊匹配均无）。因此**无法打开该页，未实测**，下列「列表页配置 / 表单页配置」来自本系统实现，**不能作为金标准对标数据**。后续需换用拥有该菜单权限的账号重新实测，或以「供应商」表单（同为主数据建档）为参考。

## 业务规范说明

- **单位来源**：ERP 往来单位-其他（`biz_party.partyType`=4）。
- **主体关系**：客户=1 supplier=2 logistics=3 other=4 统一 `biz_party`。
- **编号前缀**：WLDW（中文）/ PTR（英文），经 `next-seq` 生成。
- **类别**：列表类别列用字符串 `categoryMap`（展示文本），表单分类选择用数字 `category.id`（口径不一致）；自定义搜索键名 `category` 与后端 `categoryId` 不匹配。
- **用途**：用于费用报销（维修/培训/咨询）、质检（质检机构）、仓储合作等非购销主体关联。
