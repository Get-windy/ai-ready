## 页面概述

付款单用于对结算单位的待付款单据（采购入库单 CGRKD- 等应付来源）批量付款核销。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 付款单表单页 | `finance/payment-doc/form`（主菜单入口） | 新增付款 + 待付款单据核销 |
| 付款单列表页 | `finance/payment-doc/index`（list_path `finance/payment`） | 双入口「历史」标签，列表**双 Tab**：按单据 / 付款明细 |

单号实据：`FKD-20260723-001`（`FKD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明（每个页面都有）
- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面**顶部按钮区域**（表单页为 BillPageConfigDialog「页面配置/录单默认值/打印设置」三 Tab；列表页为 Vue「配置」弹窗「查询条件/功能按钮」两 Tab），列配置在数据表右上角表头单元格内齿轮图标（`icon-shezhi2`）。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级金标准组件**（列表仍为 `PageContainer`+`SearchBar`+`BillTableList`，表单为自定义 `a-form`），见「实现差异说明 → 待完善」。

## 业务规范说明

- **付款核销**：付款金额分摊到各待付款单据「本次结算」，记账后回写各单据「已结算/待审金额/未结算」。
- **预付抵扣（"付→抵→退"）**：选定供应商带出此前预付/可用预付；「使用预付款」从预付余额抵扣应付，抵扣后「预付款余额=此前预付−使用预付款」实时联动。
- **多付金额**：付款超过应付部分转为供应商预付（"付"环节补充入口）。
- **付款金额守恒**：本单金额（付款金额+使用预付款+更多账户）= Σ本次结算 + 多付金额。
- **自动分配**：按明细顺序/未结算金额自动分摊，分配后仍可手调。
- **记账生成凭证**：记账后自动生成会计凭证（`KJPZ-`），进入总账/明细账/科目余额表；应付对应科目 2202（核算项=往来单位）。
- **上游**：按单付款页行级「付款」进入本页；待付款单据=采购入库单（CGRKD-）等应付来源；预付来源=预付款单（YFKD-）。
- **交账前置**：职员经手单据须先在《账款交账》交账方可被选择。
- **单号前缀** `FKD-`（前端 `generateNo`/`genTaskNo` 生成，后端 save 原样落库）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 资金单一口径（红线）**：付款单记账遵循「资金付 → 抵（核销应付）→ 退（多付转预付）」主线，记账后按明细核销应付并生成会计凭证（KJPZ-），**严禁绕过核销直接修改应付余额/预付余额**（禁止双轨）。
- **P1 预付抵扣**：用供应商预付抵扣应付必须经《预付款单》（YFKD-）余额，抵扣后预付余额=此前预付−使用预付款；多付金额自动转供应商预付。
- **P1 上游联动**：待付款单据为采购入库单（CGRKD-）等应付来源；经手人须先经《账款交账》交账方可选择。
- **P2 验收**：无桩/无模拟；列表列/配置对齐金标准（双 Tab 按单据 26 列/付款明细 22 列/核销明细 23 列）；凭证、应付核销、预付联动需真实数据闭环验证。
