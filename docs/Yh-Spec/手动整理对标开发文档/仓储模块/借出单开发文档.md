# 借出单开发文档

## 页面概述

借出单用于将商品借给往来单位出库录单（后续需还回），支持按批次借出。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 借出单列表页 | http://localhost:5656/wh/borrow-out/index | 双入口「历史」标签，按单据/按明细 2 个 Tab |
| 新增/编辑借出单表单页 | http://localhost:5656/wms/borrow-out/form | 编辑模式为新增模式加 id |

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 80011 |
| menu_code | `wh:borrow-out` |
| 主菜单路径 | `wms/borrow-out/form`（点击进新增表单） |
| 标签「历史」路径 | `wh/borrow-out/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `views/wh/borrow-out/form/index.vue`（表单）、`wh/borrow-out/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后商品出库（借出库存，待还回）。
- 预计还回时间：约定归还日期，供借进借出查询跟踪逾期。
- 借出后续（借出商品查询子标签实据推断）：还回（还回入库）或借转销售（推断，待复核）。
- 往来单位必填（借出必有借入方）；借出数量不得超过可用库存；批次条码列齐备：按批次借出。
- 反向单据：借进单（从往来单位借入，预计还出时间）；台账查询：借进借出查询（借进商品查询/借出商品查询双子标签）。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 实现差异说明

**实现文件**：`frontend/apps/pc-admin/src/views/wh/borrow-out/form/index.vue`（表单页）、`views/wh/borrow-out/index.vue`（列表页）
**后端**：`wh-borrow-out` 相关模块（`BorrowOutController` / 相关实体）

### 页面对齐（已实现）
- 列表页 `views/wh/borrow-out/index.vue` 已金标准复刻：双 Tab「按单据(23列) / 按明细(51列)」，页面配置（13 项查询条件 + 功能按钮显隐）、列配置弹窗、快捷日期、记账/取消/删除/查看/修改、导出、批量导入（跳转新增表单）。
- 表单页 `views/wh/borrow-out/form/index.vue` 已金标准复刻：`BillFormPage` + `BillDetailTable`（默认 20 列 / 全部 45 列，含「批次条码」默认显示 + 扫描枪录入开关），配置弹窗 3 Tab（页面配置 / 录单默认值 / 打印设置），页眉动作（打印 F8 / 导入 / 导出 / 历史 / 配置），保存草稿 Ctrl+S、记账 Ctrl+Enter。
- 双入口（`display_mode=1`，菜单 80011 `wh:borrow-out`）已配置；位于仓储「借进借出(60305)」列组下。

### 后端闭环（已实现）
- `next-no`（单号 `JCD-`，`BorrowServiceImpl.generateOrderNo` 借出前缀 `JCD`；`next-no` 接口支持 `direction`/`prefix` 参数区分借进/借出）。
- `save`（草稿，复用 `create`/`update`）、`post`（记账，借出库存扣减）、`doc-query`（按单据分页）、`page-detail`（按明细分页）均已接入，与借进单共用 `BorrowController`/`WmsBorrowOrder` 实体。
- 数据库迁移 `V11.64.0__Enhance_Wms_Borrow_Out_Menu.sql`：80011 菜单双入口配置修正。

### 遗留项（已实现）
1. **还回（归还）**：列表页操作列 + 表单页页眉「归还」按钮，均可打开归还登记弹窗（按明细填写本次归还数量，累计归还，支撑部分归还），调用 `borrowApi.returnOrder`（后端 `BorrowServiceImpl.returnOrder`，借出归还=库存增加回冲，状态更新为部分归还/已归还）。
2. **批次拣选校验**：后端 `InventoryController` 新增 `GET /wms/inventory/batch-list?productId&warehouseId`（`InventoryService.listAvailableBatch` 返回商品×仓库可用批次行，FEFO 近效期优先）；借出记账 `BorrowServiceImpl` 按 `item.batchCode` 调用 `inventoryService.decrease`（批次为空则整仓扣减），`decrease` 内部校验可用量不足抛异常；前端表单「批次条码」列改为批次下拉（来源 batch-list），选中回填货位/可用量，并校验借出数量 ≤ 批次可用库存。
3. **借转销售登记**：后端 `BorrowController` 新增 `POST /wms/borrow/convert-sale`，`BorrowService.convertSale` 与借转采购共用 `applyConvert` 私有逻辑（文案参数化），更新明细 `processedPurchaseQuantity`（已处理-借转销售）/`nonProcessedQuantity`/`nonProcessedAmount`，单据 `convertPurchaseQuantity`/`convertPurchaseAmount`；前端列表页操作列「借转销售」按钮 + 借转销售登记弹窗（按明细填本次借转销售数量，≤ 未处理数量）。当前为**台账登记**（未生成销售单据），与借转采购（同样未生成采购单据）对称。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
