## 页面概述

提存（提现存现转款）用于**资金在本企业账户间移动**（银行提现、现金存行、账户互转）。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 提存表单页 | `finance/cash-transfer/form`（主菜单入口） | 新增转账 + 转入账户明细 + 手续费 |
| 提存列表页（历史） | `finance/cash-transfer/index` | 双入口「历史」标签，列表**双 Tab**：按单据 / 按明细 |

单号实据：`YHZKD-20260907-001`（`YHZKD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明（每个页面都有）
- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区域（列表页为 Vue「查询条件/功能按钮」配置弹窗；表单页为 dojox「页面配置/打印设置」弹窗），列配置在数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转；支持上移/下移/恢复默认/保存。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级金标准组件**（列表仍为 `SearchBar`+`BillTableList`，表单为自定义 `a-form`），见「实现差异说明 → 待完善」。

## 实现差异说明

**实现文件**：
- 前端：`views/finance/cash-transfer/form/index.vue`（表单页）、`views/finance/cash-transfer/index.vue`（列表页）
- API：`api/finance/cash-transfer.ts`
- 后端：`backend/erp/erp-finance/.../finance/cashtransfer/`（Controller/Service/Mapper/Entity/DTO）、迁移 `V11.81.0__Create_Cash_Transfer_Tables.sql`

### 页面对齐（已升级金标准，2026-09-07）
- **列表页**：`CategoryListLayout` + 双 Tab（按单据/按明细） + `BillTableList` + `ColumnConfigPanel`/`PageConfigPanel`。
  - 按单据 Tab：查询条件 10、可配置列 17、默认显示 9；按明细 Tab：查询条件 11、可配置列 17、默认显示 10（对齐文档）。
  - 快捷日期（昨日/今日/本周/近一周/本月/上月/近三月/本年）+ 查询方案 + 列配置/页面配置弹窗（查询条件/功能按钮两 Tab）。
- **表单页**：`BillFormPage` + `useBillForm` + `BillDetailTable`（转入账户明细 4 列）+ 配置三Tab（页面配置/录单默认值/打印设置，`userPageConfigApi` 持久化）。
  - 表头：转出账户（下拉，必填）/经手人（默认当前登录人）/单据日期（默认当天）；表尾：手续费/单据备注；页脚：本单金额（=Σ转入金额+手续费）+ 保存草稿 Ctrl+S / 记账 Ctrl+Enter。
- **后端**（零桩）：`/api/erp/finance/cash-transfer` 提供 `page/doc-query/page-detail/next-no/{id}/create/update/confirm/cancel`，单号 `YHZKD-YYYYMMDD-序号`。

### P0/P1 红线落地（严格按最终裁决方案）
- **P0 资金单一口径**：记账 `confirm` 必须经会计凭证（`BusinessAccountingService` 生成会计凭证，Dr 转入账户科目 / Cr 转出账户科目，手续费 Dr 6602 管理费用；凭证号沿用系统全局 `VoucherService` 口径为 `YYYYMM-XXXX`，与文档规格 `KJPZ-` 前缀的差异为既有系统记账格式，提存记账确经凭证闭环），并更新 `finance_account.balance`（转出减/转入加）+ 记 `erp_capital_flow` 双边流水。
- **P1 资金守恒**：转出金额 = Σ转入金额 + 手续费，`confirm` 时严格校验，不平衡报错。
- **P1 不动往来**：全程不涉及往来单位，不产生应收/应付。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 资金单一口径（红线）**：提存为资金账户间划转，记账必须经凭证（KJPZ-），**严禁绕过凭证直改账户余额**；且**不得涉及往来单位**（不产生应收/应付）。
- **P1 金额守恒**：本单金额=Σ转入金额（含手续费），转出=转入+手续费。
- **P1 手续费**：手续费按承担账户/科目归集，计入费用或相应会计科目。
- **P2 验收**：无桩/无模拟；账户互转、凭证、资金守恒需真实数据闭环验证。
