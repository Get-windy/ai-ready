# 拆分单开发文档

## 页面概述

拆分单用于成品拆解为原料的生产逆向录单（成品出库 + 原料入库同单完成，双明细表复合）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 拆分单列表页 | http://localhost:5656/erp/stock-split/index | 双入口「历史」标签 |
| 新增/编辑拆分单表单页 | http://localhost:5656/erp/stock-split/form | 双明细表（成品出库+原料入库） |

> **命名说明**：对标系统该页面称「拆卸单」，本系统按业务语义命名为**拆分单**（仓储菜单变更已确认）。

### 配置功能说明（每个页面都有）

- **页面配置**（页面顶部齿轮图标）：管理页面级字段的显示、隐藏和排序
- **列配置**（数据表右上角表头单元格内齿轮图标）：管理数据表列字段的显示、隐藏、排序、宽度调整及左右冻结
- 页面配置在页面顶部按钮区域，列配置在页面内嵌数据表右上角表头单元格内齿轮图标

### 双入口配置（本系统）

| 项 | 值 |
|----|----|
| 菜单 ID | 5016（原"拆分管理"，本次改名"拆分单"） |
| menu_code | `erp:stock-split` |
| 主菜单路径 | `erp/stock-split/form`（点击进新增表单） |
| 标签「历史」路径 | `erp/stock-split/index`（进列表） |
| tag_label | 历史 |
| display_mode | 1（双入口） |
| 组件 | `erp/stock-split/form`（表单）、`erp/stock-split/index`（列表） |

## 业务规范说明

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：记帐后成品按「成品详情(出库)」扣减成品仓库库存，原料按「原料详情(入库)」增加原料仓库库存。
- 与组装单结构差异：无「生产单位」字段、无「加工费用/计算成本」行（截图与 JSON 实据）。
- 可由生产模板带出原料构成（模板引用交互待复核）。
- 反向单据：组装单（原料组装为成品）；上游：生产模板（BOM 原料构成来源）；记帐后影响 分析→仓配分析→查库存/库存明细。
- **架构师红线**：对标 Odoo/SAP/金蝶/用友/管家婆等生产级系统的业务与交互逻辑；动手前过六关，仅最小可用闭环，防注入/容灾/安全防御代码不准省。
- **验收标准**：无桩（Stub）与模拟（mock|todo|fixme|占位|placeholder），确保真实数据。
- **对标系统**：ql361（`22stable.ql361.com`），具体见 `docs/Yh-Spec/ql361对标/README.md`。

## 开发原则（通用）

- **页面组件优先复用**：页面开发优先使用已有的页面组件，除非当前页面组件不满足业务需求；确无对应组件，则优先开发合适的通用组件。
- **功能/模块不重复开发**：已开发过的业务功能、单据、通用能力在全系统范围内只实现一次；其它模块直接复用，不重复开发。
- **Service 接口签名变更需同步测试**：修改 Service 接口签名（方法名/参数/返回值）时，必须同步更新对应测试类，否则会阻塞整模块的 `test-compile`。
- **阶段结束前回写开发文档**：当前阶段工作完成后、结束前，必须更新开发文档的「已完成」与「待完善」章节，使其反映当前代码的实际实现情况。
