## 5. 使用指南

### 5.1 应用集成
1. **标准JSON格式**:
```json
{
  "timestamp": "2026-04-30T20:38:00.123Z",
  "level": "INFO",
  "message": "用户登录成功",
  "application": "ai-ready-backend",
  "environment": "test",
  "request_id": "req-123456"
}
```

2. **HTTP发送日志**:
```bash
curl -X POST http://fluentd.logging-test:9880/app.log \
  -H "Content-Type: application/json" \
  -d '{"level":"INFO","message":"测试日志"}'
```

### 5.2 日志查询
1. **Kibana访问**: http://kibana.logging-test:5601
2. **Elasticsearch API**: http://elasticsearch.logging-test:9200
3. **常用查询**:
```json
GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "level": "ERROR" }},
        { "range": { "@timestamp": { "gte": "now-1h" }}}
      ]
    }
  }
}
```
