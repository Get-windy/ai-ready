### 口径说明（多级表头归位）

- **分组名不是数据列**：`columnConfig` 共 27（按时间）/ 34（按职员）个**叶子列**；`snapshot.headers` 中另有 6 个**分组表头**——`拜访统计`、`订货统计`、`销售统计`、`退货统计`、`回款数据`、`利润统计`，它们只承接其下叶子列的合并单元格，**不单独占序号、不可单独配置**。基准文档记「17 项 = 11 叶子 + 5 分组」即未含第 6 组与独立列，本次订正为 27/34 叶子 + 6 分组。
- 分组归位：
  - `按时间`：拜访统计（拜访客户数、拜访完成率（%））；订货统计（订货客户数、订货金额、实订金额）；销售统计（销售客户数、实销金额、其他费用、销售业绩目标、销售业绩完成率（%））；退货统计（退订金额、退订率(%)、退货金额、退货率(%)）；回款数据（回款客户数、回款总额、按期回款总额、超期回款总额、回款业绩目标、回款业绩完成率（%））；利润统计（销售收入、销售成本、销售毛利、毛利率（%））；**独立叶子**为 日期(1)、拓客数(2)、本期未结金额(27)。

## 4. 业务规范

### 统计口径（漏斗全链路）

- **漏斗链路**：拓客数（新增客户）→ 拜访统计（拜访客户数、拜访完成率 = 实际拜访 / 计划拜访）→ 订货统计（订货客户数、订货金额、实订金额）→ 销售统计（销售客户数、实销金额、其他费用、销售业绩目标/完成率）→ 退货统计（退订金额/退订率、退货金额/退货率）→ 回款数据（回款客户数、回款总额、按期/超期回款、回款业绩目标/完成率）→ 利润统计（销售收入、销售成本、销售毛利、毛利率）→ 本期未结金额。
- **实订 vs 实销**：`实订金额` 取自销售订单（XSDD-），`实销金额` 取自销售出库单（XSCKD-）；`订货金额` 为订货毛额、`实订金额` 为扣退订后的净订货额；`销售金额`（按职员）为销售毛额、`实销金额` 为净销售额。
- **退货率(%)** = 退货金额 / 实销金额 × 100；**退订率(%)** = 退订金额 / 订货金额 × 100。
- **完成率类**：`销售业绩完成率（%）` = 实销金额 / 销售业绩目标 × 100；`回款业绩完成率（%）` = 回款总额 / 回款业绩目标 × 100；`拜访完成率（%）` = 拜访客户数 / 计划拜访数 × 100。
- **利润统计**：`销售毛利` = 销售收入 − 销售成本；`毛利率（%）` = 销售毛利 / 销售收入 × 100。
- **回款拆分**：`按期回款总额` / `超期回款总额` 按信用账期是否超期拆分，两者之和构成 `回款总额` 的账期口径视图。
- **本期未结金额**：查询期内已发货未收款金额（与《销售履约分析》未结金额同源）。
- **指标卡片**（基准文档，待复核）：九卡三色——订货客户数/实订金额/实销金额/回款总额（红）、退货金额/退货率（橙）、拓客数/拜访客户数/拜访完成率（青）。2026-09-15 实测截图为**表格视图**，指标卡形态未取到。

### 与其他页面关系

- 取数：销售订单 / 销售出库单 / 销售退货单 / 收款单（经营历程流水）+ 客户主数据（拓客）+ 外勤拜访记录（拜访统计）+ 业绩目标配置。
- 下游：《业绩提成中心》《业务员提成》（业绩 → 提成取数基础）、《经营分析》（利润口径扩展）、《销售分析》（量本利明细口径）。
- 维度一致性：`按职员` 的职员集合来自部门主数据，左侧部门分类树即按 `所属部门` 过滤。

- **页面配置**：**对标有**「按时间/按职员-页面配置弹窗」实据 → 接 `PageConfigPanel`，逐 Tab 独立 `useAnalyticsPageConfig`；同时传 `:default-query-fields-config` 与 `:default-function-buttons-config`（恢复默认基准）与 `:print-config-items`。
- **查询区**：查询方案 + 时间快捷段 8 段（昨日/今日/本周/近一周/本月/上月/近三月/本年）+ 日期范围 + 客户/经手人/区域（逐 Tab 可在页面配置中显隐）+ 不显示停用职员，横向自适应网格（`.search-grid` + `flex-wrap`，样式写在页面自身 `<style scoped>`）。
- **工具栏**：刷新｜打印(F8)｜导出｜页面配置。
- **打印(F8) / 导出**：`handlePrint()` + `handleF8Key()`（`onBeforeUnmount` 移除监听）+ 基于 `useExport` 的 CSV 全量导出，导出/打印列 = 当前 Tab 默认可见列。
- **取数端点**：`GET /api/erp/sale/analysis/sales-performance/page?tab=time|staff`（后端 `SaleAnalysisReportController`，响应 `{records,total,page,size,pages,summary}`，经拦截器解包）。
- **左侧分类树**：部门分类树（`/department/tree`，选中节点按 `department_name` 模糊下推给后端）。
- **合计行**：`BillDetailTable` 的 `:summary-columns` 取后端 `summary`（**按当前过滤范围 SUM**，非当前页求和）；比率列在合计行置空（避免误读）。

### 剩余缺口（2026-09-18 复核）

1. **业绩目标 / 完成率无数据源**：`销售业绩目标`、`销售业绩完成率（%）`、`回款业绩目标`、`回款业绩完成率（%）` 4 列本系统无业绩目标配置表，后端返回 `null`（前端显示 `-`），**未用 0 冒充**。
2. **拜访统计无数据源**：`拜访客户数`、`拜访完成率（%）` 本系统无外勤拜访记录表，后端返回 `null`。
3. **`退订单数` 无数据源**：销售订单表无「退订单据数」聚合列（仅有退订数量/金额），返回 `null`。
4. **`指标设置` 弹窗未落地**：对标工具栏为「指标设置」（指标卡配置），其弹窗字段级明细从未抓取（文档记「待复核」），故不伪造入口；本系统以「页面配置」承载查询条件/功能按钮配置。
5. **`按时间` 的粒度切换（按天/周/月）**：对标本页未确证（文档记「保留待复核」），本页未提供粒度控件；`按时间` 默认按天聚合。
6. **钻取**：对标数值单元格带下划线可下钻到单据/明细，本系统未实现行级下钻（无落点页面），如实登记。
7. **打印/导出的样式**：打印为浏览器新窗口 HTML 表格（对标为专用打印模板，字段级明细未抓取）。
