### 口径说明（多级表头归位）

- **分组名不是数据列**：`snapshot.headers` 中出现 **1 个分组表头 `超期欠款分布`**，其下辖 5 个账龄叶子列（`小于1个月`、`1-3个月`、`3-6个月`、`6-12个月`、`12个月以上`，序号 11-15 / 10-14 / 10-14）；该分组只承接合并单元格，**不单独占序号、不可单独配置**。基准文档记「12 个数据列 + 1 个分组表头」即按此归位口径。
- **`按客户` / `按区域` 增加信用额度三列**（`信用总额度`、`已用信用额度`、`信用额度使用率`），`按职员` 无——说明信用额度是**客户（及其所属区域汇总）级**属性，不下放到职员级。
- **维度列差异**：`按职员` 首列 `职员名称`（+ 隐藏 `职员编号`/`所属部门`）；`按客户` 首列 `客户名称`（+ `客户编号`）；`按区域` 首列 `区域名称`（+ `区域编号`）。`按客户`/`按区域` 的维度名列**默认可见**，`按职员` 的 `所属部门` 默认隐藏。
- **固定列**：实测表头串**不含** `操作`/`排名`；列表前另有序号列，不进列配置弹窗。
- **隐藏列差异**：`按职员` 隐藏 3 列（职员编号、所属部门、本期新增收款）；`按客户`/`按区域` 隐藏 1 列（本期新增欠款）。复刻时勿套用同一默认集。

## 4. 业务规范

### 统计口径（欠款滚动 + 账龄）

- **欠款余额** = 此前欠款 + 本期新增欠款 − 本期新增收款 − 结算优惠（滚动口径）。**恒等式已用实据验证 ✅**（`本期新增收款` 列虽默认隐藏，但可从同一行数据串还原）：
  - 杨生淮：−246,437.29 + 36,778.12 − 29,355.02 − 61.88 = **−239,076.07** ✅
  - 许军：235 + 35 − 154.93 − 0.07 = **115** ✅
  - 高晓丽：−90,016.04 + 1,188 − 5,792.88 − 2.12 = **−94,623.04** ✅
  - 陈新义：2,663 + 1,903 − 3,076.28 − 3.72 = **1,486** ✅（回款额 3,076.28 由恒等式反推）
- **负值语义**：欠款余额为负 = 该职员/客户名下净预存/超收（预收款大于应收）；正值 = 净欠款。实据多名职员为负（杨生淮 −239,076.07、高晓丽 −94,623.04、方丽萍 −136），刘洋洋为 +170,723.89。
- **负值语义**：欠款余额为负 = 该职员/客户名下净预存/超收（预收款大于应收）；正值 = 净欠款。实据多名职员为负（杨生淮 −239,076.07、高晓丽 −94,623.04、方丽萍 −136），刘洋洋为 +170,723.89。
- **此前欠款**：查询起始日前的累计未结；**本期新增欠款**：查询期内销售产生的未结金额；**本期新增收款**：查询期内实际收款（冲减欠款）；**结算优惠**：本期收款让利冲减欠款。
- **超期欠款总额**：超过信用账期未结的金额；**账龄五档分布**：按超期时长归入 `小于1个月` / `1-3个月` / `3-6个月` / `6-12个月` / `12个月以上`（本次实据全部为 0 = 无超期或该租户未配账期）。
- **日期类型**：实测默认 `单据日期`，决定欠款归属期口径；其它可选值**待复核**。
- **信用额度三项（按客户/按区域）**：`信用总额度`（授信上限）、`已用信用额度`（当前占用）、`信用额度使用率` = 已用 / 总额度（预期口径，具体待复核）。
- **`实销金额` 恒为 0（本次实据）**：按职员 9 条全部为 0，说明本次查询区间内该列取数口径未命中（或需配合其它维度），**待复核**。

### 与其他页面关系

- 取数：销售出库单未结金额（应收）− 收款单已收 + 预收款抵扣；与《销售履约分析》`未结金额`同源（汇总粒度 vs 单据粒度）。
- 下游：《查应收》（单据级应收明细）、《往来余额表》（客户级应收应付净额）、《回款统计》（回款侧口径）。
- 授信一致性：`信用总额度`/`已用信用额度` 应与《客户》主数据会员/授信设置同源。
