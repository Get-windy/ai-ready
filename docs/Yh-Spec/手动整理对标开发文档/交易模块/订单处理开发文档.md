# 订单处理开发文档

> **文档类型：** 页面对标复刻
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）

## 页面概述

订单处理是**商城订单统一处理工作台**：按商城订单来源（微商城/XSDD-）查询、审核、收款、发货、终止的处理中心。**单入口**，含 **2 个视图 Tab**（按单据 / 按明细）。

| 页面 | 地址 | 说明 |
|------|------|------|
| 订单处理 | `mall/order-process` | 复合页（列表 + 2 Tab：按单据 / 按明细） |

单入口：商城 → 订单处理 → 订单处理。

- 实测实据：按单据 Tab 共 11 条记录、合计金额 2,451，含 `XSDD-20260907-014` … `XSDD-20260907-001`。
- 单号前缀：`XSDD-YYYYMMDD-序号`。
- 单据状态下拉（多选）：`审核中,待付款,待发货,发货完成,交易完成,审核驳回`。
- 订单来源：微商城；支付方式：微信支付。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区（「配置」齿轮）；列配置在数据表右上角表头单元格内齿轮图标（`.icon-shezhi2`）。

- ⚠️ **当前实现说明**：本页**尚未升级金标准组件**（当前为 `ARReportPage`，单 Tab、无列/页面配置弹窗），见「实现差异说明 → 待完善」。

## 业务规范说明

- **订单主线**：商城订单（微商城，`XSDD-` 前缀）→ 本页统一处理；状态流转 待付款/待发货/已发货/发货完成/交易完成/审核驳回。
- **行级操作（按单据）**：审核、收款、终止、更多。审核=通过订单；收款=对订单发起收款；终止=强制终止订单。
- **金额口径**：订单金额（商品金额+运费+其他费用−优惠）；已结金额=已收款。
- **配送**：配送方式/物流公司/运单号/运费/运费承担方/代收金额；收货人/联系电话/收货地址/客户备注/卖家备注。
- **订单来源**：微商城；订单来源为「微商城」时展示。
- **下游**：审核后进入发货流程；收款联动收款单；记账状态（未完成/已完成）与审批流联动。

### 页面对齐（已建成：`ARReportPage`）
- **单 Tab 列表**：当前为 `ARReportPage`，**无按单据/按明细双 Tab**。
- **查询区（2 字段）**：关键字（订单号/客户/收货人）、订单状态（待付款/待审核/已审核/已发货/已完成/已取消驳回）。**仅有 2 个查询字段，未对齐金标准 24 字段**。
- **数据表列（9 列）**：订单编号、客户名称、订单总额、已收款、订单状态、支付状态、收货人、下单时间、操作（详情/通过/驳回）。
- **统计卡片**：总订单数、商城GMV、客单价、退款率（`/erp/mall/admin/trade-analysis`）。
- **行级操作**：详情（弹窗）、通过（`PAID` 状态「审核通过」）、驳回（`PAID/PENDING_PAYMENT` 状态「审核驳回」，必填原因）。
- **订单状态映射**：PENDING_PAYMENT待付款/PAID待审核/APPROVED已审核/SHIPPED已发货/COMPLETED已完成/CANCELLED已取消/REJECTED已驳回（`extInfo.originalMallStatus`）。
- **支付状态**：待支付/支付中/已支付/部分支付/已退款。
