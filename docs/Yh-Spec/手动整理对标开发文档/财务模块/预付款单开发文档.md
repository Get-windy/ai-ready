## 页面概述

预付款单用于**先付供应商货款、后抵应付**的预付款登记。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 预付款单表单页 | `finance/advance-payment/form`（主菜单入口） | 新增预付 + 付款账户明细 |
| 预付款单列表页（历史） | `finance/advance-payment/index`（list_path `finance/advance-payment`） | 双入口「历史」标签 |

单号实据：`YFKD-20260723-001`（`YFKD-` 前缀 + `YYYYMMDD-序号`）。

### 配置功能说明
- **页面配置/列配置**：管理页面级字段与数据表列显示/隐藏/排序/宽度/冻结。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

## 新增编辑预付款单表单页配置

### 页面结构（本系统实测，自定义 `a-form`）
表头结算单位字段区 → 付款账户明细表格 → 备注区 → 单据信息（制单人/制单时间/打印次数/源单）→ 底部本单金额与操作。

### 表头字段（对标 15 字段，较预收少"本单赠送金额"）
| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 编号 | a-input | 是 | prePaymentNo，`YFKD-` 前端生成 |
| 结算单位 | a-select | **是** | 联动带出此前预付 |
| 供应商编号 | a-input 只读 | 否 | |
| 经手人 | a-select | 是 | 默认当前登录人 |
| 部门 | a-select | 否 | |
| 单据日期 | a-date-picker | 是 | 默认当天 |
| 此前预付 | a-input 只读 | 否 | 选定结算单位后带出当前预付余额 |
| 摘要 | a-input | 否 | |
| 单据备注 | a-input | 否 | |
| 源单 | a-input 只读 | 否 | 源单未结金额 |

### 付款账户明细表格（对标 5 列）
操作、付款账户编号、付款账户、付款金额、备注。

|------|------|------|
| 任意 | 保存草稿 Ctrl+S | `save` |
| 任意 | 记账 Ctrl+Enter | `confirm` |

## 业务规范说明

- **预付"付→抵→退"主线之"付"**：本页为预付余额标准入口；《付款单》「使用预付款」为"抵"；采购退货退款退回预付为"退"（与预收"收→抵→退"对称）。
- **记账生效**：记账后结算单位"预付余额"增加（此前预付为记账前余额快照）。
- **一单多账户**：明细可填多行不同付款账户，本单金额=Σ付款金额。
- **账户主数据**：付款账户来自资料 → 财务账户 → 银行账户。
- **对比预收款单**：无"本单赠送金额"字段（供应商侧无赠送场景）。
- **记账生成凭证**：会计凭证（KJPZ-），总账科目 1123 预付账款。
