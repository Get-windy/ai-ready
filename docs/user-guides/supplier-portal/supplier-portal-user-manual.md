# 供应商门户用户操作手册

## 文档概述

### 手册简介
欢迎使用供应商门户系统！本操作手册旨在为供应商企业的各类用户提供全面的系统操作指导，帮助您快速掌握系统功能，高效开展业务合作。

### 适用对象
- **供应商管理员**: 负责企业账户管理、用户权限分配
- **采购员**: 负责日常采购业务操作，包括询价、报价、订单处理
- **财务人员**: 负责财务结算、对账、发票管理等财务操作
- **新用户**: 需要了解系统基本功能和操作流程的用户

### 系统概览
供应商门户是一个集成的B2B协作平台，主要功能包括：
- 企业信息管理
- 询价报价管理
- 订单协同处理
- 交付跟踪管理
- 结算对账服务
- 沟通协作工具

- **手册版本**: v1.0
- **适用系统**: 供应商门户 v2.0+
- **更新日期**: 2026-05-01
- **文档维护**: 供应商门户产品团队

## 第二部分：用户角色与权限

### 2.1 角色概述
系统预设三种主要角色，每种角色对应不同的功能权限：

#### 2.1.1 供应商管理员
- **核心职责**: 企业账户管理和权限分配
- **关键权限**: 用户管理、企业信息维护、安全设置
- **适用对象**: IT负责人、企业管理员

#### 2.1.2 采购员
- **核心职责**: 日常采购业务操作
- **关键权限**: 询价处理、订单管理、交付跟踪
- **适用对象**: 业务员、销售代表、客户经理

#### 2.1.3 财务人员
- **核心职责**: 财务结算和相关操作
- **关键权限**: 结算管理、发票处理、对账核对
- **适用对象**: 财务专员、会计、出纳

### 2.2 权限矩阵
详细权限对照表请参考: [供应商角色与权限说明](./supplier-roles-and-permissions.md)

### 2.3 权限管理
**管理员操作**:
1. 创建新用户并分配角色
2. 调整现有用户权限
3. 审核权限申请
4. 定期权限审计

**用户操作**:
1. 查看自身权限范围
2. 申请额外权限（如需）
3. 报告权限相关问题

## 第三部分：核心功能操作指南

### 3.1 注册与认证
**完整流程**:
1. 访问门户网站并点击注册
2. 填写企业基本信息
3. 设置管理员账户
4. 邮箱验证
5. 提交企业资质材料
6. 等待平台审核
7. 账户激活和初始设置

**详细步骤**: 参考[注册与认证操作指南](./registration-authentication-guide.md)

### 3.2 询价报价管理
**业务流程**:
```
接收询价 → 查看详情 → 准备报价 → 提交报价 → 跟踪状态 → 结果处理
```

**关键操作**:
1. 及时查看新询价通知
2. 仔细分析询价要求
3. 准备完整的报价方案
4. 在规定时间内提交报价
5. 跟踪报价状态和结果

**详细指南**: 参考[询价报价操作指南](./quotation-management-guide.md)

### 3.3 订单协同处理
**协同流程**:
```
订单接收 → 内部评审 → 订单确认 → 执行跟踪 → 变更处理 → 完成确认
```

**协同要点**:
1. 及时确认或拒绝订单
2. 定期更新生产进度
3. 主动沟通异常情况
4. 规范处理变更申请
5. 完整记录执行过程

**详细指南**: 参考[订单协同操作指南](./order-collaboration-guide.md)

### 3.4 交付跟踪管理
**跟踪流程**:
```
发货准备 → 发货通知 → 物流跟踪 → 送达确认 → 异常处理
```

**管理要求**:
1. 确保发货前检查完整
2. 及时提交发货通知
3. 定期更新物流状态
4. 跟踪送达确认情况
5. 规范处理交付异常

**详细指南**: 参考[交付跟踪操作指南](./delivery-tracking-guide.md)

### 3.5 结算对账管理
**结算流程**:
```
账单生成 → 账单确认 → 发票提交 → 付款处理 → 对账核对
```

**注意事项**:
1. 及时确认结算账单
2. 规范开具和提交发票
3. 跟踪付款进度
4. 定期进行财务对账
5. 处理结算差异问题

## 第六部分：故障排除与帮助

### 6.1 常见问题解决

#### 6.1.1 登录问题
**问题**: 无法登录系统
**解决方法**:
1. 检查用户名和密码是否正确
2. 确认账户是否已激活
3. 检查网络连接是否正常
4. 清除浏览器缓存后重试
5. 联系管理员或技术支持

#### 6.1.2 功能异常
**问题**: 某个功能无法正常使用
**解决方法**:
1. 刷新页面重新尝试
2. 检查浏览器版本是否符合要求
3. 确认用户权限是否足够
4. 查看系统公告是否有维护通知
5. 联系技术支持

#### 6.1.3 数据异常
**问题**: 数据显示不正确
**解决方法**:
1. 确认数据查询条件是否正确
2. 检查数据更新时间
3. 联系相关业务人员核实
4. 报告技术支持排查系统问题

3. **规范格式**: 按系统要求格式填写
4. **及时更新**: 变更信息及时维护

#### 7.1.3 沟通协作
**协作规范**:
1. **主动沟通**: 发现问题主动联系
2. **明确表达**: 沟通内容清晰明确
3. **书面记录**: 重要沟通书面确认
4. **及时反馈**: 按要求及时反馈进展

#### 7.2.3 批量操作

1. 批量下载文件
2. 批量更新状态
3. 批量发送通知
4. 批量导出数据

### 7.3 安全建议

#### 7.3.1 账户安全
**安全措施**:
1. **密码管理**
   - 使用复杂密码
   - 定期更换密码
   - 不与其他系统共用密码
   - 使用密码管理工具

2. **登录安全**
   - 启用双因素认证
   - 不在公共电脑保存密码
   - 及时退出不使用的会话
   - 监控异常登录尝试

#### 7.3.2 数据安全
**保护措施**:
1. **敏感数据**
   - 不通过非加密渠道传输敏感数据
   - 严格控制数据访问权限
   - 及时删除过期数据
   - 遵守数据保护法规

2. **操作安全**
   - 重要操作前确认权限
   - 操作后检查结果
   - 保留操作日志
   - 定期审计操作记录
