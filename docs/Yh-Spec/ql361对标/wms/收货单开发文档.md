# 收货单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`wms/receive/form`（表单）+ `wh/receiving-order/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=历史）：主按钮 → 新增/编辑表单页 `wms/receive/form`；标签"历史"→ 列表页 `wh/receiving-order/index`。
- **表单页**：WMS 收货执行——PDA/PC 收货登记，入库上架前环节（我方实现，views/wh/receiving-order/form/index.vue）。
- **列表页**：收货单台账（我方实现，views/wh/receiving-order/index.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `wh/receiving-order/index.vue`（4 项）

- `keyword` 单号/来源单号（输入）
- `sourceType` 来源类型（下拉：采购入库/生产入库/退货入库/调拨入库/其他）
- `status` 状态（下拉：WMS_STATUS_MAP 全部状态）
- `warehouseId` 仓库ID（输入）

### 功能按钮

来源：我方源码 `wh/receiving-order/index.vue`

- 工具栏：新增收货单（跳转 `wms/receive/form`）
- 行操作：查看、编辑（仅状态=待处理）、删除（仅状态=待处理，popconfirm 确认）

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段

来源：我方源码 `wh/receiving-order/form/index.vue`

- 必填：收货仓库\*（a-form-item required）、单号\*（保存时校验非空）
- 选填：来源类型、来源单号、供应商、预计时间、优先级、备注

### 字段分组／录单默认值／打印设置

- 字段分组：单据头 → 收货明细 → 最近收货单
- 明细表格列（编辑态 8 列）：行号、商品、规格、单位、应收数量、货位、批次号、操作
- 明细表格列（只读态 11 列）：行号、商品编码、商品名称、规格、单位、应收数量、已收数量、已上架、货位、批次号、状态
- 最近收货单列表列（9 列）：单号、来源类型、来源单号、仓库、供应商、进度(收/总)、状态、创建时间、操作
- 录单默认值：单号自动生成（RC 前缀 `genTaskNo('RC')`）、来源类型默认"采购入库"(0)、优先级默认"普通"(0)
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（13 列，来源：我方源码 `wh/receiving-order/index.vue`）

单号、仓库、来源类型、来源单号、供应商、总数量、已收货、进度、状态、优先级、备注、创建时间、操作

### 全部可配置列（13 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `columns` 数组（13 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`wms/receive/form`，标签按钮 list_path=`wh/receiving-order/index`，tag_label=历史（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- WMS 收货执行：PDA/PC 收货登记，入库上架前环节；收货完成后进入上架环节（见《上架单开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
