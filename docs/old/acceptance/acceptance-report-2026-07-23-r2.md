### 🔴 灾难级红线：V11.31.0 迁移致全站无法启动

- **事实**：`V11.31.0__Create_Cost_Sharing_Tables.sql` 通篇 MySQL 语法（行内 COMMENT/DATETIME），Flyway 报 `语法错误 在 "COMMENT" 或附近的` → 启动中断
- **违反纪律（两条）**：① SQL 规则 5——"脚本写完立即 psql 手动执行"，执行过一次就不可能带语法错误；② 可落地性标准——交付前必须启动验证，团队连应用都未起过一次
- **附带发现**：支付方式列约定修复（应为 V11.31.0 的内容之一）被费用分摊占号且整体失败，导致问题 2 也未修
- **返工要求**：改写为 PG 语法（COMMENT ON COLUMN 语句、TIMESTAMP），**psql 手动执行验证** + Flyway 登记，启动通过后 curl 复测全部新端点
