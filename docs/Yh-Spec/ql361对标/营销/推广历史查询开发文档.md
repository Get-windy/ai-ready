## 业务规范说明

### 推广转化漏斗（列实据归纳）

- **一行 = 一次分享动作**（分享时间 + 分享人 + 分享类型 + 分享概要）；分享类型对应《我要推广开发文档》5 类可推广对象（商品/优惠券/促销/拼团/秒杀，推断待复核）
- **效果漏斗四段**（列实据，列头带口径注释）：
  1. 触达：浏览次数 / 浏览人数（推广链接被打开的量与人）
  2. 领取：分享领取数（经分享领取的券/福利数）
  3. 转化：下单人数 / 下单笔数（经推广下单的买家数与订单数）
  4. 金额：下单金额（推广带来的成交额）
- 合计行对 6 个效果列全量汇总（实据），支撑推广业绩按人/按对象考核
- 分享日期必填（* 实据）——效果数据量大，强制限定时间窗
- 与订单的衔接：订单处理中心默认列"推广人"（销售域实据）记录单笔订单的推广归属，本页为其汇总查询端

### 与其他页面关系

- 数据上游：《我要推广开发文档》产生的分享动作及其浏览/领取/下单回流数据
- 分析域：营销分析 → 营销推广分析（菜单树实据）为图形化分析端，本页为明细台账端
- 本系统落地：对应推广历史查询 `/api/crm/marketing` 效果报表（api/marketing.ts 实据）
