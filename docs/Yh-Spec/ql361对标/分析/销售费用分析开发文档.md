## 业务规范说明

### 统计口径（六类费用 + 费销比）

- **费用总额**=赠品+促销活动+优惠+商品兑付+金额兑付+其它费用（合计行 35.7+0+215.3+0+0+0=251 ✅）
- **费销比(%)**=费用总额/销售收入×100（肃州区春旺优品百货商行：1.42/483≈0.29 ✅；敦煌市一杆旗餐馆：0.34/0（销售收入为 0）→ 显示 100，零收入有费用时的兜底口径待复核；销售收入为负（退货净额）时费销比为负）
- **六类费用分项**：赠品（随单赠货成本）、促销活动（活动分摊费用）、优惠（整单/单品优惠让利）、商品兑付（以货抵付）、金额兑付（以款抵付）、其它费用
- **销售收入**：与《销售分析》销售收入口径一致（净销售=销售额−退货额；本周合计 93,973.99 与《销售业绩》实销金额一致 ✅）

### 与其他页面关系

- 取数：销售出库单优惠/赠品明细 + 促销活动费用分摊 + 兑付记录 + 随单费用
- 同源页：《销售分析》（其他费用支出/结算优惠列）、《查费用》（费用单单据级口径）、《营销活动分析》（活动侧投入产出）
