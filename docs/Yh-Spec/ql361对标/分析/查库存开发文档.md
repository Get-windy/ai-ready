## 业务规范说明

### 统计口径（商品×仓库粒度）

- **双数量口径**：账面库存（数量 + 小单位数量）= 全部出入库流水净额；可用库存（换算结果 + 小单位数量）= 账面 − 占用（待发货锁定/拣货中）
- **在途三口径**（右滚区列实据）：已发待记账数量（已发货未记账）、已收待记账数量（已收货未记账）、未发数量（已下单未发货）——台账与在途分列，支撑账实核对
- **多单位换算**（行实据）：换算结果按商品换算关系把数量折算为多单位表达（1箱4瓶）；小单位数量为折到最小单位的数量（16瓶）；单位列为商品基本单位（瓶/袋）
- **成本口径**：成本单价（实据 16.2719，四位小数）；成本金额 = 成本单价 × 账面数量（右滚区，成本核算口径与《进销存分析》联动）
- **色标**：零库存商品名称红色显示（截图实据），缺货一眼可辨
- **三视图分工**：当前库存（商品×仓库台账，本视图）/ 按属性（按商品属性展开的库存视图，列结构待复核）/ 库存分布（商品×仓库二维分布，多仓调配决策用，列结构待复核）
- **行级联查四件套**：分布→库存分布视图；明细→《库存明细》流水；对账→库存对账；批次号→《查批次》批次台账
- **批量上架/下架**：库存商品与 B2B 商城商品上架状态联动——有库存才可上架销售

### 与其他页面关系

- 取数：库存流水（《库存明细》逐笔）+ 商品主数据
- 同组页面：《查批次》（批次粒度）、《进销存分析》（期间变动口径）、《库存明细》（流水粒度）
- 下游：《采购准备》（缺货=账面不足触发补货）；商城商品管理（上架状态）
