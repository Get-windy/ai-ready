# 明细账开发文档

> **文档类型：** 页面对标复刻（已完成代码）
> **对标系统：** ql361（来肯企汇，`22stable.ql361.com`）
> **定位：** 按金标准结构编写；按凭证逐笔的科目明细账簿。

## 页面概述

明细账是**按凭证逐笔的科目明细账簿**（凭证→分录→借贷金额逐笔列示）。**复合页**（查询 + 表格），单入口。

| 页面 | 地址 | 说明 |
|------|------|------|
| 明细账 | `finance/detail-ledger` | 查询 + 明细分录表格 |

菜单：财务 → 账簿 → 明细账。

### 配置功能说明
- **查询参数**：会计年度/期间、科目代码。
- ⚠️ **当前实现说明**：本页尚未升级金标准组件，见「实现差异说明 → 待完善」。

| path | `finance/detail-ledger` |
| 组件 | `views/finance/detail-ledger/index.vue` |

### 查询条件（本系统实测）

## 业务规范说明

- **账簿口径**：按凭证/分录逐笔列示，反映科目明细流水。
- **余额**：逐笔累计余额（期初+借−贷）。
- **来源**：会计凭证（KJPZ-）分录入明细账；摘要实据"由[收款单 SKD-…]"（业务单据自动生成凭证）。
- **核算项**：科目挂核算项（往来单位/部门/职员）时核算项列示。
