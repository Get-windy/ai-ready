### 口径说明（多级表头归位）

- **分组名不是数据列**：`columnConfig` 共 27（按时间）/ 34（按职员）个**叶子列**；`snapshot.headers` 中另有 6 个**分组表头**——`拜访统计`、`订货统计`、`销售统计`、`退货统计`、`回款数据`、`利润统计`，它们只承接其下叶子列的合并单元格，**不单独占序号、不可单独配置**。基准文档记「17 项 = 11 叶子 + 5 分组」即未含第 6 组与独立列，本次订正为 27/34 叶子 + 6 分组。
- 分组归位：
  - `按时间`：拜访统计（拜访客户数、拜访完成率（%））；订货统计（订货客户数、订货金额、实订金额）；销售统计（销售客户数、实销金额、其他费用、销售业绩目标、销售业绩完成率（%））；退货统计（退订金额、退订率(%)、退货金额、退货率(%)）；回款数据（回款客户数、回款总额、按期回款总额、超期回款总额、回款业绩目标、回款业绩完成率（%））；利润统计（销售收入、销售成本、销售毛利、毛利率（%））；**独立叶子**为 日期(1)、拓客数(2)、本期未结金额(27)。

## 4. 业务规范

### 统计口径（漏斗全链路）

- **漏斗链路**：拓客数（新增客户）→ 拜访统计（拜访客户数、拜访完成率 = 实际拜访 / 计划拜访）→ 订货统计（订货客户数、订货金额、实订金额）→ 销售统计（销售客户数、实销金额、其他费用、销售业绩目标/完成率）→ 退货统计（退订金额/退订率、退货金额/退货率）→ 回款数据（回款客户数、回款总额、按期/超期回款、回款业绩目标/完成率）→ 利润统计（销售收入、销售成本、销售毛利、毛利率）→ 本期未结金额。
- **实订 vs 实销**：`实订金额` 取自销售订单（XSDD-），`实销金额` 取自销售出库单（XSCKD-）；`订货金额` 为订货毛额、`实订金额` 为扣退订后的净订货额；`销售金额`（按职员）为销售毛额、`实销金额` 为净销售额。
- **退货率(%)** = 退货金额 / 实销金额 × 100；**退订率(%)** = 退订金额 / 订货金额 × 100。
- **完成率类**：`销售业绩完成率（%）` = 实销金额 / 销售业绩目标 × 100；`回款业绩完成率（%）` = 回款总额 / 回款业绩目标 × 100；`拜访完成率（%）` = 拜访客户数 / 计划拜访数 × 100。
- **利润统计**：`销售毛利` = 销售收入 − 销售成本；`毛利率（%）` = 销售毛利 / 销售收入 × 100。
- **回款拆分**：`按期回款总额` / `超期回款总额` 按信用账期是否超期拆分，两者之和构成 `回款总额` 的账期口径视图。
- **本期未结金额**：查询期内已发货未收款金额（与《销售履约分析》未结金额同源）。
- **指标卡片**（基准文档，待复核）：九卡三色——订货客户数/实订金额/实销金额/回款总额（红）、退货金额/退货率（橙）、拓客数/拜访客户数/拜访完成率（青）。2026-09-15 实测截图为**表格视图**，指标卡形态未取到。

### 与其他页面关系

- 取数：销售订单 / 销售出库单 / 销售退货单 / 收款单（经营历程流水）+ 客户主数据（拓客）+ 外勤拜访记录（拜访统计）+ 业绩目标配置。
- 下游：《业绩提成中心》《业务员提成》（业绩 → 提成取数基础）、《经营分析》（利润口径扩展）、《销售分析》（量本利明细口径）。
- 维度一致性：`按职员` 的职员集合来自部门主数据，左侧部门分类树即按 `所属部门` 过滤。
