## 页面概述

线路用于维护**配送线路主数据**（线路编号/名称/类型/物流公司/配送区域）。**当前本系统页面为占位桩页**：前端直连 `/md/route/page`，后端无对应 Controller（404）。现有真实相关后端 `RouteController`（`/api/delivery/route`，表 `erp_delivery_route` + `erp_route_point`）为**配送路线单（执行单据）**，非本主数据。单入口，列表 + 新增弹窗。

| 页面 | 地址 | 说明 |
|------|------|------|
| 线路 | `md/route` | 线路列表 + 新增「配送路线」弹窗（⚠️ 桩页，未接入） |

菜单：资料 → 配送管理 → 线路。

> ⚠️ 区分：本页为「线路**主数据**」（`md:route`），并非《配送路线单》（`/api/delivery/route`，配送执行单）。

### 配置功能说明

- **列配置弹窗**：可开列配置（个人配置/全局配置 Tab），全部可配置 6 列，全部默认显示。
- ⚠️ **无页面配置弹窗**：本页无「配置」齿轮 —— 查询条件与功能按钮为**固定项**（见下表）。
- ⚠️ **当前实现说明**：本页为 `PageContainer` + 搜索区 + `apiUrl='/md/route/page'` 传给 `BillTableList` 的只读桩页，后端无 `/md/route` Controller → 404。

## 新增线路表单（对标系统实测 · 弹窗标题「配送路线」）

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 线路类型 | 复选框（自配 / 物流） | **是** | usetype_zp（自配）/ usetype_wl（物流） |
| 线路编号 | 输入框 | **是** | code |
| 线路名称 | 输入框 | **是** | fullname |
| 物流公司 | 输入框 | 否 | expressname（线路类型=物流 时显示） |
| 配送区域 | 子表 | 否 | 配送区域类型 gptype（单选）+ 配送区域编码 gpcode；子表 新增/删除 |
| 备注 | 输入框 | 否 | remark |

按钮：**保存(Enter)**、**关闭(Esc)**。

> ⚠️ **对标/本系统差异**：对标实测线路主数据含 **线路类型（自配/物流）+ 物流公司 + 配送区域子表**；本系统初稿（桩页）此前只写了 线路编码/名称/起点/终点/里程/状态，与对标页不同（对标页**无 起点/终点/里程**，配送区域以子表维护）。

## 业务规范说明

- **⭐ 占位缺口**：`/md/route/page` 后端未实现；**需新建「线路主数据」**（线路类型/编号/名称/物流公司/配送区域 + 启用状态）。
