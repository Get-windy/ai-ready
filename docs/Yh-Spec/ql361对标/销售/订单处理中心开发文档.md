## 1. 页面概述

- **复合管理页**：销售订单统一处理工作台——3 个工作流阶段（全部/待审核/拣货发货）× 5 种维度视图（按单据/按时间/按线路/按客户/订单履约）+ 统计卡片 + 查询区 + 数据表格。
- 即 XSMK《销售订单开发文档》的"销售订单列表页"。

## 4. 业务规范

- 状态流转：提交（待审核）→ 审核 → 待出库 → 待发货 → 已出库 → 发货完成 → 交易完成；统计卡片六档（订单总数/待出库/待发货/已出库/发货完成/交易完成）与之一一对应；单据状态下拉多选含"审核中,待付款,待发货"等值。
- 特殊交互：统计卡片可点击，点击卡片即按对应状态过滤表格（推断，待复核）；"按明细显示"勾选后表格从一行一单切换为一行一明细；"不显示有关联审核中退货申请单的单据"过滤存在审核中退货申请的原单，避免重复处理；行级收款/取消/修改（待审核阶段可修改/取消，收款直接对订单收款）；商品汇总把选中订单按商品汇总数量（配货用）；批量打印选中订单；补单类型/订单履约跟踪已发货不足订单的补单。
- 与其他页面：新增按钮 → 销售订单表单页（`sales/order/form`）；拣货/发货阶段生成销售出库单；退货关联销售退货申请（查询勾选项实据）；本页即 XSMK《销售订单开发文档》的"销售订单列表页"。
