# 盘点单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stocktake`（表单）+ `erp/stocktake/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：库存盘点录单（页面标题「库存盘点单」），编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品快速录入行 + 盘点明细表格 + 定位/盈亏筛选工具行 + 备注区 + 单据信息行 + 底部盈亏金额与操作按钮。
- **列表页**：双入口「历史」标签（查询条件与表格列待抓取弹窗数据后补全）。
- **双入口**：主菜单 → `erp/stocktake`；标签「历史」→ `erp/stocktake/index`。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

- 必填：盘点仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 快速录入：商品（条码/名称/编码 输入框）、X 数量（默认 1）
- 摘要区：盈亏金额（自动计算）

### 表格工具行（JSON filters + 截图实据）

- 快速定位：输入商品名称、条码、货号快速定位（表格内行定位）
- 盈亏状态（全部）下拉：按盘盈/盘亏/无差异过滤明细行（枚举值待复核）
- 刷新库存：重新取数当前账面库存

### 字段分组

顶部基本信息（盘点仓库/经手人/单据日期）→ 商品快速录入行 → 盘点明细表格（含工具行）→ 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 盈亏金额。

### 功能按钮（抓取 JSON buttons 实据）

快速盘点、打印(F8)、历史、更多、快速定位、刷新库存、保存 Ctrl+S；底部「盘点处理 Ctrl+Enter」（JSON _desktop.tabBar 实据，截图确认）

### 打印配置

无（抓取未覆盖打印配置弹窗；表单页有打印(F8)按钮及打印次数/打印记录字段，打印模板细节待复核）。

## 5. 业务规范

- 保存（Ctrl+S，注意非「保存草稿」）→ 盘点处理（Ctrl+Enter）：保存后盘点单可继续盘点，盘点处理后按盈亏生成后续单据（推断生成报损单/报溢单，待复核）。
- 库存数量=账面库存，盘点数量=实盘数，盈亏数量=盘点数量−库存数量 自动计算；盈亏金额汇总于右下角。
- 快速盘点：右上角独立按钮，推断为批量导入/扫码连续盘点模式（弹窗内容待复核）。
- 商品快速录入行：扫码或输入条码/名称/编码 + 数量直接追加盘点行。
- 快速定位/盈亏状态/刷新库存为表格辅助工具，不参与单据字段。
- 盘点处理产出报损单（盘亏）/报溢单（盘盈）（推断，待复核）；处理后影响 分析→仓配分析→查库存/库存明细。
