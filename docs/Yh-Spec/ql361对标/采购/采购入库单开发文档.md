# 采购入库单开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`purchase/inbound/form`（表单）+ `purchase/inbound/index`（列表）
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：采购入库录单，编辑模式为新增模式加 id。页面性质 = 表头字段区 + 商品明细表格 + 底部付款区 + 备注区 + 单据信息行 + 摘要面板。
- **列表页**：按单据 / 按明细 2 个 Tab。
- **双入口**：主菜单 → `purchase/inbound/form`；标签「历史」→ `purchase/inbound/index`。

## 2. 表单页配置

### 表头字段（实据 2026-07-23 抓取）

- 必填：供应商\*、仓库\*、经手人\*、单据日期\*
- 底部付款区：付款账户、其他费用

### 全部表单字段（37 个，cfg 实据 37 字段 ✅）

编号、供应商、供应商编号、开户行、银行账号、税号、仓库、经手人、部门、单据日期、联系人、联系电话、联系地址、自定义字段1(数字)~2(数字)、自定义字段3(文本)~5(文本)、审核人、摘要、付款账户、付款金额、更多账户、此前预付、使用预付款、预付余额、本次欠款、此前欠款、欠款余额、付款期限、其他费用、源单、单据备注、制单人、制单时间、打印次数、优惠金额

### 字段分组

顶部基本信息 → 付款区 → 备注区 → 单据信息 → 摘要面板。

### 录单默认值

- 默认仓库：录单时自动带出（对标系统经手人默认当前登录人，仓库可选）
- 默认经手人：当前登录人（对标系统实据：表单打开经手人=杨生淮）
- 默认付款方式：按供应商结算方式带出（付现/赊销）
- 默认税率：13%（可按商品/供应商调整）

### 打印设置

打印模板：标准模板 / 简化模板 / 详细模板；打印份数默认 1 份；纸张大小 A4 / A5 / B5（默认 A5）。

### 功能按钮（抓取 JSON buttons 实据）

打印(F8)、历史、导入、更多、保存草稿 Ctrl+S、记账 Ctrl+Enter

### 打印配置

无（抓取未覆盖打印配置弹窗；打印模板细节待复核）。

## 5. 业务规范

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后单据生效增加库存；付款区（付款账户/付款金额/更多账户/此前预付/使用预付款/此前欠款/其他费用/源单）联动供应商往来。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 批次管理列齐备（批次条码/生产日期/保质期/到期日期），入库可登记批次与效期。
- 上游：采购订单（收货带单）；下游：库存增加、供应商应付（财务）、采购价格跟踪价格写入、采购费用分摊（成本计入，待复核）。
- 关联查询：采购单据查询/采购明细查询（本单纳入统一检索）。
