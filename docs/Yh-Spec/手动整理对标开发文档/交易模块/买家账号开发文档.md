## 页面概述

买家账号是**商城买家/客户账号统一管理**页：按买家归属分类查询商城注册的买家账号，查看其注册/交易/登录信息、默认经手人、客户级别、所属仓库/部门、状态，并支持删除/编辑/解锁。**单入口，无独立表单，无子 Tab**。

| 页面 | 地址 | 说明 |
|------|------|------|
| 买家账号 | `mall/buyer-account` | 单视图列表页（分类树 + 买家列表） |

单入口：商城 → 基础业务 → 买家账号。

- 实测实据：左侧分类树「买家归属分类」含 全部客户/系统用户/餐饮客户/合作商/个人会员/其他渠道/单位客户/餐饮连锁/在线注册客户/观望筹备客户。
- 买家行含「登录名」（即买家手机号，如 13014104938）、客户级别（A餐饮客户 / 校园餐饮 / 自助餐 / A敦|瓜|玉餐饮客户）、默认经手人（杨生淮/高晓丽）、所属仓库（配送中心）、所属部门（管理部）、状态（正常）。

### 配置功能说明
- **列表结构**：买家账号页为**分类树 + 数据表**的列表页，**无**标准「页面配置」（查询条件/功能按钮 Tab 的配置齿轮）。
- **数据表列配置**：数据表右上角表头齿轮图标（`.icon-shezhi2`），弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**共 9 个可配置列，全部默认显示**。
- ⚠️ **当前实现说明**：本页**尚未升级金标准组件**（当前为 `ARReportPage`，单表、无分类树、无列/页面配置弹窗、无删除/编辑/解锁），见「实现差异说明 → 待完善」。

## 业务规范说明

- **买家主线**：商城注册买家（客户）账号 → 本页统一管理；买家归属分类（全部客户/系统用户/餐饮客户/合作商/个人会员/其他渠道/单位客户/餐饮连锁/在线注册客户/观望筹备客户）决定其归类。
- **登录名**：买家登录名即手机号（登录商城用）；客户级别（A餐饮客户、校园餐饮、自助餐等）为商城客户分层。
- **登记维度**：注册时间 = 买家账号注册时间；最近交易时间 / 最后登录时间 = 商城最近交易/登录记录。
- **分配维度**：默认经手人、所属仓库、所属部门 = 该买家账号归属的销售/仓储组织。
- **状态**：正常；行级可删除 / 编辑 / 解锁（解锁用于停用/锁定后恢复）。「注册验证码查询」按钮用于找回注册验证码。
- **与 ERP 往来单位关系**：商城买家账号为商城侧客户；买家申请管理产生「绑定客户」，买家账号可关联 ERP 往来单位（本页未直接展示绑定往来单位列）。

## 实现差异说明

**实现文件**：
- 前端：`apps/pc-admin/src/views/mall/buyer-account/index.vue`
- API：`apps/pc-admin/src/api/erp/mall.ts`（`shopUserApi`：`/erp/mall/shop-user/page`、`/{id}/status`）

### 页面对齐（已建成：`ARReportPage`）
- **单表列表**：当前为 `ARReportPage`，**无分类树、无删除/编辑/解锁行级操作**。
- **查询区（3 字段）**：关键字（用户名/昵称/手机号/公司）、审核状态（待审核/已通过/已驳回）、账号状态（正常/已禁用）。**未对齐金标准固定查询项**。
- **数据表列（11 列）**：用户名、昵称、公司、手机号、身份（企业客户/个人会员）、来源、审核状态、最后登录、账号状态、注册时间、操作。
- **行级操作**：禁用/启用（`status` 切换，popconfirm）。
- **状态**：账号状态 正常/已禁用/待审核/已通过/已驳回（`shop_user` 表）。
