> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`erp/stock-transfer`
> 通用规范见《对标开发技术参考文档》第 4、5 章

## 1. 页面概述

- **表单页**：仓库间库存调拨录单（出库仓库→入库仓库），编辑模式为新增模式加 id。页面性质 = 表头字段区（含调拨方式）+ 商品明细表格 + 备注区 + 单据信息行 + 底部本单金额与操作按钮。
- **单入口**：仅表单页。

## 2. 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图 + bodyPreview 确认）

- 必填：出库仓库\*、入库仓库\*、经手人\*（默认当前登录人）、单据日期\*（截图确认必填）
- 选填：调拨方式（下拉，默认「同价调拨」）
- 摘要区：本单金额（自动计算）

### 字段分组

顶部基本信息（出库仓库/入库仓库/经手人/单据日期/调拨方式）→ 商品明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 本单金额。

## 4. 业务规范

- 保存草稿（Ctrl+S）→ 记帐（Ctrl+Enter）：草稿进入「业务草稿」（分析-综合单据），记帐后生效：出库仓库减库存、入库仓库加库存。
- 调拨方式默认「同价调拨」：调拨单价=成本单价，调拨差额为 0；异价调拨时产生调拨差额（列结构含成本单价/成本金额/调拨单价/调拨金额/调拨差额五列佐证，异价调拨的差额去向（损益科目）待复核）。
- 与其他出入库单明细差异：有「规格」列、无「货位」列；无单价/金额而代之以成本与调拨价系列列。
- 扫描枪录入开关：开启后商品名称列直接接收扫码枪输入。
- 双仓库联动：一出库仓库一入库仓库，记账后两仓库存同步变动，可在 分析→仓配分析→查库存/库存明细 检索。
- 草稿在 分析→综合单据→业务草稿 中检索（销售域已确认该入口，仓储单据同体系，待复核）。
