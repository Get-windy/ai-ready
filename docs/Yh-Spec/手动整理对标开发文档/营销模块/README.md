# 营销模块 · 对标开发文档集

> **对标系统**：来肯企汇 ql361 v2.2（`22stable.ql361.com`，桌面式多标签，页面无独立路由）。营销模块 = ql361 顶部「**营销**」域（4 分组 17 页，**1:1 对应**）。
> **数据来源**：Playwright 实测抓取（首抓 2026-07-23；**全量复核 2026-09-15**，账号 15095664266）——列配置弹窗（表头 `.icon-shezhi2`，「个人配置 / 全局配置」两 Tab）、页面结构（查询区/工具栏/表头/分类树）、逐 Tab 抓取、截图。
> **抓取方法**：见《ql361对标/README.md》§2.5 与《抓取结果/抓取方法指南.md》；本模块 2026-09-15 复核脚本 = **`tools/ql361-domain-crawl.cjs`**（通用域抓取器，自动发现菜单结构 + 逐页逐 Tab）。
> **通用规范**：见《ql361对标/对标开发技术参考文档》第 4、5 章；施工手册见《交易模块/_开发指南-金标准.md》（三条路线 A/A′/B、模板、陷阱、自检清单）。
> **术语**：会员 = 客户扩展档案（积分卡）；促销 = 商品行级/整单级优惠活动的统称；推广 = 商城分享裂变。

## 1. 模块定位与边界

| 分组 | 对标实测 | 本系统菜单（sys_menu，顶级 `60008 营销` / `mega:marketing`） |
|------|---------|--------------------------------------------------------|
| **会员中心** | 会员管理 / 积分兑换 / 会员设置（3 页） | 同（3 项） |
| **营销活动** | 发短信 / 优惠券 / 商品促销 / 整单促销 / 特价 / 套餐（6 页） | 同（6 项） |
| **商城营销** | 商城拼团 / 商城秒杀 / 商城预售 / 商城弹窗广告 / 加价购 / 热门搜索词推荐（6 页） | 同（6 项） |
| **营销推广** | 我要推广 / 推广历史查询（2 页） | 同（2 项） |

> **边界铁律（2026-09-18 修订）**：ql361「营销」域**只有上述 17 页**（2026-09-15 实测菜单弹层逐项读取：`会员中心(3) 营销活动(6) 商城营销(6) 营销推广(2)`）。本模块 = **17 页对标复刻（↔ 17 篇对标文档，一一对应）+ 2 页本系统建模**，明细见 §1.3。
> ⚠️ **修订原因**：2026-09-18 业界对标调研（SAP Commerce / Odoo 18 / 用友畅捷通 / 金蝶云星辰 / 有赞 / 微盟）确认有两项缺口在结构上**无法补进现有 17 页**（营销自动化＝多规则×多触发点×执行台账；储值卡＝独立账户+单据+流水台账），故单开页并**如实标注「本系统建模」**。
> ⚠️ **新增页边界**：ql361 无对应页 ⇒ **不得**给它们编造"对标实测列/按钮"；其页面文档必须写清「对标口径：ql361 无对应页」，且列/字段须标注来源（业界建模 or 本系统既有模型）。

## 3. 域级说明

- **会员口径**：会员 = **客户扩展档案**（积分卡），挂在 ERP 往来单位上；`会员设置` 页首行开关「客户 | 会员管理」控制启用。会员积分账户与销售订单表单页底部「会员信息」Tab（此前积分/销售积分/退货积分/兑换积分/使用积分/当前积分）**同源读写**。
- **促销口径**：`商品促销`（商品行级赠品/折扣）、`整单促销`（整单满减门槛）、`特价`（商品×客户范围特价）、`套餐`（多商品组合装）四者互补；`优惠券` 是**券**形态，与促销叠加规则由销售开单侧结算面板处理。
- **商城营销口径**：`商城拼团/秒杀/预售` 三者均为「活动 + 订单」双视图（活动定义 + 参与订单台账）；`商城弹窗广告`、`加价购`、`热门搜索词推荐` 为商城前台展示位配置。
- **推广口径**：`我要推广` 是**推广物料工作台**（6 个 Tab：商品/优惠券/促销/拼团/秒杀/我的推广），`推广历史查询` 是分享触达台账；效果归入《分析模块 → 营销分析》。
- **上下游**：销售开单（优惠金额/赠品）← 促销与优惠券；商城下单 ← 商城营销活动；效果分析 → 分析模块「营销分析」组。

### 4.2 本轮实测踩出的两条运行期陷阱（已修，务必避开）

1. **`LocalDateTime` 只接受 ISO-8601**：本项目 Jackson 未配全局 `date-format`，`2026-01-01 00:00:00` 形态会 400
   「请求参数格式错误」。日期选择器 `value-format` 一律用 **`YYYY-MM-DDTHH:mm:ss`**。
2. **`CategoryListLayout` 的 `#search-fields` 插槽不可整体 `v-if`**：插槽退化为注释节点时布局会**回落内置「查询」按钮**
   （表单页凭空多出查询）。外层 `div` 必须常驻，`v-if` 写在里层。
