# 物流发货开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/order?stage=pick-ship`（直达订单处理中心拣货/发货阶段）+ 标签"历史"→ 列表页
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表操作页**：发货执行工作台——订单处理中心"2.拣货/发货"阶段的菜单直达入口，**非独立页面**。
- 同源性判定（实据结论）：点击菜单"物流发货"后打开的桌面标签为"**订单处理中心**"并自动选中"2.拣货/发货"阶段。证据链：①桌面标签名为"订单处理中心"，深灰条显示 全部 / 1.待审核 / 2.拣货/发货 三阶段 Tab；②JSON tabs 实据 `["订单处理中心","全部","1.待审核","2.拣货/发货",…]`；③本页 18 个默认列（拣货仓库、集货位等拣货/发货特征列）全部落在订单处理中心拣货/发货子标签 37 列全量集合内且顺序一致；④按钮组含"拣完批量发货""物流备注"等阶段特有执行动作，时间快捷段 8 段与订单处理中心完全一致；⑤JSON pageTitle/url 与同会话订单处理中心记录同源。**结论**：本系统"物流发货"菜单应实现为订单处理中心（/sales/order）携带 `stage=pick-ship` 的直达链接，复用同一视图组件，不重复造独立页面。
- **双入口**：主菜单 → `sales/order?stage=pick-ship`；标签"历史"→ 列表页（查询条件与表格列配置待抓取弹窗数据后补全）。

## 2. 页面配置

### 查询条件

按抓取 JSON 实据（filterLabels：客户、经手人）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、客户、经手人、单据编号、打印次数（带 ≥ 比较符下拉）

（更多条件折叠区是否存在待复核；订单处理中心"全部-按单据"视图有"更多条件"入口。）

### 功能按钮

按抓取 JSON buttons 实据：刷新、批量打印、商品汇总、拣完批量发货、物流备注、查询、跳转（分页跳转）

行级操作：本次快照无数据行未捕获；按"拣完批量发货"推断存在行级"拣完发货"及取消/更多（待复核）。

### 打印配置

待复核（抓取数据未覆盖打印配置弹窗；沿用订单处理中心打印配置）。

## 3. 数据表格列配置

### 默认显示列（18 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、单据状态、打印次数、拣货仓库、集货位、客户、销售金额、商品数量、预计发货时间、经手人、摘要、提货地址、配送方式、物流公司、单据来源、单据备注

> JSON columns 首项"操作 单据日期 单据编号"为抓取拼接串（表头合并单元格的文本拼接），非真实单列，已剔除，不计入列数。

### 全部可配置列（37 列，订单处理中心拣货/发货子标签，销售域《订单处理中心开发文档》依据）

单据日期、单据编号、单据状态、打印次数、结算状态、拣货仓库、集货位、客户、销售金额、体积（m³）、重量（kg）、商品行数、商品数量、已拣货数量、未拣货数量、已发货数量、未发货数量、收货人、联系电话、收货地址、预计发货时间、经手人、摘要、提货地址、配送方式、物流公司、配送司机、单据来源、制单时间、表头自定义字段1~5、单据备注、排序、排序值

## 4. 业务规范

- 进入本视图的源单是**销售订单**（单据状态处于"待发货"段），发货执行在销售订单上完成拣货确认与发货确认。
- **拣完批量发货**：勾选多行后批量执行发货确认；推断行级有对应"拣完发货"（待复核）。发货后生成**销售出库单（XSCKD-）**——《发货查询开发文档》实据：发货查询中每行销售出库单均有"来源订单 XSDD-"回链。
- **物流备注**：对选中单据填写物流方向备注（具体交互待复核）。
- **商品汇总**：把选中订单按商品汇总数量（配货用）；**批量打印**：批量打印选中订单。
- **拣货仓库 / 集货位**列：支持按仓库分单拣货、集货位归集待发，是波次拣货的字段基础。
- 打印次数可作为查询条件（≥ 比较符），用于筛出未打印/已打印单据。
- 发货完成后订单在销售主线进入"发货完成 → 交易完成"（订单处理中心统计卡片口径），出库单进入发货查询台账。
- 上下游：本页 = 订单处理中心"2.拣货/发货"阶段（入口直达，见同源性判定），上游为"1.待审核"（销售订单提交后）；下游发货查询（发货后生成的销售出库单台账）、配送查询（出库单进入配送任务）；退货方向对称页物流退货收货（收货业务组）。
