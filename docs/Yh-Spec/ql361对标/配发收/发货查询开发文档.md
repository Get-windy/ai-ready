# 发货查询开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`dispatch/ship-query`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页**：销售出库单（XSCKD）台账查询——发货结果检索，含结算状态与来源订单回链；无阶段 Tab、无新增按钮，纯查询定位。
- 与同组"物流发货"构成**"执行 + 查询"配对**：物流发货处理发货前的销售订单，发货查询检索发货后生成的销售出库单。
- 单入口（无历史/添加标签）。
- 截图：![发货查询](../../../../tool-results/ql361/pages/配发收__发货业务__发货查询.png)

## 2. 页面配置

### 查询条件

按抓取 JSON 实据（filterLabels：客户、经手人、仓库）与截图确认：

- 查询方案（--查询方案--，支持保存方案）
- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）、单据编号、客户、经手人、仓库、结算状态（全部）
- 来源订单（按源销售订单号检索）
- 勾选项：显示红冲

### 功能按钮

按抓取 JSON buttons 实据：刷新、批量打印、商品汇总、更多、查询、跳转（分页跳转）

行级操作（截图确认）：物流/备注（物流信息与备注维护，具体弹窗交互待复核）。

### 打印配置

待复核（抓取数据未覆盖打印配置弹窗；"更多"内预计含打印/导出类入口）。

## 3. 数据表格列配置

### 默认显示列（15 列，抓取 JSON columns 实据）

操作、单据日期、单据编号、单据状态、来源订单、仓库、客户、经手人、本单金额、已结金额、结算状态、数量、产生方式、单据备注、打印次数

> JSON columns 首项"操作 单据日期 单据编号"为抓取拼接串（表头合并单元格的文本拼接），非真实单列，已剔除，不计入列数。

## 4. 业务规范

- 一行 = 一张**销售出库单**（单据编号 XSCKD- 前缀，与销售域《销售出库单开发文档》编号规则一致）。
- **来源订单**列回链**销售订单**（XSDD- 前缀）：销售订单经"拣货/发货"执行后生成销售出库单，一单对一单（本快照中每行均为一对一）。
- **单据状态**实值为"已记账"（绿色标签）：出库单记账后库存扣减生效。
- **结算状态**与**已结金额**：出库单的收款结算进度（实值"结算完成/未结算"；存在本单金额 90、已结金额 0 的未结算行），发货与收款解耦。
- **显示红冲**勾选：被红冲的出库单默认隐藏，勾选后显示。
- 上下游：上游物流发货（订单处理中心拣货/发货阶段直达）、销售出库单（销售域表单页）；同组物流发货（执行页）；下游配送查询（配送任务组织）；财务收款（结算状态/已结金额口径来源，待复核）。
