# 商机开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`crm/opportunity/index`（列表）+ `crm/opportunity/form`（表单）
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **双入口**（display_mode=1，tag=添加）：主按钮 → 列表页 `crm/opportunity/index`；标签"添加"→ 新增/编辑表单页 `crm/opportunity/form`。
- **列表页**：商机台账（我方实现，views/crm/opportunity/index.vue）。
- **表单页**：CRM 商机——线索转化/商机阶段推进（我方实现，views/crm/opportunity/form.vue）。

## 2. 页面配置（列表页）

### 查询条件

来源：我方源码 `crm/opportunity/index.vue`（5 项）

- `name` 商机名称（输入）
- `customerName` 客户名称（输入）
- `stage` 商机阶段（下拉：线索/资格确认/方案报价/商务谈判/成交阶段/已成交/已流失）
- `ownerId` 负责人（下拉，用户选择）
- `minAmount` / `maxAmount` 预计金额区间（数字区间）

### 功能按钮

来源：我方源码 `crm/opportunity/index.vue`

- 工具栏：新增（Ctrl+N）、刷新（F5）、查询、重置
- 行操作：查看、编辑、添加跟进、关闭商机

## 3. 表单页配置

### 表头字段（必填 *）／全部表单字段（16 个）

来源：我方源码 `crm/opportunity/form.vue`

- 必填：商机名称\*（opportunityName）、客户名称\*（customerName）
- 选填：商机编号（自动生成，disabled）、来源线索ID、阶段、预计金额、实际金额、赢单概率(%)、商机类型、商机来源、意向产品、需求描述、竞争对手、赢单原因、输单原因、状态

### 字段分组／录单默认值／打印设置

- 字段分组：单块基本信息（BillFormPage basic-info，无底部 Tab；底部按钮：保存 Ctrl+S / 提交 Ctrl+Enter）
- 录单默认值：商机编号自动生成、阶段默认"初步接触"(1)（select 首项）；其余字段无显式默认值
- 打印设置：源码未发现打印配置，省略

## 4. 数据表格列配置

### 默认显示列（9 列，来源：我方源码 `crm/opportunity/index.vue`）

商机名称、客户名称、阶段、预计金额、成交概率、优先级、负责人、预计成交日期、操作

### 全部可配置列（9 列）

列配置弹窗按页面配置/列配置齿轮实现；源码仅定义默认 `vxeColumns` 数组（9 列），全部可配置列与默认列一致，未发现额外隐藏列定义。

## 5. 业务规范

- 双入口配置：主按钮 path=`crm/opportunity/index`，标签按钮 list_path=`crm/opportunity/form`，tag_label=添加（sys_menu 数据库配置）。
- 我方实现模式：表单页+列表页均由我方标准组件（BillFormPage/BillTableList 等）实现。
- CRM 商机：线索转化/商机阶段推进；成交后签订合同（见《合同开发文档》），客户落 CRM 客户池（见《客户开发文档》）。

## 6. 实现差异说明

- ql361 对标系统无此页面（我方独有功能），本文档基于我方实现 + 数据库双入口菜单配置（sys_menu display_mode=1）。
