### 口径说明

- **粒度**：一行 = 单据 × 商品明细（× 批次）；`单据编号` 重复多行即同单多品（实测 `XSCKD-20260901-002` 连续 4 行）。
- **账面入库 / 账面出库双组**：入 / 出**分列**（出库单只填 `账面出库`，入库单只填 `账面入库`，实测零值填充另一组），每组四子列 = 数量 / 小单位数量 / 成本单价 / 成本金额，是**该笔流水的账面影响**，不是余额。
- **批次维度**：`批次条码` + `生产日期` + `到期日期` 三列与《查批次》同源；行级 `批次号` 链接即跳《查批次》的批次跟踪视图。
- **客户 / 收货信息列群**：`客户级别`、`所属分类`、`地址`、`联系人`、`客户备注`、`收货人姓名`、`收货人电话`、`收货人地址` 为往来单位侧快照（默认隐藏），支撑配送类单据的收货落点追溯。
- **单据链信息**：`来源订单`（上游单据）、`单据类型`、`单据明细备注`、`记账时间`、`是否赠品`——`记账时间` 默认隐藏，用于区分单据日期与过账日期口径。
- **成本口径**：`成本单价 / 成本金额` 按出库/入库时的成本价（批次成本 / 移动加权）；实测 `0.625 × 288 = 180` 勾稽成立。

## 4. 业务规范

### 统计口径（明细账粒度）

- **粒度**：一行 = 一张单据 × 一个商品明细（× 批次）；`单据编号` 重复即同单多品。
- **账面入库 / 账面出库**：入 / 出数量**分列**（出库单只填账面出库，入库单只填账面入库）；基准文档记「`数量` 为入 − 出净值口径（具体符号规则待复核）」——本次实测 `columnConfig` **无独立 `数量` 列**（`数量` 是 `账面入库` / `账面出库` 两组的同名子列），**基准该表述待复核**。
- **成本口径**：`成本单价` / `成本金额` 按出库/入库时的成本价（批次成本 / 移动加权）。
- **批次维度**：`批次条码` + `生产日期` + `到期日期` 三列与《查批次》同源。
- **显示红冲**：勾选后红冲单明细入列（与《经营历程》「显示红冲」同规则），实测默认不勾选。
- **日期类型**：单据日期（实测默认）/ 其他日期口径（**可选值待复核**）。
- **期间口径**：查询区默认 `本月`（实测 `2026-09-01 至 2026-09-15`），全部流水按此区间过滤；分页 19 行/页。

### 与其他页面关系

- 上游：全部出入库单据（销售出库 / 采购入库 / 调拨 / 盘点 / 借进借出 / 采退 / 销退等）过账流水。
- 联查终点：《进销存分析》行级「对账」→ 本页该商品期间流水；各汇总页金额钻取的明细落地页。
- 行级去向：`批次号` → 《查批次》批次跟踪；`单据编号` → 打开源单据。
- 同组页面：《查库存》（时点存量）、《查批次》（批次台账）、《进销存分析》（期间汇总）。
