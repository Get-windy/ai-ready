# 费用单开发文档

## 页面概述

| 页面 | 地址 | 说明 |
|------|------|------|
| 新增/编辑费用单表单页 | 对标系统：https://22stable.ql361.com/desktop.html#/（桌面式多标签架构，页面以桌面标签打开，无独立路由）；菜单路径：财务 → 收入支出 → 费用单；本系统路由：http://localhost:5656/finance/expense-doc | 表单页：非主营支出的费用登记（往来单位费用/内部费用两类） |

### 配置功能说明

- **页面配置**（标题行右侧齿轮图标）：管理表单字段的显示、隐藏和排序
- **列配置**（明细表格左上角表头单元格内齿轮图标）：管理明细列的显示、隐藏、排序

## 表单页配置

### 表头字段（抓取 JSON filterLabels + 截图确认）

费用类型：往来单位费用 / 内部费用（单选，默认往来单位费用）
必填：往来单位*、经手人*（另有单据日期* 截图确认必填；选"内部费用"时往来单位是否仍必填待复核）
付款区：付款账户、付款金额（带"全/清"）、更多账户
只读联动：往来编号（随往来单位带出）

### 字段分组

费用类型单选 → 表头（往来单位/往来编号/经手人/单据日期/付款账户/付款金额/更多账户）→ 费用项明细表格 → 备注区（单据备注）→ 单据信息（制单人/制单时间/打印次数/打印记录）→ 底部本单金额与操作

### 数据表格列配置

#### 默认显示列（抓取 JSON columns 实据，5 列）

操作、费用编号、费用名称、金额、备注

> JSON columns 首项"操作 费用编号 费用名称 金额 备注"为抓取拼接串（表头整行文本），已剔除，不计入列数。

## 业务规范说明

### 状态流转与特殊交互

- 保存草稿（Ctrl+S）→ 记账（Ctrl+Enter）：记账后费用生效——付款账户资金减少、费用科目入账
- 往来单位费用 vs 内部费用：往来单位费用挂往来单位（如为客户代垫运费、供应商罚款）；内部费用不挂往来单位（公司日常开支），仅科目入账
- 一单多费用项：明细按费用类型分行（费用编号/费用名称来自费用类型主数据），本单金额=Σ金额
- 付款金额与费用合计的差额处理（挂账费用/后续核销）待复核
- 记账后生成会计凭证（KJPZ-）；损益类费用科目实据 6601 销售费用/6602 管理费用/6603 财务费用（科目余额表实据）

### 与其他页面关系

- 费用类目主数据：资料 → 财务账户 → 费用类型（抓取成功：列=操作、科目编号、科目名称、核算项；按钮=新增费用…）
- 反向单据：《其他收入开发文档》（结构对称）
- 采购侧费用另有"采购费用分摊"（采购域，抓取标签实据）
- 下游账簿：明细账/科目余额表费用科目
- 本系统前端目录 `finance/expense-doc`（另有 expense-apply/expense-approval/expense-pay/expense-reimburse/expense-stats 费用报销系列，对应关系待复核）

### 客户来源

往来单位来源通过 ERP 模块的往来单位分类处理（客户/供应商均可，费用对象按业务定），而非 CRM 模块的客户信息。
