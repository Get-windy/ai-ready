# 供应商门户用户手册

## 1. 系统概述

### 1.1 欢迎使用供应商门户
供应商门户是AI-Ready ERP系统的核心协同平台，专为供应商合作伙伴设计。通过本门户，您可以：
- **实时查询**：查看订单状态、发货进度、历史交易
- **高效对账**：在线核对账单、处理对账差异
- **便捷报价**：响应询价、提交报价、跟踪结果
- **自主管理**：维护企业信息、管理用户权限

### 1.2 系统要求
- **浏览器**：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+
- **屏幕分辨率**：推荐1920×1080或更高
- **网络环境**：稳定的互联网连接，建议10Mbps以上
- **设备支持**：PC、平板、手机（推荐PC端操作）

## 2. 账号与登录

### 2.1 首次访问
1. 访问供应商门户网址：`https://supplier.enterprise.com`
2. 点击【注册新账号】按钮
3. 填写企业基本信息：
   - 企业名称（需与营业执照一致）
   - 统一社会信用代码
   - 联系人姓名、电话、邮箱
   - 设置登录密码（8-20位，包含大小写字母和数字）
4. 提交注册申请，等待管理员审核（1-2个工作日）

### 2.2 账号激活
1. 审核通过后，系统将发送激活邮件到注册邮箱
2. 点击邮件中的激活链接
3. 首次登录需完善企业信息：
   - 企业logo上传
   - 详细地址信息
   - 银行账户信息（用于结算）
   - 税务信息

### 2.3 登录系统
1. 访问供应商门户登录页面
2. 输入用户名（注册邮箱）和密码
3. 可选择「记住密码」方便下次登录
4. 点击【登录】按钮进入系统

> **注意**：连续5次密码错误将锁定账号30分钟，请联系客服解锁。

### 2.4 密码管理
- **修改密码**：登录后点击右上角头像→账号设置→安全设置→修改密码
- **忘记密码**：登录页点击「忘记密码」→输入注册邮箱→按邮件指引重置
- **密码策略**：
  - 长度8-20位
  - 必须包含大小写字母和数字
  - 不能与最近5次密码相同
  - 每90天需修改一次

## 4. 订单管理（核心功能1）

### 4.1 查看订单列表
1. 点击主菜单【订单管理】
2. 系统显示所有订单列表，默认按创建时间倒序排列
3. 支持以下筛选条件：
   - 订单状态：待确认、已确认、生产中、已发货、已完成、已取消
   - 订单日期范围
   - 订单金额范围
   - 客户名称
   - 产品类别

### 4.2 订单详情查看
1. 在订单列表中点击任意订单行
2. 弹出订单详情窗口，包含：
   - **基本信息**：订单编号、客户名称、下单时间、交货日期
   - **产品明细**：产品名称、规格、数量、单价、金额
   - **物流信息**：发货地址、物流公司、运单号
   - **状态历史**：订单状态变更记录
   - **附件文档**：技术图纸、合同文件等

### 4.3 订单状态更新
1. **确认订单**：收到新订单后，3个工作日内需确认
   - 点击订单右侧【确认】按钮
   - 确认交货日期和生产计划
   - 系统自动发送确认通知给采购方

2. **更新生产进度**：
   - 点击【更新进度】按钮
   - 选择当前进度：备料中、生产中、质检中
   - 上传相关照片或文档（可选）
   - 系统自动通知采购方进度更新

3. **发货操作**：
   - 产品生产完成后，点击【发货】按钮
   - 填写物流信息：物流公司、运单号、发货时间
   - 上传发货单照片
   - 系统自动更新订单状态为「已发货」

### 4.4 批量操作
1. **批量导出**：
   - 勾选多个订单
   - 点击【批量导出】按钮
   - 选择导出格式：Excel、PDF
   - 系统生成包含选中订单的报表

2. **批量打印**：
   - 勾选多个订单
   - 点击【批量打印】按钮
   - 系统生成打印预览，可调整打印设置
   - 支持直接打印或导出为PDF

## 5. 对账中心（核心功能2）

### 5.1 月度对账单
1. 点击主菜单【对账中心】
2. 默认显示当月对账单，包含：
   - 期初余额
   - 本期交易明细（订单、退货、调整）
   - 本期应收/应付总额
   - 期末余额
   - 对账差异明细（如有）

### 5.2 对账流程
1. **查看对账单**：
   - 选择对账月份
   - 系统生成该月完整对账单
   - 支持导出Excel进行线下核对

2. **核对交易明细**：
   - 逐条核对订单、退货等交易记录
   - 标记有疑问的交易项
   - 添加核对备注说明

3. **确认对账结果**：
   - 核对无误后，点击【确认对账】按钮
   - 系统生成电子对账确认书
   - 需要输入支付密码确认

4. **处理对账差异**：
   - 如发现差异，点击【发起争议】按钮
   - 填写差异说明和期望调整金额
   - 上传相关凭证（截图、照片等）
   - 系统通知采购方处理人员

### 5.3 历史对账查询
1. 在对账中心页面点击【历史对账】
2. 可按年份、季度筛选历史对账单
3. 支持查看历年对账记录和确认状态
4. 可导出历史对账汇总报表

## 6. 报价管理（核心功能3）

### 6.1 接收询价单
1. 系统收到新询价单时，顶部通知栏会显示红点提醒
2. 点击主菜单【报价管理】→【待报价】
3. 查看询价单详情：
   - 询价产品清单（名称、规格、数量）
   - 技术要求和技术图纸
   - 报价截止时间
   - 交货地点和条件

### 6.2 提交报价
1. **填写报价信息**：
   - 单价（含税/不含税）
   - 总金额自动计算
   - 交货周期（从确认订单到交货的天数）
   - 付款条件（账期、预付款比例等）
   - 备注说明（特殊要求、替代方案等）

2. **上传报价文件**：
   - 支持上传正式报价单PDF
   - 上传产品样品照片或视频
   - 上传质量认证证书
   - 上传过往合作案例

3. **提交报价**：
   - 确认报价信息无误
   - 点击【提交报价】按钮
   - 系统提示提交成功，并显示报价编号

### 6.3 报价状态跟踪
1. **待审核**：报价已提交，等待采购方审核
2. **审核中**：采购方正在评估报价
3. **已接受**：报价被接受，将生成正式订单
4. **已拒绝**：报价未被接受，可查看拒绝原因
5. **已过期**：超过报价有效期未处理

### 6.4 报价历史
1. 可查看历史所有报价记录
2. 支持按状态、时间、客户筛选
3. 可分析报价成功率、平均响应时间等数据
4. 支持导出报价分析报表

## 7. 供应商管理（核心功能4）

### 7.1 企业信息维护
1. 点击主菜单【供应商管理】→【企业信息】
2. 可维护以下信息：
   - **基本信息**：企业名称、logo、简介
   - **联系信息**：地址、电话、邮箱、联系人
   - **资质信息**：营业执照、税务登记证、行业许可证
   - **财务信息**：银行账户、税号、开票信息

### 7.2 用户权限管理
1. **添加子账号**：
   - 点击【用户管理】→【添加用户】
   - 填写用户信息：姓名、邮箱、部门、职位
   - 设置初始密码（系统生成或手动设置）
   - 分配权限角色

2. **权限角色**：
   - **管理员**：全部权限，包括用户管理、系统设置
   - **操作员**：订单处理、对账核对、报价提交
   - **财务员**：对账确认、发票管理
   - **查看员**：仅查看权限，无操作权限

3. **权限设置**：
   - 按模块设置具体操作权限
   - 支持数据权限控制（如只能查看本部门订单）
   - 可设置操作时间限制

### 7.3 资质证书管理
1. 上传各类资质证书：
   - 营业执照（每年更新）
   - 质量体系认证（ISO9001等）
   - 产品检测报告
   - 专利证书

2. 证书到期提醒：
   - 系统提前30天发送到期提醒
   - 过期证书自动标记为无效
   - 需及时更新有效证书

## 8. 数据导入导出

### 8.1 批量导入订单
1. **下载模板**：
   - 点击订单管理页面【批量导入】按钮
   - 下载Excel导入模板
   - 按模板格式填写订单数据

2. **数据校验**：
   - 产品编码必须存在于系统中
   - 单价必须在合理范围内
   - 交货日期不能早于当前日期
   - 必填字段不能为空

3. **执行导入**：
   - 上传填写好的Excel文件
   - 系统校验数据格式
   - 显示导入预览，确认无误后执行
   - 导入成功生成导入报告

### 8.2 批量导出数据
1. **订单数据导出**：
   - 支持导出字段自定义
   - 导出格式：Excel、CSV、PDF
   - 支持按条件筛选后导出

2. **对账数据导出**：
   - 导出月度对账单
   - 导出交易明细
   - 导出对账差异报告

3. **报价数据导出**：
   - 导出报价历史
   - 导出报价分析报表
   - 导出询价记录

### 8.3 数据接口
1. **API接口**：支持通过API与内部系统对接
2. **Webhook**：支持重要事件实时推送
3. **SFTP**：支持大文件通过SFTP传输

## 10. 故障排除

### 10.1 常见问题
1. **无法登录**：
   - 检查用户名密码是否正确
   - 确认网络连接正常
   - 清除浏览器缓存后重试

2. **页面加载慢**：
   - 检查网络速度
   - 关闭浏览器其他标签页
   - 联系客服检查服务器状态

3. **数据不显示**：
   - 检查筛选条件设置
   - 确认有数据权限
   - 刷新页面重试

## 11. 附录

### 11.1 操作流程图
```
注册账号 → 完善信息 → 等待审核 → 账号激活 → 首次登录
    ↓
查看订单 → 确认订单 → 更新进度 → 发货操作
    ↓
月度对账 → 核对明细 → 确认对账 → 处理差异
    ↓
接收询价 → 提交报价 → 跟踪状态 → 查看结果
```

### 11.2 重要时间节点
- **订单确认**：收到订单后3个工作日内
- **报价提交**：询价截止时间前
- **对账确认**：每月10日前确认上月对账
- **证书更新**：到期前30天内完成更新

### 11.3 文件命名规范
- 报价单：`报价_客户名称_YYYYMMDD_序号.pdf`
- 发货单：`发货_订单号_YYYYMMDD.pdf`
- 资质证书：`证书类型_有效期至YYYYMMDD.pdf`
