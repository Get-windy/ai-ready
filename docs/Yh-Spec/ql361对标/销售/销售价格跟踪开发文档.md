# 销售价格跟踪开发文档

> 对标系统：22stable.ql361.com（桌面多标签，无独立路由）｜本系统路由：`sales/price-track`
> 通用规范见《对标开发技术参考文档》第 4、5 章（价格等级 8 字段 / 客户来源 / 红线 / 验收）。

## 1. 页面概述

- **列表查询页（查询 + 轻维护复合页）**：客户-商品维度的最近成交价跟踪（最近销售价/折扣/日期），支持手工新增/修改/删除。
- 页面结构：查询区 + 工具按钮区 + 左侧商品分类树 + 数据表格 + 底部分页。

## 2. 页面配置

### 查询条件（抓取 JSON filterLabels 实据，6 项）

- 时间快捷段：昨日、今日、本周、近一周、本月、上月、近三月、本年
- 日期范围（起 至 止）
- 往来单位（弹窗选择）
- 商品（弹窗选择）
- 单位类型（下拉，默认"全部"）
- 仅显示已选中（勾选框）

### 功能按钮

- 抓取 JSON buttons 实据：新增、刷新、打印(F8)、更多、查询、跳转（分页）
- 行级操作（截图确认）：修改、删除；行首带勾选框（配合批量操作，批量项在"更多"内，具体内容待复核）

### 打印配置

无（页面有打印(F8)按钮，打印模板配置细节待复核）。

## 3. 数据表格列配置

### 默认显示列（抓取 JSON columns 实据，11 列）

操作、商品名称、货号、商品单位、条码、往来单位编号、往来单位名称、最近销售价、最近销售折扣（%）、最近销售日期、最后修改时间

### 全部可配置列（XSMK《销售价格跟踪页开发文档》依据，13 列）

商品名称、货号、商品单位、条码、规格、型号、产地、往来单位编号、往来单位名称、最近销售价、最近销售折扣（%）、最近销售日期、最后修改时间

## 4. 业务规范

- 一行 = 一个"商品 × 往来单位"组合的最近成交价记录（截图实据：同一商品按不同往来单位重复多行，价格各不相同）。
- 数据来源两类：销售单据成交自动写入（最近销售价/最近销售折扣/最近销售日期）+ 手工新增/修改（"最后修改时间"列存在即为此佐证）；自动与手工的优先级规则待复核。
- 录单联动：销售订单/出库单录单选择客户+商品时按此表带出该客户最近售价（XSMK 明细全量列含"最近销售日期、最近售价"字段，与此页数据同源）。
- 单位类型：同一商品多计量单位（瓶/箱/件/袋）时分别跟踪价格（截图实据同商品按"瓶/箱"分行）。
- 数据写入方：销售出库单、销售订单等成交类单据；数据消费方：各销售单据录单页的"最近售价"参考与价格带出逻辑；商品分类树与"资料"域商品分类一致。

## 5. 实现差异说明（2026-08-12 对标核对）

- 我方：**销售明细流水**（每行 = 一条出库明细 + 销售单价走势图，只读）——`views/sales/price-track/index.vue` 调 `/sales/price-track/page`。
