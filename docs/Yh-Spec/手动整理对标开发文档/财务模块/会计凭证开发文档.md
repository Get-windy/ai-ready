## 页面概述

会计凭证用于**手工录入记账凭证**（明细摘要/科目/借贷金额录入式网格）。模块含两个页面：

| 页面 | 地址 | 说明 |
|------|------|------|
| 记账凭证表单页 | `finance/voucher/form`（主菜单入口） | 录入凭证分录 |
| 记账凭证列表页（历史） | `finance/voucher/index` | 双入口「历史」标签 |

单号实据：`KJPZ-20260723-127`（`KJPZ-` 前缀 + `YYYYMMDD-序号`；业务单据自动生成凭证共用此号段）。

## 新增编辑记账凭证表单页配置

### 页面结构（`a-form`/网格录入）
表头字段区 → 凭证分录录入表格（摘要/科目/借贷金额）→ 备注区 → 单据信息 → 底部操作。

### 表头字段
| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 单据日期 | a-date-picker | 是 | 默认当天 |
| 经手人 | a-select | 否 | 默认当前登录人 |
| 部门 | a-select | 否 | |

### 凭证分录录入表格
操作、明细摘要、科目编号、科目全名、明细科目、借方金额、贷方金额。

- **科目编号**：输入/选择科目编码，联动带出科目全名。
- **科目全名**：科目完整路径名（随科目编号联动）。
- **明细科目**：科目的末级/辅助明细（核算项，如往来单位/部门/职员）。

### 工作流按钮
| 状态 | 按钮 | 动作 |
|------|------|------|
| 任意 | 保存草稿 Ctrl+S | `save` |
| 任意 | 记账 | `confirm`（借贷平衡校验） |

## 业务规范说明

- **借贷平衡**：借合计=贷合计方可记账。
- **核算项**：科目挂核算项（往来单位/部门/职员）时需选明细科目。
- **自动生成**：业务单据（收款/付款/收入/费用等）记账自动生成 KJPZ- 凭证，共用号段。
- **下游**：凭证 → 总账/明细账/科目余额表/辅助核算余额表。
- **单号前缀** `KJPZ-`。
