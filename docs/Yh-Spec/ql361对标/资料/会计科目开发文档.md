## 业务规范说明

### 状态流转与特殊交互

- 科目四大类：资产类（1）、负债类（2）、所有者权益类（4）、损益类（6）——截图实据为顶层大类行，编号即大类码；成本类未见（商贸企业口径，待复核）
- 树形层级：左侧科目分类树 + 行首文件夹图标 + "显示层次结构"默认勾选，科目按大类 → 一级科目 → 明细科目逐级展开（如 损益类 下的 6601 销售费用，见费用类型页）
- 核算项：科目的辅助核算维度（本页该列数据为空，配置细节待复核）
- 停用优先：与"显示停用"勾选项配套；被凭证引用的科目不允许物理删除（生产级口径）

### 与其他页面关系

- 银行账户：资金账户（1001 现金库存、1002 银行存款）即本科目表资产类下的科目
- 费用类型：费用类型科目（6403/6601 等）即本科目表损益类下的科目
- 其他收入：收入类型科目（6101 公允价值变动损益/6111 投资收益/6301 营业外收入/6902 利息收入）即本科目表损益类下的科目
- 财务凭证：单据（收付款/费用/收入）按科目生成凭证
