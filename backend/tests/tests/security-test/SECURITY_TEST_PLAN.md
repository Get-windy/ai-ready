# 企智连安全测试方案

## 1. 测试概述

### 1.1 测试目标
- 验证企智连系统的安全性
- 识别潜在安全风险
- 确保符合安全标准和规范

### 1.2 测试范围
- 认证与授权测试
- 数据安全测试
- API安全测试
- 业务安全测试

### 1.3 测试依据
- OWASP Top 10
-ISO 27001
- 等保2.0三级要求

## 2. 认证与授权测试

### 2.1 登录安全测试

| ID | 测试项 | 优先级 | 类型 | 描述 |
|----|--------|--------|------|------|
| TC-SEC-001 | 暴力破解防护 | P0 | 安全 | 连续失败5次锁定账号 |
| TC-SEC-002 | 密码策略 | P0 |安全 | 密码长度≥8位，含大小写、数字、特殊字符 |
| TC-SEC-003 | 密码加密存储 | P0 | 安全 | 密码使用BCrypt加密 |
| TC-SEC-004 | 短信验证码 | P1 | 安全 | 验证码60秒有效，6次重试限制 |
| TC-SEC-005 | 登录日志审计 | P1 | 安全 | 记录登录时间、IP、设备信息 |

#### TC-SEC-001: 暴力破解防护

```
测试步骤:
1. 连续输错密码5次
2. 观察系统行为

预期结果:
- 第5次失败后，账号被锁定
- 提示"账号已被锁定"
- 可通过重置密码解锁
- 记录安全日志
```

#### TC-SEC-002: 密码策略

```
测试步骤:
1. 尝试设置弱密码（123456）
2. 尝试设置过短密码（5位）
3. 尝试设置纯数字密码

预期结果:
- 系统拒绝弱密码
- 提示密码不符合要求
- 密码强度指示器显示
```

```

- 用户已登录，Token有效期2小时

测试步骤:

```

#### TC-SEC-011: 垂直越权防护

```
前置条件: 
- 普通用户has普通权限
- 管理员接口/api/v1/admin/*

测试步骤:
1. 用普通用户Token访问管理员接口

预期结果:
- 返回403 Forbidden
- 提示"无访问权限"
- 记录安全日志
```

#### TC-SEC-012: 水平越权防护

```
前置条件: 
- 用户A有权限访问自己的订单
- 用户B有权限访问自己的订单

测试步骤:
1. 用户A尝试访问用户B的订单详情

预期结果:
- 返回403 Forbidden或404 Not Found
- 不泄露用户B的订单信息
- 记录安全日志
```

## 6. 安全测试工具

### 6.1 工具选型

| 工具 | 用途 | 类型 |
|------|------|------|
| **OWASP ZAP** | Web应用扫描 | OSS |
| **Burp Suite** | 手动渗透测试 | 商业/OSS |
| **sqlmap** | SQL注入测试 | OSS |
| **Nmap** | 端口扫描 | OSS |
| **Nessus** | 漏洞扫描 | 商业 |
| **Arachni** | Web安全扫描 | OSS |
| **DirBuster** | 目录枚举 | OSS |

### 6.2 工具使用示例

```bash
# OWASP ZAP主动扫描
zap-baseline.py -t http://test.qizhilian.com -r report.html

# sqlmap注入测试
sqlmap -u "http://test.qizhilian.com/api/user?id=1" --batch

# DirBuster目录枚举
dirb http://test.qizhilian.com /path/to/wordlist.txt
```

## 7. 安全测试流程

### 7.1 测试阶段

| 阶段 | 时间 | 内容 |
|------|------|------|
| 静态分析 | Day 1 | 代码审计、配置检查 |
| 动态扫描 | Day 2-3 | 工具扫描、手工测试 |
| 漏洞修复 | Day 4-5 | 修复高危漏洞 |
| 复测验证 | Day 6 | 漏洞复测 |
| 报告输出 | Day 7 | 安全报告 |

### 7.2 漏洞分级标准

| 等级 | 描述 | 修复时限 |
|------|------|----------|
| 高危 | 可直接导致系统沦陷 | 24h |
| 中危 | 可能导致信息泄露 | 1周 |
| 低危 | 功能性问题 | 下个版本 |
