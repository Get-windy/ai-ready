## 页面概述

会计凭证模块用于**手工录入记账凭证**（明细摘要/科目/借贷金额录入式网格）。模块含两个页面（双入口）：

| 页面 | 地址 | 说明 |
|------|------|------|
| 记账凭证表单页 | `finance/voucher/form`（主菜单入口） | 录入凭证分录（表头 + 分录明细网格） |
| 记账凭证列表页（历史） | `finance/voucher/index` | 双入口「历史」标签，列表页**单视图**（无子Tab，凭证多级聚合网格） |

单号实据：`KJPZ-20260907-148`（`KJPZ-` 前缀 + `YYYYMMDD-序号`；业务单据自动生成凭证共用此号段）。

### 配置功能说明（每个页面都有）
- **页面配置/列配置**：管理页面级字段与数据表列的显示/隐藏/排序/宽度/冻结。
- 页面配置在页面顶部按钮区域，列配置在数据表右上角表头单元格内齿轮图标。
- 列配置弹窗结构：个人配置 Tab / 全局配置 Tab，配置列：上级、列名、显示名、显示、回车键跳转、公式内容；支持上移/下移/恢复默认/保存。
- 表单页页面配置弹窗（`BillPageConfigDialog`）结构：页面配置 / 打印设置 两 Tab；列表页页面配置弹窗（Vue `配置`）结构：查询条件 / 功能按钮 两 Tab。
- ⚠️ **当前实现说明**：本页列表/表单**尚未升级金标准组件**（列表仍为 `PageContainer`+`SearchBar`+`BillTableList`，表单为自定义 `a-form` + 分录网格），见「实现差异说明 → 待完善」。

## 业务规范说明

- **借贷平衡**：借合计=贷合计方可记账。
- **核算项**：科目挂核算项（往来单位/部门/职员）时需选明细科目，保证辅助核算余额可查。
- **自动生成**：业务单据（收款/付款/收入/费用等）记账自动生成 KJPZ- 凭证，共用号段。
- **单据类型**：系统凭证（业务自动生成）/ 手工凭证（用户录入）。
- **下游**：凭证 → 总账/明细账/科目余额表/辅助核算余额表。
- **单号前缀** `KJPZ-`（前端生成，后端 save 原样落库）。

## 最终裁决方案（2026-09-07 · 严格按此执行）

- **P0 记账平移（红线）**：业务单据记账必须经凭证（KJPZ-）落库并实现借贷平衡，**严禁绕过凭证直接改科目余额**；每笔合法凭证借合计=贷合计不得例外。
- **P1 核算项**：科目挂核算项（往来单位/部门/职员）时必填明细科目，保证辅助核算余额可查。
- **P1 单一口径**：业务自动生成凭证（单据类型=系统凭证）与手工凭证共用 KJPZ- 号段，无重复号、无双轨。
- **P2 验收**：无桩/无模拟；凭证平衡校验、核算项联动、自动生成需真实数据闭环验证。
