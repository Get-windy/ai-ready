## 页面概述

科目余额表是**按科目汇总期初/本期发生/本年累计/期末四段余额的试算平衡表**。**复合页**（查询 + 分组表头汇总表格 + 合计行），无分页，单入口。

菜单：财务 → 账簿 → 科目余额表。

### 配置功能说明
- **列配置**：数据表表头内齿轮图标（`.icon-shezhi2`，表头左起「𞸎/谢」列）→ 列配置弹窗（个人配置 / 全局配置），配置列：上级、列名、显示名、显示；支持上移/下移/恢复默认/保存。**10 列全部默认显示，无隐藏列**。
- **页面配置**：无。本页工具栏仅 刷新/打印(F8)/导出/明细对账/查询，无「配置」齿轮，故**无页面配置弹窗**（仅列配置弹窗）。
- ✅ **本系统实现**：与对标一致 —— 表头齿轮复用 `BillDetailTable` 内置列配置弹窗（个人配置 / 全局配置，含序号/拖拽上级/列名/显示名/显示/列宽/恢复默认），序号列锁定不可隐藏；本页**不挂载** `PageConfigPanel`。

## 业务规范说明

- **取数逻辑**：数据源自会计凭证分录按科目聚合——期初余额（会计月起时点）、本期发生额（起止月间借贷）、本年累计（年初至止月）、期末余额（止月时点）。
- **试算平衡**：Σ本期借方=Σ本期贷方、Σ本年累计借方=Σ本年累计贷方（凭证借贷守恒表级体现）。
- **明细对账**：科目 → 明细账穿透（科目名称链接 + 「明细对账」按钮）。

### 本系统取数口径（实现即口径）

| 段 | 口径 |
|----|------|
| 期初余额 | `会计年首期期初结转（finance_ledger 首期 opening_debit − opening_credit）` + `本年 会计月(起) 之前凭证分录净额 Σ(借−贷)` |
| 本期发生额 | `fiscal_period ∈ [起, 止]` 的 `Σ借方` / `Σ贷方` |
| 本年累计 | `fiscal_period ≤ 止` 的 `Σ借方` / `Σ贷方`（年初至止月） |
| 期末余额 | `期初 + 本期借 − 本期贷`（逐行勾稽，已实测校验） |
| 数据源 | `finance_voucher_item ⨝ finance_voucher`，`vi.deleted_flag=0 AND v.deleted_flag=0 AND v.status='posted'`，按 `v.fiscal_year` 限定年度 |
| 父级科目 | 金额 = **本级 + 全部下级汇总**（roll-up，环保护）；`hasChildren` 标识 |
| 合计行 | 只累加**顶级科目**（父级未出现在结果集中的科目），父子同屏不重复累加；同时输出本期/本年借贷平衡标记 |
| 层级过滤 | `科目层级` = 显示层级上限（1=仅一级，默认；4=到四级） |
| 无数据科目 | `显示无数据科目=false` 时过滤「期初/本期/本年/期末全为 0」的科目 |

## 接口契约

`GET /api/erp/finance/report/v2/trial-balance-page`
权限：`hasPermission('/api/erp/finance/report/trial-balance', 'finance:report:view')`　无分页。

**入参（`TrialBalanceQuery`）**

| 参数 | 类型 | 说明 |
|------|------|------|
| fiscalYear | Integer | 会计年度（默认当年；前端取「会计月(止)」所属年度） |
| startPeriod | Integer | 会计月(起) 1-12（默认=endPeriod） |
| endPeriod | Integer | 会计月(止) 1-12（默认当前月） |
| subjectLevel | Integer | 科目层级上限（默认 1；空/0=全部层级） |
| subjectKeyword | String | 科目编码/名称模糊（命中项含全部下级） |
| showNoData | Boolean | 是否显示无数据科目（默认 false） |

**出参（`TrialBalancePageDTO`）**

```
{
  records: [{
    subjectType, subjectTypeName, subjectCode, subjectName, level,
    openingBalance, openingDirection,          // 期初余额（借正贷负）+ 方向
    periodDebit, periodCredit,                 // 本期发生额
    yearDebit, yearCredit,                     // 本年累计
    closingBalance, closingDirection,          // 期末余额 + 方向
    hasChildren
  }],
  total,
  summary: {
    openingDebit, openingCredit, periodDebit, periodCredit,
    yearDebit, yearCredit, closingDebit, closingCredit,
    periodBalanced, yearBalanced               // 试算平衡（P0 红线）
  }
}
```

> 说明：项目全局 Jackson 配置将 `Long/BigDecimal` 序列化为字符串（规避 JS 大整数精度问题），前端统一 `Number()` 归一后展示。

## 跨页勾稽关系（账簿组内一致性）

| 关系 | 口径 | 实测 |
|------|------|------|
| 科目余额表 ↔ 明细账 | 同源 `finance_voucher_item ⨝ finance_voucher`(posted)；期末余额应逐科目一致 | ✅ 逐科目一致（1001/1002/1122），全科目 Σ净额 = 明细账期末 = 0 |
| 科目余额表 ↔ 辅助核算余额表 | 辅助余额表按**核算项**列示，其核算项期末净额是科目期末的**子集**（科目可能含未挂核算项分录） | ✅ 1122 完全一致（800=800）；2202 方向一致、金额为子集 |
| 试算平衡 ↔ 凭证 | Σ债权发生 = Σ贷方发生（借贷守恒表级体现） | ✅ 本期 1466=1466、累计 3721=3721、期初 1600=1600、期末 2466=2466 |
| 明细穿透 ↔ 明细账 | 科目行 → 明细账（带科目 + 会计月起止），账面可对上 | ✅ 跳转携带 `subjectCode` + `dateStart/dateEnd` |

> 注：辅助核算余额表按核算项列示，借贷两侧核算维度不同（如 借 1122-客户甲 / 贷 6001 无核算项），故其**表级 Σ借 ≠ Σ贷 属正常**，不可作平衡判据；平衡判据仍以科目余额表/凭证为准。

## 开发原则（通用）
- **页面组件优先复用**、**功能/模块不重复开发**、**阶段结束前回写开发文档**。
- **【金标准】模块级 E2E 脚本统一放 `tools/`**：新增模块级端到端验收脚本命名 `tools/e2e-<模块>.cjs`，用 `NODE_PATH` 加载依赖、**不依赖脚本自身所在位置**；历史散落在项目根目录的脚本已统一归置到 `tools/acceptance/`，**该目录不可再移动**（脚本用 `__dirname` 定位项目根，见其 README）。
- **【金标准】启动进程随手关**：任何人 / 每个 AI 会话在结束工作前，必须关闭**自己启动**的实例 —— 后端 `java -jar ...core-api-*.jar`（含为验证临时复制的 `<模块>-run.jar`）与前端 `vite` dev server，并清理自己产生的临时产物（临时 fat jar、日志、截图）；**不得清理他人产物**（尤其刚打包好的 `target/*.jar`）。详见 `AI_DEVELOPER_RULES.md` **7.3 会话收尾纪律**。
- 本页复用：`CategoryListLayout` / `BillTableList` / `BillDetailTable`（含新增分组表头能力）/ `ExportCsv`；**未新建**任何报表专用表格或列配置组件。
